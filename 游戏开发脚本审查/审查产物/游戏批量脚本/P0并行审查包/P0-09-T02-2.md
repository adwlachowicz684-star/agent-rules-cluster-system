## 判据（先读）

### T02 · 循环变量可为 ±Infinity

正确：上下界都收口为有限值；

**扫描特征**：`for (let i = <非字面量>; i < <非字面量>; ...)` 附近无收口； 失效：`-Infinity + 1` 仍为 `-Infinity`。与 B01 区别：B01 看上界，T02 同时看**起始值**。

## 审查流程

每条三步：

1. **看上下文** —— 必须读命中行**上方 10~30 行注释**。
   这个库大量「看起来像 bug」的写法上方有长注释解释原因，
   **没读注释就报问题是最高频的误报来源**。
2. **问三个问题**：
   - 该值**可能**取到非法值吗？（配置/用户输入/前序运算 → 是；常量/枚举 → 否）
   - 取到非法值后**会报错吗**？（不报错 = 静默失效，严重度更高）
   - 能恢复吗？（不可逆 → 严重度更高）
3. **存疑写探针实测**，不靠推理下结论。

**常见降级**（命中即非真问题）：

| 情况 | 处理 |
|---|---|
| 字段为非数值型（布尔/字符串/枚举） | 忽略 |
| 参数只可能是常量或枚举 | 忽略 |
| 用的是 `clampNum` / `numOr`（内部 isNaN→fallback 有兜底） | 忽略 |
| 上游已夹紧 / 已收口 | 忽略 |
| 文档已明确标注为设计意图 | 降 P2 |
