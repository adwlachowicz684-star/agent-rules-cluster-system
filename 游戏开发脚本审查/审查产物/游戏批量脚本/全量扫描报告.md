## 三·五、重点问题实测确认

以下 6 条已跑最小复现实测，**不是扫描器推断**。

### 1. A03 `clamp` 遇 NaN 穿透（5 处）

```typescript
baseVolume: clamp(opts.volume ?? 1, 0, 4),   // audio:335
```

双重失守：`??` 只挡 `null`/`undefined`；`clamp` 用比较实现，NaN 两个分支都 false。

```
实测：clamp(NaN ?? 1, 0, 4)  →  NaN      （期望 1）
```

**后果**：音量变 NaN → 音频节点静默失效，无报错。

### 2. T01 `while` 角度归一化遇 Infinity 死循环（6 处）

```typescript
while (d > Math.PI) d -= Math.PI * 2;   // gesture:118
```

```
实测：d = Infinity 时，1001 次迭代后 d 仍为 Infinity  ← 永不退出
```

**后果**：主线程挂死。6 处在 `gesture:118/119`、`hitbox:373/374`、`projectile:444/445`。
（`noise`、`perception`、`indicator` 已改用取模修好，这几处是漏网的。）

### 3. E01 `forEach` 遍历监听器 + 回调内退订（1 处）

```typescript
this._listeners.forEach((fn) => fn(result, ctx, target));   // damage-pipeline:155
```

```
实测：订阅者 A/B/C，A 在回调内退订 → 实际执行 A、C，B 被静默跳过
```

**后果**：飘字/音效/统计各自订阅时，某一类反馈永久失效且不报错。
这是上一轮已报的 P0，**当前版本仍未修**。

### 4. C01 裸 Record 查表命中原型链（4 处）

```typescript
const prec = PRECEDENCE[t.value];   // expression:517
```

```
实测：PRECEDENCE["constructor"]  →  [Function: Object]   ← 非 undefined
```

**后果**：表达式里出现 `constructor`/`toString` 等会被当成合法操作符。

### 5. S01 调试/作弊功能默认启用（4 处）

```typescript
this._enabled = opts.enabled ?? true;   // cheatcode:240
```

**后果**：忘记显式关闭时，作弊码与调试控制台在生产环境可用。
按 skill 的升级规则，安全链路 fail-open 一律 P0。

### 6. L01 空 `if` 块 —— 校验写了一半（3 处）

```typescript
if (this._onConflict === 'error') { }   // skill-variant:161
```

**后果**：冲突策略配成 `error` 时什么都不做，静默放行。

## 七、本次扫描器的修正（影响所有历史报告）

### 7.1 行号系统性错位

`strip_comments` 把块注释替换成等量换行，导致后续行整体前移：

```
受影响文件   215 / 229（93%）
最大偏移     85 行（entity/EntityRegistry.ts）
```

已改为**等长空白替换** —— 行数、列位置不变，注释内容不再参与匹配。
顺带修了行尾注释：`^\s*//.*$` 只剥整行注释，
`const a = 1; // clamp(opts.x, 0, 1)` 里的 clamp 会被当成真代码。

### 7.2 A03 误报 `clampNum`

`clampNum` 内部走 `numOr(v, NaN)` + `isNaN → fallback`，NaN 有兜底**不穿透**，
但正则 `clamp(?:Num|01)?` 把它一起匹配了 —— 66 条候选里 **61 条误报**。
限定只匹配裸 `clamp` / `clamp01` 后剩 5 条真问题。

### 7.3 新增基础设施自检

`--self-test` 开头先验证行数守恒与注释剔除，不通过直接中断：

```
基础设施自检（strip_comments）
  ✓ 行数守恒（5 个用例）
  ✓ 注释内容已剔除，不参与匹配
```

**必要性**：行号错位时模式自检仍是 61/61 全绿 ——
它只验证"模式能不能检出"，管不了行号对不对。
