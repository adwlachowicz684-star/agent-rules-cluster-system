## 审查原则

1. 只审查，**不改码** —— 修复由其他窗口负责
2. 结论必须**实测**，不靠推理下判断
3. 测试全绿 ≠ 可发布
4. **先读注释**再报问题 —— 高频误报来源
5. 台账「已修」不等于真修 —— 实测复现再关闭
