# 01 更新形态与产物边界（热更新域）

> **本步交付**：更新形态分类 + 产物边界 + 硬限制清单
> **对应**：流程 `howto/godot/hotupdate.md` · 审核 `audit/godot/hotupdate.md`

## 0. 交付物定义

1. 逐项标明本次要更的东西属于**资源 / 配置 / 代码**哪一类
2. 每种产物有唯一加载路径，不与别的形式混用
3. 两条硬限制（不可卸载、`_init()` 加载）写进设计约束

## 1. 前置检查清单

- [ ] 已列出本次热更要覆盖的全部内容
- [ ] ⚠ 已过一遍平台合规（iOS / 主机 / Steam）
- [ ] 已确认没有任何方案依赖"卸载已加载的 PCK"

## 2. 工序

### Step 1　分清资源热更与代码热更　`[hotupdate/01#S1]`

【读】`howto/godot/hotupdate.md#0. 先分清两种"热更"`

【做】
把本次要更的东西逐项归类：资源（贴图/音频/场景）、配置数值、逻辑代码。
⛔ 把"逻辑代码"混进资源热更 —— 两者差一个量级，且后者是**合规问题不是技术问题**。

【产出】更新形态分类表（每项标注：资源 / 配置 / 代码）

【判据】能指着每一项说出它是哪一类，且没有一项标着"都算"。

【审】`audit/godot/hotupdate.md#1`

### Step 2　定产物边界：PCK / 配置 / DLC 各走哪条路　`[hotupdate/01#S2]`

【读】`howto/godot/hotupdate.md#1. 资源热更：PCK 覆盖`

【做】
资源走 PCK 覆盖、数值走配置下发、新增内容走 DLC 占位。
⛔ 三种策略混用 —— 同一个资源既走 PCK 又走 DLC，离线时状态不确定。

【产出】产物边界清单 + 每种产物的加载路径

【判据】断网启动，每种产物要么全在、要么明确显示不可用，**没有第三种状态**。

【审】`audit/godot/hotupdate.md#2`

### Step 3　代码热更红线判定　`[hotupdate/01#S3]`

【读】`howto/godot/hotupdate.md#2. ⚠ 代码热更是红线，不是技术问题`

【做】
任何"下载脚本改行为"的方案先过合规判定，不要先做技术验证。
⛔ 以为用 Lua/JS 解释器就能绕开 —— 解释器加载下载脚本改功能**一样违规**。
⛔ 配置里放 URL 跳板、功能开关、可执行表达式 —— 跨过"数据变逻辑"的线，同样判定为变相代码热更。

【产出】合规判定结论（允许 / 禁止 / 需改形态）+ 依据条款

【判据】结论能追溯到具体平台条款，而不是"大家都这么做"。

【审】`audit/godot/hotupdate.md#6`

### Step 4　平台差异逐个过（iOS / 主机 / Steam）　`[hotupdate/01#S4]`

【读】`howto/godot/hotupdate.md#14. 平台差异`

【做】
iOS 审核指南、主机认证流程、Steam depot 各自单列。
⛔ Steam 版照常推自建热更 —— 会**双重更新**覆盖 depot。
⛔ 以为主机也能热修 —— 每次提交重过认证（PS/Nintendo 首提 2–6 周），只能靠服务端配置与预埋开关。

【产出】平台差异表（发行渠道 × 允许形态）

【判据】每个发行渠道都有明确结论，没有"待定"。

【审】`audit/godot/hotupdate.md#7`

### Step 5　先把两条硬限制写进设计约束　`[hotupdate/01#S5]`

【读】`howto/godot/hotupdate.md#5. ⚠ 第一硬限制：PCK 无法卸载`

【做】
设计文档开头写明：① 没有 `unload_resource_pack()`，只能重启进程；② 补丁必须在 autoload 的 `_init()` 里加载。
⛔ 假设能卸载包 —— 卸载逻辑写好了一调用才发现不存在，整条回滚路径作废。
⛔ 以为 `clear_path_cache` 能卸载 pack —— 它只清单个资源缓存，**PCK 虚拟文件系统层仍挂着**。

【产出】硬限制约束清单（写进设计文档与代码注释）

【判据】代码里没有任何一处假设"可以卸载已加载的包"。

【审】`audit/godot/hotupdate.md#4`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：形态分类与硬限制
# ⛔ Godot 无 unload_resource_pack()，卸载 = 重启进程
const PATCH_DIR := "user://patches"

func _init() -> void:          # ⛔ 必须是 _init()，_ready() 永远不生效
    for p in _list_patches():
        ProjectSettings.load_resource_pack(p)
```
