# 05 换血与生效时机（热更新域）

> **本步交付**：`_init()` 加载 + 换血清单 + 三档处理 + 生效时机
> **对应**：流程 `howto/godot/hotupdate.md` · 审核 `audit/godot/hotupdate.md`

## 0. 交付物定义

1. 补丁在 `_init()` 加载，产物无"部分新"
2. 换血清单覆盖全部已缓存资源
3. 已实例化对象三档分类，战斗中不被换
4. 每个产物有显式生效时机

## 1. 前置检查清单

- [ ] 04 的原子切换已完成
- [ ] 已列出全部会被缓存 / `preload` 的资源
- [ ] 已定义哪些状态属于"不可中断"

## 2. 工序

### Step 1　补丁必须在 autoload 的 `_init()` 里加载　`[hotupdate/05#S1]`

【读】`howto/godot/hotupdate.md#6. ⚠ 第二硬限制：补丁必须在 autoload 的 `_init()` 里加载`

【做】
加载写在 autoload 的 `_init()`。
⛔ 写在 `_ready()` —— **永远不生效**，且已 `preload()` 的场景不受影响，表现为"部分是新的、部分是旧的"。

【产出】autoload 加载点 + 加载顺序说明

【判据】启动后任取一个补丁内资源，读到的是新版本（不是部分新）。

【审】`audit/godot/hotupdate.md#3`

### Step 2　已缓存资源不会自动换血　`[hotupdate/05#S2]`

【读】`howto/godot/hotupdate.md#10. 加载新包后的"换血"：最容易崩的一步`

【做】
显式列出哪些资源需要主动失效/重载。
⛔ 以为加载新包就自动生效 —— 已缓存、已 `preload` 的资源**不会自动换**。

【产出】换血清单（哪些资源要重载、怎么重载）

【判据】换血后取一个已缓存资源，读到的是新版本。

【审】`audit/godot/hotupdate.md#2`

### Step 3　已实例化对象分三档处理　`[hotupdate/05#S3]`

【读】`howto/godot/hotupdate.md#已实例化对象分三档处理`

【做】
(可立即换 / 可下次进入换 / 不可换要重启)三档分别标注。
⛔ 一刀切全部立即换 —— 战斗中的对象被换掉，状态错乱。

【产出】三档分类表 + 每档的处理时机

【判据】战斗中触发热更，战斗对象不被换掉且无报错。

【审】`audit/godot/hotupdate.md#31`

### Step 4　不可中断状态绝不热换　`[hotupdate/05#S4]`

【读】`howto/godot/hotupdate.md#已实例化对象分三档处理`

【做】
战斗、结算、过场等不可中断状态，标记**下次进入生效**。
⛔ 运行时热换战斗中的场景 —— 状态错乱且不可复现。

【产出】不可中断状态清单 + 延迟生效标记

【判据】在战斗/结算中触发热更，本次不生效，下次进入生效。

【审】`audit/godot/hotupdate.md#31`

### Step 5　旧节点要停 `_process`，⛔ 否则幽灵回调　`[hotupdate/05#S5]`

【读】`howto/godot/hotupdate.md#10. 加载新包后的"换血"：最容易崩的一步`

【做】
切场景时旧节点**不会自动停** `_process`，要 `set_process(false)` 并禁输入。
⛔ 以为切场景就停了 —— 旧节点继续跑，产生**幽灵回调**。

【产出】节点退役流程（set_process(false) + 禁输入 + 断开信号）

【判据】换血后旧节点不再有任何回调，日志可证。

【审】`audit/godot/hotupdate.md#32`

### Step 6　生效时机要显式声明　`[hotupdate/05#S6]`

【读】`howto/godot/hotupdate.md#生效时机要显式声明`

【做】
每个产物声明生效时机（立即 / 下次启动 / 下次进入场景）。
⛔ 不声明 —— 玩家看到"装完了但没变"，客服无法解释。

【产出】生效时机声明（写在补丁元数据里）

【判据】能对着元数据说出每个产物什么时候生效。

【审】`audit/godot/hotupdate.md#2`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：三档 + 幽灵回调防护
enum SwapKind { NOW, NEXT_ENTER, NEVER }   # ⛔ NEVER 档必须存在：不可逆资源

func retire(node: Node) -> void:
    node.set_process(false)      # ⛔ 切场景不会自动停
    node.set_process_input(false)
```
