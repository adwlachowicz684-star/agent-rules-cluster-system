# 06 灰度、回滚与降级（热更新域）

> **本步交付**：可禁用开关 + 触发条件 + 三种故障实测 + 稳定分桶
> **对应**：流程 `howto/godot/hotupdate.md` · 审核 `audit/godot/hotupdate.md`

## 0. 交付物定义

1. 回滚触发条件可自动判定，不靠人
2. 补丁可禁用（revoked），最近两份全量包常驻
3. 三种故障**实测通过**并有记录
4. 灰度稳定分桶，强更不灰度

## 2. 工序

### Step 1　回滚触发条件预先枚举　`[hotupdate/06#S1]`

【读】`howto/godot/hotupdate.md#回滚：触发条件要预先枚举，⛔ 不能靠人判断`

【做】
把触发条件写成可判定的条件列表（崩溃率、启动失败率、关键指标阈值）。
⛔ 靠人判断 —— 事故时没人敢拍板，错过窗口。

【产出】回滚触发条件表（指标 × 阈值 × 判定窗口）

【判据】给定一组指标数据，能自动判定该不该回滚，无需人工讨论。

【审】`audit/godot/hotupdate.md#27`

### Step 2　补丁做成可禁用开关，⛔ 不是删除　`[hotupdate/06#S2]`

【读】`howto/godot/hotupdate.md#8. 补丁生成：基线、差分、签名`

【做】
补丁有 `active ↔ revoked` 状态，回滚 = 置 revoked。
⛔ 删除即回滚 —— 客户端已装的无法撤回，且删了就没法再查。
⚠ 最近两份**全量包必须常驻**，否则 revoking 后无包可回。

【产出】补丁状态字段 + 撤销流程 + 常驻全量包策略

【判据】把一个补丁置 revoked，客户端下次启动回到上一个可用版本。

【审】`audit/godot/hotupdate.md#15`

### Step 3　三种故障必须实测　`[hotupdate/06#S3]`

【读】`howto/godot/hotupdate.md#回滚：触发条件要预先枚举，⛔ 不能靠人判断`

【做】
实测：下载到 70% 杀进程、PCK 内容改成全零、`load_resource_pack` 后抛异常。
⛔ 回滚代码写了就行 —— 95% 项目从未在故障路径跑过。
⛔ 开服后出错就 restore —— 会抹掉玩家真实行为，构成**二次事故**。

【产出】三个故障场景的实测记录（含结果）

【判据】三个场景**全部实测通过**且记录可查，不是"代码里有处理"。

【审】`audit/godot/hotupdate.md#27`

### Step 4　灰度用稳定哈希分桶　`[hotupdate/06#S4]`

【读】`howto/godot/hotupdate.md#13. 灰度与应急`

【做】
用玩家 ID 的稳定哈希分桶。
⛔ 用 `rand()` 分桶 —— 玩家每次启动换桶，**A/B 数据作废**。

【产出】稳定分桶函数 + 灰度名单

【判据】同一账号连续启动 10 次，始终落在同一桶。

【审】`audit/godot/hotupdate.md#30`

### Step 5　强制更新不能灰度　`[hotupdate/06#S5]`

【读】`howto/godot/hotupdate.md#⚠ 强制更新不能灰度（结构性矛盾）`

【做】
强更全量放行，不做灰度。
⛔ 给强更配灰度 —— **结构性矛盾**：同一账号两台设备行为会不一致。

【产出】强更与灰度的互斥规则（写进发布流程）

【判据】发布流程中强更条目无法同时勾选灰度。

【审】`audit/godot/hotupdate.md#29`

### Step 6　配置热更的不可逆字段必须 never　`[hotupdate/06#S6]`

【读】`howto/godot/hotupdate.md#12. 配置热更：纯数据的边界要守住`

【做】
已购货币、永久属性点等不可逆字段标记 `never`（永不热更）。
⛔ 允许热更 —— 一次配置错误就是资产事故，且不可回退。
⛔ 数值不合理也算配置错误要回滚 —— 是**运营判断**，改回数值重发；回滚会让属性来回跳。

【产出】字段生效策略表（immediate / next_boot / never）

【判据】尝试热更一个 `never` 字段，被明确拒绝且有日志。

【审】`audit/godot/hotupdate.md#35`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：稳定分桶 + 可禁用
const BUCKETS := 100

func bucket_of(uid: String) -> int:
    return abs(uid.hash()) % BUCKETS   # ⛔ 用 rand() 则每次启动换桶

func is_active(p: Dictionary) -> bool:
    return p.get("state", "revoked") == "active"   # ⛔ 删除 ≠ 回滚
```
