# 物理 —— 域流程总览

> ⚠ **第 0 步：先定做什么。**
> 本域有 7 个功能点，⛔ **不是全做** —— 按本次需求挑。

## 0. 先定做什么

| 本次要做的 | 走哪些功能点 |
|---|---|
| 只是"能碰撞、能查询" | 01 → 02 → 03 → 07 |
| 有可推动/可炸飞的物体 | 01 → 02 → 04 → 07 |
| 有角色移动、斜坡、移动平台 | 01 → 02 → 05 → 07 |
| 有堆叠/高速/大量物体（要稳） | 01 → 02 → 04 → 06 → 07 |
| 全套（含性能与稳定性） | 01 → 02 → 03 → 04 → 05 → 06 → 07 |

⚠ **01 是全域地基，不能跳过。**
物理引擎与刻度（TPS / 插值）一旦中途改，
⛔ 之前调好的所有质量、力、速度**都要重调**——
表现为"换个引擎后手感全变了"，而排查方向常被误引到参数本身。

ⓘ **02（碰撞层与形状）几乎总是要做**：
它是其他域的公共前置，
⛔ 层写错表现为"某两个东西永远撞不上"，不报错。

⛔ **不要因为"物理不就是加个碰撞体"就跳过 06。**
本域的坑**大部分只在极限工况暴露**（高速、堆叠、远离原点、帧率崩塌），
⚠ 而 06 是唯一专门处理它们的功能点。

## 1. 功能点拆解（按依赖，不可颠倒）

| # | 功能点 | 依赖 | 交付物 |
|---|---|---|---|
| 01 | 物理引擎与刻度选型 | — | 引擎 + TPS + 插值开关 + 步数上限 |
| 02 | 碰撞层与形状 | 01 | 命名层 + Layers 常量 + 形状选型 |
| 03 | 查询与检测 | 02 | 射线/形状查询/Area 触发 |
| 04 | 刚体与施力 | 02 | impulse/force 分工 + CCD + 睡眠 |
| 05 | 角色与移动平台 | 02 | CharacterBody + AnimatableBody |
| 06 | 稳定性与性能 | 04 | 防穿透/防抖/防螺旋死亡 |
| 07 | 物理验收 | 全部 | 10 TPS 慢放 + 极限工况实测 |

⚠ **01 必须在一切之前**：刻度与引擎是后面所有参数的基准。
⚠ **02 必须在 03/04/05 之前**：没有正确的层与形状，查询和施力都无从谈起。
⚠ **06 依赖 04**：稳定性问题（穿透/堆叠）主要发生在刚体上。

## 2. 与其他域的接缝

> ⚠ **组合的真正难点不是排序，是接缝。**
> 下面每条都必须能指认到具体符号或字段，⛔ 不能是"做完了"。

| 接缝 | 契约 |
|---|---|
| `character.md` 角色 | 角色碰撞形状选型（⛔ 不用圆柱）与 `move_and_slide` 参数 |
| `vehicle.md` 载具 | 载具高速不稳需提高 TPS（见 06），与本域 TPS 是**同一个设置** |
| `destruction-cloth.md` 破坏 | 碎片**池化**与本域 `reset_physics_interpolation()` 必须配对 |
| `movement-advanced.md` 移动 | 移动手感参数与物理刻度的一致性 |
| `save-migration.md` 存档 | 存档不存物理中间量（速度/受力），只存 transform |
| `level-design.md` 关卡 | 静态碰撞厚度、composite collider 的归属 |
| `openworld.md` 开放世界 | 远离原点的精度问题（见 06 S6） |

⛔ **若某条接缝对不上，要单独立一个接线功能点**，
⛔ 不许在各处偷偷转格式。

⚠ **各功能点自己的验收不能替代集成验收** ——
部件全合格、拼起来不能用，是跨域开发的典型失败。

ⓘ **与 destruction 域的接缝尤其容易漏**：
碎片池化必然瞬移，而瞬移在开插值时必须调 `reset_physics_interpolation()`。
⛔ 关掉插值"就好了"是常见的错误解法——它把问题掩盖成"插值有 bug"。

## 3. 本域最容易做反的顺序

⛔ **先做查询（03）再做层与形状（02）。**

"射线打中敌人"是最直观的验收点，
于是先写查询 → 打不中 →
⚠ 就在代码里放宽条件（加大检测范围、改成遍历所有物体）。

⛔ 后果链：
碰撞层没配对 → 射线永远打不中 →
放宽 `collision_mask` 到全层 → 打到自己和地面 →
再加 `if` 过滤 → 查询逻辑变成一堆特例，⛔ 且每层新增物体都要回来改。

✅ 正确顺序：先把层与形状（02）钉死，再谈查询（03）。

⛔ **第二个常见反序：先调手感再定刻度（01）。**

质量/力/速度在 60 TPS 下调好，
⚠ 中途为了修穿透把 TPS 提到 240 →
所有力参数效果变成 1/4，⛔ 手感全变且不报错。
