## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：物体能撞上就算过了。**

⛔ 常见假完成：层用裸数字写着，形状是编辑器默认拖出来的，
缩放靠改 `scale`。
⚠ 这三条**在简单场景下都能正常工作**——
⛔ 问题只在新增物体类型、改尺寸、跨 tile 时才暴露，那时已遍地是特例。

做完这一步，应该能**当场演示**：

1. 项目设置里**每一层都有名字**（不是 Layer 1/2/3）
2. `Layers` 常量与项目设置**一一对应**
3. ⛔ 场景里搜不到被缩放的 `CollisionShape*`
4. ⛔ 角色碰撞形状**不是** `CylinderShape3D`
5. ⚠ 形状资源在需要差异化时已 `duplicate()`

**产出物**：

```text
LAYERS:   <常量名> = 1 << (N-1)   # ⛔ 第 3 层是 4，不是 3
SHAPES:   角色=box|capsule / 静态=box|trimesh / 高速=sphere|capsule
```

## 2. 工序

### Step 1　⚠ 给层命名，建 Layers 常量　`[physics/02#S1]`

【读】`howto/godot/physics.md#5.5 碰撞层与形状：位掩码与命名`

【做】项目设置 → Layer Names 逐层命名；建 `layers.gd` 常量。

⛔ **第 3 层的值是 4，不是 3**。
写 `collision_layer = 3` 表示"同时属于第 1 和第 2 层"——
是合法值但不是你要的，⛔ 而且**不报错**，
表现为"这个物体同时撞两组东西"，排查极难。

【产出】`layers.gd` + 项目设置层名

【判据】⚠ 常量与层名一一对应，无裸数字散落在业务代码

【审】`audit/godot/physics.md#1`

### Step 2　⚠ 每个 body 配 layer 与 mask　`[physics/02#S2]`

【读】`howto/godot/physics.md#5.5 碰撞层与形状：位掩码与命名`

【做】逐个 body 设 `collision_layer`（我是谁）与 `collision_mask`（我能撞谁）。

⛔ 只设其中一个 → 表现为"某两个东西永远撞不上"或"撞了不该撞的"，
⚠ 两者都不报错，且**在只有两三个物体时看不出来**。

ⓘ 配合 GC-03：层值从 `Layers` 常量取，不硬编码。

【产出】全场景 body 的层配置

【判据】⚠ 每个 body 两个字段都已显式设（不是默认值）

【审】`audit/godot/physics.md#1`

### Step 3　⚠ 选形状：⛔ 角色不用圆柱　`[physics/02#S3]`

【读】`howto/godot/physics.md#6.1 ⛔ 圆柱碰撞形状不稳定`

【做】为每个 body 选形状；角色用 box 或 capsule。

⛔ 官方：圆柱是重写实现、有若干已知 bug，**建议用 box 或 capsule**。
- box：可靠性最好，代价是对角方向占地更大
- capsule：无此代价，但**精确平台跳跃变难**

⚠ 形状选型错了表现为"偶尔卡住/偶尔穿过去"，
⛔ 时序性故障，最难复现。

【产出】形状选型表

【判据】⛔ 角色碰撞形状不是 `CylinderShape3D`

【审】`audit/godot/physics.md#13`

### Step 4　⛔ 缩放禁令：改 extents 不改 scale　`[physics/02#S4]`

【读】`howto/godot/physics.md#6. ⛔ 缩放禁令：物理体与碰撞形状不能缩放`

【做】全场景排查被缩放的碰撞形状，改走形状参数。

⛔ **官方原话：Godot 目前不支持缩放物理体或碰撞形状。**
改 `scale` 让角色变大 → **碰撞体不变** →
视觉与碰撞脱节：看起来撞上了、实际穿过去。
⛔ **不报错**，排查时没人会想到是 scale。

⚠ 三条配套：
1. 要让视觉也变 → 视觉与碰撞**各自独立**改
2. ⛔ 碰撞形状**不能是视觉表示的子节点**（父节点缩放会带过去）
3. ⓘ 形状资源默认共享，差异化前要 `duplicate()`

【产出】零缩放证据 + `duplicate()` 约定

【判据】⛔ 场景里搜不到被缩放的 `CollisionShape*`

【审】`audit/godot/physics.md#10`

### Step 5　⚠ 单向平台与复合碰撞体　`[physics/02#S5]`

【读】`howto/godot/physics.md#7. 官方故障排查清单`

【做】单向平台设 `one_way_collision`；跨 tile 的地面做 composite collider。

⛔ **跨 tile 颠簸是引擎已知问题**：物体会撞到
**已被另一个形状覆盖**的边缘。官方解法是做 composite collider
（把一组 tile 合成一个碰撞体），⛔ 不是"调大容差"。

⚠ 它表现为"走过 tile 接缝时莫名弹一下"，
在单块地板上测试**完全正常**。

【产出】单向平台配置 + composite collider

【判据】⚠ 角色走过 tile 接缝**无颠簸**

【审】`audit/godot/physics.md#25`

## 5. 常见返工

**① 用裸数字写层。** 第 3 层写成 3，语义全错且合法。

**② 只设 layer 不设 mask。** 撞不上，不报错。

**③ 用圆柱做角色。** 偶发卡顿/穿透，难复现。

**④ 改 scale 调尺寸。** 视觉与碰撞脱节，不报错。

**⑤ 跨 tile 颠簸靠调容差。** 真解法是 composite collider。
