# 01 载具模型定性（vehicle 域）

> **前置**：无（本域地基）
> **本步交付**：**一句话说清本次载具是哪种，且选对根节点**
> **对应**：做法 `howto/godot/vehicle.md#0. 先定性：轮式与非轮式走不同节点`
> 　　　审核 `audit/godot/vehicle.md#1`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：车能动了就算过了。**

⛔ 常见假完成：拿 `VehicleBody3D` 做飞行器，
"能飞"就认为做完了——
⚠ 但 `VehicleBody3D` 的悬挂/车轮逻辑**一直在空跑**，
⛔ 表现为后期调参时改什么都没反应，
而排查方向被引到"参数没生效"。

做完这一步，应该能**当场演示**：

1. 一句话说清载具类型（轮式 / 履带 / 飞行 / 船舶）
2. 选了对应的根节点，且说得出**为什么不选别的**
3. ⛔ 若是非轮式，**没有**使用 `VehicleWheel3D`
4. 载具的"自由度"已定（能翻滚吗？能离地吗？）
5. ⚠ 已知本次**不做什么**（如不做水上浮力）

**产出物**（下游按名字对接）：

```text
VEHICLE_TYPE: wheeled | tracked | airborne | marine
ROOT_NODE:    VehicleBody3D | RigidBody3D
# 轮式 → VehicleBody3D；其余 → RigidBody3D + 自定义力
```

## 2. 工序

### Step 1　⚠ 判据：有轮 → VehicleBody3D，无轮 → RigidBody3D　`[vehicle/01#S1]`

【读】`howto/godot/vehicle.md#0. 先定性：轮式与非轮式走不同节点`

【做】按有无轮子选根节点，写进文档。

⛔ `VehicleBody3D` 是**轮式专用**：它的动力全部经由
`VehicleWheel3D` 的接地点输出。无轮载具用它 → 动力无出口。

【产出】`VEHICLE_TYPE` + `ROOT_NODE`

【判据】⚠ 类型与根节点**一一对应**，且文档记录

【审】`audit/godot/vehicle.md#1`

### Step 2　⛔ 非轮式禁止挂 VehicleWheel3D　`[vehicle/01#S2]`

【读】`howto/godot/vehicle.md#0. 先定性：轮式与非轮式走不同节点`

【做】飞行/船舶载具下不出现 `VehicleWheel3D` 节点。

⛔ 挂了也不会报错——只是悬挂射线一直在打空，
⚠ 白费 CPU 且排查时不知道该看哪。

【产出】节点树（无车轮节点）

【判据】⛔ 场景树里搜不到 `VehicleWheel3D`

【审】`audit/godot/vehicle.md#2`

### Step 3　⚠ 定自由度：能翻滚吗　`[vehicle/01#S3]`

【读】`howto/godot/vehicle.md#4. 重心与防翻：低速翻车是参数问题`

【做】明确是否允许车身翻滚，是否需要自动扶正。

⛔ 不定 → 后期"车翻了怎么办"会变成各写各的补丁，
⚠ 有的地方强制扶正、有的地方不管，表现不一致。

【产出】自由度约定

【判据】⚠ 文档能指出翻车后的处理方式

【审】`audit/godot/vehicle.md#8`

### Step 4　⚠ 定质量来源　`[vehicle/01#S4]`

【读】`howto/godot/vehicle.md#3. ⛔ mass 必须显式设，否则载具不动`

【做】决定 `mass` 是硬编码还是配置，并确认**一定会设**。

⛔ `VehicleBody3D` 继承 `RigidBody3D`，
质量若依赖子节点而子节点没贡献 → 总质量异常 →
表现为"推不动"或"一碰就飞"，⛔ 且不报错。

【产出】质量约定（显式值）

【判据】⚠ 检视器里 `mass` **不为 0**

【审】`audit/godot/vehicle.md#7`

### Step 5　⚠ 明确本次不做什么　`[vehicle/01#S5]`

【读】`howto/godot/vehicle.md#0. 先定性：轮式与非轮式走不同节点`

【做】列出排除项（浮力/飞行/破坏等）。

⛔ 不写排除项 → 需求蔓延，
⚠ 且后期加功能时发现地基（根节点）选错了。

【产出】排除项清单

【判据】⚠ 清单存在，且与 00 第 0 节一致

【审】`audit/godot/vehicle.md#1`

## 5. 常见返工

**① 用 VehicleBody3D 做飞行器。** 参数改了没反应。

**② 不设 mass。** 推不动且不报错。

**③ 不定翻车处理。** 后期各写各的补丁。

**④ 不列排除项。** 需求蔓延后地基要重选。
