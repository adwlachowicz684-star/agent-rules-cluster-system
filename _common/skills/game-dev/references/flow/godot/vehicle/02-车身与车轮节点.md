# 02 车身与车轮节点（vehicle 域）

> **前置**：`01-载具模型定性.md` 已完成
> **本步交付**：**四个轮子着地，车身随地形起伏**
> **对应**：做法 `howto/godot/vehicle.md#1. 节点结构：车身是根，车轮是子节点`
> 　　　审核 `audit/godot/vehicle.md#4`

## 0. 交付物定义

⚠ **本步的关键不是"车能跑"，是"悬挂真的在动"。**

⛔ 常见假完成：四个 `VehicleWheel3D` 挂上去，车能动了就过——
⚠ 但 `suspension_travel` 若为 0，悬挂**不压缩**，
表现为"轮子贴地但车身不跟随地形"，
⛔ 看起来像滑板，而且**不报错**。

做完这一步，应该能**当场演示**：

1. 车身静止时，四个轮子**都接触地面**（可见网格不悬空）
2. ⚠ 把车放到斜坡上，车身**随坡度倾斜**（不是水平悬浮）
3. ⛔ 从高处落下，落地瞬间悬挂**压缩后回弹**
4. 车轮节点**没有**自己的碰撞体
5. ⚠ 车轮有可见网格（`MeshInstance3D` 子节点）

**产出物**（下游按名字对接）：

```text
VehicleBody3D            # 根，mass 显式设
├── MeshInstance3D       # 车身外观
├── CollisionShape3D     # 车身碰撞
└── VehicleWheel3D × N   # 车轮（无碰撞体）
    └── MeshInstance3D   # 轮子外观（物理层不自动渲染）
```

## 2. 工序

### Step 1　⚠ VehicleBody3D 作根，车轮作子节点　`[vehicle/02#S1]`

【读】`howto/godot/vehicle.md#1. 节点结构：车身是根，车轮是子节点`

【做】车身为根，每个车轮是它的**直接**子节点。

⛔ 车轮挂在车身之外（如并列在场景根）→
`VehicleBody3D` 找不到车轮 → 无动力输出，
⚠ 且不报错，只是"车不动"。

【产出】节点树

【判据】⚠ 所有车轮都是车身的**直接**子节点

【审】`audit/godot/vehicle.md#3`

### Step 2　⛔ 车轮禁止挂碰撞体　`[vehicle/02#S2]`

【读】`howto/godot/vehicle.md#2. ⛔ 车轮不要用碰撞体，用射线`

【做】`VehicleWheel3D` 下**只有** `MeshInstance3D`，无 `CollisionShape3D`。

⛔ 车轮加碰撞体 → 与车身碰撞体互相挤压 →
表现为"车一放地上就弹飞"或"原地抖动"。

【产出】车轮节点（无碰撞）

【判据】⛔ 车轮子树里搜不到 `CollisionShape3D`

【审】`audit/godot/vehicle.md#4`

### Step 3　⚠ suspension_travel 必须大于 0　`[vehicle/02#S3]`

【读】`howto/godot/vehicle.md#5. 悬挂四元组：travel / stiffness / damping / rest_length`

【做】设 `suspension_travel > 0`（典型 0.2 上下，按车高定）。

⛔ 为 0 → 悬挂不压缩 → 车身不随地形 → 像滑板，
⛔ **不报错**，是本域最隐蔽的假完成之一。

【产出】悬挂 travel 值

【判据】⚠ 放斜坡上车身**随坡倾斜**

【审】`audit/godot/vehicle.md#13`

### Step 4　⚠ 车轮要有可见网格　`[vehicle/02#S4]`

【读】`howto/godot/vehicle.md#1. 节点结构：车身是根，车轮是子节点`

【做】每个 `VehicleWheel3D` 加 `MeshInstance3D` 子节点。

⛔ 物理层**不自动渲染**轮子——
不挂网格 → 运行时看不到轮子，
⚠ 而"车能开"让人误以为做完了。

【产出】车轮网格

【判据】⚠ 运行后**看得到**四个轮子

【审】`audit/godot/vehicle.md#5`

### Step 5　⚠ 标记转向轮与驱动轮　`[vehicle/02#S5]`

【读】`howto/godot/vehicle.md#1. 节点结构：车身是根，车轮是子节点`

【做】前轮标 `use_as_steered`，驱动轮标 `use_as_traction`。

⛔ 不标 → 转向/动力施加到错误的轮子上，
表现为"打方向盘车头不动"或"四驱变后驱"，
⚠ 排查时容易被引到"输入没接上"。

【产出】车轮职责标记

【判据】⚠ 打方向盘，前轮**可见地转向**

【审】`audit/godot/vehicle.md#6`

## 5. 常见返工

**① 车轮挂外面。** 车不动且不报错。

**② 车轮加碰撞。** 弹飞或抖动。

**③ travel=0。** 像滑板，最隐蔽。

**④ 不标职责。** 打方向盘没反应。
