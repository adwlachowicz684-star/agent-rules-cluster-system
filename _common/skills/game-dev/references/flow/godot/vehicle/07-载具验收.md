# 07 载具验收（vehicle 域）

> **前置**：01–06 全部完成
> **本步交付**：一份**可签核**的验收报告
> **对应**：做法 `howto/godot/vehicle.md` 全文 · 审核 `audit/godot/vehicle.md` 全部条目

## 0. 交付物定义

⚠ **载具域的验收必须在"极限工况"下做，不是在平地上做。**

⛔ 平地能开 = 什么都没验到。
本域的坑**全部只在高速、斜坡、落地、连按时暴露**。

做完这一步，应该能**当场演示**并**签核**：

1. ⚠ **高速过弯**不翻车（04 核心指标）
2. ⚠ **从高处落下**：悬挂压缩回弹后停稳（04 核心指标）
3. ⛔ **斜坡驻车**不滑走（04 核心指标）
4. ⚠ **连按上下车 100 次**不崩溃不漂移（06 核心指标）
5. ⚠ **载具销毁**时所有乘客安全落地（05 核心指标）
6. ⚠ 接缝复查：与 7 个域的契约全对上

- [ ] 01–06 每个功能点的验收清单都已勾选
- [ ] ⚠ 有斜坡、跳台、减速带的**测试场景**
- [ ] ⚠ 有可连按测试的入口（不依赖手速）

## 2. 工序

### Step 1　⚠ 高速过弯实测　`[vehicle/07#S1]`

【读】`howto/godot/vehicle.md#4. 重心与防翻：低速翻车是参数问题`

【做】最高速下打满方向，多次往返。

⛔ 只在中低速测 → 翻车问题完全测不到，
⚠ 而这是玩家**最先遇到**的体验问题。

【产出】过弯结果

【判据】⚠ 最高速打满方向**不翻车**

【审】`audit/godot/vehicle.md#8`

### Step 2　⚠ 从高处落下实测　`[vehicle/07#S2]`

【读】`howto/godot/vehicle.md#5. 悬挂四元组：travel / stiffness / damping / rest_length`

【做】从数倍车高处落下，观察落地。

⛔ 不测落地 → 悬挂压到底穿地 或 无限弹跳，
⚠ 这两类在平地行驶时**完全正常**。

【产出】落地表现

【判据】⚠ 落地后**2 秒内停稳**且未穿地

【审】`audit/godot/vehicle.md#14`

### Step 3　⛔ 斜坡驻车实测　`[vehicle/07#S3]`

【读】`howto/godot/vehicle.md#5. 悬挂四元组：travel / stiffness / damping / rest_length`

【做】停在斜坡上等待一段时间。

⛔ 不测 → 车自己滑走，
⚠ 表现为"停车后车不见了"，排查被引到位置同步。

【产出】驻车结果

【判据】⚠ 斜坡上**静止不动**

【审】`audit/godot/vehicle.md#15`

### Step 4　⚠ 连按上下车压力测试　`[vehicle/07#S4]`

【读】`howto/godot/vehicle.md#9. 上下车是事务：先定位，再切换`

【做】脚本连按 100 次，观察位置与崩溃。

⛔ 只测单次 → 冷却缺失与状态翻转**测不到**，
⚠ 而这是最容易被玩家（或猴子测试）触发的。

【产出】100 次结果

【判据】⚠ **不崩溃、位置不漂移**

【审】`audit/godot/vehicle.md#20`

### Step 5　⚠ 载具销毁与乘员　`[vehicle/07#S5]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】载满员后销毁载具。

⛔ 不测 → 乘客悬空崩溃或掉出地图，
⚠ 而这在"车一直不毁"的测试里永远正常。

【产出】销毁结果

【判据】⚠ 所有乘客**安全站在地面**

【审】`audit/godot/vehicle.md#18`

### Step 6　⚠ 接缝复查　`[vehicle/07#S6]`

【读】`howto/godot/vehicle.md#7. 待核对项（运行时验证）`

【做】逐条核对 00 总览第 2 节的七条契约：

| 接缝 | 复查点 |
|---|---|
| `physics-materials.md` 物理 | 地面摩擦与本域 `friction_slip` 不冲突 |
| `movement-advanced.md` 移动 | 上下车时移动状态机正确交接 |
| `input-remap.md` 输入 | 载具复用同一套 action，改键同时生效 |
| `netsync.md` 网络 | 控制者唯一，同步口径已定 |
| `camera-cutscene.md` 相机 | 载具相机跟随不抖动 |
| `save.md` 存档 | 只存 transform + 控制者，不存物理中间量 |
| `level-design.md` 关卡 | 生成点合法、可行驶区正确 |

⛔ **这七条不查，部件全合格也可能拼不起来。**

【产出】接缝复查表

【判据】⚠ 七条全部对上，每条有实测证据

【审】`audit/godot/vehicle.md#25`

## 4. 常见返工

**① 只测平地。** 本域 bug 全在极限工况。

**② 不测落地。** 穿地与无限弹跳测不出。

**③ 只测单次上下车。** 冷却问题测不出。

**④ 不测载具销毁。** 悬空崩溃测不出。
