# 03 输入与驱动（vehicle 域）

> **前置**：`02-车身与车轮节点.md` 已完成
> **本步交付**：**松开按键后车能滑行停下，方向盘渐进回正**
> **对应**：做法 `howto/godot/vehicle.md#6. ⚠ engine_force / steering 是持续属性，不是脉冲`
> 　　　审核 `audit/godot/vehicle.md#9`

## 0. 交付物定义

⚠ **本步的关键不是"按 W 会走"，是"松开后行为正确"。**

⛔ 常见假完成：按住能走就过——
⚠ 但 `engine_force` 是**持续属性**，
若每帧只在有输入时设值、无输入时**忘了设 0**，
表现为"松开 W 车还在加速"，⛔ 且不报错。

做完这一步，应该能**当场演示**：

1. 按住 W 加速，松开后**自然滑行减速**
2. ⚠ 打方向盘后松开，方向**渐进回正**（不是瞬间弹回）
3. ⛔ 刹车与倒车互斥（不会同时施加）
4. 输入走同一套 action，⛔ 没有另起 InputMap
5. ⚠ 在物理帧（`_physics_process`）里施加，不是每帧

**产出物**（下游按名字对接）：

```text
_physics_process(delta):
  读 action → 设 engine_force / brake / steering
  ⛔ 无输入时显式归零
steering 回正：lerp 到 0，非直接置 0
```

## 2. 工序

### Step 1　⚠ 在物理帧施加，不是渲染帧　`[vehicle/03#S1]`

【读】`howto/godot/vehicle.md#6. ⚠ engine_force / steering 是持续属性，不是脉冲`

【做】驱动逻辑写在 `_physics_process(delta)`。

⛔ 写在 `_process` → 与物理步长不同步 →
表现为"帧率高时车快、帧率低时车慢"，
⚠ 这是本域最典型的"手感不对"来源。

【产出】驱动代码位置

【判据】⚠ 改帧率上限，车的最高速度**不变**

【审】`audit/godot/vehicle.md#10`

### Step 2　⛔ 无输入时必须显式归零　`[vehicle/03#S2]`

【读】`howto/godot/vehicle.md#6. ⚠ engine_force / steering 是持续属性，不是脉冲`

【做】无输入分支里 `engine_force = 0`。

⛔ 持续属性不会自动清零 →
"松开 W 还在加速"，⛔ 不报错。

【产出】归零分支

【判据】⚠ 松开 W 后车速**自然衰减**

【审】`audit/godot/vehicle.md#9`

### Step 3　⚠ steering 渐进回正，不瞬间弹回　`[vehicle/03#S3]`

【读】`howto/godot/vehicle.md#6. ⚠ engine_force / steering 是持续属性，不是脉冲`

【做】松开方向键时 `steering = lerp(steering, 0, k)`。

⛔ 直接置 0 → 方向盘瞬间弹正，
表现为"高速时车头猛地一甩"，手感极差，
⚠ 且容易诱发翻车（见 04）。

【产出】回正逻辑

【判据】⚠ 松开方向键，车轮**可见地缓慢回正**

【审】`audit/godot/vehicle.md#11`

### Step 4　⛔ 刹车与倒车互斥　`[vehicle/03#S4]`

【读】`howto/godot/vehicle.md#6. ⚠ engine_force / steering 是持续属性，不是脉冲`

【做】`brake` 与负向 `engine_force` 不同时施加。

⛔ 同时施加 → 力互相抵消又都生效 →
表现为"踩刹车时车抖动/顿挫"，且不报错。

【产出】互斥逻辑

【判据】⚠ 踩刹车时车速**平滑下降**无顿挫

【审】`audit/godot/vehicle.md#9`

### Step 5　⚠ 输入复用现有 action　`[vehicle/03#S5]`

【读】`howto/godot/vehicle.md#7. 待核对项（运行时验证）`

【做】载具输入用与角色相同的 action 名。

⛔ 另起一套 InputMap → 改键系统只对角色生效，
⚠ 表现为"我改了按键但车上没变"，
而排查时不会想到是两套输入。

【产出】action 复用

【判据】⚠ 改一次按键，角色与载具**同时生效**

【审】`audit/godot/vehicle.md#22`

### Step 6　⚠ 高速转向衰减　`[vehicle/03#S6]`

【读】`howto/godot/vehicle.md#4. 重心与防翻：低速翻车是参数问题`

【做】转向幅度随速度增大而减小。

⛔ 不衰减 → 高速打满方向 → 直接翻车，
⚠ 表现为"高速时轻轻一碰方向就翻"，
⛔ 这常被误判为"物理引擎有问题"。

【产出】转向衰减曲线

【判据】⚠ 高速打满方向**不翻车**

【审】`audit/godot/vehicle.md#12`
