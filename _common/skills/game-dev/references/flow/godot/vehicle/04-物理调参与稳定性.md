# 04 物理调参与稳定性（vehicle 域）

> **前置**：`03-输入与驱动.md` 已完成
> **本步交付**：**高速过弯不翻车，落地悬挂回弹后停稳**
> **对应**：做法 `howto/godot/vehicle.md#4. 重心与防翻：低速翻车是参数问题`
> 　　　审核 `audit/godot/vehicle.md#12`

## 0. 交付物定义

⚠ **本步是本域最耗时的：要反复实车试，没有"算出来"的捷径。**

⛔ 常见假完成：平地能开就过——
⚠ 但重心与悬挂的坑**只在斜坡、高速、落地时暴露**，
⛔ 表现为"测试时好好的，玩家一开就翻"。

做完这一步，应该能**当场演示**：

1. ⚠ 高速过弯**不翻车**
2. ⚠ 从高处落下，悬挂**压缩后回弹并停稳**（不是一直晃）
3. ⛔ 侧向停放（斜坡）**不滑走**
4. ⚠ 连续过减速带，车身**不持续弹跳**
5. ⛔ 知道重心位置的**具体数值**并写在文档里

**产出物**（下游按名字对接）：

```text
mass                 # 显式非 0
center_of_mass       # 低于悬挂点，防翻
suspension_travel    # > 0
suspension_stiffness # 支撑车重
damping_compression / damping_relaxation  # ⛔ 非 0，否则无限弹
```

- [ ] 驱动已可用（03）
- [ ] ⚠ 已确认车重与轮数（决定 stiffness）
- [ ] 有可测试的斜坡与跳台场景
- [ ] 已知 damping 默认为 0 即无限弹跳

## 2. 工序

### Step 1　⛔ mass 显式设且非 0　`[vehicle/04#S1]`

【读】`howto/godot/vehicle.md#3. ⛔ mass 必须显式设，否则载具不动`

【做】直接给 `VehicleBody3D.mass` 一个明确值。

⛔ 依赖子节点自动计算而子节点不贡献 → 质量异常 →
表现为"推不动"或"一碰就飞"，⛔ 不报错。

【产出】`mass` 值

【判据】⚠ 检视器里数值**非 0**，且手感符合车重

【审】`audit/godot/vehicle.md#7`

### Step 2　⚠ 重心必须低于悬挂点　`[vehicle/04#S2]`

【读】`howto/godot/vehicle.md#4. 重心与防翻：低速翻车是参数问题`

【做】调整重心高度，使其低于车轮悬挂点。

⛔ 重心过高 → 过弯即翻，
⚠ 表现为"低速转弯也翻车"，
⛔ 常被误判为"转向力太大"，于是越调越错。

【产出】重心高度值

【判据】⚠ 中速过弯**不翻车**

【审】`audit/godot/vehicle.md#8`

### Step 3　⛔ damping 必须非 0　`[vehicle/04#S3]`

【读】`howto/godot/vehicle.md#5. 悬挂四元组：travel / stiffness / damping / rest_length`

【做】设 `damping_compression` 与 `damping_relaxation`。

⛔ 为 0 → 悬挂无限弹跳 →
表现为"过个坎车身一直晃"，
⛔ 这是本域最常见且**最容易被当成物理引擎 bug** 的现象。

【产出】damping 两个值

【判据】⚠ 过减速带后车身**2 秒内停稳**

【审】`audit/godot/vehicle.md#14`

### Step 4　⚠ stiffness 要能撑住车重　`[vehicle/04#S4]`

【读】`howto/godot/vehicle.md#5. 悬挂四元组：travel / stiffness / damping / rest_length`

【做】`suspension_stiffness` 按车重/轮数调。

⛔ 刚度不足 → 车身"坐地"（悬挂压到底），
表现为"车看起来矮了一截"且过坎触底，⛔ 不报错。

【产出】stiffness 值

【判据】⚠ 静止时悬挂**未压到底**

【审】`audit/godot/vehicle.md#15`

### Step 5　⛔ 斜坡驻车不滑走　`[vehicle/04#S5]`

【读】`howto/godot/vehicle.md#5. 悬挂四元组：travel / stiffness / damping / rest_length`

【做】用 `brake` 或 `friction_slip` 保证静止摩擦。

⛔ 不处理 → 斜坡上車自己滑走，
⚠ 表现为"停车后车不见了"，排查方向被引到"位置同步"。

【产出】驻车摩擦

【判据】⚠ 斜坡上停车**静止不动**

【审】`audit/godot/vehicle.md#15`

### Step 6　⚠ 高速转向衰减（与 03 联动）　`[vehicle/04#S6]`

【读】`howto/godot/vehicle.md#4. 重心与防翻：低速翻车是参数问题`

【做】确认 03/S6 的衰减曲线在**实车**上够用。

⛔ 参数区写好了但实车翻 → 衰减不够，
⚠ 注意：翻车是**重心 + 转向 + 速度**三者的合结果，
单调一个往往无效。

【产出】实测结论

【判据】⚠ 最高速打满方向**不翻车**

【审】`audit/godot/vehicle.md#12`

## 5. 常见返工

**① mass 依赖子节点。** 推不动。

**② 重心过高。** 低速就翻。

**③ damping=0。** 一直晃，最像引擎 bug。

**④ stiffness 不足。** 车身坐地。
