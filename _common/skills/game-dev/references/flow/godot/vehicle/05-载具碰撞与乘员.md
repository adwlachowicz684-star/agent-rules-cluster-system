# 05 载具碰撞与乘员（vehicle 域）

> **前置**：`02-车身与车轮节点.md` 已完成

> **对应**：做法 `howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`
> 　　　审核 `audit/godot/vehicle.md#16`

## 0. 交付物定义

⚠ **本步的坑是"检测信号用错"与"状态挂在载具上"。**

⛔ 常见假完成：车能载人就行——
⚠ 但用 `body_entered` 检测乘员会把**地面也当成乘客**，
且乘员状态若挂在载具节点上，⛔ 载具销毁时乘客**悬空崩溃**。

做完这一步，应该能**当场演示**：

1. 乘员检测**只**收角色，不收地面/道具
2. ⚠ 乘员状态**独立于载具**存储（不在载具子节点上）
3. ⛔ 载具销毁时所有乘客**安全落地**
4. ⚠ 满员后拒绝上车
5. ⛔ 角色在车内的碰撞**已关闭**（不与车身互挤）

**产出物**（下游按名字对接）：

```text
Area3D (载具包围盒) → 乘员检测
occupants: Array[Node]     # ⛔ 存在外部管理器，非载具子节点
max_occupants: int
# ⛔ 用 area/body 信号前必须过滤类型
```

## 2. 工序

### Step 1　⚠ 用 Area3D 检测，不用车身碰撞体　`[vehicle/05#S1]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】加 `Area3D` 包围车身，用它收乘员。

⛔ 直接用车身 `body_entered` → 车轮/地面都触发 →
乘客列表混入非角色，⚠ 表现为"车里莫名多了东西"。

【产出】`Area3D` 包围盒

【判据】⚠ 乘员表里**只有**角色

【审】`audit/godot/vehicle.md#16`

### Step 2　⛔ 信号回调必须过滤类型　`[vehicle/05#S2]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】`body_entered` 里先判 `is 角色` 再加。

⛔ 不过滤 → 地面/道具进表，
⚠ 表现为"上车后车不动"或"乘客数永远满"，
⛔ 排查时不会想到是过滤问题。

【产出】类型过滤

【判据】⛔ 压到地面时乘员表**不增长**

【审】`audit/godot/vehicle.md#16`

### Step 3　⚠ 乘员状态存外部，不挂载具　`[vehicle/05#S3]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】乘员表放在**独立的载具管理器**，不是载具的子节点。

⛔ 挂在载具上 → 载具销毁 → 乘客引用悬空 →
⚠ 表现为"车一毁就崩"，而崩溃点离载具逻辑很远。

【产出】`occupants`（外部）

【判据】⚠ 销毁载具**不崩溃**

【审】`audit/godot/vehicle.md#17`

### Step 4　⛔ 载具销毁前先退出乘员　`[vehicle/05#S4]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】销毁流程：先让所有乘客下车并定位 → 再销毁。

⛔ 先销毁再处理乘客 → 角色位置丢失 →
表现为"车毁后人掉出地图"或崩溃。

【产出】销毁顺序

【判据】⚠ 车毁后所有乘客**站在地面上**

【审】`audit/godot/vehicle.md#18`

### Step 5　⚠ 满员拒绝上车　`[vehicle/05#S5]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】上车前校验 `occupants.size() < max`。

⛔ 不校验 → 超载，且后续"谁在车上"逻辑全乱，
⚠ 表现为"两个人开同一辆车，方向互相打架"。

【产出】满员校验

【判据】⚠ 满员时上车请求**被拒绝**

【审】`audit/godot/vehicle.md#24`

### Step 6　⛔ 关闭车内角色碰撞　`[vehicle/05#S6]`

【读】`howto/godot/vehicle.md#8. 乘员：用 Area3D 检测，状态独立于载具`

【做】上车后关闭角色与车身的碰撞。

⛔ 不关 → 角色与车身互挤 →
表现为"上车后被弹飞"或"车身抖动"，
⛔ 常被误判为"物理穿透"。

【产出】碰撞关闭

【判据】⚠ 上车后车身**不抖动**

【审】`audit/godot/vehicle.md#23`
