# 01 生成物与种子契约（程序化生成域）

> **本步交付**：一张"哪些东西是生成的"边界清单 + 种子来源与版本约定
> **对应**：流程 `howto/godot/procedural-generation.md` · 审核 `audit/godot/procedural-generation.md`

## 0. 交付物定义

1. 明确列出**生成物**（地形 / 布局 / 敌人 / 奖励 / 任务）与**手工物**（剧情、Boss 房）
2. 种子有唯一来源，能从分享码还原
3. 生成器有版本号，写进存档

## 1. 前置检查清单

- [ ] 已确认哪些内容是**程序生成**的，哪些是手工的
- [ ] ⚠ 已确认生成结果**不进存档**，只进种子
- [ ] 有一张能跑通的最小地形可测

## 2. 工序

### Step 1　划定生成物边界　`[procgen/01#S1]`

【读】`howto/godot/procedural-generation.md#0. 起点不是"生成画面"，是可复现的数据管线`

【做】
列出本次要生成的东西，逐项标注是否生成、是否随种子变化。
⛔ 把剧情、教学关也标成"生成" → 无法保证叙事节奏。

【产出】生成物边界清单（表格式，含"是否随种子变化"一列）

【判据】能指着清单说出"这一项不是生成的，因为它是剧情"。

【审】`audit/godot/procedural-generation.md#1`

### Step 2　确定种子来源与分享码　`[procgen/01#S2]`

【读】`howto/godot/procedural-generation.md#1. RandomNumberGenerator`

【做】
种子唯一入口：`seed_source → hash → rng.seed`。
⛔ 用 `rng.seed` 的 getter 去"回看"分享码 —— 返回的**是先前状态不是原始种子**。
分享码单独存一份原始值。

【产出】一个 `set_seed(src)` 入口 + 分享码字段

【判据】输入同一个分享码两次，生成结果逐格一致。

【审】`audit/godot/procedural-generation.md#4`

### Step 3　给生成器定版本号　`[procgen/01#S3]`

【读】`howto/godot/procedural-generation.md#0. 起点不是"生成画面"，是可复现的数据管线`

【做】
生成器加 `GENERATOR_VERSION` 常量，改动生成逻辑时递增。
⛔ 以为改了参数不影响老档 —— 老档按旧参数配的种子，地形会变。

【产出】`GENERATOR_VERSION` + 变更记录

【判据】改一次生成参数 → 版本号 +1，且在记录里能查到改了什么。

【审】`audit/godot/procedural-generation.md#20`

### Step 4　把生成结果定义成纯数据　`[procgen/01#S4]`

【读】`howto/godot/procedural-generation.md#0. 起点不是"生成画面"，是可复现的数据管线`

【做】
先算完**纯数据**（布局数组 / 房间图 / 投放表），最后才实例化。
⛔ 边算边 `add_child` —— 每帧插几十节点会掉帧，且中途失败留半截场景。

【产出】可序列化的数据结构定义

【判据】能在**不创建任何节点**的前提下把整关算完。

【审】`audit/godot/procedural-generation.md#11`

### Step 5　埋好复现钩子　`[procgen/01#S5]`

【读】`howto/godot/procedural-generation.md#6. 坐标精度是硬约束`

【做】
暴露 `regenerate(seed)` 入口，能在运行时重跑一次。
⛔ 只在原点附近测过就算过 —— 精度问题**只在远处出现**。

【产出】一个调试用的"重生成"按钮或命令

【判据】能在世界**边缘坐标**处重生成并比对，不只是原点。

【审】`audit/godot/procedural-generation.md#19`

## 3. 参考实现

```gdscript
const GENERATOR_VERSION := 1

var _seed_source: String = ""
var _rng := RandomNumberGenerator.new()

func set_seed(src: String) -> void:
    _seed_source = src
    _rng.seed = hash(src)      # ⚠ 先过 hash，见 02
```
