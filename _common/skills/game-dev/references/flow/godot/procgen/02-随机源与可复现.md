# 02 随机源与可复现（程序化生成域）

## 0. 交付物定义

1. 没有任何一处用全局 `randi()`
2. 外部种子先过 `hash()`
3. 同一个种子，跨会话逐格一致

## 2. 工序

### Step 1　实例隔离，禁用全局 randi　`[procgen/02#S1]`

【读】`howto/godot/procedural-generation.md#1. RandomNumberGenerator`

【做】
每个生成子系统**各自一个** `RandomNumberGenerator` 实例。
⛔ 全局 `randi()` 是**全局状态**，任何脚本、插件、引擎行为调用它都会改变下一次结果 —— 必须实例隔离。

【产出】地形 / 布局 / 投放 各一个 RNG 实例

【判据】全库搜索 `randi()` / `randf()` **零命中**。

【审】`audit/godot/procedural-generation.md#2`

### Step 2　外部种子先过 hash　`[procgen/02#S2]`

【读】`howto/godot/procedural-generation.md#7. 种子质量：RNG 无雪崩效应`

【做】
`rng.seed = hash(seed_source)`。
⛔ 直接拿关卡号 1/2/3 当种子 —— RNG **无雪崩效应**，
相邻种子产出**相似流**，连开三局会觉得"根本没随机"。

【产出】种子入口统一走 `hash()`

【判据】种子 1 / 2 / 3 生成的三张图，结构差异肉眼可辨。

【审】`audit/godot/procedural-generation.md#16`

### Step 3　seed 与 state 的顺序　`[procgen/02#S3]`

【读】`howto/godot/procedural-generation.md#1. RandomNumberGenerator`

【做】
**先 seed 后 state**。
⛔ 先恢复 `state` 再设 `seed` —— 官方写明设 seed 会**改变内部状态**，
刚恢复的 state 被覆盖掉，⛔ 表现为"读档后前几次正常、之后逐渐不一致"。

【产出】存档里存 `state`，加载时按"先 seed 后 state"恢复

【判据】存档后连续抽取 20 次，逐次与存档前一致。

【审】`audit/godot/procedural-generation.md#3`

### Step 4　锁定调用顺序与版本　`[procgen/02#S4]`

【读】`howto/godot/procedural-generation.md#1. RandomNumberGenerator`

【做】
固定遍历顺序（不依赖字典顺序、不依赖 `get_children()` 顺序）。
⛔ 以为同种子永远同结果 —— 官方明确 PCG32 是**实现细节，不承诺跨版本复现**。

【产出】确定性说明文档（含 Godot 版本与导出模板版本）

【判据】跨会话、跨重启一致；跨引擎版本**不**作承诺并已写明。

【审】`audit/godot/procedural-generation.md#5`

### Step 5　热路径不重建 RNG　`[procgen/02#S5]`

【读】`howto/godot/procedural-generation.md#1. RandomNumberGenerator`

【做】
RNG 实例**复用**，不在循环里 `RandomNumberGenerator.new()`。
⛔ 紧密循环里连续构造可能撞种子（待核对项），且无谓开销。

【产出】RNG 生命周期说明（谁持有、何时重置）

【判据】生成一次全程**零次** `RandomNumberGenerator.new()`（除初始化）。

【审】`audit/godot/procedural-generation.md#22`

## 3. 参考实现

```gdscript
var _rng_terrain := RandomNumberGenerator.new()
var _rng_layout  := RandomNumberGenerator.new()
var _rng_loot    := RandomNumberGenerator.new()

func set_seed(src: String) -> void:
    var h := hash(src)
    _rng_terrain.seed = h
    _rng_layout.seed  = h ^ 0x9E3779B9
    _rng_loot.seed    = h ^ 0x85EBCA6B
```
