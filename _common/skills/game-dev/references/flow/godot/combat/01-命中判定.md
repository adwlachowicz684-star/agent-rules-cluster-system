# 01 命中判定（战斗结算域）

> **前置**：已定死 2D/3D、已确定"谁是攻击者谁是目标"（见 `00-域流程总览.md`）
> **本步交付**：一次攻击产生**一个** `AttackContext`，几何层只回答"重叠/打中了什么"，不做任何伤害
> **对应**：做法 `howto/godot/combat.md` · 审核 `audit/godot/combat.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 按攻击键，范围内的敌人被**识别**为候选目标（先不扣血）
2. 一次按键**只产生一次**命中事件（⚠ 不是两次、不是四段）
3. 穿透攻击命中多个目标时，每个目标各一次
4. ⚠ **关掉伤害逻辑也能验证**——只看"识别到了谁"

**产出物**（下游按名字对接）：

```text
AttackContext          class_name，字段见下方
CombatResolver.resolve(ctx) -> HitResponse
can_hit_fired 信号     携带 attacker / target / ctx
```

⚠ 产出物必须能指认到符号。⛔ "完成了命中判定"不算——下游（02 伤害结算）要靠 `AttackContext` 的字段名对接。

## 1. 前置检查清单

- [ ] 已确认物理层：攻击者在哪个 layer、敌人受击框在哪个 layer
- [ ] 已确认 `Physics Ticks Per Second`（默认 60）
- [ ] 已有可识别的敌人对象（哪怕是色块 + `class_name Enemy`）
- [ ] ⚠ 已确认判定放在 **`_physics_process`**，不是 `_process`
- [ ] ⛔ 已确认**不在** `body_entered` 回调里写伤害/特效/死亡广播

## 2. 工序

### Step 1　定义 AttackContext（几何与伤害之间的协议）　`[combat/01#S1]`

【读】`howto/godot/combat.md#1. AttackContext —— 几何与伤害之间的协议`

【做】新建 `attack_context.gd`，字段至少包含：

```gdscript
class_name AttackContext
extends RefCounted

enum HitResponse { ACCEPTED, BLOCKED, DODGED, IMMUNE, DEAD, CONSUMED }

var attacker: Node
var base_amount: float
var damage_tag: StringName = &"physical"
var direction: Vector2 = Vector2.RIGHT
var knockback: float = 120.0
var can_be_blocked: bool = true
var can_crit: bool = true
var attack_id: int = 0          # ⚠ 去重用，必须
var hit_targets: Array[Node] = []  # ⚠ 已命中集合，必须

func already_hit(target: Node) -> bool:
    return target in hit_targets
```

【产出】`attack_context.gd` 可被实例化，`already_hit()` 返回正确结果

【判据】同一个 target 加进 `hit_targets` 后再查 `already_hit()` 返回 `true`

【审】`audit/godot/combat.md#5`（一次攻击一个回调 → 要 `attack_id` 去重）

### Step 2　几何层只做三件事　`[combat/01#S2]`

【读】`howto/godot/combat.md#0. 四层分离` 与 `#2. 命中判定：三种方式按内容分层`

【做】按武器类型选一种判定方式：

| 方式 | 适合 | 关键点 |
|---|---|---|
| `Area2D/3D` + `body_entered` | 持续接触、范围持续伤害 | 只回答"重叠了什么" |
| 射线 `intersect_ray` | 即时命中（枪、激光） | 改了 target 要 `force_raycast_update()` |
| 形状查询 `intersect_shape` | 范围攻击（爆炸、横扫） | 拿到的是数组 |

⚠ 回调里**只做**：组装 `AttackContext` → 调 `CombatResolver.resolve_hit()`。
⛔ 不扣血、不播特效、不发死亡广播。

【产出】命中时打印出"谁打中了谁、attack_id 是多少"，但**血量不变**

【判据】在回调里加一行 `print()`，血量值前后一致（证明没有偷偷扣血）

【审】`audit/godot/combat.md#1`（碰撞体回调里写伤害逻辑 → 加规则要改所有武器回调）

### Step 3　hitbox 默认关闭，由动画开　`[combat/01#S3]`

【读】`howto/godot/combat.md#2. 命中判定` 的「hitbox / hurtbox 三层」小节

【做】
```
攻击框 hitbox    只在 active 帧启用   ← ⚠ 默认关闭
受击框 hurtbox   常驻
防御框 blockbox  有朝向（背后攻击不算格挡）
```

⚠ hitbox 的 `monitoring` 初始必须是 `false`。

【产出】角色站着不动时，走进敌人**不造成伤害**

【判据】不按攻击键，让角色穿过敌人堆，血量全程不变

【审】`audit/godot/combat.md#2`（hitbox 常开省事 → 走路也在造成伤害）

### Step 4　判定放进固定步长　`[combat/01#S4]`

【读】`howto/godot/combat.md#2. 命中判定` 开头的 ⚠ 提示

【做】所有命中检测逻辑放 `_physics_process`（固定步长）。
表现层可以插值，判定不能跟着渲染帧走。

【产出】判定逻辑全部位于 `_physics_process` / 由 Call Method Track 触发

【判据】⚠ **把帧率上限设成 30 和设成 240，同一段操作命中结果完全一致**

【审】`audit/godot/combat.md#3`（判定放 `_process` → 帧率不同手感不同）

### Step 5　射线的强制刷新　`[combat/01#S5]`

【读】`howto/godot/combat.md#2. 命中判定` 的射线行

【做】若用 `RayCast2D/3D`：改了 `target_position` 之后**必须**调 `force_raycast_update()`。

【产出】改完 target 立即查询，拿到的是当前帧结果

【判据】⚠ 单步调试下"改 target 后立刻查询"与"等一帧再查询"结果一致

【审】`audit/godot/combat.md#4`（改了射线 target 就能用 → 要 `force_raycast_update()`）

### Step 6　去重：一次攻击一次结算　`[combat/01#S6]`

【读】`howto/godot/combat.md#1. AttackContext` 的 ⚠ 提示

【做】每次攻击发起时 `attack_id += 1`；命中回调里先查 `ctx.already_hit(target)`，
已命中则直接 `return`，否则加入 `hit_targets`。

【产出】旋转斩扫过同一敌人 3 帧，只结算 1 次

【判据】⚠ **加日志计数**：一次按键内 `resolve_hit` 被调用的总次数 == 命中到的**不同目标数**

【审】`audit/godot/combat.md#5`（同帧多重叠 → 要 attack_id 去重）

## 3. 参考实现

```gdscript
# hitbox.gd —— 挂在武器/角色的 Area2D 上
extends Area2D
class_name Hitbox

@export var damage: float = 10.0
@export var knockback: float = 120.0
@export var can_crit: bool = true

var _attack_id: int = 0
var _hit_targets: Array[Node] = []

func _ready() -> void:
    # ⚠ 默认关闭，由动画的 Call Method Track 打开
    monitoring = false
    collision_layer = 0
    collision_mask = HURTBOX_LAYER

func begin_attack() -> void:
    _attack_id += 1
    _hit_targets.clear()
    monitoring = true     # active 帧开

func end_attack() -> void:
    monitoring = false    # 判定帧结束立刻关

func _on_body_entered(body: Node) -> void:
    if body in _hit_targets:
        return            # ⚠ 同一次攻击不重复结算
    _hit_targets.append(body)
    var ctx := AttackContext.new()
    ctx.attacker = owner
    ctx.base_amount = damage
    ctx.knockback = knockback
    ctx.can_crit = can_crit
    ctx.attack_id = _attack_id
    ctx.direction = (body.global_position - owner.global_position).normalized()
    CombatResolver.resolve_hit(body, ctx)
```

⚠ `begin_attack()` / `end_attack()` 由动画的 **Call Method Track** 调用，
⛔ 不要用计时器猜时间（见 03）。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 一次攻击掉两次血 | 同帧多重叠没去重 | S6 |
| 走路就在扣血 | hitbox 常开 | S3 |
| 高刷屏上打不中 | 判定放 `_process` | S4 |
| 加新武器要改一堆回调 | 伤害写在回调里 | S2 |
| 射线打不中 | 没 `force_raycast_update()` | S5 |
