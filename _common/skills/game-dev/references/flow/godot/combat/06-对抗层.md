# 06 对抗层（战斗结算域）

> **前置**：02 结算管线已通，04 状态容器已可用
> **本步交付**：命中之后，双方进入明确的**行动权**状态——硬直、霸体、格挡、招架、破防、处决、部位破坏
> **对应**：做法 `howto/godot/combat.md` · 审核 `audit/godot/combat.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 打中后受击方**进硬直**（不能立刻还手），硬直会随连段递减但有下限
2. 霸体期间**照掉血**但不进硬直，且霸体被打掉时**统一结算**（不是每帧重判）
3. 格挡耗持续资源、招架耗时间窗口，⛔ 两者不共用一条
4. 招架成功时，伤害**根本没进结算**（不是扣了再撤销）
5. 处决期间攻击方无敌、目标不可打断

**产出物**（下游按名字对接）：

```text
PoiseState        韧性/霸体：poise_damage 累计 + 窗口统一结算
GuardState        格挡（资源条）与招架（时间窗）分离
HitstunState      硬直：两个来源、按真实时间衰减、空地独立
part_broken 信号  携带 part_id / flags，供 AI 行为树订阅
```

⚠ 本层的本质是**争夺行动权**，不是数值增减。
⛔ 把它做成"伤害计算里加几个 flag"是后期最难拆的债。

## 1. 前置检查清单

- [ ] 02 的 `resolve_hit()` 有清晰的**分支入口**（招架要插在伤害之前）
- [ ] 04 的 `StatusContainer` 可用（硬直/霸体都是状态）
- [ ] ⚠ 已确认"两个硬直来源"的设计（攻击方 + 受击方）
- [ ] 已确认霸体的**代价**（至少一项）
- [ ] 已确认帧率无关：衰减用真实时间

## 2. 工序

### Step 1　硬直：两个来源分开　`[combat/06#S1]`

【读】`howto/godot/combat.md#8.1 硬直：行动权的租借，不是"受伤动画的时长"`

【做】硬直时长 = **攻击方 `base_hitstun` × 受击方 `combo_scaling`**。
⛔ 不能只放在攻击方。

⚠ 出招硬直和受击硬直是**两种完全不同的状态**，⛔ 共用一个 `stun` 字段。
被打断是**转入受击**，不是计时器相加。

【产出】`HitstunState` 区分 `attack_commit` 与 `hit_reaction`

【判据】⚠ 出招被打断时，受击硬直**替换**了出招硬直，不是两者相加

【审】`audit/godot/combat.md#16`（硬直时长只放攻击方 → 要两个来源分开）
　　　`#17`（共用一个 stun 字段 → 被打断是转入受击，不是计时器相加）

### Step 2　硬直衰减：按真实时间 + floor　`[combat/06#S2]`

【读】`howto/godot/combat.md#8.1 硬直`

【做】硬直要**按真实时间衰减并设 floor**。
⛔ 不递减、只加连段上限 → 连段断得突兀。

⚠ **空中/地面要两套独立的衰减计时器**——共用的话落地会重置衰减，
空中连变成地面长连。

【产出】衰减曲线可配（速率 + floor），空地两套独立计时

【判据】⚠ 同一段连招在空中打与在地面打，**衰减行为不同且各自可复现**

【审】`audit/godot/combat.md#18`（硬直不递减 → 要按真实时间衰减并设 floor）
　　　`#19`（空地共用衰减计时器 → 落地重置，要两套独立）

### Step 3　暴击要有 ignore_decay 豁免　`[combat/06#S3]`

【读】`howto/godot/combat.md#8.1 硬直` 的暴击衰减 ⚠

【做】暴击的设计价值是"打断敌人动作"。
若它走同一条衰减链路，会出现**连段越深暴击越打不出硬直**——
设计意图被自己做的衰减系统吃掉。要加 `ignore_decay`。

【产出】`AttackContext.ignore_decay` 字段，暴击时置 `true`

【判据】⚠ **连段第 10 段时暴击，仍能打出可感知的硬直**（不是被衰减抹平）

【审】`audit/godot/combat.md#20`（暴击也走衰减链路 → 要 ignore_decay）

### Step 4　霸体是"延迟硬直"，不是减伤　`[combat/06#S4]`

【读】`howto/godot/combat.md#8.2 霸体 / 韧性：延迟硬直，不是消灭硬直`

【做】霸体期间**照掉血、照吃状态**，只是不立刻进硬直。
⚠ 混在一起玩家无法从"我被打出硬直"推断该堆韧性还是堆护甲。

⚠ **霸体必须有代价**（至少一项）：动作变慢 / 耗资源 / 视觉明显 / 可被抓取。
⛔ 无代价的霸体 = 无脑站桩。

【产出】`PoiseState` 只管"是否延迟硬直"，⛔ 不改伤害数值

【判据】⚠ 开霸体挨打，血照掉，但角色能继续出招

【审】`audit/godot/combat.md#21`（霸体 = 减伤 → 实际是延迟硬直）
　　　`#24`（霸体无代价 → 变无脑站桩）

### Step 5　霸体窗口结束统一结算　`[combat/06#S5]`

【读】`howto/godot/combat.md#8.2 霸体 / 韧性`

【做】窗口内**累计** `poise_damage`，⚠ **窗口结束时统一判定**。
⛔ 每帧重新判定 → 会出现"轻击一下把霸体打掉，但霸体状态还挂着"。

⚠ 韧性恢复要**瞬时回满 + 连续 X 秒未受击**。
⛔ 缓慢回血会出现"模糊半恢复态"（玩家看不出到底还有多少韧性）。

【产出】`PoiseState` 有明确的窗口边界与瞬时恢复逻辑

【判据】⚠ 在窗口内连续挨 5 下轻击，霸体在**窗口结束那一刻**统一破除（不是第 1 下就破）

【审】`audit/godot/combat.md#22`（霸体每帧重新判定 → 要窗口结束统一结算）
　　　`#23`（韧性缓慢回血 → 要瞬时回满 + 连续 X 秒未受击）

### Step 6　格挡与招架是两种资源　`[combat/06#S6]`

【读】`howto/godot/combat.md#8.3 格挡 / 破防 / 招架：三个状态，一条时间线`

【做】⛔ 不共用一条"防御条"：

| | 消耗 |
|---|---|
| **格挡** | **持续资源**（耐力/防御值） |
| **招架** | **时间窗口** |

⚠ 招架 ⛔ **不能做成概率触发**——"按对了但有 30% 失败"，
玩家无法判断是自己按错还是系统判错；而"按早了也有机会成功"
会让玩家一直按住，退化成无脑站桩。

【产出】`GuardState` 里格挡与招架是两个独立字段

【判据】⚠ 耐力耗尽时格挡失效但招架仍可用（证明是两套资源）

【审】`audit/godot/combat.md#25`（格挡和招架共用一个防御条 → 是两种资源）
　　　`#26`（招架做成概率触发 → 消灭可读性，玩家会一直按住）

### Step 7　招架先于伤害结算　`[combat/06#S7]`

【读】`howto/godot/combat.md#8.3 格挡 / 破防 / 招架`

【做】⚠ **招架必须"先于伤害结算分支"**，⛔ 不能是伤害之后的回调。
那时伤害已扣、韧性已扣、硬直已进，再撤销就是一堆 flag 互相抵消。

⚠ 招架失败要有**显式代价**（`fail_recovery` 配表），
⛔ 无代价 = 无风险选项 = 玩家无脑按。

【产出】招架成功时 `resolve_hit()` 在扣血之前就返回 `BLOCKED`/招架响应

【判据】⚠ **招架成功时，HP 数值前后完全相同**（不是扣了再补回来）

【审】`audit/godot/combat.md#27`（招架是伤害之后的回调 → 要先于伤害结算分支）
　　　`#28`（招架失败无代价 → 要显式 fail_recovery 配表）

### Step 8　破防窗口要给收益　`[combat/06#S8]`

【读】`howto/godot/combat.md#8.3 格挡 / 破防 / 招架`

【做】⚠ 破防窗口必须**够一次攻击落地、不够两次**。
⛔ 窗口给不出收益，整个破防系统就不成立。

【产出】破防窗口时长可配，且实测验证"够一次不够两次"

【判据】⚠ 破防后能稳定打出一次重击，但**打不出第二次**

【审】`audit/godot/combat.md#29`（破防窗口不给收益 → 破防系统不成立）

### Step 9　处决：优先级与期间无敌　`[combat/06#S9]`

【读】`howto/godot/combat.md#8.4 处决：状态切换的"事务"，不是一段动画`

【做】优先级：**背后未警觉 > 破防 > 血量阈值**。
⛔ "血量低就能处决"是奖励不是技巧。

⚠ **处决期间攻击方无敌、目标不可打断**——这不是便利是**必需**：
处决动画里攻击方不能闪避不能取消，若还能被任意攻击打断，
那处决就是**自伤动作**。

【产出】处决状态机：进入时锁双方，结束时统一解锁

【判据】⚠ 处决过程中让另一个敌人攻击你，**不掉血也不被打断**

【审】`audit/godot/combat.md#30`（处决条件是「血量低」→ 那是奖励不是技巧）
　　　`#31`（处决期间可被任意伤害打断 → 处决成自伤动作）

### Step 10　部位是独立实体　`[combat/06#S10]`

【读】`howto/godot/combat.md#8.5 部位破坏：独立实体 + 独立状态 + 独立 hitbox`

【做】部位 ⛔ 不是"伤害结算里加个 flag"，是**独立实体**：
独立 HP、与本体分离、独立 hitbox。

⚠ 部位破坏 = **掉落物 + 模型切换 + 残留表现** 三件事，⛔ 不是换个模型。

【产出】`part_broken(part_id, flags)` 信号，供 AI 行为树监听

【判据】⚠ AI ⛔ **不直接读** `part.hp`，而是订阅 `part_broken` 信号做出反应

【审】`audit/godot/combat.md#32`（部位 = 加个 flag → 是独立实体）
　　　`#33`（AI 直接读 part.hp → 要发 part_broken 信号）
　　　`#34`（部位破坏 = 换模型 → 是掉落物+模型切换+残留表现三件事）

### Step 11　攻防解耦，靠返回码回流　`[combat/06#S11]`

【读】`howto/godot/combat.md#8.7 Godot 实现：两棵树、一份数据、一个权威源`

【做】攻防双方 ⛔ **不要互相持引用**。靠事件与 `AttackContext` 解耦，
结果用**返回码**回流。

⚠ 联网时：**不要等服务端确认才表现招架** ——
60ms 延迟足以让短窗口完全不可用。要**客户端预测 + 服务端校正**。

【产出】`resolve_hit()` 不持有对方引用；联网时招架走预测

【判据】⚠ 加一个全新的对抗状态（如"弹反"）时，**不需要改任何武器类**

【审】`audit/godot/combat.md#39`（攻防双方互相持引用 → 要靠事件与 AttackContext 解耦）
　　　`#40`（等服务端确认才表现招架 → 要客户端预测 + 服务端校正）

## 3. 参考实现

```gdscript
# poise_state.gd —— ⚠ 只管"是否延迟硬直"，不改伤害
extends Node
class_name PoiseState

@export var max_poise: float = 100.0
@export var regen_delay: float = 3.0      # ⚠ 连续 X 秒未受击才回

var _poise: float
var _window_damage: float = 0.0           # 窗口内累计
var _since_hit: float = 0.0

func _physics_process(delta: float) -> void:
    _since_hit += delta
    if _since_hit >= regen_delay and _poise < max_poise:
        _poise = max_poise                # ⚠ 瞬时回满，不缓慢恢复

func on_hit(amount: float, poise_damage: float) -> void:
    _since_hit = 0.0
    _window_damage += poise_damage        # ⚠ 只累计，不判定

func end_window() -> bool:
    # ⚠ 窗口结束统一结算，⛔ 不是每帧重判
    var broke := _window_damage >= _poise
    if broke: _poise = 0.0
    _window_damage = 0.0
    return broke
```

⚠ `_window_damage` 的窗口边界由 03 的帧数据决定（通常是每次攻击的 active 结束）。

## 4. 验收清单

- [ ] 出招被打断时受击硬直**替换**出招硬直（不相加）
- [ ] 硬直按真实时间衰减并设 floor，空地两套独立
- [ ] 连段第 10 段暴击仍能打出硬直（ignore_decay）
- [ ] 霸体期间照掉血但能继续出招，且有代价
- [ ] 霸体在窗口结束统一破除（不是第 1 下就破）
- [ ] 耐力耗尽时格挡失效但招架仍可用
- [ ] 招架成功时 HP 完全不变（不是扣了再补）
- [ ] 破防后能打一次、打不出两次
- [ ] 处决期间双方锁定，掉血为 0
- [ ] AI 订阅 `part_broken` 而不是读 `part.hp`
- [ ] 加新对抗状态不用改武器类

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 连段越深打不动 | 暴击走了衰减链路 | S3 |
| 空中连变地面长连 | 空地共用衰减计时器 | S2 |
| 霸体一碰就破 | 每帧重判 | S5 |
| 招架后血先掉后回 | 招架是伤害后回调 | S7 |
| 玩家一直按防御键 | 招架无失败代价 | S7 |
| 处决时被打断 | 期间没锁双方 | S9 |
| 加个新状态要改所有武器 | 攻防互相持引用 | S11 |
