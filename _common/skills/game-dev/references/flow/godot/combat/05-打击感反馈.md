# 05 打击感反馈（战斗结算域）

> **前置**：02 已能发出 `damage_applied` 信号，03 已有判定窗
> **本步交付**：命中瞬间有一组**同步**反馈（顿帧+击退+屏震+特效+音效），不是只飘个数字
> **对应**：做法 `howto/godot/combat.md` `vfx-feel.md` · 审核 `audit/godot/combat.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 命中瞬间有**顿帧**（几十毫秒的冻结），能明显感觉到"打实了"
2. 顿帧结束后，时间**一定**恢复正常（不会卡死在 0）
3. 受击方有位移（击退）、屏幕有震动、有特效与音效，且**同时**发生
4. 暴击与普攻的反馈**不同**（不是只差一个数字大小）

**产出物**（下游按名字对接）：

```text
HitStop.trigger(duration, scale_override)
FeedbackDirector.on_hit(target, amount, response, is_crit)
```

⚠ `FeedbackDirector` 是**监听者**——它订阅 02 的 `damage_applied`，
⛔ 不参与结算。这样 06 对抗层新增"格挡/招架"反馈时不用改结算代码。

## 2. 工序

### Step 1　把反馈做成"一组"，不是一个数字　`[combat/05#S1]`

【读】`howto/godot/combat.md#7. 打击感：一组同步反馈，不是一个大数字`

【做】命中瞬间**同时**触发：

| 手段 | 说明 |
|---|---|
| 顿帧 hitstop | 命中瞬间冻结几十毫秒（**最关键**） |
| 击退 | 受击方位移 |
| 屏震 | trauma 模型 |
| 命中特效 | 粒子、闪光、拖尾 |
| 音效 | 与特效同步 |

⚠ **打击感靠调大伤害数字是无效的**——它是这一组反馈的**同步**。

【产出】`FeedbackDirector.on_hit()` 里五件事一起触发

【判据】⚠ 逐项关掉验证：只留顿帧 vs 只留音效，手感差异明显
（若感觉不出来，说明某一项没真正生效）

【审】`audit/godot/combat.md#12`（打击感靠调大伤害数字 → 是同步反馈）
【品】`craft/godot/aesthetics.md#4. 打击感配方：叠加，不是加量`
【品】`craft/godot/feel-params.md#8. 命中反馈的四个要素`

### Step 2　实现 hitstop（且一定能恢复）　`[combat/05#S2]`

【读】`howto/godot/combat.md#7. 打击感` 的「hitstop 实现」小节

【做】`HitStop` 用**真实时间**倒计时（`_process` 里 `delta` 不受 time_scale 影响
的前提是单独计时）：

```gdscript
func _process(delta: float) -> void:
    if not _active: return
    _remaining -= delta      # ⚠ 真实时间
    if _remaining <= 0.0:
        Engine.time_scale = _original_scale
        _active = false
```

⚠ `Engine.time_scale = 0` 会冻结物理、计时器、动画和输入。
⛔ **期间不能用普通 `await`** 等恢复——await 也被冻了。

⚠ 时长要 clamp（如 0.03–0.12 秒）。

【产出】顿帧后 `Engine.time_scale` **必定**恢复原值

【判据】⚠ **连续触发 50 次顿帧，结束后 `Engine.time_scale == 1.0`**
（这是最容易漏的 bug：重入时覆盖了 `_original_scale`，再也回不来）

【审】`audit/godot/combat.md#13`（hitstop 用 await 等恢复 → time_scale=0 时 await 也被冻）
【品】`craft/godot/feel-params.md#4. 顿帧（Hitstop / Freeze Frame）`

### Step 3　暴击与普攻走不同反馈分支　`[combat/05#S3]`

【读】`howto/godot/combat.md#7. 打击感` 与 `#4. 伤害公式` 的暴击位置

【做】`on_hit()` 按 `response` / `is_crit` 分支：
普通 / 暴击 / 格挡 / 闪避 四类反馈**各不相同**。

⚠ 若所有分支长得一样，玩家无法从画面判断"刚才发生了什么"。

【产出】四类反馈可区分（至少顿帧时长与音效不同）

【判据】⚠ 蒙住伤害数字，只看画面能分清"这是暴击还是普通命中"

【审】`audit/godot/combat.md#6`（顺序写死，玩家才能形成预期）
【品】`craft/godot/aesthetics.md#6. 一致性：同一动作，不同对象，强度要成体系`
【品】`craft/godot/polish.md#2. 润色层（第 3 层）：让反馈有层次`

### Step 4　4.7 的顿帧粒子行为变更　`[combat/05#S4]`

### Step 5　输入缓冲是手感的隐藏一半　`[combat/05#S5]`

【读】`howto/godot/combat.md#7. 打击感` 末尾的输入缓冲 ⚠

## 3. 参考实现

```gdscript
# hit_stop.gd —— autoload
extends Node
class_name HitStop

const MIN_DURATION := 0.03
const MAX_DURATION := 0.12

var _remaining := 0.0
var _original_scale := 1.0
var _active := false

func trigger(duration: float, scale_override := 0.0) -> void:
    var clamped := clampf(duration, MIN_DURATION, MAX_DURATION)
    if _active and clamped <= _remaining:
        return                          # ⚠ 重入保护：不覆盖 _original_scale
    if not _active:
        _original_scale = Engine.time_scale
        _active = true
    _remaining = clamped
    Engine.time_scale = scale_override if scale_override > 0.0 else 0.0

func _process(delta: float) -> void:
    if not _active: return
    _remaining -= delta                 # ⚠ 用真实时间
    if _remaining <= 0.0:
        Engine.time_scale = _original_scale
        _active = false

# feedback_director.gd —— ⚠ 监听者，不参与结算
extends Node
class_name FeedbackDirector

func _ready() -> void:
    CombatResolver.damage_applied.connect(_on_damage)

func _on_damage(target, amount, response, is_crit) -> void:
    match response:
        AttackContext.HitResponse.ACCEPTED:
            HitStop.trigger(0.05 if is_crit else 0.03)
            _knockback(target)
            _screen_shake(0.3 if is_crit else 0.15)
            _spawn_hit_vfx(target, is_crit)
            _play_hit_sfx(is_crit)
        AttackContext.HitResponse.BLOCKED:
            _play_block_sfx()             # ⚠ 与命中明显不同
        AttackContext.HitResponse.DODGED:
            pass                          # 闪避：无命中反馈，或只有轻微音效
        _:
            pass
```

⚠ 更可控的做法是只冻结战斗相关的动画与物理 tick。
首次实现可以围绕 `Engine.time_scale`，后期替换成自定义 `CombatTimeScale`。
