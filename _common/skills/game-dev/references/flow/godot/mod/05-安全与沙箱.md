## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：解压时校验一下路径就算安全了。**

⛔ 常见假完成：防住了 zip-slip，
⚠ 安全清单上打了个勾，
⛔ 但**引擎内置无法沙箱隔离 Mod 脚本**这件事没被写进任何文档，
玩家以为"装 Mod 是安全的"，而实际等价于运行陌生人给的代码。

做完这一步，应该能**当场演示**：

1. zip-slip 已防住（规范化后仍在根目录内）
2. ⛔ "加载 Mod = 运行第三方代码"**已明示给玩家**
3. ⛔ 清楚引擎**无内置沙箱**，第三方方案不是引擎能力
4. ⚠ 临时解压目录有清理，不泄漏
5. ⚠ 加密 PCK 不被当成安全边界

**产出物**（下游按名字对接）：

```text
安全解压函数（防 zip-slip）
风险告知文案（玩家可见）
临时目录清理策略
```

## 3. 参考实现

```gdscript
func _safe_extract(entry: String, root: String) -> bool:
    var target := root.path_join(entry).simplify_path()
    return target.begins_with(root)   # 超出根目录 = zip-slip
```

⛔ **返工：只防 zip-slip 就认为安全了** —— 真正的风险是 Mod 脚本权限与游戏相同，
这个风险**不防就永远存在**，只能靠告知与边界约定管理。
