# 06 启用禁用与存档交互（mod 域）

> **前置**：`05-安全与沙箱.md`
> **本步交付**：**存档记录 Mod id+版本 + 缺失降级 + 启用禁用不炸档**
> **对应**：做法 `howto/godot/modding.md#10. 与存档的交互`
> 　　　审核 `audit/godot/modding.md`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：存档里存了个"启用数量"就算记录了。**

⛔ 常见假完成：存档记 `mod_count: 3`，
⚠ 校验时数量对得上，看起来很稳，
⛔ 但玩家换了三个**不同**的 Mod（数量还是 3），**校验通过、内容全错** ——
这是最典型的"校验在、但校验的是错的东西"。

做完这一步，应该能**当场演示**：

1. 存档记录**每个启用 Mod 的 id + 版本**
2. ⛔ 缺失 Mod 时**降级提示**而非崩溃
3. ⛔ 卸载 Mod 后老存档**能打开**（不是变砖）
4. ⚠ 启用/禁用有冷却，不抖动
5. ⚠ 顺序配置随存档走（见 03/S5）
6. ⚠ 存档与 Mod 变更都有日志可查

**产出物**（下游按名字对接）：

```text
存档 Mod 记录结构（id + 版本）
缺失降级流程
启用禁用事务
```

## 1. 前置检查清单

- [ ] 已定存档里的 Mod 记录结构
- [ ] 已实现缺失降级（提示而非崩溃）
- [ ] 已设计启用/禁用事务
- [ ] 已确认顺序配置随存档
- [ ] 已准备变更日志

## 2. 工序

### Step 1　⛔ 存档记 id + 版本，不是数量　`[06#S1]`

【读】`howto/godot/modding.md#10. 与存档的交互`

【做】存档存 `enabled_mods: [{id, version}]`，校验逐项比对。

【产出】存档 Mod 记录结构

【判据】⛔ 换一批不同 Mod 但数量相同，校验**不通过**（能识别出内容变了）

【审】`audit/godot/modding.md#22`

### Step 2　⛔ 缺失 Mod 要降级提示，不能崩溃　`[06#S2]`

【读】`howto/godot/modding.md#10. 与存档的交互`

【做】读档时发现 id 缺失 → 提示玩家缺哪些，或加载占位资源继续。

【产出】缺失降级流程

【判据】⛔ 删掉一个已用 Mod 后读档，**游戏能进且提示明确**（不是崩溃/变砖）

【审】`audit/godot/modding.md#32`

### Step 3　⛔ 卸载 Mod 后老存档仍能打开　`[06#S3]`

【读】`howto/godot/modding.md#10. 与存档的交互`

【做】存档引用的 Mod 内容要有 fallback（占位/默认值），缺失不阻断读档。

【产出】内容 fallback 策略

【判据】⛔ 卸载全部 Mod 后打开老存档，**不报错**

【审】`audit/godot/modding.md#13`

### Step 4　⚠ 启用/禁用是事务，要有冷却　`[06#S4]`

【读】`howto/godot/modding.md#10. 与存档的交互`

【做】启用/禁用走"校验 → 应用 → 记录 → 提示"，且两次操作间有最小间隔。

【产出】启用禁用事务 + 冷却

【判据】⚠ 快速连点 10 次，**状态一致**且无重复加载

【审】`audit/godot/modding.md#29`

### Step 5　⚠ 顺序配置随存档走　`[06#S5]`

【读】`howto/godot/modding.md#7. 清单、依赖与加载顺序`

【做】把当前顺序写入存档（或与之关联的配置），换机器可复现。

【产出】顺序持久化（与存档关联）

【判据】⚠ 换机器加载同批 Mod，**冲突表现一致**

【审】`audit/godot/modding.md#36`

### Step 6　⚠ 变更要有日志，出问题时能回溯　`[06#S6]`

【读】`howto/godot/modding.md#8. 冲突检测：声明来源 ≠ 运行时解析结果`

【做】记录每次启用/禁用/加载失败（时间、id、版本、结果）。

【产出】Mod 变更日志

【判据】⚠ 玩家报告问题时，能**查出**他最近改了哪些 Mod

【审】`audit/godot/modding.md#10`

## 3. 参考实现

```text
save.enabled_mods = [ {id, version}, ... ]   # 不是数量
on_load:
    missing = enabled_mods - installed
    if missing: 提示降级，不崩溃
```

## 4. 验收清单

- [ ] 存档记 id + 版本
- [ ] 缺 Mod 时降级提示不崩溃
- [ ] 卸载后老存档能打开
- [ ] 启用禁用有冷却且状态一致
- [ ] 顺序随存档
- [ ] 变更有日志

玩家表现为"存档莫名其妙不对"，而所有校验信号都是绿的。
