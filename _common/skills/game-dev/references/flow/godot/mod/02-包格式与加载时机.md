## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：`load_resource_pack()` 返回 true 就算成功。**

⛔ 常见假完成：在菜单的 `_ready()` 里加载，返回 true，
⚠ 单测也过了（因为测的是返回值），
⛔ 但**已 `preload()` 的场景根本不受影响** —— 玩家看到"装了没变化"，
而开发者这边所有信号都是绿的。

做完这一步，应该能**当场演示**：

1. 包格式已按需求选定（是否要删除文件 / 是否要加密）
2. ⛔ 加载发生在 autoload 的 **`_init()`**（不是 `_ready()`）
3. ⛔ 路径用 `OS.get_executable_dir()` 拼接，不用相对路径
4. ⚠ C# 的 DLL 在资源包**之前**加载
5. ⚠ 加载失败有显式记录与提示，不静默继续

**产出物**（下游按名字对接）：

```text
包格式选型结论（PCK / ZIP）
ModLoader autoload（_init 加载）
路径拼接工具函数
```

## 2. 工序

### Step 1　⛔ 包格式按能力选，不是按熟悉度选　`[02#S1]`

【读】`howto/godot/modding.md#4. PCK vs ZIP：怎么选`

【做】要移除文件 → 必须 PCK（ZIP 不支持）；要加密 → 必须 PCK；要玩家用系统工具改 → ZIP 更友好。

【产出】格式选型结论 + 理由

【判据】⛔ 选型结论里**明确写了**是否需要"文件移除"与"加密"两项能力

【审】`audit/godot/modding.md#18`

### Step 2　⛔ 加载必须在 autoload 的 `_init()`，不是 `_ready()`　`[02#S2]`

【读】`howto/godot/modding.md#2. ⛔ 加载时机：必须在 autoload 的 _init()`

【做】新建 autoload，在 `_init()` 里调用 `load_resource_pack()`。

【产出】`ModLoader` autoload（`_init()` 内加载）

【判据】⛔ 已 `preload()` 的菜单场景**也能**取到 Mod 资源（不只在 `_ready()` 之后才生效）

【审】`audit/godot/modding.md#15`

### Step 3　⛔ 已 preload 的场景不受影响，这是官方明说的　`[02#S3]`

【读】`howto/godot/modding.md#2. ⛔ 加载时机：必须在 autoload 的 _init()`

【做】排查项目里所有 `preload()`，确认它们都在 Mod 加载之后才首次解析。

【产出】`preload()` 排查结果 + 改为 `load()` 的清单

【判据】⚠ 菜单场景下加载 Mod，改动**立刻可见**（不是"部分资源是 Mod 的"）

【审】`audit/godot/modding.md#16`

### Step 4　⛔ 路径用可执行文件目录拼，不用相对路径　`[02#S4]`

【读】`howto/godot/modding.md#3. ⛔ 路径：CWD 不保证是可执行文件所在目录`

【做】`OS.get_executable_dir().path_join("mods/foo.pck")`；导出项目里不用 `globalize_path("res://")`。

【产出】路径拼接工具函数

【判据】⛔ 从快捷方式 / 搜索栏 / 符号链接启动，Mod **同样加载成功**

【审】`audit/godot/modding.md#17`

### Step 5　⛔ C# 的 DLL 必须在资源包之前加载　`[02#S5]`

【读】`howto/godot/modding.md#2. ⛔ 加载时机：必须在 autoload 的 _init()`

【做】先 `Assembly.LoadFile("mod.dll")`，再 `load_resource_pack()`。

【产出】加载顺序（DLL → 资源包）

【判据】⛔ 包内脚本引用的类型**能解析到**（不报找不到类型）

【审】`audit/godot/modding.md#9`

## 3. 参考实现

```gdscript
# ModLoader.gd —— autoload，_init() 而非 _ready()
func _init() -> void:
    var dir := OS.get_executable_dir()
    for pack in _scan(dir.path_join("mods")):
        var ok := ProjectSettings.load_resource_pack(pack, true)
        if not ok:
            _record_failure(pack)   # 不静默
```

## 5. 常见返工

⛔ **返工：加载时机写在 `_ready()`** —— 表现为"部分资源是 Mod 的、部分是原版的"，
**比全部失效更难排查**，因为看起来是"Mod 半生效"。
