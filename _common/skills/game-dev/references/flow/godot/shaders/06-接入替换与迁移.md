# 06 接入替换与迁移（着色器域）

> **本步交付**：批量替换完成 + 旧 API 清理 + 设参路径统一
> **对应**：流程 `howto/godot/shaders.md` · 审核 `audit/godot/shaders.md`

## 0. 交付物定义

1. 迁移是**全局替换**，⛔ 不是改个别材质
2. 4.x 不再有全局 `SCREEN_TEXTURE`，已全部显式声明
3. `hint_enum` 全部按整数传值
4. 设参统一走 `set_shader_parameter()`（⛔ 不是 3.x 的 `set_shader_param()`）
5. uniform 名与 shader 声明**逐字符**一致
6. 取材质走 `get_active_material(0)` 或已确认的 override

## 2. 工序

### Step 1　迁移要全局替换，不是改个别材质　`[shaders/06#S1]`

【读】`howto/godot/shaders.md#9. 3.x → 4.x 迁移`

【做】
按符号做全局替换：`hint_albedo` / `hint_color` → `source_color`，
`hint_white` / `hint_black` → `hint_default_white` / `hint_default_black`，
粒子 `vertex()` → `start()` / `process()`。

⛔ 只改个别材质 —— 症状是"只有个别材质偏亮"，
那是漏改一处；"多个材质异常"才是全局检查没做。
⛔ 前者最容易被当成"这个材质本身有问题"，于是反复调一个根本没错的材质。

【产出】替换清单（旧符号 → 新符号 → 命中处数）

【判据】全库搜旧符号，命中数为 0。

【审】`audit/godot/shaders.md#28`

### Step 2　SCREEN_TEXTURE 必须显式声明　`[shaders/06#S2]`

【读】`howto/godot/shaders.md#常见错误对照`

【做】
4.x 没有全局变量 `SCREEN_TEXTURE`，必须自己声明
`uniform sampler2D screen_texture : hint_screen_texture`。
⛔ 保留 3.x 写法 —— 报 `undeclared identifier`，
但如果那段代码在测试路径上没被走到，⛔ 就只在玩家触发到时才炸。

【产出】所有屏幕 / 深度纹理采样点的声明清单

【判据】全库无 `SCREEN_TEXTURE` / `DEPTH_TEXTURE` 的裸用法。

【审】`audit/godot/shaders.md#12`

### Step 3　hint_enum 存整数，传字符串静默无效　`[shaders/06#S3]`

【读】`howto/godot/shaders.md#uniform 提示（hint）完整清单`

【做】
`hint_enum` 的取值是**整数**（选项下标，或冒号语法指定的值）。
⛔ 传字符串名称 —— 静默无效，无报错，
表现为"下拉框显示对了但效果没变"，而检查器上一切正常。

【产出】枚举清单（uniform 名 → 选项 → 对应整数）

【判据】每个 `set_shader_parameter()` 传给枚举的都是整数。

【审】`audit/godot/shaders.md#6`

### Step 4　4.x 是 set_shader_parameter，不是 set_shader_param　`[shaders/06#S4]`

【读】`howto/godot/shaders.md#uniform 名的三处静默失败`

【做】
统一用 `set_shader_parameter()` / `get_shader_parameter()`。
⛔ 沿用 3.x 的 `set_shader_param()` —— 4.x 无此方法，
⛔ 而如果调用路径在测试时没走到，报错也不会出现。

【产出】全库设参调用点清单

【判据】全库搜 `set_shader_param(`，命中数为 0。

【审】`audit/godot/shaders.md#22`

### Step 5　uniform 名大小写敏感，写错不报错　`[shaders/06#S5]`

【读】`howto/godot/shaders.md#uniform 名的三处静默失败`

【做】
`uniform` 名必须与 `.gdshader` 里的声明**逐字符**一致，区分大小写。
⛔ 靠记忆写名字 —— GDScript 侧没有自动补全，写错不报错也不生效，
⛔ 表现为"改了没反应"，排查会被引向逻辑或时序，而不是一个字母的大小写。

【产出】uniform 名 ↔ 调用点对照表（双向可查）

【判据】表里每一行的名字都能在 shader 声明里逐字符找到。

【审】`audit/godot/shaders.md#23`

### Step 6　取材质走 get_active_material，别假定 material 非空　`[shaders/06#S6]`

【读】`howto/godot/shaders.md#uniform 名的三处静默失败`

【做】
3D 用 `get_active_material(0)`，2D 用 `node.material`，取到后判空再用。
⛔ 直接用 `$Sprite.material` 就设参 —— 没设 override 时它是 `null`，
或者返回的是**表面基础材质**而不是你以为的那个 override，
⛔ 表现为"设了但没生效"，而代码看起来毫无问题。

【产出】取材质工具函数（含判空与类型检查）

【判据】每个设参点都先判空，且取到的是 override 材质。

【审】`audit/godot/shaders.md#24`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：4.x 用 set_shader_parameter；枚举传整数；取材质要判空
const MODE_RIM := 1   # ⓘ 与 .gdshader 里 hint_enum 的选项下标一致

func _set_effect(node: MeshInstance3D, amount: float) -> void:
    var mat := node.get_active_material(0) as ShaderMaterial
    if mat == null:                       # ⛔ 未设 override 时是 null
        push_warning("no ShaderMaterial override on %s" % node.name)
        return
    mat.set_shader_parameter("u_amount", amount)   # ⛔ 不是 set_shader_param
    mat.set_shader_parameter("u_mode", MODE_RIM)   # ⛔ 枚举传字符串会静默无效
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 只有个别材质偏亮 | 漏改一处，没做全局替换 | S1 |
| 迁移后报 undeclared identifier | 保留 3.x 全局采样器 | S2 |
| 下拉框对了但效果没变 | 枚举传了字符串 | S3 |
| 改参数没反应 | uniform 名大小写不符 | S5 |
| 设了但没生效 | 取到的是表面基础材质 | S6 |
