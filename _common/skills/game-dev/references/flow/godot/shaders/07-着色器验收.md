# 07 着色器验收（着色器域）

> **本步交付**：截图测试通过 + 真机通过 + 敌意环境实测通过
> **对应**：流程 `howto/godot/shaders.md` · 审核 `audit/godot/shaders.md`

## 0. 交付物定义

1. 效果**对照静态截图**确认，⛔ 不对照描述、不对照代码
2. 已在最低目标设备上验证，⛔ 桌面预览不算
3. 首次出现的卡顿已被加载界面预热覆盖
4. 改分辨率 / 换渲染器无新增卡顿
5. 逐实例参数不串，全局参数同步
6. 目标渲染器下颜色不发白

## 2. 工序


### Step 1　看截图，不看代码　`[shaders/07#S1]`

【读】`howto/godot/shaders.md#7. 调试`

【做】
把画面截下来单独看。⛔ 靠读代码判断效果好不好 ——
shader 代码的"正确性"和画面观感是两件事，
⛔ 而"逻辑全对但很难看"是完全可能、且极常见的结果。

⛔ 录屏也不算：运动中看不出的瑕疵，静态截图里一眼就能看见。

【品】`craft/godot/aesthetics.md#0. 总判据：截图测试`

【产出】静态截图（含默认参数 / 最大参数 / 关闭效果三张）

【判据】不看代码，只看截图，能说出画面主体是什么、效果是否达成。

【审】`audit/godot/shaders.md#37`

### Step 2　真机验收，桌面预览不算　`[shaders/07#S2]`

【读】`howto/godot/shaders.md#精度限定符`

【做】
在最低目标设备上跑一遍完整路径。
⛔ 用桌面预览交付 —— 移动端降级精度只在特定设备出现远处闪烁，
⛔ 而它在开发机上永远复现不了，等于把 bug 直接发给玩家。

⛔ 尤其要跑到"远处"：精度问题在近处完全看不出来。

【产出】真机验收记录（设备型号 / 渲染器 / 是否闪烁）

【判据】最低目标设备上跑完整路径，无闪烁、无闪烁式抖动。

【审】`audit/godot/shaders.md#15`

### Step 3　首次出现的卡顿要被加载界面覆盖　`[shaders/07#S3]`

【读】`howto/godot/shaders.md#预热`

【做】
清掉管线缓存，从启动跑到首次出现该效果的完整路径，测有没有新增卡顿。
⛔ 不清缓存就测 —— 缓存命中时一切正常，
⛔ 而玩家第一次进游戏就是没有缓存的状态。

⛔ `preload()` 不等于预热：要真的执行代表性 draw，首帧才不会编译。

【产出】清缓存重跑的卡顿记录

【判据】清缓存后首次出现该效果，无新增卡顿尖峰。

【审】`audit/godot/shaders.md#17`

### Step 4　改分辨率、换渲染器也要测　`[shaders/07#S4]`

【读】`howto/godot/shaders.md#预热`

【做】
至少覆盖：默认分辨率 + 一个更高分辨率 + 目标渲染器 + 一个更低质量档。
⛔ 只在默认配置下测 —— 改分辨率、换材质、动态灯光配置变化
都会生成新管线，⛔ 这些是"玩了一阵才开始卡"的典型来源，
而默认配置的测试结果会给出完全错误的信心。

【产出】覆盖矩阵 × 卡顿记录

【判据】矩阵每一格都无新增卡顿。

【审】`audit/godot/shaders.md#32`

### Step 5　逐实例参数不串，全局参数同步　`[shaders/07#S5]`

【读】`howto/godot/shaders.md#材质是共享资源，改一个会改全部`

【做】
两个方向都要测：改一个逐实例参数，**画面上**确认其他实例不变；
改一个全局参数，确认所有目标同步变化。
⛔ 只测"改了有效果" —— 那两种错误都会通过：
共享没复制时"有效果"（十个一起变），全局被复制时"也有效果"（只变一个）。

【产出】串扰测试记录（逐实例 / 全局各一组）

【判据】逐实例改动只影响一个；全局改动影响全部，无一例外。

【审】`audit/godot/shaders.md#19`

### Step 6　目标渲染器下颜色不发白　`[shaders/07#S6]`

【读】`howto/godot/shaders.md#uniform 提示（hint）完整清单`

【做】
在**目标渲染器**下看颜色：颜色纹理必须有 `source_color`。
⛔ 在 Compatibility 下测完就交付 —— `source_color` 在
Forward+ / Mobile 下是**必须**的，在 Compatibility 下是可选的，
⛔ 于是"本机正常、导出后发白"成为常态，而排查方向会被引向导出设置。

ⓘ 反向一条：法线 / 粗糙度 / 金属度 / 高度**不能加** `source_color`，
它们不是显示颜色。

【产出】渲染器 × 纹理类型对照表

【判据】目标渲染器下颜色与源图一致；非颜色纹理未误加提示。

【审】`audit/godot/shaders.md#4`、`audit/godot/shaders.md#5`

## 3. 验收清单

- [ ] 静态截图（默认 / 最大 / 关闭）已确认
- [ ] 最低目标设备真机跑通，无远处闪烁
- [ ] 清缓存重跑，首次出现无新增卡顿
- [ ] 分辨率 × 渲染器矩阵无新增卡顿
- [ ] 逐实例不串、全局同步，两个方向都测过
- [ ] 目标渲染器下颜色不发白

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 逻辑全对但很难看 | 只看代码没看截图 | S1 |
| 真机远处闪烁 | 桌面交付，精度没验证 | S2 |
| 玩家第一次进游戏就卡 | 清缓存没测，首帧仍编译 | S3 |
| 玩了一阵才开始卡 | 改分辨率 / 换渲染器生成新管线 | S4 |
| 导出后颜色发白 | Compatibility 下测完就交付 | S6 |
| 改一个实例全场都跟着变 | 材质共享没复制，逐实例参数串了 | S5 |
