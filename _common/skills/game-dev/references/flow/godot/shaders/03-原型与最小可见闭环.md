# 03 原型与最小可见闭环（着色器域）

> **本步交付**：一个 uniform 一个效果，跑通且可调试
> **对应**：流程 `howto/godot/shaders.md` · 审核 `audit/godot/shaders.md`

## 0. 交付物定义

1. 最小闭环已跑通：**一个 uniform，一个可见变化**
2. 所有分支都写了输出，⛔ 无未定义值
3. varying 都在允许的阶段赋值
4. 中间值可用颜色可视化调试
5. 效果不对照描述判断，对照截图判断

## 1. 前置检查清单

- [ ] `shader_type` 已定（01）
- [ ] uniform 清单与归属已定（01 / 02）
- [ ] 材质实例已处理好共享（02）
- [ ] ⚠ 已准备好一个 uniform bool 的调试开关
- [ ] 已确认能在目标设备上看到画面（不只是编辑器）

## 2. 工序

### Step 1　一次只加一个 uniform，先跑通再叠加　`[shaders/03#S1]`

【读】`howto/godot/shaders.md#1. 语言基础`

【做】
先做最小闭环：加一个 uniform，让它产生一个肉眼可见的变化，确认后再加下一个。
⛔ 一次性写完整个效果 —— 出问题时分不清是哪一段造成的，
而 shader 的报错信息往往只指向行号，不指向语义。

【产出】只有一个 uniform 的最小可用 shader

【判据】改这一个 uniform 的值，画面上有明确且单调的变化。

【审】`audit/godot/shaders.md#29`

### Step 2　所有分支都要写输出，没有例外　`[shaders/03#S2]`

【读】`howto/godot/shaders.md#数据类型`

【做】
每个可能影响输出的分支，都要给输出赋值。
⛔ 只在 `if` 的成功分支里写输出 —— 局部变量**不会默认初始化为 0**，
失败分支读到的是未定义数据，⛔ 不是"保持原值"。

表现为"某些像素出现随机噪点"，且只在部分设备、部分帧出现，
于是被当成驱动 bug 或精度问题去查，实际是一行没写。

【产出】分支输出对照表（每个分支 → 输出值）

【判据】把每个分支单独置为假，画面都仍然确定、无噪点。

【审】`audit/godot/shaders.md#7`

### Step 3　varying 只能在允许的阶段赋值　`[shaders/03#S3]`

【读】`howto/godot/shaders.md#varying`

【做】
varying 只能从 `vertex()` 传向 `fragment()`，或在 `fragment()` 写入后供 `light()` 读。
⛔ 在普通 helper 函数里给 varying 赋值 —— 会直接报错；
⛔ 在 `light()` 里给从顶点阶段传入的 varying 赋值 —— 同样不允许。

ⓘ 离散索引（如物体 ID）用 `varying flat int`，默认 `smooth` 会做透视校正插值，
把 ID 插出不存在的中间值。

【产出】varying 清单（名字 / 写阶段 / 读阶段 / 是否 flat）

【判据】每个 varying 都能说出在哪写、在哪读、是否插值。

【审】`audit/godot/shaders.md#30`

### Step 4　把中间值映射成颜色来调试　`[shaders/03#S4]`

【读】`howto/godot/shaders.md#7. 调试`

【做】
不读数字，把中间值映射成颜色直接看：标量用 `vec3(value)`，
法线用 `NORMAL * 0.5 + 0.5`，屏幕 UV 用 `vec3(SCREEN_UV, 0.0)`。

⛔ 靠打印或猜测判断中间值 —— shader 里没有 console，
而"大体像那么回事"的效果会掩盖方向错误。

ⓘ 调试路径用 `uniform bool u_debug` 保护，发布时关掉。

【产出】调试开关 + 至少三种中间值的颜色映射

【判据】打开调试开关，能直接看出哪个中间量不对。

【审】`audit/godot/shaders.md#39`

### Step 5　编译通过不等于结果对，先隔离阶段　`[shaders/03#S5]`

【读】`howto/godot/shaders.md#常见错误对照`

【做】
症状出现时先隔离阶段：全黑查输出是否写入，颜色异常查颜色空间，
坐标异常查空间变换，部分像素错查分支与精度。
⛔ 编译通过就认为对了 —— 方言差异、空间错误、精度降级都能编译得过。

⛔ "只有首次卡顿"是管线编译，⛔ 不是算法问题，
往算法方向优化是纯粹的时间浪费。

【产出】症状 → 首查项对照表（按本域用过的症状填）

【判据】任一症状都能一步定位到该查的阶段。

【审】`audit/godot/shaders.md#31`、`audit/godot/shaders.md#2`

## 3. 参考实现

```gdshader
// ⓘ 承接本步产出：最小闭环 + 所有分支写输出 + 调试开关
shader_type spatial;

uniform float u_amount : hint_range(0.0, 1.0, 0.01) = 0.0;
uniform bool u_debug = false;

varying flat int v_id;   // ⓘ 离散索引用 flat，smooth 会插出不存在的中间值

void vertex() {
    v_id = int(INSTANCE_ID);
}

void fragment() {
    vec3 base = vec3(1.0, 1.0, 1.0);
    vec3 lit  = mix(base, vec3(1.0, 0.2, 0.2), u_amount);
    // ⛔ 只在 if 里写输出 → 其他分支输出未定义值
    ALBEDO = u_debug ? vec3(float(v_id) * 0.01) : lit;
}
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 某些像素随机噪点 | 只在 if 分支写输出 | S2 |
| 物体 ID 出现不存在的中间值 | 离散量用了 smooth | S3 |
| helper 里赋值报编译错 | varying 阶段不允许 | S3 |
| 效果大体像但哪都不对 | 没隔离阶段就盲调 | S5 |
| 加了三个 uniform 后全乱 | 一次写完，没做最小闭环 | S1 |
