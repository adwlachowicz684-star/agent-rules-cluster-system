# 07 XR 验收（XR 域）

> **本步交付**：真机六项实测全部通过
> **对应**：流程 `howto/godot/xr.md` · 审核 `audit/godot/xr.md`

## 0. 交付物定义

1. **真机**实测稳定在目标刷新率（⛔ 不是编辑器里）
2. 遮挡 / 移出版图的**降级路径**已实测触发
3. 抓取释放**高频循环**已实测
4. 传送的四类非法边界已实测拒绝
5. 舒适度经**真人**实测
6. 注入卡顿后能恢复到正常速度

⛔ XR 域的 bug **在正常游玩下几乎全测不出** ——
它们只在真机、遮挡、高频、边界、真人、卡顿后才出现。
所以本步判据全部是敌意条件实测，⛔ 不是"跑一遍看效果"。

## 2. 工序

### Step 1　真机实测稳定目标刷新率，⛔ 不是编辑器里　`[xr/07#S1]`

【读】`howto/godot/xr.md#6. 性能`

【做】
在目标头显上跑最坏场景并记录帧时间分布。
⛔ 只在编辑器 / 桌面预览里测 —— 编辑器开销与真机完全不同，
且桌面预览根本不跑立体渲染，
⛔ 表现为"开发时很流畅、出包后一戴就晕"，
而这个落差在出包前没有任何信号。
⛔ 也别只看平均帧率 —— VR 掉帧**不是"卡一下"，会让人呕吐**，
要看的是帧时间分布与尖峰，
⛔ 而平均帧率达标时这些尖峰完全被掩盖。

【判据】真机最坏场景的帧时间中位数在预算内，且无明显尖峰。

【审】`audit/godot/xr.md#10`

### Step 2　遮挡与移出版图，验证降级路径真的会触发　`[xr/07#S2]`

【读】`howto/godot/xr.md#⚠ `has_tracking_data` 为真不等于真的被追踪`

【做】
把手柄放桌上、移到身后、移出摄像头视野，各保持 10 秒。
⛔ 只测"手柄在视野内正常玩" —— 遮挡**必然会发生**，
⛔ 而代码分支写对了不代表触发条件对：
这类事件在编辑器里**根本不会发生**，
表现为"代码看着没问题，真机一遮挡就乱"。

【判据】三种遮挡下均进入所选降级策略，退出遮挡后自动恢复。

【审】`audit/godot/xr.md#23`

### Step 3　抓取与释放高频循环，验证不穿模不丢失　`[xr/07#S3]`

【读】`howto/godot/xr-deep.md#2. 抓取：管理所有权、约束和动量`

【做】
循环抓取—甩出—再抓取上千次，并覆盖极端速度（猛甩、零速松手）。
⛔ 只点几次看效果 —— 穿模与丢失只在**高频与极端速度**下暴露，
表现为"偶尔物体不见了 / 卡进墙里"，
⛔ 而单次操作永远正常，无法复现。

【判据】千次循环后物体无丢失、无卡入几何体；极端速度下行为可预期。

【审】`audit/godot/xr-deep.md#24`

### Step 4　传送的四类非法边界，验证全部被拒　`[xr/07#S4]`

【读】`howto/godot/xr.md#4. 传送`

【做】
构造四类：斜面外沿、墙角内侧、天花板下方（头顶不足）、区域边界之外。
⛔ 只测正常地面 —— 四重判定里任何一重漏掉，
都只在这些位置暴露，
⛔ 表现为"偶尔传到墙里"，而绝大多数落点合法。

【判据】四类全部被拒且有可见反馈；⛔ 无一例透传到非法位置。

【审】`audit/godot/xr.md#24`

### Step 5　舒适度必须真人实测，⛔ 开发者主观感受不算　`[xr/07#S5]`

【读】`howto/godot/xr-deep.md#3. 移动与舒适度`

【做】
找**未参与开发的人**连续体验 10 分钟以上并记录不适反馈。
⛔ 自己戴着试两下 —— 开发者因反复暴露产生耐受，
⛔ 主观感受不能当判据：
"我觉得不晕"是最容易被误信、也最容易漏掉真问题的一条。

ⓘ 要覆盖不同的移动与转向设置组合，
⛔ 只测默认组合等于只测了一种人。

【判据】有真人实测记录（人数、时长、设置组合、反馈）。

【审】`audit/godot/xr-deep.md#25`

### Step 6　人为注入卡顿，验证能恢复到正常速度　`[xr/07#S6]`

【读】`howto/godot/xr.md#5. 晕动症（VR 特有，最重要）`

【做】
制造一次长卡顿（加载、切后台、断点调试），检查恢复过程。
⛔ 只测"一直流畅" —— 卡顿在真机上是常态（发热降频、后台通知），
⛔ 表现为"掉一次帧后再也回不到正常速度"或"掉帧后开始晕"，
⛔ 而开发时卡顿会被当成调试器的问题而忽略。

【判据】长卡顿后在 1 秒内回到正常速度，不持续追帧，且不引发明显不适。

【审】`audit/godot/xr.md#25`

## 3. 验收清单

- [ ] 真机最坏场景帧时间在预算内
- [ ] 三种遮挡均触发降级并可恢复
- [ ] 千次抓取释放无穿模无丢失
- [ ] 传送四类非法边界全部被拒
- [ ] 有真人舒适度实测记录
- [ ] 长卡顿后能恢复且不持续追帧

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 开发流畅、出包一戴就晕 | 只在编辑器里测 | S1 |
| 真机一遮挡就乱 | 只在视野内测过 | S2 |
| 偶尔物体不见 / 卡墙里 | 只点几次看效果 | 03/S3、04/S2 |
| 偶尔传到墙里 | 只测正常地面 | 05/S2 |
| 上线后玩家反馈晕 | 只自己试过 | S5 |
| 掉一次帧后回不去 | 只测一直流畅 | S6 |
