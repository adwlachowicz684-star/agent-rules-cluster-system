# 02 追踪有效性与位姿降级（XR 域）

> **本步交付**：位姿可信度判据 + 丢失/不可信双分支 + 降级路径
> **对应**：流程 `howto/godot/xr.md` · 审核 `audit/godot/xr.md`

## 0. 交付物定义

1. `has_tracking_data` 与**置信度**已分开判，⛔ 不是只看一个布尔
2. 置信度读取走 `XRPose`，⛔ 不是读控制器上不存在的属性
3. 追踪丢失有**显式处理**（信号 / 隐藏 / 冻结），⛔ 不是停在最后位姿
4. 位姿不可信的降级路径已实现且三选一已选
5. `center_on_hmd` 的朝向模式已显式指定

## 1. 前置检查清单

- [ ] 判据里同时出现"有无数据"与"数据是否可信"两问
- [ ] 读的是 `pose.tracking_confidence`，不是 `ctrl.tracking_confidence`
- [ ] 追踪丢失时有可见反馈（隐藏 / 提示 / 暂停交互）
- [ ] 降级路径已实现，不是"照常用"
- [ ] `center_on_hmd` 的第二/第三参数都显式写了

## 2. 工序

### Step 1　先承认一个事实：有数据不等于数据可信　`[xr/02#S1]`

【读】`howto/godot/xr.md#⚠ `has_tracking_data` 为真不等于真的被追踪`

【做】
把判据拆成两问：① 还在收新数据吗；② 这份数据能信吗。
⛔ 只看 `has_tracking_data` —— 官方对 `XRPose.has_tracking_data` 为 false 的
说明是"state is whatever that last valid state was"，
即**保留最后有效状态**；而控制器被遮挡、被推断时它仍可能为 true，
⛔ 于是抓取、瞄准、手势全部基于一个**假位姿**继续跑，
且不报任何错。

ⓘ 这是本域最典型的一类失败：**看起来有输入、输入是错的、没有报错**。
⛔ 只测"手柄在视野内"永远不会触发它。

【产出】两问式判据（有无数据 / 是否可信）

【判据】把手柄放在桌上不动，游戏进入"不可信"分支而不是继续正常交互。

【审】`audit/godot/xr.md#13`

### Step 2　置信度在 XRPose 上，枚举只有三档　`[xr/02#S2]`

【读】`howto/godot/xr.md#8. ⛔ 官方口径：相机权威、插值与追踪置信度`

【做】
通过 `ctrl.get_pose()` 拿 `XRPose` 再读 `tracking_confidence`，
对照官方三档处理：`NONE`(0) 无追踪信息、`LOW`(1) 可能不准或是估算、
`HIGH`(2) 准确且最新。
⛔ 写 `ctrl.tracking_confidence` —— 官方 `XRNode3D` 的公开属性只有
`pose` / `show_when_tracked` / `tracker` / `physics_interpolation_mode`，
**没有置信度属性**，这行要么报错要么拿到 null，
⛔ 而排查会被引向"运行时不上报"，不会想到是"属性在别的类上"。

ⓘ 官方对 `LOW` 的举例正是"inside-out 追踪下控制器被部分遮挡"，
所以 `LOW` 不该当 `HIGH` 用。

【产出】三档置信度的处理表

【判据】被部分遮挡时判据落到 `LOW` 分支；完全遮挡时落到 `NONE`。

【审】`audit/godot/xr.md#18`

### Step 3　追踪丢失要有显式处理：默认不会自动隐藏　`[xr/02#S3]`

【读】`howto/godot/xr.md#8. ⛔ 官方口径：相机权威、插值与追踪置信度`

【做】
接 `tracking_changed` / `pose_lost_tracking` 信号，
并显式设置 `show_when_tracked = true`（⛔ 默认是 `false`）。
⛔ 依赖默认行为 —— 官方 `invalidate_pose()` 明确"不清最后状态"，
加上 `show_when_tracked` 默认 false，
结果是**手柄停在最后已知位置、不隐藏、继续参与交互**。

ⓘ "手柄悬在半空一直能抓东西"是这条最典型的现场表现，
⛔ 而日志里每一个位姿都"有值"，看起来完全正常。

【产出】追踪丢失处理函数（隐藏 / 提示 / 冻结三选一）

【判据】手柄移出版图后游戏内有可见反馈，且不再响应抓取与瞄准。

【审】`audit/godot/xr.md#19`

### Step 4　位姿不可信时的降级路径三选一并写死　`[xr/02#S4]`

【读】`howto/godot/xr.md#⚠ `has_tracking_data` 为真不等于真的被追踪`

【做】
从三条里**显式选一条**并写进参数表：
暂停交互 / 保持上一有效位姿 / 提示玩家重新定位。
⛔ "照常用" —— 这是把"位姿永远有效"当成前提，
⛔ 而它是本域唯一一个**在正常游玩中必然会发生**的前提违反
（遮挡、放桌上、出跟踪范围、强光），不是边缘情况。

ⓘ 选哪条取决于玩法：射击类通常"暂停交互"，
探索类通常"保持上一有效位姿 + 提示"。
⛔ 不要三条都实现——三条都走等于没有判据。

【产出】降级策略（一条）+ 触发阈值

【判据】遮挡事件发生时行为符合所选策略，且退出遮挡后能自动恢复。

【审】`audit/godot/xr.md#20`

### Step 5　center_on_hmd 要显式指定朝向模式，默认会重置朝向　`[xr/02#S5]`

【读】`howto/godot/xr.md#1. 最小场景结构`

【做】
调用 `XRServer.center_on_hmd(mode, keep_height)` 时**两个参数都显式写**，
从三种模式里选：`RESET_FULL_ROTATION`(0) 完全重置朝向、
`RESET_BUT_KEEP_TILT`(1) 重置但保留倾斜、`DONT_RESET_ROTATION`(2) 只居中位置。
⛔ 不写第二/第三参数 —— 默认是 `RESET_FULL_ROTATION`，
会在玩家刚转身之后**强制把朝向掰回正前方**，
表现为"重新校准后莫名转向"，⛔ 而代码里只有一行居中调用，看着毫无问题。

ⓘ 另需写下：不支持空间追踪的平台上原点就是头显位置，
⛔ 玩家朝向基本不可控，不要依赖"玩家一定朝某个方向"。

【产出】居中校准调用（含显式模式）+ 平台朝向说明

【判据】在转身后校准，朝向变化符合所选模式；三种模式各有一次实测记录。

【审】`audit/godot/xr.md#21`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：两问式判据 + 显式降级 + 显式居中模式
extends XRController3D

enum Fallback { PAUSE, HOLD_LAST, PROMPT }
# ⛔ FALLBACK 由 00 参数表选定后回填；三种只能选一种
const FALLBACK := Fallback.PAUSE
const RECENTER_MODE := XRServer.RESET_BUT_KEEP_TILT

func _ready() -> void:
    show_when_tracked = true            # ⛔ 默认 false，丢失时不隐藏
    tracking_changed.connect(_on_tracking_changed)

func _on_tracking_changed(tracking: bool) -> void:
    if not tracking:
        _enter_fallback()

func _enter_fallback() -> void:
    match FALLBACK:
        Fallback.PAUSE:      set_process(false)
        Fallback.HOLD_LAST:  pass        # ⓘ 冻结在上一有效位姿
        Fallback.PROMPT:     _show_recenter_hint()

func _is_pose_reliable() -> bool:
    var pose := get_pose()
    if pose == null or not pose.has_tracking_data:
        return false
    return pose.tracking_confidence == XRPose.XR_TRACKING_CONFIDENCE_HIGH

func recenter() -> void:
    XRServer.center_on_hmd(RECENTER_MODE, true)   # ⛔ 模式必须显式给
```

ⓘ 上例只示范判据与降级骨架，
⛔ 抓取与释放的动量传递见 04。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 手柄放桌上照样能抓东西 | 只看 `has_tracking_data`，且默认不隐藏 | S1、S3 |
| 读置信度报错或恒为空 | 置信度在 `XRPose` 不在控制器 | S2 |
| 手柄悬在半空一直可交互 | `show_when_tracked` 默认 false | S3 |
| 遮挡时行为随机 | 没选降级策略，三条都走 | S4 |
| 校准后莫名转向 | `center_on_hmd` 用了默认重置模式 | S5 |
