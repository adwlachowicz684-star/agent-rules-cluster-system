# 07 UI 验收（UI 域）

> **前置**：01–06 中本次选做的功能点**全部**验收通过
> **本步交付**：界面在多分辨率、多输入设备、多语言下都可用，且不泄漏
> **对应**：做法 `howto/godot/ui.md` `ui-advanced.md` · 审核 `audit/godot/ui.md` `ui-advanced.md`

## 0. 交付物定义

⚠ 各功能点自己的验收清单**不能替代本步**。

做完这一步，应该能**当场演示**：

1. ⚠ **多分辨率**：至少三种比例下不错位、不出屏
2. ⚠ **多输入**：全程只用键盘/手柄能走通完整流程
3. ⚠ **多语言**：切换后界面全变，且长文本（如德语）不撑破布局
4. 反复开关界面 100 次，**节点数不增长、内存不单调增长**
5. 长文本/大列表场景下**不掉帧**

**产出物**：
```text
验收记录（含三种分辨率实测截图/数据）
参数登记表已回填（见 00-域流程总览.md 第 4 节）
```

## 2. 工序

### Step 1　多分辨率实测　`[ui/07#S1]`

【读】`howto/godot/ui.md#6. 分辨率自适应`

【做】至少测三种：

| 分辨率 | 比例 | 检查点 |
|---|---|---|
| 1280×720 | 16:9 | 基准 |
| 2560×1440 | 16:9 | 缩放后是否清晰、边距是否过小 |
| 1024×768 | 4:3 | ⚠ 最窄，HUD 最容易出屏 |

⚠ 用 `expand` 时窗口比例不同会**扩展可视区域**——
宽屏看得更多，窄屏看到的更少，所以**窄屏是必测项**。

【产出】三种分辨率的实测记录

【判据】⚠ 4:3 下**没有元素出屏**（这是最容易翻车的一项）

【审】`audit/godot/ui.md`（硬编码像素坐标 → 换分辨率 UI 错位）

### Step 2　多输入设备走通　`[ui/07#S2]`

【读】`flow/godot/ui/05-焦点与导航.md`

【做】全程不碰鼠标，用键盘/手柄完成一次完整流程：

```
主菜单 → 开始 → 游戏 → 暂停 → 设置 → 返回 → 退出
```

⚠ 每个界面打开后**立刻按方向键**都要有反应——
任何一次无反应 = 焦点丢失。

【产出】完整流程记录，每个界面标注"方向键有反应"

【判据】⚠ 全程无任何一次"按了没反应"

【审】`audit/godot/ui-advanced.md#7` `audit/godot/ui-advanced.md#8`

### Step 3　多语言与长文本　`[ui/07#S3]`

【读】`howto/godot/i18n.md`

【做】切到至少两种语言，重点看：

- 文本是否全变（⛔ 没有残留硬编码）
- ⚠ **长语言撑破布局**：德语/俄语通常比中文长 30–50%
- 字体是否缺字（中文 → 英文 → 日文）

⚠ 只在中文下做布局，上线后德文把按钮撑爆是**最常见的本地化事故**。

【产出】多语言下的布局记录

【判据】⚠ 用一句**超长**文本测试，按钮**不被撑破**
　　　（要么换行、要么截断、要么自适应，⛔ 不是溢出）

【审】`audit/godot/ui.md`（硬编码像素坐标）

### Step 4　泄漏与稳定性　`[ui/07#S4]`

【读】`howto/godot/ui.md#4. 背包 / 物品格` 与 `#5. 对话框（打字机效果）`

【做】反复开关每个界面 100 次，记录节点数与内存。

⚠ 三类泄漏源：
- 重建列表只 `remove_child` 不 `queue_free`
- 重复 `connect` 不 `disconnect`
- `await` 后节点已释放但仍被引用

【产出】100 次前后的节点数/内存对比

【判据】⚠ 第 100 次与第 1 次的节点数**相同**，内存**不单调增长**

【审】`audit/godot/ui.md`（重建列表只 remove_child 不 queue_free）

### Step 5　接缝复查　`[ui/07#S5]`

【读】`structure.md#5. 组合模型`

【做】列出本域与其他域的接缝，逐条确认：

| 接缝 | 上游产出 | 下游期望 | 一致? |
|---|---|---|---|
| 游戏数据 → UI | 信号（血量/分数/物品） | UI 订阅并显示 | |
| UI → 游戏 | 按钮 → 调用系统方法 | 系统执行并回信号 | |
| UI → 本地化 | `tr(key)` | i18n 提供译文 | |
| UI → 背包 | `changed` 信号 | 见 `flow/godot/inventory/06-UI绑定.md` | |
| UI → 存档 | 设置项变更 | 存档系统持久化 | |

⚠ **各域合格 ≠ 拼起来能用。**
接缝对不上要单独立适配步骤，⛔ 不要在各处偷偷转格式。

【产出】接缝清单，每行标注"一致"或"已适配"

【判据】⚠ 每行都有明确结论，⛔ 没有"应该没问题"

【审】`audit/godot/ui.md` 全部条目

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 4:3 下 HUD 出屏 | 没测窄屏 | S1 |
| 进某界面手柄失灵 | 该界面没 grab_focus | S2 |
| 德语把按钮撑爆 | 只按中文做布局 | S3 |
| 界面越开越卡 | 只 remove_child / 重复 connect | S4 |
| UI 显示与数据不一致 | 接缝对不上 | S5 |
