# 04 菜单与面板（UI 域）

> **前置**：01 布局已稳定
> **本步交付**：菜单能开能关、默认焦点明确、返回键归属清楚、场景切换带过场
> **对应**：做法 `howto/godot/ui.md` `ui-advanced.md` · 审核 `audit/godot/ui.md` `ui-advanced.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 打开菜单，**第一个按钮已获得焦点**（不用先点一下）
2. ⚠ **手柄玩家全程不碰鼠标**能完成：开始 / 打开设置 / 返回 / 退出
3. 打开子面板 → 焦点转到子面板；关闭 → 焦点**回到来源按钮**
4. 场景切换有过渡，切换期间**输入被锁**（不穿透）
5. 反复开关菜单 100 次，节点数**不增长**

**产出物**（下游按名字对接）：

```text
MainMenu._start_btn.grab_focus()      默认焦点
每个可聚焦控件的 focus_neighbor_*
_open_panel() / _close_panel() 的焦点转移逻辑
```

⚠ 焦点链**决定可玩性**，不是无障碍的额外工作。
⚠ 鼠标能点 ≠ 手柄能选——缺的几乎总是 `grab_focus()` 与 `focus_neighbor_*`。

## 2. 工序

### Step 1　默认焦点 grab_focus　`[ui/04#S1]`

【读】`howto/godot/ui.md#3. 主菜单`

【做】
```gdscript
func _ready() -> void:
    _start_btn.pressed.connect(_on_start)
    ...
    _start_btn.grab_focus()      # ⚠ 键盘/手柄导航的入口
```

⚠ **导出到主机/移动端要处理"没有鼠标"的情况** —— 菜单必须有默认焦点，
否则手柄玩家没法操作。

【产出】打开菜单，第一个按钮已高亮（视觉上能看出）

【判据】⚠ 打开菜单后**直接按方向键**就能移动选择（⛔ 不是先点一下鼠标）

【审】`audit/godot/ui.md#5`（菜单没设默认焦点 → 手柄玩家无法操作）
　　　`audit/godot/ui-advanced.md` 第 7 条（鼠标能点就够了 → 手柄选不中）

### Step 2　focus_neighbor 显式或自动　`[ui/04#S2]`

【读】`howto/godot/ui.md#3. 主菜单` 的「键盘/手柄导航」

【做】设 `focus_neighbor_*`，或让容器自动推断。
按钮的 `focus_mode` 默认 `FOCUS_ALL`，能用 Tab 到。

⚠ 自动推断在**复杂布局**下会跳到奇怪的地方（比如从右下跳到左上）。
✅ 关键路径（主菜单、设置、确认框）**显式写**。

【产出】上下键在按钮间移动的顺序符合视觉顺序

【判据】⚠ 按"下"键，焦点**按视觉顺序**走到下一个按钮（⛔ 不是乱跳）

【审】`audit/godot/ui-advanced.md#7`

### Step 3　面板开关的焦点转移　`[ui/04#S3]`

【读】`howto/godot/ui-advanced.md#4. ⚠ 鼠标能点 ≠ 手柄能选`

【做】
```gdscript
func _on_options() -> void:
    _options_panel.visible = not _options_panel.visible
    if _options_panel.visible:
        _options_panel.get_node("VBox/BackButton").grab_focus()
    else:
        _options_btn.grab_focus()      # ⚠ 关了要还回去
```

⚠ **弹窗关闭后焦点去哪了** —— 焦点丢失是最常见的无障碍缺失。
⛔ 不显式处理的话，关闭面板后**没有任何控件有焦点**，手柄直接失灵。

【产出】开关面板任意次，焦点**始终在某个控件上**

【判据】⚠ 开关面板 20 次后，按方向键**仍能**移动焦点（⛔ 不是无反应）

【审】`audit/godot/ui-advanced.md#8`（弹窗关了焦点自动回来 → 要显式处理）

### Step 4　场景切换带过场，且锁输入　`[ui/04#S4]`

【读】`howto/godot/ui.md#3. 主菜单` 的 `_on_start`

【做】用 SceneManager 带过场切换，⛔ 不是直接 `change_scene_to_file`。

⚠ 切换期间要**锁输入**——否则玩家在过场黑屏时还在按，
可能触发新场景的按钮。

【产出】切换有过渡；过渡期间按键无副作用

【判据】⚠ 过场途中狂按回车，进入新场景后**没有**意外的按钮被触发

【审】`audit/godot/ui.md#22`（await 后不判 is_instance_valid）

### Step 5　反复开关不泄漏　`[ui/04#S5]`

【读】`howto/godot/ui.md#4. 背包 / 物品格` 的 ⚠ 提示

【做】若菜单里有动态列表（设置项、存档槽），重建时 ⚠ **必须 `queue_free()`**，
只 `remove_child()` 不释放 → 节点累积。

【产出】开关菜单 100 次，节点数回到初始值

【判据】⚠ 开关 100 次后 `get_child_count()` 与第 1 次**相同**

【审】`audit/godot/ui.md#2`（重建列表只 remove_child 不 queue_free → 节点累积）

### Step 6　ui_cancel 的归属　`[ui/04#S6]`

【读】`howto/godot/ui-advanced.md#4. ⚠ 鼠标能点 ≠ 手柄能选`

【做】手柄动作 `ui_accept` / `ui_cancel` / `ui_focus_next`。
⚠ **`ui_cancel` 在多层面板时归谁**：最上层面板吃掉，
⛔ 不能每层都响应（按一次退出键直接关到主界面）。

【产出】多层面板下按返回，只关**最上面**一层

【判据】⚠ 主菜单 → 设置 → 音效三层，按返回**一层一层退**（⛔ 不是一次退到底）

【审】`audit/godot/ui-advanced.md#8`

## 3. 参考实现

```gdscript
# main_menu.gd
extends Control

@onready var _start_btn: Button = $VBox/StartButton
@onready var _options_btn: Button = $VBox/OptionsButton
@onready var _quit_btn: Button = $VBox/QuitButton
@onready var _options_panel: Panel = $OptionsPanel

func _ready() -> void:
    _start_btn.pressed.connect(_on_start)
    _options_btn.pressed.connect(_on_options)
    _quit_btn.pressed.connect(_on_quit)
    _options_panel.visible = false
    _start_btn.grab_focus()                 # ⚠ 默认焦点

func _on_options() -> void:
    _options_panel.visible = not _options_panel.visible
    if _options_panel.visible:
        _options_panel.get_node("VBox/BackButton").grab_focus()
    else:
        _options_btn.grab_focus()           # ⚠ 关了要还回去

func _on_start() -> void:
    SceneManager.goto_scene("res://scenes/level1.tscn")

func _unhandled_input(event: InputEvent) -> void:
    if event.is_action_pressed("ui_cancel"):
        if _options_panel.visible:
            _on_options()                   # ⚠ 只关最上层
            get_viewport().set_input_as_handled()
```

⚠ `set_input_as_handled()` 在这里是**关键**——
不加的话 `ui_cancel` 还会被下层处理，可能同时退出游戏。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 进菜单要点一下才能操作 | 没 grab_focus | S1 |
| 手柄方向键乱跳 | 邻居靠自动推断 | S2 |
| 关了面板手柄失灵 | 焦点没还回去 | S3 |
| 过场时按到新场景按钮 | 没锁输入 | S4 |
| 菜单越开越卡 | 只 remove_child | S5 |
| 按一次返回直接退到桌面 | ui_cancel 多层都响应 | S6 |
