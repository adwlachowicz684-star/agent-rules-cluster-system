# 02 数据绑定与刷新（UI 域）

> **前置**：01 的布局已稳定（锚点、CanvasLayer、容器）
> **本步交付**：界面能跟随数据变化自动刷新，且**只在变化时改文本**，不每帧赋值
> **对应**：做法 `howto/godot/ui.md` · 审核 `audit/godot/ui.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 数据变化 → 界面自动刷新（不用手动调刷新）
2. ⚠ **只在值变化时**给 `Label.text` 赋值（不是每帧）
3. 分数滚动有动画，但**动画期间不每帧重排整个文本**
4. 节点被释放时，信号**已断开**（不悬空）
5. ⚠ 用脚本改数据（**不碰 UI**），界面自动跟上

**产出物**（下游按名字对接）：

```text
UI 订阅的信号名（如 Events.score_changed / player_health_changed）
_exit_tree() 里的 disconnect 配对
_changed(new_value) 回调里的"值变了才赋值"守卫
```

⚠ Godot 的 `Label` **没有**类似 Cocos `cacheMode` 的缓存开关——
每次给 `text` 赋值都触发重排。这是本步唯一的硬约束。

- [ ] 01 的布局已稳定

## 2. 工序

### Step 1　订阅信号，退出时断开　`[ui/02#S1]`

【读】`howto/godot/ui.md#2. HUD（血条 + 分数）`

【做】
```gdscript
func _ready() -> void:
    Events.score_changed.connect(_on_score_changed)

func _exit_tree() -> void:
    Events.score_changed.disconnect(_on_score_changed)   # ⚠ 必须配对
```

⚠ **`connect` 与 `disconnect` 必须成对**。只连不断 → 节点已释放还被调用，
或重复 `_ready` 时连上多次导致一次变化触发多次刷新。

【产出】界面反复打开/关闭 50 次，一次变化只刷一次

【判据】⚠ 开关界面 50 次后触发一次数据变化，
　　　回调**只被调用 1 次**（⛔ 不是 50 次）

【审】`audit/godot/ui.md#2`（await 后不判 is_instance_valid）

### Step 2　只在值变化时赋值　`[ui/02#S2]`

【读】`howto/godot/ui.md#2. HUD（血条 + 分数）` 的 ⚠ 提示

【做】
```gdscript
var _shown_score: int = -1

func _on_score_changed(new_score: int) -> void:
    if _shown_score == new_score:
        return                    # ⚠ 守卫
    _shown_score = new_score
    _score_label.text = "分数: %d" % new_score
```

⚠ **不要每帧无条件给 `Label.text` 赋值** —— Godot 的 Label 没有缓存开关，
每次赋值都触发重排。只在值变化时赋值。

【产出】数据不变时，`text` 赋值次数为 0

【判据】⚠ 加计数器统计一分钟内 `text` 被赋值多少次——
　　　数据无变化时应为 **0 次**（⛔ 不是 3600 次）

【审】`audit/godot/ui.md#1` `audit/godot/ui.md#13`（每帧赋值 Label.text → 每次触发重排）

### Step 3　数字滚动用 _process 但带守卫　`[ui/02#S3]`

【读】`howto/godot/ui.md#2. HUD（血条 + 分数）` 的「分数滚动」小节

【做】
```gdscript
func _process(delta: float) -> void:
    if _shown_score == _target_score:
        return                    # ⚠ 到了就不动，避免每帧赋值
    _shown_score = move_toward(_shown_score, _target_score,
                               maxi(1, int(abs(_target_score - _shown_score) * delta * 8)))
    _score_label.text = "分数: %d" % _shown_score
```

⚠ 滚动动画**确实**要每帧更新，但**只在还没滚到位时**更新。
⛔ 无条件每帧赋值 = 静止状态下也在重排。

【产出】分数停止变化后，`text` 赋值停止

【判据】⚠ 分数滚到位后，`text` 赋值次数**不再增长**

【审】`audit/godot/ui.md#19`（每帧赋值 Label.text）

### Step 4　血条用 ProgressBar + 自己的 Label　`[ui/02#S4]`

【读】`howto/godot/ui.md#2. HUD（血条 + 分数）`

【做】
```gdscript
func _on_health_changed(hp: int, max_hp: int) -> void:
    _health_bar.max_value = max_hp
    _health_bar.value = hp
    _hp_text.text = "%d / %d" % [hp, max_hp]
```

⚠ `ProgressBar` 自带的 `percent_visible` 建议关掉，用自己的 `Label` 更可控。

【产出】血量变化 → 条与文字同步

【判据】⚠ 血量 80/100 时显示 "80 / 100"（⛔ 不是 "80%"）

【审】`audit/godot/ui.md#18`（每帧赋值 Label.text）

### Step 5　await 之后判 is_instance_valid　`[ui/02#S5]`

【读】`howto/godot/ui.md#5. 对话框（打字机效果）` 的 ⚠ 提示

【做】任何 `await` 之后访问节点前，先判：
```gdscript
await get_tree().create_timer(0.03).timeout
if not is_instance_valid(self):
    return
```

⚠ 协程挂起期间节点可能已被 `queue_free`（玩家跳过对话、场景切换）。
不判 → 访问已释放节点报错。

【产出】在 await 期间销毁节点，**不报错**

【判据】⚠ 打字机进行中切场景，控制台**无错误**

【审】`audit/godot/ui.md#4`（await 后不判 is_instance_valid → 节点已释放访问报错）

## 3. 参考实现

```gdscript
# hud.gd
extends CanvasLayer

@onready var _health_bar: ProgressBar = $MarginContainer/VBox/HealthBar
@onready var _score_label: Label = $MarginContainer/VBox/ScoreLabel
@onready var _hp_text: Label = $MarginContainer/VBox/HealthBar/HpText

var _shown_score: int = 0
var _target_score: int = 0

func _ready() -> void:
    Events.score_changed.connect(_on_score_changed)
    Events.player_health_changed.connect(_on_health_changed)

func _exit_tree() -> void:
    Events.score_changed.disconnect(_on_score_changed)
    Events.player_health_changed.disconnect(_on_health_changed)

func _on_score_changed(new_score: int) -> void:
    _target_score = new_score          # ⚠ 只设目标，_process 里插值

func _process(delta: float) -> void:
    if _shown_score == _target_score:
        return                          # ⚠ 守卫：滚到位就停
    _shown_score = move_toward(_shown_score, _target_score,
                               maxi(1, int(abs(_target_score - _shown_score) * delta * 8)))
    _score_label.text = "分数: %d" % _shown_score
```

⚠ 注意 `_on_score_changed` 里**不直接赋值 text**——
直接赋值会让滚动动画失效（跳过中间值）。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 一次变化刷好几次 | 重复 connect | S1 |
| 静止时也在掉帧 | 每帧无条件赋值 text | S2 |
| 滚动动画不生效 | 回调里直接赋了最终值 | S3 |
| 切场景后报错 | await 后没判有效性 | S5 |
| 界面不刷新 | 用了轮询而不是信号 | S1 |
