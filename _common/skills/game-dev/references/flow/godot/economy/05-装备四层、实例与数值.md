## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：装备有属性、能穿就行。**

⛔ 常见假完成：一个 `Equipment` 类塞满字段，模板数据直接存进存档——
⚠ 功能全对，
⛔ 但 Godot 的 Resource **按路径缓存共享**，
两次加载可能引用**不同副本**，改一件影响一批。

做完这一步，应该能**当场演示**：

1. ⛔ 存档里**只有** `base_id` + 可变实例字段
2. ⛔ `base_id` 缺失时进**隔离区**，不是静默换成默认武器
3. ⛔ `instance_id` 由**服务端**生成，创建与绑定**同一事务**
4. ⛔ 词条存 `affix_id + roll`，**不存最终数值**
5. ⛔ 装备数值只走**一个计算器**

**产出物**（下游按名字对接）：

```text
EquipmentBase       # 模板：不可变
EquipmentInstance   # 实例：base_id + instance_id + 词条快照 + 养成
AffixSnapshot       # 冻结：affix_id + roll（不是最终数值）
BindingState        # 绑定策略 + 所有者 + 来源
```

## 2. 工序

### Step 1　⛔ 模板不能内嵌进存档，且 duplicate(true) 救不了　`[economy/05#S1]`

【读】`howto/godot/economy.md#4. 装备养成：模板 / 实例 / 词条 / 养成状态四层分离`

【做】存档只写 `base_id` + 可变实例字段，加载时用 Registry 解析。

⛔ 官方：Resource 默认**共享**子资源，
`duplicate(true)` 也*"will only perform a shallow copy. Nested resources
within subresources will not be duplicated and will still be shared"*。
⚠ 于是"复制一份模板再改"**仍会改到模板本身**，
⛔ 表现为**所有同模板装备属性一起变**，
而排查时会去查数据加载或缓存，不会想到复制语义。

【产出】`EquipmentRegistry.get_base(base_id)` + 存档只存 ID

【判据】⛔ 存档文件中**不含**模板属性数值

【审】`audit/godot/economy.md#17`

### Step 2　⛔ 模板 ID 缺失要进隔离区，不能静默用默认武器替换　`[economy/05#S2]`

【读】`howto/godot/economy.md#4. 装备养成：模板 / 实例 / 词条 / 养成状态四层分离`

【做】解析失败 → 移入隔离区 + 告警 + 保留原数据。

⛔ 静默替换 → **玩家的装备被悄悄换成白板**，
⚠ 且原数据一旦被覆盖就**无法追回**（这是资产损失，不是显示问题）。

【产出】隔离区流程

【判据】⛔ 故意删掉一个 `base_id` 后，装备进隔离区**而非**变成默认武器

【审】`audit/godot/economy.md#18`

### Step 3　⛔ instance_id 必须由服务端生成，且创建与绑定同一事务　`[economy/05#S3]`

【读】`howto/godot/economy.md#4. 装备养成：模板 / 实例 / 词条 / 养成状态四层分离`

【做】服务端发号（单调递增或雪花 ID），创建 + 写 `owner_index` 同一事务。

⛔ 客户端 `randi()` → **ID 碰撞**，两件装备抢同一个 ID；
⛔ 分步提交 → 断线重试会**造出两件相同装备**。

【产出】服务端 ID 生成器 + 创建/绑定事务

【判据】⛔ 断线重连后重试，装备**不重复**

【审】`audit/godot/economy.md#19`

### Step 4　⛔ 词条存 affix_id + roll，不能存最终数值　`[economy/05#S4]`

【读】`howto/godot/economy.md#4. 装备养成：模板 / 实例 / 词条 / 养成状态四层分离`

【做】生成即冻结，存 `affix_id + roll + generation_version`。

⛔ 存最终数值 → 策划改了词条上限后，
**历史装备无法重算**，
⚠ 表现为"有的装备超模有的不超模，且说不清为什么"。
⛔ 没有 `generation_version` 就**无法区分**"故意保留的旧超模装备"与"Bug 装备"。

【产出】`AffixSnapshot { affix_id, roll, generation_version }`

【判据】⛔ 修改词条上限后，历史装备按 `generation_version` **可解释**

【审】`audit/godot/economy.md#20`

### Step 5　⛔ 装备数值只能走一个计算器　`[economy/05#S5]`

【读】`howto/godot/economy.md#4. 装备养成：模板 / 实例 / 词条 / 养成状态四层分离`

【做】唯一链路：`基础模板 → 等级缩放 → 品阶缩放 → 词条 → 强化 → 镶嵌 → 外部 buff`。

⛔ 多处计算 → **同一词条受两套规则控制**，
⚠ 表现为"面板显示 12%，实际又乘了品阶和等级"。

【产出】唯一计算链路

【判据】⛔ 全局只有一处能产出装备最终数值

【审】`audit/godot/economy.md#29`

## 5. 常见返工

**① 模板内联存档。** 共享污染。

**② 静默替换。** 玩家装备变白板，不可追回。

**③ 客户端发 ID。** 碰撞与重复。

**④ 存最终数值。** 改表后无法重算。

**⑤ 多处计算。** 面板与实际不符。
