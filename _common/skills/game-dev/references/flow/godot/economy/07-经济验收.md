## 0. 交付物定义

⚠ **本域的 bug 在正常环境下大多测不出来。**

⛔ 经济系统的问题只在**改时间、注入失败、读档、溢出、大量重复**时出现，
而正常游玩流程下表现完全正常——
这是本域最需要"敌意环境"验收的原因。

做完这一步，应该能**当场演示**：

1. ⛔ 改本地时区/系统时间，限购刷新**不变**
2. ⛔ 注入扣费/发货/洗练失败，状态**完整回滚**
3. ⛔ 读档后保底、限购、保底进度**均保持**
4. ⛔ 发到上限不回绕；大额经 C# 侧**不溢出**
5. ⛔ 模拟 10 万次，掉落频率与配置**一致**
6. ⛔ 任务条件**事件驱动**，不是每帧轮询

**产出物**（下游按名字对接）：

```text
验收报告：每条用例 + 实测结果 + 通过/不通过
蒙特卡洛报告：P50/P90/P99 + 最大连败 + 掉落频率
```

## 2. 工序

### Step 1　⛔ 改本地时区与系统时间，限购刷新不变　`[economy/07#S1]`

【读】`howto/godot/economy.md#2. 商店`

【做】改时区、改系统时间到前后各一次，检查限购是否已刷新。

⛔ 受影响 → 周期仍按本地时间判定，
玩家**改时间即可刷新限购**（可直接利用的漏洞）。

【产出】用例结果

【判据】⛔ 两种极端下，限购刷新**只由服务端周期**决定

【审】`audit/godot/economy.md#9`

### Step 2　⛔ 注入扣费/发货/洗练失败，状态完整回滚　`[economy/07#S2]`

【读】`howto/godot/economy.md#洗练 / 重铸：先冻结旧快照，扣费后再切指针`

【做】分别在扣费后、发货前、切指针前注入失败。

⛔ 不回滚 → 出现**钱扣了没发货**、**旧词条也没了**这类资产损失，
⚠ 而正常流程下**完全测不出来**。

【产出】三条失败路径的实测结果

【判据】⛔ 每条失败路径后，货币与装备状态**均回到操作前**

【审】`audit/godot/economy.md#39`

### Step 3　⛔ 读档后保底、限购、保底进度均保持　`[economy/07#S3]`

【读】`howto/godot/economy.md#保底（pity）`

【做】垫若干次 → 存档 → 退出重进 → 继续抽。

⛔ 清零 → 保底不是持久化状态，
表现为"玩家永远抽不到"，而排查会去查概率配表。

【产出】读档前后计数对比

【判据】⛔ 重进后三类计数**与退出前一致**

【审】`audit/godot/economy.md#4`

### Step 4　⛔ 发到上限不回绕，大额经 C# 侧不溢出　`[economy/07#S4]`

【读】`howto/godot/economy.md#整数溢出是静默回绕，不是报错`

【做】发到上限后再发一次；构造超过 21 亿的数额走一轮 C# 侧往返。

⛔ 回绕 → 余额**变负数**（官方：wrap around，不报错）；
⛔ C# `int` → **21 亿溢出**，而 GDScript 侧完全正常，
⚠ **只在跨语言处出错**，最难归因。

【产出】上限用例 + 跨语言用例结果

【判据】⛔ 上限后余额**不变**；大额往返后**数值不变**

【审】`audit/godot/economy.md#35`

### Step 5　⛔ 模拟 10 万次，掉落频率与配置一致　`[economy/07#S5]`

【读】`howto/godot/economy.md#掉落表：互斥权重 ≠ 独立概率`

【做】跑批量模拟，逐物品比对实测频率与配置概率。

⛔ 不一致 → 大概率是**互斥权重与独立概率混用**，
⚠ 表现为"概率和策划算的不一样"，且不报错。
⛔ 改表后**必须重跑**（池内权重改错会让某物品长期消失）。

【产出】模拟报告（逐物品频率）

【判据】⛔ 各物品实测频率与配置**在误差内一致**

【审】`audit/godot/economy.md#31`

### Step 6　⛔ 任务条件是事件驱动，不是每帧轮询　`[economy/07#S6]`

【读】`howto/godot/economy.md#5. 任务/成就与长线`

【做】检查任务/长线条件的触发方式，统计每帧调用。

⛔ 每帧轮询 → 任务越多帧率越低，
⚠ 表现为"任务系统上了之后整体变卡"，
而排查时会去查渲染，不会想到任务。

【产出】每帧调用统计

【判据】⛔ 空闲状态下任务条件检查**每帧调用为 0**

【审】`audit/godot/economy.md#16`

## 4. 常见返工

**① 只测正常流程。** 敌意用例全漏。

**② 改时间没测。** 玩家可篡改限购。

**③ 读档没测。** 保底清零测不出。

**④ 没跑模拟。** 权重/概率混用发现不了。

**⑤ 任务每帧轮询。** 上了任务系统后整体变卡。
