# 01 发行地区与主体地基（合规域）

> **本步交付**：地区清单 + 主体资质 + 三栏分清 + 构建元数据字段表
> **对应**：流程 `howto/godot/compliance.md` · 审核 `audit/godot/compliance.md`

## 0. 交付物定义

1. 发行地区清单已确定，且每一栏适用规则可指认
2. 法定要求 / 商店要求 / 自定策略**三栏已分清**
3. 主体资质与技术侧送审材料已列出
4. 构建元数据字段表落地，且发布门禁会检查
5. ⛔ 所有法律阈值标注为"待法务复核"，未编造取值

## 1. 前置检查清单

- [ ] 已列出目标发行地区（国家/地区清单）
- [ ] 已分清三栏：法定要求 / 商店要求 / 自定策略
- [ ] 主体资质与技术侧送审材料已列清单
- [ ] ⚠ 构建元数据字段表已落地（不是口头约定）
- [ ] ⛔ 所有法律阈值标为待法务复核，**无编造取值**

## 2. 工序

### Step 1　先定发行地区，再谈任何合规实现　`[compliance/01#S1]`

【读】`howto/godot/compliance.md#0. 先分清三栏，否则会做无用功`

【做】
先输出地区清单，再逐栏判定适用哪套规则。
⛔ 地区没定就做防沉迷或隐私——不同地区规则不同，
先建的那套在另一地区可能是错的，而改造成本远高于一开始就分清。

【产出】发行地区清单 + 每地区适用规则对照

【判据】指着任一地区，能说出它适用哪些法定要求与商店要求。

【审】`audit/godot/compliance.md#25`

### Step 2　⛔ 版号是前置许可，不是商店审核　`[compliance/01#S2]`

【读】`howto/godot/compliance.md#1. 中国大陆：版号是前置许可，不是商店审核`

【做】
把版号当作**上线前置许可**排期，不是"提交后等商店审"。
⛔ 当成商店审核——会按商店审核的周期排期（几天到两周），
而前置许可的周期完全不在一个量级，⛔ 排期整体失效。

【产出】版号在排期中的位置（前置，非并行）

【判据】排期表里版号在商业化功能之前完成，不是与其并行。

【审】`audit/godot/compliance.md#26`

### Step 3　⛔ 无版号上线的后果不是理论风险　`[compliance/01#S3]`

【读】`howto/godot/compliance.md#无版号上线的后果（不是理论风险）`

【做】
把后果写成可执行的停损判据（下架、罚款、主体受限），
⛔ 而不是"以后补办"。
⛔ 只当理论风险——后果发生在已投入推广之后，
此时停损成本远高于延后上线。

【产出】后果清单与停损判据

【判据】出现该情形时有明确的停线动作，不是"继续跑等补办"。

【审】`audit/godot/compliance.md#27`

### Step 4　送审材料里的技术侧条目要提前准备　`[compliance/01#S4]`

【读】`howto/godot/compliance.md#送审材料里有技术侧要交的东西`

【做】
把技术侧要交的材料列成清单，与研发排期对齐。
⛔ 当成"法务的事"——部分材料需要技术产出
（如屏蔽词库版本、防沉迷版本、适龄评估截图），
⛔ 送审前才发现缺项会直接卡住，且无法临时补齐。

【产出】技术侧送审材料清单（含负责人与产出时机）

【判据】清单里每一项都能指认到具体产物，不是"到时候再要"。

【审】`audit/godot/compliance.md#28`

### Step 5　⚠ 法律阈值一律待法务复核，不得编造　`[compliance/01#S5]`

【读】`howto/godot/compliance.md#9. 待核对项（运行时验证）`

【做】
所有法律阈值在参数表里标为**待实测**，并注明由法务复核原文。
⛔ 凭行业惯例或旧文档填一个数字——法律文本会修订，
⛔ 填进去的数字会被下游当成事实使用，且**没人会再去复核它**。
ⓘ 这与"留空"的差别：留空会被门禁拦截，填错不会。

【产出】参数表中法律阈值全部标记为待法务复核

【判据】参数表里没有一项法律阈值是凭惯例填的。

【审】`audit/godot/compliance.md#29`

## 3. 参考实现

```gdscript
# ⓘ 构建元数据：发布门禁要检查的字段（缺一项就不该发）
# ⛔ 法律阈值一律为空 + 待法务复核，不得填行业惯例值
const META_FIELDS := [
    "publish_contract_no", "approval_no", "publication_no", "operator",
    "version_sha", "script_version", "wordlib_version", "antidiction_version",
    "privacy_policy_version", "sdk_sheet_version", "datamap_version",
    "age_rating_result", "crossborder_path", "ugc_sample",
]

func check_release_gate(meta: Dictionary) -> PackedStringArray:
    var missing: PackedStringArray = []
    for k in META_FIELDS:
        if not meta.has(k) or str(meta[k]).is_empty():
            missing.append(k)
    return missing   # ⛔ 非空即不该发布
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 换地区后规则整套要改 | 地区没定就先做 | S1 |
| 排期失效 | 版号当商店审核排期 | S2 |
| 送审前发现缺技术材料 | 当成法务的事 | S4 |
| 线上用了过时的法条数字 | 凭惯例填，无人复核 | S5 |
