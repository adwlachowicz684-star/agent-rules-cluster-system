# 02 数据收集清单与声明一致（合规域）

> **本步交付**：数据地图 + 最小必要判定 + 声明与实际一致校验
> **对应**：流程 `howto/godot/compliance.md` · 审核 `audit/godot/compliance.md`

## 0. 交付物定义

1. 数据地图已落地：收集什么、谁收的、存在哪、保留多久可逐项指认
2. 每个采集项都有对应用途（最小必要）
3. 商店声明与实际数据流一致，且有 CI 校验
4. ⛔ 追踪域只包含真正用于追踪的域
5. 同意前零采集，且同意状态可回溯

## 1. 前置检查清单

- [ ] 数据地图已覆盖自身代码与所有第三方 SDK
- [ ] 每个采集项都能说出用途
- [ ] 商店问卷字段与实际数据流已逐项核对
- [ ] ⛔ iOS 追踪域列表已复核，未误填基础功能域名
- [ ] 同意开关已做，且同意前不采集

## 2. 工序

### Step 1　数据地图先行，说不清收集了什么就是风险　`[compliance/02#S1]`

【读】`howto/godot/compliance.md#7. 商店：隐私声明是可验证事实，不是营销文案`

【做】
先产出数据地图：收集项、收集方（自身/SDK）、存储位置、保留期限、用途。
⛔ 跳过数据地图直接填问卷——问卷只能凭印象填，
⛔ 而新增 SDK 带来新数据流时没人知道要更新，声明必然对不上。

【产出】数据地图（覆盖自身与所有 SDK）

【判据】指着任一采集项，能说出收集方、存储位置、保留期限与用途。

【审】`audit/godot/compliance.md#30`

### Step 2　每个采集项都要有对应用途　`[compliance/02#S2]`

【读】`howto/godot/compliance.md#3. 适龄提示：不是法律意义上的分级`

【做】
按最小必要原则逐项判定：没有对应用途的采集项直接删掉。
⛔ "先采着，以后可能用"——采集已发生即产生合规义务，
⛔ 而且没人会回来清理，数据地图会持续膨胀。

【产出】采集项→用途对照表，无用途项已删除

【判据】不存在"暂时没用途但先留着"的采集项。

【审】`audit/godot/compliance.md#31`

### Step 3　⛔ 新增 SDK 未更新隐私清单，CI 必须阻止合入　`[compliance/02#S3]`

【读】`howto/godot/compliance.md#5. UGC 与 SDK：合规能力要进服务端治理`

【做】
在 CI 里加校验：新增/升级 SDK 而未更新隐私清单与数据地图的版本，阻止合入。
⛔ 靠人工Remember——新增 SDK 分散在各人各分支，
⛔ 一次漏更新就要到商店审核阶段才发现，此时数据流已上线运行。

【产出】CI 校验规则（SDK 清单变更必须同步隐私清单）

【判据】故意新增一个 SDK 而不更新清单，CI 拦截成功。

【审】`audit/godot/compliance.md#32`

### Step 4　⛔ 追踪域未授权时请求会失败，不要误填基础域名　`[compliance/02#S4]`

【读】`howto/godot/compliance.md#⛔ 追踪域未授权时，网络请求会失败`

【做】
复核 `NSPrivacyTrackingDomains`，**只填真正用于追踪的域**。
官方原文：未通过 ATT 授予追踪许可时，对这些域的网络请求会失败且 App 收到错误。
⛔ 把崩溃上报、远程配置、登录鉴权的域也填进去以求"合规"——
未授权用户对这些域的请求**全部失败**，
表现为部分第三方功能在部分用户上静默失效，
⛔ 而排查必然被引向 SDK 集成或网络库，不会想到是隐私清单填的域名。

【产出】追踪域列表（已逐项说明为何属于追踪用途）

【判据】列表里每个域都能说出追踪用途；基础功能域不在其中。

【审】`audit/godot/compliance.md#33`

### Step 5　同意前零采集，且同意状态可回溯　`[compliance/02#S5]`

【读】`howto/godot/compliance.md#4. 隐私与删除权：注销 ≠ 立即全量物理抹除`

【做】
同意开关作为采集的前置条件，同意状态持久化且可回溯。
⛔ 先采集后补同意开关——同意前的采集已经发生，
⛔ 且无法追溯哪些数据是违规采的，补救只能全量清除（含合法数据）。

【产出】同意状态存储 + 采集前置检查

【判据】未同意状态下抓包，无任何数据上报。

【审】`audit/godot/compliance.md#34`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：同意状态是采集的前置门禁
const CONSENT_KEY := "privacy/consent_version"

func can_collect() -> bool:
    # ⛔ 同意前不得采集任何数据；读不到就视为未同意
    return int(ProjectSettings.get_setting(CONSENT_KEY, 0)) > 0

func track(event_name: String, params: Dictionary) -> void:
    if not can_collect():
        return   # ⛔ 静默丢弃，不是"先存着以后补发"
    _emit(event_name, params)
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 商店问卷与实际对不上 | 没做数据地图先填问卷 | S1 |
| 数据地图越滚越大 | 保留无用途采集项 | S2 |
| 审核阶段才发现 SDK 漏报 | 靠人工记住更新清单 | S3 |
| 部分用户第三方功能失效 | 基础域名误填进追踪域 | S4 |
| 同意前已采集、无法追溯 | 开关后补 | S5 |
