# 07 交易验收（trade 域）

> **前置**：01–06 全部

> **对应**：做法 `howto/godot/player-trading.md#9. 日志：交易日志是客服和回滚的唯一真相源`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：正常流程下单、成交、到账全通过。**

⛔ 常见假完成：只在"双方都在线、网络良好、没人作恶"时测一遍 ——
⚠ 全部通过，
⛔ 但**双卖、重复结算、盗号转移、跨服复制**全部只在敌意环境下出现，
而它们的共同特征是：**不报错**。

做完这一步，应该能**当场演示**：

1. ⛔ 同一笔写操作**重放**两次，只结算一次
2. ⛔ 断线重连后，客户端显示与服务端**完全一致**
3. ⛔ 日志能回答"客户端请求的是 500 还是 5000"
4. ⛔ 跨服搬运**不会复制资产**
5. ⚠ 经济日志里**没有**完整 IP / 凭据 / 聊天原文

## 2. 工序

### Step 1　⛔ 重放同一幂等键，只结算一次　`[trade/07#S1]`

【读】`howto/godot/player-trading.md#10. Godot 实现：只发请求和显示服务端状态`

【做】用同一个 `idempotency_key` 连续发 100 次购买请求，服务端只结算一次。

⛔ `reliable` 只保证到达与顺序，**不保证幂等**；
⛔ 缺版本 + 请求 ID + 结算令牌 → **一次出价应用两次**，
表现为重复扣款，⛔ 而每笔单看都是一次合法成交。

【判据】⛔ 100 次重放后余额只变一次，且失败方收到幂等错误码

【审】`audit/godot/player-trading.md#47`

### Step 2　⛔ 断线重连后要用服务端状态整体替换本地缓存　`[trade/07#S2]`

【读】`howto/godot/player-trading.md#10. Godot 实现：只发请求和显示服务端状态`

【做】重连时客户端丢弃本地交易缓存，以服务端推送的状态为准。

⛔ 保留本地缓存 → 显示与服务端不一致，
表现为"背包里看着有货，点使用说没有"，⛔ 而服务端数据自始至终是对的。

【判据】⛔ 重连后客户端显示的余额 / 挂单数与服务端**逐项相等**

【审】`audit/godot/player-trading.md#64`

### Step 3　⛔ 日志要写"请求前快照 + 意图 + 结果"，不只写结果　`[trade/07#S3]`

【读】`howto/godot/player-trading.md#9. 日志：交易日志是客服和回滚的唯一真相源`

【做】每次状态迁移写**两个事件**：`DECISION`（校验结果、价格、策略版本）+ `EFFECT`（新余额与库存版本）。

⛔ 只写结果 → 客服无法判断"客户端请求的是 500 还是 5000""当时物品是否已锁定"，
⛔ 表现为误扣误发变成**无法定责的黑箱**。
⛔ 只记"玩家 A 交易 1000 金给玩家 B"**不够**。

【判据】⛔ 任取一笔争议交易，日志能还原请求值、当时价格与库存版本

【审】`audit/godot/player-trading.md#42`

### Step 4　⛔ 只保存最后余额 = 无法定责　`[trade/07#S4]`

【读】`howto/godot/player-trading.md#9. 日志：交易日志是客服和回滚的唯一真相源`

【做】保留**前后余额与实例快照**，而不是覆盖式保存当前值。

⛔ 只存最后余额 → 误扣和误发**无法定责**，
表现为"玩家说少了 1000，我们只能认赔"。
⚠ 保留期分三层：原始不可变账本长期保存 · 个人历史可配月数 · 风控聚合特征到期删除或脱敏。
⛔ ⛔ 不能一刀切（要么合规超限，要么丢真相）。

【判据】⛔ 任取一天，能逐笔回放当天全部交易的前后余额

【审】`audit/godot/player-trading.md#63`

### Step 5　⛔ 经济日志里不能出现完整 IP / 凭据 / 聊天原文　`[trade/07#S5]`

【读】`howto/godot/player-trading.md#9. 日志：交易日志是客服和回滚的唯一真相源`

【做】只写**哈希 ID 与设备 / IP 摘要**。

⛔ 混入完整凭据、聊天原文或精确定位 → 经济日志变成敏感数据源，
⛔ 而这类问题**不会被功能测试发现**，只在合规审查或泄露时暴露。

【判据】⛔ 全量扫描日志表，无完整 IP、无 token、无聊天原文

【审】`audit/godot/player-trading.md#44`

### Step 6　⛔ 跨服搬运不能复制资产　`[trade/07#S6]`

【读】`howto/godot/player-trading.md#11. 待核对项（运行时验证）`

【做】跨服走全局 ID + 独立账本 + 结算队列，⛔ 不當普通背包转移。

⛔ 当普通背包转移 → 时钟、账本、封禁状态、资产上限不一致会**复制资产**，
⛔ 表现为同一件装备在两个服同时存在，⛔ 而两个服的日志各自都自洽。

【判据】⛔ 跨服搬运 100 次后，两服合计数量**守恒**

【审】`audit/godot/player-trading.md#54`

## 4. 常见返工

**① 只测正常流程。** 双卖与重复结算全漏。

**② 把 reliable 当幂等。** 一次出价应用两次。

**③ 重连保留本地缓存。** 显示与实际不一致。

**④ 日志只写结果。** 误扣无法定责。

**⑤ 日志存完整 IP。** 合规风险。

**⑥ 跨服当普通转移。** 资产被复制。
