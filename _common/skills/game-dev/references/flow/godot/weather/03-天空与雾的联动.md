# 03 天空与雾的联动（weather 域）

> **前置**：`02-昼夜驱动与光照联动.md`
> **本步交付**：**天空材质已选型，且天空/雾/曝光/GI 作为一套状态联动**
> **对应**：做法 `howto/godot/environment-systems.md#1. 天空：三种材质，取舍明确`
> 　　　审核 `audit/godot/environment-systems.md#18`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：换张天空贴图就行。**

⛔ 常见假完成：只换天空材质——
⚠ 天空确实换了，
⛔ 但雾、环境光、曝光、GI 都还在 `Environment` 上没动，
表现为"换了夜空但地面还是白天那么亮"。

做完这一步，应该能**当场演示**：

1. 天空材质按目标渲染器选定（不是"Physical 更高级所以用它"）
2. ⛔ 换天空时雾/环境光/曝光**同步**
3. ⚠ 体积雾用对层级（froxel 全局 vs FogVolume 局部）
4. ⚠ 水下切换雾/后处理
5. ⛔ 目标平台的能力矩阵已查（Compatibility 无体积雾）

**产出物**（下游按名字对接）：

```text
天空材质选型 + 联动更新函数
体积雾层级方案
```

## 1. 前置检查清单

- [ ] 已知目标渲染器（Forward+/Mobile/Compatibility）
- [ ] ⚠ 已知天空是环境光主要来源
- [ ] 是否需要水下
- [ ] 是否需要多个太阳

## 2. 工序

### Step 1　⚠ 天空材质按取舍选，不按"更高级"选　`[weather/03#S1]`

【读】`howto/godot/environment-systems.md#1. 天空：三种材质，取舍明确`

【做】按是否要多个太阳、是否要夜间、成本定材质。

⛔ 一律用 `PhysicalSkyMaterial` → 更贵、**只支持一个太阳**、**夜间会变黑**。

【产出】材质选型与理由

【判据】⚠ 夜间不纯黑，且成本在预算内

【审】`audit/godot/environment-systems.md#6`

### Step 2　⛔ 换天空必须同步雾/环境光/曝光/GI　`[weather/03#S2]`

【读】`howto/godot/environment-systems.md#1. 天空：三种材质，取舍明确`

【做】把联动写进 02 的 `set_time_of_day()`。

⛔ 只换天空材质 → 地面亮度不变，
⚠ 表现为"夜空配白天地面"。

【产出】联动更新函数

【判据】⚠ 换天空后整体亮度**同步变化**

【审】`audit/godot/environment-systems.md#5`

### Step 3　⚠ 体积雾分层：froxel 全局，FogVolume 只增减密度　`[weather/03#S3]`

【读】`howto/godot/environment-systems.md#5. 体积雾：froxel 全局效果，FogVolume 只增减密度`

【做】全局雾用 froxel，局部用 FogVolume。

⛔ 想用 FogVolume 当全局雾、做"只有某区域有雾" → **做不到**，
它只能在已有全局雾上增减密度。

【产出】雾层级方案

【判据】⚠ 局部雾在全局雾基础上正确增减

【审】`audit/godot/environment-systems.md#34`

### Step 4　⚠ 水下要切换雾与后处理　`[weather/03#S4]`

【读】`howto/godot/environment-systems.md#5. 体积雾：froxel 全局效果，FogVolume 只增减密度`

【做】入水时切一套雾/后处理，出水还原。

⛔ 水下沿用陆上雾 → 水下**看不清**且颜色不对，
表现为"潜下去一片灰"。

【产出】水下环境切换

【判据】⚠ 入出水视觉**明显不同**且还原正确

【审】`audit/godot/environment-systems.md#13`

### Step 5　⛔ 选型前先查渲染器能力矩阵　`[weather/03#S5]`

【读】`howto/godot/environment-systems.md#4. 渲染器能力矩阵（选型前先查这个）`

【做】确认体积雾/GPU 粒子碰撞在目标渲染器可用。

⛔ 选型前不查渲染器能力矩阵，围绕 Compatibility **没有**的能力做核心设计 →
Web/旧 OpenGL 设备上功能直接消失，
⚠ 且不报错，只是"效果没了"。

【产出】能力矩阵核对结论

【判据】⚠ 目标平台上全部用到的能力**均可用**

【审】`audit/godot/environment-systems.md#35`

**③ FogVolume 当全局用。** 做不到。

**④ 没查能力矩阵。** 目标平台效果消失。
