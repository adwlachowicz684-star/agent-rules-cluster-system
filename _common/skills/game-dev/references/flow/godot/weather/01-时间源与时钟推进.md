# 01 时间源与时钟推进（weather 域）

> **前置**：无（本域地基）
> **本步交付**：**一个单调、可暂停、可存档恢复的游戏内时钟**
> **对应**：做法 `howto/godot/environment-systems.md#8. 时间源：昼夜时钟不能用系统时钟`
> 　　　审核 `audit/godot/environment-systems.md#16`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：太阳会转就行。**

⛔ 常见假完成：直接用 `Time.get_datetime_dict_from_system()` 取小时——
⚠ 昼夜确实会变，
⛔ 但玩家改系统时间就能跳到任意时刻，且存档无从恢复。

做完这一步，应该能**当场演示**：

1. 游戏内时间由累计 delta 推进，不读系统时钟
2. ⛔ 打开菜单时时钟**冻结**
3. ⚠ 存档后退出重进，时间**接着走**
4. ⛔ 改系统时间到一年后，游戏内时间**不受影响**
5. ⚠ 有唯一权威（联机时）

**产出物**（下游按名字对接）：

```text
GameClock: _game_seconds (float), paused (bool), TIME_SCALE
存档字段：game_seconds
```

## 2. 工序

### Step 1　⛔ 时钟源必须是单调 ticks，不能是系统时钟　`[weather/01#S1]`

【读】`howto/godot/environment-systems.md#8. 时间源：昼夜时钟不能用系统时钟`

【做】用累计 delta 推进 `_game_seconds`。

⛔ 用 `get_datetime_dict_from_system()` → 玩家改系统时间即跳时刻，
⚠ 且 `_from_system` 用**用户可手动设置**的时钟，
官方明确要求精确计时改用单调的 `get_ticks_msec()`。

【产出】`GameClock._game_seconds`

【判据】⛔ 改系统时间后游戏内时刻**不变**

【审】`audit/godot/environment-systems.md#16`

### Step 2　⛔ 暂停必须冻结时钟　`[weather/01#S2]`

【读】`howto/godot/environment-systems.md#8. 时间源：昼夜时钟不能用系统时钟`

【做】暂停时不累加 delta。

⛔ 不冻结 → **菜单里天黑了**，
⚠ 且暂停期间的流逝量在恢复后一次性补上 → 天色跳变。

【产出】`paused` 开关

【判据】⚠ 菜单里挂机 5 分钟，出来后时刻**没变**

【审】`audit/godot/environment-systems.md#28`

### Step 3　⛔ 存档存累计秒数，不存太阳角度　`[weather/01#S3]`

【读】`howto/godot/environment-systems.md#8. 时间源：昼夜时钟不能用系统时钟`

【做】只序列化 `_game_seconds`。

⛔ 存角度 → 角度是**派生值**，
改了 `TIME_SCALE` 后与真实进度脱节，
表现为"读档后天色和上次不一样"。

【产出】存档字段 `game_seconds`

【判据】⚠ 存档重进后时刻**连续**

【审】`audit/godot/environment-systems.md#29`

### Step 4　⚠ 时间缩放只改推进速度，不动其他计时器　`[weather/01#S4]`

【读】`howto/godot/environment-systems.md#8. 时间源：昼夜时钟不能用系统时钟`

【做】`TIME_SCALE` 只乘在昼夜推进上。

⛔ 同时乘到任务倒计时 → 昼夜和任务**脱节**，
表现为"过了一天但任务只过了几秒"。

【产出】缩放作用域界定

【判据】⚠ 改 `TIME_SCALE` 后任务计时**不受影响**

【审】`audit/godot/environment-systems.md#16`

### Step 5　⛔ 多人时必须只有一个权威时钟　`[weather/01#S5]`

【读】`howto/godot/environment-systems.md#12. 多人同步：时间必须只有一个权威`

【做】服务器持有唯一 `_game_seconds`，客户端只收绝对值。

⛔ 各客户端各自推进 → 几帧后**完全不同步**，
表现为"我这白天他那边天黑"。

【产出】权威判定（谁持有 `_game_seconds`）

【判据】⚠ 两个客户端同一时刻天色**一致**

【审】`audit/godot/environment-systems.md#26`

## 5. 常见返工

**① 用系统时钟。** 改时间即跳时刻。

**② 暂停不冻结。** 菜单里天黑。

**③ 存角度。** 改缩放后脱节。

**④ 各端各推。** 联机天色不一致。
