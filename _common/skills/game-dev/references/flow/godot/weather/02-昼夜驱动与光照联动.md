# 02 昼夜驱动与光照联动（weather 域）

> **前置**：`01-时间源与时钟推进.md`
> **本步交付**：**一个太阳角驱动天空/环境光/曝光/雾，且烘焙 GI 方案已定**
> **对应**：做法 `howto/godot/environment-systems.md#6. 昼夜：一个太阳角驱动一切`
> 　　　审核 `audit/godot/environment-systems.md#17`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：天会亮会暗就行。**

⛔ 常见假完成：分别插值天空色、环境色、灯光色、雾色——
⚠ 每个都"能变"，
⛔ 但太阳方向和天空里太阳的位置**对不上**，
表现为"明明是傍晚，天上太阳还在头顶"。

做完这一步，应该能**当场演示**：

1. 单一 `set_time_of_day(hour)` 驱动全部要素
2. ⛔ 太阳绕**正确轴向**旋转（不是欧拉角直映）
3. ⚠ 固定更新节拍 + 缓存，不每帧重算
4. ⛔ 烘焙 GI 方案与昼夜循环**不冲突**
5. ⚠ 夜间月亮不照亮场景
6. ⛔ 大世界阴影级联 `max_distance` 已收

**产出物**（下游按名字对接）：

```text
set_time_of_day(hour) -> void   # 单一入口
sun.rotation 绕正确轴向
更新节拍（固定）+ 缓存
```

## 2. 工序

### Step 1　⛔ 单一入口驱动全部，禁止分别插值　`[weather/02#S1]`

【读】`howto/godot/environment-systems.md#6. 昼夜：一个太阳角驱动一切`

【做】写 `set_time_of_day(hour)`，内部同步天空/曝光/雾。

⛔ 各要素分别插值 → 太阳方向与天空太阳位置不一致。

【产出】`set_time_of_day()`

【判据】⚠ 任意时刻天上太阳位置与光照方向**一致**

【审】`audit/godot/environment-systems.md#30`

### Step 2　⛔ 太阳绕正确轴向，不是欧拉角直映　`[weather/02#S2]`

【读】`howto/godot/environment-systems.md#6. 昼夜：一个太阳角驱动一切`

【做】按 `(hour/24)*TAU - PI/2` 算角，绕单一轴。

⛔ 欧拉角直接映射 → **绕错轴**，太阳走**奇怪的弧线**，
⚠ 表现为"夜里太阳从地面升起"。

【产出】太阳旋转计算

【判据】⚠ 全天太阳东升西落，夜间在地平线下

【审】`audit/godot/environment-systems.md#31`

### Step 3　⛔ 昼夜循环与烘焙 GI 的冲突必须先解　`[weather/02#S3]`

【读】`howto/godot/environment-systems.md#2. ⚠ 昼夜循环与烘焙 GI 是矛盾的`

【做】大世界选 SDFGI 或 Dynamic LightmapGI + 实时方向光。

⛔ 用 Static 烘焙后再逐帧移动方向光 →
Static **完全锁定**，表现为"天变了但阴影不动"。

【产出】GI 方案

【判据】⚠ 太阳移动时间接光/阴影**同步变化**

【审】`audit/godot/environment-systems.md#8`

### Step 4　⚠ 固定更新节拍 + 缓存，不每帧重算　`[weather/02#S4]`

【读】`howto/godot/environment-systems.md#6. 昼夜：一个太阳角驱动一切`

【做】按固定间隔更新环境光，帧间插值。

⛔ 每帧重算 → 环境光开销居高不下，
⚠ 表现为"开了昼夜后帧率掉一大截"。

【产出】节拍与缓存

【判据】⚠ 开关昼夜对帧率影响**在预算内**

【审】`audit/godot/environment-systems.md#9`

### Step 5　⚠ 夜间月亮只进天空，不照亮场景　`[weather/02#S5]`

【读】`howto/godot/environment-systems.md#6. 昼夜：一个太阳角驱动一切`

【做】月亮 `sky_mode = SKY_ONLY`。

⛔ 把月亮当普通平行光 → 夜间场景**被照亮**，
表现为"晚上和白天一样亮，只是颜色蓝一点"。

【产出】月亮光源配置

【判据】⚠ 夜间场景明显变暗，但天上能看到月亮

【审】`audit/godot/environment-systems.md#32`

### Step 6　⛔ 大世界阴影级联要收 max_distance　`[weather/02#S6]`

【读】`howto/godot/environment-systems.md#6. 昼夜：一个太阳角驱动一切`

【做】设 `directional_shadow_max_distance` 与 `fade_start`。

⛔ 4 分片铺满超大世界 → 远处**分辨率与性能同时变差**，
表现为"远处阴影全是锯齿且掉帧"。

【产出】阴影级联参数

【判据】⚠ 远处阴影可接受且帧率稳定

【审】`audit/godot/environment-systems.md#33`
