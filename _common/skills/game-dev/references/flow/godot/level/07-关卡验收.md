# 07 关卡验收（关卡流程域）

> **前置**：01–06 中本次选做的部分已完成
> **本步交付**：一份可签核的验收报告 + 接缝复查清单
> **对应**：做法 `howto/godot/level-design.md` · 审核 `audit/godot/level-design.md`

## 0. 交付物定义

⚠ **验收不是"能跑就行"。** 本步产出：

```text
验收报告（逐条打勾，含实测数据）
接缝复查清单（本域与其他域的交接点）
```

⛔ 各功能点自己的验收**不能替代**域级验收——
部件全合格、拼起来不能用，是跨域开发的典型失败。

## 1. 前置检查清单

- [ ] 本次选做的功能点都已过各自的验收清单
- [ ] ⛔ 已确认有**没参与关卡设计的人**可以试玩
- [ ] 已准备至少两种分辨率/比例

## 2. 工序

### Step 1　白盒阶段就要能跑通　`[level/07#S1]`

【读】`howto/godot/level-design.md#1. 白盒（blockout）的完整流程`

【做】白盒 = 能跑通 + 正确碰撞 + 临时光照 + **已配置的玩法逻辑**。

⛔ 白盒不是"摆几个箱子"，也不是"白盒加点细节"。

【产出】可运行的白盒关卡

【判据】没看过设计文档的人能从起点走到终点

【审】`audit/godot/level-design.md#3` `audit/godot/level-design.md#4` `audit/godot/level-design.md#21`

### Step 2　无死路 + 引导靠环境　`[level/07#S2]`

【读】`howto/godot/level-design.md#0. 关卡 = 空间`

【做】遍历所有可达区域，确认**都能回到上一个检查点**。

⚠ 引导优先用光照/色彩/形状/声音，箭头是最后手段。

【产出】可达性走查记录

【判据】任何可达点都能回到上一检查点；不需要箭头也能找到路

【审】`audit/godot/level-design.md#7` `audit/godot/level-design.md#8`

### Step 3　让没参与设计的人试玩　`[level/07#S3]`

【读】`howto/godot/level-design.md#2. 关卡验收清单`

【做】设计者知道答案，自己试玩不算验收。

⚠ 要能区分"卡住"和"有挑战"——分不清就是设计失败。

【产出】至少 1 名外部试玩者的记录

【判据】外部玩家能在不询问的情况下完成关卡

【审】`audit/godot/level-design.md#5` `audit/godot/level-design.md#6`

### Step 4　帧率与多分辨率实测　`[level/07#S4]`

【读】`howto/godot/level-design.md#2. 关卡验收清单`

【做】在**最低目标配置**上测帧率，在至少两种比例下看 UI 与黑边。

⚠ 白盒阶段就要测帧率，⛔ 别等美术做完。

【产出】帧率数据 + 分辨率截图

【判据】最低配达标；换比例不错位

【审】`audit/godot/level-design.md#10`

### Step 5　加载与切换的稳定性　`[level/07#S5]`

【读】`howto/godot/systems.md#reload_current_scene 与 Autoload 的重载边界`

【做】连续进出关卡 20 次、连续重开 10 局，观察内存与空引用。

【产出】稳定性实测记录

【判据】内存曲线平稳；无空引用报错

【审】`audit/godot/systems.md#10` `audit/godot/systems.md#8`

### Step 6　接缝复查　`[level/07#S6]`

【读】`howto/godot/level-design.md#7. 关卡生命周期`

【做】列出本域与其他域的接缝，逐条确认：

| 接缝 | 上游产出 | 下游期望 | 一致? |
|---|---|---|---|
| 关卡 → 存档 | `LevelProgress` | 回读后进度一致 | |
| 关卡 → 检查点 | 关卡内场景态 | 重生后恢复 | |
| 关卡 → 叙事 | 通关事件 | flag 置位 | |
| 关卡 → 音频 | 进入/通关 | BGM 切换 | |
| 关卡 → UI | `phase` 变化 | HUD 响应 | |

【产出】接缝复查表（逐条打勾）

【判据】每条都有"谁产出、谁消费、字段名是什么"

【审】`audit/godot/level-design.md#25` `audit/godot/level-design.md#22`

## 3. 验收清单（域级总验）

⚠ 各功能点自己的验收**不能替代**本表——部件全合格、拼起来不能用，
是跨域开发的典型失败。

- [ ] 白盒阶段就能跑通（S1）
- [ ] 无死路，引导靠环境而非箭头（S2）
- [ ] 有**外部试玩者**的记录（S3）
- [ ] 最低目标配置帧率达标；至少两种分辨率/比例看过（S4）
- [ ] 连续进出 20 次、重开 10 局，内存平稳、无空引用（S5）
- [ ] 接缝复查表逐条打勾（S6）
- [ ] ⚠ 实测参数已回填到 `00-域流程总览.md` 的参数表
- [ ] ⛔ 未通过项已记录为待办，⛔ 不是"以后再说"

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 玩家卡在某处走不出来 | 有死路或引导不足 | S2 |
| 只有设计者自己能通关 | 没找外部试玩 | S3 |
| 低配掉帧，美术已做完 | 白盒阶段没测帧率 | S4 |
| 进出几次内存持续涨 | 未池化 / Autoload 持有旧引用 | S5 |
| 通关了但任务没推进 | 接缝字段对不上 | S6 |
| 换分辨率黑边/UI 错位 | 只在一比例下看过 | S4 |
