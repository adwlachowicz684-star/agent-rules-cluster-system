# 04 区域与流式加载（关卡流程域）

> **前置**：01 + 03 已完成（已有切换时序的共识）
> **本步交付**：大地图按块加载/卸载，边界不抖动、加载不卡顿
> **对应**：做法 `howto/godot/openworld.md` · 审核 `audit/godot/openworld.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 玩家在边界来回走时，块**不会反复加载/卸载**
2. 加载过程中帧率不掉（按时间预算分帧）
3. 快速往返后内存不持续增长（池化）

**产出物**：

```text
WorldStreamer            三条半径 + 加载状态机 + 分帧预算
chunk_state: UNLOADED / LOADING / LOADED / UNLOADING
```

## 2. 工序

### Step 1　先判要不要做：⚠ 这是最容易被过度设计的环节　`[level/04#S1]`

【读】`howto/godot/openworld.md#0. 两个核心风险`

【做】写下判断依据：单场景加载耗时、内存占用、目标平台。
⛔ "以后可能会大"不是理由。

【产出】一份"需要/不需要"的结论与数据

【判据】有实测加载耗时；结论可追溯

【审】`audit/godot/openworld.md#1`

### Step 2　三条半径构成滞回，⛔ 不是一个半径　`[level/04#S2]`

【读】`howto/godot/openworld.md#三条半径构成滞回（hysteresis）`

【做】加载半径 > 保留半径 > 卸载半径，三者**不相等**。

⚠ 只有一个半径时，玩家站在边界上会导致**反复加载卸载**。

【产出】三条半径的配置（实测后回填）

【判据】在边界来回走 30 秒，加载/卸载次数为 0

【审】`audit/godot/openworld.md#3`

### Step 3　加载状态机分开 + 按时间预算分帧　`[level/04#S3]`

【读】`howto/godot/openworld.md#分帧预算`

【做】每块有独立状态；每帧只花固定**时间预算**（不是固定数量）。

ⓘ 按数量分帧在不同设备上耗时不同，预算会失控。

【产出】`chunk_state` 状态机 + 时间预算参数

【判据】低配机上加载期间帧率仍达标

【审】`audit/godot/openworld.md#4`

### Step 4　回收用池化，⛔ 不是 queue_free　`[level/04#S4]`

【读】`howto/godot/openworld.md#节点池`

【做】高频进出区域的节点池化复用。

【产出】节点池

【判据】往返 50 次后内存曲线平稳

【审】`audit/godot/openworld.md#12`

### Step 5　触发区与一次性判定　`[level/04#S5]`

【读】`howto/godot/level-design.md#7. 关卡生命周期`

【做】区域触发（进入区域、通关区）必须过**状态机 + 一次性标记**。

⚠ 触发条件每帧为真，玩家在区内来回走会**重复触发**。

【产出】触发区的一次性判定

【判据】在触发区内来回走 20 次，只触发一次

【审】`audit/godot/level-design.md#24`

### Step 6　大世界坐标精度：小项目测不出来　`[level/04#S6]`

【读】`howto/godot/openworld.md#5. 大世界坐标精度（重点）`

【做】确认坐标范围；超限就用原点重置（floating origin）。

⚠ 精度误差随 2 的幂成倍变，**没有固定安全阈值**。

【产出】坐标范围评估 + 是否启用原点重置

【判据】在最远处抖动/物理异常已消失

【审】`audit/godot/openworld.md#7` `audit/godot/openworld.md#8`

## 3. 参考实现

```gdscript
enum ChunkState { UNLOADED, LOADING, LOADED, UNLOADING }

func update(center: Vector2i) -> void:
    for c in _needed(center):
        if _state.get(c, UNLOADED) == UNLOADED:
            _state[c] = LOADING
    for c in _state.keys():
        if c not in _needed(center) and _state[c] == LOADED:
            _state[c] = UNLOADING
```
