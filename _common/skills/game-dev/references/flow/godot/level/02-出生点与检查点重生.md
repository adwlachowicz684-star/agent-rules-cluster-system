# 02 出生点与检查点重生（关卡流程域）

> **前置**：01 已完成（`LevelData.spawn_point_id` 可用）
> **本步交付**：角色在正确的位置与朝向出生；死亡后按**固定顺序**回到检查点
> **对应**：做法 `howto/godot/tilemap.md` `survival.md` · 审核 `audit/godot/tilemap.md` `survival.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 进入关卡，角色出现在 `LevelData.spawn_point_id` 指定的点，**朝向正确**
2. 死亡 → 回到最近的检查点，且**世界状态**（已开机关、已拾取）符合预期
3. 死亡瞬间不会被残留投射物连死第二次
4. ⚠ **检查点不会覆盖玩家的手动存档**

**产出物**：

```text
SpawnPoint            节点，含 position + facing
Checkpoint.snapshot() -> Dictionary     # 只存重生事实
Respawner.respawn(cp: Checkpoint)       # 固定五步顺序
```

- [ ] 出生点已列出（几个、在哪、朝哪）

## 2. 工序

### Step 1　出生点要带朝向，且判重叠　`[level/02#S1]`

【读】`howto/godot/tilemap.md#5. 场景图块：放出生点、宝箱`

【做】出生点用**场景图块或独立节点**，字段至少含 `facing`：

```gdscript
extends Marker3D
class_name SpawnPoint

@export var id: StringName = &"default"
@export var facing: float = 0.0        # ⚠ 弧度，⛔ 不是可选
```

生成前做一次形状查询，被占用就**报错并指出是哪一格**。

【产出】`SpawnPoint` 节点 + 关卡里的出生点实例

【判据】反复重生 10 次，朝向一致；出生点画在墙边会报错而不是卡住

【审】`audit/godot/tilemap.md#10` `audit/godot/tilemap.md#11`

### Step 2　检查点快照存什么：⛔ 不是只存坐标　`[level/02#S2]`

【读】`howto/godot/survival.md#8. 检查点：存什么与怎么恢复`

【做】快照至少包含：位置 + 朝向 + 任务进度 + 已拾取 + 关卡内场景态。

⛔ **不存临时 buff** —— 死亡重来会把临时变永久。

【产出】`Checkpoint.snapshot()`

【判据】读快照恢复后，临时 buff 已清空、永久进度仍在

【审】`audit/godot/survival.md#11` `audit/godot/survival.md#32`

### Step 3　检查点 ≠ 手动存档　`[level/02#S3]`

【读】`howto/godot/survival.md#3. ⚠ 检查点不覆盖手动存档`

【做】两条独立的写入路径：手动存档写完整档；检查点只写"重生事实"。

⚠ 让检查点覆盖手动存档，玩家会发现"我在第 3 关存的档，
读档回到了第 1 关的检查点"。

【产出】两套写入入口，互不覆盖

【判据】踩检查点后读手动存档，回到的是手动存档点

【审】`audit/godot/survival.md#10`

### Step 4　重生顺序写死：快照→清场→生成→恢复→释放　`[level/02#S4]`

【读】`howto/godot/survival.md#重生：快照→清场→生成→恢复→释放`

【做】五步顺序固定，**先清场再放角色**：

1. 快照当前状态
2. 清场（残留投射物、Tween、Timer）
3. 生成角色到检查点
4. 恢复血量/状态
5. 最后才交还控制权

⛔ 顺序反了会出现"刚复活就被上一轮的投射物连死"。

【产出】`Respawner.respawn()`

【判据】死亡瞬间有飞行中的投射物时复活，不会被再次击杀

【审】`audit/godot/survival.md#33` `audit/godot/survival.md#34` `audit/godot/survival.md#7`

### Step 5　重复踩检查点：默认忽略更早的点　`[level/02#S5]`

【读】`howto/godot/survival.md#8. 检查点：存什么与怎么恢复`

【做】回头踩到更早的检查点，**默认不覆盖**。

⚠ 无条件覆盖会把玩家"拉回更早的点"，表现为进度倒退。

【产出】检查点比较逻辑（按序号而非踩到的时间）

【判据】先踩 3 号再回头踩 1 号，重生仍在 3 号

【审】`audit/godot/survival.md#35`

## 3. 参考实现

```gdscript
func respawn(cp: Checkpoint) -> void:
    var snap := cp.snapshot()
    _clear_world()                 # ⛔ 必须在放角色之前
    player.global_position = snap.pos
    player.rotation.y = snap.facing
    _restore(snap)
    _grant_control()               # ⛔ 最后一步
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 每次复活朝向不同 | 出生点只存坐标 | S1 |
| 出生就卡在墙里 | 出生点没判重叠 | S1 |
| 复活后 buff 变永久 | 快照存了临时 buff | S2 |
| 读档回到错误关卡 | 检查点覆盖了手动存档 | S3 |
| 复活即死亡 | 先放角色再清场 | S4 |
| 进度倒退 | 重复踩检查点覆盖 | S5 |
