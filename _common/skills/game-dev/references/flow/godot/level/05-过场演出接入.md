# 05 过场演出接入（关卡流程域）

> **前置**：03 已完成（已有切换时序的共识）
> **本步交付**：过场能播、能跳过、⛔ 异常退出不会永久锁死输入
> **对应**：做法 `howto/godot/camera-cutscene.md` · 审核 `audit/godot/camera-cutscene.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 过场期间玩家输入被**完全**接管（不是只停移动）
2. 跳过按钮把状态推进到**终态**，不是"提前结束动画"
3. 过场中途退出（切场景、崩溃、强退）后输入能恢复
4. 黑边是 UI，不随分辨率错位

**产出物**：

```text
Cutscene.play(id)        # 入口
InputLock.push()/pop()   # 权限栈，⛔ 不是布尔
```

## 2. 工序

### Step 1　按复杂度选型，⛔ 不是一律 AnimationPlayer　`[level/05#S1]`

【读】`howto/godot/camera-cutscene.md#5. 过场：按复杂度选型`

【做】简单过场用 Tween，复杂编排才用 AnimationPlayer。

ⓘ 一律上 AnimationPlayer 的代价是：每段过场都变成一个要维护的资源。

【产出】过场清单 + 各自的选型

【判据】简单过场不新建 AnimationPlayer 资源

【审】`audit/godot/camera-cutscene.md#7`

### Step 2　控制权用权限栈，⛔ 不是布尔　`[level/05#S2]`

【读】`howto/godot/camera-cutscene.md#控制权：保存并恢复权限`

【做】`can_move` 只挡移动，会漏掉镜头、菜单、攻击。
用**权限栈**统一接管，并在结束时从**快照**恢复。

⛔ "结束时统一设回 true" —— 异常路径会永久锁死。

【产出】`InputLock.push()/pop()` + 快照恢复

【判据】过场中途强制切场景，回到游戏后输入可用

【审】`audit/godot/camera-cutscene.md#8` `audit/godot/camera-cutscene.md#9`

### Step 3　跳过 = 推进到终态　`[level/05#S3]`

【读】`howto/godot/camera-cutscene.md#可跳过`

【做】跳过不是"结束动画"，而是把**所有被动画驱动的状态**设成终态。

⚠ 只停动画的话，镜头停在中间、角色摆着奇怪姿势、flag 没置位。

【产出】`Cutscene.skip_to_end()`

【判据】在第 0.1 秒跳过与完整播完，结束后状态完全一致

【审】`audit/godot/camera-cutscene.md#10`

### Step 4　黑边是 UI，不是相机缩放　`[level/05#S4]`

【读】`howto/godot/camera-cutscene.md#2. 边界、缩放与多目标`

【做】黑边用 `CanvasLayer + ColorRect`，⛔ 不用相机缩放做。

⚠ 相机缩放会改变可视区域，limit 要重算；写死位置则在换分辨率时错位。

【产出】黑边 UI 组件

【判据】换分辨率/比例，黑边仍在正确位置

【审】`audit/godot/camera-cutscene.md#11` `audit/godot/camera-cutscene.md#12`

### Step 5　属性恢复与中途退出　`[level/05#S5]`

【读】`howto/godot/camera-cutscene.md#6. 过场三要素必须写成同一状态机`

【做】AnimationPlayer **不负责**播完把属性恢复原样——
要显式记录初值并在结束时写回。

⚠ 中途退出必须能续播或回到一致状态，⛔ 不能"随它去"。

【产出】初值快照 + 恢复逻辑

【判据】过场结束后所有被改属性回到初值；中途退出状态一致

【审】`audit/godot/camera-cutscene.md#13` `audit/godot/camera-cutscene.md#14`

## 3. 参考实现

```gdscript
func play(id: StringName) -> void:
    var snap := _capture()
    InputLock.push()
    await _run(id)
    _restore(snap)          # ⛔ 不能靠动画自己恢复
    InputLock.pop()

func skip() -> void:
    _seek_to_end()          # ⚠ 推进到终态，不是停止
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 过场时能开菜单 | 只用 can_move | S2 |
| 跳过后镜头卡中间 | 跳过=停动画 | S3 |
| 异常后永久不能操作 | 结束时设 true | S2 |
| 换分辨率黑边错位 | 用相机缩放做黑边 | S4 |
| 过场后角色姿势怪 | 动画不负责恢复 | S5 |
