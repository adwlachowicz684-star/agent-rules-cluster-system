# 关卡流程域 — 流程总览

> **本域交付**：一个关卡从"数据定义 → 加载 → 可玩 → 通关/失败 → 切到下一关"的完整生命周期。
> **对应**：做法 `howto/godot/level-design.md` `systems.md` `camera-cutscene.md` `tilemap.md` `openworld.md`
> 　　　审核 `audit/godot/level-design.md` `systems.md` `camera-cutscene.md` `tilemap.md` `openworld.md`

---

## 0. 先定做什么（⛔ 没写这三行不许开工）

⚠ **流程是从需求派生的，不是固定的。** 同在关卡域，
"做一个能跑完的单机关卡"和"做一张需要流式加载的大地图"
是**两条完全不同的流程**。

开工前写下：

```text
做什么：<一句话，说清"关卡怎么进入、怎么算过、怎么出去">
不做什么：⛔ <至少两条>
验收标准：<可观测的，不是"能玩">
```

示例（本次只做单机关卡骨架）：

```text
做什么：从主菜单进入关卡 → 在出生点生成角色 → 打到终点 → 通关 → 回菜单
不做什么：⛔ 不做流式加载（单场景装得下，见 04）
         ⛔ 不做过场演出（先用淡入淡出，见 05）
验收标准：连续进出关卡 20 次不泄漏；读档后回到正确关卡与进度；
         通关瞬间锁输入，不会二次触发
```

### 然后挑功能点

| 本次要做的 | 需要的功能点 |
|---|---|
| 关卡数据怎么放、场景怎么组织 | 01 → 07 |
| 有出生点 / 检查点 / 重生 | 01 → 02 → 07 |
| 关卡之间有切换与加载画面 | 01 → 03 → 07 |
| 大地图要流式加载 | 01 → 04 → 07 |
| 有过场演出 | 01 → 05 → 07 |
| 有通关/失败/重试的进度管理 | 01 → 06 → 07 |

⛔ **不要全做。** 全做 = 做出需求外的东西 + 浪费。

## 1. 功能点拆解与依赖顺序

```text
01 数据与场景组织 ──┬── 02 出生点与检查点 ──┐
                    ├── 03 场景切换与加载 ──┤
                    ├── 04 区域与流式加载 ──┼── 07 关卡验收
                    ├── 05 过场演出接入 ────┤
                    └── 06 生命周期与进度 ──┘
```

| # | 功能点 | 前置 | 为什么这个顺序 |
|---|---|---|---|
| 01 | 数据与场景组织 | 无 | ⚠ **先定"数值在哪"，后面每一步都在读写它**。场景里塞数值的话，02–06 全要跟着改 |
| 02 | 出生点与检查点 | 01 | 出生点是关卡数据的一部分；检查点快照要存"关卡内状态" |
| 03 | 场景切换与加载 | 01 | 切换时交接的就是 01 定义的数据 |
| 04 | 区域与流式加载 | 01 03 | ⚠ 流式加载是"切换"的细化，⛔ 不要跳过 03 直接做 |
| 05 | 过场演出接入 | 03 | 过场发生在切换前后，要先有切换时序的共识 |
| 06 | 生命周期与进度 | 01 02 | 通关/失败判定依赖"关卡当前状态"，而状态由 01/02 供给 |
| 07 | 关卡验收 | 01–06 | ⓘ 只有链路完整才谈得上验收 |

## 2. ⚠ 四个最容易做反的顺序

**① 先搭场景再抽数据。**
"先把关卡摆出来，数值以后再抽" —— 等到要抽的时候，
数值散在几十个节点的 inspector 里，⛔ 抽不干净也改不动。
✅ 先写 `LevelData`，场景只读它。

**② 先做过场再定切换时序。**
官方的切换是**两段式**（旧场景立刻出树、新场景帧末入树）。
不知道这一点就写"过场结束→读新场景"，会拿到 null。
✅ 先过 03 的时序，再谈 05 的表现。

**③ 把"通关"做成弹 UI。**
弹个结算面板就算通关，结果面板弹出期间玩家还在被追、还能拾取、
还能再踩一次通关点。✅ 通关是**状态转移**，UI 只是表现。

**④ 等美术做完才测帧率。**
⚠ 白盒阶段就要测。等美术做完才发现跑不动，
返工的是几何 + 美术 + 玩法三方。

## 3. 每做完一个功能点必做

1. 跑一遍该步的**验收清单**（第 4 节），逐条打勾
2. ⛔ 有没过的，不进下一步
3. 过该步【审】列的 audit 条目（步骤级即时检查）
4. 过功能点末尾的「整体审核」节（功能点级复查）
5. ⚠ 实测参数**回填**，⛔ 不留文档示例值
