> **前置**：01 + 02 已完成（有数据与检查点）
> **本步交付**：关卡有统一状态机；通关/失败是状态转移；进度能正确持久化

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 通关瞬间：敌人停手、输入被锁、⛔ 不会二次触发
2. 加载期间玩家无法操作
3. 暂停时该停的停、该跑的跑（⚠ 信号照常触发）
4. 读档回到正确的关卡与关卡内进度

**产出物**：

```text
Phase: LOADING / RUNNING / PAUSED / CLEARED / FAILED
Level.phase                  唯一状态源
LevelProgress.save() / load()  关卡进度，与检查点分离
```

## 2. 工序

### Step 1　定义关卡状态机，⛔ 状态不能散在各处　`[level/06#S1]`

【读】`howto/godot/level-design.md#7. 关卡生命周期`

【做】五态：LOADING / RUNNING / PAUSED / CLEARED / FAILED，集中一处。

⚠ 散在各处的后果是"通关了敌人还在追""失败了还能拾取"。

【产出】`Level.phase` + 转移表

【判据】通关后敌人立即停止攻击

【审】`audit/godot/level-design.md#23`

### Step 2　通关/失败是状态转移，不是弹 UI　`[level/06#S2]`

【读】`howto/godot/level-design.md#7. 关卡生命周期`

【做】判定函数**先过状态门**：

```gdscript
func _try_clear() -> void:
    if phase != Phase.RUNNING:
        return          # ⛔ 没这道门就会重复触发
    phase = Phase.CLEARED
    _lock_input()
```

⚠ 通关条件每帧都可为真（玩家站在触发区里来回走）。

【产出】一次性判定 + 输入锁

【判据】在通关区内来回走 20 次只触发一次

【审】`audit/godot/level-design.md#24`

### Step 3　加载期间不接受输入　`[level/06#S3]`

【读】`howto/godot/systems.md#⚠ 官方的切换时序`

【做】`LOADING` 状态下丢弃输入，并在新场景真正入树后才转 `RUNNING`。

⚠ 新场景是**帧末**才入树的，早于此就转 RUNNING 会操作到不存在的节点。

【产出】LOADING → RUNNING 的转移条件

【判据】加载期间狂点鼠标不会报错、不会提前操作

【审】`audit/godot/systems.md#8`

### Step 4　⚠ 暂停时信号照常触发　`[level/06#S4]`

【读】`howto/godot/survival.md#⚠ 暂停时信号仍然会触发`

【做】官方明确：节点停止处理时 `_process` 不跑，但**信号照常触发**，
连接的函数会执行——即使脚本挂在已暂停的节点上。

⛔ 所以"设了 `PROCESS_MODE_PAUSABLE` 就安全了"是错的：
用信号驱动的保存、伤害、拾取，暂停期间**依然会跑**。

✅ 在回调内部再判一次状态。

【产出】暂停期间仍需运行的白名单 + 回调内状态判断

【判据】暂停时不会扣血、不会拾取；UI 音仍响

【审】`audit/godot/survival.md#27` `audit/godot/survival.md#28`

### Step 5　关卡进度与解锁源单一　`[level/06#S5]`

【读】`howto/godot/narrative.md#4. 进程结构`

【做】关卡解锁、章节选择、周目继承**都从同一数据源**来。

⚠ 把检查点当关卡解锁源，会出现"读档后关卡解锁状态与进度不符"。

ⓘ 分工：检查点管**重生事实**（见 02），关卡进度管**推进到哪**。

【产出】`LevelProgress` + 解锁判定

【判据】读档后关卡解锁状态与进度一致

【审】`audit/godot/narrative.md#18`

## 3. 参考实现

```gdscript
enum Phase { LOADING, RUNNING, PAUSED, CLEARED, FAILED }
var phase: Phase = Phase.LOADING

func _on_scene_changed() -> void:
    phase = Phase.RUNNING      # ⚠ 等真正入树才转
```
