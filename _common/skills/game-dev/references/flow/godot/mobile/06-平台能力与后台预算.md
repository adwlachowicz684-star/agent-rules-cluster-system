# 06 平台能力与后台预算（移动端域）

> **本步交付**：返回键 + 权限 + 暂停恢复
> **对应**：流程 `howto/godot/mobile.md` · 审核 `audit/godot/mobile.md`

## 0. 交付物定义

1. 返回键走窗口通知，且已 `set_input_as_handled()`
2. 返回键有层级判定，⛔ 不只是"关弹窗"
3. 权限在运行时请求，且**等回调之后**才用功能
4. 暂停回调里的工作在 iOS 预算内（约 5 秒）
5. 恢复后重取时间基准
6. 暂停期间停止计时与活动推进

## 1. 前置检查清单

- [ ] 返回键用 `NOTIFICATION_WM_GO_BACK_REQUEST`
- [ ] 处理分支里调了 `set_input_as_handled()`
- [ ] 有层级判定（弹窗 / 二级界面 / 主界面）
- [ ] 权限用了运行时请求且等回调
- [ ] ⚠ 暂停回调的工作量已估过，不超过 iOS 预算
- [ ] 恢复后重取时间基准
- [ ] 暂停期间计时已停止

## 2. 工序

### Step 1　返回键是窗口通知，不是 InputMap 动作　`[mobile/06#S1]`

【读】`howto/godot/mobile.md#6. 返回键（Android）`

【做】
在 `_notification()` 里处理 `NOTIFICATION_WM_GO_BACK_REQUEST`。
⛔ 去 InputMap 里找返回键动作 —— 它不是输入动作，
⛔ 不处理就直接退出游戏（不是"没反应"，是**退出**）。

⛔ 另一个方向也要注意：忘了 `set_input_as_handled()` 的话，
即使处理了也会退出 —— 表现为"代码执行了但游戏还是关了"，
排查会被引向"是不是有第二个退出调用"。

【产出】返回键处理代码，含 `set_input_as_handled()`

【判据】有弹窗时按返回键，弹窗关闭且游戏不退出。

【审】`audit/godot/mobile.md#5`、`audit/godot/mobile.md#31`

### Step 2　返回键要有层级判定　`[mobile/06#S2]`

【读】`howto/godot/mobile.md#6. 返回键（Android）`

【做】
按界面层级决定返回键行为：有弹窗关弹窗、在二级界面回上级、在主界面才二次确认退出。
⛔ 只判最上层弹窗 —— 深层界面按返回直接退出游戏，
⛔ 而这是玩家最不能接受的一类行为（"我只是想返回上一页"）。

ⓘ 二次确认也要做：主界面按返回直接退出同样不可接受。

【产出】返回键层级规则（弹窗 / 二级 / 主界面）

【判据】从三层深的界面连续按返回，逐层回退且不退出。

【审】`audit/godot/mobile.md#32`

### Step 3　权限要在运行时请求，且等回调之后才用　`[mobile/06#S3]`

【读】`howto/godot/mobile.md#7. 权限`

【做】
运行时调用权限请求，并在回调之后才使用相关功能。
⛔ 只在导出预设里勾选 —— 现代系统要求运行时授权，
⛔ 表现为"功能静默失败"，而这个失败没有任何错误日志。

⛔ 请求是异步的：请求之后立刻使用功能，回调还没回来，
功能拿到的是"未授权"状态，同样静默失败。

ⓘ 权限理由文案与最小必要原则见 `compliance/02`，
⛔ 不在这里自己编一套口径。

【产出】权限请求封装（请求 → 等回调 → 使用功能）

【判据】首次安装、未授权状态下，功能给出明确提示而非静默失败。

【审】`audit/godot/mobile.md#38`、`audit/godot/mobile.md#6`

### Step 4　暂停回调的工作量必须在 iOS 预算内　`[mobile/06#S4]`

【读】`howto/godot/mobile.md#9. 暂停 / 恢复与后台预算`

【做】
`NOTIFICATION_APPLICATION_PAUSED` 里只做轻量落盘，重活交给恢复后。
⛔ 在暂停通知里做完整序列化、批量上报、资源整理 ——
官方口径是 iOS 上"只有大约 5 秒"完成由该信号启动的任务，
⛔ 超时则 **iOS 终止该应用程序，而不是暂停它**。

⛔ 表现为"iOS 上切后台回来闪退 / 进度没了"，
而排查几乎必然被引向崩溃 SDK 或内存问题 ——
没人会想到是暂停回调做得太慢。

ⓘ 落盘本身走 `save` 域的原子写，未上报的埋点队列走 `analytics/03` 的持久化，
⛔ 不在这里另写一份序列化。

【产出】暂停回调的工作清单，且每项都能说清耗时量级

【判据】暂停回调在最慢的目标设备上实测远低于 5 秒。

【审】`audit/godot/mobile.md#16`

### Step 5　恢复后要重取时间基准　`[mobile/06#S5]`

【读】`howto/godot/mobile.md#9. 暂停 / 恢复与后台预算`

【做】
`NOTIFICATION_APPLICATION_RESUMED` 之后重新取时间基准。
⛔ 沿用暂停前的时间基准 —— 挂机期间系统时钟可能已跳变
（用户改时间、跨时区、长时间后台），
⛔ 表现为"切回来体力满了 / 活动提前结束 / 倒计时变负"。

ⓘ 这与 `monetization` / `vip` 域确立的"系统时钟可被玩家设置"是同一条约束，
只是移动端它不是恶意设置，而是**正常的挂机行为** ——
所以精确计时仍要走单调时钟，绝对时间只能来自服务端。

【产出】恢复后的时间基准重取路径

【判据】挂机 30 分钟后回来，倒计时与活动状态正确。

【审】`audit/godot/mobile.md#17`

### Step 6　暂停期间停止计时与活动推进　`[mobile/06#S6]`

【读】`howto/godot/mobile.md#8. 移动端性能`

【做】
暂停时停掉游戏内计时、体力恢复、活动倒计时等一切随时间推进的逻辑。
⛔ 暂停时继续跑 —— 后台挂机就能刷进度、刷体力，
⛔ 这是可直接被利用的漏洞，而在正常测试里完全测不出来
（因为测试时不会真的挂机几小时）。

ⓘ 低端机长测也不能省：发热降频导致的掉帧通常在 10 分钟后才出现，
⛔ 只测前 2 分钟等于没测。

ⓘ `Engine.max_fps` 用来省电与稳定延迟，⛔ 不能突破 vsync 上限 ——
它不是提帧手段。

【产出】暂停时停止推进的逻辑清单 + 长测记录

【判据】挂机期间游戏内时间不推进；低端机 20 分钟实测帧率曲线已记录。

【审】`audit/godot/mobile.md#39`、`audit/godot/mobile.md#33`、`audit/godot/mobile.md#34`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：返回键消费 + 暂停轻量落盘 + 恢复重取基准
# ⓘ NOTIFICATION_WM_GO_BACK_REQUEST / NOTIFICATION_APPLICATION_PAUSED /
#   NOTIFICATION_APPLICATION_RESUMED 均为引擎内置常量（MainLoop），无需声明
func _notification(what: int) -> void:
    match what:
        NOTIFICATION_WM_GO_BACK_REQUEST:
            if _can_go_back():
                get_viewport().set_input_as_handled()   # ⛔ 不消费仍会退出（见 S1）
                _go_back()
        NOTIFICATION_APPLICATION_PAUSED:
            _paused = true          # ⛔ 停掉一切随时间推进（见 S6）
            _flush_light_save()     # ⛔ 只做轻量落盘，iOS 约 5 秒预算（见 S4）
        NOTIFICATION_APPLICATION_RESUMED:
            _paused = false
            _rebase_time()          # ⛔ 系统时钟可能已跳变（见 S5）

func _can_go_back() -> bool:
    # ⓘ 层级判定：弹窗 → 二级界面 → 主界面二次确认（见 S2）
    return _popup.visible or _current_screen != "main"
```

## 4. 验收清单

- [ ] 返回键在通知里处理，且已消费
- [ ] 三层深界面可逐层返回，不退出
- [ ] 权限运行时请求，未授权时给出提示而非静默失败
- [ ] 暂停回调工作量远低于 iOS 5 秒预算
- [ ] 恢复后重取时间基准，挂机 30 分钟结果正确
- [ ] 挂机期间游戏内时间不推进

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 代码执行了但游戏还是关了 | 未 `set_input_as_handled()` | S1 |
| 二级界面按返回直接退出 | 只判最上层弹窗 | S2 |
| 功能静默失败无日志 | 只在预设勾选 / 未等回调 | S3 |
| iOS 切后台回来闪退 | 暂停回调超时被杀 | S4 |
| 挂机回来倒计时变负 | 未重取时间基准 | S5 |
| 后台挂机能刷体力 | 暂停时仍在推进 | S6 |
