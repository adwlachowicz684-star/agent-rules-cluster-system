# 07 移动端验收（移动端域）

> **本步交付**：真机实测通过 + 敌意环境实测通过
> **对应**：流程 `howto/godot/mobile.md` · 审核 `audit/godot/mobile.md`

## 0. 交付物定义

1. 已在真机上用手（不是鼠标）跑通完整路径
2. 刘海 / 挖孔机型实测无控件被遮挡
3. 切后台再回来，进度与倒计时正确
4. 旋转屏幕、弹出软键盘后布局正确
5. 最低档设备上长测无降频掉帧

## 2. 工序

### Step 1　真机用手跑，编辑器鼠标不算　`[mobile/07#S1]`

【读】`howto/godot/mobile.md#8. 移动端性能`

【做】
在真机上用拇指跑一遍完整路径。
⛔ 用编辑器鼠标验收 —— 鼠标是单指、是精确指针、是无遮挡的，
而拇指是粗的、会挡住屏幕、会误触。⛔ 这三件事在编辑器里一个都暴露不出来。

ⓘ 要按玩家真实的持机姿势测：单手拇指能够到所有常用控件吗？
⛔ "能点到"和"能舒服地点到"是两件事，
后者才是玩家评论里说的"操作难受"。

【产出】真机验收记录（设备型号 / 持机姿势 / 是否误触）

【判据】单手持机时，所有常用控件都在拇指自然活动范围内。

【审】`audit/godot/mobile.md#37`

### Step 2　刘海 / 挖孔机型要实测，不能靠模拟器　`[mobile/07#S2]`

【读】`howto/godot/mobile.md#安全区（刘海屏）`

【做】
在至少一台刘海（或挖孔）机型上确认顶部 / 底部控件不被遮挡。
⛔ 用模拟器或普通矩形屏验收 —— 安全区代码在这类设备上
返回的就是整屏，⛔ 于是"看起来完全正确"，问题只在真机刘海上出现。

ⓘ 横屏尤其要测：横屏时刘海在侧边，安全区形状与竖屏不同，
⛔ 只测竖屏等于没测。

【产出】刘海机型 × 横竖屏的安全区实测记录

【判据】横竖屏下，安全区内的控件均不被遮挡。

【审】`audit/godot/mobile.md#24`、`audit/godot/mobile.md#7`

### Step 3　切后台再回来，进度与倒计时都要对　`[mobile/07#S3]`

【读】`howto/godot/mobile.md#9. 暂停 / 恢复与后台预算`

【做】
切后台、等待、再回来，检查进度已保存、倒计时正确、活动状态正确。
⛔ 只测"切一下立刻回来" —— 那是另一条代码路径，
⛔ 真正的风险在"挂机很久"和"被系统回收后冷启动"两种情形。

ⓘ iOS 上还要专门确认暂停回调没超时：
超时的话系统**终止 App 而不是暂停它**，
⛔ 表现为"切回来闪退"，而这在短测里永远不出现。

【产出】后台场景记录（短切 / 挂机 30 分钟 / 被回收冷启动）

【判据】三种情形下进度、倒计时、活动状态均正确。

【审】`audit/godot/mobile.md#16`、`audit/godot/mobile.md#17`、`audit/godot/mobile.md#39`

### Step 4　旋转屏幕与弹出软键盘后布局仍正确　`[mobile/07#S4]`

【读】`howto/godot/mobile.md#方向与分辨率`

【做】
旋转屏幕、弹出软键盘，各确认一次布局。
⛔ 只在初始状态下验收 —— 旋转会触发 `size_changed`，
软键盘会改变可用高度，⛔ 这两件事都会让"初始正确"变成"之后错误"。

ⓘ 旋转要连转多次（不只是转一次），
确认安全区每次都重算、且没有累积偏移。

【产出】旋转 × 软键盘的布局记录

【判据】连转四次后边距仍正确；键盘弹出后输入框可见。

【审】`audit/godot/mobile.md#20`、`audit/godot/mobile.md#22`

### Step 5　最低档设备长测 20 分钟，看降频　`[mobile/07#S5]`

【读】`howto/godot/mobile.md#8. 移动端性能`

【做】
在最低档设备上连续跑 20 分钟，记录帧率曲线与发热。
⛔ 只测 2 分钟 —— 发热导致的降频掉帧通常在 10 分钟后才出现，
⛔ 短测给出的"很流畅"是完全错误的信心，而它恰恰来自最需要被验证的那台设备。

ⓘ 同时确认 `Engine.max_fps` 的用法正确：它用来省电与稳定延迟，
⛔ 不能突破 vsync 上限 —— 它不是提帧手段。

【产出】20 分钟帧率曲线 + 发热记录

【判据】20 分钟后帧率无明显下滑；帧率曲线已归档。

【审】`audit/godot/mobile.md#33`、`audit/godot/mobile.md#10`、`audit/godot/mobile.md#34`

## 3. 验收清单

- [ ] 真机单手持机跑通，常用控件在拇指范围内
- [ ] 刘海机型横竖屏均无控件被遮挡
- [ ] 短切 / 挂机 30 分钟 / 冷启动三种情形均正确
- [ ] 连转四次后边距正确；键盘弹出后输入框可见
- [ ] 最低档设备 20 分钟帧率曲线无下滑

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 上线后"操作难受" | 编辑器鼠标验收 | S1 |
| 真机上 UI 被刘海挡住 | 模拟器 / 矩形屏验收 | S2 |
| 切回来闪退 / 进度没了 | 只测短切，未测挂机与冷启动 | S3 |
| 转屏后布局错乱 | 只测初始状态 | S4 |
| 玩一阵就开始掉帧 | 只测 2 分钟，未测降频 | S5 |
