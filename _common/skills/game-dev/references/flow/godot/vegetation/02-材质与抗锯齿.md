## 0. 交付物定义

⚠ **这一节的直觉几乎全是错的**，是植被域返工率最高的一步。

⛔ 三个常见直觉：

| 直觉 | 实际 |
|---|---|
| 边缘闪 → 开 MSAA | 官方：MSAA **对 alpha scissor 无效** |
| 只开 alpha antialiasing | 官方：依赖 MSAA，**没有则退化成抖动** |
| 改了 threshold 不用管 edge | 官方：edge **必须严格低于** threshold |

做完这一步，应该能**当场演示**：

1. 摄像机推近拉远，叶片边缘**稳定不闪**
2. ⚠ 项目设置里 `MSAA 3D` ≥ 2×（不是 `MSAA 2D`）
3. ⚠ `Alpha Antialiasing Edge` **严格低于** scissor threshold
4. 非双面的叶片**不渲染背面**
5. 透明叶片用了 **Depth Pre-Pass**

**产出物**（下游按名字对接）：

```text
material.transparency = Alpha Scissor
material.alpha_antialiasing       # 三种模式之一
material.alpha_antialiasing_edge  # < threshold
material.cull_mode                # 显式，不为"碰巧"
material.depth_draw_mode = Depth Pre-Pass   # 透明叶片
```

## 2. 工序

### Step 1　⛔ MSAA 与 alpha AA 必须成对　`[vegetation/02#S1]`

【读】`howto/godot/vegetation.md#2. ⚠ alpha scissor 植被：MSAA 无效，正确解法是两者组合`

【做】先开 `MSAA 3D ≥ 2×`，再开材质上的 Alpha Antialiasing。

⛔ **官方原话：*"MSAA does not reduce transparency aliasing for materials
using the Alpha Scissor transparency mode."*** —— 只开 MSAA 无效。
⛔ 只开 alpha AA 不开 MSAA → 官方原话 *"isn't very effective"*。

【产出】两项都已开

【判据】⚠ 推近拉远边缘稳定；⛔ 关掉 MSAA 后**明显变差**（证明真的在用）

【审】`audit/godot/vegetation.md#7`

### Step 2　⚠ 改的是 MSAA 3D 不是 MSAA 2D　`[vegetation/02#S2]`

【读】`howto/godot/vegetation.md#2. ⚠ alpha scissor 植被：MSAA 无效，正确解法是两者组合`

【做】项目设置里改 `Rendering > Anti Aliasing > Quality > MSAA 3D`。

⛔ **官方："it's important to change the value of the MSAA 3D setting and
not MSAA 2D, as these are entirely separate settings."**

【产出】`MSAA 3D` 已设

【判据】⚠ 项目设置里两个值分别确认过

【审】`audit/godot/vegetation.md#10`

### Step 3　⛔ edge 严格低于 threshold　`[vegetation/02#S3]`

【读】`howto/godot/vegetation.md#2.1 ⛔ Alpha Antialiasing Edge 必须严格低于阈值`

【做】`alpha_antialiasing_edge < alpha_scissor_threshold`。

⛔ **官方："must always be set to a value that is strictly below"**。
改了 threshold 不同步改 edge → 表现为"摄像机靠近时贴图外观明显变化"。

【产出】两个值的配对关系

【判据】⚠ 改 threshold 时 edge **跟着联动**（代码或检查表）

【审】`audit/godot/vegetation.md#9`

### Step 4　⚠ 双面显式设，不为"碰巧"　`[vegetation/02#S4]`

【读】`howto/godot/vegetation.md#3. ⛔ 双面叶片：从 Blender 导出会带上 Disabled`

【做】需双面 → 显式 `Disabled`；不需 → 导出前在 Blender 开 Backface Culling。

⛔ **官方："Blender has backface culling disabled ... materials in Godot
will have their cull mode set to Disabled."**
背面也渲染 → 植被这种大量叶片片，**填充率翻倍且不报错**。

【产出】每种植被的 cull mode 显式声明

【判据】⚠ 不需要双面的植被，**cull mode 不是 Disabled**

【审】`audit/godot/vegetation.md#11` `audit/godot/vegetation.md#12`

### Step 5　ⓘ 透明叶片用 Depth Pre-Pass　`[vegetation/02#S5]`

【读】`howto/godot/vegetation.md#4. ⓘ 透明草地/树叶：官方点名要用 Depth Pre-Pass`

【做】`depth_draw_mode = Depth Pre-Pass`。

ⓘ **官方原话："Use this option with transparent grass or tree foliage."**
先画不透明部分再画透明部分，避免自穿插排序错误。

【产出】透明叶片的深度模式

【判据】⚠ 透明叶片**自穿插无排序错误**

【审】`audit/godot/vegetation.md#13`

## 5. 常见返工

**① 只开 MSAA。** 对 alpha scissor 无效，边缘照闪。

**② 只开 alpha AA。** 无 MSAA 退化成抖动。

**③ 改 threshold 不改 edge。** 靠近时外观突变。

**④ cull mode 听天由命。** 填充率翻倍。
