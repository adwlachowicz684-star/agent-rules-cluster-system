# 03 风与动画（植被域）

> **前置**：`02-材质与抗锯齿.md` 已完成
> **本步交付**：整片植被摆动，且**风强度一改全都跟着变**
> **对应**：做法 `howto/godot/vegetation.md#5. 风动画：走 shader，不走 CPU`
> 　　　审核 `audit/godot/vegetation.md#14`

## 0. 交付物定义

⚠ **一万个实例的摇摆绝不能在 CPU 上逐个改 transform** ——
那会把 MultiMesh 的意义全部抵消。

⛔ 逐帧 `set_instance_transform` 一万个实例 = 每帧一万次矩阵写入 +
一次全量 buffer 上传，**帧时间直接翻倍**，
而在实例少时（比如测试用 100 株）完全测不出来。

做完这一步，应该能**当场演示**：

1. 整片植被摆动，**帧时间与不摆动时基本持平**
2. ⚠ 改一次风的全局强度，**全部植被立刻跟着变**
3. 每株相位不同（不是整片同步摆动）
4. 天气系统改风速 → 植被**自动跟随**，无需通知
5. ⛔ 修改单株参数**不影响**其他株

**产出物**（下游按名字对接）：

```text
wind_strength: float      # 全局 uniform / 全局状态，植被只读
vertex() 里的位移         # 按世界坐标 + TIME + 每株相位
set_instance_shader_parameter()   # 每株不同时用这个
```

## 2. 工序

### Step 1　⛔ 走顶点着色器，不走 CPU　`[vegetation/03#S1]`

【读】`howto/godot/vegetation.md#5. 风动画：走 shader，不走 CPU`

【做】在 `vertex()` 里按世界坐标 + `TIME` 做位移。

⛔ CPU 逐个改 transform → 每帧一万次矩阵写入 + 全量上传，
抵消 MultiMesh 的全部意义。

【产出】顶点着色器位移

【判据】⚠ 摆动开启前后**帧时间基本不变**

【审】`audit/godot/vegetation.md#14`

### Step 2　⚠ 每株相位不同　`[vegetation/03#S2]`

【读】`howto/godot/vegetation.md#5. 风动画：走 shader，不走 CPU`

【做】用 `INSTANCE_ID` 或 per-instance `custom_data` 做相位偏移。

⛔ 不做偏移 → 整片**完全同步摆动**，看起来像果冻而不像风，
而这个"不像"很难说清是哪不对。

【产出】相位偏移

【判据】⚠ 相邻两株**不同步**

【审】`audit/godot/vegetation.md#14`

### Step 3　⛔ 风强度是全局状态，植被只读　`[vegetation/03#S3]`

【读】`howto/godot/vegetation.md#5. 风动画：走 shader，不走 CPU`

【做】风强度来自 `environment-systems.md#3. 天气` 的全局状态。

⛔ 每株各自算风 → 天气系统改了风的强度，植被**不会跟着变**，
表现为"改成大风天了，草还在微风摆"。

【产出】全局风 uniform

【判据】⚠ 改一次风强度，**全部植被立刻变**

【审】`audit/godot/vegetation.md#16`

### Step 4　⚠ 每株不同参数用 set_instance_shader_parameter　`[vegetation/03#S4]`

【读】`howto/godot/vegetation.md#5. 风动画：走 shader，不走 CPU`

【做】需要每株不同时用 `set_instance_shader_parameter()`。

⛔ 用 `set_shader_parameter()` → 那是改**所有实例共享**的那个，
表现为"给一株调参数，整片都变了"。

【产出】per-instance uniform 调用

【判据】⚠ 改一株的参数，**其他株不变**

【审】`audit/godot/vegetation.md#15`

### Step 5　⚠ 摆动不影响碰撞与交互判定　`[vegetation/03#S5]`

【读】`howto/godot/vegetation.md#9. 相关文档`

【做】摆动只在渲染层，⛔ 不改变 05/06 用的位置数据。

⛔ 视觉位移带进判定 → "明明没碰到却判定命中"，
而这类偏差**随风速变化**，时灵时不灵，最难复现。

【产出】渲染位移与逻辑位置分离

【判据】⚠ 风速拉到最大，**交互判定结果不变**

【审】`audit/godot/vegetation.md#14`

## 5. 常见返工

**① CPU 改 transform。** 帧时间翻倍，实例少时测不出。

**② 整片同步。** 像果冻不像风。

**③ 每株自己算风。** 改天气不跟随。

**④ 位移带进判定。** 时灵时不灵。
