## 0. 交付物定义

⚠ **各功能点自己的验收不能替代域级验收。**
植被尤其如此——它横跨实例化 / 材质 / 天气 / 开放世界 / 程序化生成 / 抗锯齿六个域，
⛔ 而且**大量问题只在数量上来之后才出现**。

做完这一步，应该能**当场演示**并**签核**：

1. ⚠ 转视角 `Vertices Drawn` **立刻下降**（01 的核心指标）
2. ⚠ 推近拉远叶片边缘**不闪**（02 的核心指标）
3. ⚠ 连砍 10 棵**逐棵对得上**（05 的核心指标）
4. ⚠ 拉远帧时间**可测下降**（04 的核心指标）
5. ⚠ 接缝复查：与 7 个域的契约全对上

## 2. 工序

### Step 1　⚠ 满量实测顶点数　`[vegetation/07#S1]`

【读】`howto/godot/vegetation.md#1. ⚠ MultiMesh 是一个 AABB，不是一万个`

【做】在**满量**场景下转视角，看 `Vertices Drawn`。

⛔ 用几十株测 → 一切正常，因为问题只在数量上来后才暴露。
⚠ 这是本域**最常见的验收造假**。

【产出】满量转视角的顶点数曲线

【判据】⚠ 转向后顶点数**立刻下降**；不降则 01 的 AABB 仍错

【审】`audit/godot/vegetation.md#23`

### Step 2　⚠ 边缘稳定性实测　`[vegetation/07#S2]`

【读】`howto/godot/vegetation.md#2. ⚠ alpha scissor 植被：MSAA 无效，正确解法是两者组合`

【做】推近拉远 + 横向平移，看叶片边缘。

⛔ 只在一个距离看 → 闪烁恰恰在**距离变化**时才出现。

【产出】多距离截图或录屏

【判据】⚠ 全程边缘稳定；⛔ 关掉 MSAA 后**明显变差**（证明真的在用）

【审】`audit/godot/vegetation.md#7`

### Step 3　⚠ 连砍 10 棵逐棵核对　`[vegetation/07#S3]`

【读】`howto/godot/vegetation.md#7. ⛔ 可交互植被：MultiMesh 实例没有独立身份`

【做】连砍 10 棵，每次确认倒下的是目标那棵。

⛔ 只砍一棵 → 索引错位的 bug **碰巧能通过**（第一次砍总是对的）。

【产出】10 次砍伐的逐次核对记录

【判据】⚠ 10 次全部对得上

【审】`audit/godot/vegetation.md#20` `audit/godot/vegetation.md#21`

### Step 4　⚠ 帧时间随距离下降　`[vegetation/07#S4]`

【读】`howto/godot/vegetation.md#6. LOD 与可见距离`

【做】从近到远采样帧时间与 `Vertices Drawn`。

⛔ 恒定 → range 没生效（04/S1）或 AABB 错（01/S2），
ⓘ 两者症状一样，要分别确认。

【产出】距离—帧时间曲线

【判据】⚠ 可测下降，且**无空档距离**

【审】`audit/godot/vegetation.md#23`

### Step 5　⚠ 接缝复查　`[vegetation/07#S5]`

【读】`howto/godot/vegetation.md#9. 相关文档`

【做】逐条核对 00 总览第 2 节的七条契约：

| 接缝 | 复查点 |
|---|---|
| `occlusion-instancing.md` | 基础在那篇，本域只讲分块与 AABB，不重复 |
| `environment-systems.md` 天气 | 风强度**全局**，植被只读不写 |
| `openworld.md` 流式 | 分块尺寸与流式单元对齐，跨界无闪烁 |
| `procedural-generation.md` 布点 | 泊松只管不挤，不管玩法密度 |
| `upscaling.md` 抗锯齿 | alpha AA 依赖 MSAA，与超分选型联动 |
| `render-pipeline.md` | 能力矩阵覆盖当前后端 |
| `lifeskill-housing.md` 采集 | 走 05 的状态表，不另起一套 |

⛔ **这七条不查，部件全合格也可能拼不起来。**

【产出】接缝复查表

【判据】⚠ 七条全部对上，每条都有实测证据

【审】`audit/godot/vegetation.md#19`

## 4. 常见返工

**① 用几十株验收。** 问题只在满量出现。

**② 只砍一棵。** 索引错位碰巧通过。

**③ 只看一个距离。** 闪烁在距离变化时才出现。

**④ 不查接缝。** 部件合格但拼不起来。
