# 01 实例化与分块（植被域）

> **前置**：已确认数量大到不能逐个建节点（见 `00-域流程总览.md` 第 0 节）
> **本步交付**：转视角时 **`Vertices Drawn` 立刻下降**
> **对应**：做法 `howto/godot/vegetation.md#1. ⚠ MultiMesh 是一个 AABB，不是一万个`
> 　　　审核 `audit/godot/vegetation.md#2`

## 0. 交付物定义

⚠ **本步是整个域的地基。** AABB 与分块决定后面所有性能手段是否有效。
⛔ 跳过它直接铺植被，做到最后会发现"怎么调参数帧率都不动"。

做完这一步，应该能**当场演示**：

1. 转视角时 `Vertices Drawn` **立刻下降**
2. ⚠ 摄像机背对原点时，植被**不会整片消失**
3. 视锥边缘的实例**不会被切掉一半**
4. 一万实例下帧时间**随可见格数**变化，不是随总数
5. transform 不再变化时，**不每帧重刷** buffer

**产出物**（下游按名字对接）：

```text
VegetationCell: MultiMeshInstance3D   # 每格一个
custom_aabb                            # 填完 transform 后显式写
CELL_SIZE: float                       # 进配置，不硬编码
```

- [ ] 已确认实例数量级（几千还是几万）
- [ ] ⚠ 已确认网格半径（用于 `grow()`）
- [ ] 已确认是否需要与 `openworld.md` 的流式单元对齐
- [ ] 已知引擎**不逐实例剔除**

## 2. 工序

### Step 1　⛔ 用 MultiMesh 不用 MeshInstance3D　`[vegetation/01#S1]`

【读】`howto/godot/vegetation.md#0. 先定性：这是实例化问题，不是建模问题`

【做】全部散布物走 `MultiMeshInstance3D`。

⛔ 逐个建 `MeshInstance3D`：一万个节点参与遍历、剔除、变换更新，
**在加第二棵树之前帧率就崩了**，而这个方向错要铺满场景才暴露。

【产出】MultiMesh 结构

【判据】⚠ 一万个实例的 draw call **不随数量增长**

【审】`audit/godot/vegetation.md#1`

### Step 2　⚠ 填完 transform 后显式写 custom_aabb　`[vegetation/01#S2]`

【读】`howto/godot/vegetation.md#1. ⚠ MultiMesh 是一个 AABB，不是一万个`

【做】
```gdscript
aabb = aabb.expand(positions[i])
custom_aabb = aabb.grow(mesh_radius)
```

⛔ 代码填 transform 前 AABB 已算好 → 退化成原点上的零尺寸盒，
症状是**摄像机背对原点时整片植被消失**。

【产出】`custom_aabb` 显式写入

【判据】⚠ 摄像机绕原点转一圈，**植被不消失**

【审】`audit/godot/vegetation.md#3`

### Step 3　⛔ grow 留出网格半径　`[vegetation/01#S3]`

【读】`howto/godot/vegetation.md#1. ⚠ MultiMesh 是一个 AABB，不是一万个`

【做】`aabb.grow(mesh_radius)`，⛔ 只用实例中心扩。

⛔ 少了 `grow()` → 中心刚好在视锥外的实例**边缘被切掉**，
表现为"走到边界时草突然缺一角"。

【产出】带 `grow()` 的 AABB

【判据】⚠ 沿视锥边缘平移，实例**无缺口**

【审】`audit/godot/vegetation.md#4`

### Step 4　⚠ 按格子分块　`[vegetation/01#S4]`

【读】`howto/godot/vegetation.md#1. ⚠ MultiMesh 是一个 AABB，不是一万个`

【做】每格一个 `MultiMeshInstance3D`，各自 AABB。

⛔ 只写对 AABB 仍然一刀切：看到一棵就画全部，
性能**不随屏幕覆盖率变化**。

【产出】分块结构 + `CELL_SIZE`

【判据】⚠ 转视角 `Vertices Drawn` **立刻下降**

【审】`audit/godot/vegetation.md#2`

### Step 5　⚠ 分块尺寸与流式单元对齐　`[vegetation/01#S5]`

【读】`howto/godot/vegetation.md#9. 相关文档`

【做】`CELL_SIZE` 与 `openworld.md` 的流式加载单元对齐或成整数倍。

⛔ 两套边界 → 流式加载一个单元时要处理跨界的植被块，
表现为"走到边界时植被闪一下"。

【产出】对齐说明

【判据】⚠ 跨流式单元移动，**植被无闪烁**

【审】`audit/godot/vegetation.md#3`

### Step 6　⛔ 静态植被不每帧刷 buffer　`[vegetation/01#S6]`

【读】`howto/godot/vegetation.md#1. ⚠ MultiMesh 是一个 AABB，不是一万个`

【做】transform 不再变化时只写一次，⛔ 不每帧 `set_instance_transform`。

⛔ 每帧刷 → 白付 CPU→GPU 传输，
而这在实例少时**测不出来**。

【产出】只在变动时写入

【判据】⚠ 静置时，**无 per-frame buffer 写入**

【审】`audit/godot/vegetation.md#24`

## 5. 常见返工

**① 逐个建节点。** 加第二棵前就崩。

**② 不写 custom_aabb。** 背对原点整片消失。

**③ 忘记 grow。** 视锥边缘被切。

**④ 分块尺寸拍脑袋。** 与流式不对齐，边界闪烁。
