> **前置**：01–06 中本次选做的功能点**全部**验收通过
> **本步交付**：**打开调试可视化亲眼看过**全部行为——这是本域唯一有意义的验收
> **对应**：做法 `howto/godot/ai-tactics.md` `ai-perception.md` `ai-behavior.md` `ai-navigation.md` · 审核 `audit/godot/` 同名文件

## 0. 交付物定义

⚠ **各功能点自己的验收清单不能替代本步。**

⚠ **AI 验收必须开着调试可视化看**。
AI 的绝大多数问题不是"崩溃"，而是"**行为不对但代码看着没错**"——
只看代码永远发现不了"为什么它不上"。

做完这一步，应该能**当场演示**：

1. 单个敌人：感知/决策/转移全部符合设计
2. 一群敌人：不挤、轮流攻击、目标不横跳
3. ⚠ 长时间运行（10 分钟）**无泄漏、无集体发呆**
4. ⚠ 20 个敌人时帧率达标
5. 接缝（战斗层、网络层）已确认

**产出物**：
```text
调试可视化下的实测记录
参数登记表已回填（见 00-域流程总览.md 第 4 节）
```

## 2. 工序

### Step 1　个体行为总扫　`[ai/07#S1]`

【读】`howto/godot/ai-behavior.md#5. Idle 不是"什么都不做"`

【做】⚠ **开着调试可视化**逐个确认：

| 场景 | 期望 | 实际 |
|---|---|---|
| 背对玩家站定 | 不被发现 | |
| 正对进入视野 | 被发现 | |
| 隔墙站定 | ⚠ 不被发现（射线生效） | |
| 玩家躲进死角 | 搜索→放弃→返回 | |
| 待机 10 秒 | ⚠ 有微动作（⛔ 不是定格） | |
| 受击 | 立刻中断当前任务 | |

【产出】表格每行有实测结果

【判据】⚠ 每一行都在**开着可视化**的情况下亲眼确认过

【审】`audit/godot/ai-perception.md` `audit/godot/ai-behavior.md`

### Step 2　转移与抖动　`[ai/07#S2]`

【读】`howto/godot/ai-behavior.md#5. Idle 不是"什么都不做"`

【做】⚠ 让敌人在各阈值边界停留 10 秒，**数状态切换次数**。

| 边界 | 期望切换次数 |
|---|---|
| Idle ↔ Alert | < 3 |
| Chase ↔ Attack | < 3 |

⛔ 每帧切换 = 最短驻留没做（回到 03 S3）。

ⓘ 开着可视化看状态标签，⛔ 不要靠"感觉好像没抖"。

【产出】切换次数记录

【判据】⚠ 每个边界 10 秒内**切换 < 3 次**

【审】`audit/godot/ai-behavior.md`

### Step 3　群体行为　`[ai/07#S3]`

【读】`howto/godot/ai-tactics.md#4. 群体协作：攻击令牌`

【做】⚠ 一群敌人（5–10 个）围攻玩家时确认：

| 观察项 | 期望 |
|---|---|
| 站位 | ⚠ 分散（⛔ 不是叠成一团） |
| 同时攻击数 | ≤ 设定值 |
| 目标切换 | ⚠ 不横跳（迟滞生效） |
| 掩体 | ⛔ 两个单位不在同一个掩体 |

【产出】群体行为记录

【判据】⚠ 同时攻击数**不超过设定值**，且**一直有人在攻击**（⛔ 不是集体发呆）

【审】`audit/godot/ai-tactics.md` 第 5/10 条

### Step 4　⚠ 杀戮测试（令牌/掩体回收）　`[ai/07#S4]`

【读】`howto/godot/ai-tactics.md#4. 群体协作：攻击令牌`

【做】⚠ 这是本域**最容易漏、后果最严重**的一项。

逐个杀死敌人（特别是**正在攻击的**、**已预约掩体的**），确认：

- [ ] 杀死正在攻击者 → 其余**立即补上攻击位**
- [ ] 杀死持令牌者（硬直中/动画中）→ 令牌**被回收**
- [ ] 杀死已预约掩体者 → 掩体**超时后释放**
- [ ] 全部杀光再刷新 → 新批次**正常攻击**（⛔ 不是集体不动）

⛔ 只测"正常打完一圈"会漏掉所有泄漏路径。

【产出】杀戮测试记录

【判据】⚠ 杀死任意敌人后，**攻击不中断**

【审】`audit/godot/ai-tactics.md` 第 10 条

### Step 5　长跑与压测　`[ai/07#S5]`

【读】`howto/godot/ai-tactics.md#7. AI 性能预算与 LOD`

【做】三项：

1. **长跑** —— 10 分钟后：威胁表条目稳定、节点数不涨、令牌无累积泄漏
2. **压测** —— 20 个敌人：帧率达标，AI 耗时不平方增长
3. ⚠ **尖峰** —— 帧时间曲线无周期性高峰（分帧已错开）

【产出】10 分钟长跑 + 20 敌人压测记录

【判据】⚠ 10 分钟后各项计数**稳定**；20 敌人**帧率达标**

【审】`audit/godot/ai-tactics.md` 第 15 条

### Step 6　接缝复查　`[ai/07#S6]`

【读】`structure.md#5. 组合模型`

【做】列出本域与其他域的接缝，逐条确认：

| 接缝 | 上游产出 | 下游期望 | 一致? |
|---|---|---|---|
| AI → 战斗 | 攻击意图 + 破绽窗口 | combat 层的硬直/霸体 | |
| AI → 寻路 | 目标点（槽位/掩体） | NavigationAgent 接管 | |
| AI → 感知 | 证据（非 bool） | 决策层消费 | |
| AI → 网络 | ⚠ AI 决策位置 | netsync 的权威归属 | |
| AI → 存档 | 黑板存 id | 读档后 AI 正常 | |
| AI → 性能 | LOD 降级 | 渲染 LOD 不冲突 | |

⚠ **AI 要联机时，决策必须在权威端** ——
⛔ 各客户端各自跑 AI 会导致行为分叉。见 `flow/godot/netsync/` 03。

⚠ **各域合格 ≠ 拼起来能用。**
接缝对不上要单独立适配步骤，⛔ 不要在各处偷偷转格式。

【产出】接缝清单，每行标注"一致"或"已适配"

【判据】⚠ 每行都有明确结论，⛔ 没有"应该没问题"

【审】`audit/godot/ai-tactics.md` 全部条目

## 3. 验收清单（域级总验）

**个体**
- [ ] 背对不被发现、正对被发现、隔墙不被发现

- [ ] 受击能中断当前任务
- [ ] 每个状态边界 10 秒切换 < 3 次

- [ ] 站位分散，不叠成一团
- [ ] 同时攻击数 ≤ 设定值
- [ ] 目标不横跳
- [ ] 不抢同一掩体

- [ ] 10 分钟后威胁表/节点数稳定
- [ ] 20 敌人帧率达标
