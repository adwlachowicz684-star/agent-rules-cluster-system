没有调试可视化，04/05 的每一个参数都是**盲调**。

⚠ **AI 是唯一会随单位数平方级变贵的系统。**
20 个敌人 × 每个每帧检测 20 个目标 = 400 次。

做完这一步，应该能**当场演示**：

1. 打开调试总开关，能看到状态 / 视锥 / 路径 / 令牌持有者

4. ⚠ 20 个敌人时 AI 耗时**不随数量平方增长**
5. ⚠ 没有"所有敌人同一帧一起决策"的尖峰

## 2. 工序

### Step 1　三条正交的省法　`[ai/06#S1]`

【读】`howto/godot/ai-tactics.md#7. AI 性能预算与 LOD`

【做】

| 手段 | 做法 |
|---|---|
| **降低频率** | 感知 10Hz 通常够；远处单位 2–4Hz |
| **分帧** | 每帧只更新 N 个 AI，其余排队 |
| **LOD 降级** | 远处/屏幕外：关避障、关感知细节、只跑简化巡逻 |

⚠ **三条是正交的**，可以同时用；
⛔ 但不要以为用了分帧就不需要降频率——分帧只是摊平尖峰。

【产出】至少两条已实现

【判据】⚠ 20 个敌人时，单帧 AI 耗时**有上限**（⛔ 不是随数量线性涨）

【审】`audit/godot/ai-tactics.md#15` `audit/godot/ai-tactics.md#17`

### Step 2　⚠ 分帧要错开　`[ai/06#S2]`

【读】`howto/godot/ai-tactics.md#7. AI 性能预算与 LOD`

【做】⚠ **分帧不能让 AI "变笨得不一致"** ——
⛔ 每个单位每 5 帧才思考一次，但**第几帧**要错开（按 id 取模），
否则会出现"**所有敌人同一帧一起决策**"的尖峰。

```gdscript
func _should_tick(id: int) -> bool:
    return (Engine.get_physics_frames() + id) % _stride == 0
```

【产出】按 id 错开

【判据】⚠ 看帧时间曲线，**无周期性尖峰**（⛔ 不是每 N 帧一个高峰）

【审】`audit/godot/ai-tactics.md#15`

### Step 3　⚠ LOD 切换要有迟滞　`[ai/06#S3]`

【读】`howto/godot/ai-tactics.md#7. AI 性能预算与 LOD`

【做】⚠ **LOD 切换要有迟滞**，否则单位在边界反复切换时行为会跳变
（正在攻击的**突然降级成巡逻**）。

ⓘ 迟滞做法：升级用距离 A，降级用距离 B（B > A）。

⚠ 还要考虑：**战斗中的单位不应降级**。
否则玩家拉远视角就能让敌人变笨——这是可利用的漏洞。

【产出】LOD 有迟滞 + 战斗中不降级

【判据】⚠ 单位在 LOD 边界来回移动 10 秒，**行为不跳变**

【审】`audit/godot/ai-tactics.md#16`

### Step 4　动态开关避障　`[ai/06#S4]`

【读】`howto/godot/ai-navigation.md#7. 群体避障（RVO）`

【做】⚠ 官方明确：*"Avoidance processing with many registered agents has a
**significant performance cost** and should only be enabled on agents that
currently require it."*

✅ 只对**近处且在移动中**的单位开。

⚠ 关闭 `avoidance_enabled` 时 `velocity_computed` **不触发** ——
如果你把所有移动都写在信号回调里，关掉避障后敌人就**完全不动了**。
⛔ 这是"做完 LOD 后远处敌人不动"的根因。

【产出】避障动态开关 + 移动代码不依赖信号（有 fallback）

【判据】⚠ 关掉远处避障后，远处敌人**仍能移动**（⛔ 不是定住）

【审】`audit/godot/ai-navigation.md#10`

### Step 5　调试可视化四类必画　`[ai/06#S5]`

【读】`howto/godot/ai-tactics.md#8. AI 调试可视化`

【做】⚠ **没有可视化调试的 AI 系统，调参会变成猜谜。**

| 画什么 | 作用 |
|---|---|
| 当前状态 / 行为树活动节点 | 知道"它现在在想什么" |
| 视锥与感知射线 | 知道"它到底看没看见" |
| 路径与当前目标点 | 知道"它要去哪" |
| 令牌持有者 / 槽位分配 | 知道"为什么它不上" |

ⓘ **导航路径不用自己画** ——
`NavigationAgent` 有 `debug_enabled` + `debug_path_custom_color`，
见 `howto/godot/ai-navigation.md#8. 官方明确列出的路径跟随坑`。

【产出】四类可视化 + 导航用内建

【判据】⚠ 打开后能回答"这个敌人现在为什么不攻击"

【审】`audit/godot/ai-tactics.md#18` `audit/godot/ai-perception.md#15`

### Step 6　⚠ 调试默认关　`[ai/06#S6]`

【读】`howto/godot/ai-tactics.md#8. AI 调试可视化`

【做】⚠ **调试可视化要有总开关，且默认关。**
一屏 20 个视锥会看不清画面，也会**掩盖真实渲染问题**。

ⓘ 建议绑到 Debug 绘制开关或自定义快捷键，
并确保导出包里**不会误开**。

【产出】总开关 + 默认关 + 导出包不误开

【判据】⚠ 导出包运行，**无调试绘制**（除非显式开）

【审】`audit/godot/ai-tactics.md#19`

## 3. 参考实现

```gdscript
class_name AILod
extends Node

@export var near_dist := 15.0
@export var far_dist := 40.0
@export var tick_hz_near := 10.0
@export var tick_hz_far := 2.0

func evaluate(unit, dist: float, in_combat: bool) -> Dictionary:
    var lod := 0
    if dist > far_dist and not in_combat:
        lod = 2                       # ⚠ 战斗中不降级
    elif dist > near_dist:
        lod = 1
    return {
        tick_hz = tick_hz_far if lod == 2 else tick_hz_near,
        avoidance = (lod == 0),       # ⚠ 只有近处开避障
        full_perception = (lod < 2),
    }
```

⚠ 注意 `in_combat` 参与判断——
只按距离降级会让"拉远视角"成为可利用的漏洞。
