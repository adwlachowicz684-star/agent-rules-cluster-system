# 05 布料与软体（destruction 域）

> **前置**：01 完成（与 02–04 并行可做）
> **本步交付**：**会飘的布料 / 软体，且不穿模、不塌陷、不接管动画**
> **对应**：做法 `howto/godot/destruction-cloth.md#3. 布料：优先动画，SoftBody3D 只用于必要变形`
> 　　　审核 `audit/godot/destruction-cloth.md#8`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：布会动。**

⛔ 常见假完成：给角色衣服挂 `SoftBody3D`，看到会晃就交付。
⚠ 官方口径明确：软体**适合旗帜、软垫、果冻**，
**不适合任意角色服装、长绳索、关卡机制**。

做完这一步，应该能**当场演示**：

1. ⛔ `SoftBody3D` 只用在真正需要变形的地方
2. ⛔ `simulation_precision` **不低于 5**
3. ⛔ 非封闭网格的 `pressure_coefficient` **为 0**
4. ⛔ 设了 `Parent Collision Ignore`（否则穿模）
5. ⚠ 钉固点用 `attachment_path` 依附骨骼

**产出物**（下游按名字对接）：

```text
SoftBodyConfig: precision, pressure, stiffness, parent_collision_ignore
钉固点：attachment_path 指向 BoneAttachment3D
```

## 1. 前置检查清单

- [ ] ⚠ 已确认这个布料**是否真的需要**物理（动画能不能做）
- [ ] 网格是否封闭（决定 pressure 能不能 > 0）
- [ ] 已知软体不受物理插值影响
- [ ] 已确认引擎与版本（4.7 软体参数变了）

## 2. 工序

### Step 1　⛔ 优先用动画，SoftBody3D 只用于必要变形　`[destruction/05#S1]`

【读】`howto/godot/destruction-cloth.md#3. 布料：优先动画，SoftBody3D 只用于必要变形`

【做】角色服装走骨骼/动画，只有旗帜、软垫、果冻这类才用软体。

⛔ 给任意角色服装上软体 →
⚠ 官方明确不适合，且 `SoftBody3D` **不能替代 `AnimationPlayer` 或骨骼**
（不响应动画轨道形变目标）。
⛔ 长绳索要走 `Joint3D` / `Generic6DOFJoint3D` 链、骨骼布娃娃或离线模拟。

【产出】"哪些用软体"的清单（应尽量短）

【判据】⚠ 清单上的每一项都能说出"为什么动画做不到"

【审】`audit/godot/destruction-cloth.md#9`

### Step 2　⛔ simulation_precision 不低于 5，否则塌陷　`[destruction/05#S2]`

【读】`howto/godot/destruction-cloth.md#6. 软体：官方教程里的四条硬警告`

【做】`soft.simulation_precision = 5`（源码范围 1–100，默认 5）。

⛔ 为了省性能调低 → 官方原话 *"the soft body may **collapse**"*。
⚠ 症状是"软体自己塌成一团"，⛔ 极易被当成参数没调好而反复改 stiffness，
越改越糟。

【产出】精度下限约定

【判据】⛔ 所有软体的 precision ≥ 5

【审】`audit/godot/destruction-cloth.md#20`

### Step 3　⛔ 网格未封闭时 pressure 必须为 0　`[destruction/05#S3]`

【读】`howto/godot/destruction-cloth.md#6. 软体：官方教程里的四条硬警告`

【做】只有确认网格完全封闭，`pressure_coefficient` 才允许 > 0。

⛔ 未封闭网格 + pressure > 0 → 官方原话
*"the soft body will **fly around like a plastic bag under strong wind**"*。
⛔ 症状极具迷惑性：看起来像物理引擎坏了，其实只是网格没封口。

【产出】每个软体的"网格是否封闭"标注

【判据】⛔ 非封闭网格的 pressure 均为 0

【审】`audit/godot/destruction-cloth.md#21`

### Step 4　⛔ 必须设 Parent Collision Ignore，否则与父物体穿模　`[destruction/05#S4]`

【读】`howto/godot/destruction-cloth.md#11. 软体：父碰撞忽略、钉固点依附、4.7 质量默认值变更`

【做】把父角色（场景根的物理体）填进 `Parent Collision Ignore`。

⛔ 不设 → **披风与角色穿模/抖动**。
ⓘ 官方教程把这一步放在**最后一步**，不做则前面全对也白搭。
⚠ 症状极易被误判成"软体参数没调好"，于是反复调 stiffness，越调越糟。

【产出】每个软体的 `parent_collision_ignore`

【判据】⛔ 角色跑动时披风**不穿模**

【审】`audit/godot/destruction-cloth.md#32`

### Step 5　⚠ 钉固点用 attachment_path 依附骨骼，不要挪节点　`[destruction/05#S5]`

【读】`howto/godot/destruction-cloth.md#11. 软体：父碰撞忽略、钉固点依附、4.7 质量默认值变更`

【做】用 `set_point_pinned` 的 `attachment_path`（编辑器：Attachments →
Spatial Attachment Path）指向 `BoneAttachment3D`。

⛔ 把 `SoftBody3D` 直接挪到 `BoneAttachment3D` **下面** → 官方明确不要这么做。
⚠ 表现为披风不跟随骨骼，或跟随了但物理行为异常。

【产出】钉固点配置

【判据】⚠ 角色动时披风钉固点**跟着骨骼走**

【审】`audit/godot/destruction-cloth.md#33`

## 5. 常见返工

**① 角色服装也上软体。** 不响应动画。

**② 调低 precision 省性能。** 塌陷。

**③ 未封闭网格开 pressure。** 像塑料袋乱飞。

**④ 不设父碰撞忽略。** 穿模，且误判为参数问题。
