## 0. 交付物定义

⚠ **各功能点自己的验收不能替代域级验收。**
部件全合格、拼起来不能用，是跨域开发的典型失败——
宝石尤其如此，它横跨 economy / inventory / class-awaken / save / netsync 五个域。

做完这一步，应该能**当场演示**并**签核**：

1. 01 定义的三个证明场景全部成立
2. ⚠ **失败路径实测**：扣费后提交失败，宝石与金币完整退回
3. ⚠ **资产保全实测**：全流程宝石总数与金币不减少
4. ⚠ **套利实测**：穷举合成/拆卸无产出 > 投入的路径
5. ⚠ **接缝复查**：与 economy / inventory / class-awaken 的契约全对上

### Step 3　⚠ 资产保全实测　`[gem/07#S3]`

```text

每个节点记录一次；只允许因"合成消耗"按规则减少，

```

【产出】资产流水表

【判据】⚠ 全流程的每一次减少**都能对应到一条明示规则**
