## 0. 交付物定义

⚠ 与 `economy.md` 的 `EquipmentBase / EquipmentInstance` **同构**。
⛔ 不要另发明第三套——做"宝石与装备联动"时要写两份适配。

做完这一步，应该能**当场演示**：

1. 配表改一颗宝石的数值，**所有已镶嵌的**该宝石随之变化
2. 两颗同级宝石，**各自升级互不影响**
3. ⚠ 插槽类型不匹配时，**明确报错**而不是列表为空
4. 宝石是 `Resource`，能被 `ResourceSaver` 存档

**产出物**（下游按名字对接）：

```text
GemBase:      gem_id / tier / mods[{stat,value,op}] / socket_type
GemInstance:  gem_id / instance_id / tier
SocketSlot:   index / socket_type / gem_instance_id（-1=空）
```

## 2. 工序

### Step 1　⛔ 必须是 Resource 不是 Node　`[gem/02#S1]`

【读】`howto/godot/gem-rune.md#1. 宝石是 Resource，不是 Node`

【做】`GemBase extends Resource`、`GemInstance extends Resource`。

⛔ 做成 Node 的后果：Node 带 `_process` / 树路径 / 父子关系，
序列化会带上整棵子树，且**不能被 `ResourceSaver` 直接存**。

【产出】两个 Resource 类

【判据】⚠ `ResourceSaver.save()` 能存、能读回，且读回后字段相等

【审】`audit/godot/gem-rune.md#1`

### Step 2　⚠ 插槽数来自装备实例　`[gem/02#S2]`

【读】`howto/godot/gem-rune.md#2. 插槽：数量来自装备，类型来自配表`

【做】插槽数是 `EquipmentInstance` 的属性，⛔ 不是全局常量。

⛔ 做成常量的话"高级装备孔多"这条设计无法实现。

【产出】`EquipmentInstance.sockets: Array[SocketSlot]`

【判据】⚠ 两件不同装备能有**不同数量**的插槽

【审】`audit/godot/gem-rune.md#2`

### Step 3　⛔ 插槽类型只许两处赋值　`[gem/02#S3]`

【读】`howto/godot/gem-rune.md#2. 插槽：数量来自装备，类型来自配表`

【做】`socket_type` 只允许**配表导入**与**实例反序列化**两处赋值。

⚠ 常见坑：装备说"红槽"、宝石说"可插红槽"，两边字符串不一致
→ 永远插不进去，而且**没有报错**（只是列表为空）。

【产出】匹配函数单一入口

【判据】⚠ 搜索 `socket_type` 的赋值处，**只有两处**

【审】`audit/godot/gem-rune.md#3`

### Step 4　⚠ mods 用 op 字段表达加/乘　`[gem/02#S4]`

【读】`howto/godot/gem-rune.md#7. 属性并入统一管线`

【做】`mods: [{stat, value, op}]`，`op` 取 `add` / `mul`。

⛔ 只支持 `add` 的话，"暴击伤害 +30%"这类百分比无法表达，
后期要加 `mul` 时所有配表都要改结构。

【产出】`mods` 结构含 `op`

【判据】⚠ 同一颗宝石能同时表达 `+10 攻击` 与 `×1.3 暴伤`

【审】`audit/godot/gem-rune.md#4`

### Step 5　⚠ 空槽用 -1 而非 null　`[gem/02#S5]`

【读】`howto/godot/gem-rune.md#2. 插槽：数量来自装备，类型来自配表`

【做】`gem_instance_id = -1` 表示空。

ⓘ 用 `null` 在序列化/网络传输里更容易出问题，
且判空写法不统一（`== null` vs `is_valid()`）。

【产出】空槽哨兵值 -1

【判据】⚠ 全项目对空槽的判断写法**只有一种**

【审】`audit/godot/gem-rune.md#4`

## 5. 常见返工

**① 做成 Node。** 存不了档、进不了网络包。

**② 插槽数全局常量。** "高级装备孔多"做不了。

**③ `socket_type` 到处赋值。** 字符串不一致 → 静默插不进去。

**④ mods 只支持 add。** 百分比后期加不进去。
