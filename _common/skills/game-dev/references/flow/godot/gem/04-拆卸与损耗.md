## 0. 交付物定义

⚠ **拆卸是镶嵌的逆操作，但它比镶嵌更容易丢东西**——
因为产出物要**回到背包**，而背包可能已满。

⛔ "拆下来直接进背包"在背包满时会静默丢弃，
这是本域最典型的资产事故：**不崩溃、不报错，只是东西没了**。

做完这一步，应该能**当场演示**：

1. ⚠ 背包满时点拆卸 → **整个操作失败**，宝石仍在原装备上
2. 拆卸确认弹窗里能**直接读到**损耗规则
3. 损耗后宝石等级/状态**与文案一致**
4. 拆卸后属性**立即重算**（面板当场变化）
5. ⚠ 拆卸也走事务：失败时原装备状态不变

**产出物**（下游按名字对接）：

```text
try_unsocket(p, equip, slot_idx) -> {ok, reason?, preview?}
  preview 含：返还的宝石实例 / 损耗后的 tier / 消耗的金币
```

## 2. 工序

### Step 1　⚠ 三选一并写进文档　`[gem/04#S1]`

【读】`howto/godot/gem-rune.md#4. 拆卸与损耗`

【做】定免费无损 / 付费无损 / 有损耗，**写进域文档**。

| 方案 | 后果 |
|---|---|
| 免费无损 | 一套宝石全服通用，养成深度消失 |
| 付费无损 | 可控，但要给明确价格 |
| 有损耗 | 养成压力最大，⛔ **必须明示规则** |

⛔ 不选就默认成了"免费无损"，因为没写规则的代码就是什么都不做。

【产出】方案 + 书面记录

【判据】⚠ 新人不看代码、只看文档，**能说出是哪种**

【审】`audit/godot/gem-rune.md#8`

### Step 2　⚠ 损耗必须在 UI 明示　`[gem/04#S2]`

【读】`howto/godot/gem-rune.md#4. 拆卸与损耗`

【做】确认弹窗里写清：降级 / 销毁 / 付费多少。

⛔ 不明示的话，玩家拆出一颗降级宝石会认为是 bug，
且这类投诉**无法自证清白**——没有日志能证明"这是设计如此"。

【产出】确认弹窗含损耗规则

【判据】⚠ 不打开其他界面、只看弹窗，**也能知道代价**

【审】`audit/godot/gem-rune.md#8`

### Step 3　⛔ 拆卸前先预检背包容量　`[gem/04#S3]`

【读】`howto/godot/gem-rune.md#4. 拆卸与损耗`

【做】**在扣费之前**校验背包能否容纳返还物。

⛔ 先拆后放、放不下再丢弃 = 宝石静默消失。
ⓘ 与 `inventory.md` 的移动事务同源：试算阶段就要知道容量。

【产出】容量预检在试算阶段

【判据】⚠ 背包满时点拆卸，**宝石仍在原装备上**（不是消失了）

【审】`audit/godot/gem-rune.md#24`

### Step 4　⚠ 拆卸也走事务　`[gem/04#S4]`

【读】`howto/godot/gem-rune.md#3. 镶嵌是事务：顺序不能错`

【做】拆卸复用 03 的五段骨架：校验→试算→扣费→提交→回滚。

⛔ 拆卸写成"两步独立操作"（移除 + 入包）的话，
第二步失败时宝石已经离开装备、还没进背包 = **彻底消失**。

【产出】拆卸调用同一事务骨架

【判据】⚠ 注入异常让入包失败，**宝石回到原插槽**

【审】`audit/godot/gem-rune.md#6`

### Step 5　⚠ 损耗后的实例状态与文案一致　`[gem/04#S5]`

【读】`howto/godot/gem-rune.md#5. 合成：等级与数量`

【做】若损耗是降级，则 `GemInstance.tier` 实际减少；若是销毁，则实例被移除。

⛔ 文案说"降级"而代码没改 `tier` → 玩家看到的等级没变，
会认为"文案骗人"；反向则更严重（说无损实际降级）。

【产出】损耗规则与实例状态一一对应

【判据】⚠ 逐条比对文案与实例 `tier`，**完全一致**

【审】`audit/godot/gem-rune.md#10`

### Step 6　⚠ 拆卸后立即重算　`[gem/04#S6]`

【读】`howto/godot/gem-rune.md#7. 属性并入统一管线`

【做】拆卸成功立即调用属性重算。

⛔ 不刷缓存 → 面板还显示有加成的数字 → 玩家以为没拆成功 → 再拆一次。

【产出】拆卸后的缓存失效调用

【判据】⚠ 拆卸后不切场景，**面板数字当场变化**

【审】`audit/godot/gem-rune.md#19`

## 5. 常见返工

**① 先拆后放、放不下就丢。** 静默资产丢失。

**② 损耗不明示。** 投诉无法自证清白。

**③ 拆卸不走事务。** 入包失败时宝石彻底消失。

**④ 不刷缓存。** 玩家以为没拆成 → 再拆。
