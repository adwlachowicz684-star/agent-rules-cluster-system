# 动画进阶（AnimationTree） —— 域流程总览

> ⚠ **第 0 步：先定"谁拥有位移、谁拥有姿势"。**
> 本域有 7 个功能点，⛔ **不是全做** —— 按本次需求挑。

## 0. 先定做什么

| 本次要做的 | 走哪些功能点 |
|---|---|
| 角色状态机与移动混合 | 01 → 02 → 07 |
| 精确位移的动作游戏（根运动） | 01 → 03 → 07 |
| "下半身跑、上半身开火"分层 | 01 → 04 → 07 |
| 脚部贴地 / 持枪手部 IK / 头部朝向 | 01 → 05 → 07 |
| 同屏大量角色 | 01 → 06 → 07 |
| 全套动画管线 | 01 → 02 → 03 → 04 → 05 → 06 → 07 |

⛔ **01 不能跳过** ——
状态机、混合空间、分层、IK 的技术形态差异很大，
但**"谁拥有姿势"**这一件事必须在动工前定死。
⛔ 不先定，就会出现"代码也在改 transform、树也在改 transform"，
表现为位移翻倍或骨骼抖动，而每一处单看都对。

⛔ **03 的核心不是"启用根运动"，是位移归属的转移**：
先做表现后定归属，会在启用物理插值、接入网络同步时成片返工。

⛔ **05 的 IK 要在美术铺开之前定清"谁负责最终位置"**：
IK 与根运动同时改骨骼时，位置与骨骼修正会互相打架，
⛔ 表现为"脚陷进地里"或"手抖"，而两者单独跑都正常。

ⓘ 若本次只是**"加一个待机动画、连两条过渡"**，那是资源配置，不套本域。
ⓘ 若只是**排查动画不播**，先按本文 §8 的三个覆盖默认值自查，再回本域 01。

ⓘ 分工：
- `howto/godot/animation-advanced.md` 讲**各机制的技术做法**（状态机、混合空间、根运动、IK、分层）
- `howto/godot/animation.md` 讲**基础播放与 Tween**
- 本域讲**这些机制按什么顺序做、怎么保证换场景换版本后仍然对**

⛔ 若本域某步需要"过渡时间""IK 迭代次数""同屏角色上限"这类细节，
指向项目实测，⛔ 不在这里编数字。

## 1. 功能点拆解（按依赖，不可颠倒）

| # | 功能点 | 依赖 | 交付物 |
|---|---|---|---|
| 01 | 状态机与姿势归属地基 | — | 归属清单 + Start 节点口径 + 三个覆盖默认值确认 |
| 02 | 混合空间与参数驱动 | 01 | 连续量映射 + 轨道类型口径 + 确定性初值 |
| 03 | 根运动与位移归属 | 01 | 单一驱动口径 + 朝向换算 + 插值与同步口径 |
| 04 | 分层遮罩与叠加 | 01, 02 | 轨道过滤清单 + 叠加权重口径 |
| 05 | IK 与贴地瞄准 | 01, 03 | 最终位置归属 + 生效时机 + LOD 关卡 |
| 06 | 性能与大量角色 | 01–05 | 资源共享口径 + LOD 降级清单 + 帧预算 |
| 07 | 动画验收 | 全部 | 敌意环境实测 + 混合边界实测 |

⚠ **01 必须在连第一条过渡之前**：
先连图再回头定归属，每条过渡都要重核一遍"这个状态会不会改位移"。

⚠ **04 的轨道过滤要在美术给出上半身动画之前**：
过滤清单直接决定骨骼命名规范，
⛔ 先做完动画再补过滤，等于重导一遍资源。

⚠ **06 的资源共享口径要随功能点同步写，不能最后统一补**：
补的时候会顺手把"改树参数"也当成安全操作，
表现为"改一个敌人全场一起变"，而没人知道是哪次引入的。

## 2. 与其他域的接缝

> ⚠ **组合的真正难点不是单个动画，是接缝。**
> 下面每条都必须能指认到具体符号或字段，⛔ 不能是"做完了"。

| 接缝 | 契约 |
|---|---|
| `character` 域 角色控制 | 移动与碰撞见 `character`，⛔ 本域只定**位移由谁产出** |
| `companion` 域 宠物坐骑 | reparent 时序见 `companion`，⛔ 本域只定 reparent 后 IK 会失效 |
| `firearms` 域 枪械 | 开火动画与上半身分层见 `firearms`，⛔ 本域只定分层过滤口径 |
| `physics` 域 物理 | 物理插值与 `reset_physics_interpolation` 见 `physics`，⛔ 根运动要引用该口径 |
| `netsync` 域 网络同步 | 动画状态同步内容见 `netsync`，⛔ 本域只定"哪些参数必须同步" |
| `perf` 域 性能 | 同屏角色的帧预算见 `perf`，⛔ 本域只定 LOD 降级清单，不编数量 |
| `mobile` 域 移动端 | 移动端骨骼数与内存预算见 `mobile`，⛔ 本域不另定移动端口径 |
| `cosmetic` 域 外观 | 换装后的骨骼重定向见 `cosmetic`，⛔ 本域不定义外观资产 |
| `animation` | ⓘ howto 层，暂无 flow 域 —— 基础播放与 Tween 见该篇 |
| `3d` | ⓘ howto 层，暂无 flow 域 —— 骨骼与模型导入见该篇 |

## 3. 参数登记

| 参数 | 所在功能点 | 初始值 | 实测值 | 状态 |
|---|---|---|---|---|
| `MAX_SPEED` 归一时参考速度 | 02 | — | — | 待实测（与角色移动速度相关） |
| `XFADE_TIME` 状态过渡时间 | 01 | 0.0（引擎默认） | — | 待实测（⛔ 默认 0.0 即硬切） |
| `IK_INFLUENCE` IK 影响强度 | 05 | — | — | 待实测（与骨骼链长度相关） |
| `IK_MAX_ITER` IK 解算迭代上限 | 05 | 10（引擎默认） | — | 待实测 |
| `IK_MIN_DISTANCE` 解算停止距离 | 05 | 0.01（引擎默认） | — | 待实测 |
| `IK_DISABLE_DISTANCE` 关闭 IK 的距离 | 06 | — | — | 待实测（与同屏人数与帧预算相关） |
| 分层过滤的骨骼清单 | 04 | — | — | 待实测（⛔ 由骨骼命名规范决定，不由本域编） |

⛔ 上表"待实测"项**不得凭行业惯例填** ——
填错不会报错，只会表现为"偶发穿地""偶发抖动""偶发全场一起变"，
⛔ 而这类偶发在测试环境几乎不出现。
