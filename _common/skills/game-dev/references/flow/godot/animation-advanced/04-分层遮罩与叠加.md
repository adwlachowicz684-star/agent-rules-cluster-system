# 04 分层遮罩与叠加（动画进阶域）

> **本步交付**：轨道过滤清单 + 叠加权重口径
> **对应**：流程 `howto/godot/animation-advanced.md` · 审核 `audit/godot/animation-advanced.md`

## 0. 交付物定义

1. 每层的骨骼过滤清单已写下（⛔ 不是"全选"）
2. 叠加类节点（`Add2` / `Add3` / `Sub2`）的权重口径已结合 `deterministic` 确认
3. 权重大于 1.0 的用法已逐处登记
4. 缺轨道的动画在混合中的行为已确认
5. 分层与 03 的根运动位移归属已对照

## 1. 前置检查清单

- [ ] 每层都有明确的骨骼过滤清单
- [ ] 用了 Add 类节点的地方都记了权重口径
- [ ] 权重 > 1.0 处已逐处登记
- [ ] 缺轨道的行为已确认
- [ ] 与根运动位移的对照已写

## 2. 工序

### Step 1　分层必配轨道过滤，⛔ 不是连上 Blend2 就完　`[animation-advanced/04#S1]`

【读】`howto/godot/animation-advanced.md#5. 分层与遮罩`

【做】
每一层写下**参与混合的骨骼清单**（轨道过滤）。
⛔ 不做过滤 —— 得到的是**全身混合**，
表现为"上半身开火动作被下半身跑步稀释"，
⛔ 而混合节点连对了、amount 也给了，每一处单看都对。

ⓘ 这条要在美术给出上半身动画之前定：
⛔ 过滤清单直接决定骨骼命名规范，先做完动画再补过滤等于重导一遍资源。

【产出】逐层骨骼过滤清单

【判据】上半身播放开火、下半身播放跑步时，两个动作各自完整。

【审】`audit/godot/animation-advanced.md#11`、`audit/godot/animation-advanced.md#30`

### Step 2　叠加类节点的权重先算一遍，⛔ 不是给了 1.0 就期望叠加　`[animation-advanced/04#S2]`

【读】`howto/godot/animation-advanced.md#⛔ deterministic 为 true 让 Add 类节点效果减半`

【做】
凡用 `Add2` / `Add3` / `Sub2` 处，先按 `deterministic` 的口径算出实际结果。
⛔ 不核算 —— 官方明确举例：
Add2 混合两个 amount 为 1.0 的节点，总权重 2.0 却**被归一化回 1.0**，
结果等于 `AnimationNodeBlend2` 取 **0.5**。
⛔ 表现为"叠加调了没反应 / 效果只有一半"，
而节点连对了、amount 明明是 1.0，**且不报错**。

ⓘ 这是 01/S3 那条覆盖默认值在分层处的具体后果：
⛔ 不先确认 `deterministic`，这里必然出现"效果减半"且无法归因。

【产出】叠加节点清单 + 每处的期望权重与实际权重对照

【判据】实测叠加结果等于按口径算出的值；⛔ 没有"应该差不多"。

【审】`audit/godot/animation-advanced.md#18`、`audit/godot/animation-advanced.md#19`

### Step 3　权重大于 1.0 的用法逐处登记　`[animation-advanced/04#S3]`

【读】`howto/godot/animation-advanced.md#⛔ deterministic 为 true 让 Add 类节点效果减半`

【做】
所有权重 > 1.0 的混合逐处登记，并写下它在 `deterministic` 下的实际结果。
⛔ 不登记 —— 官方把"权重大于 1.0"与 Add 类节点并列为
**可能产生意外结果**的两种情况，
⛔ 表现为"调大权重反而变淡"，
而权重面板上的数字确实变大了，排查被引向"是不是节点连错了"。

ⓘ 这类问题在单层调试时**完全正常**（只有一层，归一化不改变相对关系），
⛔ 只在多层叠加后才现形，所以分层做完必须重新核算一遍。

【产出】权重 > 1.0 的登记清单（含实测结果）

【判据】多层叠加下，调大权重的效果单调且符合预期。

【审】`audit/godot/animation-advanced.md#18`、`audit/godot/animation-advanced.md#35`

### Step 4　缺轨道的动画在混合中的行为　`[animation-advanced/04#S4]`

【读】`howto/godot/animation-advanced.md#⛔ deterministic 为 true 让 Add 类节点效果减半`

【做】
确认"混合动画之间轨道数不同"时的行为：
`deterministic = true` 下缺轨道的动画**按初值参与**；
`false` 下**跳过不做处理**。
⛔ 不确认 —— 表现为"某条动画只改了一半属性"或"混合后某属性被拉回初始值"，
⛔ 而这条动画单独播放完全正常，排查被引向动画导出。

ⓘ 这与 01/S5 的 RESET 是同一条链：
⛔ `deterministic = true` 且总权重为 0 时结果等于 RESET 动画，
所以要改的是初值来源，不是逐条补轨道。

【产出】轨道差异清单 + 缺轨道时的处理口径

【判据】任意两条轨道数不同的动画混合，结果可复现。

【审】`audit/godot/animation-advanced.md#35`、`audit/godot/animation-advanced.md#36`

### Step 5　分层与根运动位移的对照　`[animation-advanced/04#S5]`

【读】`howto/godot/animation-advanced.md#root_motion_local 与混合前后的位移`

【做】
写下"分层是否影响根运动取值的哪一段"。
⛔ 不对照 —— 叠加层一开位移就变多/变少，
⛔ 而每个动画单独播位移都精确，排查被引向动画资源。
ⓘ 与 03/S3 是同一条，本步只做**回路确认**：
分层改动后回 03 复核一次取值口径。

【产出】分层 ↔ 根运动取值的对照一行结论

【判据】叠加层开关时，基础位移量符合 03/S3 的结论。

【审】`audit/godot/animation-advanced.md#27`、`audit/godot/animation-advanced.md#30`

## 3. 参考实现
```gdscript
# ⓘ 承接 04/S1、S2：分层混合前确认权重口径
const AIM_AMOUNT := 1.0

func set_aim(amount: float) -> void:
    # ⓘ deterministic 下 Add 类会归一化，此处的实际叠加量按 04/S2 口径核算
    tree["parameters/AimBlend/blend_amount"] = clampf(amount, 0.0, AIM_AMOUNT)
```

## 5. 常见返工
| 症状 | 原因 | 回到 |
|---|---|---|
| 上半身动作被稀释 | 没做轨道过滤 | S1 |
| 叠加效果只有一半 | deterministic 归一化 | S2 |
| 调大权重反而变淡 | 权重 > 1.0 未登记 | S3 |
| 某属性被拉回初值 | 缺轨道行为未确认 | S4 |
| 叠加层一开位移变多 | 未与 03 对照 | S5 |
