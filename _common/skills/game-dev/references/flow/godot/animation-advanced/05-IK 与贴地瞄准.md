## 2. 工序

### Step 1　先确认 IK 节点的弃用状态　`[animation-advanced/05#S1]`

【读】`howto/godot/animation-advanced.md#9. IK 节点：已弃用 + 三个生效时机`

【做】
确认所用的 IK 节点：官方对 `SkeletonIK3D` 的标注是 **Deprecated**
（*"might be removed in a future release"*），
其 `interpolation` 同样 deprecated，官方指向 `SkeletonModifier3D.influence`。
⛔ 不确认 —— 新代码写在一个随时可能被移除的类上，
⛔ 而它在当前版本**能跑能看**，没有任何提示。

ⓘ 头部朝向要用 `LookAtModifier3D`；
⛔ 4.7 起 `LookAtModifier3D.relative` 默认从 `true` 改为 `false`，
已配好的瞄准/IK 需重核 ——
表现为"升级后头部朝向偏了"，而配置一个字没改。

【产出】IK 节点选型表（含 deprecated 标记与替代方案）

【判据】无新代码使用被标注 deprecated 的 API。

【审】`audit/godot/animation-advanced.md#22`、`audit/godot/animation-advanced.md#23`

### Step 2　三个生效时机逐条写下　`[animation-advanced/05#S2]`

【读】`howto/godot/animation-advanced.md#9. IK 节点：已弃用 + 三个生效时机`

【做】
写下三条：`start()` **下一帧才生效**；
`start(true)` 立即但下一帧重置；`stop()` 会调用
`clear_bones_global_pose_override()` 清除**全部骨骼**的 override。
⛔ 不知道 —— 表现为三类：
"第一帧 IK 没生效"、"一次性 IK 第二帧就没了"、
**"关掉脚部 IK，手部 IK 也失效了"**。

ⓘ 第三条最容易误判：
⛔ 清的是**所有骨骼**的 override，不是这条链，
所以别处设的 override 会一起被清，
而关 IK 的代码看起来完全正确（就是在关自己）。

【产出】三条生效机时的记录 + 每类症状的对应方式

【判据】同一骨架上两条 IK 链，关掉一条不影响另一条。

【审】`audit/godot/animation-advanced.md#24`、`audit/godot/animation-advanced.md#25`、`audit/godot/animation-advanced.md#31`

### Step 3　influence 的关闭阈值与连带影响　`[animation-advanced/05#S3]`

【读】`howto/godot/animation-advanced.md#9. IK 节点：已弃用 + 三个生效时机`

【做】
用 `influence <= 0.01` 作为"视觉关闭"的口径（官方明确该阈值会清 override）。
⛔ 用"不调用 start()"代替关闭 —— 已在运行的 IK 不会停，
⛔ 表现为"想关但关不掉"，而代码里确实没有启动语句。

ⓘ 反向一条：
⛔ 用 `stop()` 做"临时关一下再开"会连带清掉别处 override（见 S2），
所以"临时关"与"永久关"要区分实现。

【产出】关闭方式的选取口径（临时关 / 永久关 各一种）

【判据】临时关后重开，别处 override 仍在。

【审】`audit/godot/animation-advanced.md#25`、`audit/godot/animation-advanced.md#31`

### Step 4　reparent 后 IK 不会重新绑定　`[animation-advanced/05#S4]`

【读】`howto/godot/animation-advanced.md#9. IK 节点：已弃用 + 三个生效时机`

【做】
凡有 reparent 的场景（骑乘、附身、换父节点），写下**重绑方案**。
⛔ 不安排 —— `get_parent_skeleton()` 返回的是 **IK 进入场景树时**的父节点，
若那时父节点不是 `Skeleton3D` 则返回 `null`，**之后不重新绑定**。
⛔ 表现为"骑上坐骑后脚部 IK 失效"，
而 IK 节点本身正常、骨骼名也没改。

ⓘ 与 `companion` 域的接缝：
⛔ reparent 时序在 `companion` 域，本域只定"reparent 后必须重绑 IK"这一条。

【产出】reparent 场景清单 + 重绑实现点

【判据】reparent 后脚部仍贴地。

【审】`audit/godot/animation-advanced.md#26`

### Step 5　LOD 关闭 IK 的距离与方式　`[animation-advanced/05#S5]`

【读】`howto/godot/animation-advanced.md#4. IK（反向动力学）`

【做】
定下关闭 IK 的距离与方式（按 `influence` 归零 或 停解算），距离进参数表。
⛔ 只降频率 —— IK 是**每帧求解**，只降频率仍占用解算，
⛔ 表现为"远处角色多了就掉帧"，
而 profiling 看到的是"每帧都有 IK"，排查被引向"频率还不够低"。

ⓘ 与 06 的帧预算联动：
⛔ 距离值必须由同屏人数与帧预算反推，不由本域编。

【产出】LOD 关闭距离（进参数表）+ 关闭方式

【判据】达到该距离后 IK 完全不参与解算。

【审】`audit/godot/animation-advanced.md#10`、`audit/godot/animation-advanced.md#37`

## 3. 参考实现
```gdscript
# ⓘ 承接 05/S3、S5：IK_MOD 为 SkeletonModifier3D 系节点
const IK_DISABLE_DISTANCE := 30.0

@onready var ik_mod: SkeletonModifier3D = $Skeleton3D/IK

func _process(_delta: float) -> void:
    var far := global_position.distance_to(get_viewport().get_camera_3d().global_position)
    ik_mod.influence = 0.0 if far > IK_DISABLE_DISTANCE else 1.0
```
