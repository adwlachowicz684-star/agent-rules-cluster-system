# 07 动画验收（动画进阶域）

> **本步交付**：敌意环境实测 + 混合边界实测
> **对应**：流程 `howto/godot/animation-advanced.md` · 审核 `audit/godot/animation-advanced.md`

## 0. 交付物定义

1. 混合边界实测通过（离散轨道无中间态、叠加权重符合核算值）
2. 多个实例间互不干扰（改一个不影响其他）
3. reparent 与骑乘后 IK 仍生效
4. 同屏大量角色压测通过且帧率达标
5. 升级引擎版本后动画行为无回归
6. 过渡与状态切换的 20 次往返无变形

## 2. 工序

### Step 1　离散轨道在混合中无中间态　`[animation-advanced/07#S1]`

【读】`howto/godot/animation-advanced.md#⛔ Discrete 轨道在 AnimationTree 里会被强制连续`

【做】
在**两个状态混合到一半**的时刻截图，检查离散轨道（表情、开关、整数索引）
**不出现中间态**。
⛔ 只在状态稳定后截图 —— 中间态**只在过渡期间**出现，
⛔ 而稳定后一切正常，于是这个 bug 会一路活到上线。

ⓘ 这条要配合 01/S4 的 `callback_mode_discrete`：
⛔ 只设了取值却不实测，等于没有验证 ——
因为取值是否生效，只有在这个时刻才看得出。

【产出】过渡中截图（含离散轨道取值）

【判据】混合到 50% 时，离散轨道取值等于起点或终点之一。

【审】`audit/godot/animation-advanced.md#16`、`audit/godot/animation-advanced.md#17`

### Step 2　叠加权重实测等于核算值　`[animation-advanced/07#S2]`

【读】`howto/godot/animation-advanced.md#⛔ deterministic 为 true 让 Add 类节点效果减半`

【做】
对每个 `Add2` / `Add3` / `Sub2` 节点，实测实际叠加幅度，
与 04/S2 按口径算出的值对照。
⛔ 只目测"有效果" —— 官方举例的情形下，
**效果正是它的一半**，看起来"有效果"但幅度不对，
⛔ 而美术往往不会精确比对幅度，于是长期隐身。

ⓘ 这条的判据必须是**数值**，不是"看着对"：
⛔ "有效果"这个判据同时能通过"完全正确"和"只有一半"。

【产出】叠加幅度实测表（期望值 / 实测值）

【判据】实测值等于核算值；⛔ 差一半即为未核算 deterministic。

【审】`audit/godot/animation-advanced.md#18`、`audit/godot/animation-advanced.md#19`

### Step 3　多个实例互不干扰　`[animation-advanced/07#S3]`

【读】`howto/godot/animation-advanced.md#⛔ 动画节点是资源，实例间共享`

【做】
同屏放多个同类角色，改其中一个的动画参数，
验证其他角色**画面上不变**。
⛔ 只放一个角色测 —— 共享污染**只在多实例时出现**，
⛔ 而单实例下一切正常，这是最典型的"编辑器里对、上线后不对"。

ⓘ 分诊要按 06/S2 的对照走：
⛔ 全场一起变 → 查树参数；只有自己变 → 查 playback。
没有这条对照，两类问题会被当成同一类去查。

【产出】多实例对照记录（改一个，其余是否变化）

【判据】改一个实例参数，同类其他实例画面上完全不变。

【审】`audit/godot/animation-advanced.md#20`、`audit/godot/animation-advanced.md#21`、`audit/godot/animation-advanced.md#38`

### Step 4　reparent 与骑乘后 IK 仍生效　`[animation-advanced/07#S4]`

【读】`howto/godot/animation-advanced.md#9. IK 节点：已弃用 + 三个生效时机`

【做】
实测：上下乘具 20 次后，脚部仍贴地；复杂地形（斜坡、台阶）同样成立。
⛔ 只在平坦地面测一次 —— 穿地与悬空**只在复杂地形**出现，
⛔ 而平坦地面上一切正常。

ⓘ 这条要单独看"是不是 reparent 导致的"：
⛔ 若平地正常、骑乘后失效，原因在 `get_parent_skeleton()` 绑定时机（05/S4），
不是 IK 参数问题 —— 两种修法完全不同。

【产出】20 次骑乘 + 复杂地形的贴地记录

【判据】20 次骑乘后脚部仍贴地；复杂地形无穿地悬空。

【审】`audit/godot/animation-advanced.md#26`、`audit/godot/animation-advanced.md#24`

### Step 5　同屏大量角色压测　`[animation-advanced/07#S5]`

【读】`howto/godot/animation-advanced.md#4. IK（反向动力学）`

【做】
在目标数量附近连续生成/销毁角色，记录帧率与各 LOD 档位的实际降级情况。
⛔ 只测"生成 10 个再删掉" —— LOD 与预算问题**只在临界点**出现，
⛔ 而编辑器里 10 个角色的帧率说明不了任何问题。

ⓘ 同时验 06/S6 的退化路径：
⛔ 任一级退化下角色行为都要符合该级预期，
表现为"远处角色走得更慢"就是根运动降级没统一（06/S3）。

【产出】压测记录（数量峰值、帧率、各档位降级是否触发）

【判据】任何时刻帧率在预算内；各档位降级按表触发。

【审】`audit/godot/animation-advanced.md#37`、`audit/godot/animation-advanced.md#10`

### Step 6　升级引擎版本后动画行为无回归　`[animation-advanced/07#S6]`

【读】`howto/godot/animation-advanced.md#9. IK 节点：已弃用 + 三个生效时机`

【做】
升级后重测：头部朝向（⛔ 4.7 起 `LookAtModifier3D.relative` 默认值变更）、
叠加幅度、离散轨道。
⛔ 只跑一遍看能不能打开 —— 默认值变更**不产生任何报错**，
⛔ 表现为"升级后朝向偏了"，而配置一个字没改。

ⓘ 这条与 deprecated API 是同一个风险的两面：
⛔ 类被移除是**显性**失败（会报错），默认值变更是**隐性**失败（不报错），
后者更危险，所以升级必须重测数值而不只是"能跑"。

【产出】升级前后对照（朝向、叠加幅度、离散轨道三项）

【判据】三项与升级前一致；⛔ 有差异即为默认值变更未处理。

【审】`audit/godot/animation-advanced.md#22`、`audit/godot/animation-advanced.md#23`、`audit/godot/animation-advanced.md#18`

## 3. 验收清单

- [ ] 混合中离散轨道无中间态
- [ ] 叠加幅度实测等于核算值
- [ ] 多实例互不干扰
- [ ] 20 次骑乘后仍贴地
- [ ] 压测帧率在预算内且降级按表触发
- [ ] 升级后三项无回归

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 过渡期表情滑动 | 只测稳定态 | S1 |
| 叠加效果差一半 | 只目测"有效果" | S2 |
| 改一个全场变 | 单实例测试 | S3 |
| 骑乘后脚不贴地 | 只测平地 | S4 |
| 远处角色走得更慢 | 根运动降级未统一 | S5 |
| 升级后朝向偏了 | 只测"能不能打开" | S6 |
