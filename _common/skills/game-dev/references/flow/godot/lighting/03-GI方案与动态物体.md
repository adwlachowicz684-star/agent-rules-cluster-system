# 03 GI 方案与动态物体（光照域）

> **本步交付**：VoxelGI / SDFGI 选型 + 反馈上限 + 收敛与更新时机
> **对应**：流程 `howto/godot/lighting.md` · 审核 `audit/godot/lighting.md`

## 0. 交付物定义

1. VoxelGI 与 SDFGI 之间已选定，并写下**按什么判据选**
2. 网格 `gi_mode` 已按用途逐个设对（⛔ Dynamic 在 SDFGI 下不贡献 GI）
3. Bounce Feedback **有上限**，且有"变极亮"的回退手段
4. 收敛帧数已知，场景切换有过渡处理
5. SDFGI 的更新时机已知，改网格后的重生成步骤已写成操作

## 1. 前置检查清单

- [ ] 选型判据写下来了（封闭 / 开放、要不要动态遮挡）
- [ ] 每个网格的 gi_mode 按用途设过

- [ ] 切场景的收敛过渡已处理
- [ ] "改网格后如何重生成"是书面步骤

## 2. 工序
### Step 1　按 gi_mode 语义选型：Dynamic 在 SDFGI 下等同 Disabled　`[lighting/03#S1]`

【读】`howto/godot/lighting.md#2. VoxelGI vs SDFGI`

【做】
用"要不要动态遮挡物 / 动态自发光"定 VoxelGI 还是 SDFGI，
并逐个网格设 `gi_mode`。

⛔ SDFGI 下网格的 **Dynamic 模式等同 Disabled**：
只接收间接光、**不贡献**间接光。
表现为"摆了一堆物体，GI 却像没看见它们"，
而那些物体**明明在画面里**。

| | VoxelGI | SDFGI |
|---|---|---|
| 动态遮挡物 | ✓ | **✗** |
| 动态自发光表面 | ✓ | **✗** |
| 适合 | 封闭 / 半封闭中小场景 | 开放世界、程序化关卡 |
【审】`audit/godot/lighting.md#29`
### Step 2　Bounce Feedback 设硬上限，防无限反馈循环　`[lighting/03#S2]`

【读】`howto/godot/lighting.md#8. ⛔ SDFGI 的反馈循环、收敛与更新时机`

【做】
给 Bounce Feedback 设上限并写进配置。

⛔ 官方：**大于 0.5 的值可能导致无限反馈循环发生，
使场景在几秒钟内变得极其明亮**。
⛔ 这是本域最阴的一条：调参时前几秒看着正是"变亮了挺好"，
等发现时整个场景已过曝，而**参数面板上是合法值**。

ⓘ 官方给的合理区间是 **0.3 – 1.0**，并提示
"如果因此太亮，降低 Energy 补偿"。
【审】`audit/godot/lighting.md#27`
### Step 3　收敛需要时间：切场景要有过渡　`[lighting/03#S3]`

【读】`howto/godot/lighting.md#8. ⛔ SDFGI 的反馈循环、收敛与更新时机`

【做】
按默认 **25 帧收敛**安排场景切换的过渡（例如全屏 ColorRect 淡出）。

⛔ 不知道收敛这回事时，表现为"切场景瞬间光照怪一下又好了"，
⛔ 而这个现象在**第一次进场景**时不会出现（那时没有对比），
只在反复切换时才被注意到。
【审】`audit/godot/lighting.md#31`
### Step 4　改网格后必须触发重生成：相机远离或开关 SDFGI　`[lighting/03#S4]`

【读】`howto/godot/lighting.md#8. ⛔ SDFGI 的反馈循环、收敛与更新时机`

【做】
把"改了静态几何之后如何重生成 SDF"写成书面步骤：
**相机远离物体再移回**，或**关闭再开启 SDFGI**。

⛔ 官方：**仅在相机移入 / 移出级联时更新 SDF**。
不改相机位置就永远不更新，
表现为"间接光看起来不对劲"，
⛔ 而 SDFGI 面板上一切正常、也没有任何提示。
【审】`audit/godot/lighting.md#28`
### Step 5　Max Distance 低于相机 far，Y Scale 减漏光　`[lighting/03#S5]`

【读】`howto/godot/lighting.md#8. ⛔ SDFGI 的反馈循环、收敛与更新时机`

【做】
把 `Max Distance` 设为**低于相机 far 的值**，
并按场景垂直程度调 `Y Scale`。

⛔ 官方：Max Distance **应始终低于相机 far**，
超出观看距离的部分算了也没有收益。
ⓘ Y Scale 设 **75% 甚至 50%** 可减少漏光且**不影响性能**
（多数游戏场景不是高度垂直的）。
【审】`audit/godot/lighting.md#30`

## 3. 参考实现

```gdscript
# SDFGI 参数守卫 —— 加载场景时调用
# ⓘ SDFGI_BOUNCE_CAP 承接 Step 2：官方提示 > 0.5 可能无限反馈
const SDFGI_BOUNCE_CAP := 0.5

func apply_sdfgi(env: Environment, camera_far: float) -> void:
    env.sdfgi_enabled = true
    env.sdfgi_bounce_feedback = minf(env.sdfgi_bounce_feedback, SDFGI_BOUNCE_CAP)
    # ⛔ Max Distance 必须低于相机 far，否则白算
    if env.sdfgi_max_distance > camera_far:
        env.sdfgi_max_distance = camera_far * 0.9
    env.sdfgi_y_scale = 0.75   # ⓘ 官方建议 0.5–0.75，减漏光且不影响性能
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 摆了物体 GI 却看不见它 | gi_mode 设成 Dynamic（SDFGI 下等同 Disabled） | S1 |
| 场景几秒内变得极亮 | Bounce Feedback > 0.5 触发无限反馈 | S2 |
| 切场景光照怪一下 | 25 帧收敛未处理 | S3 |
| 间接光一直不对 | 改网格后未触发 SDF 重生成 | S4 |
| 远处 GI 开销大却看不见 | Max Distance 超过相机 far | S5 |
