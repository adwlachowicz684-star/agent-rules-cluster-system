# 04 阴影偏置与方向光级联（光照域）

> **本步交付**：bias 调整顺序 + PSSM 分段点 + 极端几何处理
> **对应**：流程 `howto/godot/lighting.md` · 审核 `audit/godot/lighting.md`

## 0. 交付物定义

1. bias 的**调整顺序**已定：先 Normal Bias 后 Bias
2. 每盏灯的 bias **逐灯记录**，⛔ 不是全局一个值
3. PSSM 的**分段点与 max_distance** 已调，⛔ 不是加 cascade 数量
4. 跨 cascade 的大物体已处理（否则画 5 遍）
5. 聚光灯角度上限已知
6. Pancake Size 与 Fade Start 的适用条件已写明

## 2. 工序
### Step 1　先调 Normal Bias，后调 Bias —— 顺序不能反　`[lighting/04#S1]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
按官方口径把 **Shadow Normal Bias** 作为第一手段。

⛔ 先调 Shadow Bias 会更快"看起来干净"，
但 peter-panning（影子脱离物体）来得也更快，
表现为"影子不连脚"，
⛔ 而这个现象在静态截图里常被视为"还行"。

| 现象 | 成因 | 修法 |
|---|---|---|
| shadow acne（条纹状自阴影） | bias 过低 | 提高 bias |
| peter-panning（影子不连脚） | bias 过高 | 降低 bias |
【审】`audit/godot/lighting.md#7`
### Step 2　逐灯调、逐灯记：没有通用值　`[lighting/04#S2]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
为每盏灯单独调 bias 并把值记在灯旁边（注释或配置）。

⛔ 官方：**没有通用最优值**，
要按几何尺寸和复杂度逐灯调，每盏灯可以不同。
⛔ 统一填一个值会让部分灯 acne、部分灯 peter-panning，
而"大部分灯看着还行"会给出错误的安全感。
【审】`audit/godot/lighting.md#8`
### Step 3　PSSM 的关键是分段点与 max_distance，不是 cascade 数　`[lighting/04#S3]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
调 `split_1/2/3`（相对相机 far 或 `max_distance` 的比例）
与 `max_distance`，而不是加 cascade 数量。

⛔ **`max_distance` 是性能与精度的最大杠杆**：
越低，近处阴影越精细、参与阴影渲染的物体越少。
ⓘ 官方：默认 4 分屏通常够用，
常见的调整是**把第一段稍微调近**，给第三人称角色脚下更多细节。
【审】`audit/godot/lighting.md#9`
### Step 4　大物体跨 cascade 会画 5 遍　`[lighting/04#S4]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
把跨多个 cascade 的大地面/大物体拆成段网格，
或降低 `max_distance` 对冲。

⛔ 官方：物体足够大到出现在全部四个分段里时，
它会被渲染**五次**（四个阴影分段 + 一次最终场景）。
⛔ 表现为"加了一块大地面后帧时间掉一截"，
而剖析器里看到的是 draw call 变多，
⛔ 不容易联想到是同一块地面被画了多遍。
【审】`audit/godot/lighting.md#10`
### Step 5　聚光灯角度超过 89 度，阴影完全停止工作　`[lighting/04#S5]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
给聚光灯角度设上限（≤ 89 度），需要更宽就换全向光。

⛔ 官方：**角度大于 89 度时聚光阴影将完全停止工作**。
表现为"把灯调宽之后阴影没了"，
⛔ 而灯本身照常发光、面板无警告 ——
排查方向必然被引向 bias 或分辨率。
【审】`audit/godot/lighting.md#36`
### Step 6　Pancake Size 与 Fade Start：只在满足条件时才用　`[lighting/04#S6]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
两个参数都写成"只在 X 条件下才动"：

- **Pancake Size** —— 只在**大物体 + 未细分网格**导致阴影缺失时调，
  ⛔ 且官方明确"只在确认不是 shadow biasing 问题后才改"。
- **Fade Start = 1.0** —— 只在 **Max Distance 完全覆盖场景**时用；
  ⛔ 否则阴影会在远处**突然被切断**，而不是渐隐。
【审】`audit/godot/lighting.md#37`

## 3. 参考实现

```gdscript
# 阴影参数守卫 —— 加载灯时调用
# ⓘ SPOT_ANGLE_MAX 为官方硬限制：超过 89 度聚光阴影完全停止工作
const SPOT_ANGLE_MAX := 89.0

func apply_shadow_guard(l: Light3D) -> void:
    if l is SpotLight3D:
        if l.spot_angle > SPOT_ANGLE_MAX:
            push_warning("聚光灯角度 %.1f 超过 %.1f，阴影会失效" % [l.spot_angle, SPOT_ANGLE_MAX])
            l.spot_angle = SPOT_ANGLE_MAX
    # ⛔ 先 Normal Bias 后 Bias，见 Step 1
    l.shadow_normal_bias = 1.0
    l.shadow_bias = 0.03
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 影子不连脚 | 先调了 Shadow Bias | S1 |
| 部分灯 acne 部分灯飘 | 用了通用 bias 值 | S2 |
| 阴影糊且开销大 | 只加 cascade 没调 max_distance | S3 |
| 加地面后掉帧 | 大物体跨 cascade 画 5 遍 | S4 |
| 调宽聚光灯后阴影消失 | 角度 > 89 度 | S5 |
| 阴影远处突然切断 | Fade Start 用了 1.0 但覆盖不全 | S6 |
