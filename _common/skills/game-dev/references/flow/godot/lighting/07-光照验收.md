# 07 光照验收（光照域）

> **本步交付**：换渲染器实测 + 目标平台烘焙实测 + 极端角度实测
> **对应**：流程 `howto/godot/lighting.md` · 审核 `audit/godot/lighting.md`

## 0. 交付物定义

1. **换渲染器**后光照仍成立（⛔ 不是只在编辑器默认档测）
2. **烘焙在目标平台**已实测（⛔ Web 编辑器不能烘）
3. **动态物体的间接光**已实测（探针重烘路径）
4. **极端角度与距离**下阴影已实测
5. 雾与面光在**回退档位**下已实测

⛔ 光照域的 bug **在正常视口下几乎全测不出** ——
它们只在换渲染器、换平台、极端角度、薄雾转镜头时才出现。
所以本步的判据全部是"敌意条件实测"，⛔ 不是"看一眼觉得亮了"。

## 2. 工序
### Step 1　换渲染器实测：Forward+ / Mobile / Compatibility 各跑一遍　`[lighting/07#S1]`

【读】`howto/godot/lighting.md#0. 方案选型（先看这个）`

【做】
把同一个场景在三个渲染器下各跑一遍，比对**有没有间接光、有没有雾**。

⛔ 只在编辑器默认（Forward+）下测 ——
VoxelGI / SDFGI 与体积雾**只有 Forward+ 有**，
⛔ 表现为"出包到手机上没有间接光也没有雾"，
而开发机上**一切正常**。
【审】`audit/godot/lighting.md#2`
### Step 2　烘焙在目标平台实测：Web 编辑器不能烘　`[lighting/07#S2]`

【读】`howto/godot/lighting.md#1. LightmapGI 烘焙`

【做】
在**真实的目标平台**上跑一次完整烘焙流程。

⛔ 官方：**Web 编辑器不支持烘焙**（图形 API 限制），
只能渲染在别的平台上烘好的光照图。
⛔ 表现为"在 Web 版里点烘焙没反应/失败"，
而同样的场景在桌面端完全正常。
【审】`audit/godot/lighting.md#15`
### Step 3　动态物体间接光实测：确认探针真的生效　`[lighting/07#S3]`

【读】`howto/godot/lighting.md#7. ⛔ 烘焙的静默失效：三类不报错的错`

【做】
让一个动态物体走过探针区域，比对**间接光是否随位置变化**。

⛔ 只测静态场景 —— 手动放置探针后**必须重新烘焙才生效**，
不重烘等于没摆。
⛔ 表现为"探针摆了一片，动态物体还是死黑"，
而探针在编辑器里**看得见**。
【审】`audit/godot/lighting.md#19`
### Step 4　极端角度与距离实测：> 89 度与远处切断　`[lighting/07#S4]`

【读】`howto/godot/lighting.md#3. 阴影`

【做】
把聚光灯角度推到 90 度附近、把相机推到 max_distance 边缘，
逐档截图比对。

⛔ 只测"正常机位" ——
角度 > 89 度时阴影**完全停止工作**，
Fade Start = 1.0 而 max_distance 没覆盖时阴影会**突然切断**，
⛔ 两者在默认机位下**都不出现**。
【审】`audit/godot/lighting.md#36`
### Step 5　雾与面光在回退档位实测　`[lighting/07#S5]`

【读】`howto/godot/lighting.md#5. 4.7 的 AreaLight3D`

【做】
把渲染器降到 Mobile / Compatibility，
检查 FogVolume 与 AreaLight3D 的回退表现。

⛔ 只在高端档测 ——
**Compatibility 没有体积雾、面积光不能投影、也不支持面积纹理**。
⛔ 表现为"低端机上既没雾，发光屏幕也不发光"，
而这两处**都不会报错**。
【审】`audit/godot/lighting.md#17`

## 3. 验收清单

- [ ] 三个渲染器各跑一遍并比对
- [ ] 目标平台完整烘焙已实测
- [ ] 动态物体走过探针区域，间接光有变化
- [ ] 聚光灯 90 度、相机推到边缘已逐档截图
- [ ] 回退档位下雾与面光表现已确认

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 手机上没间接光没雾 | 仅 Forward+ 支持 | 01/S2 |
| Web 里烘焙没反应 | Web 编辑器不支持烘焙 | 02/S4 |
| 探针摆了动态物体还是黑 | 摆完没重烘 | 02/S5 |
| 灯调宽后阴影没了 | 聚光灯 > 89 度 | 04/S5 |
| 低端机没雾、屏幕不发光 | Compatibility 不支持 | 05/S1、06/S1 |
