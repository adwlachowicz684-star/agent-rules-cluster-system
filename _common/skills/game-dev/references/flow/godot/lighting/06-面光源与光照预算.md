# 06 面光源与光照预算（光照域）

> **本步交付**：AreaLight3D 预算 + 几何细分 + 衰减与纹理
> **对应**：流程 `howto/godot/lighting.md` · 审核 `audit/godot/lighting.md`

## 0. 交付物定义

1. 面光源**已计入光照与阴影预算**（⛔ 不是免费的 GI 替代）
2. 已知道 Forward+ 下**一盏面光源影响所有物体**的成本
3. 投射阴影的物体**细分度**已核对
4. `area_attenuation` 的取值与 `area_range` **联动**已核过可见性
5. 面光源纹理尺寸符合免缩放条件

## 2. 工序
### Step 1　面光源是实时光，进预算 —— 不是 GI 替代　`[lighting/06#S1]`

【读】`howto/godot/lighting.md#10. 面光源的预算与几何限制`

【做】
把 `AreaLight3D` 当作**实时光**计入光照预算与阴影预算。

⛔ 它是矩形面光源，替代过去"自发光材质 + GI"模拟发光屏幕的做法，
但它**不是免费的**：
⛔ 官方明确面积光在实时渲染时**性能开销最大**，
建议仅用于过场动画或高端设备。
ⓘ 不需要柔和阴影时可把 Size 设为 `0.0` 直接关闭软阴影。
【审】`audit/godot/lighting.md#16`
### Step 2　Forward+ 下：视锥内有一盏，所有物体都有额外成本　`[lighting/06#S2]`

【读】`howto/godot/lighting.md#10. 面光源的预算与几何限制`

【做】
把面光源的数量约束写进预算。

⛔ 官方：Forward+ 下**只要视锥内存在一个面光源，
所有被渲染的物体都有额外 GPU 成本**（clustered lighting 性质）。
⛔ 表现为"加了一盏灯，整个场景都变慢"，
而剖析器上"那盏灯"的耗时并不突出 ——
成本摊在所有物体上，**看不出归属**。
【审】`audit/godot/lighting.md#40`
### Step 3　投射物细分不足且离得近 → 阴影不对　`[lighting/06#S3]`

【读】`howto/godot/lighting.md#10. 面光源的预算与几何限制`

【做】
核对靠近面光源的阴影投射物的网格细分度。

⛔ 官方：投射阴影的物体**细分度不够、又离面光源非常近**时，
阴影看起来会不对劲（与 OmniLight3D 的 Dual Paraboloid 限制相同）。
⛔ 表现为"离灯越近阴影越怪"，
而 bias 怎么调都不对 ——
⛔ 因为这不是 bias 问题。
【审】`audit/godot/lighting.md#39`
### Step 4　attenuation 2.0 的可见性陷阱：与 range 联动　`[lighting/06#S4]`

【读】`howto/godot/lighting.md#10. 面光源的预算与几何限制`

【做】
设 `area_attenuation` 时**连带核一遍 `area_range` 下的实际可见性**。

⛔ 官方：`2.0` 是物理正确的平方反比，但
range 4096 时 **100 单位处的衰减因子是 0.0001** ——
默认亮度下那盏灯**根本看不见**。
⛔ 表现为"按物理正确配了，灯却不亮"，
而参数面板上每一项都"更正确"。
⛔ 负值或 > 10.0 会有意外结果。
【审】`audit/godot/lighting.md#41`
### Step 5　纹理尺寸与运行时切换成本　`[lighting/06#S5]`

【读】`howto/godot/lighting.md#10. 面光源的预算与几何限制`

【做】
面光源纹理每维取 **128 的倍数或 2 的幂**。

⛔ 官方：运行时切换纹理有性能代价（需要带 mipmap 过滤重绘到图集）；
符合上述尺寸可**省掉缩放 pass**。
⛔ 表现为"动态换广告牌内容时卡一下"，
而纹理本身尺寸并不大。
【审】`audit/godot/lighting.md#42`

## 3. 参考实现

```gdscript
# 面光源预算与参数守卫
# ⓘ MAX_AREA_LIGHTS 承接 Step 2：Forward+ 下每盏都影响全部物体
const MAX_AREA_LIGHTS := 2

var _area_lights: Array[AreaLight3D] = []

func add_area_light(l: AreaLight3D) -> bool:
    if _area_lights.size() >= MAX_AREA_LIGHTS:
        push_warning("面光源已达上限 %d（Forward+ 下影响所有物体）" % MAX_AREA_LIGHTS)
        return false
    # ⓘ 默认 area_range 5.0；attenuation 2.0 时远处衰减极快，需按场景核
    l.area_attenuation = 1.0
    l.area_normalize_energy = true
    _area_lights.append(l)
    return true
```
