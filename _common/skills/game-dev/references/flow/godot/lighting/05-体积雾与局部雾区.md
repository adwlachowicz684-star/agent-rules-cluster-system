# 05 体积雾与局部雾区（光照域）

> **本步交付**：全局体积雾前提 + FogMaterial + 薄雾闪烁修法
> **对应**：流程 `howto/godot/lighting.md` · 审核 `audit/godot/lighting.md`

## 0. 交付物定义

1. `Environment.volumetric_fog_enabled` 已开（⛔ FogVolume 的前提）
2. "只要局部雾"已用 **density = 0.0** 实现，⛔ 不是关掉体积雾
3. FogVolume 已配 `FogMaterial`，密度正负语义已明确
4. 薄雾闪烁已有选定修法
5. cone / cylinder 的缩放方式正确（缩放节点而非 size）

## 1. 前置检查清单

- [ ] Environment 里体积雾是开的
- [ ] 全局 density 已按需要设为 0.0 或目标值
- [ ] 每个 FogVolume 都有 FogMaterial
- [ ] 薄雾的厚度与 density 已按选定修法调过
- [ ] 无 cone/cylinder 用 size 做非均匀缩放

## 2. 工序
### Step 1　FogVolume 的前提是全局体积雾已开　`[lighting/05#S1]`

【读】`howto/godot/lighting.md#9. 体积雾的可见性前提与薄雾闪烁`

【做】
先在 `WorldEnvironment` 的 Environment 里开
`volumetric_fog_enabled`，再摆 FogVolume。

⛔ 官方：**FogVolume 只在 `volumetric_fog_enabled = true` 时有可见效果**。
表现为"摆了 FogVolume 但画面一点变化都没有"，
⛔ 而节点、形状、材质**全部正确**，
且**没有任何报错** —— 排查会被引向材质或层级。

ⓘ 体积雾是**三维 froxel 缓冲**，不是后处理贴片，
**只有 Forward+ 支持**。
【审】`audit/godot/lighting.md#32`
### Step 2　只要局部雾：把全局 density 设 0.0，⛔ 不是关掉　`[lighting/05#S2]`

【读】`howto/godot/lighting.md#9. 体积雾的可见性前提与薄雾闪烁`

【做】
想要"只有雾区里有雾"时，把全局
`volumetric_fog_density` 设为 `0.0`。

⛔ 关掉 `volumetric_fog_enabled` 会让 FogVolume **一起失效** ——
这正是上一步那条约束的另一面。
⛔ 表现为"为了去掉全局雾，把局部雾也一起弄没了"，
而两个操作在面板上看起来都是"关掉雾"。
【审】`audit/godot/lighting.md#33`
### Step 3　FogMaterial 的密度可正可负：叠加与挖洞　`[lighting/05#S3]`

【读】`howto/godot/lighting.md#4. 体积雾与体积光`

【做】
给每个 FogVolume 配 `FogMaterial`，明确密度符号的用途：
**正值叠加**局部雾，**负值从其他雾或全局雾里减去**（挖洞）。

⛔ 官方：emission **不向其他表面投射光/阴影**。
想做"体积光柱照亮地面"要用真正的体积雾 + 光源，
⛔ 单靠雾 quad 做不到 ——
表现为"光柱看得见但地面没被照亮"，
而光柱本身看着完全正常。
【审】`audit/godot/lighting.md#13`
### Step 4　薄雾闪烁：三条官方修法选一条　`[lighting/05#S4]`

【读】`howto/godot/lighting.md#9. 体积雾的可见性前提与薄雾闪烁`

【做】
薄 FogVolume 在相机移动 / 旋转时会闪。按官方给的三条选其一：
① 提高 `rendering/environment/volumetric_fog/volume_depth`（**有性能代价**）；
② 降低 `volumetric_fog_length`（**无性能代价**，但雾程变短）；
③ 加厚体积 + 降低材质密度。

⛔ 不处理的话表现为"转镜头时雾一闪一闪"，
⛔ 而截图完全正常 —— 静态验收**永远发现不了**。
【审】`audit/godot/lighting.md#34`
### Step 5　cone / cylinder 的非均匀缩放要缩放节点　`[lighting/05#S5]`

【读】`howto/godot/lighting.md#9. 体积雾的可见性前提与薄雾闪烁`

【做】
需要非均匀缩放 cone / cylinder 形状的雾区时，
缩放 **FogVolume 节点本身**。

⛔ 官方：**不支持**通过 Extents / size 属性做非均匀缩放
（cone/cylinder 会被调整以适配 extents）。
表现为"想要的椭长雾柱做不出来"，
⛔ 而属性面板接受输入、不报错。
【审】`audit/godot/lighting.md#35`

## 3. 参考实现

```gdscript
# 体积雾前提校验 —— 场景加载后调用
func check_fog_prereq(env: Environment) -> bool:
    if not env.volumetric_fog_enabled:
        push_warning("未开 volumetric_fog_enabled，所有 FogVolume 都不会显示")
        return false
    return true

# ⓘ 只要局部雾：把全局密度设 0.0，而不是关掉体积雾
func local_fog_only(env: Environment) -> void:
    env.volumetric_fog_enabled = true
    env.volumetric_fog_density = 0.0
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| FogVolume 完全没效果 | 未开 volumetric_fog_enabled | S1 |
| 去掉全局雾连带局部雾没了 | 关了开关而非设 density=0 | S2 |
| 光柱可见但地面没被照亮 | emission 不投射光/阴影 | S3 |
| 转镜头时雾闪烁 | 薄雾未处理 | S4 |
| 椭长雾柱做不出来 | 用 size 做非均匀缩放 | S5 |
