## 0. 交付物定义

⚠ **技能点/天赋点通常是付费或长线积累的。**
⛔ 重置后不返还 = 玩家资产损失，**与删档性质相同**。

做完这一步，应该能**当场演示**：

1. 转职后技能点总数**等于投入量**（不是剩余量）
2. ⚠ 先点满再转职**不能套利**（返还的是投入，重置后从零开始）
3. 跨职业转职后，每条旧技能都有对应的映射（⛔ 无孤儿技能）
4. 觉醒（原职业保留）时，旧技能**仍然可用**
5. ⚠ 天赋重置走**统一入口**，不是转职侧自己改数据

**产出物**（下游按名字对接）：

```text
skill_remap: {old_skill_id -> new_skill_id}     # 跨职业映射表
reset_talents(p) -> 统一重置入口（economy.md 提供）
refund_amount = 历史投入量（不是当前剩余）
```

## 2. 工序

### Step 1　⚠ 三选一并明示　`[class/05#S1]`

【读】`howto/godot/class-awaken.md#5. 技能与天赋：重置还是继承`

【做】选继承 / 全额返还 / 部分返还，并把**损耗比例**写在 UI 上。

| 方案 | 适用 | 注意 |
|---|---|---|
| 全继承 | 觉醒（原职业还在） | 技能 ID 冲突要有映射表 |
| 全额返还 | 转职（新职业重置） | ⚠ 返还投入量，不是当前值 |
| 部分返还 | 有损耗的设计 | 损耗比例必须明示 |

⛔ 不明示的话，玩家会认为"点数被吞了"。

【产出】方案 + UI 文案里的损耗说明

【判据】⚠ UI 上能**直接读到**返还比例

【审】`audit/godot/class-awaken.md#12`

### Step 2　⛔ 返还投入量而非剩余量　`[class/05#S2]`

【读】`howto/godot/class-awaken.md#5. 技能与天赋：重置还是继承`

【做】记录**历史累计投入**，转职时按它返还。

⛔ 返还"当前剩余"（投入 − 已用）会让玩家**先点满再转职来套利**：
点满 → 剩余为 0 → 但技能全满 → 转职返还 0 却带着满技能？
⚠ 实际更常见的反向漏洞是：返还剩余 + 不重置 = 白嫖一套加点。

【产出】`invested_points` 累计字段（不只是 `remaining`）

【判据】⚠ 点满后转职再转回，**总点数与初始一致**（无增减）

【审】`audit/godot/class-awaken.md#13`

### Step 3　⚠ 建跨职业技能映射表　`[class/05#S3]`

【读】`howto/godot/class-awaken.md#5. 技能与天赋：重置还是继承`

【做】`skill_remap: {old_id -> new_id}`，覆盖全部职业对。

⛔ 没有映射表时，转职后旧技能**既不能用也不显示**，
玩家看到技能栏少了一半，而且**无法恢复**——因为不知道原来是什么。

【产出】映射表，逐职业对完整

【判据】⚠ 遍历全部职业对，**无孤儿技能**（每条旧技能都有去向）

【审】`audit/godot/class-awaken.md#14`

### Step 4　⚠ 觉醒时旧技能仍可用　`[class/05#S4]`

【读】`howto/godot/class-awaken.md#5. 技能与天赋：重置还是继承`

【做】定性为觉醒时，原职业技能**保留并叠加**觉醒技能。

⛔ 觉醒也走"重置"路径的话，玩家会发现"觉醒后变弱了"——
因为原职业的加点没了。

【产出】觉醒路径不调用重置

【判据】⚠ 觉醒前后，**原职业技能等级不变**

【审】`audit/godot/class-awaken.md#22`

### Step 5　⛔ 天赋重置走统一入口　`[class/05#S5]`

【读】`howto/godot/class-awaken.md#5. 技能与天赋：重置还是继承`

【做】转职侧**调用** `economy.md` 提供的重置接口，⛔ 不自己改天赋数据。

⛔ 自己改的话，两处重置逻辑会漂移——
表现为"转职重置和洗点道具重置的结果不一样"。

ⓘ 这是本域与 economy 域的**主要接缝**，见 00 总览第 3 节。

【产出】重置调用指向 `economy.md` 的单一入口

【判据】⚠ 转职重置 与 洗点道具重置，**结果逐字段相等**

【审】`audit/godot/class-awaken.md#12`

## 5. 常见返工

**① 返还剩余量。** 可套利，且玩家会自发传播这个漏洞。

**② 无映射表。** 技能栏莫名少一半且无法恢复。

**③ 觉醒走重置。** 觉醒后反而变弱。

**④ 自己写重置。** 与洗点道具结果不一致。
