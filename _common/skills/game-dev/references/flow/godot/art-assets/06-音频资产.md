# 06 音频资产（美术资产域）

> **本步交付**：格式按用途分层 + 采样率统一 + 循环点可用
> **对应**：流程 `howto/godot/art-assets.md` · 审核 `audit/godot/art-assets.md`

## 0. 交付物定义

1. 短音效用 WAV、BGM 与长音频用 OGG，逐条标注
2. 全部素材采样率统一，混用的已标记待重导
3. 循环 BGM 的循环点已实测（连续播放 ≥ 一个完整循环无咔哒声）
4. 音频总线与音量分级已定（不逐个音效调）
5. 若用 FMOD/Wwise，已确认是社区绑定且维护状态已查

## 1. 前置检查清单

- [ ] 音效与 BGM 已分类，格式已定
- [ ] 全部素材采样率已列出并统一
- [ ] 循环 BGM 的循环点已标注
- [ ] 总线结构已定（主/音效/音乐/语音）
- [ ] 第三方音频中间件的支持状态已查（不是凭印象）

## 2. 工序

### Step 1　短音效 WAV，BGM 用 OGG　`[art-assets/06#S1]`

【读】``howto/godot/art-assets.md#6. 音频资产``

【做】
短音效（打击、UI 点击）用 **WAV**；BGM 与长音频用 **OGG**。
⛔ 不要为了省体积把短音效也转成 OGG ——
OGG 需要解码，**解码延迟会让密集触发的音效迟到**，
⛔ 表现为"打击感和音效对不上"，⛔ 而排查被引向动画帧或输入延迟。

ⓘ 判定依据是**触发频率**，不是时长：
⛔ 一段 0.2 秒的音效如果每秒触发十几次，它就是"密集"，
⛔ 按"短 = WAV"的时长判据会把它分错。

【产出】音频清单（逐条：类别、格式、触发频率）

【判据】高频触发的音效全为 WAV；BGM/长音频全为 OGG。

【审】``audit/godot/art-assets.md#12``

### Step 2　采样率必须统一　`[art-assets/06#S2]`

【读】``howto/godot/art-assets.md#6. 音频资产``

【做】
全部素材统一到一个采样率，混用的重导出。
⛔ 不要混着用 —— 混用会触发重采样，代价是**开销与音质损失**，
⛔ 而⛔ **单条素材听不出问题，多条叠在一起才暴露**，
⛔ 于是排查被引向混音设置或总线音量，而真因是素材本身。

ⓘ 统一要覆盖**外部来源**的素材：
⛔ 素材站下载的音效往往是 48k，自己录的是 44.1k，
⛔ 来源是"合规素材"反而更容易被漏检。

【产出】采样率清单（含外部来源素材）

【判据】清单里采样率只有一种值。

【审】``audit/godot/art-assets.md#25``

### Step 3　循环 BGM 不用 MP3，循环点要实测　`[art-assets/06#S3]`

【读】``howto/godot/art-assets.md#6. 音频资产``

【做】
循环 BGM 用 OGG，并把循环点设对；MP3 基本不做无缝循环。
⛔ 不要只在编辑器里试听两秒就过 ——
循环点的咔哒声**只在循环处出现一次**，
⛔ 短时试听几乎必然错过，⛔ 于是它稳定地活到出包之后，
玩家听到的就是"每隔几分钟咔一下"。

ⓘ 验收要**连续播放一个完整循环以上**：
⛔ 只听开头和结尾两段，会漏掉"结尾接开头"那一瞬，
⛔ 而那一瞬正是唯一会出问题的地方。

【产出】循环点标注 + 连续播放实测记录

【判据】连续播放一个完整循环以上，接缝处无咔哒声。

【审】``audit/godot/art-assets.md#26``

### Step 4　音量分级走总线，不逐个音效调　`[art-assets/06#S4]`

【读】``howto/godot/art-assets.md#6. 音频资产``

【做】
建总线（主 / 音效 / 音乐 / 语音），音效的整体音量在总线上调。
⛔ 不要逐个音效改音量 —— 逐个调的结果是**每次调音量都要改几十个资源**，
⛔ 而且改完互相之间的比例关系也变了，
⛔ 表现为"调完音效后 BGM 显得太响"，于是又去改 BGM，来回震荡。

ⓘ 总线还有个不可替代的作用：
⛔ 玩家设置里的"音乐/音效音量"只能靠总线实现，
⛔ 逐资源调音量的话，**设置项根本无处可接**。

【产出】总线结构 + 各音效所属总线

【判据】设置界面能分别控制音乐与音效音量。

【审】``audit/godot/art-assets.md#25``

### Step 5　FMOD / Wwise 没有官方一级集成　`[art-assets/06#S5]`

【读】``howto/godot/art-assets.md#6. 音频资产``

【做】
若要上 FMOD / Wwise，先确认用的是**社区绑定**，并查它当前的维护状态与支持的引擎版本。
⛔ 不要按"有集成"来排期 —— Godot 没有官方一级集成，
⛔ 而"社区绑定"的维护状态是**会变的**，
⛔ 按半年前的结论排期，结果是上线前才发现绑定停更。

ⓘ 这条属于"必须现查"的一类：
⛔ 它的答案随时间变化，写死在文档里就会过期，
⛔ 所以文档里要写"查于某日"，而不是写结论。

【产出】中间件选型记录（含查询日期与支持版本）

【判据】记录里有查询日期；结论能追溯到当时的来源。

【审】``audit/godot/art-assets.md#15``


## 3. 参考实现

```gdscript
# ⓘ 本块内自足：常量在此声明，承接上文即可直接用
const BUS_MASTER := "Master"
const BUS_SFX := "SFX"
const BUS_BGM := "BGM"

# ⛔ 只做统一入口：音量在总线上调，不逐个资源改
func set_volume(sfx_linear: float, bgm_linear: float) -> void:
    var sfx_idx = AudioServer.get_bus_index(BUS_SFX)
    var bgm_idx = AudioServer.get_bus_index(BUS_BGM)
    AudioServer.set_bus_volume_db(sfx_idx, linear_to_db(sfx_linear))
    AudioServer.set_bus_volume_db(bgm_idx, linear_to_db(bgm_linear))

func buses_exist() -> bool:
    return AudioServer.get_bus_index(BUS_SFX) >= 0 \
        and AudioServer.get_bus_index(BUS_BGM) >= 0
```

## 5. 常见返工

| 现象 | 返工到 |
|---|---|
| 打击感与音效对不上 | 返工 Step 1（音效用 OGG，解码延迟） |
| 多条音效叠在一起发闷 | 返工 Step 2（采样率混用） |
| BGM 每隔几分钟咔一下 | 返工 Step 3（循环点未实测） |
| 调音量后比例全乱 | 返工 Step 4（逐个资源调音量） |
| 上线前发现绑定停更 | 返工 Step 5（没查维护状态） |
