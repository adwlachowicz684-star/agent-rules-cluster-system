# 07 美术资产验收（美术资产域）

> **本步交付**：缩小后比对通过 + 跨机字形一致 + 包体与显存实测 + 导入设置可追溯
> **对应**：流程 `howto/godot/art-assets.md` · 审核 `audit/godot/art-assets.md`

## 0. 交付物定义

1. 关键界面在**目标分辨率、缩小后**逐像素比对通过
2. 字形在 ≥2 个平台一致（不靠本机判断）
3. 包体与显存是**导出版实测值**，不是编辑器估计
4. SVG 资产已复核"文本转曲"
5. 任一导入设置能回答"它现在是什么、上次是什么、谁改的"

## 2. 工序

### Step 1　验收在缩小后做，不在编辑器里放大看　`[art-assets/07#S1]`

【读】``howto/godot/art-assets.md#1. 像素美术``

【做】
在目标分辨率截图，按实际显示尺寸比对（含缩放过程）。
⛔ 不要放大验收 —— 图集缝隙与像素糊都是**缩小后才明显**，
⛔ 而放大是本能动作，它恰好把这类问题全部隐藏，
⛔ 于是"验收时没发现"和"出包后被玩家发现"成了同一个流程的标准结局。

ⓘ 比对对象要**固定**：
⛔ 没有基准图就没法说"变了没有"，
⛔ 而"看着差不多"在连续小改动下会一路漂移，直到某天突然"明显不对"。

【产出】基准图 + 当前图 + 差异图

【判据】差异图无邻区串色、无边缘光晕、缩放过程无闪烁。

【审】``audit/godot/art-assets.md#24``

### Step 2　字形跨机比对，不靠本机判断　`[art-assets/07#S2]`

【读】``howto/godot/art-assets.md#三个默认值``

【做】
至少两个平台渲染同一段文本并比对字形。
⛔ 不要只在本机看 —— `allow_system_fallback` 默认 true，
缺字会用系统字体**静默兜底**，⛔ 表现不是豆腐块而是"能显示但不一样"，
⛔ 于是单机验证必然通过，而问题只在跨机比对时现形。

ⓘ 还要覆盖**运行时文本**：
⛔ 玩家昵称、数字格式化这些不在静态文案里，
⛔ 只比对 UI 静态文案会漏掉真正会缺字的那部分。

【产出】≥2 平台的字形比对图（含运行时拼接文本）

【判据】两平台字形完全一致，且无系统字体痕迹。

【审】``audit/godot/art-assets.md#19``

### Step 3　包体与显存用导出版实测　`[art-assets/07#S3]`

【读】``howto/godot/art-assets.md#2. 纹理压缩``

【做】
出包后实测包体与显存，与 `PKG_SIZE_BUDGET_MB` / `TEXTURE_BUDGET_MB` 对照。
⛔ 不要用编辑器里看到的数字 —— 导出版的导入产物与编辑器不同
（压缩、Basis 转码、3D 检测状态都可能不同），
⛔ 表现为"编辑器里一切正常、出包后爆内存"，
⛔ 而排查被引向"平台问题"，因为差异只在包里出现。

ⓘ 实测要分档记录：
⛔ 只记一个总数无法定位"是哪类资产超了"，
⛔ 而"显存超了"这个结论本身对下一步没有任何指导。

【产出】导出版实测表（按资产类型分档）

【判据】分档之和与总量吻合，且每档都在预算内。

【审】``audit/godot/art-assets.md#38``

### Step 4　SVG 资产复核"文本转曲"　`[art-assets/07#S4]`

【读】``howto/godot/art-assets.md#8. SVG``

【做】
逐个复核 SVG：源文件中不能含 `<text>`，必须先转成路径。
⛔ 不要等看到"字没了"再查 —— 官方明确 Godot 的 SVG 库
**不支持对 SVG 中的文本做光栅化**，
⛔ 结果是**文字整块消失**且⛔ **不报任何错**，
⛔ 文件在位、尺寸也对、缩略图可能还有，只是内容少了一块，
⛔ 排查被引向缩放、路径或渲染顺序，没人会想到"源文件里有文本"。

ⓘ 判据要前置到**收资源时**：
⛔ 出包前查会变成"所有 SVG 重导一遍"，
⛔ 而收资源时查只是一句要求。

【产出】SVG 清单（逐个标注是否已转曲）

【判据】清单中无"含文本未转曲"项；渲染结果与源文件目视一致。

【审】``audit/godot/art-assets.md#16``

### Step 5　导入设置要能回答"它现在是什么"　`[art-assets/07#S5]`

【读】``howto/godot/art-assets.md#检测 3D``

【做】
收尾时用 01 的脚本再跑一次导入设置快照，与开工基线对照。
⛔ 不要默认"没人动过就是没变" —— `detect_3d` 与 `detect 法线`
都会**自动重新导入并改写设置**，
⛔ 而面板上显示得"像一直如此"，没有对照就发现不了。

⛔ 这里还有一条最容易踩的：
把「检查 3D > 压缩至」设为 Disabled **并不会回滚**已有的压缩模式
（官方：*"will not change the existing compress mode"*）。
⛔ 所以"设了 Disabled 却发现没变回来"不是选项失效，
⛔ 正确做法是**先设 Disabled 停止改写，再手动改回并重新导入**两步都做。

【产出】导入设置快照对照（开工 vs 收尾）

【判据】差异项都能解释；无法解释的差异已回到对应功能点。

【审】``audit/godot/art-assets.md#29``


## 3. 验收清单

- [ ] 缩小后逐像素比对通过，含缩放过程
- [ ] ≥2 平台字形一致，含运行时拼接文本
- [ ] 包体与显存为导出版实测，且分档
- [ ] SVG 无"含文本未转曲"项
- [ ] 导入设置快照有开工/收尾对照，差异可解释
- [ ] `PKG_SIZE_BUDGET_MB` / `TEXTURE_BUDGET_MB` 未被突破

## 4. 常见返工

| 现象 | 返工到 |
|---|---|
| 出包后发现缝隙/糊 | → `07#S1`（放大验收） |
| 各平台字形不一致 | → `07#S2`（fallback 掩盖漏字） |
| 编辑器正常、出包爆内存 | → `07#S3`（用编辑器数字） |
| logo 里的字整块消失 | → `07#S4`（SVG 未转曲） |
| 设了 Disabled 却没变回来 | → `07#S5`（Disabled 不回滚） |
| 改了设置又变回去 | → `01#S4`（无对照基线） |
| 缩小后边缘发暗 | → `03#S4`（透明像素黑边） |
| 自定义着色器蓝通道不对 | → `04#S4`（Detect 自动改 RGTC） |
