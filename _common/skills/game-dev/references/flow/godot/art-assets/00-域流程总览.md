# 美术资产管线（Art Assets）—— 域流程总览

> ⚠ **第 0 步：先定"规范与导入设置"，再谈单张资源怎么调。**
> 本域有 7 个功能点，⛔ **不是全做** —— 按当前资产类型挑。

## 0. 先定做什么

| 本次要做的 | 走哪些功能点 |
|---|---|
| 项目刚起步，还没有资产规范 | 01 → 07 |
| 美术给了 2D 图，怎么导 | 01 → 02 → 07 |
| 像素美术糊了 / 有缝隙 | 02 → 03 → 07 |
| 要打图集 | 03 → 07 |
| 美术给了 3D 模型 | 01 → 04 → 07 |
| 中文界面 / 字体发虚 / 漏字 | 05 → 07 |
| 音效与 BGM | 06 → 07 |
| 出包后发现包体爆了、显存涨了 | 07（先查是谁改了导入设置） |

⛔ **01 不能跳过**：本域绝大多数故障的成因**不在"这张图怎么设"，
而在"没人动过它它自己变了"或"规范没写下来"。
⛔ 直接开始调单张图的参数，最常见的结果是**改完又被自动改回去**
（官方：`detect_3d` 一检测到 3D 使用就重新导入并改写设置），
⛔ 表现为"改了又变回去"，于是被引向"谁又动了我的设置"。

⛔ **07 的验收要在"缩小后"和"导出版"做，不能在编辑器放大看**：
图集缝隙（audit #24）与像素糊（#2）都是**缩小后才明显**，
⛔ 而放大验收是人的本能动作 —— 于是"验收时没发现，出包后被玩家发现"。

## 1. 功能点拆解与依赖

| # | 功能点 | 交付 | 依赖 |
|---|---|---|---|
| 01 | 资产规范与导入地基 | 目录/命名规范、`.uid` 入库、导入设置可校验 | — |
| 02 | 2D 纹理三开关与像素清晰度 | Filter/Repeat/Mipmap 定档、压缩分层、像素不糊 | 01 |
| 03 | 图集与切片 | padding/extrusion 定档、图集边界不串色 | 01 / 02 |
| 04 | 3D 资产导入 | 格式、缩放核对、PBR 通道与 sRGB、共享材质 | 01 |
| 05 | 字体与中文子集化 | 子集化、MSDF 取舍、fallback 与预渲染定档 | 01 |
| 06 | 音频资产 | 格式分层、采样率统一、循环点可用 | 01 |
| 07 | 美术资产验收 | 缩小后比对、跨机字形一致、包体与显存实测 | 全部 |

⛔ **依赖是硬的**：02 的"压缩按用途分层"要靠 01 的内存预算，
⛔ 没有预算就只剩"无损最好"这个直觉（audit #6），而它在 3D 大图上直接把显存顶满。

⛔ **04 与 02 的"检测改写"是同一族**：
纹理被检测到用于 3D（`detect_3d`）或被当作法线（`compress/normal_map`）都会**自动重新导入**，
⛔ 两边只允许各判一次，否则会出现"2D 那边改、3D 那边又改回去"的拉锯。

## 2. 域边界与接缝

| 邻域 | 分工 |
|---|---|
| `ui` 域 界面 | 九宫格与 UI 资产用法见 `ui`，⛔ 本域只管**资产怎么进引擎** |
| `shaders` 域 着色器 | 自定义着色器采样法线见 `shaders`，⛔ 本域只管**导入格式改了通道**这件事 |
| `render-pipeline` | ⓘ howto 层，暂无 flow 域 —— 渲染器能力对压缩格式的影响见该篇 |
| `performance` | ⓘ howto 层，暂无 flow 域 —— 显存与包体预算方法见该篇 |
| `io-network` | ⓘ howto 层，暂无 flow 域 —— 资源加载与异步见该篇 |
| `audio-advanced` | ⓘ howto 层，暂无 flow 域 —— 音频系统设计见该篇，本域只管**素材格式** |

## 3. 参数登记

| 参数 | 所在功能点 | 初始值 | 实测值 | 状态 |
|---|---|---|---|---|
| `ATLAS_PADDING_PX` 图集切片内边距（像素） | 03 | 2 | — | 待实测（⛔ 不足则线性过滤采到邻区） |
| `ATLAS_EXTRUDE_PX` 图集切片外扩（像素） | 03 | 1 | — | 待实测（⛔ padding 只挡缝隙，挡不住边缘光晕） |
| `MIPMAP_MEM_HEADROOM` mipmap 内存余量（比例） | 02 | 0.33 | — | 待实测（⛔ 官方：约 +33%） |
| `TEXTURE_BUDGET_MB` 单场景纹理显存上限（MB） | 02 | 256 | — | 待实测（⛔ 无预算就只能凭"无损最好"） |
| `FONT_SUBSET_GLYPHS` 中文子集字数 | 05 | — | — | 待实测（⛔ 不许按常用字表凭印象填） |
| `FONT_PRELOAD_RANGES` 预渲染字形范围 | 05 | — | — | 待实测（⛔ 预渲染涨加载时间与内存，见 audit #33） |
| `PKG_SIZE_BUDGET_MB` 包体上限（MB） | 07 | — | — | 待实测（⛔ 平台相关，硬编码即过期） |

⛔ 上表"待实测"项**不得凭行业惯例填** ——
填错不会报错，只会表现为"出包后包体/显存爆了"或"低配机上字体发虚"。

⛔ `FONT_SUBSET_GBYPHS` 一类数字尤其危险：
⛔ 漏字**不会显示成豆腐块**（官方 `allow_system_fallback` 默认 true，见 audit #19），
⛔ 本机永远看不出来，只会表现为**各平台字形不一致**。
