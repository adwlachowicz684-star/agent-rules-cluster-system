## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：合成台能合成、材料能扣、成品能出。**

⛔ 常见假完成：配方是**单输入单输出**，且**入队即扣材料**。
这两件事在只有一个配方时完全正常，等链变深（原矿 → 锭 → 部件 → 成品）才暴露。

做完这一步，应该能**当场演示**：

1. ⛔ 配方支持**中间产物 / 副产物 / 损耗 / 不可逆失败**
2. ⛔ 入队**只做可逆预留**，开始制作时才原子扣减
3. ⛔ 批量制作已拆成 N 个独立任务
4. ⛔ 加载配方时做过**拓扑检查**（无循环依赖）
5. ⛔ 材料不足有**四态**，自动暂停而非静默删除
6. ⛔ 暴击 / 完美 / 无损**互相独立**

**产出物**（下游按名字对接）：

```text
Recipe（inputs / outputs / byproducts / failure_chance / loss_on_failure / station_tags）
五阶段结算（校验 → 预扣 → 开始 → 完成 → 回滚）
四态（READY / MISSING_INPUTS / WAITING_STATION / PAUSED）
```

## 2. 工序

### Step 1　⛔ 配方是多级 DAG，不是单入单出　`[03#S1]`

【读】`howto/godot/lifeskill-housing.md#3. 加工链是有向无环图 + 原子事务`

【审】`audit/godot/lifeskill-housing.md#11`

⚠ 单输入单输出只是**特例**。真正的链是"原矿 → 锭 → 部件 → 成品"的多级图。
配方要显式表达中间产物、副产物、损耗、不可逆失败。

### Step 2　⛔ 入队 ≠ 消耗，开始时才原子扣减　`[03#S2]`

【读】`howto/godot/lifeskill-housing.md#3. 加工链是有向无环图 + 原子事务`

【审】`audit/godot/lifeskill-housing.md#12`

⚠ 先构建 `required` 与 `will_lose` 两个快照，**开始制作时才做原子扣减**。
⛔ 入队即扣 → "队列允许 10 个，中途第 3 个已无材料"。

### Step 3　⛔ 批量制作拆成 N 个任务，不能塞进单次 RNG　`[03#S3]`

【读】`howto/godot/lifeskill-housing.md#3. 加工链是有向无环图 + 原子事务`

【审】`audit/godot/lifeskill-housing.md#13`

⛔ 把数量塞进单次 RNG → 大批量**一次性承担极高损失**，
玩家也难以逐件控制失败。
✅ 拆成 N 个相同任务，逐件结算。

### Step 4　⛔ 加载配方时做拓扑检查，防循环依赖　`[03#S4]`

【读】`howto/godot/lifeskill-housing.md#3. 加工链是有向无环图 + 原子事务`

【审】`audit/godot/lifeskill-housing.md#14`

⛔ 一个"通用回收配方"就可能形成**无限增值**。
✅ 加载配方时建图做拓扑检查。
⚠ 两种缓存都要有最大展开深度：向上展开"做个成品要多少原始材料"、
向下展开"一个原材料最终能变成什么"。

### Step 5　⛔ 材料不足要四态，自动暂停优于静默删除　`[03#S5]`

【读】`howto/godot/lifeskill-housing.md#3. 加工链是有向无环图 + 原子事务`

【审】`audit/godot/lifeskill-housing.md#15`

⚠ 四态：`READY` / `MISSING_INPUTS` / `WAITING_STATION` / `PAUSED`。
⛔ 自动暂停优于静默删除；自动找替代又容易让玩家以为成品已锁定。
⛔ 替代组必须在**数据层显式配置**，不让客户端按名称模糊匹配。

### Step 6　⛔ 失败与损耗必须承担经济功能，且三类成功互相独立　`[03#S6]`

【读】`howto/godot/lifeskill-housing.md#失败与损耗必须承担经济功能`

【审】`audit/godot/lifeskill-housing.md#17`

⚠ 失败全保留材料 → 品质堆叠没有风险；失败清空所有材料 → 新玩家无法接受。
⛔ **暴击、完美、稀有成功要互相独立**，
不能形成"暴击必完美 + 完美必无损"的叠加。

⛔ 五阶段每步都要对：校验（拒绝非法 RPC）→ 预扣（可逆预留）→
开始（⛔ 不用客户端本地时间）→ 完成（⛔ 不由客户端上报结果）→
回滚（退回预留或按规则损耗）。

## 3. 参考实现

```gdscript
class_name Recipe extends Resource
@export var inputs: Array[Ingredient] = []
@export var outputs: Array[OutputSlot] = []
@export var byproducts: Array[OutputSlot] = []
@export var failure_chance: float = 0.05
@export var loss_on_failure: float = 0.5
@export var station_tags: Array[StringName] = []
```

```gdscript
# ⛔ 完成锚点必须由服务端写，不能用客户端本地时间
func start_job(job, now: int) -> void:
    if not consume_inputs(job):      # 原子扣减，失败则整体回滚
        job.state = JobState.MISSING_INPUTS   # ⛔ 暂停而非删除
        return
    job.finish_at = now + recipe.seconds      # ⛔ now 来自服务端
```

⛔ 数组字段（`inputs` / `outputs`）在 `duplicate(true)` 下**不会被复制**，
模板实例化的配方必须逐项复制（见 `01` Step 4）。

## 5. 常见返工

| 现象 | 回到 |
|---|---|
| 队列中途说没材料 | Step 2（入队即扣） |
| 批量一次损失惨重 | Step 3（塞进单次 RNG） |
| 材料可无限增值 | Step 4（无拓扑检查） |
| 任务莫名消失 | Step 5（静默删除而非暂停） |
| 客户端改时间立即完成 | Step 6（完成锚点非服务端） |
