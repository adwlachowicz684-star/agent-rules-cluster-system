# 04 熟练度与配方解锁（lifeskill 域）

> **前置**：`03`（加工链已通）
> **本步交付**：**三张表职责分离 + 各项收益硬上限**
> **对应**：做法 `howto/godot/lifeskill-housing.md#4. 熟练度：三张表 + 硬上限`
> 　　　审核 `audit/godot/lifeskill-housing.md`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：熟练度会涨、涨了会解锁配方，就够了。**

⛔ 常见假完成：熟练度**线性**增长，且回收率、技能收益、暴击概率**都没有上限**。
这两件事在前期完全正常，要到中期出现"自己种自己炼的无损闭环"才暴露。

做完这一步，应该能**当场演示**：

1. ⛔ 知识 / 等级 / 权重**三张表职责分离**（不是一张表）
2. ⛔ 解锁走**知识表**，不是等级表
3. ⛔ 熟练度收益**边际非线性**
4. ⛔ 回收率 / 技能收益 / 暴击概率**都有硬上限**
5. ⛔ 不存在"无损刷熟练度"闭环

**产出物**（下游按名字对接）：

```text
知识表（已解锁 recipe 集合）
等级表（熟练度数值）
权重表（产出品质分布）
硬上限清单（回收率 / 技能收益 / 暴击 / 单条属性 / 同类家具）
```

## 2. 工序

### Step 1　⛔ 熟练度提升的边际不能线性　`[04#S1]`

【读】`howto/godot/lifeskill-housing.md#4. 熟练度：三张表 + 硬上限`

【审】`audit/godot/lifeskill-housing.md#20`

⚠ 线性涨价 / 线性增产会崩：后期产出增速远超消耗增速。
✅ 收益曲线要有边际 —— 每级增量递减或成本递增。

### Step 2　⛔ 回收率、技能收益、暴击概率都要硬上限　`[04#S2]`

【读】`howto/godot/lifeskill-housing.md#4. 熟练度：三张表 + 硬上限`

【审】`audit/godot/lifeskill-housing.md#21`

⛔ 不封顶会出现：完美闭环（自己种自己炼无损循环）、
供给通胀、**无损刷熟练度**。
✅ 硬上限清单要逐项列出并集中配置。

### Step 3　⛔ 知识与等级是两张表，解锁走知识表　`[04#S3]`

【读】`howto/godot/lifeskill-housing.md#4. 熟练度：三张表 + 硬上限`

【审】`audit/godot/lifeskill-housing.md#33`

⚠ 配方发现与熟练度共享**知识（已解锁）/ 等级（熟练度）/ 权重（产出品质）**三张表。
⛔ 把"解锁"挂在等级上 → 玩家被迫刷熟练度才能用已发现的配方，
而"发现"是一次性事件（做出来过 / 学到过），两者语义不同。

### Step 4　⛔ 权重表不随等级表联动，品质分布单独配置　`[04#S4]`

【读】`howto/godot/lifeskill-housing.md#4. 熟练度：三张表 + 硬上限`

【审】`audit/godot/lifeskill-housing.md#34`

⚠ 权重表决定"产出什么品质"，等级表决定"熟练程度"。
⛔ 两者共用一套数值 → 调熟练度收益时**顺带改坏了品质分布**，
表现为"改动一处，掉落全变"，而改动本身看起来只动了等级。

### Step 5　⛔ 必须验证不存在无损刷熟练度的闭环　`[04#S5]`

【读】`howto/godot/lifeskill-housing.md#4. 熟练度：三张表 + 硬上限`

【审】`audit/godot/lifeskill-housing.md#21`

⛔ 只要存在"A 材料加工成 B、B 分解回 A 且无损耗"的路径，
玩家就能**零成本无限刷熟练度**，且所有产出指标看起来都在涨。
✅ 建图后跑一次闭环检测（与 `03` Step 4 的拓扑检查共用同一张图）。

## 3. 参考实现

```gdscript
# ⛔ 三张表分开存，不要合成一张
var knowledge: Dictionary = {}   # recipe_id -> true（已解锁，一次性事件）
var levels: Dictionary = {}      # skill_id -> int（熟练度数值）
var weights: Dictionary = {}     # skill_id -> 品质分布（与等级独立）

# ⛔ 每项收益都要有上限，集中配置便于回测
const CAPS := {
    "recycle_rate": 0.75,
    "skill_yield_bonus": 0.30,
    "crit_chance": 0.35,
}
```

⛔ 上限值必须集中在一处 —— 散落在各公式里则无法整体回测，
而经济回测（`07`）恰恰要求改一处就能重跑。

## 5. 常见返工
