# 00 域流程总览 · 生活职业 / 采集生产 / 家园建造（lifeskill 域）

## 0. 先定做什么

⚠ **本域的核心不是"怎么做采集 / 加工 / 家园"，而是"同一种材料在这三个闸门里，
是不是一个 ID、一套绑定规则、一个权威源"。**

生活玩法不是三个独立玩法，是**同一个材料闭环的三个闸门**：

```
采集（时间/风险/探索 → 材料） → 加工链（中间物/成品/副产物/损耗） → 家园（消耗终点 + 局部增益）
```

⛔ 分开实现的后果：**同一种材料在不同系统里有不同 ID、不同堆叠规则、
不同绑定状态和不同权威源** —— 而这个后果要到"玩家把绑定矿石交给公共加工设施、
再用另一个角色取走"时才被发现，那时三套数据结构都已定型。

本域讲**按什么顺序做**；单个要素怎么配见做法篇。

## 3. 本域最容易做反的顺序

⛔ **先做家园摆放，再统一 ID。** 摆放的视觉反馈最快，
于是先有了"家具表"和"材料表"两套 ID；等到加工链要接材料时才发现对不上。

⛔ **先做加工，再补循环依赖检查。** 一个"通用回收配方"
就能形成**无限增值**；链做完后加检查等于重画整张图。

⛔ **先在客户端判定，再补服务端权威。** 采集产出、合成结果、
放置合法性这三件事一旦在客户端跑过，补服务端等于重写所有权。

⛔ **刷新用相对倒计时。** 停服、分区、离线结算、时钟校正时
**累积漂移**，表现为"刷新时间越来越不准"，而单次测试完全正常。
