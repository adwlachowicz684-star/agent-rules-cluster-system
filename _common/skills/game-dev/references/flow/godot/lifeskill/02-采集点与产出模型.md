## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：矿点能采、能刷新，就以为采集系统做完了。**

⛔ 常见假完成：刷新用**相对倒计时**（`respawn_timer -= delta`），
单次测试完全正常，而停服、分区、离线结算、时钟校正时**累积漂移**。

做完这一步，应该能**当场演示**：

1. ⛔ 矿点**不是**节点自带状态，节点只是 `instance_id` 的视图
2. ⛔ 刷新存的是**绝对时间** `available_at`，不是倒计时
3. ⛔ 开放世界与个人领地用**两套**刷新语义
4. ⛔ 共享池用**随机占槽**（不是固定点位整点刷）
5. ⛔ 保底计数**已持久化**（不是只在内存里放大 RNG）

**产出物**（下游按名字对接）：

```text
GatherTemplate（模板 Resource）
WorldNodeState（instance_id / template_id / cell / charges / available_at / owner_peer）
两种刷新策略（共享池随机占槽 / 私有实例独立生成）
保底计数持久字段
```

## 2. 工序

### Step 1　⛔ 矿点不是场景脚本，是模板 + 世界实例　`[02#S1]`

【读】`howto/godot/lifeskill-housing.md#1. 采集点 = 模板 + 世界实例，不是一个场景脚本`

【审】`audit/godot/lifeskill-housing.md#6`

⛔ 矿点不能继承节点后保存 HP、刷新时间、占有者；**节点只是世界实例 ID 的视图**。
⚠ 一张地图 2,000 个矿点若各自成节点 → 节点树、处理循环、碰撞对象、
序列化、draw call、编辑器加载**全部线性叠加**。

### Step 2　⛔ 刷新存绝对时间，不存倒计时　`[02#S2]`

【读】`howto/godot/lifeskill-housing.md#1. 采集点 = 模板 + 世界实例，不是一个场景脚本`

【审】`audit/godot/lifeskill-housing.md#7`

⚠ `available_at` 用 **Unix 秒绝对时间**，服务端从 `node.available_at <= now`
推出可见性。
⛔ 相对倒计时在停服、分区、离线结算、时钟校正时**累积漂移**，
表现为"刷新越来越不准"，而单次运行完全正常。

### Step 3　⛔ 开放世界与个人领地是两套刷新语义　`[02#S3]`

【读】`howto/godot/lifeskill-housing.md#两种刷新语义要分开`

【审】`audit/godot/lifeskill-housing.md#8`

| 场景 | 策略 |
|---|---|
| 开放世界矿点 | **共享节点池**：区域登记若干 `spawn_slot`，采空后重新随机占用空槽 |
| 私有领地 / 个人资源岛 | **按角色或领地实例生成独立节点**，他人不可见 |

⛔ 两者不能用同一套逻辑：开放世界强调竞争与路线，私人空间强调确定性与离线收益。

### Step 4　⛔ 共享池用随机占槽，不要固定点位整点刷　`[02#S4]`

【读】`howto/godot/lifeskill-housing.md#两种刷新语义要分开`

【审】`audit/godot/lifeskill-housing.md#9`

⚠ 固定点位 + 固定间隔 → 玩家**整点蹲守**。
✅ 共享池用随机占槽可避免"固定点位时钟完全同步"。

### Step 5　⛔ 保底要进状态，不是放大 RNG　`[02#S5]`

【读】`howto/godot/lifeskill-housing.md#2. 产出：四层随机模型，保底进状态`

【审】`audit/godot/lifeskill-housing.md#10`

⚠ 四层：基础权重 → 品质修正 → 保底计数 → 最终产出。
⛔ 保底要**进入状态（未命中计数持久化）**，而不是放大 RNG ——
否则重开客户端保底清零，玩家永远抽不到稀有材料而看不到原因。
⛔ 失败、损耗、稀有材料**全部服务端结算**。

## 3. 参考实现

```gdscript
class_name WorldNodeState extends RefCounted
var instance_id: int
var template_id: StringName
var cell: Vector3i
var charges: int
var available_at: int      # ⚠ Unix 秒绝对时间，不是倒计时
var owner_peer: int = 0

# ⛔ 服务端从绝对时间推可见性，不做 countdown -= delta
func is_available(now: int) -> bool:
    return available_at <= now and charges > 0
```

⛔ 保底计数必须随 `WorldNodeState` 或角色状态一起持久化，
只放内存等于"每次重开都从零开始"。
