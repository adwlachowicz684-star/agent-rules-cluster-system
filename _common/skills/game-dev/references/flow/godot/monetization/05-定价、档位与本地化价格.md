# 05 定价、档位与本地化价格（商业化域）

> **本步交付**：平台档位 + 不自算汇率 + UTC 周期 + 限额实现
> **对应**：流程 `howto/godot/monetization.md` · 审核 `audit/godot/monetization.md`

## 0. 交付物定义

1. 商品档位来自平台，不自造价格
2. 展示价格用平台返回的本地化结果
3. 日 / 周 / 月周期按 **UTC** 重置
4. 未成年限额作为**产品需求**实现，不是运营口头约定

## 1. 前置检查清单

- [ ] 01 已完成
- [ ] 各平台商品已在后台创建（档位由平台定义）
- [ ] 已确认发行地区（决定限额与公示口径）

## 2. 工序

### Step 1　档位由平台定义，不自己定价　`[monetization/05#S1]`

【读】`howto/godot/monetization.md#6. 商城与定价`

【做】
商品与档位在平台后台创建，客户端只按 `product_id` 拉取并展示。
⛔ 在客户端 / 服务端自己定义"6 元 = 60 钻石"并硬编码价格 ——
各平台有**固定档位**，随便定价会导致后台配置不上或被拒审。

【产出】`product_id` → 档位映射（来自平台后台）

【判据】改平台后台价格，客户端展示随之变化，客户端代码零改动。

【审】`audit/godot/monetization.md#30`

### Step 2　本地化价格用平台返回值，不自算汇率　`[monetization/05#S2]`

【读】`howto/godot/monetization.md#6. 商城与定价`

【做】
展示用平台返回的本地化价格字符串与币种。
⛔ 拿一个基准价按汇率自己换算 —— 汇率、税费、各区定价策略都不在你的掌握中，
算出来的价格与玩家实际被扣的**不一致**，这是**退款与差评**的直接来源。

【产出】价格展示统一走平台返回的字段

【判据】切到三个不同地区账号，展示的价格与被扣金额完全一致。

【审】`audit/godot/monetization.md#31`

### Step 3　周期重置按 UTC，不用本地时区　`[monetization/05#S3]`

【读】`howto/godot/monetization.md#6. 商城与定价`

【做】
日 / 周 / 月重置与月卡到期统一按 **UTC** 计算，服务端下发绝对时间戳。
⛔ 按玩家本地时区算 —— 跨时区玩家的"每日重置"落在不同时刻，
表现为"有人一天刷了两次"，而运营看到的是数据异常，不会想到时区。
⛔ 用 `Time` 的 `_from_system` 系列做精确计时 —— 官方明确该系统时钟**用户可手动设置**。

【产出】UTC 周期计算 + 服务端下发的重置时间戳

【判据】改设备时区到东西两端各测一次，重置时刻的 UTC 秒数完全一致。

【审】`audit/godot/monetization.md#32`

### Step 4　未成年限额与宵禁是产品需求，要实现　`[monetization/05#S4]`

【读】`howto/godot/monetization.md#1. ⚠ 合规优先于体验`

【做】
把限额表（未满 8 岁禁止付费；8–16 岁单次 50 / 每月 200；16–18 岁单次 100 / 每月 400）
与宵禁时段实现为**服务端规则**，并在客户端给出可理解的提示。
⛔ 当成"法务的事"只在用户协议里写一句 —— 是**产品需求**，
没实现就是没实现，⛔ 且这是**行政处罚**级别的风险。

【产出】服务端限额规则（可配置）+ 触发时的明确提示

【判据】构造各年龄段测试账号，超限时被拒且提示文案说清原因与额度。

【审】`audit/godot/monetization.md#35`

### Step 5　商业化判定不进热更包　`[monetization/05#S5]`

【读】`howto/godot/monetization.md#9. 退款、风控与审计日志`

【做】
价格、档位、限额、发货判定全部在服务端；客户端热更包只更新展示资源。
⛔ 把价格表 / 限额规则放进可热更的配置 —— ⛔ 等于把定价权交给了热更通道，
一旦通道被利用就是**直接改价**，且这是合规问题不是技术问题。

【产出】商业化逻辑的服务端 / 客户端边界清单

【判据】改热更包里任何配置，都不能改变实际扣款金额与发货结果。

【审】`audit/godot/monetization.md#39`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：展示用平台返回值，周期用服务端 UTC 时间戳
# ⛔ 不自算汇率、不用本地时区、不用 _from_system 做精确计时
const PERIOD_KEYS := ["daily", "weekly", "monthly"]

func _format_reset_time(reset_unix_utc: int) -> String:
    var d := Time.get_datetime_dict_from_unix_time(reset_unix_utc)
    return "%02d:%02d UTC" % [d.hour, d.minute]
```

| 后台改价客户端不变 | 价格硬编码 | S1 |
