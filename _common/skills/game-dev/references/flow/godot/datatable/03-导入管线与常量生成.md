# 03 导入管线与常量生成（配置表域）

> **前置**：02 的 `Resource` 类定义已完成
> **本步交付**：CSV 能一键转成 `.tres`（或 `.res`），并生成 ID 常量文件
> **对应**：做法 `howto/godot/datatable.md` · 审核 `audit/godot/datatable.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 改 CSV → 跑导入 → `.tres` 更新（不用手改）
2. ⚠ 生成的 ID 常量文件让 `Data.SKILL_FIREBALL` 可用
3. `preload()` 全部表时启动时间可接受（或已走异步）
4. ⚠ 已确认**导出后**仍能读到（⛔ 不是只在编辑器里行）
5. 导入是**幂等**的：同一份 CSV 跑两次结果一致

**产出物**（下游按名字对接）：

```text
导入脚本（编辑器插件 / EditorScript / 命令行）
res://data/generated/*.tres
res://data/generated/ids.gd   ID 常量
```

## 2. 工序

### Step 1　读 CSV（用 get_csv_line）　`[datatable/03#S1]`

【读】`howto/godot/datatable.md#1. 数据源格式对比`

【做】
```gdscript
var f := FileAccess.open(path, FileAccess.READ)
if f == null:
    push_error("打不开 %s: %d" % [path, FileAccess.get_open_error()])
    return
var header := f.get_csv_line()      # 第一行是列名
while not f.eof_reached():
    var row := f.get_csv_line()
    if row.size() < header.size():
        continue                     # ⚠ 空行/残缺行跳过
```

⚠ `FileAccess.get_csv_line()` 返回 `PackedStringArray`，
比 `String.split(",")` 更可靠（能处理带引号的字段）。

⚠ 要跳过空行和残缺行——Excel 经常在末尾留下空行。

【产出】能读出列名与每一行

【判据】⚠ 打印行数 == Excel 里的数据行数（不含表头与空行）

【审】`audit/godot/datatable.md#7`（CSV 导入器够了 → 没有校验）

### Step 2　列名映射与类型转换　`[datatable/03#S2]`

【读】`howto/godot/datatable.md#3. 导入期校验是必做步骤`

【做】⚠ **CSV 里全是字符串**，要转成 `int` / `float` / `StringName`。
⛔ 直接赋值给 `@export var damage: int` 不会自动转。

✅ 按 02 的类定义逐字段映射，转换失败要**报出具体行列**。

【产出】每个字段有明确的转换函数与失败提示

【判据】⚠ 故意在数值列写 `abc`，报错**包含行号与列名**

【审】`audit/godot/datatable.md#7`

### Step 3　生成 ID 常量　`[datatable/03#S3]`

【读】`howto/godot/datatable.md#5. ID 规范`

【做】⚠ **字符串 ID 需要常量生成防拼写错** ——
手敲 `"skill.firebal"` 少一个 l，只能运行时才发现。

生成的 `ids.gd`：
```gdscript
const SKILL_FIREBALL := &"skill.fireball"
const SKILL_ICEBOLT := &"skill.icebolt"
```

⚠ 常量文件是**生成物**，⛔ 不要手改——下次导入会覆盖。

【产出】`ids.gd` 覆盖所有表的 ID

【判据】⚠ 代码里搜字符串字面量 ID，**结果为 0**（全用常量）

【审】`audit/godot/datatable.md#11`（ID 用数字省内存 → 需要常量生成）

### Step 4　保存产物（tres vs res）　`[datatable/03#S4]`

【读】`howto/godot/datatable.md#1. 数据源格式对比`

【做】
```gdscript
ResourceSaver.save(resource, "res://data/generated/%s.tres" % id)
```

| | `.tres` | `.res` |
|---|---|---|
| 文本 | ✅ diff 友好、可手工修 | ⛔ 二进制 |
| 体积/加载 | 大、慢 | 小、快（可 `FLAG_COMPRESS`） |

⚠ `ResourceSaver.save()` 的 flags：`FLAG_COMPRESS` 用 zstd 压缩，
**仅对二进制资源类型可用**。

【产出】产物格式已定，且放进 `generated/` 与手写资产分离

【判据】⚠ 删掉 `generated/` 后重跑导入，**完全恢复**

【审】`audit/godot/datatable.md#2`

### Step 5　⚠ 导出后还能读到　`[datatable/03#S5]`

【读】`howto/godot/datatable.md#6. 导出与运行时加载的冲突（隐藏最深的一条）`

【做】⚠ **项目设置 `editor/export/convert_text_resources_to_binary` 若为 `true`，
导出后 `load()` 读不了被转换的文件。**

官方原话：开启时 `@GDScript.load` 将无法读取导出项目中被转换的文件；
若要在运行时加载 PCK 内的文件，必须设为 `false`。

⛔ 症状极具迷惑性：**编辑器里一切正常，导出后配表全空**。
报错往往不是"文件不存在"，而是拿到空资源 → "技能伤害全是 0"。

```text
editor/export/convert_text_resources_to_binary = false
```

【产出】设置已确认，且**导出版本实测**能加载

【判据】⚠ 真机跑导出包，配表**有数据**（⛔ 不是只在编辑器里通）

【审】`audit/godot/datatable.md#7`

### Step 6　导入幂等　`[datatable/03#S6]`

【读】`howto/godot/datatable.md#3. 导入期校验是必做步骤`

【做】⚠ 同一份 CSV 跑两次，产物**必须一致**
（含 ID 顺序、子资源路径）。

⛔ 不幂等的话，每次导入都产生 diff，
代码评审时满屏是无关变更，真改动反而看不见。

【产出】跑两次后 `git diff` 为空

【判据】⚠ 连续导入两次，`git status` **无变化**

【审】`audit/godot/datatable.md#7`

## 3. 参考实现

```gdscript
# ⓘ 导入器骨架（编辑器插件或命令行跑，不进运行时）
@tool
extends EditorScript

const CSV_DIR := "res://data/csv/"
const OUT_DIR := "res://data/generated/"

func _run() -> void:
    var rows := _read_csv(CSV_DIR + "skill.csv")
    var consts: PackedStringArray = []
    for r in rows:
        var d := SkillData.new()            # ⚠ 无参构造（见 02 S5）
        d.id = StringName(r["id"])
        d.name_key = "skill.%s.name" % r["id"]
        d.base_damage = _to_int(r, "base_damage")
        d.cooldown = _to_float(r, "cooldown")
        ResourceSaver.save(d, "%s%s.tres" % [OUT_DIR, _safe(r["id"])])
        consts.append('const %s := &"%s"' % [_const_name(r["id"]), r["id"]])
    _write_ids(consts)                      # ⚠ 生成物，别手改

func _to_int(row: Dictionary, col: String) -> int:
    if not row.has(col) or not row[col].is_valid_int():
        push_error("第 %d 行 %s 不是整数: %s" % [row["__line"], col, row.get(col, "")])
        return 0
    return int(row[col])
```

⚠ `_safe()` 是必要的：ID 里可能有 `/` 或空格，直接当文件名会失败。

| 症状 | 原因 | 回到 |
|---|---|---|
| 列名永远匹配不上 | CSV 带 BOM | S1 |

| 拼错 ID 运行时才炸 | 没生成常量 | S3 |
