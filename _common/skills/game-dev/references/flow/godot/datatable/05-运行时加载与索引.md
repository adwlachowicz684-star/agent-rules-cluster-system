# 05 运行时加载与索引（配置表域）

> **前置**：03 已产出 `.tres`，04 校验已通过
> **本步交付**：启动时（或按需）加载全部表并建好索引，启动耗时可接受
> **对应**：做法 `howto/godot/datatable.md` · 审核 `audit/godot/datatable.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. `Data.get_skill(&"skill.fireball")` 能拿到只读模板
2. ⚠ 启动加载耗时**已实测**并回填参数表
3. ⚠ 若走异步：用了 `load_threaded_request`，且**没在轮询外调 `load_threaded_get`**
4. 重复请求同一路径有守卫（不会出现 `ERR_ALREADY_IN_USE`）
5. 索引是**只读**的，运行时不往里写

**产出物**（下游按名字对接）：

```text
Data 单例（autoload）
_index: Dictionary     id -> 只读模板
get_skill(id) / get_item(id) ...
```

## 2. 工序

### Step 1　建索引：id -> 模板　`[datatable/05#S1]`

【读】`howto/godot/datatable.md#2. Resource 作为配表载体`

【做】
```gdscript
var _index: Dictionary = {}      # StringName -> SkillData（只读模板）

func _build_index() -> void:
    for path in _scan("res://data/generated/skill/"):
        var d := load(path) as SkillData
        _index[d.id] = d
```

⚠ 用 `StringName`（`&"..."`）做键，不是 `String`——
配表 ID 会高频比较与查表，`StringName` 比较是哈希比较。

⚠ **索引里的对象是只读模板**，⛔ 运行时绝不修改它（见 06）。

【产出】`get_skill(id)` 能取到模板

【判据】⚠ 对同一个 ID 调两次，返回的是**同一个对象**（引用相等）

【审】`audit/godot/datatable.md#3`（Resource 存运行时状态 → 会被共享）

### Step 2　preload vs load vs 异步　`[datatable/05#S2]`

【读】`howto/godot/datatable.md#4. 运行时加载`

【做】三种路径的取舍：

| | 时机 | 代价 |
|---|---|---|
| `preload()` | **编译期** | ⚠ 启动时全加载，内存与启动时间都是代价 |
| `load()` | 调用时（同步） | 会阻塞当前帧 |
| `load_threaded_request()` | 异步 | ✅ 推荐（大表/多表） |

⚠ **`preload()` 在编译期加载** —— 启动时全加载。
⚠ **`load_threaded_request()` 才是异步路径**，
⛔ **不是** `load()` 放线程里（那是自己开线程同步读，容易踩线程安全）。

【产出】已选定加载方式，理由落在"启动耗时实测"上

【判据】⚠ 打印启动到索引建好的耗时，数值**已回填**参数表

【审】`audit/godot/datatable.md#9` `audit/godot/datatable.md#13`

### Step 3　⛔ load_threaded_get 会阻塞　`[datatable/05#S3]`

【读】`howto/godot/datatable.md#8. 异步加载的三个 API 与一个阻塞陷阱`

【做】⚠ **`load_threaded_get()` 在加载未完成时，会阻塞调用线程直到加载结束**
—— 官方原话就是这个。

⛔ 不能在轮询之外"顺手"调它，
必须在 `get_status()` 返回 `THREAD_LOAD_LOADED` **之后**再取。
否则异步就退化成同步，白做。

【产出】`load_threaded_get` 只在 LOADED 分支里调用

【判据】⚠ 加载大表时，加载画面**不卡**（帧率正常）

【审】`audit/godot/datatable.md#9`

### Step 4　重复请求守卫　`[datatable/05#S4]`

【读】`howto/godot/datatable.md#8. 异步加载的三个 API 与一个阻塞陷阱`

【做】⚠ **重复对同一路径 `load_threaded_request()` 会返回 `ERR_ALREADY_IN_USE`**。

玩家连点两次触发、或同一表被两个系统同时请求，都会刷出这个错误。

✅ 用一个"请求中"的集合做守卫：

```gdscript
var _pending: Dictionary = {}
func request(path: String) -> void:
    if _pending.has(path):
        return                      # ⚠ 守卫
```

【产出】重复请求不报错

【判据】⚠ 同一帧内请求同一路径 10 次，**无 `ERR_ALREADY_IN_USE`**

【审】`audit/godot/datatable.md#9`

### Step 5　索引只读　`[datatable/05#S5]`

【读】`howto/godot/datatable.md#2. Resource 作为配表载体` 的 ⚠

【做】⚠ 索引是**只读视图**。运行时要改数据，必须拷贝（见 06）。

⛔ 一旦有人在运行时改了模板，
所有引用该模板的实例**同时变化**，
而且症状是"改一个全改"——Godot 4 的 #1 新手 bug。

【产出】`Data` 暴露的接口只返回模板，且文档注明只读

【判据】⚠ 全项目搜索对 `Data.get_*()` 结果的赋值，**为 0**

【审】`audit/godot/datatable.md#3`

### Step 6　大表按需加载　`[datatable/05#S6]`

【读】`howto/godot/datatable.md#4. 运行时加载`

【做】ⓘ 若某张表极大（上万行），启动时全加载不合适。

两种做法：
- **按组分文件** —— `skill/` 下按类别分多个 `.tres`，用到哪组加载哪组
- **索引与数据分离** —— 先加载一个轻量索引（id → 路径），用到再加载具体行

⚠ 不要为了"优化"提前做这个——
先测出启动耗时，**确定是瓶颈再做**。

【产出】启动耗时在可接受范围（或已拆分）

【判据】⚠ 启动耗时**低于你的目标值**（如 500ms）

【审】`audit/godot/datatable.md#13`（preload 很方便 → 编译期加载启动变慢）

## 3. 参考实现

```gdscript
const ASYNC_THRESHOLD := 2 * 1024 * 1024   # 超过 2 MB 走异步，待实测

# data.gd （autoload）
extends Node

var _skill: Dictionary = {}
var _pending: Dictionary = {}
var _progress: Array = []

func _ready() -> void:
    if _total_size() > ASYNC_THRESHOLD:
        _request_all_async()
    else:
        _load_all_sync()
    _build_all()

func request(path: String) -> void:
    if _pending.has(path):
        return                                    # ⚠ 守卫
    var err := ResourceLoader.load_threaded_request(path)
    if err != OK:
        push_error("异步加载请求失败 %s: %d" % [path, err])
        return
    _pending[path] = true

func _process(_delta: float) -> void:
    for path in _pending.keys():
        var st := ResourceLoader.load_threaded_get_status(path, _progress)
        if st == ResourceLoader.THREAD_LOAD_LOADED:
            var res := ResourceLoader.load_threaded_get(path)   # ✅ 就绪才取
            _pending.erase(path)
            _on_loaded(path, res)
        elif st == ResourceLoader.THREAD_LOAD_FAILED:
            push_error("异步加载失败 %s" % path)
            _pending.erase(path)

func get_skill(id: StringName) -> SkillData:
    return _skill.get(id)      # ⚠ 只读模板，调用方要改请 duplicate
```

⚠ `get_skill()` 返回的是**模板**。调用方要持有可修改的运行时数据，
必须走 06 的深拷贝——这是最容易漏的一条约定。
