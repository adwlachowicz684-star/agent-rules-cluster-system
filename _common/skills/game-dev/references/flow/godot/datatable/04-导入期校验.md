# 04 导入期校验（配置表域）

> **前置**：03 导入管线已能跑通
> **本步交付**：坏数据在**进包之前**被拦下——⛔ 不是警告，是阻止导入
> **对应**：做法 `howto/godot/datatable.md` · 审核 `audit/godot/datatable.md`

## 0. 交付物定义

⚠ **一句话**：校验失败应该**报错并阻止导入**，不是警告。
否则坏数据进了包，问题会在运行时以**完全无关的形式**出现。

做完这一步，应该能**当场演示**：

1. 故意造四种坏数据，全部**阻止导入**且报错带行列
2. ⚠ 校验通过的表才能生成产物（⛔ 不是"生成了但打印警告"）
3. 外键悬空能被查出来
4. 数值超范围能被查出来
5. ⚠ 已在 CI 或提交流程里跑（不是靠人记得点一下）

**产出物**（下游按名字对接）：

```text
_validate_all(tables) -> bool      返回 false 就中止导入
每条报错格式：<表> 第 N 行 <列名>：<原因>
```

### Step 2　⛔ 阻止导入而不是警告　`[datatable/04#S2]`

【读】`howto/godot/datatable.md#3. 导入期校验是必做步骤` 的 ⚠

【做】⚠ **校验失败应该报错并阻止导入，不是警告** ——
否则坏数据进了包，问题会在运行时以完全无关的形式出现。

ⓘ 为什么"警告"没用：
导入是批量操作，一屏几百行输出，没有人会逐行看警告。
而坏数据的后果会**延迟到运行时**，且表现为"血量是负的"
而不是"第 30 行错了"——排查成本差两个数量级。

【产出】校验不通过时**不写任何产物**，返回错误码

【判据】⚠ 坏表导入后，`generated/` 目录**没有更新**

【审】`audit/godot/datatable.md#8`（校验失败警告一下就行 → 要阻止导入）

### Step 3　外键悬空检查　`[datatable/04#S3]`

【读】`howto/godot/datatable.md#3. 导入期校验是必做步骤`

【做】⚠ **外键悬空** —— 指向不存在的 ID。

ⓘ 这依赖 02 的"外键存 ID"决定：
正因为存的是字符串 ID，才能在这里做**纯文本比对**。
若存的是 Resource 引用，悬空会表现为加载失败而不是校验错误。

⚠ 要**先收集全部表的 ID 集合**，再统一校验——
表之间有循环引用是很正常的（A 需要 B，B 需要 A）。

【产出】跨表外键检查（不是只查单表内）

【判据】⚠ 删掉被引用的那一行，导入**报错指出引用方**

【审】`audit/godot/datatable.md#6`

### Step 4　范围与语义约束　`[datatable/04#S4]`

【读】`howto/godot/datatable.md#3. 导入期校验是必做步骤`

【做】⚠ **范围** —— 负数、超上限。

ⓘ 除了"不为负"这类通用约束，还要写**语义约束**：

```text
掉落权重之和 > 0
技能冷却 > 0 或 == 0（表示无冷却，但不能为负）
升级曲线的第 N 级 >= 第 N-1 级
```

⚠ 语义约束是"只有你知道"的那部分，
也是策划最容易填错的部分（复制粘贴时漏改）。

【产出】每张表至少一条语义约束

【判据】⚠ 人为把掉落权重全填 0，导入**被阻止**

【审】`audit/godot/datatable.md#18`

## 3. 参考实现

```gdscript
func _validate_all(tables: Dictionary) -> bool:
    var ok := true

    # ⚠ 先收集全部 ID，再查外键（表间可循环引用）
    var all_ids: Dictionary = {}
    for t in tables:
        all_ids[t] = {}
        for row in tables[t]:
            all_ids[t][row["id"]] = true

    for t in tables:
        var seen: Dictionary = {}
        for row in tables[t]:
            var line := int(row.get("__line", 0))
            # 1) 主键重复
            if seen.has(row["id"]):
                push_error("%s 第 %d 行：duplicate id %s" % [t, line, row["id"]])
                ok = false
            seen[row["id"]] = true
            # 2) 外键悬空
            var fk := row.get("require_skill", "")
            if fk != "" and not all_ids.get("skill", {}).has(fk):
                push_error("%s 第 %d 行 require_skill 悬空：%s" % [t, line, fk])
                ok = false
    return ok          # ⚠ false 就中止，不写产物
```

⚠ 注意 `_validate_all` 返回 `false` 时**直接 return，不保存任何东西**——
部分写入比全不写更糟（会让人以为"导入成功了只是有几条警告"）。
