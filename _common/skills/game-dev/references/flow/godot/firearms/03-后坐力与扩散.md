# 03 后坐力与扩散（枪械 / 射击系统域）

> **本步交付**：后坐力拆成三个独立变量 + 可学习模式 + 玩家可读的扩散
> **对应**：流程 `howto/godot/firearms.md` · 审核 `audit/godot/firearms.md`

## 0. 交付物定义

1. 后坐力是**视觉 / 模式 / 扩散**三个独立变量，不是一个"镜头抖动"
2. 后坐力模式可学习（固定模式 + 越界稳态），压枪技术有意义
3. 扩散**可读**：准星实时显示命中半径

## 1. 前置检查清单

- [ ] 已拆分三个变量，没有混成一个
- [ ] ⚠ 已确认扩散有可视化（准星）
- [ ] 有一堵墙可打弹孔测分布

## 2. 工序

### Step 1　后坐力拆成视觉 / 模式 / 扩散三个独立变量　`[firearms/03#S1]`

【读】`howto/godot/firearms.md#2. 后坐力是三个独立变量，不是镜头抖动`

【做】
⛔ 后坐力 = 镜头抖动 —— 混了之后**准星与落点永久错位**，且无从修。
⛔ 直接改摄像机旋转生成弹道 —— 同上，弹道要由模式驱动。

【产出】三个变量各自的数据结构（互不影响）

【判据】关掉视觉后坐力，落点分布不变（只影响观感）。

【审】`audit/godot/firearms.md#8`

### Step 2　模式固定且可学习，带 decay_delay　`[firearms/03#S2]`

【读】`howto/godot/firearms.md#2. 后坐力是三个独立变量，不是镜头抖动`

【做】
固定模式 + 越界稳态。
⛔ 后坐力纯随机 —— 没有可学习性，压枪技术无意义。
⛔ 后坐力每帧朝零插值 —— 开火期间第一发上抬被立即抵消；要 `decay_delay` 后接管。

【产出】`recoil_pattern` + `decay_delay` 参数

【判据】同一把枪连打两梭子，弹孔分布形状一致（可学习）。

【审】`audit/godot/firearms.md#10`

### Step 3　扩散可读：准星实时显示命中半径　`[firearms/03#S3]`

【读】`howto/godot/firearms.md#3. 扩散必须可读、可收敛`

【做】
⛔ 不可读的 Random Circle 只是**随机惩罚** —— 玩家认为系统骗他。
准星要实时反映当前命中半径。
⛔ 准星反向参与命中 —— 缩放动画、画布宽高比会偷偷改变枪法。

【产出】准星随扩散实时缩放（**只读，不参与命中计算**）

【判据】连发时准星张开，停火后收拢，且与弹孔分布一致。

【审】`audit/godot/firearms.md#15`

### Step 4　扩散按乘区组合，写进数据规约　`[firearms/03#S4]`

【读】`howto/godot/firearms.md#7. ADS 是独立状态，扩散按乘区组合`

【做】
移动 / 跳跃 / ADS / 连发各是一个乘区，乘法加法**二选一**并写进规约。
⛔ 扩散乘区散落在 if-else —— 改动时必然漏项。
⛔ ADS 瞬间消除全部扩散 —— 玩家感觉前几毫秒开了挂。

【产出】乘区表 + 组合规则（明确是乘还是加）

【判据】改一个乘区，扩散结果按规约变化，没有散落的 if-else 漏掉。

【审】`audit/godot/firearms.md#37`

### Step 5　视觉后坐力分层，不无限累积　`[firearms/03#S5]`

【读】`howto/godot/firearms.md#2. 后坐力是三个独立变量，不是镜头抖动`

【做】
短期上抬 / 中期阻尼 / 长期 roll 三层分开。
⛔ 视觉后坐力无限累积 —— 打完一梭子枪口指天且回不来。
⛔ 动画师手工 key 后坐力动作 —— 必须依赖 `pattern_offset`，不能与数据无关。

【产出】三层视觉参数 + 与模式的绑定方式

【判据】停火后视觉在预期时间内回正，不残留偏移。

【审】`audit/godot/firearms.md#13`
【品】`craft/godot/feel-params.md#5. 屏幕震动（Trauma 模型）`

## 3. 参考实现

```gdscript
# ⓘ 承接 Step 1/2/5：三个变量独立，模式固定可学习
const DECAY_DELAY := 0.12      # 开火后多久才开始回正
const SPREAD_PER_SHOT := 0.35  # 每发固定增量（度）
const SPREAD_MAX := 3.0

var _spread := 0.0
var _visual_recoil := Vector2.ZERO

func apply_shot_recoil(shot_index: int) -> void:
    var p := _ctx.recoil_pattern
    var off := p[shot_index] if shot_index < p.size() else p[-1]
    _visual_recoil += off                 # 视觉（观感）
    _spread = minf(_spread + SPREAD_PER_SHOT, SPREAD_MAX)  # 扩散（命中）
```
