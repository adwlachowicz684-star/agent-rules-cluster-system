# 06 多人射击与延迟补偿（枪械 / 射击系统域）

> **本步交付**：服务端权威判定 + rewind 有窗口上限 + 时基统一
> **对应**：流程 `howto/godot/firearms.md` · 审核 `audit/godot/firearms.md`

## 0. 交付物定义

1. 命中判定在**服务端**，客户端只提交输入
2. rewind（延迟补偿）有**窗口上限**
3. 时基统一，客户端与服务器不混用两套时间

## 1. 前置检查清单

- [ ] 已确认命中判定在服务端（不是客户端说了算）
- [ ] ⚠ 已定义 rewind 最大回退窗口
- [ ] 有两个客户端可测

## 2. 工序

### Step 1　命中判定绝不能由客户端定　`[firearms/06#S1]`

【读】`howto/godot/firearms.md#10. 多人射击：服务端验证输入与结果`

【做】
⛔ 客户端说"我打中 X 扣 Y 血" —— 这是**可直接利用的漏洞**。
客户端只提交输入与朝向，服务端验证输入与结果。

【产出】服务端判定路径（客户端只发 intent）

【判据】伪造客户端消息无法造成伤害。

【审】`audit/godot/firearms.md#52`

### Step 2　rewind 必须有窗口上限　`[firearms/06#S2]`

【读】`howto/godot/firearms.md#延迟补偿（rewind）`

【做】
⛔ rewind 无窗口上限 —— 会引入重计算开销、时钟伪造、时间跳跃漏洞。
⛔ 以为修好 rewind 就没 peeker's advantage —— 那是**预测与延迟的固有产物**，只能缓解。

【产出】`MAX_REWIND_MS` + 超出窗口的处理（按当前状态判定）

【判据】构造超高延迟客户端，回退不超过窗口上限。

【审】`audit/godot/firearms.md#55`

### Step 3　时基统一，不混用 get_ticks_msec 与服务器 tick　`[firearms/06#S3]`

【读】`howto/godot/firearms.md#延迟补偿（rewind）`

【做】
⛔ 混用 `get_ticks_msec()` 与服务器 tick —— 两侧时钟漂移，rewind 算出错误的过去位置。

【产出】唯一下游时基（服务器 tick），客户端时间只用于插值显示

【判据】长时间运行后（>10 分钟）命中判定不漂移。

【审】`audit/godot/firearms.md#54`

### Step 4　观战不混入 rewind 逻辑　`[firearms/06#S4]`

【读】`howto/godot/firearms.md#延迟补偿（rewind）`

【做】
⛔ 观战视角混入 rewind 逻辑 —— 观战者看到的不是真实世界状态，会造成误判。

【产出】观战走独立路径（只消费快照，不参与补偿）

【判据】观战画面与服务器真实状态一致。

【审】`audit/godot/firearms.md#57`

### Step 5　反馈可协商，不得改变伤害　`[firearms/06#S5]`

【读】`howto/godot/firearms.md#10. 多人射击：服务端验证输入与结果`

【做】
⛔ 客户端反馈反向改变伤害 —— 反馈（命中标记、音效）是表现层，
⛔ **绝不能反向影响权威结果**。
⛔ 客户端把渲染结果发回服务端 —— 摄像机只能用于输入投射。

【产出】反馈与权威结算的单向边界（表现 ← 权威，不可反向）

【判据】客户端不报命中，服务端该中的依然中。

【审】`audit/godot/firearms.md#58`

### Step 6　projectile 走服务端模拟 + 低频同步 + 外插　`[firearms/06#S6]`

【读】`howto/godot/firearms.md#1. hitscan 与 projectile：选择依据是手感，不是优劣`

【做】
⛔ 每帧给每个 projectile 发位置 RPC —— 带宽与状态都不稳定。
服务端持续模拟 + 低频同步 + 客户端预测外插。

【产出】投射物同步策略（频率 + 外插 + 校正）

【判据】弱网下投射物轨迹平滑，不出现瞬移或抖动。

【审】`audit/godot/firearms.md#53`

## 3. 参考实现

```gdscript
# ⓘ 承接 Step 2/3：窗口上限 + 唯一下游时基
const MAX_REWIND_MS := 200
const TICK_RATE := 60

func rewind_to(client_time_ms: int, now_ms: int) -> int:
    var back := now_ms - client_time_ms
    if back > MAX_REWIND_MS:
        back = MAX_REWIND_MS      # ⛔ 超窗不无限回退，见 Step 2
    if back < 0:
        back = 0
    return back
```
