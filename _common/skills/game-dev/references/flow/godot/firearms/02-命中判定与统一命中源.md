# 02 命中判定与统一命中源（枪械 / 射击系统域）

> **本步交付**：三套坐标归一到统一命中源 + 射线时序正确 + 不会打到自己
> **对应**：流程 `howto/godot/firearms.md` · 审核 `audit/godot/firearms.md`

## 0. 交付物定义

1. 瞄准 / 角色 / 枪口三套坐标**归一到一个权威命中源**
2. 射线读取时序正确（不读上一物理帧的陈旧结果）
3. 不会打到自己 / 不会从掩体内穿透判定出错

## 1. 前置检查清单

- [ ] 已定义"权威命中源"是哪一个（枪口 / 相机 / 两者归一）
- [ ] ⚠ 已确认射线在 `_physics_process()` 内取
- [ ] 有一面墙和一段掩体可测

## 2. 工序

### Step 1　三套坐标归一到统一命中源　`[firearms/02#S1]`

【读】`howto/godot/firearms.md#8. 掩体：三套坐标（瞄准 / 角色 / 枪口）`

【做】
瞄准（相机）、角色（胶囊）、枪口（武器 socket）三套坐标归一。
⛔ 射线从摄像机中心发 —— "看到头露出来却打不到人"；
⛔ 射线从枪口发 —— 贴墙时"看不见目标却命中"。两者都要归一到**统一命中源**。

【产出】`aim_origin` / `aim_dir` 的唯一取值路径

【判据】贴墙探头时，看到的与打到的**是同一个东西**。

【审】`audit/godot/firearms.md#42`

### Step 2　射线不读上一物理帧的陈旧结果　`[firearms/02#S2]`

【读】`howto/godot/firearms.md#1. hitscan 与 projectile：选择依据是手感，不是优劣`

【做】
⛔ 每帧挂 `RayCast3D`、开火时直接读 `is_colliding()` ——
**官方口径：RayCast3D 每物理帧算一次，结果保留到下一物理帧**，读到的是上一帧的。
开火瞬间必须 `force_raycast_update()`，或用直接空间查询。

【产出】开火路径上的射线取值方式（二选一，全项目统一）

【判据】移动中开火，命中点与准星一致（不滞后一帧）。

【审】`audit/godot/firearms.md#5`

### Step 3　排除自己：exclude_parent 只在父节点是碰撞体时生效　`[firearms/02#S3]`

【读】`howto/godot/firearms.md#8. 掩体：三套坐标（瞄准 / 角色 / 枪口）`

【做】
⛔ `exclude_parent` 默认 `true`，但**官方口径：只在父节点是 CollisionObject3D 时才有作用**。
射线常挂在枪口 `Node3D` 或相机下 —— 那时**不会排除角色自己** → 打到自己。

【产出】显式 `exclude`（RID 或对象），不依赖 `exclude_parent`

【判据】枪口贴墙 / 贴自己身体开火，不会命中自己。

【审】`audit/godot/firearms.md#43`

### Step 4　开了 hit_from_inside 时法线是零向量　`[firearms/02#S4]`

【读】`howto/godot/firearms.md#8. 掩体：三套坐标（瞄准 / 角色 / 枪口）`

【做】
⛔ 官方口径：`hit_from_inside` 为 true 时，射线从形状内部起算的命中，
**碰撞法线是 `Vector3(0,0,0)`**。
用它算贴花朝向、跳弹反射、穿透入射角会得到**错误的方向或除零**。

【产出】法线为零时的兜底（用射线反方向代替）

【判据】枪口探进墙内开火，贴花朝向正常、不出现 NaN。

【审】`audit/godot/firearms.md#59`

### Step 5　掩体收益按暴露比例算，不按相机能否看见　`[firearms/02#S5]`

【读】`howto/godot/firearms.md#8. 掩体：三套坐标（瞄准 / 角色 / 枪口）`

【做】
掩体判据是**暴露比例 / 受击部位**，不是"相机能不能看见敌人"。
⛔ 探头可逐帧自由拖到墙外 —— 要固定时长状态机 + 胶囊夹紧。

【产出】暴露比例计算 + 探头状态机

【判据】探头时只暴露上半身，被打到的部位与视觉一致。

【审】`audit/godot/firearms.md#45`

### Step 6　部位判定走独立碰撞层，不复用叶子碰撞体　`[firearms/02#S6]`

【读】`howto/godot/firearms.md#8. 掩体：三套坐标（瞄准 / 角色 / 枪口）`

【做】
⛔ 一个"叶子碰撞体"同时管弹道 / AI 视线 / 隐藏 ——
会"客户端看到草、服务器没有这根草"。

【产出】部位碰撞层划分（弹道 / 视线 / 装饰各自独立）

【判据】爆头判定命中头部层，且不影响 AI 视线与草丛隐藏。

【审】`audit/godot/firearms.md#40`

## 3. 参考实现

```gdscript
# ⓘ 承接 Step 1/2/3：统一命中源 + 立即更新 + 显式排除自己
const WEAPON_RANGE := 500.0
const LAYER_HITBOX := 1 << 5

func fire_immediate() -> Dictionary:
    var from := _aim_origin()          # 统一命中源，见 Step 1
    var to := from + _aim_dir() * WEAPON_RANGE
    var q := PhysicsRayQueryParameters3D.create(from, to)
    q.collision_mask = LAYER_HITBOX
    q.exclude = [get_rid()]            # ⛔ 不依赖 exclude_parent
    var hit := get_world_3d().direct_space_state.intersect_ray(q)
    if hit.is_empty():
        return {}
    var n: Vector3 = hit.get("normal", Vector3.ZERO)
    if n == Vector3.ZERO:
        n = -_aim_dir()                # hit_from_inside 时法线为零，见 Step 4
    return hit
```
