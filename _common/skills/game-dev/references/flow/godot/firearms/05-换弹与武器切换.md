# 05 换弹与武器切换（枪械 / 射击系统域）

> **本步交付**：换弹的逻辑门限 / 动画 / 可取消窗口三分开 + 部署门限 + 弹药模型
> **对应**：流程 `howto/godot/firearms.md` · 审核 `audit/godot/firearms.md`

## 0. 交付物定义

1. 换弹的**逻辑门限 / 动画 / 可取消窗口**是三件分开的事
2. 武器切换有独立的**部署门限**（不等动画播完）
3. 弹药模型已选定（武器 / 弹药类型 / 弹匣 三种之一）

## 1. 前置检查清单

- [ ] 已选定弹药模型（三种之一）
- [ ] ⚠ 已确认"改弹药的是逻辑门限，不是动画播完"
- [ ] 有两把武器可测切换

## 2. 工序

### Step 1　换弹三件事分开：逻辑门限 / 动画 / 可取消窗口　`[firearms/05#S1]`

【读】`howto/godot/firearms.md#5. 换弹：逻辑门限 / 动画 / 可取消窗口 三件事分开`

【做】
真正改弹药的是 `SwappingMag` 的**逻辑门限**。
⛔ 动画播完 = 换弹完成 —— 取消、切枪、预测回滚时会失去唯一事实源。
⛔ 动画通知反向驱动弹药 —— 要状态机推进，动画用 seek / cross-fade 跟。

【产出】换弹状态机（含明确的"弹药已加入"时点）

【判据】在动画中途取消，弹药状态与逻辑一致（不加也不丢）。

【审】`audit/godot/firearms.md#25`

### Step 2　战术换弹与空仓换弹分开扣备弹　`[firearms/05#S2]`

【读】`howto/godot/firearms.md#9. 弹药：是节奏资源，备弹要支持多武器共享`

【做】
战术换弹枪膛留一发。
⛔ 两者统一扣备弹 —— 战术换弹会让**玩家白丢一发**。

【产出】两条换弹路径（战术 / 空仓）各自的备弹结算

【判据】满弹匣战术换弹后，膛内 + 弹匣总数正确，不丢发。

【审】`audit/godot/firearms.md#26`

### Step 3　切换有独立部署门限，不等动画结束　`[firearms/05#S3]`

【读】`howto/godot/firearms.md#6. 武器切换：核心是"部署门限"`

【做】
⛔ 等动画完全结束才允许射击 —— 玩家感觉输入迟钝。
要有独立的**部署门限**（早于动画结束）。
⛔ 切换期间射击请求直接执行 —— 新武器可能还没部署；要丢弃 / 缓冲 / 延迟三选一。

【产出】每把枪的 `deploy_time` + 切换期间请求的处理策略

【判据】切枪后在部署门限时刻即可开火，早于该时刻的请求按策略处理。

【审】`audit/godot/firearms.md#33`

### Step 4　切枪取消换弹不是免费加速　`[firearms/05#S4]`

【读】`howto/godot/firearms.md#6. 武器切换：核心是"部署门限"`

【做】
⛔ 切枪取消换弹 = 免费加速 —— 那是**经济型漏洞**，不是操作深度。
⛔ 切换是销毁武器再实例化 —— 要 `disable` 而非销毁，弹药存实例或 loadout。

【产出】切枪取消换弹的代价（时间或资源）+ 武器复用策略

【判据】连续切枪取消换弹，总耗时不低于正常换弹。

【审】`audit/godot/firearms.md#32`

### Step 5　弹药模型三选一定清楚　`[firearms/05#S5]`

【读】`howto/godot/firearms.md#9. 弹药：是节奏资源，备弹要支持多武器共享`

【做】
三种模型（按武器 / 按弹药类型 / 按弹匣）是**不同的设计**，要选。
⛔ 备弹只按武器存 —— 多武器共享备弹做不到。
⛔ 弹药类型用武器名字符串 —— 要稳定 `AmmoType` 资源。

【产出】弹药模型选型结论 + `AmmoType` 资源

【判据】两把同弹药类型的武器共享备弹，扣减正确。

【审】`audit/godot/firearms.md#48`

## 3. 参考实现

```gdscript
# ⓘ 承接 Step 1/2：逻辑门限改弹药，动画只是表现
const DEPLOY_TIME := 0.35       # 部署门限，早于动画结束
const RELOAD_SWAP_AT := 0.6     # 弹药在此刻加入（逻辑门限）

enum Reload NONE, TACTICAL, EMPTY

func finish_reload(kind: Reload) -> void:
    var chamber := 1 if kind == Reload.TACTICAL else 0  # 战术换弹膛内留一发
    var need := _ctx.mag_size - chamber
    var take := mini(need, _reserve)
    _reserve -= take
    _mag = take + chamber
```
