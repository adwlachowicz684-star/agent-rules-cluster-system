# 04 弹道下坠与穿透（枪械 / 射击系统域）

> **本步交付**：固定子步的弹道积分 + 预测与实际共用积分器 + 穿透规则表
> **对应**：流程 `howto/godot/firearms.md` · 审核 `audit/godot/firearms.md`

## 0. 交付物定义

1. 弹道用**固定子步**积分（可变 dt 会改变下坠量）
2. 预测线与实际弹道**共用同一个积分器**
3. 穿透是独立规则表（层数 / 厚度 / 硬度 / 角度 / 衰减）

## 1. 前置检查清单

- [ ] 已确认本次武器**需要**弹道下坠（短距高弹速应归零）
- [ ] ⚠ 已确认预测线与真实弹道用同一函数
- [ ] 有一块可穿透的薄墙与一块厚墙可测

## 2. 工序

### Step 1　弹道用固定子步，不用可变 dt　`[firearms/04#S1]`

【读】`howto/godot/firearms.md#4. 弹道下坠：必须与预测共用一个积分器`

【做】
固定 `h` + 累加器。
⛔ sub-step 用可变 dt —— **帧率会改变下坠量**，同一把枪在不同机器上弹道不同。

【产出】固定子步积分器（输入固定 h）

【判据】30 FPS 与 144 FPS 下，同一距离的落点一致。

【审】`audit/godot/firearms.md#21`

### Step 2　预测线与真实弹道共用同一积分器　`[firearms/04#S2]`

【读】`howto/godot/firearms.md#4. 弹道下坠：必须与预测共用一个积分器`

【做】
⛔ 预测线另写一套简化公式 —— 表现为"预测命中墙后，实际打到墙里"。
必须从**同一函数**出结果。

【产出】`integrate(state, h)` 单一函数，预测与实际都调它

【判据】瞄准预测终点开火，实际落点与预测终点重合。

【审】`audit/godot/firearms.md#22`

### Step 3　穿透是规则表，不是一个布尔　`[firearms/04#S3]`

【读】`howto/godot/firearms.md#4. 弹道下坠：必须与预测共用一个积分器`

【做】
独立规则表：层数 / 厚度 / 硬度 / 角度 / 衰减。
⛔ 穿透靠一个布尔 —— 薄墙扫射与厚墙单点是不同玩法。
⛔ 穿透复用装饰性材质标签 —— 美术改一次材质，穿透规则跟着变。

【产出】穿透规则表（独立于视觉材质）

【判据】薄墙能穿、厚墙不能穿，且改视觉材质不影响穿透。

【审】`audit/godot/firearms.md#23`

### Step 4　短距高弹速的下坠归零　`[firearms/04#S4]`

【读】`howto/godot/firearms.md#4. 弹道下坠：必须与预测共用一个积分器`

【做】
⛔ 所有武器都做弹道下坠 —— 短距高弹速只有零点几像素，
**引入了复杂度却不可感知**，还带来预测/实际不同步的风险。

【产出】逐武器的"是否需要下坠"判定（含距离与弹速阈值）

【判据】能指着每把枪说出"它要不要下坠、为什么"。

【审】`audit/godot/firearms.md#20`

## 3. 参考实现

```gdscript
# ⓘ 承接 Step 1/2：固定子步，预测与实际共用同一积分器
const SUB_H := 1.0 / 120.0     # 固定子步，绝不传 delta
const GRAVITY := 9.8

func integrate(pos: Vector3, vel: Vector3, steps: int) -> Vector3:
    var p := pos
    var v := vel
    for _i in steps:
        v.y -= GRAVITY * SUB_H
        p += v * SUB_H
    return p                    # 预测线与实际弹道都走这里
```
