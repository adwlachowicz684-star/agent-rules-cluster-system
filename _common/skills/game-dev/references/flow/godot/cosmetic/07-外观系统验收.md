# 07 外观系统验收（外观域）

> **本步交付**：敌意环境实测通过 + 多端一致性实测通过
> **对应**：流程 `howto/godot/cosmetic.md` · 审核 `audit/godot/cosmetic.md`

## 0. 交付物定义

1. 改内存 / 改包伪造外观的请求已被服务端拒绝
2. 加载失败、超时、切来切去三种敌意场景下回退正确
3. 丢包与重连后多端外观一致
4. 导出包（⛔ 不只是编辑器）能加载并展示外观

## 2. 工序

### Step 1　伪造请求必须被服务端拒绝　`[cosmetic/07#S1]`

【读】`howto/godot/cosmetic.md#3. 称号 / 头像框：纯 UI 资产，但仍要服务端权威`

【做】
构造改内存与改包的请求（未拥有的时装、高权限称号、过期外观），验证服务端全部拒绝。
⛔ 只测正常路径 —— 外观的伪造**在正常流程里永远测不出来**，
因为它只在有人主动改包时才触发，⛔ 而测试环境下没人会改包。

ⓘ 同时验证拒绝后客户端**撤销预览**，
⛔ 不能停在"显示着但没有拥有"的中间态。

【产出】伪造用例清单（至少 3 类）+ 服务端拒绝与客户端回退记录

【判据】三类伪造全部被拒，客户端均回退且无中间态。

【审】`audit/godot/cosmetic.md#7`、`audit/godot/cosmetic.md#14`

### Step 2　加载失败、超时、连续切换三种场景回退正确　`[cosmetic/07#S2]`

【读】`howto/godot/cosmetic.md#6. 加载：必须保留默认外观、超时、令牌、取消`

【做】
实测：资产路径不存在、加载超时、连续快速切换 5 件。
⛔ 只测"正常加载一次" —— 三种失败**全部只在异常时出现**，
而单次成功给出的"很稳"是完全错误的信心。

ⓘ 连续切换那条尤其要测：最终必须显示最后点的那件，
⛔ 若显示最先点的，说明没有令牌校验。

【产出】三种失败场景的实测记录 + 回退截图

【判据】三种场景均回退默认或显示最后选择，⛔ 无空洞、无错件。

【审】`audit/godot/cosmetic.md#22`、`audit/godot/cosmetic.md#42`

### Step 3　丢包与重连后多端一致　`[cosmetic/07#S3]`

【读】`howto/godot/cosmetic.md#7. 网络：进场景全量 + 变更增量 + 周期全量校正`

【做】
人为丢包、强杀重连，验证多端外观一致。
⛔ 只测"点退出再登录" —— 那是**两条不同的代码路径**，
强杀走的是超时与全量校正，点退出走的是正常登出。

ⓘ 外观没有天然周期重写，⛔ 丢包不会自愈，
所以这条必须实测"少一个事件后是否自动补齐"。

【产出】丢包与强杀重连的多端一致性记录

【判据】丢掉一个增量后，客户端在下一个全量时机自动补齐。

【审】`audit/godot/cosmetic.md#25`、`audit/godot/cosmetic.md#26`

### Step 4　导出包实测，⛔ 编辑器里能跑不算　`[cosmetic/07#S4]`

【读】`howto/godot/cosmetic.md#6.2 ⛔ 导出后运行时加载：默认的二进制转换会让它整体失效`

【做】
用真实导出包跑一遍外观加载与展示。
⛔ 只在编辑器里验收 —— 二进制转换、路径变化、资源打包差异
**全部只在导出后显现**，而编辑器一切正常。

⛔ 表现为"编辑器里完美、出包后外观全回退默认"，
那时能改的余地很小，排查成本远高于开发期多打一个包。

【产出】导出包实测记录（含加载成功数与回退数）

【判据】导出包中外观加载成功率与编辑器一致。

【审】`audit/godot/cosmetic.md#38`、`audit/godot/cosmetic.md#20`

## 3. 验收清单

- [ ] 三类伪造请求全部被拒
- [ ] 加载失败/超时/连续切换回退正确
- [ ] 丢包与强杀重连后多端一致
- [ ] 导出包中外观加载与展示正常

## 4. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 有人穿着未发售的时装 | 只测正常路径 | S1 |
| 切来切去显示最先点的 | 未测连续切换 | S2 |
| 少一件但界面显示已装备 | 只测点退出重登 | S3 |
| 编辑器完美、出包后全回退 | 只在编辑器验收 | S4 |
