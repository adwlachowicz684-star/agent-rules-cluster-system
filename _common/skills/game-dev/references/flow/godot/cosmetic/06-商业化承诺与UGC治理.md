# 06 商业化承诺与 UGC 治理（外观域）

> **本步交付**：不改数值扫描 + 到期承诺 + UGC 三阶段 + 退款边界
> **对应**：流程 `howto/godot/cosmetic.md` · 审核 `audit/godot/cosmetic.md`

## 0. 交付物定义

1. 购买前已写明：永久/限时、可交易、绑定角色、随账号转移、染色独立、到期处置
2. 到期"消失 vs 转永久"是两种产品承诺，⛔ 未默认替运营选
3. 外观系统**不决定**能否退款，退款归订单与客服
4. UGC 三阶段审核 + 巡查，且审**组合结果**
5. UGC 资产用临时令牌与过期白名单，下架立即隐藏

## 1. 前置检查清单

- [ ] 购买页写明六项属性
- [ ] 到期处置是产品决策，有明确记录
- [ ] 退款逻辑不在外观系统内
- [ ] UGC 有上传前/上传后/组合三阶段 + 巡查
- [ ] UGC 用临时令牌，下架立即生效

## 2. 工序

### Step 1　购买前写明六项属性，⛔ 不只是"不影响平衡"　`[cosmetic/06#S1]`

【读】`howto/godot/cosmetic.md#8. 商业化：承诺的核心是明确"外观到底不改什么"`

【做】
在商城/公告/购买页写明：是否永久、是否限时、是否可交易、是否绑定角色、
是否随账号转移、染色是否独立、**到期后是消失还是转永久**、
坐骑皮肤是否含移速/碰撞变化。
⛔ 只写"本商品不影响平衡" —— 玩家真正投诉的不是"影响平衡"，
是"我以为永久的时装过期了"，⛔ 而这两件事在协议里都没写。

【产出】购买页属性清单（八项）

【判据】随机抽一件商品，八项属性在购买页均可查到。

【审】`audit/godot/cosmetic.md#28`

### Step 2　到期"消失 vs 转永久"是产品决策，⛔ 不默认替运营选　`[cosmetic/06#S2]`

【读】`howto/godot/cosmetic.md#限时时装的六个状态`

【做】
把"到期后消失"与"到期后转永久"作为两种明确的产品承诺，购买前确定。
⛔ 代码里默认一种 —— 表现为"运营以为会转永久、实际全消失了"，
而这个默认值藏在状态机里，**没有任何地方会报错**。

ⓘ 判据是"有记录"，不是"选了哪个"：
两种都合法，⛔ 不能由实现细节隐式决定。

【产出】到期处置的产品决策记录

【判据】指着任一件限时时装，能指出它的到期处置决策出自哪里。

【审】`audit/godot/cosmetic.md#28`

### Step 3　外观系统不决定能否退款　`[cosmetic/06#S3]`

【读】`howto/godot/cosmetic.md#8. 商业化：承诺的核心是明确"外观到底不改什么"`

【做】
退款口径交给订单与客服，外观系统只提供"是否已使用"这类事实。
⛔ 外观系统自己判断能否退 —— 退款与发行地区、支付渠道、
是否使用、当地消费者法有关，⛔ 表现为"同一个诉求在不同地区结果不同且无法解释"。

【产出】外观系统提供的退款事实字段清单

【判据】外观模块内没有任何退款判定分支。

【审】`audit/godot/cosmetic.md#29`

### Step 4　UGC 三阶段审核，且审组合结果　`[cosmetic/06#S4]`

【读】`howto/godot/cosmetic.md#9. UGC 外观：责任不因"玩家上传"而转移`

【做】
做上传前、上传后、巡查三阶段审核，并专门审**组合结果**。
⛔ 上传时审一次就放行 —— 模型、贴图、动画、染色各自合规，
**组合起来可能共同违规**，表现为"审核全过的内容被玩家投诉"。

ⓘ 责任不因"玩家上传"而转移，这是本步最该记住的一条。

【产出】三阶段审核流程 + 组合结果审核项

【判据】构造"单件合规、组合违规"的用例，能被第三/巡查阶段拦下。

【审】`audit/godot/cosmetic.md#30`

### Step 5　UGC 用临时令牌，下架立即隐藏　`[cosmetic/06#S5]`

【读】`howto/godot/cosmetic.md#9. UGC 外观：责任不因"玩家上传"而转移`

【做】
UGC 资产用临时令牌与过期白名单，下架时**立即隐藏**，不等刷新。
⛔ 客户端可永久缓存 —— 下架后违规内容仍在被看到，
⛔ 表现为"我们已经下架了，但截图还在流传"。

【产出】临时令牌有效期规则 + 下架广播与立即隐藏路径

【判据】下架后所有在线客户端立即隐藏，⛔ 不等下次刷新。

【审】`audit/godot/cosmetic.md#31`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：UGC 临时令牌 + 下架立即隐藏
const UGC_TOKEN_TTL_SECONDS := 3600   # ⓘ 待实测：按合规要求与运营成本确认

func is_ugc_visible(instance_id: StringName) -> bool:
    # ⛔ 下架立即隐藏，⛔ 不等刷新
    if revoked.has(instance_id): return false
    return token_expires_at.get(instance_id, 0) > now_monotonic()
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 玩家投诉"以为永久的过期了" | 只写了不影响平衡 | S1 |
| 运营以为转永久、实际全消失 | 默认值隐式决定 | S2 |
| 同诉求不同地区结果不同 | 外观系统自行判退款 | S3 |
| 审核全过的内容被投诉 | 未审组合结果 | S4 |
| 已下架内容仍在流传 | 客户端永久缓存 | S5 |
