## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：用了异步加载就以为不卡。**

⛔ 常见假完成：`load_threaded_request` 调了，
但 `instantiate()` 仍在主线程且**一帧内实例化几十个** → 一帧卡几十毫秒。

做完这一步，应该能**当场演示**：

1. 分帧循环按**时间预算**退出，不是按数量
2. ⛔ `load_threaded_get` 的阻塞特性已被理解
3. 实例化集中在主线程且被预算切分
4. ⛔ 池化对象**复用前重置状态**
5. ⛔ 池子有**上限**
6. 高频对象走池化，不走 `queue_free`

**产出物**（下游按名字对接）：

```text
ChunkLoader（时间预算切分）
ChunkNodePool（带上限 + 复用重置）
```

## 3. 参考实现

```gdscript
const FRAME_BUDGET_MS := 4.0

func _process(_d: float) -> void:
    var start := Time.get_ticks_usec()
    while not _pending.is_empty():
        _instantiate_one(_pending.pop_front())
        if (Time.get_ticks_usec() - start) / 1000.0 > FRAME_BUDGET_MS:
            break        # 超预算，下一帧继续
```

⛔ 池化对象 `acquire()` 后必须重置业务状态，不能只改 transform。
