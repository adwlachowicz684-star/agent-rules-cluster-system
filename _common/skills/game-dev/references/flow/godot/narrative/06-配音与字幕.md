# 06 配音与字幕 `[narrative/06]`


⚠ 本功能点与 `audio` 域有接缝：语音走音频总线，⛔ 不要绕过总线直接播。

---

对话文本可本地化、字幕与语音可对齐的演出层。

## 2. 工序

### Step 1　对话文本不硬编码　`[narrative/06#S1]`

【读】`howto/godot/narrative.md#2. 对话树`

【做】
⛔ **对话文本绝不能写在 GDScript 里** —— 那样无法翻译。
✅ 存在 Resource 或外部数据文件中。

【产出】
所有对话文本都在数据资源里，脚本中 0 处对话字面量。

【判据】
【审】`audit/godot/narrative.md#29`
全项目 GDScript 里搜索对话句，结果为 0。

---

### Step 2　翻译键策略　`[narrative/06#S2]`

【读】`howto/godot/narrative.md#0. ⚠ 首要任务不是写对话 UI，是建单一数据源`

【做】
ⓘ 与 flag 命名同理，翻译键也要有层次：
`act1.smith.line.001` 这类**带位置信息**的键，
便于译者理解上下文（同一句 "Yes" 在不同场景译法可能不同）。

⚠ **不要用英文原句当键** —— 改一个字所有语言全部失配。

【产出】
翻译键命名规范 + 键表。

【判据】
【审】`audit/godot/narrative.md#30`
改一句英文原文 → **其他语言的翻译不受影响**（键没变）。

---

### Step 3　字幕与语音对齐　`[narrative/06#S3]`

【读】`howto/godot/audio-advanced.md`

【做】
语音播放与字幕显示要**由同一个节点驱动**，
⛔ 不要各播各的（会累积漂移）。

⚠ 语音走 `audio` 域定义的语音总线，
⛔ 不要绕过总线直接 `play()`（那样音量设置对语音无效）。

【产出】
一个同步单元：播放语音 + 显示字幕 + 结束后回调。

【判据】
【审】`audit/godot/narrative.md#31`
连续播放 20 句带语音的对话 → **字幕与语音始终对应**，无累积错位。

---

### Step 4　跳过语音　`[narrative/06#S4]`

【读】`howto/godot/narrative.md#8. ⚠ 对话状态绝不能存在 UI 节点里`

【做】
⚠ 有配音后"跳过"变成两层：
- 跳过**本句语音**（立即显示完整字幕）
- 跳过**整段**（过场动画）

✅ 两层都要有，且**已看过的剧情**应能快速跳过。

【产出】
两级跳过控制。

【判据】
【审】`audit/godot/narrative.md#32`
按住跳过 → 语音停止、字幕完整显示、**不进入下一句**。
