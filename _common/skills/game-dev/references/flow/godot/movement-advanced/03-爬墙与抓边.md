# 03 爬墙与抓边（进阶移动域）

> **本步交付**：双射线传感器可用 + 三阶段过渡正确 + 蹬墙跳能蹬上去
> **对应**：流程 `howto/godot/movement-advanced.md` · 审核 `audit/godot/movement-advanced.md`

## 0. 交付物定义

1. 抓边判定用**两条射线**（上方探边缘 + 前方探墙面）
2. 阈值按**胶囊高度与网格台阶实测**，不是拍脑袋
3. 吸附 → 悬停 → 攀爬三阶段用 `move_and_collide()` 过渡，不直接赋坐标
4. 攀爬姿态对齐**不把碰撞法线当表面法线**
5. 蹬墙跳的**垂直分量**足够
6. 小台阶与角落不误触发、边缘不抖动

## 1. 前置检查清单

- [ ] 01 的传感器集中更新已就绪（本域不再单独投射）
- [ ] 胶囊高度与半径已知
- [ ] 目标台阶网格已有一个可复用的测试场景
- [ ] 三个阶段的动画资源已就位
- [ ] 蹬墙跳速度已登记进参数表

## 2. 工序

### Step 1　抓边要两条射线，一条不够　`[movement-advanced/03#S1]`

【读】``howto/godot/movement-advanced.md#2. 爬墙 / 抓边（重点）``

【做】
投射**两条**射线：一条从肩部略偏上向墙方向（探是否存在可用墙顶），
一条从腰部沿墙方向（探是否正对墙面）。
⛔ 不要只用一条 ——
单射线只能告诉你"前方有墙"，分不清"墙的中段"和"墙的上边缘"，
⛔ 表现为"贴着墙跳起来就自动抓边"，也就是在墙中段被凭空吸住，
⛔ 而单看那条射线的命中结果，它**确实命中了墙**。

【产出】双射线传感器（结果写入 01 的传感器结构）

【判据】正对墙中段起跳不会触发抓边；只在边缘带内触发。

【审】``audit/godot/movement-advanced.md#3``

### Step 2　阈值按胶囊高度实测，不拍脑袋　`[movement-advanced/03#S2]`

【读】``howto/godot/movement-advanced.md#2. 爬墙 / 抓边（重点）``

【做】
把 `LEDGE_TOP_OFFSET` / `LEDGE_REACH` / `LEDGE_EDGE_BAND` 三个阈值
按**胶囊高度**与目标台阶网格**实测**确定，并登记进参数表。
⛔ 不要照抄别人项目的数值 ——
阈值与胶囊高度、网格台阶尺寸是**绑定**的，
⛔ 抄来的值在自己的角色上会整体偏上或偏下，
表现为"某些台阶抓得到、某些抓不到"，
⛔ 而"部分能用"比"完全不能用"更难归因到阈值。

【产出】三个阈值的实测值（含测试场景说明）

【判据】场景内所有预期可抓的边缘都能抓到，所有预期不可抓的都不触发。

【审】``audit/godot/movement-advanced.md#6``

### Step 3　三阶段过渡用 move_and_collide，不直接赋坐标　`[movement-advanced/03#S3]`

【读】``howto/godot/movement-advanced.md#2. 爬墙 / 抓边（重点）``

【做】
吸附（禁用输入、沿逆上方向拉向边缘）→ 悬停（播动画、锁物理）→ 攀爬（移到边缘上方、恢复地面态），
位移用 `move_and_collide()` 并限制单次最大距离。
⛔ 不要直接 `global_transform.origin = edge_point` ——
一步跨过薄墙会**直接穿过去**，
⛔ 表现为"偶尔掉进墙里"或"动画与位置对不上"，
⛔ 而目标点本身是算对的，所以排查不会去看赋值方式。

【产出】三阶段状态与位移实现

【判据】对薄墙测试体反复抓边 20 次，无一次穿透。

【审】``audit/godot/movement-advanced.md#4``

### Step 4　攀爬姿态对齐不要拿碰撞法线当表面法线　`[movement-advanced/03#S4]`

【读】``howto/godot/movement-advanced.md#2. 爬墙 / 抓边（重点）``

【做】
对齐攀爬姿态时，把 `get_floor_normal()` 当作**碰撞法线**处理，
并准备好它在部分几何上与表面法线不一致的兜底（例如回退到射线法线）。
⛔ 不要假设两者恒等 ——
官方 Warning：**碰撞法线并不总是与表面法线相同**。
⛔ 表现为"在大部分墙面上贴得很正，在少数几何上歪一点"，
⛔ 少数几何通常被当成美术资源问题，而不是法线来源问题。

【产出】法线获取与兜底逻辑

【判据】在凹角、斜面接缝、拼接网格上姿态不歪。

【审】``audit/godot/movement-advanced.md#23``

### Step 5　蹬墙跳的垂直分量要够　`[movement-advanced/03#S5]`

【读】``howto/godot/movement-advanced.md#2. 爬墙 / 抓边（重点）``

【做】
蹬墙跳的速度里显式给足**垂直分量**（`WALLJUMP_UP_SPEED`），
水平分量按离开墙的方向给。
⛔ 不要只给一个"斜向的力"让它自然分解 ——
斜面角度一变，垂直分量就跟着变，
⛔ 表现为"有些角度蹬得上去、有些蹬不上去"，
⛔ 而总速度大小是恒定的，所以测速看到的值**完全正常**。

【产出】蹬墙跳速度（垂直 / 水平分量分离）

【判据】在所有可抓墙面上蹬墙跳都能达到预期高度。

【审】``audit/godot/movement-advanced.md#5``

### Step 6　误触发与边缘抖动：回到传感器集中　`[movement-advanced/03#S6]`

【读】``howto/godot/movement-advanced.md#0. 状态机是地基``

【做】
出现小台阶误触发或边缘抖动时，**先查传感器是不是只有一处**投射，
再回头调阈值。
⛔ 不要一上来就调 `LEDGE_EDGE_BAND` ——
如果多个状态各自投射射线，同一帧的起点与长度会不一致，
⛔ 抖动来自"这帧抓到、下帧没抓到"，
⛔ 此时调阈值只会把抖动从一个位置挪到另一个位置，永远调不完。

【产出】误触发 / 抖动的归因结论（先集中，后调参）

【判据】抖动消失后，阈值无需再微调即可覆盖全部测试边缘。

【审】``audit/godot/movement-advanced.md#15``


## 3. 参考实现

```gdscript
# ⓘ 本块内自足：常量在此声明，承接上文即可直接用
const LEDGE_TOP_OFFSET := 0.05   # 上方射线起点相对胶囊顶偏移（米）
const LEDGE_REACH := 0.6         # 抓边射线长度（米）
const LEDGE_EDGE_BAND := 0.25    # 可接受边缘高度带（米）
const WALLJUMP_UP_SPEED := 7.0   # 蹬墙跳垂直分量（米/秒）
const SNAP_MAX_STEP := 0.08      # 单帧最大吸附位移（米，防穿薄墙）

func probe_ledge(body: CharacterBody3D, wall_dir: Vector3) -> Dictionary:
    var space := body.get_world_3d().direct_space_state
    var origin_top := body.global_position + Vector3.UP * (_capsule_h * 0.5 - LEDGE_TOP_OFFSET)
    var origin_waist := body.global_position
    var q := PhysicsRayQueryParameters3D.create(origin_top, origin_top + wall_dir * LEDGE_REACH)
    var q2 := PhysicsRayQueryParameters3D.create(origin_waist, origin_waist + wall_dir * LEDGE_REACH)
    var hit_top := space.intersect_ray(q)
    var hit_waist := space.intersect_ray(q2)
    # ⛔ 两条都命中 = 正对墙中段；只有上方命中 = 存在可用边缘
    return {"top": hit_top, "waist": hit_waist,
            "grab": hit_top.is_empty() and not hit_waist.is_empty()}

var _capsule_h := 1.8

func snap_toward(body: CharacterBody3D, target: Vector3) -> void:
    var delta := target - body.global_position
    if delta.length() > SNAP_MAX_STEP:
        delta = delta.normalized() * SNAP_MAX_STEP
    # ⛔ 用 move_and_collide 步进，不要直接赋 global_transform.origin
    body.move_and_collide(delta)
```

## 5. 常见返工

| 现象 | 返工到 |
|---|---|
| 贴墙跳起就自动抓边 | 返工 Step 1（只有一条射线） |
| 某些台阶抓得到、某些抓不到 | 返工 Step 2（阈值抄来的） |
| 偶尔掉进墙里 | 返工 Step 3（直接赋了坐标） |
| 少数几何上姿态歪 | 返工 Step 4（碰撞法线当表面法线） |
| 有些角度蹬不上去 | 返工 Step 5（垂直分量被斜面分解） |
| 抖动永远调不完 | 返工 Step 6（多处投射射线） |
