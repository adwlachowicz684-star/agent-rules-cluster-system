# 05 相机与载具过场交接（camera 域）

> **前置**：`03-多相机管理与优先级.md` 已完成
> **本步交付**：**上车载具相机生效，下车自动还回角色相机**
> **对应**：做法 `howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`
> 　　　审核 `audit/godot/camera-cutscene.md#22`

## 0. 交付物定义

⚠ **本步是关键接缝：载具域与过场都要借相机，借了必须还。**

⛔ 常见假完成：上车时切载具相机、下车时切回角色相机，
⚠ **用手动还原**——
⛔ 一旦嵌套（过场中上车、车上触发过场）就会还原错层。

做完这一步，应该能**当场演示**：

1. 上车 → 载具相机生效；下车 → **自动还回**角色相机
2. ⚠ 过场中上车 → 过场结束后仍在**载具**视角（不是角色）
3. ⛔ 载具相机**不直接**用车身 transform（否则抖）
4. ⚠ 过场相机走**同一个栈**，不另起一套
5. ⛔ 交接失败**有可观测**的表现（不是静默）

**产出物**（下游按名字对接）：

```text
vehicle 相机：独立跟随逻辑，⛔ 不直接用车身 transform
cutscene 相机：走 CameraStack，与载具同一套
```

## 2. 工序

### Step 1　⛔ 载具相机不直接用车身 transform　`[camera/05#S1]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】载具相机用独立跟随/平滑，不绑车身 transform。

⛔ 直接绑 → 车身物理抖动全部传给相机 →
表现为"开车时镜头一直抖"，
⛔ 常被误判为物理问题。

【产出】载具相机跟随逻辑

【判据】⚠ 行驶中镜头**平稳**不抖

【审】`audit/godot/camera-cutscene.md#22`
【品】`craft/godot/aesthetics.md#5. 镜头语言`

### Step 2　⛔ 用栈交接，不手动还原　`[camera/05#S2]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】上车 push、下车 pop，由栈决定回到哪个相机。

⛔ 手动"切回角色相机" → 嵌套场景还原错层 →
表现为"过场中上车，过场结束回到角色视角但人还在车上"。

【产出】栈交接

【判据】⚠ 过场中上车 → 结束后仍在**载具**视角

【审】`audit/godot/camera-cutscene.md#18`

### Step 3　⚠ 过场相机复用同一栈　`[camera/05#S3]`

【读】`howto/godot/camera-cutscene.md#6. 过场三要素必须写成同一状态机`

【做】过场与其他接管者走同一个 `CameraStack`。

⛔ 过场另起一套 → 两套互相不知情 →
表现为"过场结束后相机状态不确定"，⛔ 且与时序相关。

【产出】统一栈

【判据】⛔ 全库只有**一个**相机栈实现

【审】`audit/godot/camera-cutscene.md#18`

### Step 4　⚠ 载具销毁时释放相机　`[camera/05#S4]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】载具销毁/爆炸时 pop 它的相机请求。

⛔ 不释放 → 栈泄漏 → 相机永久停在载具层，
⚠ 与 `vehicle` 域 05/S4（销毁前先退出乘员）是同一类顺序问题。

【产出】销毁释放

【判据】⚠ 载具销毁后**回到**下层相机

【审】`audit/godot/camera-cutscene.md#20`

### Step 5　⛔ 交接失败可观测　`[camera/05#S5]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】栈异常（重复 pop / 未配对）时报警或日志。

⛔ 静默失败 → "画面不对"无从查起，
⚠ 这是相机问题最难排查的根源：没有错误信号。

【产出】异常可观测

【判据】⚠ 人为制造未配对 → **有明确告警**

【审】`audit/godot/camera-cutscene.md#21`

### Step 6　⚠ 与载具域的接缝确认　`[camera/05#S6]`

【读】`howto/godot/camera-cutscene.md#10. 相关文档`

【做】与 `vehicle` 域 05/06 的契约对齐。

⛔ 不对齐 → 载具域改了上下车顺序而相机侧不知 →
表现为"下车后相机没还"。

【产出】接缝确认

【判据】⚠ 载具域与相机域**同一套**交接顺序

【审】`audit/godot/camera-cutscene.md#21`

## 5. 常见返工

**① 相机绑车身。** 开车抖。

**② 手动还原。** 嵌套还原错层。

**③ 过场另起一套。** 状态不确定。

**④ 载具销毁不释放。** 永久停载具层。
