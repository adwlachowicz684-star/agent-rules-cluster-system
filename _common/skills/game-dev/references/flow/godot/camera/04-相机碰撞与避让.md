## 0. 交付物定义

⚠ **本步的坑是"以为 SpringArm 自动避让角色"。**

⛔ `SpringArm3D` 的碰撞层必须**显式配置**，
且要**排除角色自己**——否则相机被角色自身碰撞体挡住，
表现为"相机一直贴在角色头上"，⛔ 且不报错。

做完这一步，应该能**当场演示**：

1. ⛔ 相机贴近墙面时**自动拉近**（不穿墙）
2. ⚠ 角色**自己不会**挡住相机
3. ⛔ 离开墙面后相机**平滑回到**原距离
4. ⚠ 避让**不抖动**（不会来回弹）
5. ⛔ 相机不会被**载具/过场**的碰撞体误挡

**产出物**（下游按名字对接）：

```text
SpringArm3D.collision_mask  # ⛔ 显式配置，排除角色层
避让回弹：平滑，不瞬移
```

## 2. 工序

### Step 1　⛔ 显式配置碰撞层并排除角色　`[camera/04#S1]`

【读】`howto/godot/camera-cutscene.md#4. 3D 第三人称：标准三层结构`

【做】设 `SpringArm3D.collision_mask`，排除角色所在层。

⛔ 不配或没排除角色 → 相机被角色自己挡 →
表现为"相机贴脸"，⛔ 且不报错，
常被误判为"距离参数没生效"。

【产出】collision_mask

【判据】⚠ 角色**自己不挡**相机

【审】`audit/godot/camera-cutscene.md#6`

### Step 2　⚠ 贴墙时自动拉近　`[camera/04#S2]`

【读】`howto/godot/camera-cutscene.md#4. 3D 第三人称：标准三层结构`

【做】确认 SpringArm 在碰撞时缩短。

⛔ 不用 SpringArm 而用固定距离 → 相机穿墙 →
表现为"墙后变成透视视角"，⛔ 玩家能看穿地形。

【产出】避让行为

【判据】⛔ 贴墙时相机**拉近**且不穿墙

【审】`audit/godot/camera-cutscene.md#6`

### Step 3　⚠ 离开墙面平滑回弹，不瞬移　`[camera/04#S3]`

【读】`howto/godot/camera-cutscene.md#1. 跟随策略对比`

【做】回弹用平滑插值（帧率无关）。

⛔ 直接恢复 → 相机"跳一下"，
⚠ 表现为"绕过墙角时镜头猛地拉远"。

ⓘ 平滑要用 `1-exp(-k*dt)`，
⛔ 不是 `lerp(a,b,0.1)`（帧率相关）。

【产出】回弹插值

【判据】⚠ 绕过墙角**平滑过渡**无跳变

【审】`audit/godot/camera-cutscene.md#2`

### Step 4　⛔ 避让不抖动　`[camera/04#S4]`

【读】`howto/godot/camera-cutscene.md#4. 3D 第三人称：标准三层结构`

【做】处理墙面边缘的临界抖动。

⛔ 临界位置反复进出 → 相机"抽搐"，
⚠ 表现为"贴着墙走时镜头一直在抖"，
⛔ 常被误判为跟随算法有问题。

【产出】防抖处理

【判据】⚠ 沿墙行走**相机稳定**不抖

【审】`audit/godot/camera-cutscene.md#6`

### Step 5　⛔ 排除不该挡相机的物体　`[camera/04#S5]`

【读】`howto/godot/camera-cutscene.md#4. 3D 第三人称：标准三层结构`

【做】载具/触发器/特效等不参与避让。

⛔ 触发器参与 → 相机被看不见的东西挡，
⚠ 表现为"莫名其妙被拉近"，排查极难。

【产出】层过滤

【判据】⚠ 只有**实体墙**触发避让

【审】`audit/godot/camera-cutscene.md#6`

## 5. 常见返工

**① 没排除角色。** 相机贴脸。

**② 固定距离。** 穿墙透视。

**③ 直接恢复。** 绕过墙角跳变。

**④ 触发器参与。** 莫名被拉近。
