# 07 相机验收（camera 域）

> **前置**：01–06 全部完成
> **本步交付**：一份**可签核**的验收报告
> **对应**：做法 `howto/godot/camera-cutscene.md` 全文 · 审核 `audit/godot/camera-cutscene.md` 全部 25 条

## 0. 交付物定义

⚠ **相机域的验收必须在"嵌套与异常"下做，不是在正常流程下做。**

⛔ 正常流程下所有相机都正确——
本域的 bug 全部只在**切换、抢用、异常中断**时出现。

做完这一步，应该能**当场演示**并**签核**：

1. ⚠ **视角切换**双向朝向都正确（02 核心指标）
2. ⚠ **过场结束**相机自动还回（03 核心指标）
3. ⛔ **嵌套**（过场中上车/菜单）逐层正确回退（05 核心指标）
4. ⚠ **强制中断**后相机回到正常（06 核心指标）
5. ⛔ **贴墙**不穿墙、沿墙不抖（04 核心指标）
6. ⚠ 接缝复查：与 6 个域的契约全对上

## 1. 前置检查清单

- [ ] ⚠ 有可制造**嵌套**的测试场景（过场中上车）
- [ ] ⚠ 有可**强制中断**的入口（跳关/重开）

## 2. 工序

### Step 1　⚠ 视角切换双向实测　`[camera/07#S1]`

【读】`howto/godot/camera-cutscene.md#8. 视角切换：第一人称与第三人称`

【做】第一↔第三人称反复切换，检查朝向与模型显示。

⛔ 只测单向 → 反向切换的朝向丢失**测不到**，
⚠ 且"切回第三人称但头还藏着"这类残留也测不到。

【产出】双向切换结果

【判据】⚠ 双向朝向**都正确**，无模型残留

【审】`audit/godot/camera-cutscene.md#15`

### Step 2　⚠ 过场结束还回实测　`[camera/07#S2]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】播完过场，确认相机自动回到下层。

⛔ 不测 → 过场结束卡住，
⚠ 而这是"过场做完就测一遍"最容易漏的一步。

【产出】过场还回结果

【判据】⚠ 过场结束**自动**回到下层视角

【审】`audit/godot/camera-cutscene.md#18`

### Step 3　⛔ 嵌套回退实测　`[camera/07#S3]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】过场中上车、车上开菜单，逐层**出栈**退出（验证 push/pop 配对）。

⛔ 只测单层 → 手动还原的错层问题**完全测不到**，
⚠ 而这是最容易在真实游玩中触发的场景。

【产出】嵌套结果

【判据】⚠ 逐层退出**每层都正确**

【审】`audit/godot/camera-cutscene.md#20`

### Step 4　⛔ 强制中断实测　`[camera/07#S4]`

【读】`howto/godot/camera-cutscene.md#9. 多相机管理：优先级与交接`

【做】过场/载具/死亡中途强制跳关或重开。

⛔ 不测中断 → 栈残留 → 相机永久异常，
⚠ 玩家**无法自行恢复**，只能重启游戏。

【产出】中断结果

【判据】⚠ 中断后相机**回到正常**视角

【审】`audit/godot/camera-cutscene.md#25`

### Step 5　⚠ 贴墙与沿墙实测　`[camera/07#S5]`

【读】`howto/godot/camera-cutscene.md#4. 3D 第三人称：标准三层结构`

【做】贴墙站立、沿墙行走、绕过墙角。

⛔ 不测沿墙 → 临界抖动测不到，
⚠ 表现为"贴着墙走镜头一直在抖"。

【产出】避让结果

【判据】⛔ 不穿墙、⚠ 沿墙**不抖**、回弹平滑

【审】`audit/godot/camera-cutscene.md#6`

### Step 6　⚠ 接缝复查　`[camera/07#S6]`

【读】`howto/godot/camera-cutscene.md#10. 相关文档`

【做】逐条核对 00 总览第 2 节的六条契约：

| 接缝 | 复查点 |
|---|---|
| `character` 域 03 相机跟随 | 跟随算法在那边，本域不重复实现 |
| `vehicle` 域 载具 | 载具相机独立跟随，交接顺序一致 |
| `narrative` 域 过场 | 过场相机走同一优先级栈 |
| `camera-cutscene.md` 屏震 | 屏震是**叠加**，不占栈层级 |
| `input-remap.md` 输入 | 视角切换复用同一套 action |
| `ui` 域 菜单 | 菜单打开接管或冻结相机 |

⛔ **这六条不查，部件全合格也可能拼不起来。**

【产出】接缝复查表

【判据】⚠ 六条全部对上，每条有实测证据

【审】`audit/godot/camera-cutscene.md#21`
【品】`craft/godot/cheapness.md#5. 结构类廉价感（最隐蔽）`

## 4. 常见返工

**① 只测单向切换。** 反向与残留测不到。

**② 只测单层。** 嵌套错层测不到。

**③ 不测中断。** 永久异常测不到。

**④ 不测沿墙。** 临界抖动测不到。
