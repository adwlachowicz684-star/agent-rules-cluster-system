# 05 战争迷雾与视野（RTS 域）

> **本步交付**：每方独立层 + `visible / explored` 两态 + 脏区批量
> **对应**：流程 `howto/godot/genres-rts.md` · 审核 `audit/godot/genres-rts.md`

## 0. 交付物定义

1. 迷雾是独立的格子状态层，⛔ 不是 `Light2D`
2. 每方一张独立层，视野不互相泄漏
3. `visible` 与 `explored` 两态分开存
4. 视野更新走脏区收集、逻辑帧末一次性提交
5. 迷雾层关闭 `navigation_enabled`

## 1. 前置检查清单

- [ ] 迷雾是 `TileMapLayer` 格子状态，没有用光照节点
- [ ] 每个阵营 / 玩家一张层
- [ ] 两态分开（当前可见 / 曾经探索）
- [ ] `set_cell` 只出现在脏区提交函数里
- [ ] 层上 `navigation_enabled = false`

## 2. 工序

### Step 1　迷雾是独立格子状态，⛔ 不是 `Light2D`　`[rts/05#S1]`

【读】`howto/godot/genres-rts.md#4. 战争迷雾是独立的格子状态，不是 Light2D`

【做】
用独立 `TileMapLayer` 存每格状态。
⛔ 用 `Light2D` 当视野系统 —— 它管的是 2D 光照与阴影
（`range_z_min/max`、`height`、`shadow_item_cull_mask`），
⛔ 表现为"阴影边缘有渐变、单位在阴影边缘时隐时现"，
而光照参数怎么调都不对，因为那本来就不是可见性。

【产出】迷雾层节点 + 格子状态定义

【判据】单位进入视野是整格切换，无渐变过渡。

【审】`audit/godot/genres-rts.md#6`

### Step 2　`visible` 与 `explored` 两态分开　`[rts/05#S2]`

【读】`howto/godot/genres-rts.md#4. 战争迷雾是独立的格子状态，不是 Light2D`

【做】
每格存两态：当前可见与曾经探索过。
⛔ 只存一态 —— 单位离开后区域直接变全黑，
失去"探索过"的信息，表现为"刚探完的地图又黑了"，
⛔ 而记忆功能常被当成"小地图的事"，于是逻辑层只留一态。

【产出】两态存储结构 + 渲染时区分三档（未探索 / 已探索未可见 / 可见）

【判据】单位离开后区域变为"已探索"的暗色，不是全黑。

【审】`audit/godot/genres-rts.md#25`

### Step 3　每方一张独立层，⛔ 不共享　`[rts/05#S3]`

【读】`howto/godot/genres-rts.md#4. 战争迷雾是独立的格子状态，不是 Light2D`

【做】
每个阵营 / 玩家一张迷雾层。
⛔ 多阵营共享一张 —— 己方视野会被敌方单位反推泄漏，
表现为"对面知道你在哪"，⛔ 而单机测试只用一个阵营，永远测不出来。

ⓘ 观战与回放要有**第三张层**（双方视野都不给），
⛔ 复用任一阵营的层等于把该方情报给了观众。

【产出】按阵营索引的迷雾层表 + 观战专用层

【判据】两个阵营的层互不包含对方视野；观战层不含任一方视野。

【审】`audit/godot/genres-rts.md#27`

### Step 4　脏区收集、逻辑帧末一次性提交　`[rts/05#S4]`

【读】`howto/godot/genres-rts.md#7. 视野更新做脏区批量`

【做】
`reveal()` 只往 `_dirty` 里追加格子，`_flush()` 在**逻辑帧末**一次性 `set_cell` 并清空。
⛔ 按帧实时写 `set_cell` —— 反复触发导航与渲染重算，
表现为"单位一多就卡"，⛔ 而每一次 `set_cell` 单看都是必要的。

【产出】`_dirty` 收集 + `_flush()` 提交（挂在逻辑帧）

【判据】上百单位移动时每逻辑帧只提交一次。

【审】`audit/godot/genres-rts.md#26`

### Step 5　迷雾层关闭 `navigation_enabled`　`[rts/05#S5]`

【读】`howto/godot/genres-rts.md#4. 战争迷雾是独立的格子状态，不是 Light2D`

【做】
迷雾层的 `navigation_enabled` 设为 `false`。
⛔ 留默认 —— 会为迷雾格子生成无意义的导航区域，
表现为"寻路莫名绕远 / 导航烘焙变慢"，
⛔ 而迷雾层在编辑器里看着就是一张普通的图层。

【产出】迷雾层属性清单（含 `navigation_enabled = false`）

【判据】导航烘焙结果不包含迷雾层贡献的区域。

【审】`audit/godot/genres-rts.md#35`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：FOG_CELL_SIZE / FOG_FLUSH_EVERY_N_TICKS 见 00 参数登记（待实测）
# ⓘ SRC_FOG 为迷雾图集源 id，ATLAS_VISIBLE / ATLAS_EXPLORED / ATLAS_HIDDEN 为图集坐标；四者均按项目图集定
# ATLAS_VISIBLE / ATLAS_EXPLORED / ATLAS_HIDDEN 为图集坐标，按项目图集定
var _dirty: Array[Vector2i] = []

func reveal(world_pos: Vector2, radius: int) -> void:
    var center := fog_layer.local_to_map(fog_layer.to_local(world_pos))
    for c in _cells_in_radius(center, radius):
        if _state(c) != ATLAS_VISIBLE:
            _dirty.append(c)

func _flush() -> void:            # 逻辑帧末一次性提交
    for c in _dirty:
        fog_layer.set_cell(c, SRC_FOG, ATLAS_VISIBLE)
    _dirty.clear()
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 阴影边缘渐变时隐时现 | 用 Light2D 做迷雾 | S1 |
| 探完的地图又黑了 | 只存一态 | S2 |
| 对面知道你在哪 | 多阵营共享层 | S3 |
| 单位一多就卡 | 按帧实时 set_cell | S4 |
| 寻路莫名绕远 | 迷雾层开了 navigation | S5 |
