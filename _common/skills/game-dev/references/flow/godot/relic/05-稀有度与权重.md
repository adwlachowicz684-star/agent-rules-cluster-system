> **前置**：`02-遗物池与实例.md` 已完成
> **本步交付**：一张**可改数值不改代码**的权重表，且空池不静默出错
> **对应**：做法 `howto/godot/relic-build.md#4. 权重抽取：空数组返回 -1`
> 　　　审核 `audit/godot/relic-build.md#7`

## 0. 交付物定义

⚠ **权重是策划最常调的数值，必须能改表不改代码。**

⛔ 硬编码的话，每次调平衡都要发版——
而调平衡恰恰是上线后最频繁的操作。

做完这一步，应该能**当场演示**：

1. 改配表权重，**不改代码**即生效
2. ⚠ 某稀有度抽完后，走**显式兜底**而不是返回最后一个
3. ⚠ 每次 `rand_weighted` 都判了 `-1`（全项目可查）
4. 保底计数**持久化且绑定池**
5. 权重表与 `genres-roguelike.md` 道具池的逻辑**不冲突**

**产出物**（下游按名字对接）：

```text
RelicPool: rarity -> Array[relic_id]        # 进配表
rarity_weights: PackedFloat32Array          # 进配表
pity_counter: { pool_id -> count }          # 持久化，绑定池
```

## 2. 工序

### Step 1　⚠ 权重进配表　`[relic/05#S1]`

【读】`howto/godot/relic-build.md#1. 遗物池三层：池 / 稀有度 / 实例`

【做】`rarity_weights` 与池内容都进配表，⛔ 不硬编码。

【产出】配表字段

【判据】⚠ 搜索权重数字常量，**结果为 0**

【审】`audit/godot/relic-build.md#17`

### Step 2　⛔ 每次 rand_weighted 都判 -1　`[relic/05#S2]`

【读】`howto/godot/relic-build.md#4. 权重抽取：空数组返回 -1`

【做】
```gdscript
var idx := _run_rng.rand_weighted(weights)
if idx == -1:
    return _fallback_pick()      # 显式兜底
```

⛔ **官方原话：空数组时"输出错误并返回 `-1`"。**
不判 → 取 `pool[-1]` = 最后一个，**不崩溃不报错**。

ⓘ 特征是"某种稀有度抽完后再也不出别的"，极难归因。

【产出】`-1` 判定，全项目覆盖

【判据】⚠ 搜索 `rand_weighted(` 的调用，**每处后面都有 -1 判定**

【审】`audit/godot/relic-build.md#7` `audit/godot/relic-build.md#18`

### Step 3　⚠ 池空要有显式兜底路径　`[relic/05#S3]`

【读】`howto/godot/relic-build.md#4. 权重抽取：空数组返回 -1`

【做】抽空时明确：降到下一稀有度 / 给通用替代品 / 跳过本次，
⛔ **不能**让它自然为空。

【产出】`_fallback_pick()` 显式路径

【判据】⚠ 人为清空一个池，**结果是兜底路径而非固定最后一个**

【审】`audit/godot/relic-build.md#18`

### Step 4　⚠ 保底计数持久化且绑定池　`[relic/05#S4]`

【读】`howto/godot/relic-build.md#8. 待核对项（运行时验证）`

【做】`pity_counter` 按 `pool_id` 分别记录并落盘。

⛔ 只存一个全局计数 → 换池后计数错乱，
表现为"刚换池就出了稀有"（或反过来永远不出）。

【产出】绑定池的保底计数

【判据】⚠ 两个池各自抽，**计数互不影响**

【审】`audit/godot/relic-build.md#17`

### Step 5　⚠ 与道具池权重不冲突　`[relic/05#S5]`

【读】`howto/godot/relic-build.md#9. 相关文档`

【做】确认本域的权重表与 `genres-roguelike.md` 的道具池
是**两套独立**的表，或共用但语义一致。

⛔ 两套表语义不同却互相复用 → 改一处影响另一处，
表现为"改了遗物权重，房间奖励也变了"。

【产出】两池关系说明（独立 or 共用且一致）

【判据】⚠ 改遗物权重，**房间奖励概率不变**（若独立）

【审】`audit/godot/relic-build.md#17`

## 5. 常见返工

**① 权重硬编码。** 每次调平衡都要发版。

**② 不判 -1。** 空池静默返回最后一个。

**③ 保底全局计数。** 换池后错乱。

**④ 两池语义混淆。** 改一处影响另一处。
