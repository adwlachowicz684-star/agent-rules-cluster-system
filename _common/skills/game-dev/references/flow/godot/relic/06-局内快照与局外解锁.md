# 06 局内快照与局外解锁（遗物域）

> **前置**：`03-抽取与三选一.md` 已完成
> **本步交付**：属性不每帧重算，且局外解锁**不会丢**
> **对应**：做法 `howto/godot/relic-build.md#6. 局内属性：脏标记快照，不是每帧遍历`
> 　　　审核 `audit/godot/relic-build.md#10`

## 0. 交付物定义

⚠ **两件事看起来无关，实则共用同一个时机点：拿遗物的那一刻。**

⛔ 分开做的话，会出现"拿了遗物但属性没变"或
"通关前崩溃、整局解锁全丢"——后者玩家会**明确感知**。

做完这一步，应该能**当场演示**：

1. 拿遗物后属性**立即**变化（不用等下一帧逻辑）
2. ⚠ 100 件遗物下，**帧时间不随遗物数增长**
3. 局外解锁在**获得瞬间**已落盘（中途崩溃不丢）
4. ⚠ 存档只写 `relic_id`，删配表不导致空引用
5. 清局内状态**不影响**局外解锁

**产出物**（下游按名字对接）：

```text
_dirty: bool                    # 脏标记
_snapshot: Dictionary           # 一次算好的属性快照
unlock(relic_id)                # 关键节点即存
```

## 2. 工序

### Step 1　⚠ 脏标记快照，不是每帧遍历　`[relic/06#S1]`

【读】`howto/godot/relic-build.md#6. 局内属性：脏标记快照，不是每帧遍历`

【做】拿遗物时置 `_dirty`，下一次取用时重算并存快照。

⛔ 每帧遍历累加 → 遗物越多越卡，
而这类卡顿在前期遗物少时**完全测不出来**。

【产出】`_dirty` + `_snapshot`

【判据】⚠ 遗物数 10 → 100，**帧时间基本不变**

【审】`audit/godot/relic-build.md#10`

### Step 2　⚠ 与词条共用同一套脏标记　`[relic/06#S2]`

【读】`howto/godot/relic-build.md#6. 局内属性：脏标记快照，不是每帧遍历`

【做】遗物与词条（来自 `build-affix.md`）共用**一个**脏标记。

⛔ 各有一套 → 拿遗物只置遗物的标记，词条快照不更新，
表现为"拿了遗物，词条加成的部分没变"。

【产出】单一脏标记入口

【判据】⚠ 拿遗物后，**词条相关属性也一起更新**

【审】`audit/godot/relic-build.md#10`

### Step 3　⛔ 局外解锁关键节点即存　`[relic/06#S3]`

【读】`howto/godot/relic-build.md#7. 局外解锁：关键节点即存`

【做】解锁在**获得瞬间**落盘，⛔ 不等通关结算。

⛔ 只在通关时存一次 → 中途崩溃则整局解锁全丢，
玩家会明确感知"我明明拿到了"。

【产出】`unlock()` 立即落盘

【判据】⚠ 获得解锁后**立即强杀进程**，重进后仍在

【审】`audit/godot/relic-build.md#12`

### Step 4　⛔ 存档只写 relic_id　`[relic/06#S4]`

【读】`howto/godot/relic-build.md#7. 局外解锁：关键节点即存`

【做】存档写 `relic_id` + 实例可变字段，⛔ 不写模板本身。

⛔ 存模板 → 配表删掉某个遗物后旧存档指向空，
且**不报错**，只是那个遗物变成空白。

【产出】存档结构

【判据】⚠ 删一个配表遗物后读旧档，**进隔离区而非静默变空**

【审】`audit/godot/relic-build.md#13`

### Step 5　⚠ 清局内不影响局外　`[relic/06#S5]`

【读】`howto/godot/relic-build.md#0. 先分清三件事`

【做】一局结束的清理只清 `RelicInstance` 集合，
⛔ 不动局外解锁集合。

⛔ 共用清理路径 → "打完一局，永久解锁也没了"，
这是最严重的资产事故类型之一。

【产出】两套集合，清理路径分离

【判据】⚠ 连打 3 局，**局外解锁数量单调递增**

【审】`audit/godot/relic-build.md#1`

### Step 6　⚠ 拿遗物后立即刷缓存　`[relic/06#S6]`

【读】`howto/godot/relic-build.md#6. 局内属性：脏标记快照，不是每帧遍历`

【做】拿到遗物立即置脏并广播变更。

⛔ 不刷 → UI 显示旧面板，玩家以为没拿到 → **再拿一次**（重复触发）。

【产出】拿遗物后的缓存失效调用

【判据】⚠ 拿遗物后不切场景，**面板数字当场变化**

【审】`audit/godot/relic-build.md#14`

## 5. 常见返工

**① 每帧遍历。** 遗物多了才卡，前期测不出。

**② 两套脏标记。** 词条部分不更新。

**③ 解锁等结算。** 崩溃全丢。

**④ 清理路径共用。** 打完一局永久解锁也没了。
