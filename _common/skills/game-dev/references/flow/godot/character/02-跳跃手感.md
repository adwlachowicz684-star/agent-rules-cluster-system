# 02 跳跃手感（角色控制域）

> **前置**：[01-移动基座](01-移动基座.md) 已验收（角色能跑、站得住、下坡贴地）
> **本步交付**：土狼时间、跳跃缓冲、可变跳跃高度、顶点悬停 四件套
> **对应**：流程 `howto/godot/platformer-feel.md` · 审核 `audit/godot/platformer-feel.md`

## 0. 交付物定义

能当场演示这四条，每条都能"感觉到"而不是"代码里有"：

1. **土狼时间**：走出平台边缘后 **~0.12 秒内**按跳，**仍然能跳**
2. **跳跃缓冲**：落地前 **~0.15 秒内**按跳，**落地瞬间自动起跳**（不用卡帧）
3. **可变高度**：轻点 = 小跳，按住 = 大跳，两者高度明显不同
4. **顶点悬停**：跳跃最高点附近**下落变慢**（滞空感）

- [ ] 01 已完成：`is_on_floor()` 在 `move_and_slide()` **之后**读取
- [ ] 已确认 `floor_snap_length` 已设（否则下坡时 `is_on_floor()` 会假 false）
- [ ] ⚠ 已确认跳跃用**速度赋值**不是加力（`velocity.y = -JUMP_VELOCITY`）
- [ ] 有一处"走出边缘"和一个"高低差"可测地形

## 2. 工序

### Step 1　建立状态变量　`[character/02#S1]`

【读】`howto/godot/platformer-feel.md#0. 控制器状态`

【做】
```gdscript
var coyote_timer := 0.0        # 土狼时间剩余
var jump_buffer_timer := 0.0   # 跳跃缓冲剩余
var jump_hold := 0.0           # 已按住时长
var was_on_floor := false
var is_jumping := false

const COYOTE_WINDOW := 0.12    # 待实测
const BUFFER_WINDOW := 0.15    # 待实测
const MAX_HOLD := 0.25         # 待实测
const CUT_SPEED := -150.0      # 松手时的截断速度，待实测
```

【产出】控制器有完整状态

【判据】无（这是结构步）

【审】`audit/godot/platformer-feel.md#9`

### Step 2　⚠ 固定每帧顺序（顺序错了手感就错）　`[character/02#S2]`

【读】`howto/godot/platformer-feel.md#0. 控制器状态`

【做】严格按这个顺序写 `_physics_process`：

```text
① 采样输入      → 更新 buffer/coyote 计时器
② 消耗缓冲      → 判定本帧是否起跳
③ 重力/水平     → 施加重力（含顶点减重力）
④ move_and_slide()
⑤ 更新状态      → was_on_floor / is_jumping / 计时器递减
```

【产出】一个顺序正确的物理帧

【判据】⛔ **把"更新状态"放到 `move_and_slide()` 之前**会导致 `is_on_floor()` 读到旧值，
表现为"偶尔跳不起来"——出现这个症状先查顺序

【审】`audit/godot/platformer-feel.md#9`

### Step 3　土狼时间　`[character/02#S3]`

【读】`howto/godot/platformer-feel.md#1. 土狼时间（Coyote Time）`

【做】
```gdscript
# ① 采样阶段
if is_on_floor():
    coyote_timer = COYOTE_WINDOW
else:
    coyote_timer -= delta

# ② 消耗缓冲阶段
if Input.is_action_just_pressed("jump") and coyote_timer > 0.0:
    velocity.y = -JUMP_VELOCITY
    coyote_timer = 0.0        # ⚠ 必须清零，否则能连跳
    is_jumping = true
```

【产出】走出边缘后短时间内仍能跳

【判据】**实测**：走出平台边缘，在约 0.1 秒时按跳 → **能跳起来**；
等 0.5 秒再按 → **不能跳**。两边都对才算对。

【审】`audit/godot/platformer-feel.md#7`

### Step 4　跳跃缓冲　`[character/02#S4]`

【读】`howto/godot/platformer-feel.md#2. 跳跃缓冲（Jump Buffer）`

【做】
```gdscript
# ① 采样：按键先记账，不立即跳
if Input.is_action_just_pressed("jump"):
    jump_buffer_timer = BUFFER_WINDOW
else:
    jump_buffer_timer -= delta

# ② 消耗：落地瞬间若缓冲未过期，自动起跳
if jump_buffer_timer > 0.0 and coyote_timer > 0.0:
    velocity.y = -JUMP_VELOCITY
    jump_buffer_timer = 0.0
    coyote_timer = 0.0
    is_jumping = true
```

【产出】落地前按跳，落地即跳

【判据】**实测**：从高处落下，**在落地前约 0.1 秒**按跳 → 落地瞬间自动弹起。
⚠ 注意：缓冲和土狼**一起判**，只用缓冲会在空中乱跳。

【审】`audit/godot/platformer-feel.md#1`

### Step 5　可变跳跃高度　`[character/02#S5]`

【读】`howto/godot/platformer-feel.md#3. 可变跳跃高度`

【做】
```gdscript
# ③ 重力阶段前：松手就截断上升
if is_jumping and not Input.is_action_pressed("jump") and velocity.y < 0.0:
    velocity.y = maxf(velocity.y, -CUT_SPEED)   # 截断，不是归零
    is_jumping = false
```

【产出】轻点小跳、按住大跳

【判据】**实测**：轻点跳高度 ≈ 按住跳高度的 **40%~60%**。
⛔ 若两者一样高，说明截断没生效；若小跳几乎跳不起来，说明 `CUT_SPEED` 太小。

【审】`audit/godot/platformer-feel.md#4`

### Step 6　顶点悬停（apex）　`[character/02#S6]`

【读】`howto/godot/platformer-feel.md#8. 顶点悬停（apex）：降低顶点附近的重力`

【做】
```gdscript
const APEX_THRESHOLD := 60.0    # 待实测
const APEX_GRAVITY_SCALE := 0.5 # 待实测

# ③ 重力阶段
var g := gravity
if is_jumping and absf(velocity.y) < APEX_THRESHOLD:
    g *= APEX_GRAVITY_SCALE      # 顶点附近减重力
velocity.y += g * delta
```

【产出】最高点有滞空感

【判据】**实测**：上升末段到下落初段，**明显变慢**（录像逐帧看）；
⚠ 但要确认**总跳跃高度没变太多**，否则关卡的跳跃距离设计要重算。

【审】`audit/godot/platformer-feel.md#11`

## 3. 参考实现（2D 完整片段）

```gdscript
# 接在 01 的 player.gd 上 — Godot 4.x
@export var jump_velocity := 420.0     # 待实测
@export var gravity := 980.0           # 待实测

const COYOTE_WINDOW := 0.12
const BUFFER_WINDOW := 0.15
const MAX_HOLD := 0.25
const CUT_SPEED := -150.0
const APEX_THRESHOLD := 60.0
const APEX_GRAVITY_SCALE := 0.5

var coyote_timer := 0.0
var jump_buffer_timer := 0.0
var is_jumping := false

func _physics_process(delta: float) -> void:
    # ── ① 采样输入 ──
    var dir := Input.get_axis("move_left", "move_right")
    if is_on_floor():
        coyote_timer = COYOTE_WINDOW
    else:
        coyote_timer -= delta
    if Input.is_action_just_pressed("jump"):
        jump_buffer_timer = BUFFER_WINDOW
    else:
        jump_buffer_timer -= delta

    # ── ② 消耗缓冲 ──
    if jump_buffer_timer > 0.0 and coyote_timer > 0.0:
        velocity.y = -jump_velocity
        jump_buffer_timer = 0.0
        coyote_timer = 0.0
        is_jumping = true

    # ── ③ 重力 / 水平 ──
    velocity.x = move_toward(velocity.x, dir * move_speed,
        (accel if dir != 0.0 else decel) * delta)
    if is_jumping and not Input.is_action_pressed("jump") and velocity.y < 0.0:
        velocity.y = maxf(velocity.y, -CUT_SPEED)
        is_jumping = false
    var g := gravity
    if is_jumping and absf(velocity.y) < APEX_THRESHOLD:
        g *= APEX_GRAVITY_SCALE
    if not is_on_floor():
        velocity.y += g * delta

    # ── ④ 移动 ──
    move_and_slide()

    # ── ⑤ 更新状态（⛔ 必须在 move_and_slide 之后）──
    if is_on_floor() and velocity.y >= 0.0:
        is_jumping = false
```

## 4. 验收清单

- [ ] 走出边缘 ~0.1s 内按跳：**能跳**
- [ ] 走出边缘 0.5s 后按跳：**不能跳**
- [ ] 落地前 ~0.1s 按跳：**落地自动起跳**
- [ ] 空中随便按跳：**不会二段跳**（除非设计要二段跳）
- [ ] 轻点 vs 按住：高度**明显不同**
- [ ] 顶点附近：**下落变慢**
- [ ] 连按跳跃：**不会连跳**（`coyote_timer` 清零生效）
- [ ] 下坡时跑动中按跳：**能跳**（`floor_snap_length` 生效）
- [ ] 顶到天花板：**正常下落，不卡住**
- [ ] ⚠ 改物理 tick 60→30：上述全部**仍然成立**



## 5. 常见返工

⚠ **`coyote_timer` 没清零** —— 走出边缘后能无限连跳，这是最常见的 bug。

⚠ **缓冲在空中也生效** —— 变成"空中预输入后落地即跳"变成"空中乱跳"。
✅ 必须 `buffer > 0 and coyote > 0` 同时成立。

⚠ **状态更新写在 `move_and_slide()` 之前** —— `is_on_floor()` 是"本帧最近一次 move_and_slide 的结果"，
提前读拿到旧值 → 出现"偶尔跳不起来"的玄学 bug。

⚠ **松手时 `velocity.y = 0` 而不是截断** —— 手感是"撞到天花板"很突兀。
✅ 用 `maxf(velocity.y, -CUT_SPEED)` 截断。

⚠ **顶点减重力改了总跳跃高度** —— 关卡按原高度设计的跳距全部失效。
✅ 减重力后**重测**跳跃高度与水平跳距，回填到关卡设计。

⚠ **先做动画再调手感** —— 动画会掩盖"其实跳得很别扭"。
