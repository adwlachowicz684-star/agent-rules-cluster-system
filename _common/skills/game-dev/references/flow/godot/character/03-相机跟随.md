# 03 相机跟随（角色控制域）

> **前置**：[01-移动基座](01-移动基座.md) 已验收
> **本步交付**：一个跟得住、不抖、不穿墙、跳跃时不晕的相机
> **对应**：流程 `howto/godot/camera-cutscene.md` `howto/godot/3d.md` · 审核 `audit/godot/camera-cutscene.md`

## 0. 交付物定义

能演示：

1. 角色移动时相机平滑跟随，⛔ 不是硬贴
2. 角色**小跳时相机不上下猛晃**（这是新手最容易做错的）
3. 角色走到关卡边缘时相机**不越界**（不露出场景外的黑边）
4. 快速移动时角色不被相机"甩掉"

## 1. 前置检查清单

- [ ] 01 已完成，角色移动是干净的（⚠ **先用固定相机确认过**移动不抖）
- [ ] 已确认 2D 用 `Camera2D`，3D 用 `Camera3D`（第三人称通常挂 `SpringArm3D`）
- [ ] 已确认相机的 `process_mode` 需求（暂停时是否仍跟随）
- [ ] ⚠ 已想清楚：**相机要跟随角色的哪个点**（脚底？中心？头部？）

## 2. 工序

### Step 1　确定跟随目标点　`[character/03#S1]`

【读】howto/godot/camera-cutscene.md —— 只查本步涉及的章节，⛔ 不要通读全文

【做】⛔ **不要直接跟角色根节点**——跳跃时根节点上下动，相机会跟着上下猛晃。

✅ 2D 常见做法：跟一个"平滑后的水平位置 + 固定的垂直位置"，
或者跟随点只在角色**落地时**才更新垂直分量。

```
跟随点策略（横版）：
  水平：跟随角色 x（平滑）
  垂直：跟随角色 y，但⛔ 只在 is_on_floor() 为真时更新
       → 跳跃时相机保持不动，落地才调整
```

【产出】确定跟随规则（写进代码注释）

【判据】角色原地跳：相机**上下不动**

### Step 3　⚠ 关键：把相机更新放进 　`[character/03#S3]``_physics_process`

【读】howto/godot/camera-cutscene.md —— 只查本步涉及的章节，⛔ 不要通读全文

【做】
```gdscript
# camera_rig.gd

    global_position = target.global_position   # 或用 lerp/smooth
```

⚠ 若相机跟的是物理物体，**必须在 `_physics_process`**，且开启
`Project Settings > Physics > Common > Smooth Traversal`（或自己插值），
⛔ 否则会出现"物理 60Hz、渲染 144Hz"导致的周期性抖动。

若只在 60Hz 屏测，这个 bug 会漏到线上。

## 3. 参考实现（2D）

```gdscript
# camera_rig.gd — Godot 4.x
extends Camera2D

@export var target_path: NodePath
@export var smooth_speed := 5.0
@export var vertical_follow_on_floor_only := true

@onready var _target := get_node(target_path) as CharacterBody2D
var _follow_y := 0.0

func _ready() -> void:
    position_smoothing_enabled = true
    position_smoothing_speed = smooth_speed
    _follow_y = _target.global_position.y

func _physics_process(delta: float) -> void:
    if _target == null:
        return
    # ⚠ 垂直只在落地时更新 → 跳跃时相机不晃
    if _target.is_on_floor():
        _follow_y = _target.global_position.y
    global_position = Vector2(_target.global_position.x, _follow_y)
```

## 4. 验收清单

- [ ] 角色跑动：平滑跟随，无硬切
- [ ] 角色**原地跳**：相机上下不动
- [ ] 角色**小跳**：相机不晃
- [ ] 角色**大跳**（跨大高差）：相机在**落地后**才调整垂直
- [ ] 关卡边缘：不露黑边
- [ ] 快速左右横跳：角色不被甩出视野
- [ ] ⚠ 高刷屏（120/144Hz）：匀速跑无周期性抖动
- [ ] 游戏暂停（`get_tree().paused = true`）：相机行为符合预期（按 `process_mode`）
- [ ] 3D：贴墙时相机自动拉近（若用 SpringArm）

## 5. 常见返工

⚠ **相机直接跟角色节点** → 每次跳跃画面上下猛晃，晕。这是最常见的相机 bug，
而且是在"做完一段时间后才被反馈晕"。

⚠ **相机更新放 `_process` 而角色在 `_physics_process`** → 高刷屏抖动。
⚠ 且这个 bug **在 60Hz 测试机上看不出来**。

⚠ **同时用 `position_smoothing` 和自己写的 `lerp`** → 两套平滑叠加，
表现为"跟随迟滞严重"或"抖动"。

⚠ **相机和移动同时开发** → 抖了分不清谁的问题。✅ 先固定相机确认移动干净。

⚠ **忘了边界限制，等美术把场景做完才发现露黑边** → 场景尺寸一改就要重配。
✅ 边界值写成导出变量，随场景尺寸配置。
