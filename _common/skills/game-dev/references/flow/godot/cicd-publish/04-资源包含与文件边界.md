# 04 资源包含与文件边界（CI/CD 与导出发布域）

> **本步交付**：非资源文件清单 + 只读路径口径 + 纹理格式校验
> **对应**：流程 `howto/godot/cicd-publish.md` · 审核 `audit/godot/cicd-publish.md`

## 0. 交付物定义

1. 所有非资源文件（`.json` / `.csv` / `.txt`）已在过滤器里显式声明
2. 没有把任何需要进包的文件放在**点开头**的目录或文件名下
3. 运行时写入路径全部走 `user://`，`res://` 只用于读
4. ETC2 / ASTC 的导入开关已确认，且 Web / Apple Embedded 能导出
5. 4.5 之前的 "Fix Import" 之后**重载过项目**
6. Android 的纹理格式与 `INTERNET` 权限已确认

## 1. 前置检查清单

- [ ] 预设的 Resources 过滤器里有全部非资源文件类型
- [ ] 无点开头的待打包文件
- [ ] 代码中没有在运行时写 `res://`
- [ ] Web / Apple Embedded 导出无空白校验错误
- [ ] 4.4.x 及更早：点过 Fix Import 后重载过项目
- [ ] Android 纹理格式已选、INTERNET 已加

## 2. 工序

### Step 1　非资源文件必须显式声明，⛔ 不会自动进包　`[cicd-publish/04#S1]`

【读】`howto/godot/cicd-publish.md#3.5 文件包含边界：非资源文件与点开头文件`

【做】
在导出预设的 **Resources 页 → Filters to export non-resource files** 里
显式声明 `.json`、`.csv`、`.txt` 等非资源文件（逗号分隔）。
⛔ 不声明 —— 编辑器里一切正常、**导出后读不到**。

⛔ 表现极具误导性：`FileAccess.open()` 报的是"打不开"，
⛔ 排查必然被引向路径拼写或打包损坏，不会想到"这个文件根本没进包"。

ⓘ 这条是 `datatable` / `i18n` / `ops` 域的下游：
那些域讲表怎么设计、文本怎么组织，
⛔ 但"文件能不能进包"由本步决定。

【产出】非资源文件类型清单（已写进过滤器）

【判据】导出后解压，配置文件确实在包里。

【审】`audit/godot/cicd-publish.md#24`

### Step 2　点开头的文件永远不会进包，且不报错　`[cicd-publish/04#S2]`

【读】`howto/godot/cicd-publish.md#3.5 文件包含边界：非资源文件与点开头文件`

【做】
检查所有待打包文件：**以点开头的文件或文件夹永远不会被导出**
（官方机制，目的是防止 `.git` 进包）。
⛔ 把配置放在 `.config/` 或命名 `.env.json` —— **永远不进包，且不报错**。

ⓘ 这条与 S1 是**两个独立的静默点**：
S1 是"类型没声明"，S2 是"名字不合格"。
⛔ 只修 S1 的人会困惑"我明明声明了 `.json` 为什么还是没有"。

【产出】待打包文件的命名检查（无点开头）

【判据】包内无缺失，且没有任何待打包文件以点开头。

【审】`audit/godot/cicd-publish.md#25`

### Step 3　导出后 `res://` 只读，运行时写入必须走 `user://`　`[cicd-publish/04#S3]`

【读】`howto/godot/cicd-publish.md#3.2 各平台要点`

【做】
所有运行时写入（存档、设置、缓存、下载的热更包）用 `user://`。
⛔ 写 `res://` —— 导出包里项目文件系统**只读**，写入失败，
⛔ 而编辑器里可写，于是"编辑器正常、出包后存档丢失"。

ⓘ 路径细节：`user://` 在各平台位置不同（Windows `%APPDATA%`、
macOS `~/Library/Application Support`、Linux `~/.local/share`），
Web 上是 **IndexedDB 虚拟文件系统**。
⛔ 用 `OS.get_user_data_dir()` 打日志确认真实位置，别猜。

【产出】写入路径清单（全部 `user://`）

【判据】出包后写一次存档并重启，数据仍在。

【审】`audit/godot/cicd-publish.md#26`

### Step 4　ETC2 / ASTC 关闭时，Web 与 Apple Embedded 给的是空白错误　`[cicd-publish/04#S4]`

【读】`howto/godot/cicd-publish.md#3.6 ETC2/ASTC 关闭时，Web 与 Apple Embedded 的空白错误`

【做】
确认 ETC2 / ASTC 导入开关已开（项目设置与导出预设**两处都要开**）。
⛔ 关闭后导 Web / Apple Embedded —— 显示**红色校验错误但消息框为空**，
⛔ 没有文字、没有提示、没有可搜索的字符串。

ⓘ 官方修复进度：macOS 在 4.3（PR #86769）、Android 在 4.7（PR #117341）
才补上说明文字；⛔ **Web 与 Apple Embedded 至今没有**（issue #119803）。
面对一个空的红色叉，⛔ 排查方向必然被引向场景、图标或模板安装。

ⓘ 两处开关在不同位置：
项目设置的 VRAM Compression → Import ETC2 ASTC，
以及导出预设 Options 里的 VRAM Texture Compression → For Mobile。
⛔ 只开预设那处、项目设置关着，正好触发空白错误。

【产出】两处开关的确认记录 + 各平台导出无空白错误

【判据】Web 与 Apple Embedded 能导出；关闭时能看到明确文字。

【审】`audit/godot/cicd-publish.md#27`

### Step 5　4.5 之前，Fix Import 不等于真的重新导入　`[cicd-publish/04#S5]`

【读】`howto/godot/cicd-publish.md#3.6 ETC2/ASTC 关闭时，Web 与 Apple Embedded 的空白错误`

【做】
在 4.4.x 及更早版本上，点 "Fix Import" 后**必须再执行
Project → Reload Current Project**。
⛔ 4.5 之前（PR #107015，issue #106992）该按钮只改项目设置、
**不真正重新导入**，`.import` 里不会写入 `.etc2` 变体。

⛔ 表现为"设置开了但纹理还是没压缩"，
而设置面板上确实是开着的，⛔ 排查被引向纹理导入参数本身。

ⓘ 验证方式：看 `.import` 文件内容，或 Import dock 的预览，
⛔ 不看设置开关。

【产出】重导入后的 `.import` 检查记录

【判据】`.import` 里存在压缩变体条目。

【审】`audit/godot/cicd-publish.md#28`

### Step 6　Android 的纹理格式与 INTERNET 权限要在导出前确认　`[cicd-publish/04#S6]`

【读】`howto/godot/cicd-publish.md#3.3 Android 高频坑`

【做】
为每个架构选好纹理压缩格式（ETC2 / ASTC / DXT），
联网游戏加上 `INTERNET` 权限。
⛔ 漏选纹理格式 —— 运行时**纹理全黑**；
⛔ 漏 `INTERNET` —— 真机网络请求全部失败，⛔ **而编辑器里正常**（编辑器默认有该权限）。

ⓘ 这两条的共同点是"编辑器全好、真机全坏"：
⛔ 只做编辑器验证的团队会一直到上架前才发现。

【产出】Android 预设检查记录（纹理格式 + 权限）

【判据】真机安装后纹理正常、网络请求成功。

【审】`audit/godot/cicd-publish.md#10`、`audit/godot/cicd-publish.md#11`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：运行时写入只走 user://
static func save_path() -> String:
    return "user://savegame.tres"      # ⛔ 不是 res://

func _ready() -> void:
    print(OS.get_user_data_dir())      # ⓘ 确认 user:// 的真实位置
```

```
# ⓘ 承接本步产出：待打包文件不能以点开头
res://data/items.json        # ✅ 但要确保过滤器声明了 *.json
res://.config/settings.json  # ⛔ 永远不进包，且不报错
```
