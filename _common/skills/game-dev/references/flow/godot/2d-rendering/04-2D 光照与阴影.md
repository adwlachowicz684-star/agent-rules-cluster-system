# 04 2D 光照与阴影（2D 渲染域）

> **本步交付**：光照节点组 + 法线贴图走法 + 遮挡轮廓 + 光源预算
> **对应**：流程 `howto/godot/2d-rendering.md` · 审核 `audit/godot/2d-rendering.md`

## 0. 交付物定义

1. `CanvasModulate` 已就位，作为整体基调
2. 法线贴图一律走 `CanvasTexture`，⛔ 不挂 Sprite 直接属性
3. 每个投影光源都有对应的 `LightOccluder2D`
4. 带阴影光源的数量有明确上限
5. 昼夜/场景切换时基调与光源开关一起切

## 1. 前置检查清单

- [ ] 场景里有且只有一个 `CanvasModulate`
- [ ] 法线贴图通过 `CanvasTexture` 指定
- [ ] 开了 `shadow_enabled` 的光源都有遮挡体
- [ ] 带阴影光源数量已写下上限
- [ ] 切换场景基调的路径已测过

## 2. 工序

### Step 1　`CanvasModulate` 打底，它是 2D 光照的"画布基色"　`[2d-rendering/04#S1]`

【读】`howto/godot/2d-rendering.md#4. 2D 光照`

【做】
先放 `CanvasModulate` 定整体基调（夜景压暗偏蓝），再放光源。
⛔ 没有 `CanvasModulate` 就上 2D 光照 —— 画面基底是纯白，
光照**看着无效**或整体过曝，⛔ 而光源的能量、贴图、范围全都检查过是对的。

⛔ 表现为"加了光但看不出来"，排查被引向 `energy` 和 `texture`，
于是越调越亮，最后过曝。

【品】`craft/godot/aesthetics.md#1. 视觉层次：一个画面只允许一个主角`

【产出】基调色（昼 / 夜 / 特殊场景各一组）

【判据】关掉所有光源时，画面仍是"夜晚"而不是"白天"。

【审】`audit/godot/2d-rendering.md#6`

### Step 2　法线贴图走 `CanvasTexture`，`height` 不是阴影高度　`[2d-rendering/04#S2]`

【读】`howto/godot/2d-rendering.md#4. 2D 光照`

【做】
法线/高光贴图通过 `CanvasTexture` 资源指定给 Sprite。
⛔ 像 3.x 那样挂 Sprite 的直接属性 —— 4.x 这套属性已移到 `CanvasTexture`，
⛔ 表现为"配了法线贴图但光照完全没立体感"，且**不报错**。

⛔ 同时别把 `PointLight2D.height` 当阴影高度调：
那是**法线贴图的感知高度**，调它只会改变立体感的强弱，
⛔ 想要投影必须靠 `shadow_enabled` + `LightOccluder2D`。

【产出】`CanvasTexture` 配置说明 + `height` 的取值口径

【判据】移动光源时，精灵表面的明暗随之变化。

【审】`audit/godot/2d-rendering.md#24`、`audit/godot/2d-rendering.md#23`

### Step 3　投影必须有 `LightOccluder2D`，否则什么也不挡　`[2d-rendering/04#S3]`

【读】`howto/godot/2d-rendering.md#遮挡阴影`

【做】
给每个需要投影的物体加 `LightOccluder2D` 并画好 `OccluderPolygon2D` 轮廓。
⛔ 只开光源的 `shadow_enabled` —— 没有遮挡体时**什么也不挡**，
表现为"开了阴影但地面一片干净"，⛔ 而光源面板上的阴影参数是勾上的。

ⓘ 轮廓要与精灵的实际占地一致：
轮廓偏大阴影会"提前出现"，偏小则阴影与物体脱节，
⛔ 两者都会被当成阴影算法的精度问题。

【产出】遮挡体清单（物体 × 轮廓来源）

【判据】物体与阴影在移动时保持贴合。

【审】`audit/godot/2d-rendering.md#7`

### Step 4　带阴影光源要有数量上限　`[2d-rendering/04#S4]`

【读】`howto/godot/2d-rendering.md#4. 2D 光照`

【做】
写下同时激活的**带阴影**光源上限，并在生成逻辑里强制。
⛔ 每个火把都开阴影 —— 阴影是**按光源的全屏开销**，
数量一多直接爆，⛔ 而在编辑器里放两三个时完全正常，
只有关卡铺满之后才出现，那时已经很难砍。

ⓘ 常见做法：只给"主角附近 N 个"或"剧情关键点"开阴影，
其余用 Additive 精灵模拟光效（视觉上够用，开销是固定几张图）。

【产出】带阴影光源上限 + 超出时的降级策略

【判据】满关卡场景下帧率仍在预算内（数字由 `perf` 域实测给出）。

【审】`audit/godot/2d-rendering.md#36`

### Step 5　切换场景基调时，基调与光源开关一起切　`[2d-rendering/04#S5]`

【读】`howto/godot/2d-rendering.md#夜景做法`

【做】
昼/夜切换同时改 `CanvasModulate.color` 与光源的 `enabled`。
⛔ 只切其中一个 —— 只改基调则夜里仍有光斑，只关光源则画面亮度没变，
⛔ 表现为"切了夜景但感觉不对"，而两处代码单看都是对的。

⛔ 这里还有个顺序陷阱：切换过程中若出现一帧"亮度已变、光源未变"，
会闪一下。⛔ 这种一帧的闪在编辑器里几乎抓不到，只在录屏逐帧看时才现形。

【产出】切换函数（一处入口，同时改两项）

【判据】逐帧录屏看不到中间态。

【审】`audit/godot/2d-rendering.md#6`、`audit/godot/2d-rendering.md#12`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：基调 + 光源 + 遮挡 + 数量上限
@onready var _modulate: CanvasModulate = $CanvasModulate

# ⓘ 带阴影光源上限：MAX_SHADOW_LIGHTS 需按目标档位实测（见 perf 域）
const MAX_SHADOW_LIGHTS := 3
const DAY_COLOR := Color(1.0, 1.0, 1.0)
const NIGHT_COLOR := Color(0.3, 0.35, 0.55)

var _shadow_lights: Array[PointLight2D] = []

func set_night(is_night: bool) -> void:
    # ⓘ 基调与光源必须同一处改，否则出现中间态闪帧
    _modulate.color = NIGHT_COLOR if is_night else DAY_COLOR
    for l in get_tree().get_nodes_in_group("light"):
        l.enabled = is_night

# ⓘ 超出上限的降级：改为不带阴影的等效光源
func register_shadow_light(l: PointLight2D) -> void:
    if _shadow_lights.size() >= MAX_SHADOW_LIGHTS:
        l.shadow_enabled = false
        return
    _shadow_lights.append(l)
```

```gdscript
# ⓘ 法线贴图走 CanvasTexture，⛔ 不挂 Sprite 直接属性
func apply_normal_map(sprite: Sprite2D, base: Texture2D, normal: Texture2D) -> void:
    var ct := CanvasTexture.new()
    ct.diffuse_texture = base
    ct.normal_texture = normal
    sprite.texture = ct
```

## 4. 验收清单

- [ ] 关掉全部光源，画面仍是夜晚基调
- [ ] 移动光源时精灵表面明暗随之变化
- [ ] 开了阴影的光源都有对应遮挡体，且轮廓贴合
- [ ] 带阴影光源不超过上限，超出有降级
- [ ] 昼夜切换逐帧无中间态

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 加了光但看不出来 / 过曝 | 没有 `CanvasModulate` | S1 |
| 配了法线但没立体感 | 挂错位置或调了 `height` | S2 |
| 开了阴影地面一片干净 | 没有 `LightOccluder2D` | S3 |
| 关卡铺满后掉帧 | 带阴影光源过多 | S4 |
| 切夜景感觉不对 / 闪一下 | 基调与光源未同处切换 | S5 |
