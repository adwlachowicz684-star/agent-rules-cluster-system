# 05 屏幕特效与着色器（2D 渲染域）

> **本步交付**：抓屏边界 + 效果清单 + 参数常量化
> **对应**：流程 `howto/godot/2d-rendering.md` · 审核 `audit/godot/2d-rendering.md`

## 0. 交付物定义

1. 每个读屏幕的效果都有明确的 `BackBufferCopy` 边界
2. 屏幕纹理只在 `fragment()` 里读
3. 着色器参数名已常量化，⛔ 不散落字符串字面量
4. 一帧最多一次全屏拷贝
5. 溶解/描边类效果与碰撞体状态一致
6. 全屏转场不吞点击

## 1. 前置检查清单

- [ ] 读屏效果前都插了 `BackBufferCopy`
- [ ] 没有在 `vertex()` 里采样屏幕纹理
- [ ] 参数名常量已集中定义
- [ ] 全屏拷贝次数已数过（目标 ≤ 1）
- [ ] 溶解/死亡时碰撞体同步关闭
- [ ] 转场层 `mouse_filter = Ignore`

## 2. 工序

### Step 1　读屏幕的效果必须先划出 `BackBufferCopy` 边界　`[2d-rendering/05#S1]`

【读】`howto/godot/2d-rendering.md#水面/热扭曲`

【做】
在需要"从这一层开始抓屏"的位置插 `BackBufferCopy`。
⛔ 不插 —— 2D 的抓取时机是"绘制顺序中**第一个**读取 `hint_screen_texture`
的 CanvasItem 触发一次全屏拷贝"，
⛔ 于是拷到的是**已经画上去的东西**：水面把 UI、把角色一起扭了，
或者反过来该扭的没扭到，而 shader 代码本身完全正确。

⛔ 排查代价极高：shader、uniform、SCREEN_UV 全都对，
⛔ 唯一错的是"没有声明从哪里开始拷"，而这个东西在 shader 文件里**根本看不到**。

【产出】BackBufferCopy 节点位置说明（哪个效果、插在哪一层之前）

【判据】扭曲线只影响它下面的层，不影响 UI 与角色。

【审】`audit/godot/2d-rendering.md#8`

### Step 2　屏幕纹理只在 `fragment()` 里读　`[2d-rendering/05#S2]`

【读】`howto/godot/2d-rendering.md#5. CanvasItem 着色器配方`

【做】
所有 `hint_screen_texture` 的采样写在 `fragment()`。
⛔ 写在 `vertex()` —— 官方限定该 hint **只在 `fragment()` 可读**，
⛔ 表现为效果完全不出现（或取到垃圾值），而编译**不报错**。

ⓘ 同样的静默失效还有一处：4.x 移除了 3.x 的 `SCREEN_TEXTURE` 内置变量
（PR #70967），必须自己声明 `uniform sampler2D xxx : hint_screen_texture`。
⛔ 照抄 3.x 教程的写法是编译错误，反而更容易发现；
⛔ 而"声明了但在 vertex 里用"是编译通过、效果没有。

【产出】屏幕特效清单（效果 × 采样位置 × 抓屏边界）

【判据】每个读屏效果都能指认它的采样函数名。

【审】`audit/godot/2d-rendering.md#25`

### Step 3　着色器参数名常量化，别散落字面量　`[2d-rendering/05#S3]`

【读】`howto/godot/2d-rendering.md#受击闪白`

【做】
把 `set_shader_parameter` 的名字集中定义成常量。
⛔ 在各处直接写字符串 —— 拼错时**静默失效**：
不报错、不警告、参数就是没设上，表现为"调了半天没反应"。

⛔ 这类 bug 特别难查，因为它长得很像"shader 逻辑写错了"，
于是反复去改 glsl，而 glsl 一直是对的。

ⓘ 常量化还有个附带收益：改名时只有一处要改。
⛔ 否则每处字符串都要手动找，漏一处就是一个静默失效。

【产出】参数名常量表（常量 ↔ shader uniform 名）

【判据】grep 不到散落在业务代码里的 shader 参数字符串。

【审】`audit/godot/2d-rendering.md#16`

### Step 4　一帧最多一次全屏拷贝　`[2d-rendering/05#S4]`

【读】`howto/godot/2d-rendering.md#水面/热扭曲`

【做】
数一遍一帧内触发的全屏拷贝次数，控制在一次。
⛔ 每个全屏效果各自拷一份 —— 一帧多次全屏拷贝，
在中低端设备上是**直接爆掉**的量级，⛔ 而在开发机上只表现为"略卡"。

ⓘ 多个屏幕效果应当共用同一次拷贝（一个 `BackBufferCopy` + 多个读取者），
而不是每个效果前面各插一个。

【产出】全屏拷贝次数清单（效果 × 是否共用拷贝）

【判据】一帧内 BackBufferCopy 触发次数 ≤ 1。

【审】`audit/godot/2d-rendering.md#31`

### Step 5　溶解与描边要和碰撞体状态同步　`[2d-rendering/05#S5]`

【读】`howto/godot/2d-rendering.md#溶解（死亡消散）`

【做】
溶解到"视觉上消失"时同步关掉碰撞/受击。
⛔ 只用 `discard` 让像素消失 —— 碰撞体仍在，
表现为"明明看着散掉了还被打中/还能挡路"，
⛔ 而打击判定代码完全正确，问题只在于两个系统的状态没同步。

ⓘ 溶解进度与"何时算死亡"要定一个明确阈值（如 ≥ 0.9），
⛔ 不要两边各判一次，否则会出现"有的怪 0.8 就死、有的 1.0 才死"。

【产出】溶解进度与碰撞体/受击状态的映射（含阈值）

【判据】溶解到阈值后，该对象不再参与任何碰撞与受击。

【审】`audit/godot/2d-rendering.md#30`、`audit/godot/2d-rendering.md#4`

### Step 6　全屏转场层不能吞点击　`[2d-rendering/05#S6]`

【读】`howto/godot/2d-rendering.md#8. 转场`

【做】
全屏转场用的 `ColorRect` 设 `mouse_filter = Ignore`。
⛔ 用默认的 Stop —— 过场期间挡住所有点击，
表现为"过场后点不了按钮"，⛔ 而这与转场逻辑毫无关系，
排查必然被引向 UI 的事件分发。

ⓘ 顺便：转场期间应当**显式**屏蔽输入，
而不是靠一层透明控件"顺带"挡住。
⛔ 靠副作用挡输入，等于把输入屏蔽的开关藏在一个控件的属性里。

【产出】转场层的 mouse_filter 设置 + 输入屏蔽的显式开关

【判据】转场结束后第一个点击能被正确接收。

【审】`audit/godot/2d-rendering.md#5`

## 3. 参考实现

```glsl
// ⓘ 承接本步产出：屏幕扭曲 —— 只在 fragment() 里读 hint_screen_texture
shader_type canvas_item;
render_mode unshaded;

uniform sampler2D screen_tex : hint_screen_texture;
uniform float strength = 0.02;

void fragment() {
    vec2 uv = SCREEN_UV;
    float w = sin(uv.y * 40.0 + TIME) * strength;
    COLOR = texture(screen_tex, uv + vec2(w, 0.0));
}
```

```gdscript
# ⓘ 承接本步产出：抓屏边界 + 参数常量化 + 拷贝次数控制
const P_DISSOLVE := "dissolve"      # ⓘ 与 shader 里的 uniform 名一一对应
const DISSOLVE_DEAD := 0.9          # ⓘ 视觉消失与判定消失共用一个阈值

var _bbc: BackBufferCopy

func _ready() -> void:
    # ⓘ 所有屏幕效果共用这一次拷贝，⛔ 不要每个效果各插一个
    _bbc = BackBufferCopy.new()
    _bbc.copy_mode = BackBufferCopy.COPY_MODE_VIEWPORT
    add_child(_bbc)

func tick_dissolve(mat: ShaderMaterial, hurtbox: CollisionShape2D, v: float) -> void:
    mat.set_shader_parameter(P_DISSOLVE, v)
    hurtbox.disabled = v >= DISSOLVE_DEAD
```

## 4. 验收清单

- [ ] 每个读屏效果都有 `BackBufferCopy` 边界，不影响 UI
- [ ] 屏幕纹理采样全在 `fragment()`
- [ ] shader 参数名已常量化，无散落字面量
- [ ] 一帧全屏拷贝 ≤ 1 次
- [ ] 溶解到阈值后碰撞与受击同步关闭
- [ ] 转场层 `mouse_filter = Ignore`，输入屏蔽是显式开关

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 水面把 UI/角色一起扭了 | 没插 `BackBufferCopy` | S1 |
| 屏幕效果完全不出现且不报错 | 在 `vertex()` 里采样 | S2 |
| 调了半天参数没反应 | 参数名拼错（静默失效） | S3 |
| 中低端机上直接爆 | 每帧多次全屏拷贝 | S4 |
| 看着散掉了还能被打中 | `discard` 后碰撞体未关 | S5 |
| 过场后点不了按钮 | 转场层吞点击 | S6 |
