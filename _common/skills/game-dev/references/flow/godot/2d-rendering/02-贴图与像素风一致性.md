# 02 贴图与像素风一致性（2D 渲染域）

> **本步交付**：三层过滤口径 + 重新导入 + stretch 模式
> **对应**：流程 `howto/godot/2d-rendering.md` · 审核 `audit/godot/2d-rendering.md`

## 0. 交付物定义

1. 三层过滤（项目默认 / 每份导入 / 逐节点）口径已定，且三者不打架
2. 已确认**重新导入**执行过，⛔ 不只是改了项目默认
3. stretch 模式与基准分辨率已定
4. 相机 `zoom` 与像素风的关系已明确（整数倍或接受代价）
5. 描边/放大类效果预留了透明边距

## 1. 前置检查清单

- [ ] 项目默认过滤已设，且**已重新导入**全部贴图
- [ ] 不存在逐节点 `texture_filter` 与项目默认相反的情况
- [ ] stretch 模式与基准分辨率已写下
- [ ] 相机 zoom 取值策略已定
- [ ] 描边类效果的资源已留透明边距

## 2. 工序

### Step 1　先定三层过滤口径，别只改项目默认　`[2d-rendering/02#S1]`

【读】`howto/godot/2d-rendering.md#9. 纹理过滤：像素风的三层开关`

【做】
明确三层各自的取值：项目默认、每份导入、逐节点覆盖。
⛔ 只改项目默认就以为完事 —— **改项目默认不会追溯已导入的贴图**，
改之前导入的文件保留着旧的 Linear 设置。

⛔ 这事的排查代价极高：项目设置里显示的就是 Nearest，
于是检查一遍后**排除掉这个方向**，转而去查分辨率、查相机、查导入尺寸，
而真相是"改了默认值但没重新导入"。

【产出】三层过滤取值表

【判据】能说出每一层的取值，以及"改了默认值要做什么额外动作"。

【审】`audit/godot/2d-rendering.md#10`

### Step 2　改完必须重新导入，且逐节点覆盖不与之冲突　`[2d-rendering/02#S2]`

【读】`howto/godot/2d-rendering.md#9. 纹理过滤：像素风的三层开关`

【做】
执行重新导入（删 `.godot/imported/` 重开工程，或选中贴图 Reimport），
再检查是否有逐节点 `texture_filter` 与项目默认不一致。
⛔ 两者不一致会让**同一种图有的糊有的锐** ——
美术会报"这批图有问题"，而实际是节点上被单独覆盖过。

ⓘ 逐节点覆盖优先级最高，所以它既是"局部例外"的手段，
也是"忘了自己改过"的隐患源。⛔ 建议：例外节点要在命名或注释里标出来。

【产出】重新导入记录 + 逐节点例外清单

【判据】同素材的同类节点，放大后模糊程度一致。

【审】`audit/godot/2d-rendering.md#10`、`audit/godot/2d-rendering.md#33`

### Step 3　stretch 模式与基准分辨率一起定　`[2d-rendering/02#S3]`

【读】`howto/godot/2d-rendering.md#9. 纹理过滤：像素风的三层开关`

【做】
像素风设 `Mode = viewport` 并写下基准分辨率。
⛔ 用默认模式 —— 整屏按线性插值放大，糊的是**整个游戏**，
而此时项目过滤设置是对的、贴图是对的，⛔ 于是再次排除掉正确的方向。

ⓘ stretch 与过滤是两件事：过滤管"贴图采样"，stretch 管"整屏缩放"。
⛔ 只对一个而不管另一个，结果都是糊，但排查时会互相甩锅。

【产出】stretch 模式 + 基准分辨率 + 缩放比例

【判据】窗口拉大后像素边缘仍然锐利。

【审】`audit/godot/2d-rendering.md#9`

### Step 4　相机 `zoom` 取整倍，否则接受代价　`[2d-rendering/02#S4]`

【读】`howto/godot/2d-rendering.md#9. 纹理过滤：像素风的三层开关`

【做】
明确相机 zoom 是固定整数倍，还是允许平滑缩放。
⛔ 非整数倍会让像素边缘随移动闪烁、撕裂 ——
表现为"站着看很干净，一走动画面就脏"，⛔ 极易被当成抖动或抗锯齿问题去查。

ⓘ 这是取舍不是错误：想要平滑的镜头推拉就得接受像素抖动。
⛔ 但要**写下来**，否则美术和程序会各自以为是对方的问题。

【产出】zoom 策略（整数倍档位表 / 或"平滑缩放，接受抖动"的结论）

【判据】选了哪种都能说出代价是什么。

【审】`audit/godot/2d-rendering.md#32`

### Step 5　描边与放大类效果预留透明边距　`[2d-rendering/02#S5]`

【读】`howto/godot/2d-rendering.md#描边`

【做】
给需要描边/发光/溶解的素材留透明边距，或把效果放到子节点。
⛔ 不留边距 —— 描边会让精灵**变大一圈**，而碰撞体不变，
表现为"看着还没碰到就打中了""边缘被裁掉一角"。

ⓘ 图集打包时同样要留 padding，
否则相邻图之间会**渗色**，表现为精灵边缘出现邻图的颜色。

【产出】素材边距规格（含图集 padding）

【判据】开到最大描边宽度时，边缘不被裁切、碰撞体仍与视觉一致。

【审】`audit/godot/2d-rendering.md#4`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：三层过滤口径 + stretch + zoom 档位
# 项目设置（project.godot）关键项：
#   [rendering] textures/canvas_textures/default_texture_filter = 0   # 0 = Nearest
#   [display] window/stretch/mode = "viewport"
#   [display] window/size/viewport_width = 640
#   [display] window/size/viewport_height = 360

# ⓘ zoom 档位：像素风只取整倍，⛔ 不做平滑插值
const ZOOM_STEPS := [1.0, 2.0, 3.0]

func set_zoom_step(i: int) -> void:
    var cam := get_viewport().get_camera_2d()
    cam.zoom = Vector2.ONE * ZOOM_STEPS[clampi(i, 0, ZOOM_STEPS.size() - 1)]
```

```gdscript
# ⓘ 描边素材的边距规格：OUTLINE_MARGIN 为每边预留像素
const OUTLINE_MARGIN := 4

func bake_outline(src: Image) -> Image:
    var out := Image.create(
        src.get_width() + OUTLINE_MARGIN * 2,
        src.get_height() + OUTLINE_MARGIN * 2,
        false, src.get_format())
    out.blit_rect(src, Rect2i(Vector2i.ZERO, src.get_size()), Vector2i(OUTLINE_MARGIN, OUTLINE_MARGIN))
    return out
```
