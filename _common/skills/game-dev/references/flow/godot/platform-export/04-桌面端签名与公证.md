# 04 桌面端签名与公证（多平台导出与发布域）

> **本步交付**：macOS 签名公证钉票链 + Entitlements + Bundle ID
> **对应**：流程 `howto/godot/platform-export.md` · 审核 `audit/godot/platform-export.md`

## 0. 交付物定义

1. macOS 签名链的每一环都能单独验证
2. 公证完成后 ticket 已钉进 app 本体
3. Entitlements 按实际用途开，生产不含 Debugging
4. Bundle identifier 有效且唯一
5. 产物形态与导出主机的限制已确认

## 1. 前置检查清单

- [ ] Developer ID 证书可用（或已明确走 ad-hoc 及其后果）
- [ ] 公证工具已配好（Xcode altool 或 rcodesign）
- [ ] Entitlements 清单已逐项说明理由
- [ ] Bundle identifier 已定且唯一
- [ ] ⚠ 是否打 DMG 已在 macOS 主机上执行

## 2. 工序

### Step 1　macOS 签名链逐环验证，Gatekeeper 是硬拦　`[platform-export/04#S1]`

【读】`howto/godot/platform-export.md#Gatekeeper 判定链（理解 macOS 发布的钥匙）`

【做】
按判定链逐环验证：签名 → 公证签发 ticket → 首次运行联网验证。
⛔ 只在自己机器上双击通过就算完 —— 开发机上通常已信任过该证书，
⛔ 于是"能打开"证明不了任何事。真正的验证要在一台**没装过该应用**的机器上做。

⛔ 没有 Developer ID 时的 `Built-in (ad-hoc only)` **不能过 Gatekeeper**，
⛔ 而失败提示是"无法验证开发者"或"已损坏"，
这两个提示**都不指向断的是哪一环**，排查被引向文件损坏或下载问题。

ⓘ 官方口径补充：ad-hoc 签名的作用是"让终端用户运行导出 App 更容易"，
⛔ 具体行为取决于签名 / 公证的组合（官方列了五种情形），
⛔ 所以"ad-hoc 到底能不能分发"没有单一答案，要看落在哪一种。

ⓘ 跨平台签名是官方支持的：Linux / Windows 上用 `rcodesign`（PKCS#12 凭据）。

【产出】判定链逐环的验证记录（含一台干净机器）

【判据】干净机器上首次打开不弹"已损坏"。

【审】`audit/godot/platform-export.md#9`

### Step 2　公证完必须钉票，否则离线打不开　`[platform-export/04#S2]`

【读】`howto/godot/platform-export.md#3. macOS`

【做】
公证通过后执行 `stapler staple`（或 `rcodesign staple`）把 ticket 写进 app 本体。
⛔ 公证完就发布 —— 不钉票时，离线环境首次打开会**卡在联网验证**。

⛔ 表现为"有网能开、没网打不开"，
⛔ 而排查几乎必然被引向网络权限或防火墙，不会想到是 ticket 没写进本体。
更隐蔽的是：验证期内有网的用户**全部正常**，于是这问题只在特定场景零星出现。

ⓘ 公证状态可查：`xcrun notarytool history` 查状态、
`xcrun notarytool log {ID}` 下日志 —— 失败时要看日志，不要只看"失败"两个字。

【产出】钉票命令已执行 + 离线环境实测记录

【判据】断网后首次打开仍能通过。

【审】`audit/godot/platform-export.md#10`

### Step 3　Entitlements 按实际用途开，生产必须关 Debugging　`[platform-export/04#S3]`

【读】`howto/godot/platform-export.md#Entitlements 是权限闸门`

【做】
逐项列出需要的 Entitlements 并写明理由，生产构建关掉 Debugging。
⛔ 把 Entitlements 当"全勾上省事" —— 它是权限闸门，
⛔ 而 `Debugging` 那一项**带它无法公证**：
表现为公证莫名失败，⛔ 失败日志不指向这项。

⛔ 另一类更难查：系统隐私权限（音频输入 / 相机 / 位置 / 照片库）
除了勾 Entitlements **还必须填 usage description**，
⛔ 缺了会在首次调用处直接崩，⛔ 且不提示具体原因 —— 与 iOS 的隐私描述是同一类静默崩溃。

ⓘ 需要 JIT 的 GDExtension 插件要 Allow JIT / Unsigned Executable Memory；
⛔ Steamworks overlay 所需的 `Disable Library Validation` 是社区实测、非官方确认，
⛔ 不要把它当官方口径写进规范。

【产出】Entitlements 清单（每项带理由）+ 生产构建已关 Debugging

【判据】清单里每一项都能说出"哪个功能需要它"，且无 Debugging。

【审】`audit/godot/platform-export.md#10`

### Step 4　Bundle identifier 必须有效且唯一，大小写不敏感　`[platform-export/04#S4]`

【读】`howto/godot/platform-export.md#3. macOS`

【做】
定下一个有效且唯一的 Bundle identifier，并全平台统一。
⛔ 官方要求是 **valid and unique**（有效且唯一），
⛔ 随手填一个示例值会让系统层面的识别冲突，而失败发生在签名与安装阶段。

⛔ 更隐蔽的是**大小写不敏感**（依 `CFBundleIdentifier`）：
靠大小写区分国内版 / 海外版等于**同一个应用**，
⛔ 失败时日志**完全不说明是大小写**，
排查被引向证书或 Profile。

ⓘ 该值同时是 iOS 的 App ID（见 05）与合规域的构建元数据，
⛔ 三处必须同一个字符串，不要各自维护。

【产出】Bundle identifier（唯一、大小写已确认）

【判据】该字符串在合规域、macOS 预设、iOS 预设三处逐字相同。

【审】`audit/godot/platform-export.md#33`

### Step 5　产物形态与导出主机：DMG 只能在 macOS 上打　`[platform-export/04#S5]`

【读】`howto/godot/platform-export.md#10. macOS 与 Web 的两处边界`

【做】
确认本次要不要 DMG，并在 macOS 主机上执行。
⛔ 在 Windows / Linux 上准备打 DMG —— 官方口径：
导出为 ZIP 或 DMG **仅在从 macOS 电脑导出时支持**。

⛔ 表现为该选项不可用或产物异常，
⛔ 排查被引向导出模板或预设，不会想到是导出主机的限制。
这与 iOS 那条同源：**Apple 生态的产物离不开 macOS 主机**。

ⓘ 只要不用 DMG，跨平台导出 .app 是没问题的 ——
限制只在打包成磁盘镜像这一步。

【产出】产物形态结论（.app / .zip / .dmg）+ 执行主机

【判据】要 DMG 时能说出用哪台 macOS 主机执行。

【审】`audit/godot/platform-export.md#28`

## 3. 参考实现

```bash
# ⓘ 承接本步产出：签名链四步，每步都能单独验证
# S1 签名（macOS 主机用 Xcode codesign）
codesign --force --options runtime --sign "Developer ID Application: ..." \
         --entitlements entitlements.plist MyGame.app

# S2 公证 + 钉票（⛔ 不钉票 = 离线打不开）
ditto -c -k --keepParent MyGame.app MyGame.zip
xcrun notarytool submit MyGame.zip --apple-id "$APPLE_ID" \
      --team-id "$TEAM_ID" --password "$APP_PW" --wait
xcrun stapler staple MyGame.app

# S4 校验 Bundle identifier 逐字一致
/usr/libexec/PlistBuddy -c "Print :CFBundleIdentifier" MyGame.app/Contents/Info.plist
```

## 4. 验收清单

- [ ] 干净机器首次打开不弹"已损坏"
- [ ] 断网后首次打开仍能通过（已钉票）
- [ ] Entitlements 每项有理由，生产无 Debugging
- [ ] Bundle identifier 在三处逐字相同
- [ ] 要 DMG 时在 macOS 主机上执行

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 用户报"已损坏" | 签名链断环，且提示不指明哪一环 | S1 |
| 有网能开、没网打不开 | 公证后没钉票 | S2 |
| 公证莫名失败 / 首次调用崩溃 | Entitlements 带 Debugging 或缺 usage description | S3 |
| 签名或安装阶段失败且无说明 | Bundle ID 冲突或大小写问题 | S4 |
| DMG 选项不可用 | 不在 macOS 主机上导出 | S5 |
