# 多平台导出与发布 —— 域流程总览

> ⚠ **第 0 步：先定要上哪些平台。**
> 本域有 6 个功能点 + 1 个验收，⛔ **不是全做** —— 按本次的发布目标挑。

## 0. 先定做什么

| 本次要做的 | 走哪些功能点 |
|---|---|
| 第一次把游戏导出成可执行文件 | 01 → 02 → 07 |
| 接入 CI 自动出包 | 01 → 02 → 03 → 07 |
| 上 macOS / Windows 商店或分发 | 01 → 02 → 04 → 07 |
| 上 Android / iOS | 01 → 02 → 05 → 07 |
| 上 Web（itch.io / 自建 / Pages） | 01 → 02 → 06 → 07 |
| 全套多平台发布 | 01 → 02 → 03 → 04 → 05 → 06 → 07 |

⛔ **只要发布，02 和 07 都不能跳过** ——
导出模板版本与验收这两件事在正常流程下**完全测不出来**：
开发机上是编辑器、是已装好的模板、是已登录的开发者账号，
⛔ 而发布目标上是干净机器、是商店校验、是没装过你游戏的陌生设备。
这三条恰好是"本地能跑、别人装不上"最集中的来源。

ⓘ 若本次只是**"改个图标、改个版本号"**，那是预设配置，不套本域。
ⓘ 若只是**排查导出后资源丢失**，先看 02/S3（非资源文件过滤器），
确认不是它再回本域按流程查。

ⓘ 分工：
- `howto/godot/platform-export.md` 讲**单个平台怎么配**（模板、签名、预设、各平台限制）
- 本域讲**这些配置按什么顺序做、怎么保证产物真的能被别人装上**

⛔ 若本域某步需要"某个商店的具体审核规则天数"这类细节，
指向 `compliance` 域确认，⛔ 不在这里编数字。

## 1. 功能点拆解（按依赖，不可颠倒）

| # | 功能点 | 依赖 | 交付物 |
|---|---|---|---|
| 01 | 发布目标与平台矩阵定性 | — | 平台清单 + 各维度限制表 + 构建环境可得性 |
| 02 | 导出模板与预设基线 | 01 | 模板版本锁定 + 预设名 + 资源过滤器 + 工具链版本 |
| 03 | 命令行与 CI 导出 | 02 | 可复现的导出命令 + release/debug 分离 |
| 04 | 桌面端签名与公证 | 02 | macOS 签名公证钉票链 + Entitlements + Bundle ID |
| 05 | 移动端构建与签名 | 02 | Android 工具链/keystore/权限 + iOS 三件套与 Xcode 工程 |
| 06 | Web 导出与托管 | 02 | 渲染器覆盖 + 线程与隔离头 + 持久化降级 |
| 07 | 发布验收 | 全部 | 干净机器实测 + 商店要求核对 |

⚠ **01 必须在一切之前**：平台清单决定渲染器、线程、存档、签名四件事，
⛔ 中途加一个平台不是"多勾一个预设"——
Web 要 Compatibility、iOS 要 macOS 主机、Android 要精确到 r28b 的 NDK，
这三条都是**立项时不做就来不及**的。

⚠ **02 必须在 03 之前**：CI 导出命令里的预设名是硬匹配，
预设名一次定下、进版本库后再改，会让所有 CI 脚本同时失效。

⚠ **05 不能留到最后**：iOS 的构建环境可得性（有没有 macOS 主机 / CI）
在 01 就要确认，⛔ 到了发布前才发现"没有 Mac"，
整条 iOS 路径的工期是**从零开始**，不是"补一步"。

## 2. 与其他域的接缝

> ⚠ **组合的真正难点不是排序，是接缝。**
> 下面每条都必须能指认到具体符号或字段，⛔ 不能是"做完了"。

| 接缝 | 契约 |
|---|---|
| `compliance` 域 合规 | 商店提交与构建元数据（Bundle ID、隐私清单）见 `compliance/06`；⛔ 本域不重复定法务口径 |
| `mobile` 域 移动端 | 安全区与后台预算见 `mobile/05`、`mobile/06`；⛔ 导出侧的架构/签名由本域定 |
| `security` 域 安全 | 存档加密与完整性见 `security/03`；⛔ 导出预设里的加密开关不替代它 |
| `hotupdate` 域 热更新 | PCK 产物边界与补丁形态见 `hotupdate/01`；⛔ 本域只出完整包 |
| `perf` 域 性能分析 | 发布前专项（首帧 / 内存 / 热节流）见 `perf/06`；⛔ 不在验收里现编指标 |
| `i18n` 域 本地化 | 断行数据是否进导出包见 `i18n/06`；⛔ 中日文导出后不换行查那里 |
| `cicd-publish` | ⓘ howto 层，暂无 flow 域 —— CI 与自动化发布见该篇 |
