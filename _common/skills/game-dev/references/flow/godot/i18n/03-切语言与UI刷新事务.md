# 03 切语言与 UI 刷新事务（i18n 域）

> **前置**：02（翻译资源已就位且顺序正确）
> **本步交付**：**切语言 + 刷新 + 持久化 三件事成为一个事务**
> **对应**：做法 `howto/godot/i18n.md#2. 切换语言`
> 　　　审核 `audit/godot/i18n.md`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：设置里切了语言，但界面没全变。**

⛔ `set_locale()` 会立刻让后续 `tr()` 结果变化，
但**已经赋值到 Label 上的文本不会自动更新**——
表现是"主界面变了、某个弹窗还是旧语言"，而不报错。

做完这一步，应该能**当场演示**：

1. ⛔ 切换后**所有**已存在的 UI 文本都刷新，无一遗漏
2. ⚠ 刷新机制三选一已定死并在代码里统一
3. ⛔ 语言选择写入存档，且**启动时真的应用**
4. ⛔ 没有在 `_process` 里调 `tr()`
5. ⚠ 切语言是事务：失败时三者状态一致

**产出物**：

```text
语言切换封装（切+刷新+存盘）
刷新机制选型（重载 / _ready / 集中 refresh）
启动应用流程
```

【产出】刷新触发点清单

【判据】⛔ 切语言后，**已打开**的界面文字也全部变化

【审】`audit/godot/i18n.md#4`

### Step 2　⚠ 刷新机制三选一并统一　`[03#S2]`

【读】`howto/godot/i18n.md#2. 切换语言`

【做】在「重载场景 / 所有 UI 在 `_ready` 里 `tr()` / 集中 `refresh_texts()`」里选一种，全项目统一。

【产出】刷新机制约定（写进规范）

【判据】⚠ 新增一个 UI 时，按约定写就**必然**会被刷新

【审】`audit/godot/i18n.md#4`

### Step 3　⛔ 语言选择要存盘且启动时应用　`[03#S3]`

【读】`howto/godot/i18n.md#2. 切换语言`

【做】切换时同时写存档；启动时读档后**先** `set_locale()` **再**进主界面。

【产出】启动应用流程

【判据】⛔ 重开游戏后，语言与上次一致；且首屏就是该语言

【审】`audit/godot/i18n.md#25`

### Step 4　⛔ 不在 _process 里调 tr　`[03#S4]`

【读】`howto/godot/i18n.md#2. 切换语言`

【做】只在需要显示时赋值；⛔ 禁止每帧查表。

【产出】代码规范条目（禁止 `_process` 内 `tr()`）

【判据】⛔ 全项目搜索 `_process` 内无 `tr(` 调用

【审】`audit/godot/i18n.md#5`

### Step 5　⚠ 切语言是事务，失败要一致　`[03#S5]`

【读】`howto/godot/i18n.md#2. 切换语言`

【做】把「set_locale → 刷新 → 写存档」当作一个事务：任一环失败，不留下"设置里是 A、界面是 B、存档是 C"的中间态。

【产出】事务封装与失败处理

【判据】⛔ 模拟写档失败后，界面与设置**一致**（回滚或明确报错）

【审】`audit/godot/i18n.md#25`

## 5. 常见返工

**① 以为切了就自动变。** 已赋值的 Label 不更新。

**② 三种刷新机制混用。** 有的界面刷新有的不刷新。

**③ 存了但启动没应用。** 设置界面显示对、实际语言不对。

**④ 写档失败留下中间态。** 设置/界面/存档三者不一致。
