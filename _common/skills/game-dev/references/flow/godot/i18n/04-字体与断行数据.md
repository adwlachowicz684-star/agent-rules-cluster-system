# 04 字体与断行数据（i18n 域）

> **前置**：01（key 规范已立）
> **本步交付**：**字体回退链 + 导出含断行数据 + 按 locale 分包**
> **对应**：做法 `howto/godot/i18n.md#9. ⛔ 断行数据默认不进导出包`
> 　　　审核 `audit/godot/i18n.md`

## 0. 交付物定义

⚠ **本步的坑几乎全在"编辑器正常、导出后错"。**

⛔ 最典型的一条：中文、日文等**无空格语言**的断行依赖 ICU break iterator 数据，
而该数据**默认不包含在导出项目中**——
表现为编辑器里换行正常，**导出后不换行或断错位置**，
排查方向极易被引到"容器尺寸算错了"。

做完这一步，应该能**当场演示**：

1. ⛔ 字体回退链设在 **Theme 默认字体**上（不是单个 Label）
2. ⛔ 导出设置已勾 **Include Text Server Data**
3. ⚠ CJK 字体按 locale 分包，没全塞进首包
4. ⛔ 用**导出包**（不是编辑器）验过断行

**产出物**：

```text
字体回退链配置
导出设置清单（含断行数据）
字体分包方案
```

- [ ] 已确认是否有无空格语言（中日）

## 2. 工序

### Step 1　⛔ 回退链要设在 Theme 默认字体上　`[04#S1]`

【读】`howto/godot/i18n.md#4. 字体与缺字`

【做】把 CJK 等补充字体挂到 **Theme 的 default_font 的 fallbacks** 上，全局生效。

【产出】字体回退配置

【判据】⛔ 英文设备上，中文**不显示豆腐块**；且**新增 UI 自动生效**

【审】`audit/godot/i18n.md#3`

### Step 2　⛔ 导出要勾 Include Text Server Data　`[04#S2]`

【读】`howto/godot/i18n.md#9. ⛔ 断行数据默认不进导出包`

【做】项目设置 → Internationalization → Locale 勾选 Include Text Server Data（约 4 MB）。

【产出】导出设置清单

【判据】⛔ **导出包**里中日文能正常断行

【审】`audit/godot/i18n.md#11`

### Step 3　⚠ CJK 字体按 locale 分包，不全塞首包　`[04#S3]`

【读】`howto/godot/i18n.md#4. 字体与缺字`

【做】完整 CJK 字体 10MB+，按目标语言动态加载或走分包。

【产出】字体分包方案

【判据】⚠ 首包体积可控，且切到中文时字体**能加载出来**

【审】`audit/godot/i18n.md#21`

### Step 4　⛔ 断行必须在导出包里验　`[04#S4]`

【读】`howto/godot/i18n.md#9. ⛔ 断行数据默认不进导出包`

【做】验收一律以**导出产物**为准，⛔ 不接受"编辑器里看着没问题"。

【产出】导出包断行实测记录

【判据】⛔ 导出包中所有目标语言的换行位置与编辑器一致

【审】`audit/godot/i18n.md#20`

## 5. 常见返工

**① 回退字体挂在单个 Label 上。** 新增 UI 又变豆腐块。

**② 没勾断行数据。** 编辑器正常、导出后错，极难归因。

**③ 字体全塞首包。** 包体爆炸。

**④ 只在编辑器里验。** 导出包问题测不出来。
