# 06 资源本地化与长文本适配（i18n 域）

> **前置**：02（翻译资源已就位）
> **本步交付**：**资源按 locale 重映射 + 文本膨胀后不溢出**
> **对应**：做法 `howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`
> 　　　审核 `audit/godot/i18n.md`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：英文版排版很漂亮。**

⛔ 德语通常比英语长 30%+，
⛔ 而"按钮固定宽度"会让长语言直接**截断**——
这类问题在英文版**完全看不出来**，只在做第二语言时才暴露。

做完这一步，应该能**当场演示**：

1. ⚠ 图片 / 音频按 locale 重映射已配置
2. ⛔ 没有给按钮设固定宽度，容器按内容撑开
3. ⛔ 用伪本地化的**膨胀**模式跑过一遍，无溢出
4. ⛔ 改伪本地化配置后**有**传播 `NOTIFICATION_TRANSLATION_CHANGED`
5. ⚠ `expansion_ratio` 取 0.3（官方称对大多数情况足够）
6. ⚠ 语音 / 音频按 locale 分包

**产出物**：

```text
资源 remap 配置
长文本适配规则（禁用固定宽度）
伪本地化膨胀测试记录
```

- [ ] 已确认最长语言与目标语言列表

## 2. 工序

### Step 1　⚠ 资源按 locale 重映射　`[06#S1]`

【读】`howto/godot/i18n.md#12. 资源按 locale 重映射`

【做】在项目设置 → Localization → Remaps 里按 locale 替换图片 / 音频。

【产出】资源 remap 配置

【判据】⚠ 切语言后，含文字的图片**显示对应语言版本**

【审】`audit/godot/i18n.md#26`

### Step 2　⛔ 不给按钮固定宽度　`[06#S2]`

【读】`howto/godot/i18n.md#5. 文本溢出`

【做】用 `custom_minimum_size` 限最小，让容器按内容撑开；长文本开自动换行。

【产出】长文本适配规则

【判据】⛔ 切到最长语言时，文字**不截断**、按钮自动变宽

【审】`audit/godot/i18n.md#2`

### Step 3　⛔ 用伪本地化膨胀模式测溢出　`[06#S3]`

【读】`howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`

【做】开 `double_vowels` 或 `expansion_ratio`，跑一遍主要界面。

【产出】膨胀测试记录（含截图）

【判据】⛔ 膨胀后**无一处**溢出或截断

【审】`audit/godot/i18n.md#19`

### Step 4　⛔ 改伪本地化配置要传播通知　`[06#S4]`

【读】`howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`

【做】改配置后调 `reload_pseudolocalization()`，并**手动传播** `NOTIFICATION_TRANSLATION_CHANGED`。

【产出】伪本地化开关封装

【判据】⛔ 开关一开，界面**立刻**变化（不是"看起来没生效"）

【审】`audit/godot/i18n.md#10`

### Step 5　⚠ expansion_ratio 取 0.3　`[06#S5]`

【读】`howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`

【做】按官方建议取 0.3（增加 30% 长度），覆盖大多数语言膨胀。

【产出】膨胀参数配置

【判据】⚠ 用最长真实语言复核时，与 0.3 膨胀结果**量级一致**

【审】`audit/godot/i18n.md#19`

### Step 6　⚠ 语音与音频按 locale 分包　`[06#S6]`

【读】`howto/godot/i18n.md#12. 资源按 locale 重映射`

【做】语音、配音按语言分包下载；⛔ 不随首包全量携带。

【产出】音频分包方案

【判据】⚠ 切语言后语音是**对应语言**，且首包不含全部语音

【审】`audit/godot/i18n.md#27`

## 5. 常见返工

**① 按钮固定宽度。** 长语言直接截断。

**② 没跑膨胀测试。** 上线才发现溢出。

**③ 改配置没传播通知。** 界面不变，以为开关坏了。

**④ 语音全塞首包。** 包体不可控。
