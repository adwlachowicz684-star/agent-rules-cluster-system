# 07 本地化验收（i18n 域）

> **前置**：01–06 全部完成
> **本步交付**：**一份逐条实测的验收报告，含导出包与敌意环境用例**
> **对应**：做法 `howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`
> 　　　审核 `audit/godot/i18n.md`

## 0. 交付物定义

⚠ **本域的 bug 在正常环境下大多测不出来。**

⛔ 漏译、缺字、溢出、断行、RTL 反向——
这些只在**切换语言、开伪本地化、跑导出包**时才出现。
只测默认语言的英文版，结论永远是"没问题"。

做完这一步，应该能**当场演示**：

1. ⛔ 伪本地化四种模式各跑过一遍
2. ⛔ `override` 模式下**没有**没被本地化的文本
3. ⛔ `replace_with_accents` 下**没有**豆腐块
4. ⛔ **导出包**里断行与字体正常
5. ⛔ 提交前 Test 属性已清空
6. ⚠ 各语言主要界面逐屏比对过
7. ⚠ 切语言后存档显示与界面一致

## 2. 工序

### Step 1　⛔ 伪本地化四种模式各跑一遍　`[07#S1]`

【读】`howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`

【做】依次开 `override`、`replace_with_accents`、`double_vowels`（或 `expansion_ratio`）、`fake_bidi`，逐个模式过主要界面。

【产出】四模式测试记录

【判据】⛔ 四种模式**都**实际产生了可见变化（否则说明开关没生效）

【审】`audit/godot/i18n.md#19`

### Step 2　⛔ override 模式找漏翻　`[07#S2]`

【读】`howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`

【做】开 `override` 让所有文本变成 `*`，找出**仍是原文**的位置（即没走 `tr()`）。

【产出】漏翻清单

【判据】⛔ 全界面**无一处**显示原语言明文

【审】`audit/godot/i18n.md#7`

### Step 3　⛔ replace_with_accents 找缺字　`[07#S3]`

【读】`howto/godot/i18n.md#8. 伪本地化（引擎内置，不必自己造）`

【做】开 `replace_with_accents`，检查是否有字符显示成豆腐块（字体缺 glyph）。

【产出】缺字清单

【判据】⛔ 所有界面**无豆腐块**（全部显示为带变音符的字符）

【审】`audit/godot/i18n.md#3`

### Step 4　⛔ 断行与字体在导出包里验　`[07#S4]`

【读】`howto/godot/i18n.md#9. ⛔ 断行数据默认不进导出包`

【做】用真实导出包跑一遍，⛔ 不接受"编辑器里看着没问题"。

【产出】导出包实测记录

【判据】⛔ 导出包内中日文断行正确、字体完整

【审】`audit/godot/i18n.md#11`

### Step 5　⛔ 提交前清空 Test 属性　`[07#S5]`

【读】`howto/godot/i18n.md#13. ⛔ 测试用的 Test 属性会进版本控制`

【做】确认 `internationalization/locale/test` 为空再提交；日常改用 `godot --language xx` 或编辑器预览。

【产出】提交前检查项

【判据】⛔ 其他人拉下来跑，**不会**莫名其妙是测试语言

【审】`audit/godot/i18n.md#14`

### Step 6　⚠ 各语言逐屏比对　`[07#S6]`

【读】`howto/godot/i18n.md#5. 文本溢出`

【做】每个目标语言过一遍主要界面，重点看长语言溢出与 RTL 方向。

【产出】逐语言界面比对记录

【判据】⚠ 每个语言都**无**截断、无方向错误

【审】`audit/godot/i18n.md#2`

### Step 7　⚠ 切语言后存档与界面一致　`[07#S7]`

【读】`howto/godot/i18n.md#2. 切换语言`

【做】在已有存档的情况下切语言，检查存档里引用的文本随之变化、且重开后保持。

【产出】存档一致性测试记录

【判据】⛔ 切语言后旧存档文本跟着变；重开后语言与界面**一致**

【审】`audit/godot/i18n.md#1`

- [ ] ⛔ 导出包断行与字体正常
- [ ] ⛔ Test 属性已清空
- [ ] ⚠ 各语言逐屏比对
- [ ] ⚠ 切语言后存档与界面一致

## 4. 常见返工

**① 只测默认语言。** 漏译与溢出全测不到。

**② 只在编辑器里测。** 导出包缺断行数据测不出来。

**③ 伪本地化开了但没生效。** 没传播通知，界面纹丝不动。

**④ Test 属性忘清。** 全团队跑测试语言。
