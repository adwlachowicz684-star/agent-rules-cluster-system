# 04 内存值保护与合理性自检（安全域）

> **本步交付**：受保护数值清单 + 掩码轮换 + 范围自检
> **对应**：流程 `howto/godot/security.md` · 审核 `audit/godot/security.md`

## 0. 交付物定义

1. 受保护数值清单已限定在有经济意义的字段
2. 内存里不存明文
3. 每次写入轮换掩码
4. 合理性自检已接入
5. ⛔ 已认清它挡不住什么

## 1. 前置检查清单

- [ ] 已知这只挡"搜固定值"的基础用法
- [ ] 受保护字段已列清单（不是全部数值）
- [ ] 自检频率已定（不是每帧）
- [ ] ⛔ 已确认被保护字段不属需明示采集的数据（见 `compliance` 域）

## 2. 工序

### Step 1　只保护有经济意义的数值，别全保护　`[security/04#S1]`

【读】`howto/godot/security.md#3. 内存值保护`

【做】
Cheat Engine 的基础用法是"搜 100 → 受伤 → 搜 80 → 定位地址 → 改成 9999"。
只保护**有经济意义的**：金币、钻石、体力。
⛔ 把所有数值都保护起来——开销和复杂度都会涨，
⛔ 而且会让"哪些值真的重要"这件事再也说不清。
⚠ 与 `compliance` 域的接缝：风控信号常属个人信息，采集要进数据地图。

【产出】受保护数值清单

【判据】清单里每项都能说出经济意义；非经济数值不在其中

【审】`audit/godot/security.md#27`


### Step 2　内存里不存明文，且每次写入换掩码　`[security/04#S2]`

【读】`howto/godot/security.md#3. 内存值保护`

【做】
存 `value ^ mask`，读取时再异或回来。
`set_value` 时轮换掩码，避免掩码固定后被一次性解出。
⛔ 只异或一个固定掩码——搜不到"当前值"，但可以搜"两次都变化了的量"（变化锁定），
⛔ 或者干脆找到那个常量掩码。

【产出】`ProtectedInt` 实现（掩码轮换）

【判据】每次写入后内存中的存储字节都不同

【审】`audit/godot/security.md#28`


### Step 3　合理性自检：超出范围说明被改了　`[security/04#S3]`

【读】`howto/godot/security.md#合理性自检：超出范围说明被改了`

【做】
定期 `is_plausible(min, max)` 检查。
⛔ 没有范围自检——被改成天文数字后，
只有等到"排行榜出现一个亿"才发现，而那时数值已扩散到存档与经济系统。

【产出】自检实现（含上下限）

【判据】人为写入越界值后自检返回 false

【审】`audit/godot/security.md#29`


### Step 4　⛔ 别每帧自检，隔几秒一次即可　`[security/04#S4]`

【读】`howto/godot/security.md#3. 内存值保护`

【做】
自检放在定时（几秒一次）或提交前，不要放 `_process`。
⛔ 每帧自检——开销随受保护字段数线性增长，
⛔ 而收益不变（改内存的人不会只在某一帧改）。

【产出】自检调度（定时/提交前）

【判据】`_process` 中不存在自检调用

【审】`audit/godot/security.md#30`


### Step 5　⛔ 它防不住变化锁定，别当防线　`[security/04#S5]`

【读】`howto/godot/security.md#3. 内存值保护`

【做】
防不住"重复搜索 + 变化锁定"，也防不住找到掩码的人。
它挡的是最基础的"搜固定值"用法，这就够挡掉大部分随手作弊。
⛔ 把内存保护当成"已防作弊"的证据——
真正的防线仍是 02 的服务端校验。

【产出】能力边界说明（写进设计文档）

【判据】文档中内存保护未列入"防住了什么"的防线层

【审】`audit/godot/security.md#31`


## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：只保护有经济意义的数值，掩码每次写入轮换
const PLAUSIBLE_MIN := 0
const PLAUSIBLE_MAX := 9999999      # ⛔ 按实际经济体量定，别照抄

class ProtectedInt:
    var _mask: int
    var _stored: int

    func _init(value: int = 0) -> void:
        _mask = (randi() | 0x100000)   # 仅掩码本身可用 randi；IV/密钥不行，见 03/S6
        _stored = value ^ _mask

    func get_value() -> int:
        return _stored ^ _mask

    func set_value(v: int) -> void:
        _mask = _rotate(_mask, 13) ^ 0x9E3779B9
        _stored = v ^ _mask

    func is_plausible() -> bool:
        var v := get_value()
        return v >= PLAUSIBLE_MIN and v <= PLAUSIBLE_MAX

    func _rotate(x: int, n: int) -> int:
        return (x << n) | (x >>> (32 - n))
```

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 复杂度失控 | 全字段保护 | S1 |

| 帧率下降 | 每帧自检 | S4 |
| 以为防住作弊 | 定位误判 | S5 |
