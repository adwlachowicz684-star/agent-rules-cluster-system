# 安全（存档加密 / 防作弊 / 服务端权威）—— 域流程总览

> ⚠ **第 0 步：先定防什么。**
> 本域有 7 个功能点，⛔ **不是全做** —— 按本次是单机还是联网挑。
> ⛔ 顺序错了比不做更糟：预算会先花在结构性无效的地方。

## 0. 先定做什么

| 本次要做的 | 走哪些功能点 |
|---|---|
| 单机，只想挡住记事本改存档 | 01 → 03 → 07 |
| 单机，还想挡住 Cheat Engine 基础用法 | 01 → 03 → 04 → 07 |
| 单机，有每日奖励/体力恢复 | 01 → 03 → 04 → 05 → 07 |
| 联网（有排行榜、交易、匹配） | 01 → 02 → 06 → 07（⛔ 02 是主力） |
| 联网且要防刷、防重放 | 01 → 02 → 05 → 06 → 07 |
| 全套 | 01 → 02 → 03 → 04 → 05 → 06 → 07 |

⛔ **01 无论如何不能跳过** ——
它是唯一决定"后面 6 个功能点该投多少预算"的一步。
⛔ 跳过 01 直接做 03（存档加密），是最常见的错：
存档加密直观、能立刻看到存档变乱码，
⚠ 而联网游戏里它是**结构性无效**的（密钥必在客户端）。

ⓘ 分工：
- `howto/godot/security.md` 讲**单个机制怎么实现**（加密、签名、内存保护、时间、反应）
- 本域讲**这些机制按什么顺序做、哪些是结构性无效、怎么验收**

## 1. 功能点拆解（按依赖，不可颠倒）

| # | 功能点 | 依赖 | 交付物 |
|---|---|---|---|
| 01 | 威胁边界与防什么定性 | — | 能防/防不住清单 + ROI 排序 + 反应策略先定 |
| 02 | 服务端权威与输入校验 | 01 | 权威动作清单 + 逐项校验链 + 业务幂等键 |
| 03 | 存档加密与完整性 | 01 | 32 字节 key + 随机 IV + HMAC + 先验签后解密 |
| 04 | 内存值保护与合理性自检 | 01 | 受保护数值清单 + 掩码轮换 + 范围自检 |
| 05 | 时间与速度作弊 | 01, 02 | 单调时钟 + 服务端每日奖励 + 倍速只标记 |
| 06 | 请求签名、重放与检测反应 | 01, 02 | 规范化串 + nonce + 常量时间比较 + 静默反应 |
| 07 | 安全验收 | 全部 | 敌意环境实测（改存档/改时钟/重放/改包） |

⚠ **02 必须在 03 之前**（联网场景）：
服务端权威同时解决加速、瞬移、伤害、资源、冷却、交易，
⚠ 而存档加密一项都解决不了。
⛔ 先做 03 会把"防作弊"预算一次性花光，且拿到的是**心理安全感**。

## 2. 与其他域的接缝

> ⚠ **组合的真正难点不是排序，是接缝。**
> 下面每条都必须能指认到具体符号或字段，⛔ 不能是"做完了"。

| 接缝 | 契约 |
|---|---|
| `save` 域 存档 | 加密与签名在存档写入事务内，⛔ 字段增删会改签名范围（见 03/S4） |
| `netsync` 域 网络同步 | 服务端权威与预测回滚同源；⛔ 权威时间戳不接受客户端（见 02/S2） |
| `economy` 域 经济 | 货币变动是 02 的必校验项，⛔ 客户端说"我扣了"不算 |
| `monetization` 域 商业化 | 订单幂等键与 02 的业务幂等键是同一套（见 02/S3） |
| `trade` 域 交易 | 双卖与重放靠服务端结算令牌，⛔ 不是靠客户端签名 |
| `social` 域 社交 | 刷屏与多开是信号，⛔ 处置在服务端（见 06/S6） |
| `compliance` 域 合规 | 内存保护与数据采集边界不冲突，但⛔ 风控信号属个人信息（见 04/S1） |

⛔ **若某条接缝对不上，要单独立一个接线功能点**，
⛔ 不许在各处偷偷转格式。

## 3. 本域最容易做反的顺序

⛔ **先做客户端加密与反修改，把服务端校验排到最后（03 提前、02 靠后）。**

"存档变乱码了"是最直观的验收点，
于是先加密、先上内存保护、先做调试器检测，
⚠ 而此时高价值动作还没有服务端校验。

⛔ 后果链：
客户端加密上线 → 开挂门槛从 5 分钟提到 30 分钟 → 看起来"有防作弊了" →
服务端校验被无限期推迟 →
⚠ 而排行榜、货币、胜负判定仍完全信任客户端 →
一个自制客户端就能批量刷，⛔ 且此时所有客户端防护**一个都不会报警**
（因为它们防的是"改内存"，不是"发假包"）。

✅ 正确顺序：先定边界（01），联网场景立刻做服务端权威（02），
然后才是存档（03）、内存（04）、时间（05）、签名与反应（06）。
