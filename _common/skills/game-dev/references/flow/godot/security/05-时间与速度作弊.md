# 05 时间与速度作弊（安全域）

> **本步交付**：单调时钟 + 服务端每日奖励 + 倍速只标记
> **对应**：流程 `howto/godot/security.md` · 审核 `audit/godot/security.md`

## 0. 交付物定义

1. 所有计时判定基于单调时钟
2. 每日奖励/体力恢复由服务端下发时间
3. ⛔ 计时字段已进签名范围
4. 倍速检测只标记不处理
5. 已确认改系统时钟无法绕过

## 1. 前置检查清单

- [ ] 已知 `Time` 的 `_from_system` 系列用可被用户设置的时钟
- [ ] 已知 `get_ticks_msec()` 只保证单次引擎运行期间单调
- [ ] 每日奖励字段已列入签名范围
- [ ] ⛔ 倍速阈值已知会误伤高刷屏

## 2. 工序

### Step 1　⛔ 系统时钟可被玩家设置，一律改用单调 ticks　`[security/05#S1]`

【读】`howto/godot/security.md#4. 时间作弊`

【做】
反例 `Time.get_unix_time_from_system()`，正例 `Time.get_ticks_msec()`。
⛔ 用系统时间做体力恢复/离线收益——玩家改表即绕过，
⚠ 与 `vip`/`monetization`/`weather` 域是同一条禁令（那几处已确立）。
⛔ 尤其危险的是"只在客户端算"：改表后数值完全正常，
不报错、不崩溃，只是收益凭空多出来。

【产出】计时实现（全部走 ticks）

【判据】改系统时钟后体力恢复速度不变

【审】`audit/godot/security.md#32`


### Step 2　跨会话的每日奖励只能靠服务端时间　`[security/05#S2]`

【读】`howto/godot/security.md#4. 时间作弊`

【做】
`get_ticks_msec()` 只保证**单次引擎运行期间**单调；跨会话它从 0 重新开始。
所以"每日奖励"必须靠服务端下发的服务器时间。
⛔ 用累计游玩时长判定"24 小时到了"——玩家挂机也算，
⛔ 而真正的"每日"是墙钟概念，客户端无权威墙钟。

【产出】每日奖励判定（服务端时间）

【判据】改客户端时钟后，服务端判定的可领取状态不变

【审】`audit/godot/security.md#33`


### Step 3　⛔ 计时字段必须进签名范围　`[security/05#S3]`

【读】`howto/godot/security.md#4. 时间作弊`

【做】
即使改用 monotonic，玩家改不了时钟，但可以改**存档里的 `_last_claim_mono`**。
所以这个字段必须进 HMAC 的签名范围。
⛔ 计时字段不进签名——改存档即可瞬间刷新每日奖励，
⛔ 而验签通过（因为改的字段不在签名范围内）。

【产出】签名范围清单（含所有计时字段）

【判据】改计时字段后验签失败

【审】`audit/godot/security.md#34`


### Step 4　倍速检测用单调时钟，判定 real_delta　`[security/05#S4]`

【读】`howto/godot/security.md#倍速作弊`

【做】
记录上一帧的 `Time.get_ticks_msec()`，算 `real_delta`，异常小即可疑。
⛔ 用 `delta`（引擎给的）——加速工具会同时影响它，测不出来。
⚠ 这是唯一需要"客户端侧计时"的检测：它测的是**本机**实际经过的时间。

【产出】倍速检测实现

【判据】开加速工具后 suspicious 计数上升

【审】`audit/godot/security.md#35`


### Step 5　⛔ 别用倍速直接踢人：240Hz 会误伤　`[security/05#S5]`

【读】`howto/godot/security.md#倍速作弊`

【做】
高刷屏（240Hz）的 real_delta 也可能小于阈值。
所以只作为"可疑"标记，累计很多次才处理，或者只上报不处理。
⛔ 直接踢玩家——会封掉一批高刷屏用户，
⛔ 而这类投诉往往以"我什么都没做"出现，排查成本极高。

【产出】倍速处置策略（只标记/上报）

【判据】倍速检测路径中不存在踢人或断线

【审】`audit/godot/security.md#36`


## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：判定用 ticks，处置只标记
const SPEED_MIN_DELTA_MS := 4      # ⛔ 240Hz 约 4.17ms/帧，阈值过低必误伤
const SUSPICIOUS_LIMIT := 60

var _last_tick := 0
var _suspicious_count := 0

func _process(_delta: float) -> void:
    var now := Time.get_ticks_msec()      # ⛔ 不是 get_unix_time_from_system()
    if _last_tick > 0:
        if now - _last_tick < SPEED_MIN_DELTA_MS:
            _suspicious_count += 1
            if _suspicious_count > SUSPICIOUS_LIMIT:
                _report_only("speed")     # ⛔ 只上报，不踢
    _last_tick = now
```
