# 02 服务端权威与输入校验（安全域）

> **本步交付**：权威动作清单落地 + 逐项校验链 + 业务幂等键
> **对应**：流程 `howto/godot/security.md` · 审核 `audit/godot/security.md`

## 0. 交付物定义

1. 每个高价值动作都有完整校验链
2. 服务端维护权威时间戳
3. 业务幂等键已落地
4. ⛔ HMAC 未被视为服务端校验的替代品
5. 客户端只发"我做了什么"

## 1. 前置检查清单

- [ ] 01 的权威动作清单已存在
- [ ] 校验链顺序已定（身份→归属→可达→CD→资源→频率→状态机→幂等）
- [ ] 幂等键来源已确定（不是客户端 nonce 顶替）
- [ ] ⛔ 未用客户端时间戳作为事实

## 2. 工序

### Step 1　高价值动作逐项校验，链条顺序不能省　`[security/02#S1]`

【读】`howto/godot/security.md#服务端有效性来自可证伪规则`

【做】
每个高价值动作按顺序校验：身份与 session 有效 → 角色/物品归属 →
位置可达、速度不超上限 → CD 未结束 → 资源足够 → 频率未超滑动窗口 →
数值变化符合状态机 → **重复请求用业务幂等键**。
⛔ 只校验其中几项——漏掉"归属"就出现"替别人操作"，
漏掉"状态机"就出现"负数金币"，⛔ 而这几种都只在被刷时才暴露。

【产出】校验链实现（每个权威动作一份）

【判据】故意构造越权/超速/负数请求，服务端全部拒绝

【审】`audit/godot/security.md#16`


### Step 2　⛔ 服务端维护权威时间戳，不接受客户端动作发生时间　`[security/02#S2]`

【读】`howto/godot/security.md#客户端检测只是信号`

【做】
服务端维护最近 N 秒的权威时间戳；客户端时间戳**只用于表现层插值**。
⛔ 接受客户端"动作发生时间"作为事实——改包就能让冷却瞬间结束，
⛔ 且服务端日志看起来完全正常（时间就是客户端报的那个）。

【产出】权威时间戳实现

【判据】改包伪造时间戳后，服务端仍按自己的时间判定

【审】`audit/godot/security.md#17`


### Step 3　业务幂等键：与客户端 nonce 不是同一个东西　`[security/02#S3]`

【读】`howto/godot/security.md#6. 联网游戏：唯一可靠的方案`

【做】
重复请求必须用**业务幂等键**（如 order_id / action_uuid）去重。
⛔ 用客户端 nonce 顶替业务幂等键——nonce 只防重放，
防不住"同一笔业务被合法地发两次"（玩家点两下、客户端重试）。
⚠ 与 `monetization` 域的订单幂等键、trade 域的结算令牌是同一套。

【产出】幂等键实现（按业务实体，不按请求）

【判据】同一业务实体重复提交两次，只生效一次

【审】`audit/godot/security.md#18`


### Step 4　⛔ HMAC 不能替代服务端校验　`[security/02#S4]`

【读】`howto/godot/security.md#请求签名：防篡改与重放，不能证明诚实`

【做】
HMAC 只证明"是同一个客户端发的"，证明不了"客户端没被篡改"。
⛔ 上了 HMAC 就省掉服务端数值校验——攻击者自制客户端自己签，
⛔ 签名完全合法，而数值是假的。
⚠ 正确定位：HMAC 提高构造成本、帮助定位重放与异常设备，不是防线。

【产出】签名与校验的职责边界说明

【判据】不存在"因为有签名所以跳过某项服务端校验"的代码路径

【审】`audit/godot/security.md#19`


### Step 5　客户端只发"我做了什么"，不发"结果是什么"　`[security/02#S5]`

【读】`howto/godot/security.md#反外挂分层：客户端是传感器，服务端是唯一裁判`

【做】
协议设计成：客户端只发输入与请求，服务端校验→计算→下发，客户端只负责显示。
⛔ 客户端上报"我扣了 100 加了装备"——凭什么信。
⛔ 一旦协议里出现结果字段，后面所有校验都会围绕"这个结果合不合理"展开，
⛔ 而正确的问法是"这个输入能不能产生这个结果"。

【产出】协议定义（输入/结果字段分离）

【判据】协议中不存在由客户端填报的结果字段

【审】`audit/godot/security.md#20`


## 3. 参考实现

```gdscript
# ⓘ 承接 01 的权威动作清单：校验链按固定顺序，缺一项就拒绝
const ERR_OK := 0
const ERR_NOT_OWNED := 1
const ERR_ON_COOLDOWN := 2

func validate_action(actor_id: int, action: Dictionary) -> int:
    if not _session_valid(actor_id):
        return ERR_NOT_OWNED
    if not _owns(actor_id, action.get("entity_id", -1)):
        return ERR_NOT_OWNED
    # ⛔ 服务端自己的时间戳，不是 action 里带的时间
    if _server_now_ms() < _cooldown_until(actor_id, action.get("kind", "")):
        return ERR_ON_COOLDOWN
    return ERR_OK
```

## 4. 验收清单

- [ ] 每个权威动作都有完整校验链
- [ ] 服务端时间戳独立，改包无法绕过冷却
- [ ] 同业务重复提交只生效一次
- [ ] ⛔ 无"有签名即跳过校验"的路径
- [ ] 协议中无客户端填报的结果字段

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 替别人操作成功 | 校验链漏归属 | S1 |
| 改包即冷却失效 | 信客户端时间戳 | S2 |
| 同一笔业务生效两次 | nonce 顶替幂等键 | S3 |
| 自制客户端刷数值 | HMAC 当防线 | S4 |
| 客户端说扣了多少就是多少 | 协议含结果字段 | S5 |
