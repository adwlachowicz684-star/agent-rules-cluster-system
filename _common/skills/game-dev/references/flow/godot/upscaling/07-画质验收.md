# 07 画质验收（画质域）

> **本步交付**：逐项开关对比 + 逐档验证 + 截图判据
> **对应**：流程 `howto/godot/upscaling.md` · 审核 `audit/godot/upscaling.md`

## 0. 交付物定义

1. 逐项开关对比按固定顺序做过，⛔ 不是靠感觉调
2. FSR Sharpness 的调整方向已验证正确
3. 在**目标渲染器 + 真机**上验过，⛔ 不是桌面预览
4. 每个档位都单独验过
5. 低端与高端走不同组合，⛔ 不是同一套参数调数字
6. 验收看的是截图，⛔ 不是设置面板
7. 最高档与最低档都测过

## 2. 工序

### Step 1　逐项开关对比，顺序不能变　`[upscaling/07#S1]`

【读】`howto/godot/upscaling.md#6. 三条管线的调试顺序（可照做）`

【做】
从上游到下游逐项开关：① 渲染分辨率 → ② 超分模式 → ③ AA → ④ 后处理。

⛔ "调画质靠感觉"是错的 —— 要**逐项开关对比**定位。
⛔ 顺序不能反：**后处理会掩盖上游的糊**，
先关后处理才能看清上游；从下游往上游调，
会把上游的缺陷误判成后处理参数问题。

ⓘ 2D 与 3D 要分开判断：`stretch/mode` 只影响 2D 画布，
`scaling_3d_*` 只影响 3D 视口。

【产出】逐项开关的变化记录

【判据】能按固定顺序逐项开关，并说出每次开关带来的变化。

【审】`audit/godot/upscaling.md#13`

### Step 2　FSR Sharpness 值越高锐化越少　`[upscaling/07#S2]`

【读】`howto/godot/upscaling.md#1. 超分：内置五种，没有 FSR3/DLSS/XeSS`

【做】
官方口径：默认 `0.2`，**值越高锐化越少**，`2.0` 等于关掉锐化。

⛔ "值越高越锐"是反向的 —— 想更锐应该往**低**调。
⛔ 表现为"想更锐一点就往上调，结果更糊了"，
而排查不会想到是方向反了，只会继续往上加。

【产出】Sharpness 的调值与对应观感记录

【判据】能说清"更锐"对应的是更小还是更大的值。

【审】`audit/godot/upscaling.md#32`

### Step 3　桌面预览不算，要目标渲染器 + 真机　`[upscaling/07#S3]`

【读】`howto/godot/upscaling.md#2. 抗锯齿：渲染器支持矩阵完全不同`

【做】
在**目标渲染器 + 真机**上验。

⛔ "桌面预览过了就算过"是错的 ——
编辑器预览的渲染路径与出包不同，
⛔ 而超分 / AA 的**支持矩阵是按渲染器走的**，
桌面默认 Forward+ 下正确的组合，在 Compatibility 或移动端可能一项都不成立。

【产出】目标渲染器 + 真机上的验收记录

【判据】每个目标渲染器都有一份独立记录。

【审】`audit/godot/upscaling.md#37`

### Step 4　改分辨率要重测，档位逐档验证　`[upscaling/07#S4]`

【读】`howto/godot/upscaling.md#12. ⚠ 缩放是逐轴的 + 降 scale 不涨帧说明瓶颈不在分辨率`

【做】
超分 / AA 的表现**随分辨率变化**，档位要逐档验证。

⛔ "改分辨率不用重测"是错的 ——
在一个分辨率下调好的参数换到另一个可能完全不合适
（超分的糊在低分辨率下更明显，AA 的边缘也一样）。

【产出】每个档位的独立验证记录

【判据】档位表里每一档都有单独的验证结果。

【审】`audit/godot/upscaling.md#38`

### Step 5　低端与高端走不同组合，不是同一套参数　`[upscaling/07#S5]`

【读】`howto/godot/upscaling.md#6. 三条管线的调试顺序（可照做）`

【做】
画质档位要做**不同组合**，不是同一套参数调数字。

⛔ "画质档位只做一套"是错的 ——
低端的关键矛盾是 draw call 与后处理开销，高端的关键矛盾是清晰度与稳定性，
⛔ 用同一套参数只调数字，会得到"低端糊、高端也没更好"。

【产出】低端 / 高端各自的组合表

【判据】能说清低端与高端分别换了哪几个选项，而不只是数字不同。

【审】`audit/godot/upscaling.md#39`

### Step 6　看截图，不看设置面板　`[upscaling/07#S6]`

【读】`howto/godot/upscaling.md#6. 三条管线的调试顺序（可照做）`

【做】
验收看的是**截图**。

⛔ "验收看设置面板"是错的 —— 面板上"开着"**不等于生效**：
`Use TAA` 在 FSR2 下被忽略、FSR2 在 Compatibility 回退双线性、
FXAA 在 Compatibility 不支持，⛔ 这些在面板上看起来都是"已开启"。

【产出】各档位 / 各渲染器的对比截图

【判据】每一条验收结论都能指到一张截图。

【审】`audit/godot/upscaling.md#40`

### Step 7　最高档与最低档都要测　`[upscaling/07#S7]`

【读】`howto/godot/upscaling.md#8. 后处理的性能代价要排序`

【做】
在**最高档与最低档**都测。

⛔ "只测默认档"是错的 ——
中间档的表现**不等于两端**：最高档暴露性能与稳定性问题，
最低档暴露糊与锯齿问题，⛔ 只测默认档会两头都漏。

【产出】最高档 / 默认档 / 最低档三份记录

【判据】三档都有独立记录，且各自的问题都已列出。

【审】`audit/godot/upscaling.md#42`
