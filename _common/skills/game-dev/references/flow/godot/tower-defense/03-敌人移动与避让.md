# 03 敌人移动与避让（塔防域）

> **本步交付**：agent 只给路径、移动自己写 + 避让显式开启并配齐 + `path_desired_distance` 显式配置
> **对应**：流程 `howto/godot/genres-tower-defense.md` · 审核 `audit/godot/genres-tower-defense.md`

## 0. 交付物定义

1. 移动是**自己写的**，不等 agent 推着走
2. `get_next_path_position()` 每**物理帧**调一次
3. 读碰撞修正后的真实速度用 `get_real_velocity()`，不是读 `velocity`
4. 避让**显式开启**且 `max_speed` / `max_neighbors` / `neighbor_distance` 已配
5. `path_desired_distance` 已按格子尺寸显式配置

## 1. 前置检查清单

- [ ] `move_and_slide()` 在 `_physics_process` 里被调用
- [ ] 没有"只在到达时才取下一个路径点"的写法
- [ ] 用到真实速度的地方读的是 `get_real_velocity()`
- [ ] `avoidance_enabled = true`（默认是 `false`）
- [ ] `path_desired_distance` 不是默认的 20.0

## 2. 工序

### Step 1　agent 只给路径，移动要自己写　`[tower-defense/03#S1]`

【读】``howto/godot/genres-tower-defense.md#3. 敌人移动：agent 只给路径，移动要自己写``

【做】
设了 `agent.target_position` 怪不会自己动 ——
`NavigationAgent2D` 只负责算路径与避让建议，位移要自己驱动。
⛔ 以为"设了目标就会走"是最常见的第一坑，
而它的表现是"怪站着不动"，检查时路径、agent、导航网格**全是绿的**。

ⓘ 移动放在 `_physics_process`：路径与避让都按物理帧推进，
⛔ 放 `_process` 会让避让结果与渲染帧错位，表现为怪轻微抖动。

【产出】`_physics_process` 里的移动函数

【判据】怪会沿路径走；⛔ 无「路径正常但站着不动」的情况。

【审】``audit/godot/genres-tower-defense.md#1``

### Step 2　get_next_path_position() 必须每物理帧调一次　`[tower-defense/03#S2]`

【读】``howto/godot/genres-tower-defense.md#3. 敌人移动：agent 只给路径，移动要自己写``

【做】
这个调用**同时推进 agent 内部的路径逻辑**，
只在"到达时"才调会让 agent 卡住。
⛔ 表现为怪走到第一个路径点就停，或者绕着某点打转，
而 `is_navigation_finished()` 一直是 `false`，看着像「还没到终点」。

ⓘ 顺序也别反：先判 `is_navigation_finished()` 再取点；
⛔ 反过来会在终点后取到一个无效点，让怪朝原点冲。

【产出】每物理帧调用一次的移动骨架

【判据】怪能走完整条路径；⛔ 不会在中间点停滞。

【审】``audit/godot/genres-tower-defense.md#1``

### Step 3　move_and_slide 不修改 velocity，真实速度要 get_real_velocity()　`[tower-defense/03#S3]`

【读】``howto/godot/genres-tower-defense.md#3. 敌人移动：agent 只给路径，移动要自己写``

【做】
`move_and_slide()` 是 `[const]` 方法，**不修改** `velocity` 成员变量。
要读碰撞修正后的真实速度（做朝向、动画速度、击退叠加）必须用 `get_real_velocity()`。
⛔ 直接读 `velocity` 拿到的是**期望速度不是实际速度**，
在被墙/被其他怪挡住时两者差很多，
表现为「怪贴着墙时动画还在全速跑」，且不报错。

【产出】速度读取口径（真实速度 vs 期望速度）

【判据】怪被挡住时朝向/动画速度同步变慢；⛔ 无「贴墙全速」现象。

【审】``audit/godot/genres-tower-defense.md#1``

### Step 4　避让默认关闭：显式开启并配齐四个参数　`[tower-defense/03#S4]`

【读】``howto/godot/genres-tower-defense.md#8. ⛔ 官方口径：路径查询、避让默认值与 force_update 的代价``

【做】
官方默认值：`avoidance_enabled = false`、`max_speed = 100.0`、
`max_neighbors = 10`、`neighbor_distance = 500.0`。

⛔ 两条最常被一起踩：
**避让默认根本没开**（「优化避让」改了半天全无效，
而 `max_speed` 面板上确实写着 100，看着像配好了）；
**开了也不配 `max_speed`**（默认 100 px/s 对塔防通常太慢，
千军万马挤成一团或走得极慢，而检查时「怪确实在动」）。

【产出】避让参数配置（含开启开关）

【判据】`avoidance_enabled` 为 `true` 且 `max_speed` 已按玩法设定；⛔ 密集时怪不挤成一团。

【审】``audit/godot/genres-tower-defense.md#13`　`audit/godot/genres-tower-defense.md#17``

### Step 5　path_desired_distance 显式配置：设太高与设太低都坏　`[tower-defense/03#S5]`

【读】``howto/godot/genres-tower-defense.md#8. ⛔ 官方口径：路径查询、避让默认值与 force_update 的代价``

【做】
官方双向警告（默认 20.0）：
**设太高** —— 会跳过路径点，**走出导航网格**；
**设太低** —— 每帧都过冲，**陷入重寻路循环**。

⛔ 两种失败都不报错：前者表现为「怪偶尔走到墙里或贴边卡住」，
后者表现为「帧率莫名下降」（重寻路是真开销）。
ⓘ 这个值要**与格子尺寸挂钩**：格子大了默认值就偏小，格子小了就偏大，
⛔ 抄默认 20.0 到任何尺度的地图都是在赌它恰好合适。

【产出】`path_desired_distance` 取值与格子尺寸的对应关系

【判据】怪不走进墙里；⛔ 密集时不会持续触发重寻路（可观测重寻路次数）。

【审】``audit/godot/genres-tower-defense.md#16``


## 3. 参考实现

```gdscript
# ⓘ 本块内自足：常量在此声明，承接上文即可直接用
const MOVE_SPEED := 120.0          # 期望速度 px/s
const AVOID_MAX_SPEED := 180.0     # ⛔ 避让上限，默认 100 对塔防通常太慢

func _ready() -> void:
    agent.avoidance_enabled = true              # ⛔ 默认 false
    agent.max_speed = AVOID_MAX_SPEED
    agent.max_neighbors = 16                    # 默认 10，密集阵型不够
    agent.path_desired_distance = 8.0           # ⛔ 与格子尺寸挂钩，不抄 20.0

func _physics_process(_d: float) -> void:
    if agent.is_navigation_finished():
        return
    var next := agent.get_next_path_position()  # ⛔ 每物理帧一次
    var dir := (next - global_position).normalized()
    velocity = dir * MOVE_SPEED
    move_and_slide()
    var real := get_real_velocity()             # ⛔ 不是 velocity
    if real.length_squared() > 1.0:
        _face_dir = real.normalized()
```

## 4. 验收清单

- [ ] 怪沿路径走完，不在中间点停滞
- [ ] 怪被挡住时动画速度同步变慢
- [ ] 密集时怪不挤成一团
- [ ] 重寻路次数可观测且不持续触发
- [ ] 无「走进墙里」现象

## 5. 常见返工

| 现象 | 返工到 |
|---|---|
| 怪站着不动 | 返工 Step 1（等 agent 推着走） |
| 怪走到中间点卡住 | 返工 Step 2（未每帧取点） |
| 贴墙时动画全速 | 返工 Step 3（读了 `velocity`） |
| 密集时挤成一团 | 返工 Step 4（避让没开 / `max_speed` 默认 100） |
| 帧率莫名下降 | 返工 Step 5（`path_desired_distance` 过低 → repath 循环） |
