# 04 客户端预测与回滚（网络同步域）

> **前置**：03 已能上报带序号的输入，服务端已能回权威状态
> **本步交付**：本地操作零等待，且服务器纠偏后能正确重放（不抖、不重复触发副作用）
> **对应**：做法 `howto/godot/netsync-advanced.md` · 审核 `audit/godot/netsync-advanced.md`

## 0. 交付物定义

⚠ **预测解决"我按了要马上动"，回滚解决"服务器说你算错了"。**
两者必须成对做——只做预测不做回滚，纠偏时会**瞬移**，手感比不做还差。

做完这一步，应该能**当场演示**：

1. 本地按键后**不等服务器**就先动
2. 服务器纠偏后，用未确认输入**重放**（不是瞬移）
3. ⚠ 误差小于阈值时**不重放**（否则持续抖动）
4. 重放用**固定 dt**，不用帧 delta
5. ⚠ 音效/粒子/伤害数字**不会**因回滚重复触发

**产出物**（下游按名字对接）：

```text
_unacked: Array          未确认输入历史（回滚的原料）
RECONCILE_THRESHOLD      纠偏阈值
FIXED_DT                 重放用的固定步长
predicted vs confirmed 的副作用区分
```

## 2. 工序

### Step 1　必须存输入历史　`[netsync/04#S1]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.1 客户端预测」

【做】
```gdscript
_unacked.append({"seq": _input_seq, "input": input, "tick": _predicted_tick})
_apply_movement(input, delta)
```

⚠ **必须存输入历史**，否则服务器纠偏后无法重放。
`_unacked` 就是回滚的原料。

⚠ 输入要**节流发送**（累积到间隔或队列超上限再发），
⛔ 不是每帧一次——每帧发包会吃满带宽。

【产出】`_unacked` 随输入增长，收到确认后缩减

【判据】⚠ 断开服务器后继续操作，`_unacked` **持续堆积**（证明在存）

【审】`audit/godot/netsync-advanced.md#4`

### Step 2　⚠ 回滚阈值必须有　`[netsync/04#S2]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.2 服务器回滚（reconciliation）」

【做】
```gdscript
const RECONCILE_THRESHOLD := 0.05   # 纠偏阈值，待实测

var err := global_position.distance_to(state["pos"])
if err < RECONCILE_THRESHOLD:
    return                    # ⚠ 误差小就忽略
misprediction_detected.emit(err)
```

⚠ **必须有阈值**。浮点误差每次都重放会让角色**持续抖动**——
这是"做了回滚反而更难受"的头号原因。

【产出】阈值可配，且有"误差事件"便于调参

【判据】⚠ 正常网络下（无作弊）**重放次数为 0**；
　　　人为改大误差后立刻触发一次重放

【审】`audit/godot/netsync-advanced.md#5`

### Step 3　重放必须用 FIXED_DT　`[netsync/04#S3]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.2 服务器回滚」

【做】
```gdscript
const FIXED_DT := 1.0 / 60.0        # 重放用的固定步长，待实测

global_position = state["pos"]
velocity = state["vel"]
for rec in _unacked:
    _apply_movement(rec["input"], FIXED_DT)   # ⚠ 不是 delta
```

⚠ **重放必须用固定 dt**（`FIXED_DT`），不能用帧 delta ——
否则重放结果与服务器不一致，会陷入"纠正→再错→再纠正"。

【产出】重放循环里没有 `delta`

【判据】⚠ 连续 100 次纠偏后，角色**稳定收敛**（⛔ 不是越抖越大）

【审】`audit/godot/netsync-advanced.md#6`

### Step 4　⚠ 回滚时哪些东西不能回滚　`[netsync/04#S4]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.0 ⚠ 回滚时哪些东西不能回滚」

【做】**音效、粒子、镜头震动、伤害数字、任务计数、UI 提示是纯副作用，
不能跟随模拟状态回滚。**

⚠ 客户端在预测第 1002 帧播放"开火声"，回滚到 998 帧重放 1002 帧，
**同一个输入又会触发一次开火声** → 音效重复、粒子重复、震屏叠加。

应对：
- 音效 ID 用 `(player_id, input_seq, effect_type)`，**服务器确认后才真正播放**
- 若需要"按下即反馈"，区分 `predicted_sfx` 与 `confirmed_sfx`：
  预测音效只播**短促、可打断、无持续逻辑**的声音
- ⚠ **绝不能把射击命中结算、任务奖励、冷却开始等可累加逻辑放进预测副作用**

【产出】副作用清单，每项标注 predicted / confirmed

【判据】⚠ 人为触发 10 次回滚，开火音效**只响 10 次**（⛔ 不是 20 次）

【审】`audit/godot/netsync-advanced.md#17`

### Step 5　回滚快照的内容　`[netsync/04#S5]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.0」末尾

【做】快照含：模拟 tick、随机生成器状态、确定实体数组、输入游标、计时器、事件队列。

⚠ 纹理/模型/节点引用/音频总线/粒子状态**不参与**确定模拟，
完整场景序列化既慢又容易包含不可序列化对象。

【产出】快照是纯数据字典，无 Object 引用

【判据】⚠ 快照能 `var_to_str()` 且不含任何 Node/RID

【审】`audit/godot/netsync-advanced.md#18`

### Step 6　未确认队列上限　`[netsync/04#S6]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.1 客户端预测」

【做】
```gdscript
const MAX_UNACKED := 64             # 未确认输入上限，待实测

while _unacked.size() > MAX_UNACKED:
    _unacked.pop_front()
```

⚠ 不设上限的话，服务器长时间不回包会让重放**越来越长**，
一次重放几百帧 → 单帧卡死。

【产出】队列超上限时丢弃最老的（接受少量误差换流畅）

【判据】⚠ 服务器停 10 秒后恢复，重放耗时**不导致掉帧**

【审】`audit/godot/netsync-advanced.md#19`

## 3. 参考实现

```gdscript
const FIXED_DT := 1.0 / 60.0        # 重放用的固定步长，待实测
const RECONCILE_THRESHOLD := 0.05   # 纠偏阈值，待实测
const MAX_UNACKED := 64             # 未确认输入上限，待实测
const SEND_INTERVAL := 0.05         # 上报间隔，待实测

func _process_local_prediction(delta: float) -> void:
    var input := _read_input()
    _input_seq += 1
    _predicted_tick += 1

    _unacked.append({"seq": _input_seq, "input": input, "tick": _predicted_tick})
    _apply_movement(input, delta)

    _send_accum += delta
    if _send_accum >= SEND_INTERVAL or _unacked.size() > MAX_UNACKED:
        _send_accum = 0.0
        _client_input.rpc_id(1, {
            "seq": _input_seq,
            "client_tick": _predicted_tick,
            "input": input,
            "ack_server_tick": _latest_server_tick,
        })

    while _unacked.size() > MAX_UNACKED:
        _unacked.pop_front()

func _on_server_state(state: Dictionary) -> void:
    while _unacked.size() > 0 and _unacked[0]["seq"] <= state["last_seq"]:
        _unacked.pop_front()                    # 丢弃已确认
    _latest_server_tick = state["tick"]

    var err := global_position.distance_to(state["pos"])
    if err < RECONCILE_THRESHOLD:
        return                                  # ⚠ 阈值守卫
    misprediction_detected.emit(err)

    global_position = state["pos"]
    velocity = state["vel"]
    for rec in _unacked:
        _apply_movement(rec["input"], FIXED_DT)  # ⚠ 固定 dt 重放
```

⚠ 注意报错事件 `misprediction_detected` ——
它是**调参的唯一依据**：正常网络下它应该几乎不触发，
频繁触发说明阈值太小或服务端/客户端物理不一致。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 纠偏时瞬移 | 没存输入历史 | S1 |
| 角色持续抖动 | 没设阈值 | S2 |
| 纠正→再错→再纠正 | 重放用了帧 delta | S3 |
| 音效/粒子重复 | 副作用放进预测 | S4 |
| 重放越久越卡 | 队列无上限 | S6 |
| 快照序列化失败 | 含 Node/RID | S5 |
