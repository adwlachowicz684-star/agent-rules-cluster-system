# 07 上线验收（网络同步域）

> **前置**：01–06 中本次选做的功能点**全部**验收通过
> **本步交付**：在**劣化网络**与**主动作弊**下仍可用——这是本域唯一有意义的验收
> **对应**：做法 `howto/godot/multiplayer.md` · 审核 `audit/godot/multiplayer.md` `netsync-advanced.md`

## 0. 交付物定义

⚠ **本域是所有域里最"本地测不出来"的一个。**
局域网延迟 <5ms、丢包 0%，**所有抖动问题都被隐藏**。

⚠ 各功能点自己的验收清单**不能替代本步**。

做完这一步，应该能**当场演示**：

1. ⚠ **150ms 延迟 + 5% 丢包**下本地移动无等待感、远端不抖
2. 伪造 RPC / 改内存 / 重放旧包 **全部被拒**
3. 专用服务器能 `--headless` 跑，且**不含 UI/相机/输入节点**
4. 断线重连后状态一致，无孤儿实体
5. 服务端 tick 与客户端重放**结果一致**

**产出物**：
```text
劣化网络实测记录（延迟/丢包下的数据）
作弊测试记录（每种手法的实际结果）
参数登记表已回填（见 00-域流程总览.md 第 4 节）
```

## 2. 工序

### Step 1　劣化网络实测　`[netsync/07#S1]`

【读】`howto/godot/multiplayer.md#上线前检查`

【做】至少三档：

| 档位 | 延迟 | 丢包 | 验收点 |
|---|---|---|---|
| 理想 | 20ms | 0% | 基准 |
| 一般 | 80ms | 2% | 本地无等待感，远端轻微平滑 |
| ⚠ 恶劣 | 150ms | 5% | **本档必须可用**——本地不卡、远端不抖 |

⚠ 只测"理想"档等于没测。150ms+ 是跨区联机的真实情况。

【产出】三档的实测记录（帧时间、重放次数、抖动幅度）

【判据】⚠ 恶劣档下：本地操作**无等待感**；
　　　远端**不出现**"卡顿—追帧"循环

【审】`audit/godot/multiplayer.md`

### Step 2　作弊测试　`[netsync/07#S2]`

| 手法 | 期望 | 实际 |
|---|---|---|

⛔ 只"觉得自己校验了"不算——**没实测过的校验等于没写**。

【产出】上表每行都有实测结果

【判据】⚠ 全部被拒，且**审计日志里有记录**

【审】`audit/godot/multiplayer.md`

### Step 3　专用服务器　`[netsync/07#S3]`

【读】`howto/godot/multiplayer.md#6. 专用服务器`

【做】
```bash
godot --headless --export-release "Linux/X11" build/server.x86_64
./server.x86_64 --headless
```

⚠ **`--headless` 只是无显示模式，不会裁剪资源**。
要真正瘦身得用 Dedicated Server 导出预设（可 Strip Visuals）。

⚠ 服务器场景**不要包含** UI、相机、输入捕获、粒子、音效。
推荐直接分两个场景文件：`WorldServer.tscn` / `WorldClient.tscn`，
逻辑节点路径保持一致。

【产出】服务器能 headless 跑起来，且不含 UI/相机/输入

【判据】⚠ 服务器进程内存**明显小于**客户端；
　　　且 `--headless` 实测能跑（⛔ 不是只在编辑器里通）

【审】`audit/godot/multiplayer.md`

### Step 4　服务端不做阻塞 IO　`[netsync/07#S4]`

【读】`howto/godot/multiplayer.md#6. 专用服务器` 的 ⚠ 提示

【做】⚠ 服务端别在 RPC 回调里做阻塞 IO / 睡眠 / 长循环。
数据库、验证、排行榜走队列，后台线程完成后回主线程应用。

⛔ 在 RPC 回调里查数据库 = 每个玩家的输入都在等磁盘，
tick 直接掉到个位数。

【产出】服务端无阻塞调用路径

【判据】⚠ 人为给数据库加 200ms 延迟，
　　　服务端 **tick 率不降**（⛔ 不是跟着变慢）

【审】`audit/godot/multiplayer.md`
