# 03 服务器权威与输入上报（网络同步域）

> **前置**：02 连接已能建立，RPC 参数已显式声明
> **本步交付**：客户端只发**意图**，服务端算结果——改内存/伪造 RPC 都会被拒
> **对应**：做法 `howto/godot/multiplayer.md` `netsync-advanced.md` · 审核 `audit/godot/multiplayer.md` `netsync-advanced.md`

## 0. 交付物定义

⚠ **任何从客户端来的数据都不可信** —— 这不是建议，是架构约束。

```
客户端权威（错）                服务器权威（对）
─────────────────              ─────────────────
客户端算结果 → 广播             客户端发意图 → 服务端算 → 同步状态
"我打死了 Boss，扣 100 血"       "我在这个位置按了攻击"
        ↓                               ↓
    谁都能改                      服务端校验合法性
```

做完这一步，应该能**当场演示**：

1. 客户端发的是 `{seq, input}`，⛔ **不是**位置、血量、伤害
2. ⚠ 伪造 RPC 说"我扣了 Boss 100 血"，**被服务端拒绝**
3. 输入做了范数/NaN/序号校验（改内存发 `NaN` 不会污染世界）
4. 关键数据（经济、伤害、胜负）**只在服务端计算**
5. 时间用**服务端时钟**，不收客户端时间

**产出物**（下游按名字对接）：

```text
submit_input(seq, input) -> void        @rpc any_peer unreliable_ordered
_validate_input(sender, seq, input)     校验函数
服务端校验表（移动/伤害/经济/时间/数值）
```

## 2. 工序

### Step 1　输入最小单元是「序号 + 意图 + 采集时刻」　`[netsync/03#S1]`

【读】`howto/godot/multiplayer.md#3. 输入上报（服务器权威核心）`

【做】⚠ **裸 Vector 不够** —— 没有序号就没法回滚（见 04）。

```gdscript
_input_seq += 1
_pending.push_back({"seq": _input_seq, "input": dir})
submit_input.rpc_id(1, _input_seq, dir)
```

【产出】输入包含 `seq`，且 `_pending` 队列已建（04 的原料）

【判据】⚠ 抓包看输入内容，**只有序号和方向**，没有位置/血量

【审】`audit/godot/netsync-advanced.md#32`

### Step 2　输入队列要有上限　`[netsync/03#S2]`

【读】`howto/godot/multiplayer.md#3. 输入上报（服务器权威核心）`

【做】
```gdscript
const MAX_QUEUE := 120
if _pending.size() > MAX_QUEUE:
    push_warning("输入缓冲溢出，从权威状态重置")
    _pending = []
    _rewind()
```

⚠ 队列无上限 = 服务器卡住时客户端**无限堆积**，
恢复后一次性重放几百帧，直接卡死。

【产出】队列溢出时能重置（⛔ 不是崩或卡死）

【判据】⚠ 人为让服务端停 5 秒再恢复，客户端**重置重放**而非卡死

【审】`audit/godot/netsync-advanced.md#31`

### Step 3　服务端校验五项　`[netsync/03#S3]`

【读】`howto/godot/multiplayer.md#7. 服务端校验什么`

【做】逐项实现：

| 数据 | 校验 |
|---|---|
| 移动 | 速度上限、位置连续性（防瞬移） |
| 伤害 | 冷却、射程、弹药、合法性 |
| 经济 | 余额、物品是否存在、交易幂等 |
| 时间 | **用服务端时钟**，不收客户端时间 |
| 数值 | 上限（金币不能超过产出总和） |

⚠ 输入还要做**范数 / NaN / 序号**校验——
改内存发一个 `NaN` 位置会让整个世界的物理计算变成 `NaN`。

【产出】校验表每行都有实现

【判据】⚠ 客户端发 `{input: Vector2(NaN, NaN)}`，服务端**拒绝且世界未污染**

【审】`audit/godot/multiplayer.md#2`

### Step 4　权威服务器 ≠ 反作弊　`[netsync/03#S4]`

【读】`howto/godot/multiplayer.md#7. 服务端校验什么` 的 ⚠ 提示

【做】⚠ **权威服务器 ≠ 自动反作弊**。它只是"你能执行服务端代码"。
仍需要：账号认证、限流、审计日志、服务端规则、幂等事务。

ⓘ 单机游戏的"防作弊"是提高修改成本（见 `security.md`），
与联网的服务器权威**不是一回事**，别混。

【产出】限流与审计日志已就位

【判据】⚠ 客户端 1 秒内发 1000 次输入，被**限流**且记入日志

【审】`audit/godot/netsync-advanced.md#30`

### Step 5　服务端固定 tick　`[netsync/03#S5]`

【读】`howto/godot/netsync-advanced.md#2. 延迟补偿（核心）` 的「2.2 服务器回滚」

【做】服务端按固定 dt 模拟，⛔ 不用帧 delta。

⚠ 客户端重放**必须用 `FIXED_DT`**——
用帧 delta 的话重放结果与服务器不一致，
会陷入"纠正→再错→再纠正"的死循环。

【产出】服务端 tick 率已定，客户端重放用同一个 `FIXED_DT`

【判据】⚠ 同一段输入，服务端算与客户端重放**结果一致**

【审】`audit/godot/netsync-advanced.md#6`

### Step 6　作弊测试　`[netsync/03#S6]`

【读】`howto/godot/multiplayer.md#上线前检查`

【做】⚠ **必须真的造一次作弊测试**：
改内存 / 伪造 RPC / 重放旧包，逐条确认被拒。

⛔ 只"觉得自己校验了"不算——
没实测过的校验等于没写。

【产出】作弊测试记录（每种手法的实际结果）

【判据】⚠ 至少 3 种作弊手法**全部被拒**，且有日志

【审】`audit/godot/netsync-advanced.md#30`

## 3. 参考实现

```gdscript
# ---- 客户端 ----
extends CharacterBody2D

const MAX_QUEUE := 120

var _input_seq := 0
var _pending: Array = []
var _last_processed := -1

func _physics_process(delta: float) -> void:
    if not is_multiplayer_authority():
        return                          # ⚠ 只处理本地控制的角色
    var dir := Vector2(
        Input.get_axis("ui_left", "ui_right"),
        Input.get_axis("ui_up", "ui_down")
    ).limit_length(1.0)                 # ⚠ 客户端侧先夹一次

    _input_seq += 1
    _pending.push_back({"seq": _input_seq, "input": dir})
    if _pending.size() > MAX_QUEUE:
        push_warning("输入缓冲溢出，从权威状态重置")
        _pending = []
        _rewind()
    submit_input.rpc_id(1, _input_seq, dir)
    _apply_input(dir, delta)            # 客户端预测

# ---- 服务端 ----
@rpc("any_peer", "call_remote", "unreliable_ordered", 0)
func submit_input(seq: int, input: Vector2) -> void:
    var sender := multiplayer.get_remote_sender_id()
    if not _validate_input(sender, seq, input):
        _audit_log(sender, "input_rejected", seq)
        return
    _apply_input_on_server(sender, seq, input)

func _validate_input(sender: int, seq: int, input: Vector2) -> bool:
    if seq <= _last_seq.get(sender, 0):
        return false                    # ⚠ 重放旧包
    if not is_finite(input.x) or not is_finite(input.y):
        return false                    # ⚠ NaN 防护
    if input.length() > 1.001:
        return false                    # ⚠ 范数上限
    return _rate_limit_ok(sender)
```

⚠ `_last_seq` 判重是防**重放攻击**的关键——
录下"我向前走"的包反复发，就能绕过速度限制。
