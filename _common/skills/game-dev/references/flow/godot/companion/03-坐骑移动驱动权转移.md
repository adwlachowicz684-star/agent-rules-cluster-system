# 03 坐骑：移动驱动权转移（伴侣物域）

> **本步交付**：单一驱动口径 + reparent 时序 + 碰撞层与下马检测
> **对应**：流程 `howto/godot/companion.md` · 审核 `audit/godot/companion.md`

## 0. 交付物定义

1. 骑乘期间**只有一个** `CharacterBody3D` 在 `move_and_slide()`
2. reparent 的时机与后续 `reset_physics_interpolation()` 已确立
3. ⛔ 没有手写 `remove_child` + `add_child` 去"补偿"变换
4. 碰撞层的关闭与**恢复**顺序已明确，且恢复在 reparent 之后
5. 下马点有安全检测；飞行坐骑的落地判据已按模式修正

## 1. 前置检查清单

- [ ] 骑乘时只有坐骑在驱动移动
- [ ] reparent 不在信号回调里直接做
- [ ] reparent 之后调了 `reset_physics_interpolation()`
- [ ] 下马恢复了角色碰撞层
- [ ] 飞行坐骑没有沿用 `is_on_floor()` 判落地

## 2. 工序

### Step 1　骑乘期间只有一个驱动源　`[companion/03#S1]`

【读】`howto/godot/companion.md#2. 坐骑：核心是"谁在驱动移动"`

【做】
确立：**骑乘期间只有坐骑本体在 `move_and_slide()`**，
角色成为坐骑的子节点，不再独立移动。
⛔ 两个 `CharacterBody3D` 各自 `move_and_slide()` 再把角色位置贴到坐骑上 ——
**一帧延迟**、穿模、碰撞不一致，
表现为"角色在坐骑上抖动""下马后位置不对"，
⛔ 而两者的移动代码单看都完全正确。

ⓘ 这条的判据是**数 `move_and_slide()` 的调用点**：
骑乘状态下整个场景里应该只有一次。

【产出】骑乘状态机的驱动权归属表（谁在调 `move_and_slide()`）

【判据】骑乘时全局只有一处 `move_and_slide()` 被调用。

【审】`audit/godot/companion.md#7`

### Step 2　reparent 的时机与插值重置　`[companion/03#S2]`

【读】`howto/godot/companion.md#reparent 的三个坑`

【做】
reparent 不在信号回调里直接做（用 `call_deferred` 或延迟到 `_physics_process`），
且**在 reparent 之后**调用 `reset_physics_interpolation()`。
⛔ 在信号回调里直接 reparent —— 物理引擎崩溃。
⛔ 不调 `reset_physics_interpolation()` —— 官方 Warning：
插值开启且变换变化较大时，物体会在**下一个物理帧从旧位置滑到新位置**，
表现为"上马瞬间角色从原位置拖影滑到马鞍上"。

ⓘ 调用顺序是硬约束：官方注明该方法**必须在移动之后调用**，
⛔ 调早了会按旧位置重置快照，照旧插值。

【产出】reparent 时序表（含 deferred 时机与插值重置位置）

【判据】上马瞬间无拖影；连打十次上下马不崩溃。

【审】`audit/godot/companion.md#8`、`audit/godot/companion.md#26`

### Step 3　⛔ 不要手写两步去"补偿"全局变换　`[companion/03#S3]`

【读】`howto/godot/companion.md#reparent 的三个坑`

【做】
直接用 `reparent()`，⛔ **不要**手写 `remove_child()` + `add_child()`。
⚠ 官方签名是 `reparent(new_parent, keep_global_transform: bool = true)` ——
**默认就是保留全局变换**。
⛔ 误以为"默认会丢"而去手写两步补偿，那才真的丢 ——
骑手瞬移到原点，而这正是本想避免的那个 bug。

ⓘ 另有一条边界：`keep_global_transform` 只对 `Node2D` / `Node3D` / `Control` 生效，
且 `Control` **只保留 position**。
⛔ 在普通 `Node` 上显式传 `true` 也不会有效果。

【产出】reparent 调用点清单（⛔ 无手写两步的变体）

【判据】上马后骑手位置与马鞍锚点一致，不存在瞬移到原点。

【审】`audit/godot/companion.md#25`、`audit/godot/companion.md#9`

### Step 4　碰撞层的关闭与恢复顺序　`[companion/03#S4]`

【读】`howto/godot/companion.md#reparent 的三个坑`

【做】
上马后关闭角色碰撞层（两个碰撞体互挤会穿模），
下马时**恢复** —— 且恢复必须在 reparent **之后**。
⛔ 顺序反了（先恢复碰撞再 reparent）——
角色在旧位置恢复碰撞、随后被移到新位置，
表现为"下马后卡进墙里""下马瞬间被弹飞"，
⛔ 而碰撞层的值在检查时确实是对的。

ⓘ 反向也要处理：下马点要做**安全检测**（`PhysicsShapeQueryParameters3D`），
⛔ 不检测直接放，骑手会被塞进地形里。

【产出】上马/下马的动作时序（含碰撞层与 reparent 的相对顺序）

【判据】连续上下马 10 次，无穿模、无卡墙、无弹飞。

【审】`audit/godot/companion.md#10`、`audit/godot/companion.md#35`、`audit/godot/companion.md#11`

### Step 5　飞行坐骑的落地判据要按模式重写　`[companion/03#S5]`

【读】`howto/godot/companion.md#2. 坐骑：核心是"谁在驱动移动"`

【做】
飞行坐骑用 `MOTION_MODE_FLOATING` 时，**不能沿用 `is_on_floor()` 判落地**。
官方语义：该模式下**所有碰撞都报告为 `on_wall`**，且滑动时速度恒定。
⛔ 沿用 `is_on_floor()` —— 它在该模式下**永远返回 false**，
表现为"切换回地面模式前一直在空中飘""永远判不到落地"，
⛔ 而 `velocity` 与碰撞检测本身都完全正常。

ⓘ 水面/空中切换的物理表现属**真机实测项**（见 00 参数登记），
⛔ 本步只要求判据不被写死成 `is_on_floor()`。

【产出】飞行态与地面态各自的落地/入水判据（⛔ 不共用一套）

【判据】飞行坐骑能正常落地；切换到地面模式后判定立即生效。

【审】`audit/godot/companion.md#28`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：单一驱动 + deferred reparent + 插值重置 + 碰撞层顺序
# 骑乘期间 ⛔ 只有坐骑调用 move_and_slide()，角色不再独立移动
func mount(rider: CharacterBody3D, saddle: Node3D) -> void:
    # ⛔ 不在信号回调里直接 reparent —— 物理引擎崩溃
    rider.reparent.call_deferred(saddle)
    # ⛔ 必须在 reparent 之后重置插值，且不要手写 remove_child+add_child
    rider.reset_physics_interpolation.call_deferred()
    rider.set_collision_layer_value(1, false)   # 关碰撞层，避免互挤穿模
    rider.set_physics_process(false)            # ⛔ 停止角色的独立驱动

func dismount(rider: CharacterBody3D, spot: Vector3) -> void:
    if not is_spot_clear(spot):                 # 下马安全检测，⛔ 不检测会卡进墙
        return
    rider.reparent(get_tree().current_scene)
    rider.reset_physics_interpolation()         # ⛔ 顺序：移动之后
    rider.set_collision_layer_value(1, true)    # ⛔ 恢复必须在 reparent 之后
    rider.set_physics_process(true)
```

## 4. 验收清单

- [ ] 骑乘时只有一处 `move_and_slide()`

- [ ] 无手写 remove_child + add_child

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 角色在坐骑上抖动 | 两个 body 各自驱动 | S1 |
| 上马瞬间从旧位置拖影滑过来 | 未重置插值 | S2 |
| 骑手瞬移到原点 | 手写两步补偿 | S3 |
| 下马卡进墙里 | 碰撞恢复早于 reparent / 未检测 | S4 |
| 飞行坐骑永远判不到落地 | FLOATING 下 is_on_floor 恒 false | S5 |
