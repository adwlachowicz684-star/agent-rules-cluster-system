# 07 VIP 验收（VIP 域）

> **前置**：01–06 全部完成
> **本步交付**：一份**可签核**的验收报告
> **对应**：做法 `howto/godot/vip-subscription.md` 全文 · 审核 `audit/godot/vip-subscription.md` 全部 25 条

## 0. 交付物定义

⚠ **VIP 域的验收必须在"敌意环境"下做，不是在正常环境下做。**

⛔ 正常环境下所有实现都正确——
本域的 bug 全部只在**改时间、改时区、退款、重放回调**时出现。

做完这一步，应该能**当场演示**并**签核**：

1. ⚠ **改系统时间**到一年前后，权益**都不变**（01 的核心指标）
2. ⚠ **改时区**，剩余秒数**一致**（01 的核心指标）
3. ⚠ **退款**后等级正确回落（03 的核心指标）
4. ⚠ **未到期续费**剩余只增不减（05 的核心指标）
5. ⚠ **重放回调**不重复加时（05 的核心指标）
6. ⚠ 接缝复查：与 7 个域的契约全对上

## 2. 工序

### Step 1　⚠ 改系统时间实测　`[vip/07#S1]`

【读】`howto/godot/vip-subscription.md#1. ⛔ 不能用本地系统时间算到期`

【做】系统时间改到一年后与一年前，各测一次权益。

⛔ 只测"现在" → 本域最严重的一类漏洞**完全测不到**。
⚠ 这是本域**最常见的验收造假**。

【产出】两次改时间的结果

【判据】⚠ 两次权益**都不变**；变了说明用了本地时钟

【审】`audit/godot/vip-subscription.md#1`

### Step 2　⚠ 改时区实测　`[vip/07#S2]`

【读】`howto/godot/vip-subscription.md#2. ⚠ 时区与夏令时不会自动转换`

【做】切到另一时区，看剩余时间的**秒数**。

⛔ 只看"显示还剩几天" → 时区偏移被四舍五入掩盖，
⚠ 真正的偏差要在**秒级**才看得出。

【产出】多时区的剩余秒数

【判据】⚠ 秒数一致，只有**显示格式**变

【审】`audit/godot/vip-subscription.md#25` `audit/godot/vip-subscription.md#4`

### Step 3　⚠ 退款链路实测　`[vip/07#S3]`

【读】`howto/godot/vip-subscription.md#5. 等级是派生值，⛔ 不单独存`

【做】触发退款回调，确认等级回落且再重算不回升。

⛔ 只测充值不测退款 → "只降等级不减额度"的 bug
**在充值路径下完全正常**。

【产出】退款前后的额度与等级

【判据】⚠ 等级回落，且再调 `level_of(total)` **一致**

【审】`audit/godot/vip-subscription.md#13` `audit/godot/vip-subscription.md#14`

### Step 4　⚠ 续费与重放实测　`[vip/07#S4]`

【读】`howto/godot/vip-subscription.md#8. ⚠ 订阅续期要处理"叠加"与"补时"`

【做】①未到期续费看剩余是否只增；②同一订单回调两次。

⛔ 不测重放 → 一个可直接利用的漏洞被漏掉；
⚠ 而它在正常流程下**表现完全正常**。

【产出】续费与重放的结果

【判据】⚠ 剩余只增不减；⛔ 重放**只加一次**

【审】`audit/godot/vip-subscription.md#21` `audit/godot/vip-subscription.md#22`

### Step 5　⚠ 接缝复查　`[vip/07#S5]`

【读】`howto/godot/vip-subscription.md#10. 相关文档`

【做】逐条核对 00 总览第 2 节的七条契约：

| 接缝 | 复查点 |
|---|---|
| `monetization.md` 支付 | 扣款与掉单在那篇，本域只消费到账后状态，不重复实现 |
| `economy.md` 货币 | 累充额度用的货币类型一致 |
| `time-progression.md` 时间源 | 三种时间源不重复展开，本域只讲到期用哪个 |
| `datatable.md` 配置 | 阈值与权益表进配置，不硬编码 |
| `systems.md` 存档 | 只存额度与到期时刻，**不存派生等级** |
| `save-migration.md` 迁移 | 阈值结构变更时旧档能读，老玩家不掉级 |
| `auto-battle.md` 扫荡 | 扫荡次数走 `get_benefit()`，不自己判等级 |

⛔ **这七条不查，部件全合格也可能拼不起来。**

【产出】接缝复查表

【判据】⚠ 七条全部对上，每条都有实测证据

【审】`audit/godot/vip-subscription.md#23`

## 4. 常见返工

**① 只测正常环境。** 本域 bug 全在敌意环境。

**② 只看天数不看秒。** 时区偏差被掩盖。

**③ 不测退款。** 只降等级不减额度测不出。

**④ 不测重放。** 可利用漏洞被漏。
