# 01 时间源与到期基准（VIP 域）

> **前置**：无（本域地基）
> **本步交付**：**改设备系统时间，权益不变**
> **对应**：做法 `howto/godot/vip-subscription.md#1. ⛔ 不能用本地系统时间算到期`
> 　　　审核 `audit/godot/vip-subscription.md#1`

## 0. 交付物定义

⚠ **本步是本域的地基，也是最容易"看起来做完了"的一步。**

⛔ 常见假完成：写了 `Time.get_unix_time_from_system()` 当到期判据，
在**自己没改系统时间的情况下一切正常**——
于是认为"到期逻辑没问题"。

⚠ 而官方明确写了：系统时钟**用户可手动设置**，
⛔ 精确计时**禁用**这类方法。

做完这一步，应该能**当场演示**：

1. 把设备时间改到一年后，**VIP 权益不变**
2. 把设备时间改到一年前，**VIP 权益不变**
3. ⚠ 改设备时区，**剩余时间的秒数一致**（只有显示格式变）
4. 倒计时在**没有网络请求**的情况下平滑推进
5. ⛔ 时间转换失败时**不会静默落到 1970**

**产出物**（下游按名字对接）：

```text
server_now_unix: int        # 服务器权威时间戳，唯一判据
expire_at_unix: int         # 到期绝对时刻
_get_now() -> int           # 只从 server_now + ticks 插值
```

## 2. 工序

### Step 1　⛔ 到期判据只用服务器时间　`[vip/01#S1]`

【读】`howto/godot/vip-subscription.md#1. ⛔ 不能用本地系统时间算到期`

【做】`server_now_unix` 由服务器下发，本地只做插值。

⛔ **官方原话：*"Never use this method for precise time calculation since its
results are subject to automatic adjustments by the user."***

【产出】`_get_now()` 只认服务器基准

【判据】⚠ 改系统时间到一年后，**权益不变**

【审】`audit/godot/vip-subscription.md#1`

### Step 2　⚠ get_ticks_msec 只用于插值，不用于存时刻　`[vip/01#S2]`

【读】`howto/godot/vip-subscription.md#1. ⛔ 不能用本地系统时间算到期`

【做】用 `get_ticks_msec()` 推进显示，⛔ 不把它写进存档当到期时刻。

⛔ 它是**引擎启动以来的毫秒数**，
⛔ 存下来等于"游戏运行了多久"，而不是"几号到期"。

【产出】插值逻辑与存储字段分离

【判据】⚠ 重启游戏后到期时刻**不漂移**

【审】`audit/godot/vip-subscription.md#2`

### Step 3　⚠ 跨端统一 UTC　`[vip/01#S3]`

【读】`howto/godot/vip-subscription.md#2. ⚠ 时区与夏令时不会自动转换`

【做】所有跨端比较用 UTC，只在展示层转本地。

⛔ **官方："Conversion methods ... do not handle timezone conversions or DST
automatically."**
表现为"本地显示还剩 3 小时，服务器说已过期"。

【产出】UTC 约定（写进文档）

【判据】⚠ 改设备时区，**剩余秒数一致**

【审】`audit/godot/vip-subscription.md#4` `audit/godot/vip-subscription.md#5`

### Step 4　⛔ 转换结果必须校验区间　`[vip/01#S4]`

【读】`howto/godot/vip-subscription.md#3. ⛔ 空字典/缺键会静默落到 1970`

【做】转换后校验时间戳落在合理区间。

⛔ **官方："If the dictionary is empty, 0 is returned. If some keys are omitted,
they default to ... (1970-01-01 at 00:00:00)."**
表现为"刚充完值，VIP 立刻没了"，而**不报错**。

【产出】区间校验

【判据】⚠ 构造缺键字典 → **被拦下**而不是得到 0

【审】`audit/godot/vip-subscription.md#8` `audit/godot/vip-subscription.md#9`

### Step 5　⚠ 注意 system 版返回 float　`[vip/01#S5]`

【读】`howto/godot/vip-subscription.md#4. ⚠ `get_unix_time_from_system()` 返回的是 float`

【做】明确类型，⛔ 不与其他 int 版混用比较。

⛔ **官方 Note：*"Unlike other methods that use integer timestamps, this
method returns the timestamp as a float."***

【产出】类型约定

【判据】⚠ 边界上不出现"差 0.9 秒导致状态不同"

【审】`audit/godot/vip-subscription.md#11`

## 5. 常见返工

**① 用系统时间当判据。** 改时间即白嫖。

**② ticks 存进存档。** 重启后到期时刻漂移。

**③ 不校验转换结果。** 静默落到 1970。

**④ 时区不一致。** 差几小时，偶发投诉。
