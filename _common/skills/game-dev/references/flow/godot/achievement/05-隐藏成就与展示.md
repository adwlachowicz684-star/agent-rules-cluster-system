# 05 隐藏成就与展示（achievement 域）

> **前置**：02 定义与状态分离
> **本步交付**：**标题/进度/是否解锁可见，描述受控**
> **对应**：做法 `howto/godot/achievement.md#5. 隐藏成就与展示`
> 　　　审核 `audit/godot/achievement.md`

## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：描述藏起来了。**

⛔ 常见假完成：隐藏成就连"是否已解锁"都不显示，
⚠ 描述确实藏住了，
⛔ 但**玩家无法确认自己拿没拿到**，
表现为"隐藏成就永远像是没解锁"。

做完这一步，应该能**当场演示**：

1. ✅ 标题、进度、是否已解锁**必须展示**
2. ⛔ 描述解锁前不展示
3. ⚠ 隐藏描述只是客户端不显示，**改包可见**（真保密要服务端下发）
4. ⚠ id 稳定，隐藏状态切换不影响存档

**产出物**：展示层字段可见性表

## 2. 工序

### Step 1　✅ 标题与是否已解锁必须展示　`[05#S1]`

【读】`howto/godot/achievement.md#5. 隐藏成就与展示`

【做】隐藏成就在列表里显示标题与解锁状态，只藏描述。

【产出】可见性表

【判据】⛔ 玩家能确认自己**有没有拿到**

【审】`audit/godot/achievement.md#9`

### Step 2　⛔ 描述解锁前不展示　`[05#S2]`

【读】`howto/godot/achievement.md#5. 隐藏成就与展示`

【做】`hidden = true` 时描述字段走占位符；解锁后替换为真实描述。

【产出】描述占位机制

【判据】⛔ 未解锁时列表里**看不到**剧透描述

【审】`audit/godot/achievement.md#9`

### Step 3　⚠ 隐藏成就也要给进度反馈　`[05#S3]`

【读】`howto/godot/achievement.md#5. 隐藏成就与展示`

【做】进度条可见（或至少显示"进度 3/5"），不显示时才用占位。

【产出】进度展示

【判据】⚠ 玩家做隐藏成就时**有反馈**，不会以为没在做

【审】`audit/godot/achievement.md#22`

### Step 4　⚠ 描述保密靠服务端下发，不靠客户端不显示　`[05#S4]`

【读】`howto/godot/achievement.md#5. 隐藏成就与展示`

【做】真要保密则描述不下发到客户端，解锁时由服务端返回。

【产出】机密描述的获取路径

【判据】⚠ 改包**看不到**未解锁描述

【审】`audit/godot/achievement.md#10`

**② 描述放客户端以为保密。** 改包可见。

**③ 隐藏成就无进度反馈。** 玩家以为没在做。
