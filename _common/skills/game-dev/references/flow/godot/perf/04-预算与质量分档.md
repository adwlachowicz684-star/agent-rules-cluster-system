## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：在项目设置里配了几档画质就算完成。**

⛔ 常见假完成：档位写好了，但**运行时没有降级路径**——
设备掉帧时不会自动降档，玩家只能自己去设置里改。
而开发者在高端机上测试时**全程满帧**，永远看不到这个缺口。

做完这一步，应该能**当场演示**：

1. 帧预算已按目标帧率定死（含 P99 门槛）
2. ⛔ 分档能在**运行时**降级，不只是设置项
3. ⚠ 热节流降档带**迟滞**，不在阈值边界反复跳
4. ⚠ 移动端按机型分档，没有"统一上限"
5. ⚠ 分档改动已纳入 05 的回归对比

## 3. 参考实现

⛔ 分档不能只是设置项 —— 要有运行时降级链：

```text
监测 P99 超预算 N 帧 → 降一档 → 观察 → 带迟滞，不立即升回
```
