## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：跑一次游戏、记下 FPS 就算建了基线。**

⛔ 常见假完成：数字记下来了，但没记 Godot 精确版本、release/debug、
渲染方法、图形 API、内部分辨率、MSAA、场景种子——
于是这个数字**不可复现**，下次测得的值与它无法比较。

做完这一步，应该能**当场演示**：

1. 基线表已填满（含环境信息与运行分钟数）
2. ⛔ 项目特有指标已通过 `add_custom_monitor()` 进入 Monitors 面板
3. ⛔ 自定义监视器只注册一次，且返回值**非负**
4. 对象数 / 节点数基线已记录（用于后续查泄漏）
5. ⚠ 记录发生在预热之后，不含首次编译与加载

**产出物**（下游按名字对接）：

```text
基线记录表（含环境与版本）
PerfMonitors autoload（自定义监视器注册）
```

## 3. 参考实现

```gdscript
# PerfMonitors autoload
func _ready() -> void:
    if not Performance.has_custom_monitor("game/enemies"):
        Performance.add_custom_monitor("game/enemies", _enemy_count)

func _enemy_count() -> int:
    return get_tree().get_nodes_in_group("enemies").size()
```

⛔ 取值函数返回负数会被钳到 0；注册前先 `has_custom_monitor()`。
