## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：有基线文件，但没人再跑过第二次。**

⛔ 常见假完成：01 建了基线，之后两周持续改动，
**没有一次复测** —— 于是"性能有没有回退"这个问题**根本没有答案**，
而所有人默认答案是"应该没有吧"。

⛔ 更隐蔽的是：即便复测了，如果**基线没随优化更新**，
下次对比用的是旧基线，会把"已优化"误判成"又变慢了"。

做完这一步，应该能**当场演示**：

1. 基线快照可一键重建
2. ⛔ 复测入口存在且被真正跑过（有记录）
3. 进出关卡后对象数**回到基线**
4. ⛔ 性能回退与功能回退同等对待，都判失败
5. ⚠ 优化合入后基线已同步更新

## 3. 参考实现

```text
基线快照（固定种子 + 固定时长）→ 一键复测 → 与快照比对 → 超阈值判失败
```

⛔ 优化合入后必须重建快照，否则下次对比用的是旧基线。
