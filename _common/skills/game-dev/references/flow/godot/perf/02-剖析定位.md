## 0. 交付物定义

⚠ **本步最容易"看起来做完了"：打开 Profiler 看到某栏高，就认定那是瓶颈。**

⛔ 常见假完成：看到 `Inclusive` 高就去优化该函数，
但它**自己很便宜，只是调了贵函数**——优化完毫无变化，
而时间已经花掉了。

做完这一步，应该能**当场演示**：

1. 结论指到具体函数/资源，且有 `Self` 时间支撑
2. ⛔ 卡顿用的是 **P99**，不是平均帧率
3. 已确认帧时间的构成（不只等于 process 时间）
4. ⚠ C# / GDExtension 部分已知 Profiler 覆盖不到
5. ⚠ 没有把 release 下返回 0 的监视器当成"没问题"

## 1. 前置检查清单

## 3. 参考实现

⚠ 定位结论要写成"哪个函数、Self 多少毫秒、占预算百分之多少"，
⛔ 而不是"物理好像有点慢"。
