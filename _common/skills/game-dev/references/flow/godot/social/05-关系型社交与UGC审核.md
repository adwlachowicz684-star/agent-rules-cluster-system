# 05 关系型社交与 UGC 审核（社交域）

> **本步交付**：绑定 + 共享收益 + 解除代价三者齐全 + UGC 过审
> **对应**：流程 `howto/godot/social.md` · 审核 `audit/godot/social.md`

## 0. 交付物定义

1. 好友 / 师徒 / 结拜 / 婚姻都满足"绑定 + 共享收益 + **解除代价**"三要素
2. 建立与解除都有冷却，⛔ 不能反复刷奖励
3. 关系加成有硬上限，且玩家名 / 头像等 UGC 过审

## 1. 前置检查清单

- [ ] 已完成 01（身份与会话地基）
- [ ] 好友列表存服务端
- [ ] 已定义各类关系的收益与上限
- [ ] UGC 过审流程已就位（见 04）

## 2. 工序

### Step 1　三要素缺一不可：绑定 + 共享收益 + 解除代价　`[social/05#S1]`

【读】`howto/godot/social.md#6.9 关系型社交（师徒 / 结拜 / 婚姻）`

【做】
师徒 / 结拜 / 婚姻的本质是**绑定 + 共享收益 + 解除代价**。
⛔ 只有绑定和收益、没有解除代价 —— 玩家反复建立 / 解除来刷奖励，
表现为"社交活跃度很高但全是空壳关系"。

【产出】每类关系的三要素表（缺一项即不上线）

【判据】指着任一类关系，能说出解除它要付出什么。

【审】`audit/godot/social.md#60`

### Step 2　解除必须冷却，批量解除要限流　`[social/05#S2]`

【读】`howto/godot/social.md#6.9 关系型社交（师徒 / 结拜 / 婚姻）`

【做】
解除后有一段冷却期不能重建同类关系。
⛔ 解除即可重建 —— 刷奖励的循环成立。
⛔ 只限单次不限批量 —— 脚本批量解除同样能刷。

【产出】解除冷却（按关系类型）+ 批量解除限流

【判据】用脚本连续建立解除 10 次，第 2 次起即被冷却拦下。

【审】`audit/godot/social.md#61`

### Step 3　关系加成要有硬上限　`[social/05#S3]`

【读】`howto/godot/social.md#6.9 关系型社交（师徒 / 结拜 / 婚姻）`

【做】
所有关系加成加起来有硬上限。
⛔ 不限上限 —— 叠满所有关系会**破坏数值**，
表现为"社交玩家属性碾压"，且很难在不删数据的情况下回收。

【产出】关系加成的总上限（登记在参数表）

【判据】建满所有关系时的总加成不超过上限值。

【审】`audit/godot/social.md#62`

### Step 4　好友与关系状态存服务端　`[social/05#S4]`

【读】`howto/godot/social.md#1. 三层架构（推荐）`

【做】
好友列表、关系状态存服务端，客户端只读副本。
⛔ 存客户端 —— 换设备就没了，且可被改，
表现为"好友列表里多出不认识的人"。

【产出】服务端关系表 + 客户端只读副本

【判据】换一台设备登录后好友与关系完全一致。

【审】`audit/godot/social.md#10`

### Step 5　合规重点：未成年人、诱导与权力不对称　`[social/05#S5]`

【读】`howto/godot/social.md#6.9 关系型社交（师徒 / 结拜 / 婚姻）`

【做】
避免诱导加好友、诱导充值绑定、定位式社交、跨代际私聊。
⚠ 具体条款指向 `compliance.md`，⛔ 本域不重复也不自行编造。

【产出】合规检查项（指向 compliance 域，不自行定义）

【判据】每条合规要求都能指到 `compliance.md` 的对应条目。

【审】`audit/godot/social.md#63`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：解除冷却 + 加成硬上限
# ⛔ 没有解除代价的关系 = 可被刷的空壳
const RELATION_BREAK_COOLDOWN_SEC := 86400.0   # 待实测：按关系类型分档
const RELATION_BONUS_CAP := 0.25               # 待实测：所有关系加成的总上限

func apply_relation_bonus(base: float, bonuses: Array) -> float:
    var total := 0.0
    for b in bonuses:
        total += b
    return base * (1.0 + minf(total, RELATION_BONUS_CAP))   # ✅ 硬上限
```

| 症状 | 原因 | 回到 |
|---|---|---|
| 关系活跃但全是空壳 | 没有解除代价 | S1 |
| 脚本批量刷关系奖励 | 只限单次不限批量 | S2 |
| 社交玩家属性碾压 | 加成无上限 | S3 |
