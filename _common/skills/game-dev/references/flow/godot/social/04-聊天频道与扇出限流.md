# 04 聊天频道与扇出限流（社交域）

> **本步交付**：频道 / 成员资格 / 扇出三者分离 + 服务端过滤 + 可取证留存
> **对应**：流程 `howto/godot/social.md` · 审核 `audit/godot/social.md`

## 0. 交付物定义

1. 频道、成员资格、扇出是三件事，⛔ 成员列表不塞进频道对象
2. 敏感词过滤在**服务端**，客户端过滤只是体验优化
3. 聊天内容留存，举报能定位到**具体内容**

## 1. 前置检查清单

- [ ] 已完成 01（身份与会话地基）
- [ ] 已划分频道类型（世界 / 队伍 / 私聊 / 系统）
- [ ] 服务端有消息表与留存策略
- [ ] 已有举报入口与证据快照结构

## 2. 工序

### Step 1　频道、成员资格、扇出三者分离　`[social/04#S1]`

【读】`howto/godot/social.md#6.10 聊天频道：频道、成员资格、扇出三者分离`

【做】
频道是一条逻辑通道，成员资格单独存，扇出独立限流。
⛔ 把成员列表塞进频道对象 —— 热点频道（世界频道）会**拖垮战斗服**，
表现为"一到晚上聊天就卡"，而排查时会去查战斗同步。

【产出】三张结构：频道 / 成员资格 / 扇出队列

【判据】世界频道在线 1 万人时，战斗服的帧率不受发消息影响。

【审】`audit/godot/social.md#57`

### Step 2　客户端过滤不够，必须服务端过滤　`[social/04#S2]`

【读】`howto/godot/social.md#4. 聊天是合规重灾区`

【做】
敏感词过滤放服务端；客户端过滤只作体验优化（即时提示）。
⛔ 只在客户端过滤 —— **改包就能绕过**，
表现为"审核以为很干净，实际全是违规内容"。

【产出】服务端过滤服务 + 客户端仅作提示

【判据】改包绕过客户端过滤后，服务端仍能拦下并记录。

【审】`audit/godot/social.md#7`

### Step 3　留存与证据快照　`[social/04#S3]`

【读】`howto/godot/social.md#5. 举报与审核`

【做】
聊天内容要留存以配合举报取证；举报必须能定位到**具体内容**，
存证据快照（消息 id、发送者、时间、上下文若干条），
⛔ 不是只存"某人被举报了"。
⚠ 保存期限**库里没有统一天数**（各地法规未给出游戏私聊的统一要求），
⛔ 不许编一个数字 —— 按最小必要原则由运营与法务定，并登记为待核对。

【产出】消息留存表 + 举报证据快照结构 + 保存期限列为待核对

【判据】任意一条举报都能还原出被举报的那条消息及其上下文。

【审】`audit/godot/social.md#8`

### Step 4　世界频道刷屏用经济手段，不只用限流　`[social/04#S4]`

【读】`howto/godot/social.md#6.10 聊天频道：频道、成员资格、扇出三者分离`

【做】
世界频道的刷屏用**发言道具 / 冷却**（经济手段）控制，
⛔ 不是只靠限流 —— 限流会**误伤正常玩家**，
表现为"正常玩家被禁言，而刷屏的用多个小号照样刷"。

【产出】发言道具或冷却规则 + 扇出限流（按单会话维度）

【判据】小号刷屏的成本显著高于正常发言；正常玩家不被误伤。

【审】`audit/godot/social.md#58`

### Step 5　私聊与 UGC 的默认最小范围　`[social/04#S5]`

【读】`howto/godot/social.md#4. 聊天是合规重灾区`

【做】
玩家名、公会名、头像都是 **UGC**，都要过审，⛔ 不是"玩家自己填的就不用管"。
私聊保存期按最小必要原则定。
⚠ 涉及未成年人、诱导与权力不对称的部分指向 `compliance.md`，本域不重复。

【产出】UGC 过审流程（玩家名 / 公会名 / 头像）+ 私聊保存策略

【判据】新注册玩家用违规名注册时被拦下，且能通过改名流程解除。

【审】`audit/godot/social.md#15`

## 3. 参考实现

```gdscript
# ⓘ 承接本步产出：扇出独立限流 + 服务端过滤
# ⛔ 客户端过滤只是提示，不能作为合规手段
const WORLD_CHANNEL_COOLDOWN_SEC := 10.0   # 待实测：经济手段优先于限流
const MAX_FANOUT_PER_TICK := 512           # 待实测：按单会话维度，不是全局

func on_message(msg: Dictionary) -> void:
    if not multiplayer.is_server():
        return                              # ✅ 过滤与扇出都由服务端做
    var filtered := FilterServer.check(msg.text)
    _store_for_evidence(msg, filtered)
```
