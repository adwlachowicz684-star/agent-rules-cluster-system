# 06 空间音频（音频域）

> **前置**：01 总线已建，02 播放器选型已定
> **本步交付**：世界里的声音有位置感——能听出左右、远近、遮挡
> **对应**：做法 `howto/godot/audio-advanced.md` `input-audio.md` · 审核 `audit/godot/audio-advanced.md`

## 0. 交付物定义

做完这一步，应该能**当场演示**：

1. 移动监听器，**能听出左右与远近变化**
2. ⚠ 3D 播放器**已 `add_child` 进树**（否则只是普通播放器）
3. 衰减参数已实测（不是抄默认值）
4. 2D 项目用 `AudioStreamPlayer2D`，3D 用 3D
5. ⚠ 空间音效也挂了正确的总线

**产出物**（下游按名字对接）：

```text
play_at_3d(stream, pos) / play_at_2d(stream, pos)
max_distance / attenuation_model / panning_strength 实测值
```

## 2. 工序

### Step 1　⛔ 不 add_child 就没有空间效果　`[audio/06#S1]`

【读】`howto/godot/audio-advanced.md#2. 播放器节点选型` 的 ⚠

【做】⚠ 3D 音效节点**必须在场景树里**才有空间效果。
`AudioStreamPlayer3D.new()` 不 `add_child` 就是普通播放器。

```gdscript
var p := AudioStreamPlayer3D.new()
p.stream = preload("res://sfx/footstep.ogg")
p.max_distance = 20.0
p.attenuation_model = AudioStreamPlayer3D.ATTENUATION_INVERSE_DISTANCE
add_child(p)          # ⚠ 缺这行就没有 3D 效果
p.play()
```

⛔ 症状是"3D 音效没方向感但不报错"——
你会以为是衰减参数没调对，然后花时间调 `max_distance`，
其实根本问题是节点没入树。

【产出】所有空间播放器都 add_child 了

【判据】⚠ 绕过音源背后，**能听出左右互换**

【审】`audit/godot/audio-advanced.md#5`

### Step 2　衰减参数实测　`[audio/06#S2]`

【读】`howto/godot/audio-advanced.md#2. 播放器节点选型`

【做】⚠ `max_distance` 决定"多远完全听不见"。
ⓘ 它必须和**你的场景尺度**匹配——
一个 100 米长的关卡用默认 20，走到一半就没声了。

三种衰减模型：
- `ATTENUATION_INVERSE_DISTANCE` —— 默认，物理感强
- `ATTENUATION_INVERSE_SQUARE_DISTANCE` —— 衰减更快，更真实
- `ATTENUATION_LOGARITHMIC` —— 衰减更缓

✅ 戴上耳机在关卡最远处实测，⛔ 不要抄默认值。

【产出】`max_distance` 与衰减模型是实测值

【判据】⚠ 站在关卡最远的可听位置，**刚好能听见**；再远就听不见

【审】`audit/godot/audio-advanced.md#20`

### Step 3　2D 位置音效　`[audio/06#S3]`

【读】`howto/godot/input-audio.md#2. 音频` 的「2D 位置音效」

【做】
```gdscript
func play_at(stream: AudioStream, world_pos: Vector2) -> void:
    _sfx.global_position = world_pos   # 与监听器（Camera2D）的距离决定衰减
    _sfx.stream = stream
    _sfx.play()
```

⚠ `AudioStreamPlayer2D` 的衰减是**相对监听器**（通常是 Camera2D）算的，
⛔ 不是相对玩家节点——若相机与玩家分离（过场、分屏），声像会不对。

可配属性：`max_distance` / `attenuation` / `panning_strength`。

【产出】2D 音效位置正确

【判据】⚠ 音源在屏幕左侧时，**左耳更响**

【审】`audit/godot/input-audio.md#9`

### Step 4　声像强度别过头　`[audio/06#S4]`

【读】`howto/godot/input-audio.md#2. 音频` 的「2D 位置音效」

【做】⚠ `panning_strength` 调太大会让声音**完全跑到一侧耳朵**，
听感突兀（尤其戴耳机时）。

ⓘ 默认值通常是合理的起点；
只在"想要强方向感"（如潜行游戏的脚步方位）时才调高。

【产出】声像强度已实测

【判据】⚠ 从音源左侧走到右侧，**声像平滑过渡**（⛔ 不是突然跳边）

【审】`audit/godot/input-audio.md#8`

### Step 5　空间音效的并发与遮挡　`[audio/06#S5]`

【读】`howto/godot/audio-advanced.md#3. 音效池`

【做】ⓘ 空间音效**不能用池**（池化播放器没有位置）。
每个空间音效要独立节点 + 独立位置。

⚠ 所以密集的空间音效（一群敌人的脚步）**最容易爆**——
✅ 要有并发上限（见 04 S6），
超出距离/超出数量的直接丢弃。

ⓘ 遮挡（墙后声音闷）Godot 没有内置 occlusion，
要自己做射线检测 + 调音量/低通。

【产出】空间音效有并发上限

【判据】⚠ 20 个敌人围着你，**不糊不爆**

【审】`audit/godot/audio-advanced.md#21`

### Step 6　总线归属　`[audio/06#S6]`

【读】`howto/godot/audio-advanced.md#0. 总线是混音链，不是分组标签`

【做】⚠ 空间播放器也要显式设 `bus`。
⛔ 忘了设就绕过总线链，音量/静音控制全部失效。

ⓘ 混响这类效果放在 SFX 总线上时，
所有空间音效**共享同一个混响**——
这意味着室内/室外需要**不同总线**（或用 send 切换），
⛔ 不能靠单个音源的效果实例。

【产出】空间音效挂了正确总线

【判据】⚠ 静音 SFX 总线，**空间音效也静音**

【审】`audit/godot/audio-advanced.md#12`

## 3. 参考实现

```gdscript
const MAX_SPATIAL := 16        # 并发空间音效上限，待实测

func play_at_3d(stream: AudioStream, pos: Vector3) -> void:
    if _spatial_count >= MAX_SPATIAL:
        return                                  # ⚠ 并发上限，见 04 S6
    var p := AudioStreamPlayer3D.new()
    p.stream = stream
    p.bus = AudioBuses.BUS_SFX                  # ⚠ 显式指定
    p.max_distance = 30.0                       # ⚠ 实测值，与场景尺度匹配
    p.attenuation_model = AudioStreamPlayer3D.ATTENUATION_INVERSE_DISTANCE
    add_child(p)                                # ⚠ 缺这行没 3D
    p.global_position = pos
    p.play()
    _spatial_count += 1
    p.finished.connect(func():
        _spatial_count -= 1
        p.queue_free())                         # ⚠ 必须释放
```

⚠ 注意这里 `finished` 回调里做了两件事：
减计数 **和** 释放。⛔ 只做一件会导致计数泄漏或节点堆积。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 3D 音效没方向感 | 没 add_child | S1 |
| 走远了突然没声 | max_distance 太小 | S2 |
| 声像突然跳边 | panning_strength 过大 | S4 |
| 一群敌人时糊成噪音 | 空间音效无并发上限 | S5 |
| 空间音效不受音量控制 | 没设 bus | S6 |
| 节点越攒越多 | finished 没释放 | S1 |
