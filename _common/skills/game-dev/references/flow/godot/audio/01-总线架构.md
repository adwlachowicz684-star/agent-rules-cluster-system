# 01 总线架构（音频域）

> **前置**：已列出本项目有哪些声音类别（见 `00-域流程总览.md` 第 0 节）
> **本步交付**：一条混音链（不是分组标签）——每类声音有独立入口，效果挂在链上
> **对应**：做法 `howto/godot/audio-advanced.md` · 审核 `audit/godot/audio-advanced.md`

## 0. 交付物定义

⚠ **一句话**：总线是**混音链**，不是分组标签。

```
Master    ← 最终输出、全局静音/音量入口
├── Music ← BGM（可放侧链压缩、EQ）
├── SFX   ← 战斗、环境、脚步（可放混响）
├── UI    ← 按钮、提示（**独立**，见下）
└── Voice ← 语音/对话（可懂度优先）
```

做完这一步，应该能**当场演示**：

1. 底部面板 Audio 里有上面这几条总线
2. ⚠ **UI 音效不走 Master**
3. 每条子总线的 send 指向 Master（不是各自孤立）
4. ⚠ 混响/压缩这类效果**挂在总线上**，不是每个音源各挂一个
5. 代码里取总线索引时**判了 -1**

**产出物**（下游按名字对接）：

```text
总线名常量（&"Music" &"SFX" &"UI" &"Voice"）
_setup_buses() 或 AudioBusLayout 资源
```

- [ ] ⚠ 已确认 UI 要**独立**（玩家调低 Master 时想保留语音或反之）

## 2. 工序

### Step 1　建总线　`[audio/01#S1]`

【读】`howto/godot/audio-advanced.md#0. 总线是混音链，不是分组标签`

【做】
```gdscript
func setup_buses() -> void:
    for name in ["Music", "SFX", "UI", "Voice"]:
        AudioServer.add_bus()
        AudioServer.set_bus_name(AudioServer.get_bus_count() - 1, name)
```

⚠ `add_bus()` 新增的总线**默认 send 到 Master**——
要改归属得显式 `AudioServer.set_bus_send(idx, &"目标总线名")`。

ⓘ 总线也能存成 `AudioBusLayout` 资源（`.tres`），
用 `AudioServer.set_bus_layout(layout)` 整体载入，比逐条 add 更可维护。

【产出】总线已建好并命名

【判据】⚠ 打印 `AudioServer.get_bus_count()` 与每条名字，与设计一致

【审】`audit/godot/audio-advanced.md#3`（UI 音效走 Master → 耦合了静音）

### Step 2　⚠ UI 总线必须独立　`[audio/01#S2]`

【读】`howto/godot/audio-advanced.md#0. 总线是混音链，不是分组标签` 的 ⚠

【做】⚠ **UI 音效不要走 Master**。
它把"全部静音"和"界面反馈静音"耦合了——
玩家调低 Master 想保留语音时，按钮声也没了；
暂停时想保留 UI 反馈也做不到。

【产出】UI 有独立总线

【判据】⚠ 静音 Master 后，UI 总线**仍能单独出声**

【审】`audit/godot/audio-advanced.md#3`

### Step 3　效果挂在总线上　`[audio/01#S3]`

【读】`howto/godot/audio-advanced.md#10. headless 与总线 API 细节` 的 ⚠ 末尾

【做】⚠ 混响 / 压缩 / EQ 放在**总线上**，不是每个音源各挂一个。

总线是混音链，效果在链上是**共享的一份**；
挂在音源上则是 N 份实例——CPU 与听感都不对
（N 个独立混响叠加会糊成一片）。

ⓘ 典型配置：SFX 挂混响（洞穴/室内感）、Music 挂 EQ、
Voice 挂压缩（保证可懂度）、Master 挂限制器（防爆音）。

【产出】效果挂总线，音源节点上没有效果实例

【判据】⚠ 全项目搜索挂在播放器上的效果实例，**为 0**

【审】`audit/godot/audio-advanced.md#12`（混响放在每个音源上 → 应按类别放总线上）

### Step 4　get_bus_index 返回 -1 要判　`[audio/01#S4]`

【读】`howto/godot/audio-advanced.md#10. headless 与总线 API 细节`

【做】⚠ **`AudioServer.get_bus_index(name)` 不存在时返回 -1**，
官方原文就是 "Returns -1 if no bus with the specified name exist"。

⛔ 不判 -1 的话，总线名写错时会拿到 -1，
后续 `set_bus_volume_db(-1, ...)` 静默失败——
症状是"音量调不动但不报错"，排查很痛苦。

```gdscript
var idx := AudioServer.get_bus_index(bus_name)
if idx < 0:
    push_error("总线不存在: %s" % bus_name)
    return
```

【产出】所有取索引处都判了 -1

【判据】⚠ 故意传一个不存在的总线名，**报错且不含糊**

【审】`audit/godot/audio-advanced.md#13`

### Step 5　总线名用 StringName　`[audio/01#S5]`

【读】`howto/godot/input-audio.md#2. 音频` 的「AudioServer 总线」

【做】ⓘ 播放器节点的 `bus` 属性与 `get_bus_index` 都用字符串名。
⚠ 各处手写 `"SFX"` 拼错不会报错，只会静默走 Master。

✅ 集中成常量，或至少用 `&"SFX"`（`StringName`）。

【产出】总线名集中在常量里，无散落字面量

【判据】⚠ 全项目搜索字符串字面量总线名，**为 0**

【审】`audit/godot/audio-advanced.md#13`

## 3. 参考实现

```gdscript
# audio_buses.gd
const BUS_MASTER := &"Master"
const BUS_MUSIC  := &"Music"
const BUS_SFX    := &"SFX"
const BUS_UI     := &"UI"      # ⚠ 独立，不走 Master
const BUS_VOICE  := &"Voice"

static func index(name: StringName) -> int:
    var idx := AudioServer.get_bus_index(name)
    if idx < 0:
        push_error("总线不存在: %s" % name)
    return idx

static func set_volume(name: StringName, linear: float) -> void:
    var idx := index(name)
    if idx < 0:
        return
    AudioServer.set_bus_volume_linear(idx, linear)   # ⚠ 比手动转 dB 更不易错
    AudioServer.set_bus_mute(idx, linear <= 0.0)
```

⚠ `set_bus_volume_linear()` 官方说明等价于
`set_bus_volume_db(linear_to_db(v))`——**比自己转更不容易错**，优先用它。

## 5. 常见返工

| 症状 | 原因 | 回到 |
|---|---|---|
| 想只静音 BGM 做不到 | 全走 Master | S1 S2 |
| 混响糊成一片 | 效果挂在音源上 | S3 |
| 音量调不动但不报错 | 没判 -1 | S4 |
| 某类声音悄悄走 Master | 总线名拼错 | S5 |
| 暂停时按钮没声 | UI 走了会被暂停的总线 | S2 |
