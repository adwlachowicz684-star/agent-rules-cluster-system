## 2. 工序

### Step 1　三种播放器怎么选　`[audio/02#S1]`

【读】`howto/godot/audio-advanced.md#2. 播放器节点选型`

【做】

| 节点 | 用途 |
|---|---|
| `AudioStreamPlayer` | 非空间音效（UI、BGM） |
| `AudioStreamPlayer2D` | 2D 空间音效（按屏幕位置衰减/声像） |
| `AudioStreamPlayer3D` | 3D 空间音效（衰减模型、多普勒） |

ⓘ 判断标准很简单：**这个声音有"位置"吗？**
爆炸、脚步、NPC 说话 → 有；按钮、菜单 BGM → 没有。

【产出】每种声音都定了节点类型

【判据】⚠ 随机抽 5 个声音，都能说出"为什么用这个节点"

【审】`audit/godot/audio-advanced.md` 第 5 条（3D 出来就有 3D 效果 → 必须 add_child）

### Step 2　⚠ 3D 节点必须在场景树里　`[audio/02#S2]`

【读】`howto/godot/audio-advanced.md#2. 播放器节点选型` 的 ⚠

【做】⚠ 3D 音效节点**必须在场景树里**才有空间效果。
`AudioStreamPlayer3D.new()` 不 `add_child` 就是普通播放器。

⛔ 症状是"3D 音效没方向感但不报错"——
你会以为是衰减参数没调对，然后花时间调 `max_distance`，
其实根本问题是节点没入树。

```gdscript
var p := AudioStreamPlayer3D.new()
p.stream = preload("res://sfx/footstep.ogg")
p.max_distance = 20.0
p.attenuation_model = AudioStreamPlayer3D.ATTENUATION_INVERSE_DISTANCE
add_child(p)          # ⚠ 缺这行就没有 3D 效果
p.play()
```

【产出】所有空间播放器都 add_child 了

【判据】⚠ 移动监听器，**能听出左右/远近变化**

【审】`audit/godot/audio-advanced.md` 第 5 条

### Step 3　临时播放器必须释放　`[audio/02#S3]`

【读】`howto/godot/input-audio.md#2. 音频` 的「音效：用池，不要每次 new」

【做】
```gdscript
func play_sfx(stream: AudioStream, volume_db: float = 0.0) -> void:
    var p := AudioStreamPlayer.new()
    p.stream = stream
    p.bus = "SFX"
    p.volume_db = volume_db
    add_child(p)
    p.play()
    p.finished.connect(p.queue_free)   # ⚠ 关键
```

⚠ 动态 `new AudioStreamPlayer` 后**必须 `queue_free()`**（审查 GD52，P0）。
`finished.connect(p.queue_free)` 是最简写法。

⛔ 不释放的话每个音效都是节点，**越攒越多**——
跑十分钟场景树里几千个节点，且不会自己报错。

【产出】动态创建的播放器都有释放路径

【判据】⚠ 连播 100 个音效后，场景树节点数**回到基准**

【审】`audit/godot/input-audio.md`（P0 条目）

### Step 4　文件格式　`[audio/02#S4]`

【读】`howto/godot/audio-advanced.md#6. 文件格式`

【做】

| 格式 | 取舍 |
|---|---|
| **WAV** | 无压缩、无延迟、体积大。**短音效用它** |
| **OGG** | 有压缩、体积小、需解码。**BGM 与长音用它** |
| **MP3** | 许可与循环点不友好，一般不选 |

⚠ **短音效（枪声、脚步、UI）用 WAV** ——
OGG 的解码延迟会让密集触发的音效**迟到**。

⚠ **MP3 因编码特性几乎无法无缝循环**（有 encoder delay，循环处会咔哒），
循环 BGM 用 OGG。

【产出】每种音频文件的格式已定

【判据】⚠ 密集触发 20 次短音效，**无迟到感**；
　　　BGM 循环处**无咔哒声**

【审】`audit/godot/audio-advanced.md` 第 9/10 条

### Step 5　播放器挂到正确总线　`[audio/02#S5]`

【读】`howto/godot/audio-advanced.md#0. 总线是混音链，不是分组标签`

【做】⚠ 播放器节点的 `bus` 默认是 `"Master"`。
⛔ 忘了设，声音就绕过你精心设计的总线链。

ⓘ 特别是**池化播放器**——建池时批量设一次，
⛔ 不是每次 play 时设（容易漏）。

【产出】所有播放器的 bus 都显式设了

【判据】⚠ 打印每个播放器的 `bus`，与设计一致（⛔ 没有 Master）

【审】`audit/godot/audio-advanced.md`

## 3. 参考实现

```gdscript
# autoload/audio_manager.gd 骨架
extends Node

var _bgm: AudioStreamPlayer

func _ready() -> void:
    _bgm = AudioStreamPlayer.new()
    _bgm.bus = AudioBuses.BUS_MUSIC      # ⚠ 显式指定
    add_child(_bgm)

func play_sfx(stream: AudioStream, volume_db: float = 0.0) -> void:
    var p := AudioStreamPlayer.new()
    p.stream = stream
    p.bus = AudioBuses.BUS_SFX
    p.volume_db = volume_db
    add_child(p)
    p.play()
    p.finished.connect(p.queue_free)     # ⚠ 必须释放

func play_at_3d(stream: AudioStream, pos: Vector3) -> void:
    var p := AudioStreamPlayer3D.new()
    p.stream = stream
    p.bus = AudioBuses.BUS_SFX
    p.max_distance = 20.0
    p.attenuation_model = AudioStreamPlayer3D.ATTENUATION_INVERSE_DISTANCE
    add_child(p)                          # ⚠ 缺这行没 3D
    p.global_position = pos
    p.play()
    p.finished.connect(p.queue_free)
```

⚠ `play_sfx` 这种"每次 new"的写法只适合**低频音效**。
高频的（脚步、枪声、连击）必须走 04 的池或多声部，否则既卡又爆音。
