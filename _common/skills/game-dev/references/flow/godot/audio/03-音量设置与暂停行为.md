# 03 音量、设置与暂停行为（音频域）

> **前置**：01 总线已建，02 播放已通
> **本步交付**：音量滑块线性可调、设置可持久化、暂停/慢动作下行为正确
> **对应**：做法 `howto/godot/audio-advanced.md` `input-audio.md` `timescale.md` · 审核 `audit/godot/audio-advanced.md`

## 0. 交付物定义

⚠ **本步有两个"直觉完全错误"的点**，是音频域最高频的事故源：

1. **音量是分贝不是线性** —— slider 传 0.5 听起来几乎没声
2. **静音是 -80 dB，不是 0 dB** —— 0 dB 是原始音量

做完这一步，应该能**当场演示**：

1. 滑块拖到一半，**听起来是一半**
2. 拖到 0 是**真的静音**
3. 设置能存能读（重开游戏保持）
4. ⚠ 暂停时 UI 音仍响、战斗音停
5. ⚠ 慢动作时音频**跟着变慢**（`playback_speed_scale`）

**产出物**（下游按名字对接）：

```text
set_bus_volume(bus, linear) -> void     含 linear_to_db 转换
_on_pause() / _on_resume()
AudioServer.playback_speed_scale 的联动
```

## 2. 工序

### Step 1　⚠ 音量是分贝不是线性　`[audio/03#S1]`

【读】`howto/godot/audio-advanced.md#1. 音量：dB 不是线性`

【做】
```gdscript
# 错：直接拿 0–1 的 slider 值当音量
AudioServer.set_bus_volume_db(idx, slider.value)   # 完全不对

# 对：先转 dB
AudioServer.set_bus_volume_db(idx, linear_to_db(slider.value))
```

⚠ **`set_bus_volume_db` 接受的是分贝，不是 0–1**。
直接把 slider 的 `0.0–1.0` 传进去，音量曲线会完全不对
（0.5 听起来不是一半，而是**几乎听不见**）。

ⓘ 也可以用 `AudioServer.set_bus_volume_linear(idx, v)`——
官方说明它等价于 `set_bus_volume_db(linear_to_db(v))`，**更不易错**。

【产出】所有音量设置走转换（或 `_linear` 版本）

【判据】⚠ 滑块 50% 时，听感**约为一半**（⛔ 不是几乎无声）

【审】`audit/godot/audio-advanced.md#1`（音量传 0–1 → 是分贝，要 linear_to_db） `audit/godot/input-audio.md#4`

### Step 2　⚠ 静音是 -80 dB 不是 0 dB　`[audio/03#S2]`

【读】`howto/godot/audio-advanced.md#1. 音量：dB 不是线性` 的 ⚠

【做】⚠ 音量 0 要用**极小值或静音**，不能用 `0 dB`
（那是原始音量，不是无声）。

```gdscript
AudioServer.set_bus_mute(idx, linear <= 0.0)
# 或淡出时 tween 到 -80.0
```

⛔ 把滑块拖到 0 后设 `volume_db = 0`，结果是**音量变成最大**——
这是"拖到最小反而爆响"的来源。

【产出】值为 0 时走 mute 或 -80

【判据】⚠ 滑块拖到 0，**完全无声**（⛔ 不是变最大）

【审】`audit/godot/audio-advanced.md#2`（0 dB 是静音 → 错，0 dB 是原始音量）

### Step 3　设置持久化　`[audio/03#S3]`

【读】`flow/godot/save/`

【做】ⓘ 音量设置属于"设置"而非"存档"，通常单独存。
⚠ 要在**退出前**保存（或每次改动即存），
⛔ 不能只在正常退出流程里存——崩溃/强杀会丢失。

【产出】音量设置能存能读

【判据】⚠ 改音量 → 强杀进程 → 重开，**设置保持**

【审】`audit/godot/audio-advanced.md#25`

### Step 4　⚠ 暂停时 UI 音要继续　`[audio/03#S4]`

【读】`howto/godot/audio-advanced.md#5. 暂停时的音频`

【做】
```gdscript
func _on_pause() -> void:
    get_tree().paused = true
```

⚠ `get_tree().paused = true` 会停掉默认 process_mode 的节点。
UI 反馈音想要继续，播放器要设：

```gdscript
_ui_player.process_mode = PROCESS_MODE_ALWAYS
```

⚠ **用 `bus_mute` 暂停音频 ≠ 暂停播放节点** ——
播放仍在继续，恢复后声音从"中间"接上，不是重新同步。
⛔ 音乐和音效都会错位。

【产出】暂停时 UI 音仍响，战斗/BGM 停

【判据】⚠ 暂停菜单里点按钮**有音**，且背景战斗音**停了**

【审】`audit/godot/audio-advanced.md#7` `audit/godot/audio-advanced.md#8`

### Step 5　⚠ 慢动作要单独设音频速度　`[audio/03#S5]`

【读】`howto/godot/audio-advanced.md#9. 全局播放速度（与 time_scale 无关）`

【做】
```gdscript
AudioServer.playback_speed_scale = 0.5   # 音频放慢到一半
```

⚠ **官方文档明确：`playback_speed_scale` 与 `Engine.time_scale` 相互独立。**
改 `time_scale` 做慢动作时，**音频不会跟着变慢**，要单独设这个。

ⓘ 这也正是"子弹时间"里音频不同步的根因——
只改了 `time_scale` 就以为音频会跟着走。

⚠ 恢复时要**归位**，⛔ 别忘了（否则慢动作结束后声音一直是慢的）。

【产出】慢动作时音频同步变慢，结束能恢复

【判据】⚠ 触发子弹时间，**能听出音频变慢**；结束后恢复正常

【审】`audit/godot/audio-advanced.md#24`

### Step 6　爆音与限制器　`[audio/03#S6]`

【读】`howto/godot/audio-advanced.md#10. headless 与总线 API 细节`

【做】⚠ 大量音效叠加会**超过 0 dBFS 导致削波爆音**。
✅ 在 Master 上挂**限制器**（Limiter）作为最后一道保险。

ⓘ 这不是"听起来更好"的优化，是防止硬件/耳朵受损的兜底。

【产出】Master 总线有限制器

【判据】⚠ 同时触发 20 个音效，**无爆音**（波形不削顶）

【审】`audit/godot/audio-advanced.md#23`

## 3. 参考实现

```gdscript
# volume_settings.gd
const MUTE_DB := -80.0

func set_bus_volume(bus_name: StringName, linear: float) -> void:
    var idx := AudioServer.get_bus_index(bus_name)
    if idx < 0:                                   # ⚠ 判 -1
        push_error("总线不存在: %s" % bus_name)
        return
    AudioServer.set_bus_volume_linear(idx, linear)  # ⚠ 比手动转 dB 更不易错
    AudioServer.set_bus_mute(idx, linear <= 0.0)    # ⚠ 0 要 mute，不是 0 dB
    _save(bus_name, linear)

func _on_pause() -> void:
    get_tree().paused = true
    # ⚠ UI 播放器已在建池时设了 PROCESS_MODE_ALWAYS

func _on_slowmo(scale: float) -> void:
    Engine.time_scale = scale
    AudioServer.playback_speed_scale = scale   # ⚠ 独立，必须单独设
```

⚠ 注意 `set_bus_volume_linear` 与 `set_bus_mute` 要**一起用**：
linear 很小（如 0.01）时虽然接近无声，但不如直接 mute 干净。
