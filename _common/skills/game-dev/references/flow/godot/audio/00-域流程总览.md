# 音频域 — 流程总览

> **本域交付**：一套"玩家听得清、不炸音、不漏音、暂停时行为正确"的音频系统。
> **对应**：做法 `howto/godot/audio-advanced.md` `input-audio.md`
> 　　　审核 `audit/godot/audio-advanced.md` `input-audio.md`

---

## 0. 先定做什么（⛔ 没写这三行不许开工）

⚠ 同在音频域，"给按钮加个点击音"和"做一套含动态音乐的空间音频系统"
是**两条不同流程**——后者是前者的几十倍工作量。

```text
做什么：<哪些声音、要不要空间感、要不要动态音乐、要不要设置面板>
不做什么：⛔ <至少两条>
验收标准：<可观测的>
```

示例（本次只做基础音效）：

```text
做什么：UI 音效 + 战斗音效，非空间，走 SFX 总线
不做什么：⛔ 不做动态音乐（本次只有一首 BGM）
         ⛔ 不做 3D 空间音频（2D 横版，用 2D 播放器即可）
验收标准：连点 20 次不丢音；暂停时 UI 音仍响、战斗音停；
         音量滑块拖到一半听起来是一半
```

### 然后挑功能点

| 本次要做的 | 需要的功能点 |
|---|---|
| 只是"能出声" | 01 → 02 → 07 |
| 有音量设置面板 | 01 → 02 → 03 → 07 |
| 有大量/密集音效（脚步、枪声） | 01 → 02 → 04 → 07 |
| 要 BGM 切换 / 动态音乐 | 01 → 02 → 05 → 07 |
| 要位置感（2D/3D 世界音效） | 01 → 02 → 06 → 07 |
| 要暂停/慢动作下行为正确 | 01 → 02 → 03 → 07（07 的 S3 必做） |

⛔ **不要全做。** 三个音效的项目不需要音效池。

## 1. 功能点拆解与依赖顺序

```text
01 总线架构 ── 02 播放与选型 ──┬── 03 音量与设置面板 ──┐
                               ├── 04 密集音效与池 ─────┼── 07 验收
                               ├── 05 BGM 与动态音乐 ───┤
                               └── 06 空间音频 ─────────┘
```

| # | 功能点 | 前置 | 为什么这个顺序 |
|---|---|---|---|
| 01 | 总线架构 | 无 | ⚠ 总线是混音链，后面一切音量的入口；定错要全改 |
| 02 | 播放方式与节点选型 | 01 | 先知道往哪条总线送，再决定用什么节点放 |
| 03 | 音量、设置与暂停行为 | 01 02 | ⚠ dB 不是线性——这是"滑块拖一半听着几乎没声"的根源 |
| 04 | 密集音效与池 | 01 02 | 池的播放器要指定总线，先有总线 |
| 05 | BGM 与动态音乐 | 01 02 | 同上，且淡入淡出操纵的就是总线/播放器音量 |
| 06 | 空间音频 | 01 02 | 空间播放器也要挂总线 |
| 07 | 音频验收 | 01–06 | ⚠ 含**必须**戴耳机做的实测 |

## 2. ⚠ 五个最容易做反的顺序

**① 先加音效后定总线。**
所有音效默认走 Master，等要加"只静音 BGM"时才发现全耦合在一起。
⛔ 回头改总线要动每一个音源。

**② 把 slider 的 0–1 直接当音量用。**
⚠ `set_bus_volume_db` 接受的是**分贝**。直接传 0.5，
听起来**不是一半，而是几乎听不见**（分贝是对数）。

**③ 密集音效先写出来再优化。**
同一个 `AudioStreamPlayer` 反复 `play()` 会**打断自己**，
密集触发时听感是"卡住"。等做完了才发现整个播放层要换成池。

**④ 用 `bus_mute` 做暂停。**
⚠ **播放仍在继续**，恢复后声音从"中间"接上，不是重新同步。
音乐和音效都错位。

**⑤ 只做慢动作不做音频速度。**
⚠ `AudioServer.playback_speed_scale` 与 `Engine.time_scale` **相互独立**。
只改 `time_scale`，画面慢了声音不变——这是"子弹时间不像子弹时间"的根因。

## 3. 每做完一个功能点必做

1. 跑一遍该步的**验收清单**，逐条打勾
2. ⛔ 有没过的，不进下一步
3. 过该步【审】列的 audit 条目
4. 过功能点末尾的「整体审核」节
5. ⚠ 实测参数已回填，⛔ 不留示例值
6. ⚠ **本域额外一条**：**戴耳机**实测（外放听不出声像与细节）
