# 功能点总索引（Godot 4.x）

> 用法：找到你的域 → **有细化流程就打开 `00-域流程总览.md`**，
> **没有就套 _骨架.md** → 按依赖顺序做功能点。
> 每个功能点做完验收通过，才进下一个。

⚠ **⛔ 不允许"没有流程就凭记忆开工"。** 110 个域里目前只有 2 个有细化流程，
其余 108 个一律套 _骨架.md（通用六步：定边界 → 定契约 →
最小闭环 → 接外部 → 异常边界 → 验收）。

ⓘ 结构框架总纲见 [`../structure.md`](../structure.md)：三层命名、调度模型、
流程与做法的嵌合协议、跨流程组合模型、迁移映射。
