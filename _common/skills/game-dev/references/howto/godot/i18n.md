# Godot 4.x 本地化技术实现

**本文件只放技术实现**（怎么接、怎么切、怎么打包）。
翻译流程、文案管理、术语表、QA 流程 → 见独立 skill `localization`（当前为占位，待填充）。

## 1. 引擎侧机制

### 核心 API

```gdscript
tr("KEY")                      # 翻译当前 locale 下的文本
tr_n("item", "items", count)   # 复数形式
TranslationServer.get_locale()          # 当前语言，如 "zh_CN"
TranslationServer.set_locale("en")      # 切换并全局生效
TranslationServer.get_loaded_locales()  # 已加载的语言列表
OS.get_locale()                         # 系统语言（启动时自动应用）
OS.get_locale_language()                # 只要语言部分，如 "zh"
```

⚠ `OS.get_locale()` 返回 `"zh_CN"` 这种**带地区**的格式，
而 TranslationServer 里可能只注册了 `"zh"`。启动时需要根据 loaded locales 做匹配。

### 设置与资源

1. 项目设置 → Localization → Translations → 添加 `.translation` 资源
2. 运行时加载：`TranslationServer.add_translation(res)`

**推荐用 CSV 工作流**：

```
keys,en,zh_CN,ja
GREETING,Hello,你好,こんにちは
ITEM_COUNT,"{n} item","{n} 个物品","{n} 個"
```

把 CSV 放进项目，Godot 会自动导入为 `.translation`（每个语言一个）。
改 CSV 后自动重新导入，不用手动重建资源。

⚠ CSV 第一列必须叫 `keys`，表头其它列是**语言代码**。

⚠ 翻译里 `{n}` 之类的占位符要在 `tr()` 之后手动替换，
引擎不会自动做格式化：

```gdscript
# 简单场景
label.text = tr("GREETING")

# 带变量
label.text = tr("ITEM_COUNT").replace("{n}", str(count))

# 复数用 tr_n（会按 locale 的复数规则选）
label.text = tr_n("item", "items", count) % count
```

## 2. 切换语言

```gdscript
# settings 里
func set_language(locale: String) -> void:
    TranslationServer.set_locale(locale)
    SaveManager.current.language = locale
    SaveManager.save_game()
```

⚠ `set_locale()` 会**立刻让所有 `tr()` 结果变化**，
但**已经赋值到 Label 上的文本不会自动更新** —— 需要：

```gdscript
# 方案一：切换后重载场景
func apply_language() -> void:
    get_tree().reload_current_scene()

# 方案二：所有 UI 在 _ready 里用 tr() 赋值，靠重载刷新（推荐）
# 方案三：集中一个 refresh_texts()，切换时遍历调用
```

**推荐方案二**：每个 UI 的 `_ready` 里统一 `label.text = tr("XXX")`，
切语言后 `reload_current_scene()`。最省心，也最不容易漏。

⚠ 不要在 `_process` 里调 `tr()` —— 每帧查表。只在需要时赋值。

## 3. 布局方向（RTL）

阿拉伯语、希伯来语等从右向左语言：

```gdscript
# 项目设置 gui/theme/... 或代码
control.layout_direction = Control.LAYOUT_DIRECTION_RTL
```

| 枚举 | 含义 |
|---|---|
| `LAYOUT_DIRECTION_INHERIT` | 继承父节点（默认） |
| `LAYOUT_DIRECTION_APPLICATION_LOCALE` | 跟随当前 locale |
| `LAYOUT_DIRECTION_LTR` | 强制左到右 |
| `LAYOUT_DIRECTION_RTL` | 强制右到左 |
| `LAYOUT_DIRECTION_LOCALE` | 跟随节点自己的 locale |

⚠ 用 `LAYOUT_DIRECTION_APPLICATION_LOCALE` 时，
容器（HBox/VBox）的子项顺序会**自动镜像**，但锚点不会 ——
UI 要用容器布局，别写死锚点像素。

## 4. 字体与缺字

多语言最常见的翻车点：中文在英文设备上显示成方块（豆腐块）。

```gdscript
# 给字体设置回退链
@export var main_font: Font
@export var cjk_font: Font

func _ready() -> void:
    main_font.fallbacks = [cjk_font]
```

⚠ `Font.fallbacks` 是 `Array[Font]`，按顺序回退。
应该设到 **Theme 的默认字体**上，全局生效：

```gdscript
func _ready() -> void:
    var theme := load("res://ui/theme.tres") as Theme
    var f := theme.default_font as Font
    f.fallbacks = [load("res://fonts/NotoSansSC.ttf")]
```

⚠ 字体文件体积：完整 CJK 字体 10MB+。大型项目要考虑**按需子集化**
或分语言包（不同 locale 加载不同字体）。

## 5. 文本溢出

不同语言长度差异很大（德语通常比英语长 30%+）。

```gdscript
# Label 开启自动换行
label.autowrap_mode = TextServer.AUTOWRAP_WORD_SMART
label.custom_minimum_size = Vector2(200, 0)   # 限宽，高度自适应
```

⚠ **不要给按钮设固定宽度**。用 `custom_minimum_size` 限最小，
让容器根据内容撑开。

⚠ 长文本要预留空间，或用 `TextServer` 的省略号模式。

## 6. 大型项目建议

如果你要做的是**大型项目**，这几件事早点做，后期改成本极高：

| 事项 | 建议 |
|---|---|
| **Key 命名规范** | 用 `模块.位置.含义`，如 `UI.MAIN.START_BTN`；不要用英文原文当 key（改文案时 key 要跟着改） |
| **只在入口 tr()** | 所有文本集中在一处（如 `Strings` 常量类或 UI 的 `_ready`），不要在逻辑里散落 `tr()` |
| **变量插值统一** | 统一用 `{n}` / `{name}` 格式，写个 helper，别各处手写 replace |
| **别翻译的东西** | 日志、存档 key、配置值、内部 ID —— 只翻译给玩家看的 |
| **伪翻译测试** | 早期用伪本地化（把所有文本前后加 `[XX]`）检查有没有漏翻和溢出 |
| **字体分语言包** | 大字体按 locale 动态加载，不全塞进首包 |

⚠ **存档里的文本不要存翻译后的结果**。存 key 或 ID，
否则切语言后旧存档显示的还是旧语言。

```gdscript
# 反例：存翻译结果
save.item_name = tr("ITEM_SWORD")

# 正例：存 ID，显示时才翻译
save.item_id = "sword"
# 显示时
label.text = tr("ITEM_%s" % save.item_id.to_upper())
```

## 7. ⛔ 加载顺序：先 add_translation 再 set_locale

官方对 `set_locale()` 的描述是**条件句**：

> *"If translations have been loaded beforehand for the new locale, they will be applied."*

⚠ 意思是：该语言的翻译若**尚未加载**，切过去也不会生效，⛔ **且不报错**。

```gdscript
# ⛔ 错：先切后加 —— 这一刀不生效，界面仍是旧语言
TranslationServer.set_locale("ja")
TranslationServer.add_translation(load("res://i18n/ja.translation"))

# ✅ 对：先加载，再切
TranslationServer.add_translation(load("res://i18n/ja.translation"))
TranslationServer.set_locale("ja")
```

ⓘ 项目设置里注册的翻译在引擎初始化时已加载，所以在 `_ready` 里 `set_locale()` 是安全的；
⛔ 运行时**动态下载**的语言包必须先 `add_translation()`。

⚠ `set_locale()` 还会把 locale **标准化**（官方例：`en-US` 会被匹配成 `en_US`）。

## 8. 伪本地化（引擎内置，不必自己造）

Godot 自带 `TranslationServer.pseudolocalize()`，
项目设置 → Internationalization → Pseudolocalization（需开 Advanced）可勾选。

| 选项 | 作用 | 能检出什么 |
|---|---|---|
| `replace_with_accents` | 字符换成带变音符的变体 | ⛔ **缺译**（没变音符的就没走 `tr()`）+ **字体缺 glyph** |
| `double_vowels` | 元音加倍 | 文本膨胀后溢出 |
| `expansion_ratio` | 用下划线按比例填充，官方称 **0.3 对大多数情况足够** | 更精确的溢出模拟 |
| `fake_bidi` | 伪造双向文本 | RTL 布局问题 |
| `override` | 全部替换成 `*` | 一眼找出**没本地化**的文本 |
| `skip_placeholders` | 跳过 `%s` / `%f` | 占位符被破坏的地方 |

⛔ **改配置不会自动刷新场景树。** 官方要求手动传播通知：

```gdscript
ProjectSettings.set_setting("internationalization/pseudolocalization/replace_with_accents", true)
ProjectSettings.set_setting("internationalization/pseudolocalization/expansion_ratio", 0.3)
TranslationServer.reload_pseudolocalization()
# ⛔ 少了下面这行，界面上什么都不变 —— 看起来像"开关没生效"
get_tree().root.propagate_notification(MainLoop.NOTIFICATION_TRANSLATION_CHANGED)
```

ⓘ `pseudolocalization_enabled` 可在运行时整体开关。

## 9. ⛔ 断行数据默认不进导出包

中文、日文这类**无空格语言**的断行依赖 ICU 的 break iterator 数据。

⚠ 官方：该数据**默认不包含在导出项目中**，需在项目设置 →
Internationalization → Locale 勾选 **Include Text Server Data**，代价约 **4 MB**。

⛔ 症状极具迷惑性：**编辑器里断行正常，导出后不换行或断错位置。**
排查方向极易被引到"容器尺寸算错了"上。

## 10. RTL 的边界：只镜像 Control，不镜像坐标系

官方列出 Godot 会自动做的事：镜像左右锚点与边距、交换文本左右对齐、
镜像容器内子控件顺序、镜像 Tree/ItemList 项顺序、镜像内部控件元素顺序。

⚠ 同时官方明确两点**不会**自动处理：

| 官方原话 | 含义 |
|---|---|
| *"Coordinate system is not mirrored"* | 坐标系不镜像——手写的坐标/拖拽/位移动画在 RTL 下**方向是反的** |
| *"Non-UI nodes (sprites, etc.) are not affected"* | Sprite2D、3D 节点等**不受影响**，要自己处理 |

⛔ 所以"设了 `layout_direction` 就完事"是错的：UI 容器会翻，手写坐标逻辑不会翻。

## 11. 结构化文本要单独指定 BiDi 覆盖

⚠ 官方：Unicode BiDi 算法**无法处理**文件名、URI、邮箱、正则、源码
这类带层级顺序的文本——路径与 URL 在 RTL 下会显示错乱。

需设 `structured_text_bidi_override`，对路径类用 `"File"` 类型
（官方：把文本切成段、逐段应用 BiDi，从而保持目录顺序正确）。

## 12. 资源按 locale 重映射

图片与音频可按语言替换：项目设置 → Localization → Remaps。

⚠ 官方提示：带左右指向箭头的图标（如前进/后退按钮）在阿语/希伯来语下
**需要水平翻转**，其余图标可保持不变。

## 13. ⛔ 测试用的 Test 属性会进版本控制

官方给了三种测翻译的方式，其中 `Test` 属性是**项目设置**：

> *"since this is a project setting, it will show up in version control when it is set to a non-empty value. Therefore, it should be set back to an empty value before committing"*

⛔ 忘了清空就提交 → **整个团队跑起来都是测试语言**，
而每个人都会先怀疑自己的本地环境。

ⓘ 另两种不进仓库：`godot --language fr` 命令行参数、
编辑器 View → Preview Translation。

## 14. ⛔ 格式化必须在 tr() 之后

```gdscript
# ⛔ 错：先格式化再翻译，key 已经变了，永远查不到
label.text = tr("ITEM_COUNT_%d" % count)

# ✅ 对：先取翻译，再填值
label.text = tr("ITEM_COUNT") % count
```

⚠ CSV 工作流**不支持复数形式**；俄语、波兰语等复数规则复杂的语言要改用 PO。

> **反模式清单（不能怎么做，审核用）** → `audit/godot/i18n.md`
