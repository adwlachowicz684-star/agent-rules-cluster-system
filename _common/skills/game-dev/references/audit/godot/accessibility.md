# accessibility — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/accessibility.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 无障碍就是难度选项 | 是**信息通道**问题，完全不同 |
| 2 | 上线前补一下就行 | 后期补要**重做材质/UI/图标/本地化** |
| 3 | 引擎有 AccessKit 就够了 | 只是**底座** |
| 4 | 色盲模式加个滤镜 | 颜色即信息时**滤镜无效**，要形状冗余 |
| 5 | 红绿色盲很罕见 | 北欧裔男性约 **1/12** |
| 6 | 字幕就是对白 | 要含**环境音与非语音线索** |
| 7 | 字幕和音频大概同步 | 要**时间轴对齐** |
| 8 | 文字放大就解决可读性 | 要处理**布局溢出** |
| 9 | 闪烁不要太快就行 | 要**五维评估**（次数/面积/亮度/颜色/时长） |
| 10 | 无障碍选项放设置里 | 要**首次启动引导** |
| 11 | 设置重启生效可以接受 | 要**即时生效** |
| 12 | 单声道下混不重要 | 单耳听力玩家需要 |
| 13 | QTE 是玩法核心不能改 | 要有**替代路径** |
| 14 | 辅助瞄准是给新手的 | 也是**无障碍** |
| 15 | 屏幕阅读器默认就开着 | ⚠ **检测到才启用**；开发机没开就是关的 |
| 16 | 强制启用是多余选项 | 调试工具**未被识别**时必须用它，否则连不上 |
| 17 | 游戏音量能调屏幕阅读器 | ⛔ 它走系统音频，**不经过 Godot** |
| 18 | 控件自带可读名称 | 不填 `accessibility_name` 只会念"按钮" |
| 19 | 读的顺序=看到的顺序 | 是**节点树顺序**，容器重排后会不一致 |
| 20 | 色盲加滤镜就行 | ⛔ 颜色即信息时**滤镜无用**，要加冗余通道 |
| 21 | 三种色盲预设够了 | 色觉是**连续谱**，要提供强度调节 |
| 22 | 字幕时间绑游戏时间 | 要绑**音频时间轴**，否则暂停后还在滚 |
| 23 | 字幕只做对话 | 要含 `[脚步声]` 等非语音线索 |
| 24 | 字幕背景板可选 | ⚠ 明亮场景下**没有就看不清**，是刚需 |
| 25 | 替代路径更难没关系 | 奖励必须**等价**，否则等于没有 |
