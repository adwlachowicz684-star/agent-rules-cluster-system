# survival — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/survival.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 有 HealthComponent | **没有**，要自己定义 |
| 2 | 血量上限一个变量够 | 要**四层分开** |
| 3 | 存最终上限省事 | 会**超上限/比例错误**，要存输入 |
| 4 | 临时的血能留着 | modifier 过期要**重新夹取** |
| 5 | 死亡是个 bool | 是**四阶段状态机** |
| 6 | 死了还能存档 | 会把**死亡状态写进去** |
| 7 | 重生重置血量就行 | 还有 **Tween/Timer/信号/投射物** |
| 8 | Tween 会随节点销毁 | **不自动绑定节点** |
| 9 | 死亡等待用 await 随便写 | 会**跨场景泄漏** |
| 10 | 检查点=存档 | 只覆盖**重生事实** |
| 11 | 检查点只存坐标 | 还要朝向/任务/拾取/场景态 |
| 12 | 暂停时饥饿还掉 | 要按**时间源分层**决定 |
| 13 | 离线时间可以补 | 是**可作弊点**，待核对 |
| 14 | 超重直接改速度 | 要走**修饰器** |
| 15 | 耐力耗尽就没了 | 要考虑**力竭惩罚状态** |
| 16 | 死亡期间还能被打 | 要**禁止伤害** |
| 17 | 死亡时能拾取 | 要**禁止拾取** |
| 18 | 修饰器随便加减 | 会**撤销困难/来源泄漏** |
| 19 | 分层就够了 | 修饰器**无 source_id** 就无法精准撤销 |
| 20 | 按"值相等"删修饰器 | 两个 +10 会**删错**，玩家看不出但数值已错 |
| 21 | 先夹取再取比例 | ⚠ **顺序反了会丢血**，必须先取比例 |
| 22 | 每帧遍历查过期 | 到期**与帧不对齐**，会早/晚一帧 |
| 23 | 暂停时 buff 不倒计时 | 取决于时间源，要**与第 1 节一致** |
| 24 | `await tween.finished` 一定会返回 | ⚠ **被 kill 的 Tween 不发 finished**，会永久卡住 |
| 25 | 死亡动画播完才继续 | 必须有**超时兜底** |
| 26 | `Tween.new()` 能用 | 官方：手动创建的**无效** |
| 27 | 设了 PAUSABLE 就安全 | ⚠ **信号照常触发**，回调内要再判状态 |
| 28 | 暂停就什么都不跑了 | 官方：`_process` 不跑但**信号跑** |
| 29 | 力竭 = 禁止行动 | 是**进入状态**，要有明示与退出阈值 |
| 30 | 力竭退出条件 `>= 0` | 会**反复进出**（抽搐式喘气），阈值要 > 0 |
| 31 | 力竭态不用 source_id | 撤销时会**误删其它 buff** |
| 32 | 检查点存临时 buff | 死亡重来会把**临时变永久** |
| 33 | 先放角色再清场 | 会被**残留投射物连死** |
| 34 | 恢复中途就给控制权 | 出现"世界没恢复完就能操作"的撕裂 |
| 35 | 重复踩检查点覆盖 | ⚠ 会把玩家**拉回更早的点**，默认应忽略 |
| 36 | `process_always` 是个属性 | 不存在；正确枚举是 `PROCESS_MODE_PAUSABLE` |
