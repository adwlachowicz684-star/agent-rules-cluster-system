# timescale — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`flow/godot/timescale.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | time_scale 万能 | 音频**不受影响**，要单独处理 |
| 2 | time_scale 提高物理精度 | **不会**自动调整 tick |
| 3 | paused 就是全停 | **信号仍可触发** |
| 4 | UI 设 ALWAYS 就安全 | 还要 **Tween 忽略缩放**，两者正交 |
| 5 | Tween 能忽略缩放 | **4.7 才有**（4.6 要删掉或改写） |
| 6 | 停帧计时器会走 | 要 `ignore_time_scale=true`（呼应 hitstop） |
| 7 | 暂停=慢放 | 是**两件事**，混用出怪行为 |
| 8 | 倒带让物理倒流 | 要**冻结+快照** |
| 9 | 倒带不用禁物理 | 会**重新模拟** |
| 10 | 快照存位置够 | 还要旋转/速度/动画/标志 |
| 11 | 缓冲无限 | 要**环形**固定容量 |
| 12 | 能倒带别人的世界 | 一般**只能倒自己** |
| 13 | 玩家也该变慢 | 经典做法是**玩家不减速** |
| 14 | 慢动作瞬间切换 | 要**平滑过渡** |
| 15 | 恢复一定会执行 | 要设计成**必然发生** |
| 16 | 物理物体缩放 delta | 要缩放**力/速度** |
| 17 | 本地倍率替换全局 | 是**叠加** |
| 18 | 菜单动画慢点没关系 | 会变"黏"，玩家能察觉 |
