# narrative — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/narrative.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | Godot 不支持叙事系统 | 有 Resource/信号等底层能力，**要自己组织** |
| 2 | flag 写各 NPC 里方便 | 会**无法重构**，要集中 |
| 3 | flag 名随便起 | 会**撞车**，要三段式 |
| 4 | StringName 就是规范 | 只是**身份稳定**，不是命名规范 |
| 5 | 结局写 if elif | 要**判定表** |
| 6 | 结局靠数组顺序 | 要**显式优先级** |
| 7 | 优先级相同无所谓 | 要按**稳定 ID** 消除未定义行为 |
| 8 | 数据合法就能达成 | 还要查**可达性**（A 被 B 挡住） |
| 9 | 隐形前置省事 | 会**卡关**，要给替代提示 |
| 10 | 选项灰掉和不显示一样 | UI 不同，**逻辑都未满足** |
| 11 | 对话效果时机随便 | 要明确**选中时 vs 结束时** |
| 12 | 对话中途不能存档 | 要想好**从哪句恢复** |
| 13 | 存档压成一个字典 | 要**分层**保存 |
| 14 | 周目继承全都有 | 等级/装备/flag **各不相同** |
| 15 | 动态难度越明显越好 | 被察觉会**劝退** |
| 16 | 动态难度和成就不冲突 | **会冲突**，要提前想 |
| 17 | 旧字段不写没关系 | 迁移要**全部给默认值** |
| 18 | 检查点=关卡解锁源 | 都要从**单一数据源**来 |
| 19 | next_node_id 写错了没关系 | ⚠ 会**中途断对话**；要 ID 注册表 + 构建期校验 + 运行时报错 |
| 20 | 找不到下一句就结束对话 | ⛔ 把数据错误伪装成剧情结束；要**明确报错** |
| 21 | 对话状态存在 UI 节点里 | ⛔ UI 关闭/切场景就丢；要放 autoload DialogueManager |
| 22 | 打字机不需要跳过 | ⚠ 强制阅读是常见抱怨；要"立即完成本句"与"下一句"**两个动作** |
| 23 | OS.delay_msec 做逐字显示 | ⛔ **阻塞主线程**，整个游戏卡住；用 create_timer/Tween |
| 24 | 读档后对话效果会重放 | ⚠ 效果必须带**已执行标记**并持久化；记 node_id+effect_index |
| 25 | 选项条件在打开对话时求值一次 | ⚠ 对话中获得物品选项不更新；应**进入节点时求值** |
| 26 | 结局都合法就是都能达成 | ⛔ 还要查**可达性**；0 命中的结局是 bug |
| 27 | incompatible_with 单向写就行 | ⚠ 要**双向对称**，否则判定顺序影响结果 |
| 28 | 任务状态只有"未完成/已完成" | ⚠ 漏掉 可接取/已失败/已放弃 → 失败后永远接不了；要显式建模 |
| 29 | 对话文本直接写明文 | ⛔ 要存**翻译 key**；改台词不该改数据 |
| 30 | 翻译 key 用裸名 | ⚠ 不同 NPC 之间会**撞车且不报错**；要有命名空间 |
| 31 | 字幕时长写死 | ⚠ 长短句割裂且与语音对不上；有语音跟语音，无语音按字数 |
| 32 | 跳过语音就是停播放 | ⛔ 留下字幕在、下一句没触发的中间态；要**推进状态** |
