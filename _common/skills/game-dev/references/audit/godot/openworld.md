# openworld — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/openworld.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 异步加载就不卡 | `instantiate` 必须主线程，才是大头 |
| 2 | `load_threaded_get` 不阻塞 | 未完成时**会阻塞** |
| 3 | 一个半径够了 | 没有滞回会在边界**抖动加载** |
| 4 | 按数量分帧 | 要按**时间预算**切 |
| 5 | Godot 有内置地形 | 4.x **没有**，用 Terrain3D 或自写 |
| 6 | 双精度是勾选项 | 要重编译 editor + **所有**模板 |
| 7 | 8192 米内绝对安全 | 误差随 2 的幂成倍变，无固定阈值 |
| 8 | 原点重置只移相机 | 所有坐标消费方都要同步 |
| 9 | 大世界精度问题会早点暴露 | 小项目**测不出来** |
| 10 | 自动 LOD 按距离 | 按**屏幕覆盖度** |
| 11 | OBJ 也能自动生成 LOD | **不能**，glTF/blend/FBX 才行 |
| 12 | 高频加载用 queue_free | 要池化 |
| 13 | 存档存全量地形 | 存**增量** |
| 14 | 双精度后插件也变双精度 | 插件若无对应构建，仍按 32 位 |
