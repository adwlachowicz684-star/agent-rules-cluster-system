# stealth-ai — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/stealth-ai.md`
>
> 边界：本篇是**感知之上的玩法层**。感知机制本身见 `audit/godot/ai-perception.md`。

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 警戒就是一个 bool | 要拆成**证据等级**（知道多少）+ **行动状态**（正在做什么） |
| 2 | 两者一一对应 | 发现尸体可以是 `INVESTIGATE + CIRCUMSTANTIAL`，还没 `IDENTIFIED` |
| 3 | 降级可以直接回 UNSEEN | `HOSTILE → UNSEEN` 等于**抹掉玩家已付出的代价**；最低路径要过 EVASION→CALMING |
| 4 | 世界态势和个人怀疑一起降 | 哨站可长期封锁，**单个守卫**个人怀疑才按冷却降 |
| 5 | 怀疑度只做离散等级 | 玩家无法判断"少看 0.2 秒是否安全"；要**连续累积 + 离散解释** |
| 6 | 只做连续条 | 系统无限细分，守卫显得犹豫、频繁切换目标 |
| 7 | 单源怀疑度不封顶 | 一次爆炸/落地/误报就**直接进战斗**；要 `per_source_cap` |
| 8 | 被发现后开始衰减 | 衰减应从**证据失效**后开始，且取决于当前等级 |
| 9 | 搜查时怀疑度快速清零 | `SEARCH` 只停新增同来源贡献，不清零 |
| 10 | 旧变化也升温 | 要用"事件距今时间"寿命窗，超窗不再升温 |
| 11 | 搜查点 = 最后已知位置 | 守卫会在玩家曾站的点反复停留 |
| 12 | 搜查点 = 噪声源 | 忽略玩家沿走廊转移 |
| 13 | "走到即完成"搜索 | 变成巡逻式搜索，玩家无法预测或利用 |
| 14 | 只按时间终止搜索 | 大型空间过早放弃 |
| 15 | 只按"查完"终止 | 生成三个点就无事可做 |
| 16 | 搜查和巡逻共用"当前目标" | 存档/中断/行为树恢复会把两者混成一种行为 |
| 17 | 可见度是布尔（在不在阴影） | 要**连续 `exposure`** + 头/躯干/脚三点采样 |
| 18 | 只检测玩家原点 | 卡进墙时消失 |
| 19 | 只检测中心点 | 露出手指也被发现 |
| 20 | 射线不排除观察者 RID | 遮挡命中**自身骨骼** |
| 21 | 掩体让暴露度归零 | 玩家反复从同一墙角露出眼睛而守卫无反应；软掩体只**降低**视觉质量 |
| 22 | 蹲走完全无声 | 高度差与路线选择失去价值 |
| 23 | 声音能识别身份 | 听觉应可进搜查但**不识别身份**，与视觉证据分离 |
| 24 | 气味做成真实气体模拟 | 应是空间标记；**不能可视化就别加** |
| 25 | 伪装 = 换服装模型 | 核心是**身份与权限**（合法区域/动作/破绽） |
| 26 | 一个守卫识破 → 全图知道 | 要 `suspicion_per_observer`，**每个观察者独立** |
| 27 | 换装即时生效 | 要有"更换中"状态，否则成即时重置 |
| 28 | 视野锥只存在后台 | 玩家无法回答"现在探头安全吗" |
| 29 | 视野锥固定角度不受遮挡 | 鼓励玩家**贴锥边反复刷新** |
| 30 | 锥被挡就完全截止在墙根 | 玩家无法判断拐角后是否仍有视觉连接；要标**不确定区域** |
| 31 | 多敌人视野锥取平均 | 重叠区出现很亮却无人观察的**假热点**；要 `max()` 并保留主要威胁 |
| 32 | 潜行暗杀 = 普通处决换皮 | 是**状态条件**：六项都要满足，失败要触发升温 |
| 33 | 暗杀失败也播必杀动画 | 潜行变无风险赌博 |
| 34 | 消音 = 隐身 | 玩家站灯下众目睽睽连续暗杀 |
| 35 | 尸体是死亡特效 | 是**持久证据**，有发现者集合与可见度遮挡 |
| 36 | 尸体可见性用固定半径 | 倒下的位置会改变掩体关系；要按视线/距离/遮挡算 |
| 37 | 藏尸点只靠标签判定 | 两米高尸体塞进小箱子；要对 AABB 与缝隙做射线 |
| 38 | 搬运完成 = 证据删除 | 是**改变位置与可见性**；检查 A 的守卫不会自动知道柜子里 |
| 39 | 尸体不做预算 | O(敌人 × 尸体) 增长；要空间哈希 + 区域上限 + 远处睡眠 |
| 40 | 预算不足就删除尸体 | 会破坏**玩家已制造的隐藏状态**；要睡眠不是删除 |
| 41 | 脱离视野 = 重置 | 只是进入 `EVASION_COOLDOWN`，仍可被一帧视线重新点着 |
| 42 | 逃一圈就完全恢复 | 要留**持久后果**（区域威胁/巡逻点/封锁/尸体）至少一项 |
| 43 | 统一小感叹号表示状态 | 要能看出"他还在找"；图标/头部转向/语音都要区分 |
| 44 | 动画/UI/寻路直接改怀疑度 | 感知结果只通过 `PerceptionEvent` 输入 |
| 45 | 客户端决定 `suspicion_per_observer` | 伪造外观可绕过检查；必须服务端 |

## 审核时逐条问自己

1. 警戒是 bool 还是「证据等级 + 行动状态」两段？
2. 从 `HOSTILE` 能不能直接跳回 `UNSEEN`？
3. 单个证据源有没有 `per_source_cap`？一次落地会不会直接进战斗？
4. 衰减是"发现后开始"还是"证据失效后开始"？`SEARCH` 时会不会被清零？
5. 搜查点是「覆盖区域」还是「最后已知位置 / 噪声源」？
6. 搜查终止同时看了**覆盖、冷却、持续发现**吗？
7. 搜查能不能被玩家**观察和利用**（投石/关门/等待）？
8. 可见度是连续值吗？采样了头/躯干/脚三点吗？射线排除了观察者吗？
9. 软掩体是降低暴露还是归零？
10. 伪装被识破时，是所有守卫都知道还是**只有目击者**？
11. 视野锥玩家看得见吗？被遮挡处是硬截止还是标了不确定区？
12. 暗杀失败会升温吗，还是照播必杀动画？
13. 尸体有发现者集合吗？搬运后是"删除"还是"改变位置与可见性"？
14. 尸体进预算了吗？预算不足是**睡眠**还是删除？
15. 逃出后有留下**至少一项持久后果**吗？
16. 有没有任何一条"证据注入 / 警戒等级 / 暗杀合法性 / 尸体权威"判定**只跑在客户端**？
