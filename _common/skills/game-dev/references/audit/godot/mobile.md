# mobile — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/mobile.md`

## 常见漏写

| # | 漏写 | 后果 |
|---|---|---|
| 1 | 开了 `emulate_mouse_from_touch` 又处理两套事件 | 动作触发两次 |
| 2 | 用 `InputEventScreenSwipe` | 4.x 不存在，直接报错 |
| 3 | 摇杆用绝对像素半径 | 不同 DPI 手感差异巨大 |
| 4 | 摇杆 Control 的 `mouse_filter` 不是 STOP | 触摸穿透到游戏世界 |
| 5 | 返回键未 `set_input_as_handled()` | 处理了还是退出 |
| 6 | 权限请求后立刻使用 | 异步未返回，功能失败 |
| 7 | 安全区未从屏幕坐标转换 | 有拉伸时边距全错 |
| 8 | `get_display_cutouts()` 用在 iOS | 仅 Android 实现 |
| 9 | 玩家代码里分平台写输入 | 后续维护灾难 |
| 10 | 未在低端机实测 | 上线后大量掉帧投诉 |
| 11 | `VirtualJoystick` 不设 `action_left/right/up/down` | ⛔ 默认是 `ui_left/right/up/down`，摇杆一动 UI 焦点乱跳 |
| 12 | 摇杆 `deadzone_ratio` 与 InputMap 死区同时设 | 两者叠加，推一点没反应 |
| 13 | `joystick_size` / `tip_size` 用默认像素值 | 高 DPI 设备上摇杆过小，拇指按不准 |
| 14 | 摇杆与其它触摸 UI 不在各自 `CanvasLayer` | 触摸被上层不可见控件吞掉 |
| 15 | 桌面端仍显示摇杆 | 键鼠玩家看到一个用不上的控件 |
| 16 | 暂停通知里做完整序列化 / 批量上报 | ⛔ iOS 约 5 秒预算，超时**杀进程而非暂停** |
| 17 | 恢复后不重取时间基准 | 挂机 / 改时间后倒计时、活动、体力全错 |
| 18 | 手势识别不按 `index` 区分手指 | 两指互相干扰，缩放与拖拽串味 |
| 19 | 双指缩放判绝对距离 | 不同屏幕尺寸下同样的捏合得到不同结果 |
| 20 | 安全区只在 `_ready()` 算一次 | 旋转 / 分屏后边距不再更新 |
| 21 | 选竖屏却没交换基础宽高 | UI 变形（⛔ 引擎不会自动交换） |
| 22 | 软键盘弹出不调布局 | 自定义输入框被键盘遮住 |
| 23 | 权限只在导出预设里勾、运行时不请求 | 功能静默失败（⛔ 请求是异步的） |

## 常见错做

| # | 错做 | 后果 |
|---|---|---|
| 24 | 用 `get_display_cutouts()` 算 iOS 安全区 | ⛔ 仅 Android / macOS 实现，iOS 返回**空数组** |
| 25 | 把屏幕坐标当项目 Content 坐标用 | 有拉伸时边距全错 |
| 26 | 指望 `VirtualJoystick` 有可轮询的输出属性 | ⛔ 没有，只能绑 action 或收 `flicked` / `released` 信号 |
| 27 | 4.6 及更早用 `VirtualJoystick` | 该版本无此节点 |
| 28 | 把 `TouchScreenButton` 当摇杆用 | 只能绑单个 action，无方向输出、无死区 |
| 29 | 开着 `use_accumulated_input` 做精细拖拽 | ⛔ 默认开启，输入被合并到渲染帧率，低帧率下精度下降 |
| 30 | 多指各自触发同一个全局动作 | 一次点击被处理多次（⛔ 每个手指的 `index` 独立） |
| 31 | `set_input_as_handled()` 写在分支外 | 不该消费时也消费掉，返回键失灵 |
| 32 | 返回键只判最上层弹窗 | 深层界面直接退出游戏 |
| 33 | 只测发热前 2 分钟 | 降频掉帧在 10 分钟后才出现 |
| 34 | 把 `Engine.max_fps` 当提帧手段 | ⛔ vsync 优先，它主要用来省电 |
| 35 | 用 `screen_get_dpi()` 当 UI 缩放系数 | 布局错乱（它只适合定最小字号 / 热区 / 画质档） |
| 36 | 摇杆可触摸区域与视觉半径不一致 | 看着在圈内、按下去没反应 |
| 37 | 只测编辑器鼠标、不测真机拇指 | 手感与可点性完全对不上 |
| 38 | 权限请求后立刻使用功能 | ⛔ 异步未返回，功能失败 |
| 39 | 暂停时仍继续计时 / 继续跑活动逻辑 | 后台挂机刷进度 |
| 40 | 用 `emulate_mouse_from_touch` 支撑多点触控 | ⛔ 该仿真不是为多点触控设计的，第二指起行为不可靠 |
| 41 | 最低设备档位只写"尽量兼容" | 没有预算，每个效果要不要加都靠拍脑袋，最后在低端机上一起爆发 |
| 42 | 手势阈值写死像素、不按屏幕归一化 | 小屏上极易触发、大屏上很难触发，⛔ 且不报错 |
