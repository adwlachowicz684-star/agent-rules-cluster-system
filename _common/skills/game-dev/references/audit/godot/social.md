# social — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/social.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | Godot 自带大厅/房间 | **没有**，要自己搭服务 |
| 2 | ENet 是完整 P2P 平台 | 只是 **UDP 传输层** |
| 3 | ENet 能穿透 NAT | **不能**，要信令服务 |
| 4 | mesh 不用服务器 | 仍需**信令交换地址** |
| 5 | 房主=创建者 | 是**临时协调者**，要能迁移 |
| 6 | 创建者退出房间就没了 | 要**显式迁移策略** |
| 7 | 客户端过滤敏感词够用 | **改包就绕过**，要服务器过滤 |
| 8 | 聊天不用存 | 要**留存**配合举报取证 |
| 9 | 举报存个玩家 ID 就行 | 要存**证据快照** |
| 10 | 好友列表存客户端 | 要**存服务器** |
| 11 | peer ID 能当玩家身份 | **不能**，要独立会话 |
| 12 | 匹配 Godot 会做 | **不提供** |
| 13 | 掉线后社交状态也丢了 | 分**控制面/数据面**就不会 |
| 14 | 私聊保存期有统一规定 | **未给出**，按最小必要原则定 |
| 15 | 玩家名/头像不用审 | 是 **UGC**，要过审 |
| 16 | 阵营就是角色表一个枚举 | 要分 `main_faction`/`memberships`/`temporary_affiliations` 三层 |
| 17 | 阵营关系对称 | **必须非对称有向**；A 对 B 友好 ≠ B 对 A 友好，⛔ 不自动镜像 |
| 18 | 写死「同阵营不能攻击」 | 那是**战斗规则**不是 DB 约束；要房间级 PvpContext 冻结 |
| 19 | 战斗中能切阵营 | ⛔ 不能回溯修改已冻结的上下文 |
| 20 | 势力只存人数 | 要存**可作战人口**（活跃/在线/参战率），否则误判强势 |
| 21 | 势力积分单一排名 | 要分**控制分/战斗分/贡献分** |
| 22 | 阵营切换只扣钱 | 主要风险是**身份套利**；要时间+关系+经济三重代价 |
| 23 | 「免费转阵营」真免费 | 只是把代价移到冷却/窗口/审批 |
| 24 | 据点控制权写进角色表 | 要独立 CapturePoint + ControlVersion + **服务端时钟**衰减 |
| 25 | 赛季结束用新参数算旧战役 | ⛔ 必须用**该赛季配置版本**的冻结快照 |
| 26 | 人多的一方奖励更多 | 正反馈失衡；要补偿**对弱势方有直接贡献的行为** |
| 27 | 全阵营 Buff 无限期 | 要限时并同时观察转阵营率 |
| 28 | 干预不向玩家解释 | 会像黑箱操纵；要说清补偿什么、多久、依据哪个赛季 |
| 29 | 每分钟读全量平衡数据 | 会压垮 DB；要 15–60 秒采样 + 三个平滑窗口 |
| 30 | 声望只涨不跌 | 只是一根上涨的线；要**能衰减、能负值、能解除锁定** |
| 31 | 衰减惩罚活跃玩家 | 要从「上次获得后」计时，活跃行为要能抵消 |
| 32 | 战力当匹配依据 | 测的是养成不是操作（跨职业不可比/堆无用词条/版本虚高） |
| 33 | 战力只显示一个大数字 | 要**分维度 + 职业百分位 + 装备建议 + 总分** |
| 34 | 客户端算战力上传 | ⛔ 服务端算并缓存；缓存键要含**公式版本** |
| 35 | 战报存全量状态 | 要 `初始哈希 + 输入序列 + 种子 + 配置版本 + 事件摘要` |
| 36 | float 换 double 就确定性了 | IEEE 754 **不保证跨平台**一致；要冻结步长/随机序号/排序/回调顺序 |
| 37 | 回放跨版本「尽力兼容」 | 要**写入时隔离**，旧回放用旧快照；商业产品也限定只能看当前版本 |
| 38 | 战绩本来就是公开的 | PIPL 要求最小范围 + 单独同意；**未满 14 岁属敏感个人信息** |
| 39 | 公开精确对局时间 | 结合其他数据可形成**行踪** |
| 40 | 公开原始输入序列 | ⛔ 不建议 |
| 41 | 关系社交没有解除冷却 | 可反复建立/解除**刷奖励** |
| 42 | 关系加成无上限 | 叠满会破坏数值 |
| 43 | 成员列表塞进频道对象 | 热点频道会拖垮战斗服；频道/成员资格/**扇出**三者分离 |
| 44 | 世界频道刷屏只靠限流 | 会误伤正常玩家；要用**发言道具/冷却**这类经济手段 |
