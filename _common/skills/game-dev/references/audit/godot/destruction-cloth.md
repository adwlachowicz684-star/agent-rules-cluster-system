# destruction-cloth — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/destruction-cloth.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 有内置可破坏节点 | 没有，要预切分凸碎片自实现 |
| 2 | 凹网格直接转单一碰撞体 | 要用凸代理，不是 Mesh 碰撞体 |
| 3 | 破坏瞬间从零算全部顶点 | 主线程卡死，要预烘焙凸包 |
| 4 | 碎片碰撞形状越精确越好 | 凸近似足够，精确更贵 |
| 5 | 切分时复制全部材质 | 要共享材质，避免无谓 duplicate() |
| 6 | 全网格任意破坏实时切 | 要降级为预设破坏簇 + 装饰粒子 |
| 7 | 长尾物理是碎裂瓶颈 | 峰值在切分/凸包/刚体创建/实例上传 |
| 8 | SoftBody3D 替代 AnimationPlayer | 不响应动画轨道形变目标 |
| 9 | SoftBody3D 给任意角色服装用 | 只适合旗帜/软垫/果冻 |
| 10 | 长绳索交给 SoftBody3D | 要用 Joint3D 链/骨骼布娃娃/离线模拟 |
| 11 | drag_coefficient 是 Jolt 主阻力参数 | 默认物理下可能未使用，要在目标引擎验证 |
| 12 | 物理插值能平滑软体 | 软体不受物理插值影响，只能加 physics tick |
| 13 | 软体成本随 total_mass | 随顶点数与 simulation_precision |
| 14 | 旧项目自动用 Jolt | 4.6+ 仅新项目默认，旧项目要手动切 |
| 15 | 社区破坏插件直接兼容 4.7 | 要校验是否针对 4.7 API 与 Jolt 重编译 |
| 16 | 碎片落地后 apply_force 还能推动 | ⚠ **唤不醒休眠体**；一次性用 `apply_impulse` |
| 17 | 休眠能解决碎片性能 | 只省 CPU，**不省内存与实例数**，要回收 |
| 18 | 碎片用 trimesh 碰撞体 | 官方：**最慢** + 只适配静态 + **空心**会穿透 |
| 19 | 给 SoftBody3D 加 CollisionShape3D | 官方：碰撞形状**由网格推导**，加子节点不生效 |
| 20 | `simulation_precision` 调低省性能 | 低于 5 会 **collapse（塌陷）** |
| 21 | `pressure` 调大更饱满 | 网格未封闭时会**像塑料袋乱飞** |
| 22 | `drag_coefficient` 能调空气阻力 | 官方：**目前未使用**，调了无效 |
| 23 | 开了物理插值软体就平滑 | 官方：物理插值**不影响软体**，只能加 tick |
| 24 | 布料飘动要自己施力 | `Area3D` 有内建风力，官方明确软体会受影响 |
| 25 | 不动的碎片用 freeze 的 RigidBody | 官方：应改用 `StaticBody3D` / `AnimatableBody3D` |
| 26 | 碎片从池里取出直接摆位置 | ⚠ 池化必瞬移 → 要 `reset_physics_interpolation()`，否则拖影 |
| 27 | 开了插值软体就平滑 | 官方：插值**不影响软体**，只能加 physics tick |
| 28 | 碎片快了会撞墙不会穿 | 小而快会穿透薄墙（60Hz 下 60m/s 每 tick 1 米），要 `continuous_cd` |
| 29 | 开了 contact_monitor 就能收接触 | ⚠ `max_contacts_reported` 默认 0 → **一条都不报** |
| 30 | 布娃娃用默认 PinJoint | 经验：会 **crumple**；肩/髋/颈用 `ConeJoint`，肘/膝用 `HingeJoint` |
| 31 | 布娃娃骨骼与角色胶囊同层 | 骨骼把自己顶起来，表现为"尸体原地抽搐" |
| 32 | 软体不设 Parent Collision Ignore | 官方教程的**最后一步**；不做则与父物体穿模/抖动 |
| 33 | 软体挂到 BoneAttachment3D 下 | 应改用钉固点的 `attachment_path` 依附 |
| 34 | 4.6 升 4.7 软体照旧调参 | ⚠ mass 默认值变了 + `linear_stiffness` 算法变了，必须重调 |
| 35 | WorldBoundaryShape3D 平面符号不变 | ⚠ 4.7 Jolt 下约定**反转**，迁移要翻符号 |
| 36 | 爆炸击退逐点 apply_impulse | 4.5+ 有 `apply_central_impulse()`，分布到所有点 |
| 37 | 风能把碎片吹动 | 官方（写了两遍）：风力**只作用于 SoftBody3D** |
| 38 | 风向按节点 Z 轴正向 | 官方：与本地 Z 轴**相反**；搞反像风力大小设错 |
| 39 | 缩放节点改碎片大小 | 官方清单：碰撞形状/刚体**不要带 scale**，用形状尺寸参数 |
| 40 | 先做破坏表现再看性能 | GC-06 先定位再优化；碎裂峰值在切分/凸包/刚体创建 |
| 41 | 破坏掉落另写一套掉落逻辑 | 概率/保底/日志/反作弊各走各的 → **统计里查不到** |
| 42 | 破坏打通/堵死通路不用重烘导航 | AI 撞在已不存在的墙上，⛔ 常被当成寻路 bug 排查 |
| 43 | 指望刚体自己堆叠坍塌 | 堆叠稳定性差（GodotPhysics 尤甚），表现不可控，要显式结构图 |
