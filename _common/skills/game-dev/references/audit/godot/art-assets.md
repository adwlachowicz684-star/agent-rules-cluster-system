# art-assets — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`flow/godot/art-assets.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | Filter 在纹理导入页设 | 4.x 在 **CanvasItem 属性**，项目设置是默认 |
| 2 | 像素糊是 PNG 质量差 | 五个环节叠加，先查 Filter 和整数缩放 |
| 3 | Repeat 开了更省事 | UI/图标开了会采样到相邻像素 |
| 4 | Mipmap 是画质选项 | 是"缩小稳定性"，代价内存 +33% |
| 5 | 图集内切片能单独设 Repeat | 判定对象是**整个图集纹理** |
| 6 | 无损压缩最好 | 按用途分层，显存和加载时间也要算 |
| 7 | Basis Universal 万能 | 质量差、编码慢、加载要转码 |
| 8 | Basis 显存更低 | 与 VRAM Compressed 相近 |
| 9 | glTF 导入就不用检查 | 材质、缩放、动画仍要核对 |
| 10 | 材质 clone 一下没关系 | 破坏批处理（自动实例化要求同材质） |
| 11 | 法线贴图当颜色导入 | sRGB 设错，法线/粗糙度/金属度必须 **Linear** |
| 12 | 音频都用 OGG 省体积 | 短音效解码延迟会迟到 |
| 13 | 中文字体直接塞进去 | 必须**子集化**，否则包体爆炸 |
| 14 | 字体缩放糊了没办法 | 开 **MSDF** |
| 15 | FMOD/Wwise 有官方支持 | **没有**一级集成，社区绑定维护状态现查 |
