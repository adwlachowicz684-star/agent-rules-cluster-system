# i18n — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/i18n.md`

## 常见漏写

| # | 漏写 | 后果 |
|---|---|---|
| 1 | 存档存了翻译后的文本 | 切语言后旧存档不更新 |
| 2 | 给按钮固定宽度 | 德语等长语言文本截断 |
| 3 | 中文字体没有回退 | 英文设备上显示豆腐块 |
| 4 | 切语言后不刷新 UI | 界面仍是旧语言 |
| 5 | `_process` 里调 `tr()` | 每帧查表，浪费 |
| 6 | 翻译了内部 ID / 日志 | 存档、配置错乱 |
| 7 | Key 用英文原文 | 改文案要改所有引用 |
| 8 | 未处理 RTL | 阿语/希语布局反了 |
| 9 | 先 `set_locale()` 再 `add_translation()` | 切换**不生效**、界面仍是旧语言，⛔ 且不报错 |
| 10 | 开了伪本地化但没传播 `NOTIFICATION_TRANSLATION_CHANGED` | 界面毫无变化，看起来像开关失效 |
| 11 | 导出时没勾 Include Text Server Data | 编辑器断行正常、⛔ **导出后**中日文不换行或断错 |
| 12 | 以为设了 `layout_direction` 就等于处理完 RTL | 容器翻了，⛔ 手写坐标与拖拽方向仍是反的 |
| 13 | 路径 / URL 没设 `structured_text_bidi_override` | RTL 下路径层级与目录顺序错乱 |
| 14 | 测完翻译没把 Test 属性清空就提交 | ⛔ **整个团队**跑起来都是测试语言 |
| 15 | 写成 `tr("KEY" % value)` | key 已被格式化，永远查不到翻译 |
| 16 | 用 CSV 承载俄语等复杂复数语言 | CSV 不支持复数形式，复数全错 |
| 17 | 运行时下载的语言包没先 `add_translation()` | 切过去静默不生效 |
| 18 | 前进/后退等方向性图标没做翻转 | 阿语/希语下箭头指向反了 |
| 19 | 从来没跑过伪本地化 | ⛔ 上线才发现漏翻与文本溢出 |
| 20 | 只在编辑器里测翻译 | 导出包缺断行数据这类问题测不出来 |
| 21 | CJK 字体全塞进首包 | 包体 +10MB，没按 locale 分包加载 |
| 22 | 只处理 Control，漏了 Sprite2D / 3D 里的文字 | 场景内文字仍是原语言 |
| 23 | 复数用 `tr()` 而不是 `tr_n()` | 单复数不分（英文 1 item / 2 items 全错） |
| 24 | 只注册 `zh` 却拿 `zh_CN` 去匹配 | 启动时回落到默认语言 |
| 25 | 存档存了 locale 但启动时没应用 | 设置界面显示对、实际语言不对 |
| 26 | 资源没按 locale 重映射 | 切语言后含文字的图片 / 音频仍是原语言 |
| 27 | 语音 / 配音没按 locale 分包 | 首包塞满各语言语音，或切语言后语音不换 |
