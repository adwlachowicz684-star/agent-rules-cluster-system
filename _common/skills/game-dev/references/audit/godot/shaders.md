# shaders — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/shaders.md`

## 常见坑汇总

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | GDShader 就是 GLSL | 是方言，抄来的 GLSL 多数跑不了 |
| 2 | 局部变量默认 0 | **未初始化，读到未定义数据** |
| 3 | `1` 和 `1.0` 一样 | 无隐式转换，重载调用会失败 |
| 4 | `source_color` 只是 UI 控件 | 是颜色空间语义，缺了会发白 |
| 5 | 法线贴图也加 `source_color` | 不该加，它不是显示颜色 |
| 6 | `hint_enum` 传字符串名 | 存整数，传字符串静默无效 |
| 7 | 只在 if 里写输出没问题 | 其他分支输出未定义值 |
| 8 | 2D VERTEX 是 0–1 | **是像素坐标** |
| 9 | `CAMERA_MATRIX` 是相机变换 | 是视图→世界 |
| 10 | `world_vertex_coords` 后再乘 MODEL | 双重变换 |
| 11 | `POSITION` 是第二个 VERTEX | 写入后投影不再自动发生 |
| 12 | 全局变量 `SCREEN_TEXTURE` 存在 | 4.x 必须显式声明 |
| 13 | `discard` 能省性能 | 破坏 prepass，顶点仍执行 |
| 14 | GPU 没有分支预测所以别用 if | uniform 分支通常划算 |
| 15 | 精度全局调低更快 | 远处闪烁只在真机出现 |
| 16 | shader 代码短就快 | 变体数与代码行数无关 |
| 17 | `preload()` 就等于预热 | 未执行代表 draw，首帧仍编译 |
| 18 | compute 回读很便宜 | 强制同步，是常见性能杀手 |
| 19 | 材质拖给多个节点，各自独立 | 共享同一个 Resource，改一个全部跟着变 |
| 20 | 勾了 Local to Scene 就都独立了 | 只对运行时 instantiate 生效，手摆的仍共享 |
| 21 | 材质挂在 mesh 上也能 Local to Scene | 要挂 surface override 才生效 |
| 22 | `set_shader_param()` 还能用 | 4.x 改名 `set_shader_parameter()` |
| 23 | uniform 名字写错会报错 | 大小写敏感，静默无效，没有自动补全 |
| 24 | `$Sprite.material` 就是要改的材质 | 没设 override 时是 null，或返回表面基础材质 |
| 25 | 逐实例就该每个都 duplicate | 全局效果共享才对，逐个复制会漏实例 |
| 26 | 先写 shader 再想参数归谁 | 先定性逐实例还是全局，再决定共享还是复制 |
| 27 | 主菜单测 Compatibility 就算预热过了 | 要在游戏实际用的渲染器上做代表性 draw |
| 28 | 只改个别材质就行 | 迁移要全局替换，漏改一处就偏亮 |
| 29 | 一次性写完整个效果 | 先用一个 uniform 跑通，再叠加 |
| 30 | varying 在哪都能赋值 | 只能在允许阶段赋值，helper 里赋值会报错 |
| 31 | 编译通过就是对了 | 先隔离阶段再比较数值，编译通过不等于结果对 |
| 32 | 变体只在改 shader 时才变 | 改分辨率、换材质、动态灯光都会生成新管线 |
| 33 | 预热一次就永久有效 | 换设备或升驱动后缓存失效，要重新编译 |
| 34 | 宏开关方便，用它做运行时差异 | 最坏 2^N 个变体，改用 uniform |
| 35 | 多采样几次看不出差别 | 每次 texture() 可能 cache miss，重复坐标要先缓存 |
| 36 | 移动端全屏 pass 读屏幕纹理没问题 | 破坏 tile 优化，代价远高于桌面 |
| 37 | 看代码就知道效果好不好 | 要截图看，静态截图能读出画面主体 |
| 38 | 要效果就得写 shader | 先定性，引擎参数能解决的别写，写 shader 要付变体与预热成本 |
| 39 | 靠打印或猜来判断中间值 | 把中间值映射成颜色直接看，shader 里没有 console |
