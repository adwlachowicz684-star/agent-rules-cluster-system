# 审核条目 —— 载具 / 驾驶

> 用法：按功能点收尾时逐条对照。格式：本能以为 → 实际 → 审查规则

| # | 本能以为 | 实际 | 审查规则 |
|---|---|---|---|
| 1 | `VehicleBody3D` 什么载具都能做 | 轮式专用，动力经车轮接地点输出 | ⚠ 无轮载具走 `RigidBody3D` |
| 2 | 飞行器挂 `VehicleWheel3D` 无害 | 悬挂射线一直打空，白费 CPU | ⛔ 场景树里搜不到车轮节点 |
| 3 | 车轮挂外面也能被找到 | 必须是**直接**子节点，否则无动力 | ⚠ 车轮是车身直接子节点 |
| 4 | 车轮要碰撞体才物理正确 | 自带射线，加碰撞体会互挤压弹飞 | ⛔ 车轮无 `CollisionShape3D` |
| 5 | 物理层会自动渲染轮子 | 不会，不挂网格就看不见 | ⚠ 车轮有 `MeshInstance3D` |
| 6 | 不用标转向轮/驱动轮 | 不标则力施加到错轮子 | ⚠ 标 `use_as_steered` / `use_as_traction` |
| 7 | mass 会自动算 | 车轮不贡献质量，常算成 0 | ⛔ 显式设 `mass` 非 0 |
| 8 | 翻车是转向力太大 | 是重心 + 转向 + 速度合结果 | ⚠ 重心低于悬挂点 |
| 9 | `engine_force` 是每帧脉冲 | **持续属性**，不会自动归零 | ⛔ 无输入显式归零 |
| 10 | 写在 `_process` 也行 | 与物理步长不同步，帧率影响车速 | ⚠ 用 `_physics_process` |
| 11 | `steering` 直接置 0 回正 | 瞬间弹正，高速甩头 | ⚠ `lerp` 渐进回正 |
| 12 | 高速转向不用衰减 | 打满方向直接翻车 | ⚠ 随速度衰减 |
| 13 | `suspension_travel` 默认就够 | 为 0 则悬挂不压缩，像滑板 | ⛔ 必须 > 0 |
| 14 | `damping` 默认 0 没事 | 无限弹跳，最像引擎 bug | ⛔ 必须非 0 |
| 15 | stiffness 随便填 | 不足则车身坐地、过坎触底 | ⚠ 按车重/轮数调 |
| 16 | 乘员用车身信号检测 | 地面/道具也进乘客表 | ⚠ 用 `Area3D` + 类型过滤 |
| 17 | 乘员表挂载具上方便 | 载具销毁则引用悬空崩溃 | ⛔ 存外部管理器 |
| 18 | 先销毁载具再处理乘客 | 角色位置丢失，掉出地图 | ⛔ 先退出再销毁 |
| 19 | reparent 角色到载具最省事 | 物理体仍在世界，互挤弹飞 | ⛔ 角色保持独立 |
| 20 | 上下车不需要冷却 | 连按同帧翻转，车里车外闪现 | ⛔ 必设冷却 |
| 21 | 上下车顺序无所谓 | 先切控制再定位会被覆盖，回原点 | ⚠ 先定位再切控制 |
| 22 | 不切输入上下文没事 | 角色与车同时响应 | ⛔ 输入不串台 |
| 23 | 上车不用关碰撞 | 角色与车身互挤弹飞 | ⚠ 关闭车内碰撞 |
| 24 | 满了也能上车 | 超载后控制逻辑全乱 | ⚠ 满员拒绝 |
| 25 | 平地能开就是做完了 | 本域坑只在极限工况暴露 | ⚠ 必须测高速/斜坡/落地/连按 |
