# cicd-publish — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/cicd-publish.md`

## 常见坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | CI 忘记 `--import` | 资源找不到/纹理全黑，本地正常 |
| 2 | 不提交 `.import` | 各机器导入参数不一致，diff 看不出 |
| 3 | 拼错 `--export-realese` | 静默退出码 0，CI 绿但无产物 |
| 4 | 导出后不校验产物 | 上面那条发现不了 |
| 5 | 模板版本不匹配 | 导出失败或产物异常 |
| 6 | 升级引擎不重下模板 | 同上 |
| 7 | keystore 直接存 Secret | Secret 是文本，二进制损坏 |
| 8 | 密钥放仓库 | 泄露，且 Git 历史里删不掉 |
| 9 | macOS 只签名不公证 | Gatekeeper 拦截 |
| 10 | Android 漏选纹理格式 | 真机纹理全黑 |
| 11 | Android 漏 INTERNET 权限 | 真机网络全失败，编辑器正常 |
| 12 | 只测 debug 不测 release | assert 被剥离后行为不同 |
| 13 | CI 镜像版本与本地不一致 | 本地能跑 CI 红，或更糟 |
| 14 | 版本号散落三处 | 必然不同步 |
| 15 | 先配好各平台预设再定平台矩阵 | 平台一变，每个预设重配一遍；改语言/渲染后端等于重来 |
| 16 | 立项时不定目标平台（Web 不支持 C#） | 后期无法低成本更改，WebGL2 限制到渲染阶段才暴露 |
| 17 | 只验“导出命令成功” | 没验产物能启动，到发版当天才发现打不开 |
| 18 | 在无头环境跑“渲染测试”并当通过 | 无窗口无 GPU，画面相关断言从未真正执行 —— 假通过 |
| 19 | CI 缓存 key 只含 project.godot | 改了 .tscn/.import 不失效，一直用旧导入产物 |
| 20 | 预设名大小写或空格不一致 | --export-release 静默失败，且退出码仍是 0 |
| 21 | export_presets.cfg 用绝对路径 | 团队里路径不同的人导出失败，CI 上同样失败 |
| 22 | export_credentials.cfg 不入库却无人补 | 部分导出选项静默缺失，本地与 CI 行为不同且不报错 |
| 23 | custom_template 填相对路径 | 静默回退默认模板，无任何警告，产物与预期不同 |
| 24 | 非资源文件（.json/.csv/.txt）没配过滤器 | 编辑器正常、导出后读不到，报错是“打不开”而非“没进包” |
| 25 | 配置文件放在点开头的目录或文件名 | 永远不会进包，且不报错 |
| 26 | 导出后仍写 res:// | 导出包里 res:// 只读，写入失败且无明确提示 |
| 27 | 关闭 ETC2/ASTC 后导 Web / Apple Embedded | 红色校验错误但消息框为空，无文本可搜索（issue #119803） |
| 28 | 4.5 前点了 Fix Import 就以为生效 | 未真正重新导入，.import 里没有 .etc2 变体 |
| 29 | 给 fork PR 注入 Secret | 凭据泄露，且 Git 历史里删不掉 |
| 30 | 密码写进 export_presets.cfg 而非环境变量 | 该文件可安全入库，密码随之入库 |
| 31 | 签名凭据过期才发现 | 发布窗口丢失，商店审核排队白排 |
| 32 | 把“退出码 0”当导出成功 | Godot 导出失败仍返回 0（GH-83042），CI 全绿却无产物 |
| 33 | Web 产物用 file:// 打开 | wasm 加载失败白屏，报的是跨域而非路径错 |
| 34 | 因 CI 上 macOS 产物是 .zip 而本地是 .dmg 去改配置 | 两者都含 .app，改配置反而导出异常 |
| 35 | 只在编辑器里测 Android / iOS | 真机权限与纹理格式问题测不出，表现为“编辑器全好真机全黑” |
| 36 | 版本回退时没有变更日志 | 无法定位是哪个改动引入，只能逐个二分 |
| 37 | 发布没有回滚路径 | 出问题只能热修，而热修本身没被验证过 |
