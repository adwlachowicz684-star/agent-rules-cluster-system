# ui-advanced — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/ui-advanced.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 有内置虚拟列表 | **没有**，千节点必卡死 |
| 2 | Tree 会虚拟化 | **不会**，70k 项 1.21 GiB |
| 3 | ScrollContainer 会裁剪不可见区 | **没有声称**做回收 |
| 4 | BBCode 直接拼用户输入 | 含 `[` 会**破坏排版** |
| 5 | 拖拽预览自己建自己删 | **引擎接管生命周期**，不能 free |
| 6 | 预览节点可以已在树里 | **绝不能**在场景树中 |
| 7 | 鼠标能点就够了 | **手柄选不中**（缺 focus_neighbor_*） |
| 8 | 弹窗关了焦点自动回来 | 要**显式处理** |
| 9 | 剪贴板还是 OS.set_clipboard | 4.x 迁到 **DisplayServer** |
| 10 | 无障碍只能靠自己 | 4.7 有 **AccessibilityServer** |
| 11 | 富文本随便更新 | 大量/频繁更新**有性能代价** |
| 12 | 列表项高度随便量 | **动态高度**要专门测量 |
| 13 | 拖拽和滚动不冲突 | 滚动区域里拖要**实测** |
| 14 | Tooltip 位置不用管 | 屏幕边缘**会被裁切** |
| 15 | 无障碍是额外工作 | 焦点链本身**决定可玩性** |
