# performance — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`flow/godot/performance.md`

## 常见错误直觉

| 直觉 | 实际 |
|---|---|
| 节点太多导致卡 | 节点数本身很少是瓶颈 |
| 贴图太大 | 通常是 DrawCall（合批被打断） |
| 物理太重 | 先确认是不是每帧 `intersect_shape` |

## 常见漏写

| 漏写 | 后果 | 审查规则 |
|---|---|---|
| 屏幕外对象仍在处理 | 纯浪费 CPU | 人工 |
| 每帧 `get_node()` | 每帧遍历场景树 | GD11 |
| 每帧实例化/新建 | GC 压力 | GD12 |
| 每帧改 Label.text | 每帧重排 | GD13 |
| 每帧 `load()` 同步加载 | 磁盘 I/O 卡主线程 | GD91 |
| 热路径字符串比较未用 & | 逐字符比较 | GD92 |
| 比较距离用 distance_to | 多余开方 | GD94 |
| 每帧 new 材质 | 打断合批 | GD31 |
| 物理层全勾 | 无谓碰撞检测 | 人工 |
| 未在低端机实测 | 上线掉帧 | 人工 |
