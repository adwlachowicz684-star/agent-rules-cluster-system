# security — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`flow/godot/security.md`

## 常见漏写

| 漏写 | 后果 |
|---|---|
| 加密但不签名 | CBC 比特翻转，金币字段可被定向改 |
| 复用 IV | 相同明文产生相同密文前缀，泄露结构 |
| 用 `==` 比 HMAC | 时序侧信道 |
| 先解密后验签 | 把攻击者数据喂给解密器 |
| 密钥硬编码在脚本 | PCK 解包后可读，等于没加密 |
| 用系统时间做每日奖励 | 改时钟即绕过 |
| 检测到就崩溃 | 暴露检查点位置，反而更好绕过 |
| 客户端加密当防作弊 | 结构性无效，密钥必在客户端 |
| 压缩加密顺序反了 | 压缩率接近零 |
| 联网逻辑放客户端 | 加多少 HMAC 都没用 |
