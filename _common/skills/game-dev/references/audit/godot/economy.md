# economy — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/economy.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 货币一个 int 够 | 要多货币 + 来源追踪 + 上限 |
| 2 | 各处直接改货币 | 必须**单一入口**，否则对不上账 |
| 3 | 浮点算货币小心点就行 | **整数域与浮点域要分开** |
| 4 | 保底计数放内存 | **必须随存档持久化** |
| 5 | 全游戏一个保底计数 | 必须**与卡池绑定** |
| 6 | 权重可以有负数 | `rand_weighted` **明确禁止** |
| 7 | 客户端算掉落没问题 | **可篡改**，联机要服务端 |
| 8 | 购买失败统一提示 | 要能**区分原因** |
| 9 | 限购重置按本地时间 | 要 **UTC**，本地不可信 |
| 10 | 跨周期不在线不用管 | 计数必须**容忍缺席** |
| 11 | 天赋 I/II/III 三个节点 | 应是**单节点带 rank** |
| 12 | 洗点直接清空重分配 | 要「取消→校验→扣点」**同一事务** |
| 13 | +20% 就是乘 1.2 | 三种叠加**结果不同**，要约定 |
| 14 | 属性每次重算都一样 | **顺序必须固定** |
| 15 | 独立乘区越多越爽 | **必须限数量**，否则数值崩坏 |
| 16 | 任务每帧检查条件 | 要**事件驱动** |
| 17 | 装备模板直接存进存档 | 会**共享/复制污染**；只存 `base_id` + 实例字段 |
| 18 | 模板 ID 缺失用默认武器顶上 | 要进**隔离区**，静默替换是事故 |
| 19 | `instance_id` 客户端 `randi()` | 服务端生成；创建+绑定要**同一事务** |
| 20 | 词条存最终数值 | 存 `affix_id + roll`，否则改表后**无法重算** |
| 21 | 强化失败掉一级只是难一点 | 期望次数可从 31 涨到 **2557**，近似不可达 |
| 22 | 保底计数放内存/每日清零 | 不是保底，必须**随存档持久化** |
| 23 | 先改等级后存保底 | 崩溃会**状态撕裂**，必须同事务 |
| 24 | 保护符 = 概率提升 | 是**替换失败后果**，不能叠加概率 |
| 25 | 只看强化期望值 | 要看 **P50/P90/P99 与最大连败** |
| 26 | 叫它"幸运值" | 是概率递增就该叫**保底进度**，否则玩家误解 |
| 27 | 洗练先覆盖旧数据再扣费 | 要**先冻结旧快照，扣费后切指针** |
| 28 | 客户端无限次试洗后取消 | 等于**免费预览服务端随机** |
| 29 | 装备数值多处计算 | 只能走**一个计算器**，否则同词条受两套规则 |
| 30 | 升品直接改 `quality` 字段 | 旧实例会**行为不一致**，要走事务 |
| 31 | 概率百分比填进权重表 | 互斥权重 ≠ 独立概率，实际概率会**小于配置** |
| 32 | 权重表当独立概率用 | 玩家**一次拿多件** |
| 33 | 分解按模板原价返还 | 按**当前养成状态**折算，否则刷分解套利 |
| 34 | 绑定/已装备物品能分解 | 要明确**可分解边界** |
