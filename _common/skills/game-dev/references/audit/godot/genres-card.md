# genres-card — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/genres-card.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 连锁用信号连接实现 | 无法控顺序、入栈、插入响应、取消，要用显式栈 |
| 2 | 效果里直接 `target.take_damage(5)` | 跳过响应链，要生成事件入栈 |
| 3 | `Array.shuffle()` 洗牌 | 用全局 RNG 状态，无法复现/服务器校验 |
| 4 | 混用 `randf()` 与 `rng.randf()` | 两套状态，同种子不同结果 |
| 5 | 牌库空了洗弃牌堆再抽同帧无保护 | 会抽到刚洗进去的同一张，要标记 is_reshuffling |
| 6 | 卡牌是 Node/PackedScene | 同张卡多份实例成倍耗内存，数据要 Resource |
| 7 | 卡牌存档用 JSON | 无法表达 Resource 引用与类型，要用 .tres/.res |
| 8 | `FLAG_COMPRESS` 对 .tres 有效 | 仅对二进制资源有效 |
| 9 | 循环里 `instantiate()` 卡牌视图 | 很贵，要用固定容量池 |
| 10 | UI 重排滥用 `queue_redraw()` | 布局重算比纹理更耗，会拖垮拖拽帧 |
| 11 | 效果栈无深度保护 | 响应链会无限递归，要设上限与"本轮已响应"标记 |
| 12 | 伤害数字/特效在逻辑里直接播 | 应从结算结果驱动 |
| 13 | `load()` 同一路径拿同一个实例 | 官方口径是加载结果**会被缓存**，后续同路径返回同一对象；牌库/手牌/弃牌堆是同一个对象，运行时改动全泄漏，不报错 |
| 14 | `duplicate(true)` 就是深拷 | 数组与字典里的子资源在 4.2–4.4 **不复制**（已知问题），4.5 才修并新增 `duplicate_deep`；`effects` 正是 `Array[Effect]` |
| 15 | 4.5 起默认 `duplicate()` 仍深拷数组 | 语义已变：数组/字典变成**只引用不复制**，抄 4.2 时代的写法会得到另一种错 |
| 16 | 复制完不切断 `resource_path` | 保存时仍被当成外部资源，只写回路径引用，改动随原文件漂移 |
| 17 | 手牌顺序不纳入随机或写死 | 回放时牌库序列对了、摆放不同，玩家看到的仍是"这局不一样"，且自动比对常只比数据不比顺序 |
| 18 | 只记种子不记洗牌次数 | 重放时多洗一次就全线错位，看起来只是"抽牌顺序不同"这种无害差异 |
| 19 | 纯表现随机也走结果流的 `RandomNumberGenerator` | 表现改动会改变结果序列，回放与服务器校验一起崩 |
| 20 | 效果里直接改卡面数值 | 落在定义上会泄漏到牌库、弃牌堆与**下一局**，且改动入口不止一处时无从断言 |
| 21 | 结算结果里塞节点引用 | 存档时节点不存在，写出去是空引用，读档回来是 `null`，本地跑多少局都发现不了 |
| 22 | `timing` 留隐式默认 | 新卡忘了填就在**错误时机**生效，不报错，只表现为"偶尔提前/延后触发" |
| 23 | 多处推进回合阶段 | 阶段被多处推进会出现"结束效果触发两次"，每处单独看都合理 |
| 24 | 结算不校验目标仍合法 | 栈是后进先出，前一条可能已把牌送走，表现为对已离场的对象结算，数值照改 |
| 25 | 依赖数组自然顺序定"同时" | 数组顺序随洗牌/移动/读档而变，同局面不同局顺序不同，排查被引向 rng |
| 26 | 取消/替换口径各卡自定 | "不结算 / 结算为 0 / 替换"混用，每张卡各自自洽，只有对比时才看出不一致 |
| 27 | 回合起止效果各自连接 | 新增一张卡就要记得接一次，漏了就是"这张牌的回合开始效果不生效"，完全不报错 |
| 28 | 拖拽期每帧改子节点或 `queue_redraw()` | `Control` 的子节点数量与布局重算比纹理更耗，手牌一多拖拽就掉帧 |
| 29 | 单条反馈时长超过结算间隔 | 下一次结算来时上一次还没播完，连锁时堆积糊成一团，做的时候觉得很好看 |
| 30 | 存档不带 `FLAG_CHANGE_PATH` | `resource_path` 仍是旧槽位，之后不带路径的自动保存写回旧槽，覆盖另一存档且不报错 |
| 31 | 存档不带 `FLAG_BUNDLE_RESOURCES` | 外部子资源只存一行路径，原文件一变（换版本/热更）读档拿到的就是新数据 |
| 32 | 回放只记种子不记决策序列 | 种子只决定随机，决定不了玩家打了哪张牌，重放会走到完全不同的分支 |
