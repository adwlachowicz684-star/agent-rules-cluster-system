# audio-advanced — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/audio-advanced.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 音量传 0–1 | 是**分贝**，要 `linear_to_db()` |
| 2 | 0 dB 是静音 | 0 dB 是原始音量；静音要 -80 dB 或 mute |
| 3 | UI 音效走 Master 没问题 | 耦合了"全静音"和"UI 静音" |
| 4 | 反复 play() 能叠加 | 同一个播放器会**打断自己** |
| 5 | AudioStreamPlayer3D 出来就有 3D 效果 | 必须 `add_child` 进树 |
| 6 | 淡出到 0 | 要淡到 -80 |
| 7 | paused 后 UI 音还能响 | 默认被停，要设 PROCESS_MODE_ALWAYS |
| 8 | bus_mute 等于暂停 | 播放继续，恢复后从中间接 |
| 9 | 音效都用 OGG 省体积 | 短音效解码延迟会迟到 |
| 10 | MP3 能做无缝循环 BGM | 编码特性导致无法无缝 |
| 11 | 音高随机化越大越好 | 超过 ±15% 听得出变调 |
| 12 | 混响放在每个音源上 | 应按类别放**总线**上 |
| 13 | 各处手写总线名字符串 `"SFX"` | 拼错**不报错**，静默走 Master；`get_bus_index` 不存在时返回 **-1** |
| 14 | 播放器 `bus` 用默认的 `"Master"` | ⛔ 忘了设就绕过整条总线链；池化播放器要**建池时批量设一次** |
| 15 | 首次播放才让引擎注册流 | 官方：注册会造成 **lag spike**；要在加载阶段 `register_stream_as_sample()` |
| 16 | `max_polyphony` 能设多声部 | ⛔ 属性名是 **`polyphony`**（默认 32，范围 1–128）；超限时本次 `play_stream()` 返回 `INVALID_ID`，**不是裁掉最旧的** |
| 17 | 大场面所有音效都发声 | 糊成噪音 + 超 0 dBFS 削波；要有**并发上限 + 优先级** |
| 18 | 手写多个播放器做动态音乐分层 | 多播放器**无法保证层间同步**，会累积漂移；4.3+ 有 `AudioStreamSynchronized` 等内置类型 |
| 19 | `AudioStreamPlaylist` 不设 `bpm` | 切换是"播完就接"，可能切在小节中间；设 bpm 才会落在节拍边界 |
| 20 | `max_distance` 用默认值 | ⛔ 必须匹配**场景尺度**；100 米关卡用默认 20，走到一半就没声了 |
| 21 | 空间音效也用对象池 | ⛔ 池化播放器**没有位置**；空间音效要独立节点 + 独立位置 |
| 22 | 只在编辑器里听过就算验过 | ⛔ 必须测**导出包**；且 `--headless` 官方明确会**自动把音频驱动设为 Dummy** |
| 23 | Master 总线不挂限制器 | 叠加超 0 dBFS 会**削波爆音**；Limiter 是最后一道保险，不是"听起来更好" |
| 24 | 把 `playback_speed_scale` 当 `Engine.time_scale` | 官方明确**两者相互独立**；慢动作要单独设音频速度 |
| 25 | 音量设置只在正常退出流程里存 | 崩溃/强杀会丢；要**改动即存**或退出前存 |
| 26 | 各部件单独听都没问题就算通过 | 部件合格 ≠ 拼起来能用；要有**集成验收**（战斗+UI+语音同时响） |
