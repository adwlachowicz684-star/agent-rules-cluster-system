# testing — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/testing.md`

## 常见漏写

| # | 漏写 | 后果 |
|---|---|---|
| 1 | 测试没用 add_child_autofree | 测试间互相污染 |
| 2 | CI 不用 --headless | 无显示器环境跑不了 |
| 3 | 失败不返回非零退出码 | CI 永远绿 |
| 4 | gdtoolkit 版本与 Godot 大版本不一致 | 规则全错 |
| 5 | 批量关闭 lint 规则 | 真问题也被关掉 |
| 6 | 不发存档样本进测试 | 存档格式变更时无回归网 |
| 7 | 一上来要求 0 lint 问题 | 老项目直接卡死，最后被迫绕过 |
| 8 | 只测 UI 不测逻辑 | 逻辑才是出 bug 的地方 |
| 9 | 用 assert 写断言却在 release 导出包里跑 | 断言整段跳过，输出"全过"但一次都没验证 |
| 10 | `assert()` 内写有副作用的函数调用 | release 下被测函数根本没被调用，测试仍通过 |
| 11 | 假设 `quit(1)` 生效、从不实测退出码 | 测试全红但 CI 全绿，信号与事实相反 |
| 12 | release 构建未开启调用栈追踪 | 线上崩溃只有一句日志，本地却能复现出堆栈 |
| 13 | 测试间共享可变状态 | 单跑过、全跑红，报错却指向业务代码 |
| 14 | 测试产生的临时文件不清理 | 用例互相读到对方残留，偶发失败被当成不稳定 |
| 15 | 流水线步骤无超时上限 | 挂死的任务让 CI 无限等待，被误判为"CI 慢" |
| 16 | 失败只打印"测试失败"不打用例名 | 几百行日志里找不到哪红，最终被跳过 |
| 17 | 测试依赖本机时区 / locale / 路径大小写 | 我机器上过、CI 上红，最后靠改 CI 环境绕过 |
| 18 | 把 tests 目录排除在 lint 之外 | 测试代码先腐烂，且腐烂时不产生信号 |
| 19 | 测试依赖联网或外部服务 | 网络抖动造成的红被忽略，久而久之所有红都被当成抖动 |
| 20 | 回归网只覆盖最新格式 / 最新代码 | 老玩家的状态从未被验证，每次升级丢一批数据 |
