# 2d-rendering — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/2d-rendering.md`

## 常见漏写

| # | 漏写 | 后果 |
|---|---|---|
| 1 | `y_sort_enabled` 开在子节点 | 不排序 |
| 2 | 排序对象不在同一父节点 | 不互排 |
| 3 | 原点不在脚底 | 角色半身陷进物体 |
| 4 | 描边未留透明边距 | 视觉与碰撞体不符 |
| 5 | 转场 ColorRect 未设 `mouse_filter` | 挡住点击 |
| 6 | 2D 光照没有 `CanvasModulate` | 光照看着无效或整体过曝 |
| 7 | `shadow_enabled` 但没有 `LightOccluder2D` | 什么也不挡 |
| 8 | 屏幕特效层没插 `BackBufferCopy` | 抓屏时机错，扭到不该扭的层 |
| 9 | 像素风 stretch 未设 `viewport` 模式 | 整屏按线性放大，全糊 |
| 10 | 改了项目默认过滤但没重新导入 | 已导入贴图保留旧设置，仍糊 |
| 11 | hitstop 没写恢复路径 | 异常退出后 `time_scale` 停在 0，游戏假死 |
| 12 | 未在多分辨率 / 真机实测 | 上线后错位、发糊、掉帧 |
| 13 | 视差层没设 `scroll_scale` 就期待有景深 | 多层同速，等于一层 |

## 常见错做

| # | 错做 | 后果 |
|---|---|---|
| 14 | 改 Parallax2D 的 `position` | 被相机逻辑覆盖 |
| 15 | 4.x 里写 `SCREEN_TEXTURE` | 编译错误 |
| 16 | `set_shader_parameter` 名拼错 | 静默失效 |
| 17 | hitstop 的 timer 未 `ignore_time_scale` | 游戏永久卡死 |
| 18 | `Light2D`（3.x 类名） | 4.x 已拆分 |
| 19 | 排序对象 `z_index` 不同 | ⛔ 官方：只有**同一 `z_index`** 才互排，排序整体失效 |
| 20 | `limit_begin` / `limit_end` 未留视口余量 | ⛔ 视差层**完全不动**，且不报错 |
| 21 | 改 `screen_offset` 当手动滚动 | 之后的位置改动会被覆盖 |
| 22 | `repeat_size` 与贴图尺寸不一致 | 循环处跳一下 |
| 23 | `PointLight2D.height` 当阴影高度用 | 那是法线贴图感知高度 |
| 24 | 法线贴图挂 Sprite 直接属性 | 4.x 改走 `CanvasTexture` |
| 25 | `hint_screen_texture` 在 `vertex()` 里读 | 读不到，官方限定只在 `fragment()` |
| 26 | 多处 `add_trauma` 不做上限 | 叠加到满值后持续满屏抖 |
| 27 | 抖动写 `position` | 被相机跟随吃掉 |
| 28 | 抖动幅度写死像素 | 不同分辨率下幅度差异巨大 |
| 29 | hitstop 恢复写死 `1.0` | 与慢动作叠加时速率错乱 |
| 30 | 溶解用 `discard` 后碰撞体仍在 | 看着消失了还能被打中 |
| 31 | 每层全屏效果各自拷屏 | 一帧多次全屏拷贝，移动端直接爆 |
| 32 | 相机 `zoom` 取非整数倍做像素风 | 像素边缘随移动闪烁撕裂 |
| 33 | 逐节点 `texture_filter` 与项目默认不一致 | 同一种图有的糊有的锐 |
| 34 | 用 `y_sort_origin` 掩盖原点不统一 | 治标：排序对了，碰撞体仍错 |
| 35 | 动态生成的实例没放进排序父节点 | 运行时刷出来的都不参与排序 |
| 36 | 移动端带阴影光源过多 | 阴影是全屏开销，低端机掉帧 |
| 37 | UI `CanvasLayer` 与世界层混用 `z_index` | 层内外排序互相穿透 |
| 38 | 屏幕特效依赖窗口分辨率 | 换分辨率后效果错位 |
| 39 | 只在单一分辨率验收 | 多分辨率下特效与布局一起错 |
