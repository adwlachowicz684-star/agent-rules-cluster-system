# architecture — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/architecture.md`

## 常见漏写

| # | 漏写 | 后果 |
|---|---|---|
| 1 | 子调 `get_parent().get_parent()` | 改树结构就断 |
| 2 | Autoload 信号未断开 | 节点永远不释放（泄漏） |
| 3 | 深继承链 | 改基类影响全部，无法复用子组件 |
| 4 | 数据表写死在脚本 | 改数值要改代码 |
| 5 | `@export Resource` 不 duplicate | 所有实例共享 |
| 6 | 组件间互相直接引用 | 耦合，无法单独复用 |
| 7 | 脚本内部自己找依赖 | 无法测试、改结构就断 |
| 8 | 成员顺序混乱 | diff 噪音大，阅读成本高 |
| 9 | 场景树嵌套过深 | 遍历和变换成本上升 |
