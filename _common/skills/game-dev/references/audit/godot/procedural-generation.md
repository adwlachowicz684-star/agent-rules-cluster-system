# procedural-generation — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/procedural-generation.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 随机生成不用记种子 | 没种子就没法复述 bug |
| 2 | 全局 `randi()` 够用 | 是全局状态，**必须实例隔离** |
| 3 | `state` 能当种子 | 只能恢复同序列状态 |
| 4 | 读 `seed` 能回看分享码 | 返回的是先前状态 |
| 5 | 同种子永远同结果 | **跨 Godot 版本不保证**（PCG32 是实现细节） |
| 6 | BSP 出来就能玩 | 是树，**可能没环** |
| 7 | 迷宫很自然 | 机械、多长死胡同 |
| 8 | 元胞自动机天然连通 | **最容易产生不可达** |
| 9 | WFC 是瓦片随机摆 | 是**约束求解**，会矛盾需回退 |
| 10 | 泊松采样解决布点 | 只管间距，**不管玩法密度** |
| 11 | 生成完直接实例化 | 要先**纯数据算完**再一次性写 |
| 12 | 后台线程能改场景树 | **不是线程安全** |
| 13 | 4.2 的 set_cell 写法还能用 | 4.3+ 首参变了 |
| 14 | 大世界距离只影响性能 | **是精度问题**，会可见抖动 |
| 15 | flood fill 可省 | 除非方法本身保证连通 |
