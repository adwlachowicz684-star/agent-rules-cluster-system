# 审核条目 —— VIP / 订阅 / 累充

> 用法：按功能点收尾时逐条对照。格式：本能以为 → 实际 → 审查规则

| # | 本能以为 | 实际 | 审查规则 |
|---|---|---|---|
| 1 | 到期看本地时钟就行 | 官方：系统时钟**用户可手动设置**，⛔ 精确计时禁用 | ⚠ 到期必须用服务器时间 |
| 2 | `get_ticks_msec()` 能存到期时刻 | 那是**引擎启动以来的毫秒数**，不是日期 | ⛔ 只用于本地插值推进 |
| 3 | 每帧问系统时间算倒计时 | 官方：受用户/系统自动调整影响 | ⚠ 存绝对时间戳 + ticks 插值 |
| 4 | 时间转换会自动处理时区 | 官方：转换方法**不处理时区与 DST** | ⚠ 跨端统一 UTC |
| 5 | 本地字典转时间戳再转回来是自洽的，就没问题 | 自洽但**与服务端 UTC 差一个偏移** | ⛔ 只在展示层转本地 |
| 6 | 从时间戳能反推夏令时 | 官方：**无法从纪元确定 DST** | ⛔ 别指望 |
| 7 | `get_datetime_dict_from_system()` 默认 UTC | 默认 `utc=false`，即**本地时区** | ⚠ 显式传 `true` |
| 8 | 时间字典少填一字段没事 | 官方：缺键默认取 **1970-01-01** 的对应值 | ⚠ 结果必须校验合理区间 |
| 9 | 空字典转换会报错 | 官方：**返回 0**，静默 | ⛔ 不信任转换结果 |
| 10 | 带小数的字符串会保留小数 | 官方：**静默忽略**小数部分 | ⚠ 别依赖亚秒 |
| 11 | `get_unix_time_from_system()` 返回 int | 官方：返回 **float**，与其他方法不一致 | ⚠ 注意类型混用 |
| 12 | 所有 `get_unix_time_from_*` 都返回 UTC | 只有 system 版保证 UTC；dict/string 版**不转换** | ⚠ 别混用 |
| 13 | 等级单独存一份更方便 | 两份真相 → "累充够了等级没涨" | ⛔ 只存额度，等级派生 |
| 14 | 退款只降等级就行 | 不减额度 → 下次重算又升回去 | ⛔ 同链重算 |
| 15 | 权益写成 `if vip_level >= 3` | 改一次权益要改十几处，必然漏 | ⛔ 一处定义、多处读取 |
| 16 | `is_vip()` 这种布尔够用 | 不同等级不同值会退化成一堆 if | ⚠ 用 `get_benefit(key)` |
| 17 | 到期就清掉权益数据 | 玩家**永久损失**已解锁内容 | ⛔ 只改生效状态 |
| 18 | 到期删除最干净 | 续期后**历史等级丢失**，最严重 | ⛔ 绝不删除累积数据 |
| 19 | 到期用定时任务实现 | 服务器重启/玩家离线会**漏执行** | ⚠ 硬边界判定 |
| 20 | 到期什么都不做 | 权益继续生效 = 白嫖 | ⛔ 必须判定 |
| 21 | 续期直接 `end + duration` | 未到期续费反而**缩短** | ⚠ `max(end, now) + duration` |
| 22 | 到期后补买也用 `end + duration` | 已过期那段被算进去，得到"倒欠"时间 | ⚠ 先 `max` 再加 |
| 23 | 等级阈值写死在代码里 | 改数值要重新发版 | ⚠ 进配置表 |
| 24 | 本地缓存权益不用管 | 缓存无失效 = 权益**永久停在旧值** | ⚠ 必须有失效路径 |
| 25 | 跨时区玩家看到不同剩余秒数 | 秒数应一致，只有**显示格式**变 | ⚠ 实测改时区验证 |
