# genres-idle-sim — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/genres-idle-sim.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 产出率 `delta` 直乘 | 帧率不同结果不同，要固定步长 + 累加器 |
| 2 | 离线收益 = 每秒产出 × 离线秒数 | 忽略依赖链、上限、buff，要跑完整 tick 循环 |
| 3 | 用累计游戏内秒数当离线基准 | 暂停/切后台/time_scale 都失真，要用 Unix 时间 |
| 4 | 离线上限写死 8 小时 | 应作为 MetaUpgrade 解锁项 |
| 5 | 不防改系统时间 | 要记录上次时间、拒绝"倒退" |
| 6 | 建筑放置用 Area2D 重叠检测 | 网格放置查二维数组 O(1)，Area2D 只适合自由放置 |
| 7 | 每建筑一个 `_process` | 1000 个回调显著开销，要 TickEngine 批量遍历 |
| 8 | 资源键用 String | 用 StringName 避免每次哈希新字符串 |
| 9 | `FLAG_COMPRESS` 当加密 | 是压缩不是加密 |
| 10 | `OS.get_user_data_dir()` 等于 `user://` | 前者 OS 级绝对路径，后者项目数据目录 |
| 11 | 每帧写存档 | 拖垮 IO 且崩溃留半截文件，要周期 + 原子写 |
| 12 | 资源量用 int 且不设上限 | 长期运行精度丢失或溢出 |
