# vfx-feel — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/vfx-feel.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 特效越多手感越好 | 要**与事件重要性匹配** |
| 2 | GPU 粒子一定更快 | Web/兼容渲染器/需读粒子数据 → **CPU 更合适** |
| 3 | 震动就是随机偏移 | 是 **trauma + 噪声**，白噪声看起来像筛子 |
| 4 | 震动加场景根节点 | 加 **Camera** |
| 5 | 多源命中各自震动 | 要**合并 trauma**，否则互相覆盖 |
| 6 | `time_scale=0` 后定时器会恢复 | **默认也停**，要 ignore_time_scale |
| 7 | 顿帧越长越爽 | 太长难受，几十毫秒量级 |
| 8 | 粒子 emitting=false 就回收了 | 要看完整生命周期 |
| 9 | `restart()` 随时能调 | **时机不对会不播** |
| 10 | 残影复制 Sprite 就行 | **材质要独立** |
| 11 | 稳态性能够就行 | **同时触发的瞬间**才是杀手 |
| 12 | 特效不用池化 | 高频触发必须池化 |
| 13 | 4.7.2 有 Trail3D | 官方是 **RibbonTrailMesh/TubeTrailMesh**，待核对 |
| 14 | 伤害数字放场景里 | 要放 **UI 层**并做坐标转换 |
| 15 | 命中反馈六通道全开 | 按重要性选档 |
