# upscaling — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/upscaling.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | stretch 能降 3D 渲染分辨率 | **两套独立机制** |
| 2 | FSR2 能治所有锯齿 | ⛔ 官方：FSR2 自带时域抗锯齿，但**镜面反射锯齿仍以 TAA 最有效**；ⓘ 透明边缘（alpha scissor）见 #21 —— MSAA 无效，**FXAA / TAA / 超采样有效** |
| 3 | 有 FSR3 | **没有**，只有 FSR2.2 |
| 4 | 有 DLSS/XeSS | 只有**实验性 fork**，不可投产 |
| 5 | TAA 三个渲染器都能用 | **仅 Forward+** |
| 6 | 2D MSAA 和 3D MSAA 一样 | 支持矩阵**完全不同** |
| 7 | 超分对所有游戏都好 | **2D 像素风有害** |
| 8 | UI 和 3D 一起超分 | UI 会被**糊掉**，要分层 |
| 9 | FSR2 在各渲染器一样 | Compatibility **回退双线性** |
| 10 | 开了 HDR 就有 HDR | **Filmic/ACES 永远 SDR** |
| 11 | 4.7 stretch 默认值没变 | 改成 **canvas_items/expand** |
| 12 | 后处理随便开 | 要按**性能代价排序**取舍 |
| 13 | 调画质靠感觉 | 要**逐项开关对比**定位 |
| 14 | Nearest 缩放没用 | 复古/低分辨率风**专为它设计** |
| 15 | MetalFX 全平台 | 仅 **Apple 平台** |
| 16 | scale>1.0 是超采样 | ⛔ 官方：**不支持**，统一回退双线性下采样 |
| 17 | scale=1.0 就是关闭超分 | ⚠ **FSR2/MetalFX Temporal** 下是**原生分辨率作 TAA** |
| 18 | Nearest 随便给个 0.7 | ⚠ 官方建议 **1 的整数除数**（0.5/0.25…），否则像素不均 |
| 19 | FSR 就是 FSR2 | ⛔ 枚举里 **FSR=1.0 与 FSR2=2.2 是两个值** |
| 20 | MetalFX 在 Mac 上就能用 | ⚠ 是**驱动级**限制：必须 Metal 驱动 |
| 21 | MSAA 能治植被闪烁 | ⛔ alpha scissor 走 discard，**MSAA 无效** |
| 22 | AA 方案选一个就行 | ⚠ 必须先**确认渲染器**，支持矩阵完全不同 |
| 23 | 调 3D 超分能修 UI 糊 | ⛔ 2D 走 **stretch**，3D 走 scaling_3d，是两条管线 |
| 24 | 开了 HDR 就有 HDR 输出 | ⚠ **Filmic/ACES 恒输出 SDR**，要先改 tonemap |
| 25 | 后处理代价用经验值 | ⚠ 同效果在不同分辨率/渲染器下**差异很大**，要实测排序 |
| 26 | TAA 与 FSR2 能叠加改善 | ⛔ 官方：`Use TAA` 在 FSR2 下**被忽略**（时域抗锯齿优先） |
| 27 | FSR2 降分辨率一定提速 | ⛔ 官方：原生分辨率下启用 FSR2 **反而降性能**，且比原生 TAA 更贵；⚠ 只在有 GPU 余量时用 |
| 28 | SSAA 用 1.5 和 2.0 差不多 | ⚠ 官方：走硬件双线性下采样，**整数倍更锐利**（2.0 优于 1.5） |
| 29 | 改 scale 只影响分辨率 | ⛔ 会连带施加**负 mipmap LOD bias**，AA 再叠加 `-0.25`(FXAA)/`-0.5`(TAA)；运动时发颗粒感 |
| 30 | 降 scale 一定涨帧 | ⛔ 官方 Troubleshooting：降到 0.5 不涨说明**瓶颈不在分辨率**（draw call / SDFGI / SSAO） |
| 31 | 缩放是线性的，0.1 微调可控 | ⛔ **逐轴**：0.5 只渲 1/4 像素，0.1 的改动带来远超预期的帧时间变化 |
| 32 | FSR Sharpness 值越高越锐 | ⛔ 官方：默认 `0.2`，**值越高锐化越少**，`2.0` 等于关掉锐化 |
| 33 | SMAA 要装社区插件 | ⚠ 4.2+ **内置**（`screen_space_aa` 枚举），⛔ 不是社区方案 |
| 34 | FXAA 三个渲染器都能用 | ⛔ 仅 **Forward+ / Mobile**，Compatibility 不支持 |
| 35 | TAA 不影响透明背景 | ⛔ 官方已知问题：透明 viewport 上开 TAA / FSR2 会**变不透明** |
| 36 | 用分辨率缩放代替画质档位 | ⛔ 官方建议**同时暴露缩放与画质设置**两个选项，⛔ 不要用缩放替代低端硬件的画质降级 |
| 37 | 桌面预览过了就算过 | ⛔ 要**目标渲染器 + 真机**；编辑器预览的渲染路径与出包不同 |
| 38 | 改分辨率不用重测 | ⚠ 超分 / AA 的表现**随分辨率变化**，⛔ 档位要逐档验证 |
| 39 | 画质档位只做一套 | ⚠ 低端与高端应走**不同组合**，⛔ 不是同一套参数调数字 |
| 40 | 验收看设置面板 | ⛔ **看截图**；面板上"开着"不等于生效（如 `Use TAA` 被忽略） |
| 41 | 2D 纹理也会被 LOD bias 影响 | ⚠ 默认**不开 mipmap** 所以通常不受影响；⛔ 给 2D 纹理开了 mipmap 就会变颗粒 / 噪点 |
| 42 | 画质验收只测默认档 | ⛔ 要在**最高档与最低档**都测；中间档的表现不等于两端 |
