# diagnostics — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`flow/godot/diagnostics.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | GDScript 有 try/catch | **没有**，靠显式控制流 |
| 2 | print 会写出去 | 崩溃时 stdout **可能没刷盘** |
| 3 | 脚本错误和崩溃一个钩子 | **三个通道**，崩溃靠外部 |
| 4 | assert 只是提示 | release **不求值**，副作用会丢 |
| 5 | assert 能做发布版校验 | **不能** |
| 6 | load 返回 null 时会报错 | **静默**，要显式分支 |
| 7 | 退出码 0 就是正常 | **可能掩盖异常** |
| 8 | 崩溃能靠 Godot 回调上报 | 进程**直接终止** |
| 9 | Sentry 装上就能用 | 要**带符号模板**，待核对 |
| 10 | Movie Maker 能做玩家录像 | **明确不适用** |
| 11 | Movie Maker 能运行时开 | 只能**启动时启用** |
| 12 | Performance 都能用 | 内存项**发布版不可用** |
| 13 | 单帧掉帧就降级 | 要**采样窗口**，否则误判 |
| 14 | 日志随便写 | 是**隐私边界** |
| 15 | 截图不含隐私 | 可能含**聊天与昵称** |
