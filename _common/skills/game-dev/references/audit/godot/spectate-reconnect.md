# spectate-reconnect — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/spectate-reconnect.md`
> 回放录制与确定性见 `replay.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | Godot 内置快照插值 / 回溯 / 回滚 | **都没有**，全要自己实现 |
| 2 | 既录输入又录位置更保险 | 混合事实源 → 重播中角色**来回跳跃**且无法定位 |
| 3 | 回放里重放 `_process(delta)` 就行 | 必须**固定步长**，帧率不同结果不同 |
| 4 | 144Hz 和 60Hz 回放一样 | 基于渲染时间就会漂移、拖窗口改变回放长度 |
| 5 | 比赛开始 `seed()` 一次就确定性了 | `randi()` 是**全局流**，共享状态 |
| 6 | `RandomNumberGenerator` 跨版本一致 | 底层 PCG32 是**实现细节**，不承诺兼容 |
| 7 | 字典遍历顺序是契约 | **不是**，录事件必须显式排序 |
| 8 | 录 `RigidBody3D` 状态能跨机一致 | 不能，要录意图或用自定义确定性模拟 |
| 9 | 版本号写字符串 `"v3"` 也行 | 4 字节字段后**所有帧错位** |
| 10 | `store_var()` 能当长期回放格式 | 非兼容契约，且反序列化**可能执行代码** |
| 11 | 一次性压缩整个回放 | 移动端 **OOM**，要按帧组压缩 |
| 12 | `eof_reached()` 能判断还剩多少 | 要用 `get_position() < get_length()` |
| 13 | `any_peer` 等于可信 | 只表示**能调用**，服务器必须再查 sender id |
| 14 | `call_local` 是广播给所有人 | 是**调用端本地也执行**，会让主机跟着切视角 |
| 15 | `get_remote_sender_id()` 随时能取 | RPC 外返回 **0**，`await` 后会丢失 |
| 16 | 观战者当普通玩家 authority | 应是纯接收端，不参与判定 |
| 17 | 观战流实时接收即渲染 | 要 200–600ms 缓冲，否则**窥屏**且抖动 |
| 18 | "客户端不渲染"就等于不可见 | 服务器必须**隐藏未揭示信息** |
| 19 | Peer ID 是玩家身份 | 是会话 ID，重连后**会变** |
| 20 | 断线就 `queue_free()` 角色 | 抛射物变孤儿、计分不一致；应**保留+AI 托管** |
| 21 | 永远保留掉线角色 | 会长期占据据点，要有 `reconnect_grace_ms` |
| 22 | 连接成功就是重连成功 | 要**收到连续权威快照且 tick 被确认** |
| 23 | 增量能补齐已结算的击杀 | 不能，窗口必须是**完整世界版本** |
| 24 | `close()` 会通知对方 | **不发射** `peer_disconnected`，用 `disconnect_peer()` |
| 25 | 只接 `peer_disconnected` 够了 | 认证失败走另一信号，会**泄漏等待中的会话** |
| 26 | P2P 迁移选最大 peer id | 新 ID 随机不可信，要按**稳定外部 ID** 排序 |
| 27 | 每个客户端改自己角色 authority 即可 | 要**一次性切换世界 authority** + 可靠 RPC 重建 |
| 28 | 网络分区时新主机直接上位 | 会形成**双主**，仲裁必须 quorum |
| 29 | 有专用服务器也要迁移主机 | 不需要，服务器保持世界状态即可 |
| 30 | 回溯时复制整个节点树 | 只复制**最小包围盒** |
| 31 | 无限制回溯 | 帧尖峰，限制 20–30 tick 并受速率限制 |
| 32 | 每帧把 `global_position` 赋权威值 | "走路像橡皮筋"，要平滑纠正 |
| 33 | smoothing 越重越好 | 命中反馈延迟数百毫秒 |
| 34 | 插值缓冲越大越好 | 所有非本地实体更旧，**有效延迟增加** |
| 35 | `replication_interval=0.0` 适合大量实体 | 只适合小对象，观战流会炸 |
| 36 | 把回溯包围盒回传当最终位置 | 等于**把延迟补偿变成作弊** |
