# hotupdate — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`flow/godot/hotupdate.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 热更就是下载文件替换 | 资源热更与代码热更**差一个量级** |
| 2 | 加载新包就自动生效 | **已缓存/已实例资源不会自动换血** |
| 3 | 代码热更是技术问题 | 是**合规问题**，后果是下架 |
| 4 | iOS 偷偷热更没事 | 审核指南 **2.5.2 明确禁止** |
| 5 | GDScript 替换是原子的 | 脚本状态/信号/继承**不会原子切换** |
| 6 | C#/GDExtension 也能热更 | **ABI 冲突**，非常困难 |
| 7 | 补丁包和完整导出一样 | 只导资源，**与完整导出不同** |
| 8 | 配置不用版本校验 | 旧客户端读新配置**会崩** |
| 9 | DLC 没买就跳过 | 引用了 DLC 资源要**占位** |
| 10 | 更新失败重下就行 | 要能**回滚** |
| 11 | 补丁下载完就可信 | 要**验证完整性** |
| 12 | 增量一定比全量好 | 按**实际体量**定 |
| 13 | 主机平台条款公开 | **受 NDA 约束**，要问平台代表 |
| 14 | 教育类可以随意执行代码 | 有**有限例外**且要求代码可查看编辑 |
| 15 | 只有苹果管这个 | Google Play / Xbox **同样禁止** |
