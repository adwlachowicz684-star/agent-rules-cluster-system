# environment-systems — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/environment-systems.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | Godot 有官方水面 | **没有**，要自己做或找插件 |
| 2 | 没有浮力组件就做不了浮力 | `apply_force` **足够实现** |
| 3 | 波浪视觉和物理分开算没事 | 会**漂在另一个高度** |
| 4 | 纯 sine 够用 | Gerstner **更像开放水域** |
| 5 | 换天空就是换背景图 | 天空/雾/环境光/曝光/GI **联动** |
| 6 | PhysicalSky 更好所以总用它 | 更贵、**只一个太阳**、夜间变黑 |
| 7 | ProceduralSky 只能一个太阳 | **最多四个** |
| 8 | 烘焙后能移动太阳 | Static **完全锁定** |
| 9 | 昼夜循环每帧更新光照 | 要**固定节拍 + 缓存** |
| 10 | 雨放场景里就行 | 要**跟随相机** |
| 11 | 闪电就是调亮光源 | 会**炸曝光** |
| 12 | 天气切换直接换 | 要**平滑过渡** |
| 13 | 水下效果和陆上一样 | 要**切换雾/后处理** |
| 14 | SDFGI 和烘焙随便选 | 大世界**更适合 SDFGI** |
| 15 | 环境光是独立设置 | 主要**来自天空** |
| 16 | 用系统时钟驱动昼夜 | **可篡改**，且官方禁用于精确计时；要用单调 ticks |
| 17 | 天气用一组 bool 叠加 | 雨雪**同时为真**，状态与画面不一致 |
| 18 | 当前天气只存一份就够 | 还缺**目标与过渡进度**，表达不了正在转 |
| 19 | 过渡中途打断不用取消旧过渡 | 旧粒子**残留不停** |
| 20 | Tween 不用保存句柄 | 场景切换**泄漏**，或在已释放节点上跑 |
| 21 | 湿滑只改材质 | **看起来湿但抓地力没变**，刹车/扭矩都要驱动 |
| 22 | 联动状态不进存档 | 读档后**下雨但地面是干的** |
| 23 | 进入区域时应用一次天气 | 天气中途变了**不更新**，要订阅变化 |
| 24 | 室内/洞穴不用屏蔽天气 | **屋顶漏雨** |
| 25 | 区域重叠各写各的 | 天气**来回抖**，要按优先级仲裁 |
| 26 | 各客户端自己推进时钟 | 几帧后**完全不同步**，要单一权威 |
| 27 | 每秒发同步包补时钟 | 时钟**跳变**，天色突然闪 |
| 28 | 暂停时不冻结昼夜时钟 | **菜单里天黑了**，且恢复后一次性补量 → 天色跳变 |
| 29 | 存档存太阳角度 | 角度是**派生值**，改了时间缩放后与真实进度脱节 |
| 30 | 分别插值天空色/环境色/灯光色/雾色 | **太阳方向与天空太阳位置不一致** |
| 31 | 太阳角度用欧拉角直映 | **绕错轴**，夜里太阳从地面升起 |
| 32 | 把月亮当普通平行光 | 夜间场景**被照亮**，晚上和白天一样亮 |
| 33 | 大世界不收阴影级联 max_distance | 远处**分辨率与性能同时变差** |
| 34 | 用 FogVolume 当全局雾 | 它只能**在已有全局雾上增减密度** |
| 35 | 选型前不查渲染器能力矩阵 | Compatibility **无体积雾**，目标平台效果直接消失 |
| 36 | 雨雪碰撞节点给 CPUParticles 用 | **完全无效且不报错** |
| 37 | 天气改了不接 AI 感知 | 雨天敌人**照样远距离发现你**，潜行设计失效 |
| 38 | 离开区域不清理旧粒子 | **离开雨区还在下** |
