# ai-tactics — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的做法部分：`howto/godot/ai-tactics.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 战术规则写在单个敌人 AI 里就行 | 跨个体规则写在个体里 → 只能互相猜测，最后变成补丁堆 |
| 2 | 目标选择取"分最高的" | 无迟滞会**在评分边界反复切换**；要阈值 + 最短保持时间 |
| 3 | 嘲讽就是直接设目标 | 应**加威胁**让它自然胜出；直接设会让嘲讽结束立刻回头 |
| 4 | 一个 `_current` 变量够当仇恨 | 目标死亡后不知道打谁；要有**威胁表** |
| 5 | 编队就是每个单位追玩家 | 全部挤向同一点 → 被避障推开再挤回 → "原地蠕动" |
| 6 | 槽位按距离每帧重分配 | 两个单位争同一槽位来回横跳；要**固定分配** |
| 7 | 槽位世界坐标直接当移动目标 | 会穿墙；仍要交给 `NavigationAgent` |
| 8 | 掩体运行时射线找 | 每帧几十条射线且**结果不稳定**（来回跑）；要预烘焙点 |
| 9 | 掩体"到了才算占用" | 两个单位同时选中 → 都跑过去；要**预约制** |
| 10 | 单位死了令牌自然释放 | 令牌泄漏 → **所有人不再攻击**（"集体发呆"） |
| 11 | 攻击间隔固定值就够 | 所有敌人同频，玩家找到节拍后无脑闪避 |
| 12 | 破绽窗口只是数值 | 没有可读信号 = 机制不存在，玩家不知道该反击 |
| 13 | 难度自适应改血量伤害 | 易被察觉；应优先改**行为参数**（频率/并发/延迟） |
| 14 | 实时反馈式调整难度 | 玩家感到"赢了就被惩罚"；用长窗口统计或让玩家选档 |
| 15 | 分帧就是每 N 帧更新一次 | 若都同一帧决策 → 尖峰；要按 id 取模**错开** |
| 16 | LOD 切换即时生效 | 边界反复切换 → 行为跳变（攻击中突然变巡逻）；要迟滞 |
| 17 | 避障一直开着最安全 | 官方：大量 agent 有**显著开销**；只给需要的开 |
| 18 | 调试路径要自己画 | `NavigationAgent.debug_enabled` 已内建，且反映真实内部状态 |
| 19 | 调试可视化常开 | 一屏 20 个视锥看不清画面，还会掩盖真实渲染问题 |
| 20 | `avoidance_priority` 随便设 | 它决定谁让路；队长/Boss 应更高，否则互相推挤 |

## 审核时的判据（可观测）

- [ ] 单个敌人单独存在时，战术规则不报错也不空转
- [ ] 连续战斗 3 分钟，目标切换次数**明显少于**评分变更次数（迟滞生效）
- [ ] 杀掉当前目标后，AI 转向威胁表里的下一名（⛔ 不是发呆）
- [ ] 嘲讽结束 5 秒后，AI 按威胁表自然回落（⛔ 不是立刻回头）
- [ ] 一群敌人接近玩家时**不挤成一团**（有槽位/外围限制）
- [ ] 20 个敌人时，同时攻击的**不超过设定值**
- [ ] 杀掉持有令牌的敌人后，其余敌人**仍能继续攻击**
- [ ] 掩体被占用时，第二个单位会选别的（⛔ 不是挤同一个）
- [ ] 单位中途死亡后，其预约的掩体**会在超时后释放**
- [ ] 远处单位的 AI 更新频率**低于**近处（LOD 生效）
- [ ] 打开调试总开关能看到：状态、视锥、路径、令牌持有者
- [ ] 关闭调试总开关后，画面干净
