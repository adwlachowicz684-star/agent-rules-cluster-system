# animation — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于流程结束后审核自己的产出、约束边界。
> 「怎么做」见同 skill 的流程部分：`howto/godot/animation.md`

## 常见漏写

| # | 漏写 | 后果 | 审查规则 |
|---|---|---|---|
| 1 | `create_tween()` 未保存引用 | 无法 kill，重复触发叠加 | GD02 |
| 2 | 重启动画前未 `kill()` | 两个 Tween 抢同一个属性，抖动 | GD02 |
| 3 | `get_tree().create_tween()` 未 `bind_node` | 节点释放了 Tween 还在 | GD02 |
| 4 | 动画名/参数路径用字面量 | 拼错静默失效 | GD54 / GD53 |
| 5 | 该用 `lerp` 的地方用 Tween | 每帧重建，GC 压力 | 人工 |
| 6 | `lerp(a,b,0.1)` 固定系数 | 帧率相关，不同机器表现不同 | 人工 |
| 7 | 方法轨里的方法改名 | 动画调用失效，不报错 | 人工 |
| 8 | 状态转换散在各处的 if 里 | 加一个状态要改 N 个地方；要**集中**在一处（转移表或 AnimationTree） |
| 9 | 步频写死，与移动速度脱钩 | 加速/减速时脚与地面**相对滑动**；播放速度要与水平速度**成比例** |
| 10 | 转向用 `scale.x = -1` 瞬时翻转 | ⛔ 表现为**闪现**；要 blend 或短过渡 |
| 11 | 非循环动画播完不回退 | 反复触发会**卡在最后一帧**；要明确回退到哪个状态 |
