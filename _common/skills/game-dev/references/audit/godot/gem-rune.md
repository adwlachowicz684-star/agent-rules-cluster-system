# 审核条目 —— 宝石 / 符文（镶嵌系统）

> 用法：按功能点收尾时逐条对照。格式：本能以为 → 实际 → 审查规则

| # | 本能以为 | 实际 | 审查规则 |
|---|---|---|---|
| 1 | 宝石做成 `Node` 好挂特效 | Node 带树路径与 `_process`，不能被 `ResourceSaver` 存，进背包/存档/网络包会带整棵子树 | ⚠ 必须是 `Resource` |
| 2 | 插槽数做成全局常量 | 高级装备孔多这条设计无法实现 | ⚠ 插槽数是**装备实例**的属性 |
| 3 | 插槽类型也存进实例 | 配表改了旧装备不跟随，两边漂移 | ⚠ 类型约束来自配表，实例只存 `index/type/gem_id` |
| 4 | `socket_type` 到处赋值 | 装备与宝石两边字符串不一致 → 永远插不进去且**不报错** | ⚠ 只允许配表导入与反序列化两处赋值 |
| 5 | 覆盖镶嵌 = 先删再插 | 中间态失败则宝石**凭空消失** | ⛔ 必须一次原子替换：算新数组→校验→整体写回 |
| 6 | 先扣宝石再镶嵌 | 扣了没镶上，资产凭空消失 | ⛔ 试算→扣费→提交→回滚，顺序写死 |
| 7 | 先镶嵌再扣宝石 | 镶了没扣成，白嫖 | ⛔ 同上，扣费是唯一外部副作用且在提交前 |
| 8 | 拆卸损耗不写进 UI | 玩家拆出降级宝石会认为是 bug，且**无法自证清白** | ⚠ 确认弹窗必须能直接读到损耗规则 |
| 9 | 合成比与拆卸返还比随便定 | `3→1` 且 `1→3` 无损 = 无限刷 | ⚠ 必须验算无套利环 |
| 10 | 合成失败材料"没说" | 按全损处理，玩家认为被吞 | ⚠ 失败时材料去向必须明确（全损/保留/返还部分） |
| 11 | 套装按宝石总数判定 | 6 颗全插一把武器也触发，违背"分布在多件装备"的设计 | ⚠ 按 `(装备槽位, 宝石类型)` 去重集合算 |
| 12 | 相邻插槽共鸣用 `index+1` 推导 | 换装备后指向的形状完全不同 | ⚠ 邻接表存在装备定义里 |
| 13 | 宝石属性直接 `attack +=` | 下次重算被覆盖 → "刚镶上变强，打一场又变回去" | ⛔ 镶嵌是管线中一环，不是管线后的补丁 |
| 14 | 存档存宝石 Resource 引用 | 配表删宝石后旧档指向空，且**不报错** | ⛔ 存 `gem_id` + 可变字段 |
| 15 | 解析失败用默认宝石替换 | 玩家看到属性变了但不知道为什么 | ⚠ 进隔离区，不静默替换 |
| 16 | 合成成功率在客户端算 | 改内存必成 | ⛔ 服务端裁决 |
| 17 | 客户端能决定宝石是否消耗 | 可伪造消耗结果 | ⛔ 客户端只发意图 |
| 18 | 符文和宝石是同一个东西 | 宝石挂装备（换装就没），符文挂角色（换装还在） | ⚠ 先分清挂谁身上 |
| 19 | 镶嵌后不刷缓存 | UI 显示旧面板 → 玩家以为没镶上 → 再点一次 | ⚠ 提交成功立即重算并广播 |
| 20 | 预览自己算一遍 | 预览/提交/展示三份逻辑漂移 | ⛔ 预览与提交共用同一试算函数 |
| 21 | 同一宝石可镶在多件装备上 | 复制漏洞 | ⚠ 实例唯一，镶嵌时校验未被占用 |
| 22 | 宝石等级只存模板里 | 合成升过级的宝石与模板不一致 | ⚠ 实例自己存 `tier` |
| 23 | 镶嵌上限只在 UI 置灰 | 服务端仍接受超限请求 | ⚠ 上限在配表与服务端双重校验 |
| 24 | 拆下来的宝石直接进背包就行 | 若背包满，宝石**静默消失** | ⚠ 拆卸前先校验背包容量，不足则整个操作失败 |
