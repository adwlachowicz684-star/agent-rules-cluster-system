# 02 读写与原子落盘（存档域）

> **前置**：[01-存档结构设计](01-存档结构设计.md) 已验收
> **本步交付**：一个**断电不会坏**的读写层
> **对应**：流程 `flow/godot/save-migration.md` · 审核 `audit/godot/save-migration.md`

⚠ **本步是整个存档系统里最重要的一步。** 直接写目标文件的存档，
一次断电就能让玩家几十小时进度归零——而且**无法修复**。

## 0. 交付物定义

能演示（⛔ **必须真杀进程测，不能只测正常路径**）：

1. 存档写到 **50% 时强杀进程** → 重开游戏，**旧存档仍在且能读**
2. 正常保存 → 文件完整
3. 保存失败（磁盘满/权限）→ **不破坏已有存档**，且有明确报错

## 2. 工序

### Step 1　⚠ 原子落盘（核心）　`[save/02#S1]`

【读】howto/godot/save-migration.md —— 只查本步涉及的章节，⛔ 不要通读全文

【做】**绝不直接写目标文件**：

```text
① 写 user://saves/slot_0.save.tmp
② flush + close（确保真的落盘）
③ 校验 tmp 能被读回（自己读一遍）
④ 把旧的 slot_0.save 改名为 slot_0.save.bak
⑤ 把 tmp 原子 rename 成 slot_0.save
```

⚠ **同一文件系统内的 rename 是原子操作**（各主流 OS 都保证）。
⛔ 不要"先删再写"——中间那一瞬断电就是零长度文件。

【产出】一个 `save_atomic()` 函数

【判据】**实测**：在 tmp 写完后、rename 前杀进程 → 重开：`slot_0.save` 仍是旧内容

【审】audit/godot/save-migration.md —— 本步相关的具体条目（步骤级即时检查）

### Step 2　写前备份　`[save/02#S2]`

【读】howto/godot/save-migration.md —— 只查本步涉及的章节，⛔ 不要通读全文

【做】第 ④ 步的 `.bak` **保留**，⛔ 不要覆盖成"上上次的"
⚠ 保留**一份**足够；保留多份要有清理策略

【产出】`slot_0.save.bak`

【判据】每次保存后 `.bak` 是**上一次**的内容

【审】audit/godot/save-migration.md —— 本步相关的具体条目（步骤级即时检查）

### Step 3　写后自读校验　`[save/02#S3]`

【读】howto/godot/save-migration.md —— 只查本步涉及的章节，⛔ 不要通读全文

【做】保存完成后，立刻把文件读回来 `from_dict()` 一次，失败就回滚

⚠ 这一步能抓住"写出来的 JSON 其实是坏的"（比如序列化中途异常）。
⛔ 不要写完就认为成功了。

【产出】一个 `verify_saved()` 检查

【判据】人为把序列化改成返回坏数据 → **保存报错且不覆盖旧档**

【审】audit/godot/save-migration.md —— 本步相关的具体条目（步骤级即时检查）

【读】howto/godot/save-migration.md —— 只查本步涉及的章节，⛔ 不要通读全文

【做】

【产出】保存前的空间检查

## 3. 参考实现

```gdscript
# save_io.gd — Godot 4.x
extends Node

const SAVE_DIR := "user://saves/"

func save_atomic(slot: int, data: SaveData) -> int:
    DirAccess.make_dir_recursive_absolute(SAVE_DIR)
    var path := SAVE_DIR + "slot_%d.save" % slot
    var tmp := path + ".tmp"
    var bak := path + ".bak"

    var json := JSON.stringify(data.to_dict())
    var need := json.length() * 2
    if FileAccess.get_space_left() < need:
        push_error("存档空间不足：需要 %d，剩余 %d" % [need, FileAccess.get_space_left()])
        return ERR_INSUFFICIENT_SPACE

    # ① 写 tmp
    var f := FileAccess.open(tmp, FileAccess.WRITE)
    if f == null:
        return FileAccess.get_open_error()
    f.store_string(json)
    f.flush()          # ⚠ 强制落盘
    f.close()

    # ② 自读校验
    var check := FileAccess.open(tmp, FileAccess.READ)
    if check == null or SaveData.from_dict(JSON.parse_string(check.get_as_text()) or {}) == null:
        push_error("存档校验失败，保留旧档")
        DirAccess.remove_absolute(tmp)
        return ERR_INVALID_DATA
    if check:
        check.close()

    # ③ 备份旧档
    if FileAccess.file_exists(path):
        DirAccess.remove_absolute(bak)
        DirAccess.rename_absolute(path, bak)

    # ④ 原子切换
    var err := DirAccess.rename_absolute(tmp, path)
    if err != OK:
        # 回滚
        if FileAccess.file_exists(bak):
            DirAccess.rename_absolute(bak, path)
        return err
    return OK

func load_save(slot: int) -> SaveData:
    var path := SAVE_DIR + "slot_%d.save" % slot
    if not FileAccess.file_exists(path):
        return null
    var f := FileAccess.open(path, FileAccess.READ)
    if f == null:
        return _try_bak(slot)
    var parsed = JSON.parse_string(f.get_as_text())
    f.close()
    var data := SaveData.from_dict(parsed if parsed is Dictionary else {})
    if data == null:
        return _try_bak(slot)      # ⚠ 主档坏了自动退到备份
    return data

func _try_bak(slot: int) -> SaveData:
    var bak := SAVE_DIR + "slot_%d.save.bak" % slot
    if not FileAccess.file_exists(bak):
        return null
    var f := FileAccess.open(bak, FileAccess.READ)
    if f == null:
        return null
    var parsed = JSON.parse_string(f.get_as_text())
    f.close()
    return SaveData.from_dict(parsed if parsed is Dictionary else {})
```

## 5. 常见返工

⚠ **直接写目标文件** —— 这是最致命的一条。断电 = 零长度或半截文件 = 进度全丢。

⚠ **写完不校验** —— 序列化异常时写出半截 JSON，下次读直接崩。

⚠ **`.bak` 保存前先删除** —— 删除后、写备份前断电 → 备份也没了。
✅ 顺序是"写 tmp → 校验 → 备份 → 切换"。

⚠ **不检查磁盘空间** —— 写到一半失败，留下坏 tmp，且旧档可能已被移走。

⚠ **忘了 `flush()`** —— 只 `close()` 在某些平台上不保证落盘。

⚠ **只在正常路径测试** —— 存档的 bug **全部在异常路径**。
⛔ 只测"保存成功"等于没测。
