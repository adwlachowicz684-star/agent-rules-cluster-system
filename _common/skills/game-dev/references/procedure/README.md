# procedure — 开发工序层（按功能点）

> 本层回答一个 `flow/` 和 `audit/` 都不回答的问题：**按什么顺序做、每步产出什么、怎么验收。**

| 层 | 回答什么 | 组织方式 |
|---|---|---|
| `references/flow/` | 这个域怎么做（知识 + 可抄代码） | 按**域** |
| `references/audit/` | 不能怎么做（反模式坑表） | 按**域** |
| **`references/procedure/`** | **按什么顺序做、每步交付什么、怎么验收** | 按**功能点** |

三者不是替代关系，是一次开发的三段：

```text
要做一个功能
  → ① 查 procedure/<引擎>/<域>/ 找到对应功能点，按工序做
  → ② 实现时缺细节 → 查 flow/<引擎>/<域>.md 抄代码
  → ③ 做完了 → 查 audit/<引擎>/<域>.md 逐条过坑表
```

## 目录结构

```text
references/procedure/
├── README.md              本文件（层说明 + 功能点文件统一模板）
├── index.md               功能点总索引（域 → 功能点 → 文件）
└── godot/
    ├── character/         角色控制域
    │   ├── 00-域流程总览.md    ← 入口：先看这个，决定从哪个功能点开始
    │   ├── 01-<功能点>.md
    │   └── …
    └── save/              存档域
        ├── 00-域流程总览.md
        └── …
```

⚠ **永远先打开 `00-域流程总览.md`。** 它给出该域的功能点拆解、依赖顺序、
哪些必须先做——⛔ 不要直接跳到某个编号文件，功能点之间有前置关系。

## 功能点文件的统一模板

每个功能点文件必须包含以下七节，**顺序固定**（这样调用时位置可预测）：

```markdown
# <功能点名>（<所属域>）

> **前置**：<必须先完成的功能点，或"无">
> **本步交付**：<一句话，可验收的产出>
> **对应**：流程 `flow/godot/<域>.md` · 审核 `audit/godot/<域>.md`

## 0. 交付物定义
  这一步做完，应该能演示什么 / 存在哪些文件 / 跑通哪个场景。
  ⚠ 写不出"能演示什么"的功能点，说明切分有问题。

## 1. 前置检查清单
  开工前逐条确认（缺一样就先补，否则做到一半返工）。

## 2. 工序
  Step 1 … Step N
  每步固定三要素：
    【做】 具体动作
    【产出】 这一步结束时磁盘上/场景里多了什么
    【判据】 怎么确认这步做对了（可观测，不是"应该没问题"）

## 3. 参考实现
  可直接抄的代码（写清 Godot 版本与 2D/3D 差异）。

## 4. 验收清单
  逐条打勾的 checklist。⛔ 不能"看起来差不多了"就过。

## 5. 常见返工
  ⚠ 这一步最容易做错、做完要重来的几点。

## 6. 下一步
  完成后去哪个功能点；以及自审入口（audit 文件）。
```

## 用这套工序的硬规则

1. ⚠ **一个功能点做完并验收通过，才进入下一个。** 跳着做会让后面的验收无法判定
   （比如跳跃手感没做完就去接动画，你分不清是移动的问题还是动画的问题）。
2. ⚠ **每步的【判据】必须是可观测的。** "应该没问题""感觉对了"不算判据。
   写不出判据的步骤，要拆细或改成可测的形式。
3. ⚠ **【产出】要落在磁盘或场景里**，不能只在脑子里。每步结束都要有可指认的东西。
4. ✅ **工序里的参数值都是起点，不是终点。** 手感/数值类参数必须实测后回填。
5. ⚠ **第 6 节的自审入口必须走。** 做完不看 `audit/` 等于把审核环节省了。
6. ⛔ **不要把 procedure 当知识库查。** 要查"这个 API 怎么用"去 `flow/`，
   procedure 只管"按什么顺序做"。

## 与 verify.py 的关系

工序里出现 ⚠ 待核实 的参数/API，用 `scripts/verify.py` 登记并运行时回填：

```bash
python3 scripts/verify.py                              # 列出未验证项
python3 scripts/verify.py --verify=V5001 --result=failed
```

⛔ 工序中标注"待核实"的值**不得直接当生产参数**。
