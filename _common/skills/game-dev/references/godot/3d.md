# Godot 4.x 3D 开发

3D 角色控制见 `character.md`，本文件覆盖场景搭建、相机、材质、光照、着色器入门。

## 1. 坐标系与变换

**Godot 3D 是右手系，-Z 是"前"**：

```
+Y 上
-Z 前（相机默认朝这个方向看）
+X 右
```

⚠ 从 Unity 转过来的注意：Unity 是 +Z 前。模型导入后朝向可能反了。

### 局部 vs 全局

```gdscript
position                    # 相对父节点
global_position             # 世界坐标
transform / global_transform# 完整的变换矩阵（含旋转缩放）
basis                       # 旋转+缩放（3x3）
quaternion                  # 四元数
```

⚠ **`global_position = x` 是"设置当前帧的全局位置"，会被下一帧覆盖** ——
父节点变换、物理步、动画轨道都会重算它。

要持续定位就写局部 `position`，或设 `top_level = true` 脱离父变换：

```gdscript
# 反例：想让物体待在某处，但下一帧就飘了
obj.global_position = Vector3(1, 2, 3)

# 正例一：写局部坐标
obj.position = parent.to_local(Vector3(1, 2, 3))

# 正例二：脱离父变换
obj.top_level = true
obj.global_position = Vector3(1, 2, 3)
```

（审查 GD61 会提示这条）

### 朝向

```gdscript
look_at(target_global_pos)              # 让 -Z 轴指向目标
look_at_from_position(from, target, up) # 指定起点

# 平滑转向
func _process(delta: float) -> void:
    var target_basis := Basis().looking_at(to_local(target), Vector3.UP)
    transform.basis = transform.basis.slerp(target_basis, 1.0 - exp(-8.0 * delta))
```

⚠ `look_at()` 用的是**全局坐标**。传局部坐标会朝向错误。

## 2. 场景搭建

```
Level (Node3D)
├── World (Node3D)
│   ├── Ground (MeshInstance3D + StaticBody3D)
│   └── Walls
├── Player (CharacterBody3D)
│   ├── Mesh
│   ├── CollisionShape3D
│   └── Camera3D
├── Lights (Node3D)
│   ├── DirectionalLight3D      ← 太阳
│   └── ...
└── WorldEnvironment            ← 全局环境（雾、泛光、GI）
```

### 用 CSG 快速搭白模

`CSGBox3D` / `CSGCylinder3D` / `CSGSphere3D` 可以做布尔运算，
适合快速搭关卡原型，之后可"烘焙"成 MeshInstance3D。

### glTF 导入

拖 `.glb`/`.gltf` 进项目即可。导入选项在 Import 面板：

| 选项 | 说明 |
|---|---|
| `Meshes/Ensure Tangents` | 用法线贴图必须开 |
| `Meshes/Generate LODs` | 自动生成 LOD |
| `Animation/Import` | 是否导入动画 |

⚠ 导入的模型根是 `Node3D`，需要自己加 `CollisionShape3D`。

## 3. 相机

### 第三人称跟随（带避障）

```gdscript
# camera_rig.gd
extends Node3D

@export var target_path: NodePath
@export var distance := 5.0
@export var height := 2.0
@export var follow_speed := 8.0

@onready var _cam: Camera3D = $Camera3D
@onready var _target: Node3D = get_node(target_path)

func _process(delta: float) -> void:
    # 相机位置放在 rig 里平滑，rig 本身跟随目标
    var t := 1.0 - exp(-follow_speed * delta)
    global_position = global_position.lerp(_target.global_position, t)

func _unhandled_input(event: InputEvent) -> void:
    if event is InputEventMouseMotion:
        rotate_y(-event.relative.x * 0.003)          # rig 水平转
        _cam.rotate_x(-event.relative.y * 0.003)     # 相机俯仰
        _cam.rotation.x = clampf(_cam.rotation.x, -1.2, 0.6)

func _ready() -> void:
    _cam.position = Vector3(0, height, distance)     # 相机在 rig 后方
```

**碰撞避障**（相机不穿墙）：用 `ShapeCast3D` 或 `PhysicsRayQueryParameters3D`
从目标往相机打射线，命中就把相机拉近。

### 相机属性

| 属性 | 用途 |
|---|---|
| `fov` | 视野角（透视模式），默认 75 |
| `near` / `far` | 裁剪面。**near 太小会有 z-fighting** |
| `cull_mask` | 渲染哪些层（与物理层独立） |
| `current` / `make_current()` | 设为当前活动相机 |
| `keep_aspect` | KEEP_WIDTH / KEEP_HEIGHT |

⚠ `near` 别设太小（< 0.05）—— 深度精度不足导致远处物体闪烁（z-fighting）。

⚠ 物体没渲染出来，先查 `cull_mask` 而不是位置。相机、灯光各有 cull_mask。

### 坐标转换

```gdscript
# 世界坐标 → 屏幕坐标（血条跟随、伤害数字）
var screen_pos := _cam.unproject_position(world_pos)

# 屏幕坐标 → 世界射线（点击选取）
var from := _cam.project_ray_origin(mouse_pos)
var dir := _cam.project_ray_normal(mouse_pos)
```

## 4. 材质

### 共享材质陷阱

```gdscript
# 危险：多个 MeshInstance3D 共用同一个材质资源时，
# 改一个会影响所有用了它的物体
func _ready() -> void:
    var mat := $Mesh.material_override as StandardMaterial3D
    mat.albedo_color = Color.RED        # 所有共享的都变红！
```

**正例**：先复制再改

```gdscript
func _ready() -> void:
    var mat := ($Mesh.material_override as StandardMaterial3D).duplicate()
    mat.albedo_color = Color.RED
    $Mesh.material_override = mat
```

⚠ 这是 3D 最常见的"改一个变一片"bug，静态扫不出来（要靠比对 Resource 身份）。

### 三种材质槽

| 槽 | 用途 |
|---|---|
| `material_override` | 覆盖 mesh 自带材质（最常用） |
| `material_overlay` | 叠加一层（描边等） |
| mesh 资源上的材质 | 所有实例共用 |

### 常用属性

```gdscript
var mat := StandardMaterial3D.new()
mat.albedo_color = Color(0.8, 0.2, 0.2)
mat.metallic = 0.0
mat.roughness = 0.6
mat.emission_enabled = true
mat.emission = Color.ORANGE
mat.emission_energy_multiplier = 2.0
mat.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA   # 默认是 DISABLED
mat.cull_mode = BaseMaterial3D.CULL_DISABLED           # 双面（草、布料）
mat.uv1_scale = Vector3(4, 4, 1)                       # 平铺
```

⚠ **透明必须设 `transparency`** —— 只调 `albedo_color.a` 不会透明（默认是 DISABLED）。

⚠ 每帧 `new ShaderMaterial()` / `new StandardMaterial3D()` 会打断合批（审查 GD31）。
共享材质实例，只改参数。

### 着色器入门

```glsl
shader_type spatial;

uniform vec4 hit_color : source_color = vec4(1.0, 0.0, 0.0, 1.0);
uniform float hit_amount : hint_range(0.0, 1.0) = 0.0;

void fragment() {
    ALBEDO = mix(vec3(1.0), hit_color.rgb, hit_amount);
}
```

代码控制：

```gdscript
const P_HIT := "hit_amount"     # 常量化，避免拼错

func flash_hit() -> void:
    var mat := $Mesh.material_override as ShaderMaterial
    mat.set_shader_parameter(P_HIT, 1.0)
    var tw := create_tween()
    tw.tween_method(func(v): mat.set_shader_parameter(P_HIT, v), 1.0, 0.0, 0.2)
```

⚠ `set_shader_parameter` 的名字必须与 shader 里的 uniform 名**完全一致**，
不一致时**静默失效**（不报错也不生效，审查 GD64）。

**常用 spatial 输出**：`ALBEDO` / `METALLIC` / `ROUGHNESS` / `EMISSION` /
`NORMAL` / `ALPHA` / `ALPHA_SCISSOR_THRESHOLD`
**常用输入**：`UV` / `VERTEX`（vertex 函数里）/ `NORMAL` / `TIME`

## 5. 光照与环境

### 4.7+：AreaLight3D（矩形面光源）

发光屏幕、广告牌、窗户这类**矩形光源**，以前只能用自发光材质 + GI 假装。
4.7 起有真正的面光源，阴影更软、反射更真实。

```gdscript
var light := AreaLight3D.new()
light.size = Vector2(2.0, 1.0)
add_child(light)
```

⚠ 面光源的实时开销比点光源高，按场景规模实测（见 `performance.md`）。

### 三光源（点/聚光/平行）

```gdscript
# 太阳（平行光，全局，无衰减）
var sun := DirectionalLight3D.new()
sun.light_energy = 1.2
sun.shadow_enabled = true
sun.directional_shadow_max_distance = 50.0   # 超出不投影，性能相关
sun.rotation_degrees = Vector3(-45, 30, 0)

# 点光源（灯泡、爆炸）
var omni := OmniLight3D.new()
omni.omni_range = 8.0
omni.light_energy = 2.0
omni.shadow_enabled = false      # 点光源阴影很贵，按需开

# 聚光（手电筒）
var spot := SpotLight3D.new()
spot.spot_range = 15.0
spot.spot_angle = 35.0           # 别超 89
spot.light_energy = 3.0
```

⚠ `spot_angle` 超过 89° 不生效或阴影异常（审查 GD62）。要更大范围用 OmniLight3D。

⚠ 点光源/聚光的阴影开销大。**场景里同时开阴影的光源控制在 2-3 个以内**。

⚠ `editor_only = true` 忘了关 → 导出后仍占性能（审查 GD63）。

### 阴影配置

```gdscript
sun.shadow_enabled = true
sun.shadow_bias = 0.03          # 太小 → 阴影粉刺；太大 → 阴影脱离物体
sun.shadow_normal_bias = 0.1
sun.shadow_blur = 1.0
sun.directional_shadow_max_distance = 50.0
```

⚠ 阴影有条纹/噪点（shadow acne）→ 调大 `shadow_bias`。
阴影与物体分离（peter-panning）→ bias 调太大了，往回收。

### 环境（WorldEnvironment）

```gdscript
# 在编辑器建：WorldEnvironment 节点 → Environment 属性 → 新建 Environment
```

常用项：

| 项 | 说明 |
|---|---|
| `background_mode` | BG_SKY（用天空）/ BG_COLOR（纯色）/ BG_CLEAR_COLOR |
| `ambient_light_source` | 环境光来源（常用 AMBIENT_SOURCE_SKY） |
| `tonemapper` | TONE_MAPPER_FILMIC（默认）/ ACES / LINEAR |
| `glow_enabled` | 泛光（发光材质需要） |
| `ssao_enabled` | 屏幕空间环境光遮蔽 |
| `fog_enabled` | 雾（配合 volumetric 可做出体积雾） |
| `sdfgi_enabled` | 动态全局光照（开销大，按需） |

⚠ 这些**默认大多关闭**，开 Environment 不等于开了所有效果。

⚠ `sdfgi_enabled` 开销很大，中低端设备关掉。

### GI 方案

| 方案 | 适用 | 代价 |
|---|---|---|
| 无 GI（只用环境光） | 风格化、低端 | 最省 |
| `VoxelGI` | 中等场景，动态物体 | 要烘焙，有内存开销 |
| `LightmapGI` | 静态场景，画质最好 | 要烘焙 + UV2，静态才有效 |
| `SDFGI` | 大场景动态 GI | 开销最大 |

## 6. 粒子

```gdscript
# 在编辑器建 GPUParticles3D，属性：
#   amount = 64
#   lifetime = 1.5
#   process_material = 新建 ParticleProcessMaterial
#   draw_pass_1 = 一个 QuadMesh（或小 Mesh）
```

```gdscript
@onready var _particles: GPUParticles3D = $GPUParticles3D

func burst() -> void:
    _particles.restart()
    _particles.emitting = true

func _on_finished() -> void:
    _particles.emitting = false
```

⚠ **`visibility_aabb` 必须覆盖粒子可能的运动范围** —— 包围盒外会被整体剔除，
表现为"粒子飞到屏幕边缘突然消失"，**不报错**（审查 GD65）。

⚠ `local_coords = false`（默认）时粒子发射后留在世界坐标，
发射器移动不会带着粒子走。要"拖尾跟随"设 `local_coords = true`。

⚠ 大量粒子用 `fixed_fps` 限制更新率（如 30），能省一半开销。
