# 进阶移动：二段跳、爬墙抓边、绳索、游泳、可变重力（Godot 4.7.2）

"二段跳""爬墙""抓墙""游泳""潜水""滑翔""攀爬""重力方向""传送门" 此前 **全部 0 命中**。
基础平台跳跃与俯视角移动见 `character.md`，本文讲**特殊移动状态**。

## 0. 状态机是地基

⚠ 这些特殊移动**不能堆 if**，要有明确的状态机：进入 / 退出 / 优先级 / 中断。

⚠ **输入缓冲与土狼时间要覆盖所有状态**，不只是跳跃。

**传感器集中更新**，不要在多个状态里重复投射：
墙传感器（左/右或前向射线）、地面传感器（`is_on_floor()` / 法线 / 角度）、
抓边传感器（上下两条射线）。状态转换只判断这些结果。

## 1. 二段跳与空中控制

- 跳跃次数计数与**重置时机**
- ⚠ 二段跳的动画与音效触发
- ⚠ 空中水平控制的手感：不是"能不能控制"，是**加速度给多少**
- 可变跳高（松开键短跳）

## 2. 爬墙 / 抓边（重点）

### 抓边要两条射线

1. 从角色**肩部略偏上**、向墙方向投射 —— 命中且碰撞点靠近边缘 = 存在可用墙顶
2. 从角色**腰部**沿墙方向投射 —— 若墙存在而肩线没命中，通常表示正对墙中段而非边缘

⚠ 把上方射线起点提到角色顶部附近、终点略深入墙，比较命中高度与胶囊顶部，
在可接受边缘带内才允许抓。**具体阈值必须按胶囊高度和网格台阶实测**。

### 抓边后分三个阶段

**吸附**（禁用输入、沿逆上方向拉到边缘表面）→ **悬停**（播动画、锁物理）→ **攀爬**（移到边缘平面上方、恢复地面状态）

⚠ **不要直接 `global_transform.origin = edge_point`** —— 可能穿透薄墙或动画不匹配。
更好是用 `move_and_collide()` 朝目标移动并设最大插值距离。

### 蹬墙跳

⚠ **垂直分量要够**，否则蹬不上去。

### ⚠ 最容易出的问题

小台阶/角落**误触发**、边缘**抖动**。

## 6. ⚠ 改重力方向：一条被推翻的说法

⚠ 常见说法"**改 `up_direction` 后 `is_on_floor()` 必然失效**"——**这个说法不成立**。

官方 API 已确认：
- `up_direction` 用于区分地板、墙、天花板，**不能设为 `Vector3.ZERO`**
- `MOTION_MODE_FLOATING` 时**所有碰撞都被视为墙**
- `is_on_floor()` 只反映**本帧**最近一次 `move_and_slide()` 的结果

**真正导致失效的常见原因是这五个**：

1. **先读状态后移动**（顺序错了）
2. 碰撞面与当前上方向夹角超过 `floor_max_angle`
3. 把角色节点随意旋转却**没同步上方向**
4. 切换到 Floating 模式
5. 坐标系不同步（up 改了但相机/移动平面没跟着变）

⚠ 改重力方向**不是只改 gravity 向量** —— 角色 up、相机、移动平面全要跟着变。
