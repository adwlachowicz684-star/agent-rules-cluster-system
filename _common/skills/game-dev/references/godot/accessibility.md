# 无障碍与字幕系统（Godot 4.7.2）

"色盲""字幕" 此前 **0 命中**。商业项目（尤其主机/PC 发行）越来越把它当上架门槛。

## 0. 无障碍不是"加个选项"

⚠ **交互层（焦点链、键盘/手柄导航）见 `ui-advanced.md`**，本文只讲呈现层。

三类核心障碍对应**不同信息通道**：

| 障碍 | 影响的通道 |
|---|---|
| 视觉 | 读取颜色、文字、界面、空间信息 |
| 听觉 | 语音、提示音、方位判断 |
| 运动 | 反应速度、按键次数、握持方式、连续操作 |

⚠ **无障碍 ≠ 难度选项**，不要混为一谈。
⚠ **要在白板阶段介入** —— 到 QA 阶段再补，通常需要重做材质、UI、图标、教程与本地化文本。

（本文只讲**呈现层**：字幕、色盲、屏幕阅读器。
**交互层**——焦点链、键盘/手柄导航——见 `ui-advanced.md`）

**4.7.2 的官方底座**：已通过 AccessKit 提供 Control 节点的屏幕阅读器支持，
可读取系统「高对比度」「减少动画」「减少透明度」偏好。
⚠ 但**这只是底座，不等于游戏已经无障碍**。

## 1. 视觉：色盲不是"加个滤镜"

⚠ **红绿色觉障碍在北欧裔男性中约 1/12**，是最高发的类型。

⚠ **只改颜色不够** ——
如果角色用红色表示可攻击、蓝色表示不可攻击，**颜色即信息**，加滤镜也解决不了。
必须同时提供**形状、图标、亮度与文字冗余**。

色盲模式的实现：shader 后处理 vs 调色板替换，各有优劣。

**其他视觉项**：
- 文字大小与对比度（⚠ 不是简单放大字体，要处理布局溢出）
- 高对比模式
- 动态模糊/镜头晃动可关闭

### 光敏性癫痫

⚠ 工程安全线（**风险降低准则，不是医学保证**）：

| 维度 | 阈值 |
|---|---|
| 闪烁频率 | **每秒不超过 3 次** |
| 同时闪光面积 | **不超过屏幕 1/4** |
| 饱和红闪烁 | **更严格** |
| 亮度 | 普通 < 20 cd/m²，红闪 < 6 cd/m² |

按"闪烁次数、面积、亮度、颜色、时长"**五维评估**。

## 2. 听觉：字幕承载的是音频事件

⚠ **字幕 ≠ 对话文本** —— 还要包含"[脚步声]"这类**非语音音频线索**。

字幕数据结构：`speaker`（`ambient`/`sfx`/`music` 用于非语音）、文本、时间轴。
要与音频时间轴同步。样式要可配置（大小、背景、颜色）。

**其他听觉项**：
- 单声道下混（单耳听力玩家）
- 音乐/音效/语音独立音量（见 `audio-advanced.md`）
- 视觉替代音频（用 UI 提示代替关键音效）

## 3. 运动：操作无障碍

- 按键重映射（见 `input-remap.md`）
- **长按改为切换（toggle）**
- **QTE 与快速反应的替代路径**
- 可调节游戏速度
- ⚠ **自动瞄准/辅助瞄准也是无障碍的一部分**
- 单手操作模式

## 4. 设置系统

⚠ **首次启动的引导式设置** —— 让玩家先选，而不是藏进二级菜单深处。

- 设置项分类与持久化
- 可读取 OS 级无障碍偏好
- 设置变更**即时生效**（不是重启才生效）

## 5. 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 无障碍就是难度选项 | 是**信息通道**问题，完全不同 |
| 2 | 上线前补一下就行 | 后期补要**重做材质/UI/图标/本地化** |
| 3 | 引擎有 AccessKit 就够了 | 只是**底座** |
| 4 | 色盲模式加个滤镜 | 颜色即信息时**滤镜无效**，要形状冗余 |
| 5 | 红绿色盲很罕见 | 北欧裔男性约 **1/12** |
| 6 | 字幕就是对白 | 要含**环境音与非语音线索** |
| 7 | 字幕和音频大概同步 | 要**时间轴对齐** |
| 8 | 文字放大就解决可读性 | 要处理**布局溢出** |
| 9 | 闪烁不要太快就行 | 要**五维评估**（次数/面积/亮度/颜色/时长） |
| 10 | 无障碍选项放设置里 | 要**首次启动引导** |
| 11 | 设置重启生效可以接受 | 要**即时生效** |
| 12 | 单声道下混不重要 | 单耳听力玩家需要 |
| 13 | QTE 是玩法核心不能改 | 要有**替代路径** |
| 14 | 辅助瞄准是给新手的 | 也是**无障碍** |
