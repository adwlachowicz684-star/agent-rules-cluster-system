# onboarding-meta — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/onboarding-meta.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 引导遮罩盖一层半透明就行 | 要**真挖洞**，否则点不到目标 |
| 2 | 遮罩只挡视觉 | 要 `MOUSE_FILTER_STOP` 吃掉误点 |
| 3 | 引导不会卡 | **最严重的 bug**，每步都要超时兜底 |
| 4 | 引导不用存档 | 中途退出要能续 |
| 5 | 引导不用埋点 | 流失率是最有价值的调优数据 |
| 6 | 成就写死在代码里 | 定义与状态分离，否则改数值炸存档 |
| 7 | 成就轮询检测 | 事件驱动 |
| 8 | 排行榜分数客户端算就行 | 不可信，见 `security.md` |
| 9 | 统计和埋点是一回事 | 统计给玩家看，埋点给开发者看 |
| 10 | 统计每次变化就写盘 | 要节流 |
| 11 | Godot 内置 Steam 成就 | **没有**，要插件且需查兼容性 |
| 12 | Mod 只是资源替换 | 是**任意代码**，有安全风险 |
| 13 | Mod 支持很酷该做 | 除非核心卖点是 UGC，否则性价比低 |
