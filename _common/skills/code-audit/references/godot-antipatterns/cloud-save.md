# cloud-save — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/cloud-save.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 云存档就是上传文件 | 核心是**冲突** |
| 2 | 本地较新就覆盖 | **静默覆盖最危险** |
| 3 | 用文件修改时间判冲突 | **时钟不可信**，要逻辑版本号 |
| 4 | 版本号用构建号 | 一个构建内可能**多次写入** |
| 5 | Godot 有云存档 API | **没有**，要平台 SDK |
| 6 | 插件写"支持 4.x"就能用 | 要**按 4.7.2 专用构建**验证 |
| 7 | iOS 的 user:// 都会备份 | Caches/Temporary **不备份** |
| 8 | 冲突提示显示时间戳 | 要显示**相对时间**与设备 |
| 9 | 版本降级是边缘情况 | 是**正常路径** |
| 10 | 设置也要同步 | 画质/操作偏好**不该同步** |
| 11 | 写存档是原子的 | 写一半崩会**损坏存档**，要原子写 |
| 12 | HTML5 用文件系统 | 用 **IndexedDB** |
| 13 | Lamport 时钟能解决一切 | 是**补充**，防丢失仍需领域合并 |
| 14 | 云存档可信 | **可被篡改**，要服务端校验 |
