# advanced-topics — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/advanced-topics.md`

## 常见漏写

| 域 | 漏写 | 后果 |
|---|---|---|
| 生成 | 不记录生成参数 | 无法复现 bug |
| 生成 | 无连通性校验 | 出现不可通关关卡 |
| 生成 | 生成失败不重试 | 玩家拿到残缺关卡 |
| 插件 | 退出不清理 | 泄漏、异常行为 |
| 插件 | 不走 UndoRedo | Ctrl+Z 无效 |
| 插件 | @tool 改节点 | 污染 .tscn |
| 导入 | 第三方资源不审查 | 未知脚本执行 / 包体爆炸 |
| 导入 | 导入产物进版本库 | 仓库膨胀、冲突 |
| XR | 逻辑挂头显 | 追踪延迟导致判定错乱 |
| XR | 掉帧 | 晕动症 |
| XR | 只有平滑移动 | 部分玩家无法游玩 |
