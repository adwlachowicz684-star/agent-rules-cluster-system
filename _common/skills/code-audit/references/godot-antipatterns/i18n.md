# i18n — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/i18n.md`

## 常见漏写

| 漏写 | 后果 |
|---|---|
| 存档存了翻译后的文本 | 切语言后旧存档不更新 |
| 给按钮固定宽度 | 德语等长语言文本截断 |
| 中文字体没有回退 | 英文设备上显示豆腐块 |
| 切语言后不刷新 UI | 界面仍是旧语言 |
| `_process` 里调 `tr()` | 每帧查表，浪费 |
| 翻译了内部 ID / 日志 | 存档、配置错乱 |
| Key 用英文原文 | 改文案要改所有引用 |
| 未处理 RTL | 阿语/希语布局反了 |
