# level-design — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/level-design.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 关卡就是把场景搭出来 | 是**心流曲线**四要素 |
| 2 | 直接上美术更快 | 白盒返工**更贵** |
| 3 | 白盒等美术完再验可玩性 | **白盒阶段就要能跑** |
| 4 | CSG 可以做最终资产 | 官方定位是**原型** |
| 5 | CSG 已弃用 | 4.7 仍在**主线维护**并增强 |
| 6 | .tscn 是文本就能合并 | **语义冲突不会自动解决** |
| 7 | 多人同时编辑一个场景没问题 | 要**拆小 + 单人所有权** |
| 8 | 逻辑写进关卡场景方便 | 要**数据驱动** |
| 9 | 跳关功能以后再说 | **决定迭代速度**，要早做 |
| 10 | 关卡验收看模型摆完没 | 验收**玩家能否完成** |
| 11 | 卡表是策划的事 | 它是**白盒验收单** |
| 12 | Marker3D 只是个空节点 | 它是**位置/朝向锚点**的规范做法 |
