# architecture — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/architecture.md`

## 常见漏写

| 漏写 | 后果 |
|---|---|
| 子调 `get_parent().get_parent()` | 改树结构就断 |
| Autoload 信号未断开 | 节点永远不释放（泄漏） |
| 深继承链 | 改基类影响全部，无法复用子组件 |
| 数据表写死在脚本 | 改数值要改代码 |
| `@export Resource` 不 duplicate | 所有实例共享 |
| 组件间互相直接引用 | 耦合，无法单独复用 |
| 脚本内部自己找依赖 | 无法测试、改结构就断 |
| 成员顺序混乱 | diff 噪音大，阅读成本高 |
| 场景树嵌套过深 | 遍历和变换成本上升 |
