# 3d — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/3d.md`

## 常见漏写

| 漏写 | 后果 | 审查规则 |
|---|---|---|
| `global_position = x` 当持续定位 | 下一帧被覆盖 | GD61 |
| 共享材质直接改 | 所有实例一起变 | 人工 |
| 只调 `albedo.a` 不开 `transparency` | 不透明 | 人工 |
| `spot_angle` > 89 | 不生效/阴影异常 | GD62 |
| `editor_only` 忘关 | 导出后白占性能 | GD63 |
| `set_shader_parameter` 名拼错 | 静默失效 | GD64 |
| `visibility_aabb` 不足 | 粒子被剔除，不报错 | GD65 |
| `near` 设太小 | z-fighting 闪烁 | 人工 |
| 每帧 `new ShaderMaterial` | 打断合批 | GD31 |
| 移动平台用 StaticBody | 角色滑落 | 人工 |
