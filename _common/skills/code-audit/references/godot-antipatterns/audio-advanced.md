# audio-advanced — 反模式清单（审核用）

> 本文件**只写「不能怎么做」**，用于审核完成效果、约束边界。
> 「怎么做」看开发侧：`game-dev/references/godot/audio-advanced.md`

## 常见坑

| # | 本能以为 | 实际 |
|---|---|---|
| 1 | 音量传 0–1 | 是**分贝**，要 `linear_to_db()` |
| 2 | 0 dB 是静音 | 0 dB 是原始音量；静音要 -80 dB 或 mute |
| 3 | UI 音效走 Master 没问题 | 耦合了"全静音"和"UI 静音" |
| 4 | 反复 play() 能叠加 | 同一个播放器会**打断自己** |
| 5 | AudioStreamPlayer3D 出来就有 3D 效果 | 必须 `add_child` 进树 |
| 6 | 淡出到 0 | 要淡到 -80 |
| 7 | paused 后 UI 音还能响 | 默认被停，要设 PROCESS_MODE_ALWAYS |
| 8 | bus_mute 等于暂停 | 播放继续，恢复后从中间接 |
| 9 | 音效都用 OGG 省体积 | 短音效解码延迟会迟到 |
| 10 | MP3 能做无缝循环 BGM | 编码特性导致无法无缝 |
| 11 | 音高随机化越大越好 | 超过 ±15% 听得出变调 |
| 12 | 混响放在每个音源上 | 应按类别放**总线**上 |
