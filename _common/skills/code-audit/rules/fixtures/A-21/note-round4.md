# A-21 补充样本（第 4 轮）：模式互斥参数被静默忽略

- **TP2 必须命中**：参数因**当前模式**用不上而被跳过，且没有任何提示
- **FP2 必须不命中**：要么生效，要么显式报「与本模式互斥」

为什么需要第二组：第一组（A-21 原有 tp）是「文件不存在 / 被 .gitignore 屏蔽」；
本组是**参数被模式开关吞掉**——用户以为自己在控制某个行为，实际改的是别的对象。
刻意用 `-b` 与 `push()` 避开 `--branch` / `do_push` 这类白名单内名字。

实测来源：某推送工具 direct 模式下 `--branch feat/x` 完全不读 `target_ref`，
内容直推 main，且不报错。
