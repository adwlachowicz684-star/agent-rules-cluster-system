# RS-08 · Rust 语言包

对应判据条目：**RS-08**

**tp**：`Rc` 出现在 `thread::spawn` 上下文 —— `Rc` 非 `Send`，跨线程是 UB。
**fp**：`Arc` 可跨线程。

**注意**：`Rc` 检出要同时认 `Rc<...>` 和 `Rc::new(...)`——只写 `Rc\s*<`
会漏掉最常见的构造写法，而构造点才说明真的产生了 `Rc`。

**样本写法说明**：单独的 `Rc::new` 不构成缺陷（`Rc` 单线程用是合法的），
必须落在 spawn 上下文里才算，所以 tp 里带了 `std::thread::spawn`。
