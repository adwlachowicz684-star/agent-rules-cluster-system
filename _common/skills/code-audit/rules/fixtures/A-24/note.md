# A-24 工具产物与业务数据共用命名空间

- **TP 必须命中**：写用户数据目录 + `<原名>.<后缀>` 命名，无存在性检查
- **FP 必须不命中**：写到专属目录 / 系统临时目录；或写入前检查存在性

实测来源：某推送工具 `pull()` 冲突时写 `rel + ".remote"`，
用户仓库中真实存在 `config.txt.remote`（远程配置模板是完全正常的命名）
→ 静默覆盖，无备份、无提示、不可恢复。

判据要点：①② 两条同时满足才成立 ——
① 写在用户数据目录内　② 命名规则是用户可能自然采用的模式。
只满足其一（如只写在仓库外的临时目录）不算。
