# PY-18 文档字符串不在函数体首位（变成死表达式）

- **TP 必须命中**：`def` 后第一条语句不是字符串，后面另有独立的三引号字符串
- **FP 必须不命中**：字符串在函数体首位；或函数体内根本没有字符串字面量

实测来源：某推送工具 `prune()` 的 `def` 之后第一行是 `_report_conflict_artifacts()`，
其后 10 行三引号文本全部是死表达式 → `help(prune)` 取不到「只报告不删除」这条约定。

机扫：`scan-py.py` 的 `PY-18`（AST 驱动），`--self-test` 含 1 TP + 2 FP。
为什么必须机扫：语法合法、多数 linter 不报，肉眼读代码看不出来。
