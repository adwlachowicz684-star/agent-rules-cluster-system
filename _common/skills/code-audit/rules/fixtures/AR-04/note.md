# AR-04 退出码不分类（生产者侧）

- **TP 必须命中**：≥3 个退出点，但数字退出码 ≤1 种（tp.py）
- **TP2 必须命中**：换成 `sys.exit()` 同样形态（tp2.py）
- **FP 必须不命中**：退出码已分类（2/3/1）（fp.py）
- **FP2 必须不命中**：只有 1 个退出点的小脚本，不要求分码（fp2.py）

与既有「退出码」条目的分界：那些讲**消费者侧**（调用外部命令后要检查退出码），
本条讲**生产者侧**（自己要分类自己的退出码）。

实测来源：某工具退出码恒为 1，只有 Ctrl-C 是 130；
被拦下（改动未丢、照提示做即可）与真出错在自动化眼里完全一样。
