# A-25 补充样本（第 4 轮）：模式 / 枚举字段单向写入

- **TP2 必须命中**：多值模式字段只在一个方向写入，且重建 / 迁移路径沿用旧值
- **FP2 必须不命中**：有显式切换入口，或重建时接受显式指定

为什么需要第二组：A-25 原有 tp 是**布尔属性**（`chmod` / `enabled`）；
本组是**多值模式字段**（`workflow` / `mode` / `strategy`），
后果不同——布尔属性是「反复打架」，模式字段是「用户被永久锁定且无提示」。
刻意用 `mode` / `apply_mode()` 避开 `workflow` / `--direct` 这类白名单内名字。

实测来源：某推送工具一次 `--direct` 之后，唯一写 `"pr"` 的路径只有
「PR 推送成功后」，而 `--reset-baseline` 会继承旧值 → 无命令行入口可回到 PR 工作流。
