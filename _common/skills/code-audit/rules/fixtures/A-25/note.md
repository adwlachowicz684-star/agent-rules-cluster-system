# A-25 单向属性写入（只升不降）

- **TP 必须命中**：`if <条件>: 写` 且**没有 else 反向分支**
- **FP 必须不命中**：有 else 反向分支，或无条件赋值（天然双向）

实测来源：某推送工具 `_write_local()` 只在 `mode == "100755"` 时 chmod，
远端把可执行位去掉后本地 0755 文件拉取后不回退
→ `local_state_map()` 仍判 100755 → 与远端永久打架。

后果特征：用户说「这个文件每次都显示有改动」，但看 diff 又看不出内容变化。
降级：属性本身只允许单向（已读标记、单调递增计数器）→ 不报。
