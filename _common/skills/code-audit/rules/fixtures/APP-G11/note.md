# APP-G11 测试 import 扩展名写法与同目录不一致

- **TP 必须命中**：同目录 ≥3 个测试文件里，同一目标的 import 写法出现少数派（多数无扩展名，此文件带 `.mjs`）
- **FP 必须不命中**：同目录写法完全一致

为什么 fp 重要：规则只在「同目录已形成多数写法」时才报少数派，
单文件用 `.mjs` 而目录里只有它一个 → 不该报（那是项目约定，不是不一致）。
实测来源：某项目 `tests/registry.test.ts` 是唯一用 `../runner.mjs` 的
→ 加载失败 → 该文件测的内容从未执行。**测试跑不起来 ≠ 测试失败**，计数上看不出来。
