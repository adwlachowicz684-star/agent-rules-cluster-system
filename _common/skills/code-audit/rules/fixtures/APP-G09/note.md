# APP-G09 导出后零引用（已实现未接线）

- **TP 必须命中**：导出的名字全项目零引用；名字像机制/防护/订阅（`onPolicyChange`）→ P1
- **FP 必须不命中**：同名的导出被别处 import 并调用

为什么 fp 重要：这条是**全项目**判定，逐文件会大量误报（跨文件引用看不到）。
fp 证明「只看定义文件」的写法确实会被本规则放过。
实测来源：某项目 552 个导出中 16 个零引用，最值得警惕的是本该接线的机制
（`onPluginConfigChange` / `canFs` / `FS_FORBIDDEN`），静默、不报错、测试还可能全绿。
