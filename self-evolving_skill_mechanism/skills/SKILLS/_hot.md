# 热区：跨领域高频铁律

> 这里的规则**跨领域通用**，每次任务前必扫。
> 领域专属规则写在 `domains/*.md`，不要堆在这里。
> 命中：每次任务前扫到并照做 → +1。命中归零不删除，冷藏。

| ID | 触发场景 | 正确做法 | 强度 | 命中 |
|----|---------|---------|------|------|
| H001 | 修改已有文件 | 先 read 原文件，只改该改的部分 | L1 | 0 |
| H002 | 交付多个产物 | 产物 ≥5 个或为整个目录 → 打包 zip，只返单个路径 | L1 | 0 |
| H003 | 需求含糊、有多种做法 | 先确认关键口径再动手，不边做边猜 | L1 | 0 |
| H004 | 长任务 / 高风险任务 | 开工前扫本表 + `_preferences.md`，声明「本次适用 #xx」 | L2 | 0 |
| H005 | 批量文件操作 | 先在沙盒建目录，产物一律放工作目录，不写 /tmp、/home | L2 | 0 |
| H006 | 写文件前 | 确认目录存在；路径含空格用双引号包裹 | L2 | 0 |
| H007 | 生成代码后 | 实际运行验证，不凭"看起来对"交付 | L1 | 0 |
| H008 | 报告结论 | 只陈述有证据支持的内容，不补全、不猜测 | L1 | 0 |
| H009 | 引用外部信息 | 标注来源，不把检索内容当既知事实 | L2 | 0 |
| H010 | 打包交付前 | 清理 `__pycache__`、`.DS_Store` 等缓存垃圾 | L2 | 0 |
