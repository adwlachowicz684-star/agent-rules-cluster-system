# 跨 skill 接缝

> **本区性质：common / 元规则。**
>
> **本仓库有三个 skill 互相引用**：`skill-evolution`（本侧）、`game-dev`、`code-audit`。
> 内容搬过来之后，**源头改了这边不会知道**——这是接缝，不是复制。

## 一、为什么单独一篇

`flow/seams.md` 讲的是**本 skill 内部**流程之间的接缝。
本篇讲**跨 skill** 的——形态不同，风险也不同：

| | 内部接缝 | 跨 skill 接缝 |
|---|---|---|
| 谁改的 | 我 | **别人**（且是另一个活跃区） |
| 改了我知道吗 | 知道 | ⛔ **不知道** |
| 断了的表现 | 流程跑不通 | **内容悄悄过期**，且看起来完好 |

⇒ 内部断了自己会撞到，**跨 skill 断了不会**——因为你不会去读对方的文件，
只会读自己这份"看起来还在"的副本。

## 二、⛔ 实证：25 条反哺标注，22 条没写具体路径（88%）

```
反哺标注 25 条
  带具体文件/域路径    3 条  （12%）
  笼统「game-dev」   22 条  （88%）
```

⛔ 后果：源文件改名/拆分/改判据之后，
**没有任何办法知道这边哪些内容跟着过期了**。

⇒ 这不是"标注不够详细"这种风格问题——
**它是查找能力的缺失**：问"这段来自哪"，答不出。

### 判据

**能不能反查「这条内容的源头现在还在吗、改了没」？**
答不出 ⇒ 迟早会基于过期副本做决策。

```text
⛔ 反哺自 game-dev                                    （答不出具体位置）
✅ 反哺自 game-dev/references/flow/godot/mod/00-域流程总览.md
```

⇒ ⓘ 上面两行在代码块内：⛔ 示例若写成正文会被"反哺来源路径"检查器
报成真标注（87 条里 7 条就是这么来的）。

ⓘ 与「三件套」（来源/证据/后果）是同一条：
**来源要能定位，不能只是个名字**。

## 三、跨 skill 接缝表

| 接缝 | 源头 | 本侧消费方式 | 是否一致 | 风险 |
|---|---|---|---|---|
| 反哺内容 | `game-dev/**`（118 howto + 115 audit + 169 flow） | 人工提炼后写入本侧 | ⚠ **单向快照** | ⛔ 源头改了不通知 |
| 转发壳 | `code-audit/scripts/rule-registry.py` | `scripts/cocos_audit.py`（29 行壳） | ✅ 运行时转发 | ⛔ 对方换参数 → 本侧文档失效 |
| 阈值一致性 | `code-audit/scripts/check-skill.py` 的 `MAX_SKILL_SOFT` | 硬编码比对（不读对方 config） | ✅ 找到就比 | ⛔ 硬编码会漂移 |
| 路由信号 | `code-audit/scripts/route.py`（18 场景 × 4 信号） | `howto/routing-signals.md` | ⚠ 单向快照 | 同上 |

ⓘ 第三条的设计取舍值得单独记（反哺自 `code-audit/references/common-maintenance.md` 的注释）：

> ⛔ 为什么不直接读对方 config：skill 是**独立可分发的单元**，
> 单独拷到别的项目兄弟路径就不存在 ⇒ 运行时依赖会让自检崩，
> 或更糟：**静默降级成默认值**。
> ⇒ 硬编码是**慢性病**，运行时依赖是**急性病**，所以选前者。
> 但「漂移没人知道」这半个风险必须堵掉：**找到就比对，找不到就跳过**。

## 四、⛔ 双向都要声明

```
单向：本侧写了"来自 game-dev"
双向：本侧写了路径  +  对方那份也标了"被谁引用"
```

⛔ 只做单向，对方重构时**看不到谁会受影响**——
它改自己的文件，不知道本侧有 43 条依赖它。

⇒ 本侧能做的（对方是活跃区，不改对方文件）：
在每条反哺标注里写清**具体路径**，
这样对方改名时至少可以**全局搜到**。

## 五、判据汇总

| 问 | 判据 |
|---|---|
| 源头改了我知道吗 | ⛔ 不知道 ⇒ 是单向快照，不是引用 |
| 这条来自哪 | ⛔ 答不出具体路径 = 查找能力缺失 |
| 对方改名能搜到吗 | 只有写了路径才能 |
| 硬编码阈值漂移了吗 | 找到就比对，**找不到就跳过**（别误报） |

- [ ] 跨 skill 依赖是**运行时转发**还是**单向快照**？（后者要标风险）
- [ ] 硬编码的对方阈值，漂移检查是「找到就比对，找不到就跳过」吗？
