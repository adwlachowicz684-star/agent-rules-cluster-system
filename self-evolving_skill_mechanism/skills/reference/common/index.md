## ⛔ 五种入口形态（五区对照）

⛔ **入口形态由用法类型决定，不能统一按一种组织。**
用错形态，表会"看起来完整但没人走"——读的人手上有的不是那个信息。

| 区 | 用法 | 入口形态 | 读的人手上有什么 |
|---|---|---|---|
| **howto** | 怎么做 | 按**动作** | 我在做什么事 |
| **audit** | 怎么查错 | 按**症状** | 我看到了什么现象 |
| **flow** | 按什么顺序做 | 按**场景** | 我在什么情况 |
| **craft** | 什么算好 | 按**决策点** | 我在哪两端之间取舍 |
| **common** | 元规则 | 按**困惑** | 我不知道这件事归谁 |

### ⚠ craft 曾一度被写成「按动作」

表里原先把 craft 标为"按犹豫"。对照 `craft/index.md` 实测：
它那张表的"你在做什么"列，**每一条其实都是取舍的两端**——

```
判该写到多长      → 长 vs 短
拆 / 合并文件     → 拆 vs 不拆
决定要不要自动化  → 自动 vs 人工
这次做还是记下来  → 做 vs 记
```

⇒ 所以 craft 是**按决策点**，不是按动作。
⛔ 与 howto 的区别正在此：howto 的动作是"做事"（捕获 / 入库 / 写检查器），
craft 的动作是"取舍"。把两者都叫"按动作"，就看不出这个区别了。

⚠ 判据：**这一层的内容，是在回答"怎么做"，还是在回答"选哪个"？**
后者 = 按决策点。
