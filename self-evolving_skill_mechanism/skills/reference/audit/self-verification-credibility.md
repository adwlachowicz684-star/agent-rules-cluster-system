# 自检协议·可信度类：信号有了，但真假难辨

> **本区性质：audit / 不能怎么做。**
> **信号确实产生了，但无法判断它是不是真的**——
> 「没跑起来」冒充「跑了没命中」、手填字段全同值、豁免加了却没生效。

---

## 三、三态，不要二态

「没跑起来」与「跑了但没命中」是两件事，合并成一个返回值就会互相冒充：

| 合并后 | 后果 |
|---|---|
| 失败 → 当成无结果 | 扫描器崩溃被统计成「这条没有样本」 |
| 无结果 → 当成通过 | 「未覆盖」被算进「已验证」 |

返回 `(ok, result, error)` 三元组，失败单独报出：

```python
ok, hits, err = _run_scanner(scanner, src, rule_id)
# ok=False  → 没跑起来（超时/崩溃/无输出），hits 无意义
# ok=True   → 跑起来了，hits 是多少就是多少
```

同理，统计口径也要分：「未覆盖 N 条」与「执行失败 M 条」分开报，
不要把失败并进未覆盖——那会让「到底有多少没验证」这个数字本身不可信。

## 四、检测类规则必须配正反双样本

每条能自动检出的规则，配两个样本：

| 样本 | 要求 | 证明什么 |
|---|---|---|
| `tp` | **必须命中** | 规则抓得到真问题（不是死规则） |
| `fp` | **必须不命中** | 规则不过宽（不是误报源） |

⚠ 本能会只写 tp——它直观、好造，而且跑通了很有成就感。
但**只写 tp 的规则，精度永远无法验证**：知道它抓得到，不知道它会不会误伤。

没配 fp 的规则，状态字段应停在「未验证」，不得与已验证的混在同一张表里
（见 `_hot.md` H015：混在一张表等于声称全部已验证）。

**样本形态要匹配判据作用域**：判据看单文件就给单文件样本；
判据看整棵工程（忽略清单、CI 配置、多入口的策略覆盖）就要给整棵目录，
否则样本根本触发不到那条规则，还以为规则失效了。

## 五、标注字段必须可回填

手填的状态字段（`verified` / 命中数 / 验证状态）**既没有填错的成本，
也没有填对的反馈**，于是会自然收敛到同一个值：全 `no`、全 `0`、全「未验证」。

表面「标注齐全」，实际上读的人还是得逐个怀疑——**字段活着，但已经死了**。

三条出路，按强度排：

| 强度 | 做法 |
|---|---|
| ★★★ | 能实测的 → **脚本跑完自动回填**，不许手填 |
| ★★☆ | 填不了的 → 检测退化：条目数 ≥ 阈值且取值只有一种 → 预警 |
| ★☆☆ | 至少让「未标注」可见（`lint.py` 已做） |

退化预警**不是要求标成「已验证」**，而是要求**有区分度**。
全 0 的命中列有两种可能：规则从没触发过，或触发了没人更新——
两种情况都得处理，但都不会自己报错。

## 八、豁免必须可验证

标记了豁免（`# ignore` / 白名单 / 例外清单）之后，**命中数就该减少**。
如果没减少，只有两种可能：豁免没接上，或豁免写错了位置。

实测：给某规则的三处命中加了行级豁免，命中数一条没变——
因为那条规则的分支里**根本没调用豁免判断**。
加了豁免却没生效是最容易被忽略的失效：人已经"处理过"了。

| 强度 | 做法 |
|---|---|
| ★★★ | 加豁免后立即复跑，断言命中数下降；不降就报错 |
| ★★☆ | 统计豁免标记总数 vs 实际生效数 |

⚠ 豁免位置也有讲究：只检查「上一行/本行」的实现里，
豁免注释**必须写成一行**——写成两行时第一行会滑出检查窗口，静默失效。

## 二十、未验证的结论必须条目化，不能只是一句注解

文档里写着大量"我没有实测过"的结论。这些如果和已验证结论混在一起，
读者无法区分"可以直接信"和"要先测一下"——
**而后者被当成前者用，正是最难排查的一类问题**：
代码写对了、逻辑想通了，但**前提是错的**。

⚠ **只写一句「待核实」是不够的**，它有三个问题：

| 问题 | 后果 |
|---|---|
| **无索引** | 想知道"我现在该验证哪些"要全文搜 |
| **无状态** | 验证完了也不知道记在哪 |
| **无归属** | 不知道该在什么环境验证 |

✅ 改成**条目**：有 ID、有状态、可按文档/关键词过滤、可运行时回填。

```
python3 verify.py --pending              # 现在该验证哪些
python3 verify.py --verify=V012 --result=failed --note="4.7.2 实测没有该节点"
```

**判据：能不能列出"我现在该验证哪些"？**
列不出 → 那些"待核实"只是注解，不是条目，
**等于没标**——半年后没人知道哪些结论是悬空的。

⛔ **标注"待核实"的值不得直接当生产参数用。**
